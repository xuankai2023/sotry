# 2021：绿的要她举高，绳子勒指，周末碗多一双

> 这一年要写的是 00 后爷爷奶奶外公外婆自己家里过的、手里带的。1940 年生 81 岁；1945 年生 76 岁；1950 年生 71 岁，本年主核；1955 年生 66 岁，多数已退，返聘、看门、地里或帮一天，未带孙占格。被按亮绿、提货绳、周末碗、袖管进手。天天亭、两道杠没有。不写新闻。

## 这一年祖辈站在哪

- **1940 年生**：81 岁。腰腿响。绿也费。乡的仍在地里或看门。
- **1945 年生**：76 岁。被按、提货点、灯下接，常是这一档。
- **1950 年生**：71 岁。本年主核。城的已退；乡的没有退休两个字。
- **1955 年生**：66 岁。多数已退。返聘窗口、看门、地里、路过看见、帮一天。不要写成已经是奶奶。

## 这一年祖辈手里已经有的

2011 老人机、2012 绿气泡、2017 对码失败、2018 高考周盐、2020 进不去框、门口屏、视频里嘴，本年换手：被按、绳子、周末碗、袖管。进不去框、门口屏、视频里嘴不重开。少年库写自己举、柜门、成绩页。父母库写收据、帮按、转账。天天亭、抗原不本年展开。

### G-2021-01 绿的要她举高

**时间** 2021 年进出门，店门、医院或车站｜**落在哪** 器物｜**称谓** 奶奶｜**谁家有** 城退：常被按着举；县：看谁会亮；乡留守：常常没有这道门；进城帮带：机是儿女的；远距：绿不在身边

**事实核**：总表本年深挖被按亮绿。换手 2020 门口屏，详见 G-2020-02。自己举详见少年库 T-2021-01。帮按详见父母库 P-2021-04。1955 未带孙写路过看见邻居被按，他侧身去自己窗口。不编折子月数。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 81 岁。绿太小，小了她把机转到女儿手里。 |
| 1945 | 76 岁。婆家她被按着举，举完胳膊酸。 |
| 1950 | 71 岁。孙喊举高，高了她把机推回去。 |
| 1955 | 66 岁。路过看见邻居被按手，他侧身去自己窗口。 |

现场：机被塞进她掌心。女儿按中间，按完绿的爬出来，爬完要她举高，高了门卫才扫。城退的有人被按着举，举完胳膊酸一层；有人把机倒过来，过来绿就没了。县里会的也只会按中间。乡下留守常常是门闩，闩上没有绿的。进城帮带的机是儿女的，壳滑出指。远距的奶看不见这个绿。爷说「关了」，关了她找不到键。1955 年生路过，看见邻居被按手，他侧身去窗口打卡，卡绳磨腕。她把机推回茶几，推回掌心一层汗。遥控比机熟，熟完也举不高。茶几凉一下腕，腕上一道印。

**00后祖辈现在怎么提**：被按着举高、胳膊酸一层比后来门口空了先在。乡下记得闩。谁推回过茶几，比店名清。

**当时广告 / 单位 / 生活版怎么说**：门上「请出示」。柜台不管老人举不举。居委会口头教中间。

**当时家里怎么说**：奶：「绿的在哪。」爷：「关了。」女儿：「举高。」孙：「你走开。」

**邻居牌友和其他说法**：谁家老人让儿女按，谁家只登记。未见公开争论。

**祖辈自己的一对词**：把机推回茶几 vs 让女儿按着举过眉。

**感官钩子**：绿爬出来；壳滑出指；胳膊酸；掌心汗。

**会吵什么**：再让女儿按，还是先换登记本——绿已经爬了，门已经伸手了。

**和带孙的接口**：自己举详见少年库 T-2021-01。帮按详见父母库 P-2021-04。门口屏 2020 已写，详见 G-2020-02。

### G-2021-02 提货点绳子勒指

**时间** 2021 年晚饭前，小区棚下或超市后门｜**落在哪** 灶上｜**称谓** 外婆｜**谁家有** 城退：有的去拎；县：看谁群还活；乡留守：常常没有这袋；进城帮带：袋是儿女点的

**事实核**：总表本年深挖提货绳。父母点单详见 P-2021-03。柜门详见 T-2021-02。本卡写绳、剪子、指白。1955 写帮一天拎或看门路过。价口述待核。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 81 岁。绳太紧，紧了她把袋放在地上拖。 |
| 1945 | 76 岁。娘家她去后门拎，拎完菜叶出水。 |
| 1950 | 71 岁。外孙喊名字，名完她把绳绕在腕上。 |
| 1955 | 66 岁。帮一天去拎，拎完回自己看门的凳。 |

现场：棚下绳先勒进指。外婆把袋上的字对了两遍，对完袋已经渗水，水顺着绳滴到鞋面。城退的有人晚到只剩边角，角上叶蔫，蔫完她把叶掰掉一截；有人用自己的网兜倒进去，倒完冰袋凉腕，腕上一层白霜。县里后门灯黄，黄完她还要对第二个名。乡下留守常常是灶上锅，锅沿结一层皮。进城帮带的袋是儿女点的，点不在她机里，在的是她手里的绳，绳比碗沉。1955 年生帮一天把袋放到门房，放完回自己看门的凳，凳上工卡绳还在。爷说「剪子」，剪子戳袋，戳完汤洒一脚，脚上一片凉。她把绳解开放进盆，放完指上一道白。风灌棚。蝉一声。她把叶摘掉，摘完灶已经响。

**00后祖辈现在怎么提**：绳勒指、剪子戳袋比后来到家冰箱先在。乡下记得锅。谁绕过腕，比团长清。

**当时广告 / 单位 / 生活版怎么说**：群里「来提货」。居委会不管绳。生活版写菜，现场是指。

**当时家里怎么说**：外婆：「叶子蔫了。」外公：「谁点的。」女儿：「冰袋塞灶下。」孙：「柜里也有。」

**邻居牌友和其他说法**：谁家老人去拎，谁家儿女下班才到。未见公开争论。

**祖辈自己的一对词**：绳绕在腕上拎 vs 把袋放地上拖。

**感官钩子**：绳勒指；菜叶出水；冰袋凉腕；指上一道白。

**会吵什么**：再用剪子戳，还是先等女儿来——绳已经勒了，锅已经响了。

**和带孙的接口**：提货点那袋详见父母库 P-2021-03。柜门详见少年库 T-2021-02。周末碗详见 G-2021-03。

### G-2021-03 周末孙的碗多一双

**时间** 2021 年秋季周末，婆家灶边或堂屋｜**落在哪** 带孙现场｜**称谓** 奶奶｜**谁家有** 城退：周末孙常在；县：看谁班停了；乡留守：碗本来就在；进城帮带：碗在客厅铺

**事实核**：总表本年深挖周末碗。换手是班不去了碗多一双，不是重开 2020 一张桌。楼锁详见 T-2021-03。收据详见 P-2021-01。1955 未带孙写路过看见邻居多一双碗，他回自己窗口。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 81 岁。碗多一双，双了她把咸淡再问一遍。 |
| 1945 | 76 岁。婆家她先摆碗，摆完孙还没起床。 |
| 1950 | 71 岁。周末孙的勺碰桌，碰完她把罩揭开。 |
| 1955 | 66 岁。路过看见邻居多一双碗，他回自己窗口热饭。 |

现场：周末灶上先多一双碗。奶奶把罩揭开，揭完隔夜菜结一层皮，皮粘勺。城退的有人孙书包摊在桌上，带还勒着肩；有人两个孙轮着，轮着碗要换，换完筷多一双。县里看谁班停了，没停的碗仍是一双，双边罩还扣着。乡下留守碗天天在堂屋那张桌，桌边勺磕。进城帮带的碗在客厅铺，铺上电视响，响完她把音拧小。1955 年生路过，看见邻居多一双，他回自己窗口热一份饭，饭是自己的盒。爷说「盐少点」，少完孙要辣，辣罐盖已经歪。她把勺在碗边磕一下，磕完油溅腕。门轴一响是女儿问退了没。她把罩盖回去，盖回碗还热，热气顶手。

**00后祖辈现在怎么提**：周末多一双、隔夜皮比后来托管先在。乡下记得天天都在。谁磕过勺，比班名清。

**当时广告 / 单位 / 生活版怎么说**：没有广告教摆碗。居委会不管咸淡。女儿群里问退费。

**当时家里怎么说**：奶：「多摆一双。」爷：「盐少点。」女儿：「退了没。」孙：「我不去那栋了。」

**邻居牌友和其他说法**：谁家周末人齐，谁家孙去琴。未见公开争论。

**祖辈自己的一对词**：先摆碗等孙起 vs 把罩盖回去热自己的。

**感官钩子**：隔夜菜结皮；勺磕碗边；油溅腕；碗热。

**会吵什么**：再炒一碟，还是先问退了没——碗已经多了，门已经响了。

**和带孙的接口**：楼锁详见少年库 T-2021-03。收据详见父母库 P-2021-01。谁先接详见 G-2021-08。

### G-2021-04 袖管挽到肘

**时间** 2021 年排队日，医院走廊或社区桌｜**落在哪** 自己的日子｜**称谓** 爷爷｜**谁家有** 城退：常被叫去；县：看哪天排；乡：常常桌在卫生室；1955：自己窗口或帮一天

**事实核**：总表本年深挖袖管。现场写袖、棉签球、肘凉，不写新闻词。1955 写自己窗口挽袖或路过。本卡不是带孙主场。针口述免费或几块（口述、待核）。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 81 岁。袖管挽不上，上了女儿替他卷。 |
| 1945 | 76 岁。爷把袖挽到肘，挽完棉签球冰一下。 |
| 1950 | 71 岁。号被叫到，到了他把胳膊搁上桌。 |
| 1955 | 66 岁。自己窗口也挽一回，挽完回看门的凳。 |

现场：袖管先涩。爷爷把扣解开，解开袖挽到肘，肘上一层凉，凉完血管青。城退的有人坐号等，等到名字被喊，喊完椅脚刮地；有人棉签球按住，按完一股酒精冲鼻，鼻酸一下。县里看哪天排，排的桌在大厅，厅里风扇吹纸。乡下常常卫生室一张桌，桌上铺的纸起毛，毛粘肘。1940 年生挽不上，上是女儿的手，手比他的扣熟。1955 年生自己窗口挽一回，回他看门的凳，凳上工卡绳磨白。奶在旁边拎包，包带勒腕。他胳膊搁上桌，桌上冰。针过一下，一下他没出声。他袖管放下来，放下肘上一个圆印。走廊风灌领口。他把棉签球捏紧，捏紧指还凉，凉的是酒精。

**00后祖辈现在怎么提**：袖挽到肘、棉签球冰一下比后来不用排先在。乡下记得卫生室纸。谁卷过别人的袖，比窗口清。

**当时广告 / 单位 / 生活版怎么说**：墙上「请挽袖」。柜台发号。生活版写排队，现场是肘。

**当时家里怎么说**：爷：「挽好了。」奶：「包我拎。」女儿：「号到了。」窗口：「下一位。」

**邻居牌友和其他说法**：谁家老人自己去，谁家儿女陪。未见公开争论。

**祖辈自己的一对词**：自己把袖挽到肘 vs 让女儿替他卷。

**感官钩子**：袖管涩；酒精冲鼻；桌冰；肘上一个圆印。

**会吵什么**：再等一个号，还是先把袖放下来——名字已经喊了，风已经灌了。

**和带孙的接口**：绿的被按详见 G-2021-01。本卡不演孙的红点。一张桌 2020 详见父母库 P-2020-01，只钩子。

### G-2021-05 高考周盐少一撮

**时间** 2021 年 6 月，2003 孙在的灶｜**落在哪** 灶上｜**称谓** 奶奶｜**谁家有** 城退：有的孙高考；县：看谁家轮到；乡：常常进城住；未轮到：盐不为此少

**事实核**：总表本年深挖高考周盐。换手 2018 高考周，详见祖辈库 2018。准考证角详见 T-2021-05。伞详见 P-2021-06。1955 未带孙写自己窗口盐不为此少。电视关了只点名。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 81 岁。盐少一撮，撮了她把勺停在半空。 |
| 1945 | 76 岁。婆家她把电视音拧死，死完只剩锅。 |
| 1950 | 71 岁。孙要清淡，淡完她把辣罐挪走。 |
| 1955 | 66 岁。自己窗口的菜不为此少盐，他按自己的口。 |

现场：盐罐盖先歪。奶奶捏一撮，撮完又放回去半指，指上盐涩。城退的有人电视关了，关完只剩锅沿咕嘟，嘟完她把火拧小；有人把辣罐挪到柜顶，顶上孙够不着，着的是她踮一下。县里看谁家轮到，没轮到的盐仍是老分量，量在竹筒里。乡下常常孙进城住，住的旅馆菜她尝不着，听筒问吃了没，问完灶边油还响。1955 年生自己窗口热盒饭，盒沿烫，烫完他按自己的口加一撮。爷说「少油」，油仍溅，溅完腕上一圈亮。她把勺在碗边刮一下，刮完咸淡她自己先尝，尝完才给孙。门轴一响是假条回来的人。她把罩盖上，盖上蒸汽还顶手，手上潮。

**00后祖辈现在怎么提**：盐放回去半指、辣罐上柜顶比后来外卖进门先在。乡下记得听筒问吃了没。谁关过电视，比分数清。

**当时广告 / 单位 / 生活版怎么说**：没有广告教少盐。生活版写陪考，现场是撮。

**当时家里怎么说**：奶：「少一点。」爷：「电视关了。」女儿：「伞我打。」孙：「别问。」

**邻居牌友和其他说法**：谁家这周菜变淡，谁家照旧。未见公开争论。

**祖辈自己的一对词**：盐放回去半指 vs 按自己的口不为此少。

**感官钩子**：盐罐盖歪；锅沿咕嘟；蒸汽顶手；辣罐在柜顶。

**会吵什么**：再少一撮，还是先把电视开——门已经响了，伞已经出去了。

**和带孙的接口**：准考证角详见少年库 T-2021-05。考点外伞详见父母库 P-2021-06。2018 高考周详见祖辈库 2018。

### G-2021-06 折子够不够

**时间** 2021 年领款日，银行窗或柜员机｜**落在哪** 钱包｜**称谓** 爷爷｜**谁家有** 城退：折子在；县：看谁有折；乡：常常没有这两个字；1955：自己那本或还没有

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 81 岁。折子字太小，小了她把单子递给女儿读。 |
| 1945 | 76 岁。爷把折子拍在玻璃上，拍完等号。 |

| 1955 | 66 岁。自己那本或看门工钱，他按自己的窗。 |

现场：折子边先起毛。爷爷把本拍在玻璃上，拍完号被叫到，到了单子热一下指，指上一道印。城退的有人说比去年厚一点，点完他数完再数，数完把角按平；有人柜员机不认他的指，指他改去人工窗，窗上玻璃凉。县里看谁有折，没折的是薄本或现金，现金在袜筒。乡下常常是地里或看门，门边是工钱。1955 年生自己那本或看门工钱，钱按自己的窗，窗上他按指。奶在后面拎袋，袋绳勒腕。他数完把单折进本，折进纸角烫。风灌大厅，灌完领口凉。他把本塞回内衣袋，袋里一层热，热的是他的胸。

**00后祖辈现在怎么提**：单子热指、数完再数比后来手机医保先在。乡下记得没有这两个字。谁拍过玻璃，比窗口清。

**邻居牌友和其他说法**：谁家厚一点，谁家仍薄。未见公开精确月数。

**祖辈自己的一对词**：数完再数塞内衣袋 vs 把单子递给女儿读。

**感官钩子**：折子边起毛；单子热指；纸角烫；内衣袋热。

**会吵什么**：再数一遍，还是先让女儿读——号已经叫了，单已经热了。

### G-2021-07 牌桌少一门

**时间** 2021 年下午，公园石桌或楼下院｜**落在哪** 自己的日子｜**称谓** 外公｜**谁家有** 城退：牌桌常在；县：看谁还出；乡：常常树下；1955：自己的局或看门路过

**事实核**：总表本年深挖牌桌。爷线。换手不是重开 2017 音响。1955 写自己的局或路过，不等于已带孙。本卡不演绿码主场，码只在进园门口点一下钩子。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 81 岁。牌太滑，滑了她只坐着看。 |
| 1945 | 76 岁。爷把茶瓶拧开，开完少一门。 |
| 1950 | 71 岁。外孙周末在家，家完他这门缺。 |
| 1955 | 66 岁。自己的局还在，在完他回看门的点。 |

现场：石桌先烫。外公把茶瓶拧开，拧完蒸汽顶手，手上少一门，门是那把空椅。城退的有人去接孙，接完这门空到晚饭，饭点牌友散了一半；有人进园门口被按一下，按完他坐下才摸牌，牌边油。县里看谁还出，不出的在家带碗。乡下常常树下，下的土末粘牌，牌滑出指。1955 年生自己的局还在，在完他回看门的点，点上工卡绳磨白。奶在家摆多一双，双他这头看不见。他把缺的那门用砖头压住位置，压完风把牌掀开一角。蝉一声，声落在茶盖上。他把茶倒进盖，盖烫唇，唇上一圈湿。他缺的那门一直空着，空到晚饭，空椅还烫，砖头压着角。

**00后祖辈现在怎么提**：少一门、砖头压位置比后来不缺人先在。乡下记得树下土。谁为接孙空过门，比牌友清。

**当时广告 / 单位 / 生活版怎么说**：公园不管缺门。生活版写休闲，现场是砖。

**当时家里怎么说**：外公：「少一门。」外婆：「碗摆了。」女儿：「你去接。」牌友：「再等一圈。」

**邻居牌友和其他说法**：谁家老人这门常空，谁家仍齐。未见公开争论。

**祖辈自己的一对词**：用砖头压住缺门再等 vs 先回家把碗摆上。

**感官钩子**：石桌烫；茶盖烫唇；土末粘牌；蝉一声。

**会吵什么**：再等一圈，还是先去灯下——门已经缺了，碗已经摆了。

**和带孙的接口**：周末碗详见 G-2021-03。灯下谁接详见 G-2021-08。绿的详见 G-2021-01，本卡不演举。

### G-2021-08 灯亮了谁先接

**时间** 2021 年秋季傍晚，小学或初中门口｜**落在哪** 房与路｜**称谓** 外婆｜**谁家有** 城退：两家常抢；县：看谁校开课后；乡：常常没有这盏；远距：接不着，听筒问

**事实核**：总表本年深挖婆家娘家谁先接。孩子坐台阶详见 T-2021-08。父母赶表详见 P-2021-02。本卡写两家手、凳、谁先喊。1955 写帮一天或看门路过，不等于外婆。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 81 岁。灯太亮，亮了她坐在自带的凳上。 |
| 1945 | 76 岁。娘家她先到，到完婆家的人在马路对面。 |
| 1950 | 71 岁。奶喊名字，外婆把手伸出去。 |
| 1955 | 66 岁。帮一天站到灯下，下完回自己看门的点。 |

现场：马路对面先有人喊名字。外婆把手伸出去，伸出婆家奶奶也在对面喊。城退的有人自带小凳，凳脚垫砖；有人把橘子剥给台阶上的孩子，孩子本还按着。县里看谁校开课后，不开的早散。乡下常常是堂屋灯，灯下碗先热。远距听筒问「接到没有」，接的是另一家。1955 年生帮一天把本接过来，接完回自己看门的点，点上工卡绳还在。爷在牌桌少一门。她把孩子袖口拽直，拽完带宽还勒。车灯扫过。她先把本抱进怀里，怀里本角烫。风灌领。她把凳收进袋，收完手还伸着。

**00后祖辈现在怎么提**：两家对喊、自带小凳比后来只剩爸妈车先在。乡下记得堂屋灯。谁先接过本，比校名清。

**当时广告 / 单位 / 生活版怎么说**：门口「课后服务」。居委会不管谁家先。生活版写接送，现场是手。

**当时家里怎么说**：外婆：「我先到。」奶奶：「对面。」女儿：「我堵着。」孙：「本写完了。」

**邻居牌友和其他说法**：谁家外婆常先到，谁家奶奶坐凳。未见公开争论。

**祖辈自己的一对词**：把手伸出去先接本 vs 坐在自带凳上等对面过马路。

**感官钩子**：对面喊名字；凳脚垫砖；橘皮；本角烫怀里。

**会吵什么**：先把本抱进怀里，还是先等对面过——名字已经喊了，车灯已经扫了。

**和带孙的接口**：台阶上本折小详见少年库 T-2021-08。赶表详见父母库 P-2021-02。牌桌少一门详见 G-2021-07。周末碗详见 G-2021-03。
