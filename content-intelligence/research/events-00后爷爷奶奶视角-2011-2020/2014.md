# 2014：红包点不开，要儿女伸手

> 这一年要写的是 00 后爷爷奶奶外公外婆自己家里过的、手里带的。1940 年生 74 岁；1945 年生 69 岁；1950 年生 64 岁，本年主核；1955 年生 59 岁，很多人还在上班，未带孙占格。2000 年生约 14 岁。春晚客厅、扫码买菜、广场舞全民、外卖晚饭没有。绿气泡打字仍难，红的方块更不会。不写新闻。

## 这一年祖辈站在哪

- **1940 年生**：74 岁。腰腿响。点红的更费。乡的仍在地里或看门。
- **1945 年生**：69 岁。城的多已退。被按着手点开，常是这一档。
- **1950 年生**：64 岁。本年主核。城的已退或刚退；乡的没有退休两个字。红包点不开、纸包、听筒，多从这一年叠上。
- **1955 年生**：59 岁。很多人还在岗。未带孙占格：打卡、看邻居被教点。不要写成已经是奶奶。

## 这一年祖辈手里已经有的

2011 老人机、电脑 QQ 视频、凳换初中门，2012 绿气泡不会回、口袋里的脸对不准，2013 语音条当吃了没、字还是不会、夜凳、折子、罩子、麻将，本年换手：红的方块点了没反应，要儿女伸手。圆键、字不会、夜凳、折子一行、奶茶桌回来的罩子不重开。少年库写亲戚群看一眼、中考前一年、平板壳。父母库写滴滴、绑卡、收据。春晚客厅、扫码、广场舞全民不前移。不会绑卡留给 2015。

### G-2014-01 红的点了，要儿女伸手

**时间** 2014 年 1 月下旬之后，过年口袋｜**落在哪** 器物 / 钱包｜**称谓** 奶奶｜**谁家有** 城退：被按着手点；县：有机的才轮到这层；乡留守：多数仍是红纸包；进城帮带：机是儿女旧的；远距：红的在儿女那边，自己看不见

**事实核**：微信红包 2014-01-27 前后上线。本年祖辈主场是点不开、要儿女伸手指。2014 春节参与的主体是一线白领，三四线许多家还陌生（南方周末 https://www.infzm.com/contents/98055 ）。2015 才是客厅跟着重摇、不会绑卡可单开。孩子没有卡详见少年库 T-2014-01。父母绑卡详见 P-2014-02。乡下多数仍是红纸包。奶线主场，爷线可在「你按错了」里出现。1955 未带孙写路过看见邻居被按手。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 74 岁。指头按在红上，红的不动。 |
| 1945 | 69 岁。儿女的手指叠上来，叠完仍是灰。 |
| 1950 | 64 岁。第一次听见几块在机里，自己摸不着。 |
| 1955 | 59 岁。还在岗，路过看见邻居被按手。 |

现场：红的一截停在屏上，她的指头按下去，按下去没反应，没反应她说「开了」，开了两个字进不了钱。儿女的手指叠上来，叠在她指甲盖上，再按一下，按完跳到要卡，卡在儿女那张里。城退的人从此少拆红纸包，少拆像儿女说机上有。县里有机的少，少就仍收信封。乡下留守堂屋是红纸包，纸包在抽屉，抽屉比群近。进城帮带的拿儿女淘汰的触屏，淘汰的也能亮红，亮完她把机翻过来扣着，扣着像没这层。远距的奶看不见红的，红的在厂里那头，她只等听筒问「给你了」。爷在旁边说「你按错了」，错了重来，重来仍是她那一下没反应。孙抢着也按，按的是「我要领」，领了也没卡。1955 年生看邻居被按手，按完去打卡。她人在灶上，灶上锅还响。

**00后祖辈现在怎么提**：自己按了没反应、儿女手指叠上来比后来会领先在。乡下记得红纸包。谁仍要人伸手，比金额清。

**当时广告 / 单位 / 生活版怎么说**：儿女口头「这个就是红包，点一下」。柜台不管老人开不开。居委会不教绑卡。

**当时家里怎么说**：奶：「开了。」爷：「你按错了。」儿女：「我帮你点。」孙：「我要领。」

**邻居牌友和其他说法**：谁家开始用机上的红，谁家仍是纸包。未见公开争论。

**祖辈自己的一对词**：让儿女点开 vs 还是收红纸包。

**感官钩子**：指头按了不动；指甲盖被叠住；机翻过来扣着；抽屉纸包。

**会吵什么**：留下这个当给过了，还是再塞一个纸包——儿女说机上有，自己要摸到才安。

**和孩子 / 父母库的接口**：孩子没有卡详见少年库 T-2014-01。谁绑卡详见父母库 P-2014-02。给孙纸包详见 G-2014-02。

### G-2014-02 纸包按平塞进口袋

**时间** 2014 年过年，口袋和堂屋｜**落在哪** 钱包｜**称谓** 爷爷｜**谁家有** 城退：纸包和机上的红并存；县：多数仍是纸；乡留守：堂屋数票子；进城帮带：纸从老家带；远距：托人带或听筒说给了

**事实核**：2013 折子是先称肉还是给杯，详见 G-2013-04，本年不重开折子一行。换手：爷给孙的仍是按平的红纸包，机里跳的他不认。点不开是奶线主场，详见 G-2014-01。孩子交压岁详见少年库 T-2014-05。不编这家精确月数。1955 未带孙写路过看见别人塞纸包。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 74 岁。纸包角要按平，按不平不塞。 |
| 1945 | 69 岁。口袋比茶几近，近了才塞。 |
| 1950 | 64 岁。孙说领到了，他仍数纸。 |
| 1955 | 59 岁。路过看见别人塞纸包，塞完去打卡。 |

现场：爷把红纸包按平，按平从自己口袋转到孙的口袋，转的时候角不能翘。儿女说「机上有」，机上有三个字他不答，答的是「这个才是」。城退的纸包里是几十，几十他数得清，数完才塞；机里跳的他看不见。县里一样按纸，按完才去菜场。乡下堂屋数票子，票子摊在桌上，桌上没有方块。进城帮带的纸从老家布袋里掏，掏出来角皱了，皱了也要按平。远距的托人带一个，带不到就听筒说「给你了」，给了孙摸不着。孙若说「我领到了」，领到了盖不住口袋里的纸。奶在灶上看他脸色，脸色比数字硬。1955 年生路过，路过看见别人塞纸包，塞完去打卡。圆键还在另一只口袋，口袋里才是他认的电话。

**00后祖辈现在怎么提**：角按平、从自己口袋转到孙口袋比机上的钱先在。乡下记得数票子。谁说这个才是，比金额清。

**当时广告 / 单位 / 生活版怎么说**：儿女口头「钱在里面」。柜台不管。居委会不管。

**当时家里怎么说**：爷：「这个才是。」奶：「你收纸的。」孙：「我领到了。」儿女：「机上有。」

**邻居牌友和其他说法**：谁家仍塞纸，谁家只让点。未见公开争论。

**祖辈自己的一对词**：按平塞进口袋 vs 认机里跳的数字。

**感官钩子**：纸包按平；口袋转一口；票子摊开；角皱了也按。

**会吵什么**：再塞一个纸包，还是认机上那几块——孙说领到了，口袋还空着要装纸。

**和孩子 / 父母库的接口**：孩子交不交详见少年库 T-2014-05。谁绑卡详见父母库。点不开详见 G-2014-01。两侧抢口袋详见 G-2014-06。

### G-2014-03 行李绳上多了本子

**时间** 2014 年寄宿回家那一天｜**落在哪** 房与路 / 带孙现场｜**称谓** 奶奶｜**谁家有** 城退：有的寄宿一周见；县：一样，绳先到；乡留守：堂屋等绳；进城帮带：绳在城；远距：听筒问到了没有

**事实核**：2013 是晚上那口钟、缝上更空，详见 G-2013-03，本年不重开夜凳。换手：一周才见，见的那天行李绳先到，绳上多了练习。父母一周见详见父母库钩子。少年课表、寄宿号详见 T-2014-02、T-2014-06。婆家奶与娘家外婆两侧，现场只演这两套。1955 未带孙写帮一天拉绳，或路过看见邻居搬。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 74 岁。绳勒手心，勒完才看见人。 |
| 1945 | 69 岁。先接绳，人在绳后头。 |
| 1950 | 64 岁。从绳上多出来的本子认孙。 |
| 1955 | 59 岁。帮一天拉绳，拉完去打卡。 |

现场：奶先看见行李绳，绳上多了一本练习，练习比人沉。她把绳结解开一圈，解开勒进手心，勒完14 岁才拐进来，侧袋鼓着，壳若在，壳从布里顶出棱。城退的一周才搬，搬的那天牌友问「你怎么不坐」。县里车站一样等绳，等的是班车，班车晚了菜先蔫。乡下堂屋绳往桌上一搁，搁完才揭罩。进城帮带的人床在客厅，绳从门口拖到床边。远距的听筒问到了没有，到了是声音。外婆若在另一侧，两侧仍不说话，说话是看谁先接绳。爷有时不来，不来那天麻将完整。1955 年生帮姐姐拉一下绳，拉完去打卡。孩子自己放下包，放下才喊饿。灰还在绳结上，灰是车上的。

**00后祖辈现在怎么提**：先解开绳结、本子比人沉比学校名字先在。城里后来比谁先撤寄宿；乡下记得堂屋那捆。两侧谁先接，比校名清。

**当时广告 / 单位 / 生活版怎么说**：车站时刻口头。儿女口头「一周回来」。居委会不管绳。

**当时家里怎么说**：奶：「这么沉。」爷：「本子又多了。」儿女：「让他自己背。」外婆：「来我家放。」

**邻居牌友和其他说法**：谁家一周才见人。未见公开争论。

**祖辈自己的一对词**：先接绳 vs 等对面那头来接。

**感官钩子**：绳结解开；本子比人沉；壳顶出棱；灰在绳结。

**会吵什么**：奶先接，还是外婆先接——孩子只回一趟，绳只能进一扇门。

**和孩子 / 父母库的接口**：孩子课表、侧袋详见少年库 T-2014-02、T-2014-06。父母一周见只钩子。窗口面包详见 T-2014-08。

### G-2014-04 别人锅里自己的糖色

**时间** 2014 年进城帮带的晚饭｜**落在哪** 灶上｜**称谓** 奶奶｜**谁家有** 进城帮带：用儿女的锅；城退：自己的灶；县：一样；乡留守：堂屋灶；远距：寄不到热的

**事实核**：2013 是孙从奶茶桌回、罩子白扣，详见 G-2013-05，本年不重开罩子主场。换手：进城的人用儿女的锅，糖色仍是她的手。1955 未带孙写帮姐姐家热一碗。少年课表详见 T-2014-02。父母门口盒饭是另一张嘴，详见 P-2014-06。2017 进城睡客厅只点名，本年写锅。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 74 岁。锅沿烫，烫完糖色才粘。 |
| 1945 | 69 岁。儿女的铲子她使不惯，使不惯就铲浅。 |
| 1950 | 64 岁。第一次在别人灶上做出自己的糖色。 |
| 1955 | 59 岁。帮姐姐热一碗，热完上班。 |

现场：奶把糖色炒进儿女的锅，锅比老家浅，浅了她手要低一寸。铲子是不粘的，不粘她使不惯，使不惯糖色粘在锅边一圈，一圈才是她认的熟。城退自己灶上的人一样等门，等门是另一套。县里没有班的，就仍等热的。乡下堂屋灶还温，温的是她的，孙若寄宿，温给自己。外婆那头若另留一碗，咸淡另一路，孙只能吃一处。进城帮带的人床在客厅，客厅闻见糖色才算开饭。远距寄不到热的，热的在听筒里问，问完她看不见碗。爷只负责盛，盛完洗手。1955 年生帮姐姐热一碗，热完去上班。门若响了，14 岁进来说吃过了，吃过了三个字带着凉，凉的是面包渣；她仍把锅端上桌，端上桌盐更重一截。壳若从书包里露出边，边进门，她骂沉。

**00后祖辈现在怎么提**：别人浅锅里那一圈糖色比后来的袋先在。城里后来把进城前移；2014 年人还从铁门回。哪一碗是婆家哪一碗是娘家，比店名清。

**当时广告 / 单位 / 生活版怎么说**：灶上没有广告。儿女口头「你们先吃」。电线杆不进厨房。

**当时家里怎么说**：奶：「再热一下。」外婆：「来我家吃。」爷：「他吃过了。」孙：「班上买了。」

**邻居牌友和其他说法**：谁家孙开始不回家吃饭。未见公开争论。

**祖辈自己的一对词**：热第二遍 vs 承认嘴里垫过了。

**感官钩子**：锅沿烫；铲子使不惯；糖色粘锅边；面包渣带凉。

**会吵什么**：在婆家等热的，还是去外婆那碗——孙只有一个晚上，嘴里已经垫过。

**和孩子 / 父母库的接口**：课表多一节详见少年库 T-2014-02。门口盒饭是父母的，详见父母库 P-2014-06。寄宿绳详见 G-2014-03。

### G-2014-05 遥控器比机近

**时间** 2014 年过年客厅或平时下午｜**落在哪** 自己的日子｜**称谓** 爷爷｜**谁家有** 城退：遥控器和茶几上的机抢；县：一样，机少；乡留守：堂屋电视更熟；进城帮带：遥控是儿女的；远距：没有这台

**事实核**：春晚客厅跟着重摇是 2015，本年不写全民摇。2013 麻将口袋条响详见 G-2013-06，本年不重开牌桌。换手：爷抓遥控器换台，孙抢茶几上的机。机上怎么点详见 G-2014-01，本卡不演红的。1955 未带孙写路过看见邻居客厅抢机，自己去打卡。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 74 岁。遥控键大，要拍一下才亮。 |
| 1945 | 69 岁。频道他熟，机他推回去。 |
| 1950 | 64 岁。第一次为遥控器跟孙抢茶几。 |
| 1955 | 59 岁。路过看见客厅抢机，抢完去打卡。 |

现场：爷把遥控器按在掌心里，按在掌心比茶几上那部机近。孙伸手要机，他不答，答的是「看这个」，这个是台上的戏。音量键在下头，下头他熟；台的键在上头，上头按错就花。城退的客厅电视开着，开着是台，台花了要拍电池盒，拍一下键才应，应完盖还松，松了要抠开看有没有锈。县里机少，少就仍是遥控。乡下堂屋电视更熟，熟的是天线，天线歪了要人出去拧，拧完雪花才住。进城帮带的遥控是儿女的，儿女的键他按错，按错台花了。远距没有这台，台在电话里听别人说演到哪。1955 年生路过，路过看见邻居客厅抢机，抢完去打卡。奶若在灶上喊开饭，他缺一门戏；奶若坐下，他的下午完整。触屏扣着，扣着像没这层。

**00后祖辈现在怎么提**：掌心里的遥控、电池盒拍一下比后来会点机先在。乡下记得拧天线。谁说看这个，比频道名清。

**当时广告 / 单位 / 生活版怎么说**：电视报节目单。儿女口头「给你看这个」。居委会不管台。

**当时家里怎么说**：爷：「看这个。」奶：「开饭了。」孙：「给我。」儿女：「让他玩一会。」

**邻居牌友和其他说法**：谁家过年让孙抢机。未见客厅全民摇。

**祖辈自己的一对词**：遥控器抓在手里 vs 把机推给孙。

**感官钩子**：遥控在掌心；电池盒拍一下；台花了；天线要出去拧。

**会吵什么**：让孙玩机，还是把台换回去——戏还没到头，茶几上已经亮了。

**和带孙的接口**：点不开详见 G-2014-01。打卡详见 G-2014-08。听筒详见 G-2014-07。

### G-2014-06 两双手碰到同一只口袋

| 1950 | 64 岁。第一次为谁先塞跟对面抢。 |
| 1955 | 59 岁。路过看见两家递纸。 |

现场：纸包在灶台边，边还沾着油。奶把角按平，外婆也把角按平，两双手碰到同一只口袋，口袋热，热的是孙刚从外头回来。先塞进去的人像给过了。城退的两侧若都想给，给的仍是纸，纸比机先落地；第二家再塞，塞得第一张挤歪，歪了角从袋口翘出来。县里只有一侧有机，没机的先塞纸，先塞的像占了岗。乡下没有方块，两侧仍不说话，说话是看谁的纸更厚。进城帮带的人在城，城的纸从布袋里掏。远距的纸到不了两侧，到不了就等儿女念「给了」。爷在旁边说「给她」，给她是让奶先塞，塞完罩子才揭。1955 年生路过，路过看见两双手递纸。孙的袋口拉链只开一半，开一半只能进一家。

**00后祖辈现在怎么提**：两双手碰到口袋、油纸角比后来自己会点开先在。谁先塞，比金额清。

**当时广告 / 单位 / 生活版怎么说**：儿女口头「你们都给一个」。柜台不管。居委会不管。

**当时家里怎么说**：奶：「我先。」外婆：「给我。」爷：「给她。」孙：「我有了。」

**邻居牌友和其他说法**：谁家两侧抢一只口袋。未见公开争论。

**祖辈自己的一对词**：先塞纸包 vs 等对面那头先塞。

**感官钩子**：纸包沾油；两双手；口袋热；另一家的角还翘。

**会吵什么**：奶先塞，还是外婆先塞——一只口袋只能先进一家，灶上还留着人。

**和孩子 / 父母库的接口**：孩子交不交详见少年库 T-2014-05。谁的卡详见父母库。点不开详见 G-2014-01。

### G-2014-07 听筒问接到没有

**时间** 2014 年有晚自习或寄宿的晚上｜**落在哪** 房与路｜**称谓** 外婆｜**谁家有** 远距：听筒在老家；乡留守：墙上铃；进城帮带：人在城，问的是另一头；城退：有的仍拨一次才安

**事实核**：2013 是按住一条当吃了没，详见 G-2013-01，本年不重开绿条主场。换手：远距的人看不见门，只问接到没有；条若回了她听不清，听不清就再拨。父母谁接详见 P-2013-07，本年只钩子。1955 未带孙写自己班上的听筒，问的是车间。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 74 岁。铃响要扶墙，扶完才问到了吗。 |
| 1945 | 69 岁。听筒热，热完还要再拨。 |
| 1950 | 64 岁。第一次用接到没有代替看见人。 |
| 1955 | 59 岁。打卡口旁边的听筒，问车间到了没有。 |

现场：墙上铃一响，外婆先问「接到没有」，接到没有四个字是人名，不是群。远距的人看不见灯，看不见灯就听声音；声音若糊，糊了把听筒换到另一只耳朵，换完再拨一遍。乡留守堂屋只有这一只铃，铃是人声。进城帮带的人在城，城的她问老家那头接到没有，问完才揭自己的锅。城退有的仍拨一次才安，安了才去坐下。县里有机的少，少就仍靠圆键。爷在旁边说「问清楚」，问清楚是哪一个孙。1955 年生听筒在打卡口旁边，旁边问的是车间到了没有。孙若抢着按「我到了」，到了两个字进条里，条走了她人还在听筒边。灰在听筒绳上，绳绕两圈才挂得稳。

**00后祖辈现在怎么提**：听筒换耳朵再拨、问接到没有比后来视频先在。乡下记得墙上铃。谁再拨一次，比群名清。

**当时广告 / 单位 / 生活版怎么说**：儿女口头「发一条就行」。柜台不管。居委会不管。

**当时家里怎么说**：外婆：「接到没有。」奶：「我听不清。」爷：「问清楚。」孙：「我到了。」

**邻居牌友和其他说法**：谁家晚上还在拨。未见公开争论。

**祖辈自己的一对词**：听筒问到了 vs 认条里那一声。

**感官钩子**：墙上铃；听筒热；绳绕两圈；换耳朵再拨。

**会吵什么**：再拨一次，还是留下那条——儿女要省话费，自己要听见人。

**和孩子 / 父母库的接口**：孩子按到了详见少年库 T-2013-01，本年只钩子。谁吩咐走到灯那儿详见父母库 P-2013-07。点不开详见 G-2014-01。

### G-2014-08 钟口咬一下

**时间** 2014 年工作日，打卡口或车间｜**落在哪** 自己的日子｜**称谓** 还不是奶奶的那一档｜**谁家有** 城：还在岗的打卡；县：厂或单位；乡：地里或没有卡；未带孙：这张主场

**事实核**：1955 年生本年约 59 岁，很多人还在岗，不要写成已经是奶奶。2013 已单独给自己的日子，本年换手：路过看见邻居被按红的，自己卡塞进钟口。打卡仍是纸卡、考勤钟或磁卡。养老金折子不是她的本。孙若没有，现场没有辅导班和校门。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 74 岁。看他们排队打卡，自己早退了。 |
| 1945 | 69 岁。有的刚退，退了才轮到绳。 |
| 1950 | 64 岁。刚退的看 59 岁还在玻璃口。 |
| 1955 | 59 岁。本年主核。卡塞进去，钟口咬一下。 |

现场：59 岁的人把考勤卡塞进钟口，钟口咬一下，咬一下卡边热。晚了要按红钮，红钮在钟侧面，侧面按完才算今天。城的单位走廊灯还亮；厂里磁卡刷一下，刷一下闸栏抬，抬的是工位。县里一样排队，队是下班，下班没有孙在灯下等。乡下没有打卡两个字，字是日出，日出下地。未带孙的人口袋里若有儿女淘汰的机，机里群是自己班上的，班上丢文件，文件要回「收到」。邻居奶被按着手点红的，她路过看见，看见像别人的家。茶馆若喊她，她说「明天」，明天还要来。工资信封比折子薄或厚，厚薄是工龄。孙若没有，饭桌上没有空卡拍响。1950 年生在客厅抓遥控，她在打卡口数自己的钟。

**00后祖辈现在怎么提**：钟口咬一下、晚了按红钮比后来被叫奶奶先在。还在岗的人 2014 年很多没有凳。谁路过看见别人点不开，比退休证清。

**当时广告 / 单位 / 生活版怎么说**：打卡钟「迟到」。单位小黑板关灯。居委会不管她还在岗。

**当时家里怎么说**：自己：「我还没退。」同事：「打了吗。」邻居：「你家孙呢。」儿女：「你少加班。」

**邻居牌友和其他说法**：谁家 59 岁还在打，谁家已经接绳。未见全员已退已带孙。

**祖辈自己的一对词**：卡塞进钟口 vs 去接那根绳。

**感官钩子**：钟口咬一下；卡边热；红钮在侧面；闸栏抬。

**会吵什么**：再加班一年，还是回家看邻居的绳——钟还认这张卡，堂屋已经有人一周才见。

**和带孙的接口**：红包、纸包、绳、锅详见本年其余卡。本卡不抢 14 岁主场。
