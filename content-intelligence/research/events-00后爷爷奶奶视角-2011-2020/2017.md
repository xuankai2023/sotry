# 2017：广场音响震牙，手被按着对码，沙发铺成一张床

> 这一年要写的是 00 后爷爷奶奶外公外婆自己家里过的、手里带的。1940 年生 77 岁；1945 年生 72 岁；1950 年生 67 岁，本年主核；1955 年生 62 岁，很多人还在上班或刚退，未带孙占格。2000 年生约 17 岁。刷脸、抖音大字、高考周菜变好没有。绿气泡打字仍难。不写新闻。

## 这一年祖辈站在哪

- **1940 年生**：77 岁。腰腿响。音响也费。乡的仍在地里或看门。
- **1945 年生**：72 岁。城的多已退。广场、对码、沙发铺，常是这一档。
- **1950 年生**：67 岁。本年主核。城的已退；乡的没有退休两个字。音响、对码失败、客厅铺，多从这一年叠上。
- **1955 年生**：62 岁。很多人还在岗或刚把工卡交回窗口。未带孙占格：自己窗口、自己路过广场、自己单元门。不要写成已经是奶奶。

2011 老人机、电脑 QQ 视频、凳换初中门，2012 绿气泡不会回、口袋里的脸对不准，2013 语音条当吃了没、字还是不会、夜凳、折子、罩子、麻将，2014 红的点了要儿女伸手、纸包按平、行李绳、别人锅、遥控器、两家口袋，2015 客厅跟着摇、号填不进、铁门纸包、婆家先塞机、听筒三个数、中考早饭少盐、高中门凳、工卡摘下来，2016 秤边数纸、机被孙抽走、外婆先搁碗、牌桌缺一门、公交网袋、再刷工卡、听筒只有呼吸、阳台撑衣，本年换手：音响震牙、手被按着对码、沙发铺开。数两遍、抽机、缺一门、网袋勒指不重开。少年库写校门口车把、模考条。父母库写楼道挪把、空椅子、圆筒。刷脸、抖音大字、高考周不前移。

### G-2017-01 广场音响把牙震麻

**时间** 2017 年傍晚，城或县的广场｜**落在哪** 自己的日子｜**称谓** 奶奶｜**谁家有** 城退：有的晚上去；县：文化站或广场；乡：场坝有的有，有的没有；未带孙：这张更能站满；远距：音响不在身边

**事实核**：总表本年深挖广场舞音响。2016 牌桌缺一门已写，详见 G-2016-04。本年换手：拉杆箱、低音、牙震。不是 2011 全民现场。1955 未带孙写下班路过，音响从身后推过来，他侧身去打卡。父母圆筒是客厅礼物，详见 P-2017-03。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 77 岁。低音一来，牙先麻，麻了她站外边。 |
| 1945 | 72 岁。拉杆箱推到她脚边，脚边土末。 |
| 1950 | 67 岁。牙被震麻，她把音量钮往下拨。 |
| 1955 | 62 岁。下班路过，音响从身后推过来，他侧身去打卡。 |

现场：广场地砖热。她把拉杆箱停在白线外，停完低音先顶上来，顶上来牙麻一截，麻了她把钮往下拨，拨完领舞喊「再开」。城退的人有的晚上能来，来了手绢绕腕，腕上勒一道；有人被叫去校门，叫去箱还开着，开着牌友缺一门。县里文化站一样震，震了蝉在树上叫。乡下场坝有的也有一只箱，箱是别人的，别人的要先让。远距的奶听不见这只，只在儿女那头。爷在树荫说「太响」，响她不回。孙伸手要按钮，钮被按住。1955 年生下班路过，路过箱从身后推过来，推过来他侧身，侧身去打卡。箱面烫掌心，掌心换一只手。牙还麻，麻完她才跟上第一步。

**00后祖辈现在怎么提**：牙麻一截、拉杆箱烫比后来的耳机先在。乡下记得场坝那只。谁拨过钮，比曲名清。

**当时广告 / 单位 / 生活版怎么说**：居委会「文明音量」。柜台不管箱。广告不教牙麻。

**当时家里怎么说**：奶：「再开。」爷：「太响。」儿女：「早点回。」孙：「我按。」

**邻居牌友和其他说法**：谁家晚上能去，谁家总缺。场坝有箱的少。

**祖辈自己的一对词**：把钮拨低再跳 vs 牌扣着出门。

**感官钩子**：牙麻一截；地砖热；箱面烫掌心；手绢勒腕。

**会吵什么**：再跳一支，还是先推箱回家——牙还麻着，钮已经拨低。

**和带孙的接口**：空椅子详见父母库 P-2017-02。牌桌缺一门 2016 已写，详见 G-2016-04。客厅圆筒详见父母库 P-2017-03、G-2017-07。

**祖辈自己的一对词**：把手抽回数纸 vs 让女儿按着扫完。

**感官钩子**：塑封油码；手被按着转圈；找零凉；折子比码近。

**会吵什么**：留下这几张当给过了，还是再对一次——秤已经跳，口袋要摸到才安。

### G-2017-03 客厅沙发铺成一张床

**时间** 2017 年进城帮带，女儿家客厅｜**落在哪** 房与路｜**称谓** 外婆｜**谁家有** 城：有的睡客厅；县：一样；乡留守：人在堂屋，铺不在城；远距：铺在视频里看不见；婆家另写灶

现场：客厅灯一关。她把床单塞进沙发缝，塞完缝里有泡沫末，末是礼盒掉的，掉了她拍一拍。城的女儿家客厅常这样铺，铺完行李箱立在电视柜边，柜边她的鞋并齐；有人圆筒在茶几上，茶几她不敢碰，碰了灯会亮。县里一样铺，铺完能听见隔壁炒菜。乡下堂屋有自己的床，床不在这套沙发。远距的铺看不见。外公若同来，来的睡另一头，头要让过门。孙从卧室探头，探头先看鞋。1955 年生自己宿舍床，床是铁架，架上没有校徽。门缝风凉，凉的是楼道车把挡过的那阵。枕巾潮，潮了她翻一面。早上第一双鞋响，响完她已经坐直。

**00后祖辈现在怎么提**：沙发缝泡沫、行李箱立着比后来的次卧先在。娘家记得缝。谁拍过泡沫末，比月数清。

**邻居牌友和其他说法**：谁家老人睡客厅，谁家还有一间。未见公开争论。

**祖辈自己的一对词**：床单塞进沙发缝 vs 回堂屋自己的床。

**感官钩子**：沙发缝泡沫末；行李箱立着；枕巾潮；门缝风凉。

**会吵什么**：再住一阵，还是先买票——行李箱还立着，缝已经熟了。

| 1955 | 62 岁。本年主核。窗口要扫，他把纸按回去。 |

现场：62 岁的人把几张纸按在窗口玻璃上，按完托盘灯不亮，不亮收银指一下旁边，旁边他摇头，摇头纸还按着。城的有人刚过这岁，这岁食堂换了托盘；有人窗口已经催交工卡，催交他说明年。县里厂一样，一样他按纸。乡下没有工卡两个字，字是日出。口袋里若有儿女淘汰的机，机里群是自己班上的，班上要回位置。茶馆若喊他去广场，他说「下班」。工资信封比折子薄或厚，厚薄是工龄。窗口玻璃上一圈哈气，哈气里他数自己的卡，数完卡边冰一下。闸栏锈，锈完掌心一粉。纸按回去，回去他去打卡。挂绳还温，温了饭票角软。托盘边油，油他不碰。

**00后祖辈现在怎么提**：纸按回去、摇头比后来被叫奶奶先在。还在岗的人 2017 年很多没有凳。谁窗口按过自己的纸，比退休证清。

**当时广告 / 单位 / 生活版怎么说**：窗口「请扫码」。单位小黑板关灯。居委会不管他还在岗。

**当时家里怎么说**：自己：「我还没退。」同事：「扫了吗。」邻居：「你家孙呢。」儿女：「你少加班。」

**邻居牌友和其他说法**：谁家 62 岁还按纸，谁家已经交卡。未见全员已退已带孙。

**祖辈自己的一对词**：把纸按回玻璃 vs 让人按着手扫。

**感官钩子**：纸按玻璃；托盘灯不亮；挂绳还温；饭票角软。

**会吵什么**：再挂一年，还是交了回家——窗口已经要码，堂屋已经有人一周才见。

**和带孙的接口**：音响路过、对码、沙发、盐罐、门缝、圆筒、听筒详见本年其余卡。本卡不抢 17 岁主场。再刷工卡 2016 已写，详见 G-2016-06。

### G-2017-07 圆筒亮一下不回话

**时间** 2017 年秋冬，有圆筒的客厅或路过｜**落在哪** 器物｜**称谓** 爷爷｜**谁家有** 城退：有的家茶几上有一只；县：看谁带回来；乡：常常没有；进城帮带：筒在儿女茶几；远距：筒不在身边

**事实核**：父母谁买礼盒详见 P-2017-03。少年只点名。本年祖辈换手：对着筒喊、灯亮一下、不回话。1955 未带孙写工位路过同事桌，盒子不应，他去打卡。不是刷脸。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 77 岁。筒沉，沉了喊一声费气。 |
| 1945 | 72 岁。儿女让他喊，喊完灯亮一下。 |
| 1950 | 67 岁。灯亮一下不回话，他去拿遥控器。 |
| 1955 | 62 岁。工位路过同事桌，盒子不应，他去打卡。 |

现场：茶几上那只圆筒灯先亮一下。儿女说「你喊」，喊完他对着它叫一个名字，名字喊完它不回，不回他伸手去拿遥控器，遥控器键皮已经磨亮。城退的人有的家今年才有这只，有了当摆；有人它回一句，回了一句他听成噪音，噪音他关电视旋钮。县里看谁从城里带。乡下堂屋是旋钮。进城帮带的筒在女儿茶几，茶几边是她的铺，铺她把遥控器按在自己枕头下。远距的爷看不见灯。奶在灶上喊「别费电」，费电两个字盖不住灯已经亮过。孙伸手要按，按被按住。1955 年生工位同事桌上那只，只不应，不应他去打卡。底座沉，沉了桌布出印。遥控器键缝有灰，灰他熟。

**00后祖辈现在怎么提**：喊完不回、遥控器熟比后来会说话先在。乡下记得旋钮。谁拿过遥控器，比唤醒词清。

**当时广告 / 单位 / 生活版怎么说**：盒子「会听话」。柜台不管老人喊不喊。居委会不教名字。

**当时家里怎么说**：爷：「不理人。」奶：「别费电。」儿女：「你再喊。」孙：「我来。」

**邻居牌友和其他说法**：谁家老人碰筒，谁家筒当摆。未见全县一只。

**祖辈自己的一对词**：喊一声再等 vs 直接拿遥控器。

**感官钩子**：灯亮一下；遥控器键皮磨亮；听成噪音；键缝有灰。

**会吵什么**：再喊一遍，还是关了——灯已经亮过，电视还没开。

**和孩子 / 父母库的接口**：礼盒谁拆详见父母库 P-2017-03。耳塞听课详见少年库 T-2017-03。沙发铺详见 G-2017-03。路由器字详见父母库 P-2016-07。

### G-2017-08 堂屋空席她拍平

**时间** 2017 年晚上，留守堂屋或远距｜**落在哪** 带孙现场｜**称谓** 奶奶｜**谁家有** 城：少，人在同一间；县：有的周末空；乡留守：席在堂屋；进城帮带：空席在老家；远距：这张主场

**事实核**：2016 听筒只有呼吸已写，详见 G-2016-07。本年换手：空席、拍平、席草扎手、问的是进城那头铺哪张。少年邮包详见 T-2017-07。父母汇款问条详见 P-2017-07。1955 未带孙写自己工位午休床，床上没有空席。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 77 岁。席沉，沉了拍一下也费腕。 |
| 1945 | 72 岁。堂屋空席，她把草边拍平。 |
| 1950 | 67 岁。枕套翻过来，翻过来没有孙的味。 |
| 1955 | 62 岁。自己工位午休床，床上没有空席。 |

现场：堂屋那张席空着。她把席拍平，拍完席草扎进指缝，指缝红一道，红完枕套翻过来，翻过来没有孙的味。城的少这张空席，席在同一间卧室。县里有的周末空，空了她也拍，拍完等听筒。乡下留守更常，常了她把空枕立到墙根，墙根潮。进城帮带的空席在老家，老家是她拍；她人在沙发缝边，缝另有一张。远距的奶看不见缝，缝在儿女那边。爷从地里回来，回来灶里添了柴。孙说「我要看」，看的是空席，席上没有人。听筒若响，她问一句「铺哪张」就挂，挂完草还扎着手。1955 年生自己午休床一躺，躺完去打卡。邮包绳还在桌上，绳头磨白。席边土末，末粘腕。

**00后祖辈现在怎么提**：空席拍平、席草扎手比后来天天视频先在。堂屋记得枕套没有味。谁立过空枕，比通话分钟清。

**当时广告 / 单位 / 生活版怎么说**：儿女口头「打给你」。柜台不管席。居委会不教拍平。

**当时家里怎么说**：奶：「铺哪张。」爷：「门开着。」孙：「席空了。」儿女：「卷到了没。」

**邻居牌友和其他说法**：谁家席空着拍，谁家让孙接听筒。未见全员面对面。

**祖辈自己的一对词**：把空席拍平再问 vs 让孙自己划开看。

**感官钩子**：席草扎指缝；枕套没有味；空枕立墙根；席边土末。

**会吵什么**：再拍一遍，还是先问铺——草还扎着手，听筒已经挂了。

**和孩子 / 父母库的接口**：邮包卷边软详见少年库 T-2017-07。汇款单边问条详见父母库 P-2017-07。客厅沙发铺详见 G-2017-03。听筒只有呼吸 2016 已写，详见 G-2016-07。
