# 2013：语音条当「吃了没」

> 这一年要写的是 00 后爷爷奶奶外公外婆自己家里过的、手里带的。1940 年生 73 岁；1945 年生 68 岁；1950 年生 63 岁，本年主核；1955 年生 58 岁，很多人还在上班，未带孙占格。2000 年生约 13 岁。红包、扫码买菜、广场舞全民、外卖晚饭没有。绿气泡打字仍难，本年换的是按住出声。不写新闻。

## 这一年祖辈站在哪

- **1940 年生**：73 岁。腰腿响。按住更费。乡的仍在地里或看门。
- **1945 年生**：68 岁。城的多已退。被教按住说话，常是这一档。
- **1950 年生**：63 岁。本年主核。城的已退或刚退；乡的没有退休两个字。语音条、空凳、折子，多从这一年叠上。
- **1955 年生**：58 岁。很多人还在岗。未带孙占格：打卡、看邻居被教机。不要写成已经是奶奶。

## 这一年祖辈手里已经有的

2011 老人机、电脑 QQ 视频、凳换初中门，2012 绿气泡不会回、口袋里的脸对不准、空凳、折子不换机、隔夜菜、麻将、被推进圈，本年换手：按住一条当「吃了没」，字还是不会。少年库写语音、奶茶桌、丢卡。父母库写余额宝、工作群、盒饭。红包、扫码、广场舞全民不前移。

### G-2013-01 按住一条，当「吃了没」

**时间** 2013 年口袋、儿女按住的那一下｜**落在哪** 器物 / 带孙现场｜**称谓** 奶奶｜**谁家有** 城退：被教按住说；县：有的有，有的仍听筒；乡留守：多数仍是听筒；进城帮带：机是儿女旧的；远距：条在儿女那边，自己听筒问

**事实核**：语音条当「吃了没」是本年祖辈主场，2011–2012 禁止写成老人会按住说，详见 G-2012-01。本年换手：不会打字的人被按着手指，出一声「吃了」。不能写成老人自己会打字、会回绿气泡。少年按「到了」详见 T-2013-01。父母流量详见 P-2013-06。乡下多数仍是听筒。奶线主场，爷线可在「你按错了」里出现。1955 未带孙写看邻居被按手。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 73 岁。按住费，费了是气声。 |
| 1945 | 68 岁。被按着手，松口说吃了。 |
| 1950 | 63 岁。第一次用一条代替打电话。 |
| 1955 | 58 岁。还在岗，路过看见邻居被按手。 |

现场：儿女按住她的手指，指头按在绿条上，条往前长，她被说「现在说话」。她说「吃了」，吃了两个字进条里，条松手才走。城退的人从此少拨墙上的号，少拨不像学会了，像儿女不接听筒。条若发出去没人回，她仍去拨，拨通才算人在。县里有机的少，少就仍靠圆键。乡下留守墙上座机铃一响，响的是人声，不是条。进城帮带的拿儿女淘汰的触屏，淘汰的也能按，按完她把机翻过来扣着，扣完再揭罩。远距的奶听不见自己的条，条在厂里那头，她只等听筒问「吃了没」。爷在旁边说「你按错了」，错了重来，重来仍是出声，不是打字。孙抢着也按，按的是「我到了」，到了比吃了晚一截。1955 年生看邻居被按手，按完去打卡，打卡不是带孙。绿的条走了，走了像她回过了，她人在灶上。

**00后祖辈现在怎么提**：按住说「吃了」那一下比后来自己会打字先在。乡下记得听筒。谁仍要拨通才放心，比语音时长清。

**当时广告 / 单位 / 生活版怎么说**：儿女口头「这个简单，按住说」。柜台不管老人出不出声。居委会不教语音条。不是新华社。

**当时家里怎么说**：奶：「吃了。」爷：「你按错了。」儿女：「松手。」孙：「我帮你。」

**邻居牌友和其他说法**：谁家开始用条问吃了没，谁家仍是听筒。未见公开争论。

**祖辈自己的一对词**：按住说吃了 vs 还是拨通才算。

**感官钩子**：指头被按住；条往前长；机翻过来扣着；铃还是座机的。

**会吵什么**：留下这条当报到，还是听筒打一次——儿女要听声音，自己要拨通才安。

**和孩子 / 父母库的接口**：孩子按到了详见少年库 T-2013-01。流量谁加详见父母库 P-2013-06。字还是不会详见 G-2013-02。

### G-2013-02 条会出声，字还是不会

**时间** 2013 年同一只口袋｜**落在哪** 器物｜**称谓** 爷爷｜**谁家有** 城退：条会了，气泡字仍停；县：有机才轮到这层；乡留守：没有字这层；进城帮带：机是旧的；远距：字在儿女那边

**事实核**：2012 主场是绿气泡不会回，详见 G-2012-01。本年不重写「我不会」当主角度，换手：语音会出声了，打字仍不会，孙替打的她不认。朋友圈仍不是老人主场。1955 未带孙写路过看见别人盯着绿字。视频对不准 2012 已写，只点名。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 73 岁。字更小，小的仍不回。 |
| 1945 | 68 岁。条发出去，字停着。 |
| 1950 | 63 岁。第一次让孙打，打完不像自己说的。 |
| 1955 | 58 岁。未带孙的路过看见别人盯字。 |

现场：爷把机递回去，「字我不会」。儿女要他回「好」，好一个字他找不着键，键上没有他认的笔画。城退的人会按住出声，出声是「好」，好进了条；气泡里别人打来的字仍停着，停着像没看见。孙抢过去打一行，一行是「收到」，收到不是他的嘴，他不认，不认就又去拨墙上的号。县里没机的家没有这层别扭，别扭是有机才有的。乡下没有绿字，绿字是后来的。进城帮带的旧机键盘更滑，滑了更不会。远距的字他看不见，看见要等儿女念。奶在灶上听他嘀咕「这不是我说的」，说的是孙打的那一行。1955 年生路过，路过看见老人盯着绿字不回，不回不是自己的班。圆键还在另一只口袋，口袋里才是他认的电话。

**00后祖辈现在怎么提**：不认孙打的那一行，比后来学会拼音先在。有机的家才有这层别扭。谁仍要拨号，比输入法清。

**当时广告 / 单位 / 生活版怎么说**：儿女口头「你说就行，字不用管」。柜台不管。居委会不管。

**当时家里怎么说**：爷：「字我不会。」奶：「你说。」孙：「我帮你打。」儿女：「回一个好。」

**邻居牌友和其他说法**：谁家孙代打，谁家只出声。未见公开争论。

**祖辈自己的一对词**：出声当回了 vs 不认别人打的字。

**感官钩子**：键上没有笔画；孙打的收到；圆键另一只口袋；盯着绿字不回。

**会吵什么**：让孙打一行，还是自己出声，还是拨号——三条里他只信拨通。

**和孩子 / 父母库的接口**：孩子课间仍是 QQ，详见少年库 T-2013-05。谁买的机详见父母库。语音主场见 G-2013-01。

### G-2013-03 晚自习那晚，凳更空

**时间** 2013 年有晚自习的晚上｜**落在哪** 带孙现场 / 房与路｜**称谓** 奶奶｜**谁家有** 城退：晚上缝上空；县：有晚自习才空；乡留守：寄宿一周才凳；进城帮带：凳在新门；远距：听筒问接到没有

**事实核**：2012 是下午有时自己走、凳还去不去，详见 G-2012-03。本年换手：晚上那口钟，缝上更空。父母谁接详见 P-2013-07。少年散场详见 T-2013-07。不写案件。婆家奶与娘家外婆两侧，现场只演这两套。1955 未带孙写路过看邻居夜凳空着。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 73 岁。夜里缝更凉。 |
| 1945 | 68 岁。口袋钥匙还在，人更晚。 |
| 1950 | 63 岁。第一次把晚上也给牌或给灶。 |
| 1955 | 58 岁。未带孙的看邻居夜凳空着。 |

现场：奶把凳腿塞进水泥缝，缝还是那条，天已经黑。人流出校徽，13 岁有时自己拐向灯下的店，店比缝远，远了凳上就空。城退的夜凳像没来，没来牌友不问，问的是「这么晚你还坐」。县里有晚自习的一排凳，排里有的人先走，走是去巷口等车铃；没有晚自习的，这口空不存在。寄宿的一周才搬，搬的那天行李绳先到。进城帮带的人凳在，床在客厅。远距的听筒问接到没有，接的是声音，声音本年也可能是一条，条她听不清就再拨。外婆若在另一侧，两侧仍不说话，说话是看谁先空。爷有时不来，不来晚上麻将更完整。1955 年生路过，路过看见空凳，空凳不是自己的班。孩子自己走了，走了奶还是先坐一会，坐一会像岗位没撤。灰还在凳腿上，灰夜里看不清。

**00后祖辈现在怎么提**：夜里空凳那一下比学校名字先在。城里后来比谁先撤夜岗；寄宿的记得一周。两侧谁空，比校名清。

**当时广告 / 单位 / 生活版怎么说**：学校止步线、晚自习时间。儿女口头「让他自己走」。居委会不管凳。

**当时家里怎么说**：奶：「我还是去。」爷：「太黑了。」儿女：「走到灯那儿。」外婆：「我在这边。」

**邻居牌友和其他说法**：谁家夜凳开始空。未见公开争论。不写案件。

**祖辈自己的一对词**：夜里还占缝 vs 晚上也给牌。

**感官钩子**：夜里缝凉；空凳；车铃在巷口；灰看不清。

**会吵什么**：奶还去，还是外婆去，还是都不去——孩子只出一扇门，缝上只能空一张。

**和孩子 / 父母库的接口**：孩子散场详见少年库 T-2013-07。谁吩咐走到灯那儿详见父母库 P-2013-07。

### G-2013-04 折子一行，本城数待核

**时间** 2013 年领金那几天到买肉｜**落在哪** 钱包｜**称谓** 爷爷｜**谁家有** 城退：折子或卡；县：企业薄，机关厚；乡留守：新农保薄或仍无本；进城帮带：折子在老家；远距：儿女问够不够

**事实核**：人社部口径，2013 年全国企业参保退休人员调整后月人均基本养老金 1856 元（人民政协网转人社部 https://www.rmzxw.com.cn/c/2014-06-25/343966.shtml ）。本城数待核。2012 是厚一行仍不换机，详见 G-2012-04。本年换手：孙要十块奶茶或充卡，这一行先给肉还是给孙。不编这家精确月数。乡不要写成人人有城里折子。1955 还在岗的拿工资，不是这本。余额宝是儿女的，不进折子。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 73 岁。数完才敢称肉。 |
| 1945 | 68 岁。孙伸手要十块，十块像二两。 |
| 1950 | 63 岁。一行比去年厚一点，先按在肉上。 |
| 1955 | 58 岁。还在岗，不是这本折子；未带孙占格。 |

现场：爷在银行玻璃外数，数的是新的一行，一行比去年厚一点。孙在旁边说「充卡」或「喝一杯」，一杯十块，十块他听得懂，懂了看奶的脸。城退的卡和折子并存，并存怕拿错；儿女若还提换机，换机他仍不答，答的是先称肉。县里一样数，数完去菜场，菜场不谈余额宝，宝是儿女手机里的。乡下新农保若已有，薄得像意思，意思给不了卡；没有本的仍靠地里。进城帮带的折子在老家，城里买菜用儿女塞的零，零花完了才想起那一行。远距的儿女问够不够给孙，他答「行」，行是肉还够。奶在菜场按五花，按完看他脸色，脸色比杯硬。1955 年生还在岗，岗上信封不是折子，未带孙的只看见邻居排队。份子若还要随，随完这行更不敢给杯。

**00后祖辈现在怎么提**：先称肉、再看孙伸手那一下，比后来扫码先在。乡下记得薄或没有。谁把十块按出去，比调资口头清。

**当时广告 / 单位 / 生活版怎么说**：银行代发。居委会通知领。生活版有调资消息，现场是数行。不写社论。

**当时家里怎么说**：爷：「这个月紧。」奶：「肉少称一斤。」孙：「我要充。」牌友：「又调了？」

**邻居牌友和其他说法**：谁家机关厚、谁家企业薄。乡的没有本，比不了。未见公开争论。

**祖辈自己的一对词**：先称肉 vs 把十块给孙。

**感官钩子**：玻璃外数；五花按下去；孙伸手；杯两个字。

**会吵什么**：十块给孙，还是按在肉上——一行就这些，闸机不抬不是他的窗。

**和父母库的接口**：谁充卡、谁给杯详见父母库 P-2013-04。2012 不换机只点名。余额宝不进折子。

### G-2013-05 孙从奶茶桌回来，罩子白扣

**时间** 2013 年工作日晚上｜**落在哪** 灶上｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：罩子扣着；县：一样，有店的才喊吃过了；乡留守：堂屋灶；进城帮带：用儿女的锅；远距：寄不到热的

**事实核**：2012 是晚归、隔夜、便利店瓶上水珠，详见 G-2012-05。本年换手：孙从奶茶桌回，嘴里先说「吃过了」，罩子等于白扣。外卖当晚饭没有。1955 未带孙写帮姐姐家热一碗。少年桌详见 T-2013-02。父母盒饭是另一张嘴，本卡不重写工位。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 73 岁。菜边先蔫。 |
| 1945 | 68 岁。罩子揭开又盖上。 |
| 1950 | 63 岁。第一次听见吃过了是甜的。 |
| 1955 | 58 岁。未带孙的帮姐姐热一碗。 |

现场：奶把罩子扣上，扣上青菜边已经蔫，蔫了还要等门响。门响，13 岁进来说「吃过了」，吃过了三个字带着甜，甜的不是她的灶。城退的家里常热第二遍，第二遍盐更重，重了孙也不说；本年有的连第二遍都省了，省了是承认杯已经垫过。县里没有店的，这句话不存在，不存在就仍等热的。乡下堂屋灶还温，温的是她的，孙若寄宿，温给自己。外婆那头若另留一碗，咸淡另一路，孙只能吃一处。进城帮带的用儿女的锅，锅里的糖色仍是她的手。远距寄不到热的，热的在听筒里问「吃了没」，吃了没本年也可能是一条，条回「吃了」，吃了她看不见碗。爷只负责盛，盛完洗手。1955 年生帮姐姐热一碗，热完去上班。杯壁若还带着水，水珠进门，奶骂冰的，冰的不是她的灶。

**00后祖辈现在怎么提**：吃过了带着甜那一下比菜单先在。城里后来把外卖前移；2013 年没有骑手。哪一碗是婆家哪一碗是娘家，比店名清。

**当时广告 / 单位 / 生活版怎么说**：灶上没有广告。儿女口头「你们先吃」。灯箱不进厨房。

**当时家里怎么说**：奶：「再热一下。」外婆：「来我家吃。」爷：「他吃过了。」孙：「甜的。」

**邻居牌友和其他说法**：谁家孙开始不回家吃饭。未见公开争论。

**祖辈自己的一对词**：热第二遍 vs 罩子白扣。

**感官钩子**：罩子边蔫；嘴里的甜；杯壁水珠；堂屋灶温。

**会吵什么**：在婆家等热的，还是去外婆那碗——孙只有一个晚上，桌上已经垫过。

**和孩子 / 父母库的接口**：奶茶桌详见少年库 T-2013-02。盒饭是父母的，详见父母库 P-2013-03。

| 1950 | 63 岁。晚上也空了，第一次把夜给牌。 |
| 1955 | 58 岁。还在岗；未带孙的打卡是主场。 |

现场：爷把牌码好，码好听见奶说「他今晚晚自习」，晚自习四个字像放行更长。洗牌的响还在桌上，口袋里忽然震一下，震的是一条，条他听不清，听不清就让奶听，奶听完说「吃了」，吃了两个字够不够他不答，答的是再来一把。城退的茶馆风扇对着后颈，后颈汗，汗滴在牌上。县里茶馆一样要选，选完茶钱先拍在桌角。乡下场坝有牌就打，没牌就蹲。进城帮带的牌友不熟，不熟就看，看完还是要问钟。远距没有局，局在电话里听别人胡。1955 年生打卡口玻璃还亮，亮着不是爷爷。奶若仍去占夜缝，他缺一门；奶若在家，他的晚上完整。推倒不是不爱孙，是腿已经答应了牌。茶钱几块拍在桌角，拍完才抓。触屏扣着，扣着不像会回字。

**00后祖辈现在怎么提**：晚自习放行更长那一下，比胡牌先在。口袋里条响还打，比会不会用机清。

**当时广告 / 单位 / 生活版怎么说**：麻将馆茶钱口头。单位打卡铃还在。居委会不管牌。不是新闻。

**当时家里怎么说**：爷：「再来一把。」奶：「条响了。」儿女：「你少打。」牌友：「差一门。」

**邻居牌友和其他说法**：谁家退了还去门口，谁家把晚上给牌。未见公开争论。

**祖辈自己的一对词**：再来一把 vs 先听那一条。

**感官钩子**：牌上汗；口袋震一下；打卡玻璃；触屏扣着。

**会吵什么**：再打半场还是去门口瞄一眼——孩子说晚自习，缝上可能空着，条已经响了。

**和带孙的接口**：夜凳详见 G-2013-03。打卡详见 G-2013-08。不写广场舞。

### G-2013-07 婆家娘家，谁先按住听

**时间** 2013 年客厅或灶边｜**落在哪** 带孙现场 / 器物｜**称谓** 外婆 / 奶奶｜**谁家有** 城退：两侧都可能有机；县：有机的一侧先听；乡留守：没有条，仍是听筒；进城帮带：机在城；远距：条到不了两侧

**事实核**：语音条本年进带孙现场。本卡换手：婆家奶奶按住听，还是娘家外婆按住听，两侧抢的是同一条「吃了没」。2012 被推进圈详见 G-2012-07，本年不重写闪光。现场只演两套。1955 未带孙写路过看见两家老人抢机。孙的「到了」详见少年库。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 73 岁。听不清，听不清就递给另一只手。 |
| 1945 | 68 岁。先按住的人先听见。 |
| 1950 | 63 岁。第一次为一条跟对面抢。 |
| 1955 | 58 岁。未带孙的看两家抢机。 |

现场：机在灶台边震，震的是一条。奶伸手，外婆也伸手，手碰到机壳，壳热。先按住的人把气孔贴到耳边，耳边是气声，气声是「吃了」或「到了」，到了两个字像报到。城退的两侧若都有机，机里是同一句，同一句听两遍，两遍像验收。县里只有一侧有机，有机的先听，先听的像占了岗。乡下没有条，条是听筒里问，问完两侧仍不说话。进城帮带的人在城，城的机亮一下，亮给老家听筒那边听「听见了」，听见了三个字老人自己说不全。远距的条到不了两侧，到不了就等儿女念。爷在旁边说「给她」，给她是让奶听，听完罩子才揭。1955 年生路过，路过看见两双手当机，当机不是自己的孙。孙若在场抢着回，回的是自己的「到了」，到了比吃了响。

**00后祖辈现在怎么提**：两双手碰到机壳那一下比后来自己会点开先在。谁先听，比内容清。

**当时广告 / 单位 / 生活版怎么说**：儿女口头「你们都听一下」。柜台不管。居委会不管。

**当时家里怎么说**：奶：「我听。」外婆：「给我。」爷：「给她。」孙：「我回。」

**邻居牌友和其他说法**：谁家两侧抢一条。未见公开争论。

**祖辈自己的一对词**：先按住听 vs 让对面那头听。

**感官钩子**：机壳热；两双手；气孔贴耳；同一句听两遍。

**会吵什么**：奶先听，还是外婆先听——一条只能先进一只耳朵，灶上还留着人。

**和孩子 / 父母库的接口**：孩子按到了详见少年库 T-2013-01。谁的机详见父母库。圈不重写。

### G-2013-08 1955 还在打卡

**时间** 2013 年工作日，打卡口或车间｜**落在哪** 自己的日子｜**称谓** 还不是奶奶的那一档｜**谁家有** 城：还在岗的打卡；县：厂或单位；乡：地里或没有卡；未带孙：这张主场

**事实核**：1955 年生本年约 58 岁，很多人还在岗，不要写成已经是奶奶。2012 已在麻将卡占格，本年单独给自己的日子。打卡仍是纸卡、考勤钟或磁卡，不是钉钉，不是刷脸。邻居被教语音、空凳，她只路过。养老金折子不是她的本。孙若没有，现场没有奶茶和校门。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 73 岁。看他们排队打卡，自己早退了。 |
| 1945 | 68 岁。有的刚退，退了才轮到凳。 |
| 1950 | 63 岁。刚退的看 58 岁还在玻璃口。 |
| 1955 | 58 岁。本年主核。卡塞进去，钟响一下。 |

现场：58 岁的人把考勤卡塞进钟口，钟口咬一下，咬一下比绿条实。城的单位走廊灯管还亮，亮到打卡口；厂里磁卡刷一下，刷一下闸栏抬，抬的是工位，不是食堂。县里一样排队，队是下班，下班没有孙在灯下等。乡下没有打卡两个字，字是日出，日出下地。未带孙的人口袋里若有儿女淘汰的机，机里群是自己班上的，班上丢文件，文件不是「吃了没」。邻居奶被按着手按住说话，她路过看见，看见不像自己的明天，像别人的家。茶馆若喊她，她说「明天」，明天还要来。工资信封比折子薄或厚，厚薄是工龄，工龄不是带孙。孙若没有，饭桌上没有空卡拍响。1950 年生在银行玻璃外数一行，她在打卡口数自己的钟。

**00后祖辈现在怎么提**：钟口咬一下比后来被写成奶奶先在。还在岗的人 2013 年很多没有凳。谁路过看见别人按住说话，比退休证清。

**当时广告 / 单位 / 生活版怎么说**：打卡钟「迟到」。单位小黑板关灯。居委会不管她还在岗。不是新闻。

**当时家里怎么说**：自己：「我还没退。」同事：「打了吗。」邻居：「你家孙呢。」儿女：「你少加班。」

**邻居牌友和其他说法**：谁家 58 岁还在打，谁家已经占缝。未见全员已退已带孙。

**祖辈自己的一对词**：卡塞进钟口 vs 去占那条缝。

**感官钩子**：钟口咬一下；闸栏抬；路过看见按手；信封不是折子。

**会吵什么**：再加班一年，还是回家看邻居的凳——钟还认这张卡，缝上已经有空的。

**和带孙的接口**：语音、空凳、折子详见本年其余卡。本卡不抢 13 岁主场。钉钉、刷脸不本年。

## 本年不写
