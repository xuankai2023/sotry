# 带孙：门口的人、听写的人、两家抢的人

> 这是 2011–2020 爷爷奶奶外公外婆带孙本子，不是小孩课间，不是 70 后加班月供。编号 `GS-`，只写在本目录。旧祖辈库没有专篇，年份篇已经写过铁门外凳、听筒三个数、插头多一盘、机被抽走。本篇换手：两家谁先站门口、听写怎么教、偏方谁定、抢带怎么轮、红点怎么盯。删掉联播标题还能站。1950 年生主核。1955 不要写成全员已退已带孙；格子等于帮一天、自己窗口、路过看见。称谓不混：奶奶带儿子的孩子，外婆带女儿的孩子。

## 这十年祖辈站在哪（带孙这条线）

- **1940 年生**：2011 年 71 岁，2020 年 80 岁。腰腿响。城的折子在，乡的地里或看门。
- **1945 年生**：2011 年 66 岁，2020 年 75 岁。城的多已退。门口、凳、被教机常是这一档。
- **1950 年生**：2011 年 61 岁，2020 年 70 岁。主核。城的已退或刚退；乡的没有退休两个字。
- **1955 年生**：2011 年 56 岁，2020 年 65 岁。很多人还在岗或刚退。未带孙占格：看别人领、帮一天、自己窗口。

## 和年份篇的分工

年份篇禁止展开：偏方仪式单、两家抢带流程、听写怎么教。本篇才写。凳换门、纸包挥回来、听筒报数、机被抽走、插头多一盘、进城沙发铺，年份已经写过身体，本篇不重开那只手，只写谁先、怎么教、轮几天。

孩子过筐、卡密见少年库。假条、学费、家校群见父母库。月供是 70 后的账。

## 专篇主卡

### GS-01 开学两家谁先站到门口

**时间** 2011–2015 每年开学周，初中或高中门｜**落在哪** 房与路 / 带孙现场｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：两侧都能到；县：有的只一家；乡：镇上或寄宿；进城帮带：人在城；远距：听筒问到了没

**事实核**：年份篇写铁门外凳换初中门、开学谁送，详见祖辈库 2011。本卡换手：婆家奶奶先到还是娘家外婆先到，两侧抢的是同一道门缝。1955 未带孙写路过看见两家老人站门，他去自己窗口。不重开凳的身体。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 71–75 岁。腰响，常是后到的那一侧。 |
| 1945 | 66–70 岁。门口站得住，栏杆她先扶。 |
| 1950 | 61–65 岁。谁先到，多是她定，定了仍提前。 |
| 1955 | 56–60 岁。路过两家站门，回自己窗口。 |

现场：门缝先空着。奶奶把包换到左手，换完外婆的人已经站在另一侧，两侧都喊孙的小名。城退的家有的约好轮周，轮了仍会提前十分钟；不约的人抢同一道栏杆，杆上漆还热。县里常常只有一家到，到的人把水杯递过去。乡下寄宿一周才见，见的是车上，车上没有门缝。进城帮带的人从客厅铺赶来，鞋带还没系。远距的奶听筒问「到了没」，到了两个字盖不住谁先站。1955 年生下班路过，路过两家老人对着栏杆，他侧身去自己打卡口。爷在马路对面抽烟，烟比名先灭。漆热一下掌。她把水杯盖拧紧，拧完小名还在喊。

**00后祖辈现在怎么提**：谁先扶到栏杆。乡下车上喊小名。轮周仍提前那十分钟。

**当时广告 / 单位 / 生活版怎么说**：学校「不要堵门」。居委会不管两家。生活版写隔代，现场是栏杆。

**当时家里怎么说**：奶奶：「我先到。」外婆：「我们约好的。」儿子：「别吵。」孙：「你们都来了。」

**邻居牌友和其他说法**：谁家两家都到，谁家只一家。未见全员抢门。

**自己的一对词**：我先到 vs 约好轮周。

**感官钩子**：栏杆漆热；小名两侧喊；鞋带没系；烟灭。

**会吵什么**：这周谁站——婆家要近，娘家要约。

**和孩子 / 父母 / 年份的接口**：凳换门详见祖辈库 2011。接送换门详见父母库 2011。1955 窗口不是带孙。

### GS-02 听写本奶奶认不全，按手印算不算

**时间** 2011–2014，小学尾巴到初一，灯下桌｜**落在哪** 带孙现场｜**称谓** 奶奶｜**谁家有** 城退：灯下能坐；县：一样；乡留守：堂屋灯；进城帮带：灯是儿女的；远距：听筒问写完没

**事实核**：年份篇禁止展开听写怎么教。旧父母库听写条是大人饭桌。本卡换手：拼音认不全、按手印、对答案谁说对。外婆可在现场另一套：认字比奶奶多一点，仍不敢改。1955 未带孙写帮一天按手印，按完回自己窗口。不写课标。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 71–74 岁。本上字更糊，她只点「这个像」。 |
| 1945 | 66–69 岁。能坐灯下，拼音仍半认。 |
| 1950 | 61–64 岁。按手印多是她，印还湿。 |
| 1955 | 56–59 岁。帮一天按一下，回窗口。 |

现场：本子摊在灶边。奶奶把铅笔按进孙的指缝，按完拼音她只认得一半，一半她用手指点，点完说「这个像」。城退的家答案在书后，后了她不敢翻，翻了怕改错；不翻的人只喊「写完没有」。县里一样点，点完灯花爆一下。乡下堂屋煤油灯，灯下本边油。进城帮带的本是儿女买的，本上姓名她写不全，写不全就按手印，印还湿。娘家外婆若来，来了能多认两个，两个仍不改句子。远距的奶听筒问「写完没」，写完两个字盖不住对不对。1955 年生帮姐姐按一下印，按完去打卡。孙说「你不会」，奶说「先写上」。铅笔皮苦一下舌。她把本合上，合完手印还湿。

**00后祖辈现在怎么提**：手印还湿。乡下灯下说「这个像」。书后那页不敢翻。

**当时广告 / 单位 / 生活版怎么说**：文具店「听写本」。学校不管谁教。生活版写隔代辅导，现场是手印。

**当时家里怎么说**：奶奶：「这个像。」外婆：「我来看。」儿子：「别改错。」孙：「你不会。」

**邻居牌友和其他说法**：谁家老人真教，谁家只看着。未见全员会拼音。

**自己的一对词**：先写上 vs 你不会。

**感官钩子**：铅笔皮苦；手印湿；灯花；本边油。

**会吵什么**：改不改——老人要像，儿女要答案。

**和孩子 / 父母 / 年份的接口**：本子谁签详见父母库。孩子只交本，详见少年库。旧育儿听写条不重开。

### GS-03 考前偏方谁定：少盐、红糖、插头

**时间** 2015 中考、2018 高考前那几天，灶上｜**落在哪** 灶上 / 带孙现场｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：灶上能定；县：一样；乡：堂屋定；进城帮带：灶是儿女的；远距：听筒嘱咐

**事实核**：年份篇写中考早饭少放盐、高考周拔插头多一盘，详见 G-2015-06、G-2018-02。本卡换手：仪式单谁定、两家谁的方、红糖几块、电视拔不拔谁说了算。1955 未带孙写自己窗口那几天，窗口没有这盘。不重开碗沿、插头身体。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 75 / 78 岁。方是老的，盐更少。 |
| 1945 | 70 / 73 岁。红糖她称，称完搁油碗边。 |
| 1950 | 65 / 68 岁。拔不拔插头，多是她说。 |
| 1955 | 60 / 63 岁。窗口打自己的菜，没有这盘。 |

现场：外婆把红糖搁在油碗边，奶奶把盐罐推远。谁的方先说了算，算完插头还在奶手里：婆家要静，娘家要开着听个响。城退的家吵完电视黑了；县里一样推盐，推完鸡蛋另煮。乡下堂屋插头不拔，电视仍开着，开着听筒问「吃了没」。进城帮带的灶是儿女的，方仍是她的手。远距的奶嘱咐「少盐」，少盐两个字盖不住锅在哪头。1955 年生窗口打自己的菜，菜上没有红糖。爷说「吃饱就行」，行了糖仍化。碗沿甜一下唇。糖渣粘牙。她把盐罐盖盖上。插头还留在奶手里，手里凉。娘家要开着听个响，响了她仍不插回去。

**00后祖辈现在怎么提**：红糖在谁碗边。乡下电视仍开着。插头在谁手里。娘家要听个响。

**当时广告 / 单位 / 生活版怎么说**：生活版写高考食谱。居委会不管盐。现场是罐和糖。

**当时家里怎么说**：奶奶：「少盐。」外婆：「红糖补。」儿子：「别太甜。」孙：「随便。」

**邻居牌友和其他说法**：谁家拔插头，谁家仍开着。未见全员有仪式。

**自己的一对词**：少盐 vs 吃饱就行。

**感官钩子**：盐罐推远；红糖化；电视黑；碗沿甜；糖渣粘牙。

**会吵什么**：拔不拔——婆家要静，娘家要响，插头在谁手里。

**和孩子 / 父母 / 年份的接口**：少盐详见 G-2015-06。插头详见 G-2018-02。假条详见父母库。本卡不演碗沿主场。

### GS-04 婆家娘家谁先把人接走

**时间** 2011–2017 周五或放假门口｜**落在哪** 带孙现场 / 房与路｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：两侧都能接；县：有的只一家；乡：客车或堂屋；进城帮带：人已在城；远距：接不着

**事实核**：年份篇写谁接、第二遍铃，父母库有空椅子。本卡换手：两家抢带流程，谁先拉手、这周睡哪、书包扔哪辆车。1955 未带孙写路过看见两家拉同一只手，他去自己窗口。称谓不混。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 71–77 岁。常是被通知的那一侧。 |
| 1945 | 66–72 岁。能拉住书包带，带上有她的指纹。 |
| 1950 | 61–67 岁。这周睡哪，多是她争。 |
| 1955 | 56–62 岁。路过两家拉手，回窗口。 |

现场：校门口先空出两辆车。奶奶伸手，伸完外婆的人已经拉住书包带，带上两边都有指纹。城退的家有的写在日历上：单周婆家、双周娘家；写了仍会提前到。县里常常一辆车，车是先打电话的那家。乡下客车站等，等的人把袋口绳解开。进城帮带的人已经在城，城的争的是这晚睡客厅还是睡次卧。远距的奶听筒问「接走了没」，接走两个字盖不住睡哪。1955 年生下班路过，路过两双手抢同一只带，他侧身去闸栏。孙说「两边都去」，奶说「这周我」。带勒一下指。她把日历那一格按平，按完指纹还在带上。车钥匙烫一下掌。袋口绳解开，解开这晚睡哪还没定。

**00后祖辈现在怎么提**：日历上单双周。乡下客车站那根绳。书包带两边指纹。这晚睡哪还没定。

**当时广告 / 单位 / 生活版怎么说**：学校不管谁接。生活版写双家，现场是带。

**当时家里怎么说**：奶奶：「这周我。」外婆：「日历写了。」儿子：「别当着他。」孙：「两边都去。」

**邻居牌友和其他说法**：谁家真轮，谁家抢。未见全员双家。

**自己的一对词**：这周我 vs 日历写了。

**感官钩子**：书包带指纹；袋口绳；日历单双；带勒指。

**会吵什么**：这周睡哪——婆家要近，娘家要轮。

**和孩子 / 父母 / 年份的接口**：第二遍铃详见父母库 2016。开学门口详见 GS-01。1955 闸栏不是带孙。

### GS-05 行李绳谁捆，周一送到哪

**时间** 2013–2016 寄宿周一，堂屋或车站｜**落在哪** 房与路 / 带孙现场｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：有的寄宿；县：更常；乡留守：堂屋捆；进城帮带：绳在城；远距：听筒问到了没

**事实核**：年份篇写行李绳上多了本子，详见 G-2014-03。本卡换手：绳谁捆、被子谁叠、周一送到车站还是校门口、两家谁送。1955 未带孙写帮一天拉绳，拉完回窗口。不重开绳上本子身体。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 73–76 岁。被子她叠方，绳子捆不动。 |
| 1945 | 68–71 岁。绳她能勒进指缝。 |
| 1950 | 63–66 岁。送到哪，多是她定。 |
| 1955 | 58–61 岁。帮一天拉绳，回窗口。 |

现场：堂屋先空出一块地。奶奶把被子叠成方，叠完外婆来加一袋咸菜，袋口她用绳勒，勒进指缝。城退的家有的送到校门口，口上保安挥手；不让进的人送到车站，站上绳先落地。县里更常一周一趟，趟了本子在绳上只点名。乡下堂屋捆完等客车，车铃比名先响。进城帮带的绳在城，城的咸菜仍是老家味。远距的奶听筒问「到了没」，到了两个字盖不住谁捆的。1955 年生帮姐姐把绳拉紧，拉完去打卡。孙说「咸菜别放」，奶说「先带着」。麻绳刮一下腕。她把绳头塞进结里，塞完指缝还勒着。咸菜卤渗一下袋。保安挥手，挥完绳先落在车站地。她把被角再压一下。

**00后祖辈现在怎么提**：指缝那道勒印。乡下客车铃。谁加的咸菜。绳先落在车站地。

**当时广告 / 单位 / 生活版怎么说**：车站不管绳。学校「周日晚到」。生活版写寄宿，现场是勒。

**当时家里怎么说**：奶奶：「被叠方。」外婆：「咸菜。」儿子：「别太沉。」孙：「咸菜别放。」

**邻居牌友和其他说法**：谁家送到门口，谁家只到站。未见全员寄宿。

**自己的一对词**：先带着 vs 咸菜别放。

**感官钩子**：麻绳刮腕；指缝勒；客车铃；袋口咸；卤渗袋。

**会吵什么**：送到哪——老人要送到门，保安要挥手，绳先落地。

**和孩子 / 父母 / 年份的接口**：绳上本子详见 G-2014-03。寄宿号详见少年库。本卡不演本子主场。

### GS-06 听筒三个数谁先记下

**时间** 2015 年 6 月底中考、2018 年 6 月高考后｜**落在哪** 带孙现场｜**称谓** 外婆 / 奶奶｜**谁家有** 城：有的能看网；县：电话报；乡留守：听筒主场；进城帮带：人在这头，数在那头；远距：厂里噪

**事实核**：年份篇写听筒报三个数、问考完没，详见 G-2015-05、G-2018-05。本卡换手：数谁先记下、记在墙还是日历、两家谁先拨。1955 未带孙写自己听筒是组长。不重开三个数身体。志愿谁点见父母库。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 75 / 78 岁。三个数要人复述两遍。 |
| 1945 | 70 / 73 岁。能记下两个，第三个要问。 |
| 1950 | 65 / 68 岁。日历上的数多是她写，笔尖刮纸。 |
| 1955 | 60 / 63 岁。听筒是班组叫加班。 |

现场：日历先摊开。外婆听筒还在耳上，奶奶已经落笔，笔尖刮破纸。城退的家有的能看网，网上数比听筒快，快了她仍要听人报才信。县里电话主场，话里电流沙。乡下堂屋听筒更长，长了墙上一排旧数，旧数是往年。进城帮带的人在这头，数在儿女机里，机她看不清。远距厂里噪，噪了她把数写在烟盒。1955 年生听筒是组长叫加班，话里没有第几。爷说「过了就行」，行了日历仍写。笔尖刮一下指。她把日历按在灶台，按完刮破的那一格还毛。听筒换另一只耳。烟盒上那三个数被汗浸软。墙上旧数还在。

**00后祖辈现在怎么提**：日历刮破的那一格。乡下墙上旧数。谁先拨。烟盒上三个数被汗浸软。

**当时广告 / 单位 / 生活版怎么说**：招生办不管听筒。生活版写查分，现场是换耳。

**当时家里怎么说**：外婆：「我先拨。」奶奶：「我写。」儿子：「别报错。」孙：「网上有。」

**邻居牌友和其他说法**：谁家信听筒，谁家信网。未见全员会看网。

**自己的一对词**：听人报才信 vs 网上有。

### GS-14 折子那笔给不给孙

**时间** 2011–2018，银行玻璃外或堂屋｜**落在哪** 钱包 / 带孙现场｜**称谓** 爷爷 / 奶奶｜**谁家有** 城退：有折子；县：有的有；乡：新农保薄或没有；进城帮带：折子在老家；远距：问够不够

### GS-15 帮一天：窗上没有孙的名

**时间** 2011–2020 工作日，1955 年生自己的岗｜**落在哪** 自己的日子｜**称谓** 还不是奶奶的那一档｜**谁家有** 城：还在岗；县：厂或单位；乡：地里或看门口头；未带孙：这张主场

**事实核**：年份篇每年有 1955 打卡、交卡、值班表。本卡换手：帮一天带孙和自己窗口怎么切，窗上没有孙的名。格子等于现场：打卡、看门、地里，不是喂孙。1940 / 1945 / 1950 若看见，看见是别人的窗。

| 出生年 | 当时 |
|--------|------|
| 1940 | 71–80 岁。窗外椅上坐着，坐的不是这本。 |
| 1945 | 66–75 岁。路过看见别人翻表。 |
| 1950 | 61–70 岁。折子在另一扇窗口。 |
| 1955 | 56–65 岁。考勤卡塞进钟口，窗上名是自己的。 |

现场：门房桌上先摊一本。1955 年生把考勤卡塞进钟口，钟口咬一下，咬一下比绿条实。城的单位走廊灯还亮，亮的是工位那一截；厂里闸栏抬，抬的是工位。县里一样排队，队是下班，下班没有孙在灯下等。乡下没有打卡两个字，字是日出，日出下地。帮一天的人把孙送到门，送到她回窗口，窗上名是她自己的。邻居奶在栏杆抢手，她路过看见，看见两家抢栏杆，她侧身进闸。茶馆若喊她，她说「明天」，明天还要来。工资信封比折子薄或厚，厚薄是工龄。1950 年生在银行数一行，她在钟口数自己的钟。

**00后祖辈现在怎么提**：窗上没有孙的名。乡下日出下地。帮一天送回窗口。

**当时广告 / 单位 / 生活版怎么说**：单位「按时打卡」。生活版写带孙，现场是窗口。未见全员已退。

**会吵什么**：帮几天——儿女要人，窗口要她的名。
