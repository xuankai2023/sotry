# 2012：被拉进微信，绿气泡不会回

> 这一年要写的是 00 后爷爷奶奶外公外婆自己家里过的、手里带的。1940 年生 72 岁；1945 年生 67 岁；1950 年生 62 岁，本年主核；1955 年生 57 岁，很多人还在上班，未带孙占格。2000 年生约 12 岁。语音条当「吃了没」、红包、扫码、广场舞全民现场没有。微信视频 7 月才有，不会的人仍是电脑 QQ 或听筒。不写新闻。

## 这一年祖辈站在哪

- **1940 年生**：72 岁。腰腿响。绿气泡更看不清。乡的仍在地里或看门。
- **1945 年生**：67 岁。城的多已退。被拉进群、被按头拍照，常是这一档。
- **1950 年生**：62 岁。本年主核。城的已退或刚退；乡的没有退休两个字。绿气泡、折子、凳，多从这一年叠上。
- **1955 年生**：57 岁。很多人还在岗。未带孙占格：看邻居被教机、麻将少去一天。不要写成已经是奶奶。

## 这一年祖辈手里已经有的

2011 老人机、电脑 QQ 视频、凳换初中门、折子约 1511、毕业那桌、麻将、毕业照、开学谁送，本年换手：儿女把他们拉进微信，绿气泡不会回。2010 塑料凳、折子详见祖辈库 2010。月供不进他们钱包。朋友圈报平安、学区问法详见父母库。九世摊、晚自习门口详见少年库。语音条、红包不前移。

### G-2012-01 绿气泡不会回

**时间** 2012 年口袋、儿女按住的那一下｜**落在哪** 器物 / 带孙现场｜**称谓** 奶奶｜**谁家有** 城退：被拉进微信，气泡绿着；县：有的有，有的没有；乡留守：多数仍是听筒；进城帮带：机是儿女旧的；远距：气泡在儿女那边，自己看不见

**事实核**：微信在儿女口袋更常见。朋友圈 4 月才有，老人主场不是刷圈，是被拉进对话、绿气泡不会回。语音条当「吃了没」是 2013，本年禁止写成老人会按住说。少年看见大人圈详见 T-2012-02。父母发圈详见 P-2012-01。爷线可在「你按错了」里出现。1955 未带孙写看邻居被教。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 72 岁。字小，绿的更看不清。 |
| 1945 | 67 岁。被拉进去，气泡停着。 |
| 1950 | 62 岁。第一次看见绿的一串，不会回。 |
| 1955 | 57 岁。还在岗的用班上那只；未带孙的只看邻居。 |

现场：奶把机递回去，「我不会」。儿女按住她的手指，指头按在绿气泡上，气泡拉长，她松手，松手就停。城退的人被拉进家里群，群里字小，小的是「到了吗」，到了吗她不会回；孙若自己走到站，她先拨墙上的号，通了才说「接到了」，接到了三个字比绿的实。县里有机的少，少就仍靠短信，短信在圆键上。乡下留守墙上座机铃一响，响的是人声，不是绿的。进城帮带的拿儿女淘汰的触屏，淘汰的也能亮，亮了她还是把机翻过来扣着，扣完再拨。远距的奶看不见气泡，气泡在厂里那头，她只等听筒。爷在旁边说「你按错了」，错了重来，重来仍是不会回。外婆若先拨，奶的手就空着。孙要抢机看圈，圈不是她的。1955 年生看邻居被按手，按完去打卡，打卡不是带孙。绿的停在那里，停着像她还在，她人在灶上。

**00后祖辈现在怎么提**：绿气泡停着比后来的语音条先在。城里人摸得到被按住的指头；乡下记得听筒。谁不会回，比会不会滑清。

**当时广告 / 单位 / 生活版怎么说**：儿女口头「这个简单」。柜台不管老人回不回。居委会不教绿气泡。不是新华社。

**当时家里怎么说**：奶：「我不会。」爷：「你按错了。」儿女：「回一个。」孙：「我帮你。」

**邻居牌友和其他说法**：谁家被拉进去，谁家退回机。未见公开争论。牌友仍靠喊。

**祖辈自己的一对词**：绿气泡停着 vs 还是打电话。

**感官钩子**：指头被按住；字小；机翻过来扣着；铃还是座机的。

**会吵什么**：留下这个号，还是退回圆键——儿女要找得到人，自己要键上有字。

**和孩子 / 父母库的接口**：孩子看见圈详见少年库 T-2012-02。谁发报平安详见父母库 P-2012-01。

### G-2012-02 视频仍是儿女的事

**时间** 2012 年，尤其 7 月之后｜**落在哪** 器物 / 带孙现场｜**称谓** 爷爷｜**谁家有** 城退：口袋里试脸，多数对不准；县：电脑都少，口袋这层常常没有；乡留守：听筒；进城帮带：人在城，镜头对着老家；远距：厂里那头

**事实核**：微信视频约 2012-07-19 起在 iOS 4.2，安卓约 8 月（中关村在线 https://soft.zol.com.cn/308/3082467.html ）。本年只写口袋里忽然有脸、对不准、仍去摸听筒。不能写成老人自己会打。2011 电脑椅、摄像头夹子详见 G-2011-02，本年不重写脚和夹子。乡下多数仍是听筒。奶线可在旁边问「这是电话吗」。1955 未带孙写路过看见别人举机。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 72 岁。镜头正对，手不知放哪。 |
| 1945 | 67 岁。被叫看镜头，镜头在手机上更晃。 |
| 1950 | 62 岁。第一次看见脸从口袋里出来。 |
| 1955 | 57 岁。未带孙的路过看见别人举机。 |

现场：儿女把机举到爷眼前，眼前忽然有一张脸，脸会晃，晃得他对不准。城退的有人试成了，试成了也只会点头，点完手去摸圆键，圆键在另一只口袋，口袋里才是他认的电话。机壳贴到颧骨，气孔喷出热气，热气比声先到；声若断了，他问「这是电话吗」，问完儿女把机拿开，拿开他又去拨墙上的号。县里电脑都少，少就听筒报吃了没，口袋这层常常没有。乡下没有这张脸，脸是后来的。进城帮带的人在城，城的机亮一下，亮给老家听筒那边听「看见了」，看见了两个字老人自己说不出。远距那头厂里杂，杂了只能点头。奶在旁边问「挂了没」，挂了她才去揭罩。孙伸手挡镜头，挡完画面更花。1955 年生路过看见别人举机，举的不是自己的孙。爷的号仍写在墙上，墙上比绿图标近。

**00后祖辈现在怎么提**：颧骨上那一下热气比后来的熟练视频先在。乡下记得听筒。谁问「这是电话吗」，比网速清。

**当时广告 / 单位 / 生活版怎么说**：微信升级「面对面」。柜台不管老人对不准。居委会不管。生活版写视频聊天，老人现场是问这是不是电话。

**当时家里怎么说**：爷：「这是电话吗。」奶：「挂了没。」儿女：「看镜头。」孙：「我挡一下。」

**邻居牌友和其他说法**：谁家口袋里出过脸，谁家仍是听筒。未见公开争论。

**祖辈自己的一对词**：对准那张脸 vs 还是拨墙上的号。

**感官钩子**：机壳贴颧骨；气孔热气；圆键在另一只口袋；墙上的号。

**会吵什么**：再举一会儿还是去拨——儿女要看见人，自己对不准。

**和孩子 / 父母库的接口**：孩子伸手挡镜头详见少年库年龄格。谁买的机详见父母库。2011 电脑镜头只点名。语音条不本年。

### G-2012-03 凳还在，孩子有时自己走

**时间** 2012 年放学｜**落在哪** 带孙现场 / 房与路｜**称谓** 奶奶｜**谁家有** 城退：凳还占缝，有的下午空着；县：镇中门口一排；乡留守：寄宿一周才凳；进城帮带：凳在新门；远距：听筒问接到没有

**事实核**：2011 凳换初中门详见 G-2011-03。本年换手：12 岁有时被允许自己走一段，凳还去不去。父母让不让走详见 P-2012-07。少年走路详见 T-2012-07。不写案件。婆家奶与娘家外婆两侧，现场只演这两套。1955 未带孙写路过看邻居空凳。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 72 岁。缝还在，人有时不来。 |
| 1945 | 67 岁。口袋钥匙和面包，等空了。 |
| 1950 | 62 岁。第一次把凳搬回去，下午给牌。 |
| 1955 | 57 岁。未带孙的看邻居凳空着。 |

现场：奶把凳腿塞进水泥缝，缝还是去年那条。人流出校徽，12 岁有时自己拐向公交站，站比缝远，远了凳上就空。有晚自习的晚上更空。城退的空凳像没来，没来牌友会问「你孙呢」。县里一排凳，排里有的人先走，走是去巷口等车铃。寄宿的一周才搬，搬的那天行李绳先到。进城帮带的人凳在，床在客厅。远距的听筒问接到没有，接的是声音。外婆若在另一侧，两侧仍不说话，说话是看谁先空。爷有时不来，不来下午就完整。1955 年生路过，路过看见空凳，空凳不是自己的班。孩子自己走了，走了奶还是先坐一会，坐一会像岗位没撤。灰还在凳腿上。

**00后祖辈现在怎么提**：空凳那一下比学校名字先在。城里后来比谁先撤岗；寄宿的记得一周。两侧谁空，比校名清。

**当时广告 / 单位 / 生活版怎么说**：学校止步线。儿女口头「让他自己走」。居委会不管凳。

**当时家里怎么说**：奶：「我还是去。」爷：「他会走。」儿女：「走到站。」外婆：「我在这边。」

**邻居牌友和其他说法**：谁家凳开始空。未见公开争论。不写案件。

**祖辈自己的一对词**：还是占缝 vs 下午给牌。

**感官钩子**：空凳；灰在腿上；车铃在巷口；两侧不说话。

**会吵什么**：奶还去，还是外婆去，还是都不去——孩子只出一扇门，缝上只能空一张。

**和孩子 / 父母库的接口**：孩子数路口详见少年库 T-2012-07。谁吩咐走到站详见父母库 P-2012-07。

### G-2012-04 折子厚一行，不换机

**时间** 2012 年领金那几天到买肉｜**落在哪** 钱包｜**称谓** 爷爷｜**谁家有** 城退：折子或卡；县：企业薄，机关厚；乡留守：新农保薄或仍无本；进城帮带：折子在老家；远距：儿女问够不够

**事实核**：人社部回看口径，全国企业退休人员月人均基本养老金 2012 年约 1686 元（中国网转述 https://finance.china.com.cn/news/gnjj/20170530/4229724.shtml ）；当年调整后报道常见 1721 元（中国金融信息网 https://www.cnfin.com/news-xh08/a/20130619/1196020.shtml ）。本城数待核。2011 是够不够买肉、帮不帮随，详见 G-2011-04。本年换手：儿女要给他们换触屏，他们把钱按在肉上。千元安卓 800–1500，不是折子的主场。不编这家精确月数。乡不要写成人人有城里折子。1955 还在岗的拿工资，不是这本。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 72 岁。数完才敢称肉。 |
| 1945 | 67 岁。帮儿女随一份，随完紧。 |
| 1950 | 62 岁。厚了一行，仍不换机。 |
| 1955 | 57 岁。还在岗，不是这本折子；未带孙占格。 |

现场：爷在银行玻璃外数，数的是新的一行，一行大约一千六到一千七，比去年厚一点。儿女在旁边说「给你换一个能看字的」，能看字是触屏，触屏八百到一千五，一行够不够他不答，答的是先称肉。城退的卡和折子并存，并存怕拿错；机若被塞进袋，袋里圆键还在，圆键他会按。县里一样数，数完去菜场，菜场不谈双核。乡下新农保若已有，薄得像意思，意思换不了机；没有本的仍靠地里。进城帮带的折子在老家，城里买菜用儿女塞的零，零花完了才想起那一行。远距的儿女问够不够换机，他答「行」，行是肉还够。奶在菜场按五花，按完看他脸色，脸色比机硬。1955 年生还在岗，岗上信封不是折子，未带孙的只看见邻居排队。份子若还要随，随完这行更不敢换。

**00后祖辈现在怎么提**：先称肉、不换机的那一下，比后来大屏先在。乡下记得薄或没有。谁把触屏塞进袋又被退回，比调资口头清。

**当时广告 / 单位 / 生活版怎么说**：银行代发。居委会通知领。生活版有调资消息，现场是数行。不写社论。

**当时家里怎么说**：爷：「这个月紧。」奶：「肉少称一斤。」儿女：「我给你添。」牌友：「又调了？」

**邻居牌友和其他说法**：谁家机关厚、谁家企业薄。乡的没有本，比不了。未见公开争论。

**祖辈自己的一对词**：先称肉 vs 换一个能看字的。

**感官钩子**：玻璃外数；触屏被退回袋；五花按下去；圆键还在。

**会吵什么**：收下能看字的机，还是把钱按在肉上——一行就这些。

**和父母库的接口**：谁买安卓详见父母库 P-2012-04。2011 份子只点名。孙要书钱详见 G-2012-08。

### G-2012-05 孩子回来晚，隔夜菜

**时间** 2012 年工作日晚上｜**落在哪** 灶上｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：罩子扣着；县：一样；乡留守：堂屋灶；进城帮带：用儿女的锅；远距：寄不到热的

**事实核**：12 岁晚自习或自己走一段，回来更晚。本卡写灶上隔夜、咸淡、婆家娘家两套，不写父母加班主卡。外卖当晚饭没有。1955 未带孙写帮姐姐家热一碗。少年便利店详见 T-2012-06，老人只骂冰的。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 72 岁。菜边先蔫。 |
| 1945 | 67 岁。罩子揭开又盖上。 |
| 1950 | 62 岁。第一次为初中的钟热第二遍。 |
| 1955 | 57 岁。未带孙的帮姐姐热一碗。 |

现场：奶把罩子扣上，扣上青菜边已经蔫，蔫了还要等门响。城退的家里常热第二遍，第二遍盐更重，重了孙也不说。晚了就隔夜，隔夜是承认今天没有热的。县里一样，一样等。乡下堂屋灶还温，温的是她的，孙若寄宿，温给自己。外婆那头若另留一碗，咸淡另一路，孙只能吃一处。进城帮带的用儿女的锅，锅里的糖色仍是她的手。远距寄不到热的，热的在电话里问「吃了没」，吃了没不是绿气泡。爷只负责盛，盛完洗手。1955 年生帮姐姐热一碗，热完去上班。孩子若从便利店带一瓶回来，瓶上水珠，奶骂冰的，冰的不是她的灶。

**00后祖辈现在怎么提**：罩子那道印比菜单先在。城里后来把外卖前移；2012 年没有骑手。哪一碗是婆家哪一碗是娘家，比菜名清。

**当时广告 / 单位 / 生活版怎么说**：灶上没有广告。儿女口头「你们先吃」。方便面袋若在，在父母那边。

**当时家里怎么说**：奶：「再热一下。」外婆：「来我家吃。」爷：「他晚了。」孙：「我吃过了。」

**邻居牌友和其他说法**：谁家孙开始不回家吃饭。未见公开争论。

**祖辈自己的一对词**：热第二遍 vs 隔夜算了。

**感官钩子**：罩子边蔫；第二遍盐重；瓶上水珠；堂屋灶温。

**会吵什么**：在婆家等热的，还是去外婆那碗——孙只有一个晚上，便利店已经垫过。

**和孩子 / 父母库的接口**：便利店详见少年库 T-2012-06。盒饭是父母的，详见父母库，本卡不重写工位。

### G-2012-06 麻将还是还在岗

**时间** 2012 年下午｜**落在哪** 自己的日子｜**称谓** 爷爷｜**谁家有** 城退：麻将馆或楼下；县：茶馆；乡留守：场坝或没有；进城帮带：牌友不熟；远距：没有局

**事实核**：凳有时空了，下午还空不空，是自己的日子。1950 / 1955 很多人还在岗或刚退。未带孙的 1955 主场可以是打卡。禁止写成广场舞全民（2017）。语音条不进牌桌。爷线打牌，奶线可在「去不去」里出现。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 72 岁。腰不允许久坐，坐半场。 |
| 1945 | 67 岁。牌和空凳抢下午。 |
| 1950 | 62 岁。凳空了，第一次把下午给牌。 |
| 1955 | 57 岁。还在岗；未带孙的打卡是主场。 |

现场：爷把牌码好，码好听见奶说「他今天自己走」，自己走三个字像放行。洗牌的响还在桌上，他看腕上的表，表比放学铃慢，慢了也可以不走。城退的茶馆风扇对着后颈，后颈汗，汗滴在牌上，牌被他抹一下，抹完再抓。县里茶馆一样要选，选完茶钱先拍在桌角。乡下场坝有牌就打，没牌就蹲。进城帮带的牌友不熟，不熟就看，看完还是要问钟。远距没有局，局在电话里听别人胡。1955 年生打卡口玻璃还亮，亮着不是爷爷。奶若仍去占缝，他缺一门；奶若在家，他的下午完整。推倒不是不爱孙，是腿已经答应了牌。茶钱口述几块，待核。口袋里若有儿女塞的触屏，触屏扣着，扣着不像会回绿气泡。

**00后祖辈现在怎么提**：自己走三个字放行的那一下，比胡牌先在。刚退的人第一次选下午，比退休证清。

**当时广告 / 单位 / 生活版怎么说**：麻将馆茶钱口头。单位打卡铃还在。居委会不管牌。不是新闻。

**当时家里怎么说**：爷：「再来一把。」奶：「他走了。」儿女：「你少打。」牌友：「差一门。」

**邻居牌友和其他说法**：谁家退了还去门口，谁家把下午给牌。未见公开争论。

**祖辈自己的一对词**：再来一把 vs 还是去看看缝。

**感官钩子**：牌上汗；风扇后颈；打卡玻璃；触屏扣着。

**会吵什么**：再打半场还是去门口瞄一眼——孩子说自己走，缝上可能空着。

**和带孙的接口**：空凳详见 G-2012-03。不写广场舞。

### G-2012-07 被按头推进朋友圈

**时间** 2012 年 4 月之后，客厅或门口｜**落在哪** 带孙现场 / 器物｜**称谓** 外婆｜**谁家有** 城退：儿女发，老人看不见自己的脸；县：有机才发得出；乡留守：没有圈；进城帮带：人在画里；远距：照片寄不到圈

**事实核**：朋友圈是儿女的。本卡写老人被按着拍、被推进去、自己打不开那一层。不写刷圈。父母发不发脸详见 P-2012-01。婆家奶奶若在灶上，娘家外婆在镜头前，现场演这两套。1955 未带孙写路过看见别人按头。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 72 岁。闪光一白，手不知挡不挡。 |
| 1945 | 67 岁。被说笑一下，笑完问发哪。 |
| 1950 | 62 岁。第一次听见「进圈了」。 |
| 1955 | 57 岁。未带孙的看邻居被按。 |

现场：外婆被按着肩，肩对镜头，闪光白一下，白完儿女说「发了」。发了她看不见，看不见是字太小，也是没有那一层。城退的客厅里常这样，这样完娘家那边若有机，机里能赞，赞不是她点的。奶奶若不去镜头前，就在灶上听「发了」，发了像出远门报平安，平安两个字轮不到她回。县里没机的家，拍完仍洗一张纸，纸比圈实。乡下没有圈，圈是后来的。进城帮带的人在画里，画里是别人的沙发。远距的脸进不了圈，进不了就等信封。爷偶尔被拉到边上等，边上像多出来的。1955 年生路过，路过看见闪光，闪光不是自己家的。孙抢着看赞，赞是空心变实，实了与她无关。

**00后祖辈现在怎么提**：闪光白一下比后来自己会看圈先在。谁被推进去，谁只在灶上听「发了」，两边老人记得不一样。

**当时广告 / 单位 / 生活版怎么说**：微信升级页。儿女口头「让他们看看」。居委会不管。

**当时家里怎么说**：外婆：「发哪？」奶：「我看不见。」儿女：「进圈了。」孙：「我要点。」

**邻居牌友和其他说法**：谁家老人进了别人的圈。未见公开争论。

**祖辈自己的一对词**：被推进去 vs 只在灶上听发了。

**感官钩子**：闪光白；肩被按；字太小；纸比圈实。

**会吵什么**：外婆进镜头，还是奶奶进——圈里只能先发一张，灶上还留着人。

**和孩子 / 父母库的接口**：孩子乱点赞详见少年库 T-2012-02。发不发脸详见父母库 P-2012-01。

### G-2012-08 谁给孙十五块买狗书

**时间** 2012 年放学后、灶边或堂屋｜**落在哪** 钱包 / 带孙现场｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：能掏一本或租；县：租的多；乡留守：过年才有一本；进城帮带：用儿女塞的零；远距：寄不出摊

**事实核**：少年摊、父母零钱包详见 T-2012-01、P-2012-05。本卡换手：婆家奶奶掏不掏、娘家外婆掏不掏，骂不骂费眼睛。定价常见 15 元。折子那一行见 G-2012-04，本卡不重写换机。现场只演两套：奶给 vs 外婆给。1955 未带孙写看姐姐家掏。不写解题。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 72 岁。十五块像两斤肉。 |
| 1945 | 67 岁。准租不准买。 |
| 1950 | 62 岁。第一次为黄封面掏折子边。 |
| 1955 | 57 岁。未带孙的看姐姐家掏。 |

现场：孙把黄封面举到奶眼前，举到封底 15.00。奶的手在围裙兜里停一下，停的是这个月肉。城退的常准租不准买，租的一块到几块她按得下，买一本她要问爷；爷若刚数完折子，折子边抽得出，抽完骂费眼睛。外婆那头若另给，给的是另一本或同一本的租钱，孙不能两头都要。县里更常只给租。乡下过年才从城里带一本回，回的有时是盗版，盗版纸黄，黄了她也皱眉，皱眉仍塞进抽屉。进城帮带的零是儿女塞的，塞完她有时转给孙，转给就不买自己的膏药。远距寄不出摊，寄的是钱，钱到人不到。1955 年生看姐姐家掏，掏完去上班。孙若没要到，就去便利店，便利店不是她的灶。

**00后祖辈现在怎么提**：围裙兜里停住的那一下比书名先在。谁给了租钱，谁只骂费眼睛，两边老人记得不一样。

**当时广告 / 单位 / 生活版怎么说**：摊边「新到」。儿女口头「别惯」。居委会不管狗书。

**当时家里怎么说**：奶：「租。」外婆：「我给。」爷：「费眼睛。」孙：「我想买。」

**邻居牌友和其他说法**：谁家老人给买齐。未见公开争论。

**祖辈自己的一对词**：按租钱 vs 两头都要给。

**感官钩子**：围裙兜停住；封底 15.00；盗版纸黄进抽屉；膏药没买。

**会吵什么**：奶给租钱，还是外婆给买——孙只有一本的零花，两家都要当恩人。

**和孩子 / 父母库的接口**：摊、解密卡详见少年库 T-2012-01、T-2012-08。晚饭零钱详见父母库 P-2012-05。折子换机详见 G-2012-04。
