# 2011：老人机、电脑上的脸，凳挪到初中门

> 这一年要写的是 00 后爷爷奶奶外公外婆自己家里过的、手里带的。1940 年生 71 岁；1945 年生 66 岁；1950 年生 61 岁，本年主核；1955 年生 56 岁，很多人还在上班，未带孙占格。2000 年生约 11 岁。绿气泡、红包、扫码、广场舞全民现场、微信视频没有。视频通话是儿女电脑上的 QQ。不写新闻。

## 这一年祖辈站在哪

- **1940 年生**：71 岁。腰腿响。折子在的，够不够买肉自己数；乡的仍在地里或看门。
- **1945 年生**：66 岁。城的多已退。凳、门口、被举到摄像头前，常是这一档。
- **1950 年生**：61 岁。本年主核。城的已退或刚退；乡的没有退休两个字。毕业那桌、机不会滑，多从这一年叠上。
- **1955 年生**：56 岁。很多人还在岗。未带孙占格：看邻居领孙、麻将少去一天、帮着扶一下椅背。不要写成已经是奶奶。

## 这一年祖辈手里已经有的

2010 铁门外塑料凳、折子约 1300、回迁水泥地，详见祖辈库 2010，本年换手：凳挪到更远的初中门，折子月均约 1511。墙上座机、IC 卡尾巴、膏药、麻将牌还在。月供不进他们钱包。择校复印件、智能机合约详见父母库。通知书、领结详见少年库。微信在儿女口袋，不是自己的号。

### G-2011-01 老人机还在

**时间** 2011 年口袋和充电座上｜**落在哪** 器物 / 自己的日子｜**称谓** 爷爷｜**谁家有** 城退：大字按键、收音机功能；县：一样；乡留守：一部或没有，靠墙上座机；进城帮带：机是儿女旧的；远距：机在儿女那边，自己只有座机

**事实核**：2011 年触屏进柜台，老人手里仍是大字诺基亚、波导一类。少年库写摸触屏，父母库写谁签约，本卡换手：键大、铃响、不会滑。企业退休人员月人均养老金约 1511 元（人社部 http://igongyi.cntv.cn/20120629/110658.shtml ），一部智能机 1999–4999 不是他们的账。禁止写成老人已会微信。爷线写机，奶线可在「谁教」里出现。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 71 岁。键要按实，按实才响。 |
| 1945 | 66 岁。机在裤袋，袋里有钥匙。 |
| 1950 | 61 岁。刚退的人第一次发现机比打卡口近。 |
| 1955 | 56 岁。还在岗的用班上那只；未带孙的机是自己的。 |

现场：爷把机从裤袋掏出，键是圆的，圆的要按实，按实才跳出数字。城退的机带收音机，收音机比触屏先响；儿女把新机递过来，新机要滑，滑了没字，没字就还，还的时候壳还亮。县里一样，键上的数字磨白。乡下留守常没有机，墙上座机铃一响，响的是村部或堂屋，堂屋那根线比口袋远。进城帮带的人拿的是儿女淘汰的按键，淘汰的也能收「到了没」。远距的爷机不在自己身上，身上只有号码写在墙上。奶在旁边说「你按错了」，错了重来，重来仍是圆键。1955 年生未带孙的，机是班上的绳，绳不叫老人机，叫自己的。

**00后祖辈现在怎么提**：圆键磨白的那一只比后来的大屏先在。城里人摸得到袋里钥匙碰壳；乡下很多这一年没有第二部。谁不会滑，比品牌清。

**当时广告 / 单位 / 生活版怎么说**：柜台「老人机大字」。居委会不教滑。儿女口头「这个简单」。不是新华社。

**当时家里怎么说**：爷：「能响就行。」奶：「你按错了。」儿女：「滑一下。」孙：「我帮你。」

**邻居牌友和其他说法**：谁家儿女给了触屏，谁家退回来。未见公开争论。牌友仍靠喊，不靠微信。

**祖辈自己的一对词**：圆键按实 vs 滑了没字。

**感官钩子**：圆键磨白；钥匙碰壳；收音机先响；触屏还亮着被还。

**会吵什么**：收下新机还是退回——儿女要能找到人，自己要键上有字。

**和孩子 / 父母库的接口**：孩子摸触屏详见少年库 T-2011-03。谁买智能机详见父母库 P-2011-01。

### G-2011-02 视频通话是儿女的事

**时间** 2011 年客厅电脑前｜**落在哪** 器物 / 带孙现场｜**称谓** 奶奶｜**谁家有** 城退：电脑已装，摄像头另买或夹上；县：有电脑的少；乡留守：无，仍是听筒；进城帮带：人在城，摄像头对着老家；远距：厂里那头是儿女

**事实核**：微信视频约 2012-07 才有。2011 年能看见脸的，是电脑 QQ、摄像头、麦克风。宽带为了学习详见父母库 2008，本卡写老人被按在镜头前。禁止写成脸出现在手机绿气泡里。乡下多数仍是墙上听筒报吃了没，听筒详见旧祖辈库 2003，本年只点名。奶线写被按头，爷线可在旁边咳。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 71 岁。镜头正对，手不知放哪。 |
| 1945 | 66 岁。被叫「看镜头」，镜头在哪儿要问。 |
| 1950 | 61 岁。第一次看见儿女的脸在小窗里动。 |
| 1955 | 56 岁。未带孙的只帮邻居开过一次机。 |

现场：奶被按在电脑椅上，椅是给孩子写作业的，太高，脚不着地。摄像头夹在屏上，红点一亮，亮了就要笑，笑是给小窗里的人。城退的家里宽带绿灯还在，绿灯为了学习，学习两个字盖不住这张脸。县里有电脑的少，少就仍用听筒，听筒只报吃了没。乡下留守没有窗，窗是后来的；堂屋那部铃响，响完是声音，不是脸。进城帮带的奶人在城，摄像头有时对着老家空椅，空椅上没人。远距那头是厂里网吧或宿舍，宿舍里人声杂，杂了只能点头。爷在旁边咳一声，咳被当成说话，说话小窗听不清。孙被举到镜头前，举高了头碰到夹子，夹子烫。1955 年生帮邻居开过机，开完就走，走的不是自己的孙。

**00后祖辈现在怎么提**：电脑椅太高、脚不着地，比后来的手机脸先在。乡下记得听筒，不记得小窗。谁按她的头，比网速清。

**当时广告 / 单位 / 生活版怎么说**：电脑城「高清摄像头」。QQ 登录页。居委会不管。生活版写视频聊天，老人现场是被按头。

**当时家里怎么说**：奶：「我看着你。」爷：「他听不见。」儿女：「看镜头。」孙：「夹子烫。」

**邻居牌友和其他说法**：谁家能看见脸，谁家仍是听筒。未见公开争论。牌友当新鲜，新鲜不进麻将桌。

**祖辈自己的一对词**：看见脸 vs 听筒只报吃了没。

**感官钩子**：脚不着地；红点亮；夹子烫；小窗里的人声杂。

**会吵什么**：再坐一会儿还是挂——儿女要看见人，自己腿麻。

**和孩子 / 父母库的接口**：孩子被举高详见少年库年龄格。电脑谁装详见父母库。微信视频不本年。

### G-2011-03 铁门外凳还在，门换成初中门

**时间** 2011 年秋，放学那一刻｜**落在哪** 带孙现场 / 房与路｜**称谓** 奶奶｜**谁家有** 城退：凳挪到更远水泥缝；县：镇中门口一排；乡留守：寄宿则一周才凳；进城帮带：人在城，凳在新门；远距：听筒问接到没有

**事实核**：2010 祖辈库塑料凳详见 G-2010-01，父母库喇叭详见 P-2010-01。本年换门：小学那扇不再等，凳腿陷进另一条缝。不写案件。养老金约 1511，凳不花钱。少年库校服、脖子空详见 T-2011-05。婆家奶在新门，娘家外婆若来，是另一张凳，两套并入现场。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 71 岁。缝更远，腰先到。 |
| 1945 | 66 岁。口袋钥匙和一块面包，换一条路。 |
| 1950 | 61 岁。刚退的人第一次把凳搬出小区。 |
| 1955 | 56 岁。未带孙的看邻居搬凳，自己还去打卡。 |

现场：奶把凳从旧铁门那条缝拔出来，腿上的灰还在，灰要带到更远的初中门。城退的水泥缝换了，换了仍陷，陷进去才坐得住；门卫不认小学那张脸，名条换了本。县里镇中门口一排凳，排比小学长。寄宿的乡留守一周才搬一次，搬的那天行李绳比凳先到。进城帮带的人凳在新门，床在客厅。远距的奶听筒里问接到没有，接的是声音。外婆若来，凳在另一侧，两侧不说话，说话是看谁先看见校服。爷有时站着不坐，站着像还能走。1955 年生下班路过，路过帮着扶一下凳，扶完去打卡，打卡不是带孙。孩子脖子空了，空着要从人堆里被认出，认出靠校徽，不靠红领巾。

**00后祖辈现在怎么提**：两条水泥缝的距离比学校名字先在。城里后来比谁改路线；寄宿的记得一周那一趟。灰从旧缝带到新缝，比喇叭清。

**当时广告 / 单位 / 生活版怎么说**：学校「家长止步」。居委会不管凳。儿女口头「你挪过去」。不是联播。

**当时家里怎么说**：奶：「凳搬了。」爷：「我站着。」儿女：「我晚。」外婆：「我在这边。」

**邻居牌友和其他说法**：谁家奶谁家外婆先到。未见公开争论。不写案件。

**祖辈自己的一对词**：凳挪过去 vs 让他们自己走一段。

**感官钩子**：旧灰在凳腿；新缝陷进去；名条换本；两侧不说话。

**会吵什么**：奶去还是外婆去——两侧各一张凳，孩子只出一扇门。

**和孩子 / 父母库的接口**：孩子校服详见少年库 T-2011-05。谁改路线详见父母库 P-2011-05。旧凳详见祖辈库 2010。

### G-2011-04 折子本月够不够

**时间** 2011 年领金那几天到买肉｜**落在哪** 钱包｜**称谓** 爷爷｜**谁家有** 城退：折子或卡，月均约一千五；县：企业的薄，机关的厚；乡留守：新农保薄或仍无本；进城帮带：折子在老家，人在城；远距：儿女问够不够，自己不说

**事实核**：2011 年全国企业参保退休人员月人均基本养老金约 1511 元（人社部）；审计口径 1516.68 元。2011 在岗职工月均约 3538 元。机关事业更高，农村多数仍薄，新农保 2009 试点后逐年铺，不要写成乡人人有城里那本。2010 折子约 1300 详见旧库，本年只写够不够买肉、帮不帮儿女随。月供不是他们的账。爷线数折子，奶线可在买肉。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 71 岁。数完才敢称肉。 |
| 1945 | 66 岁。帮儿女随一份，随完这个月紧。 |
| 1950 | 61 岁。刚退的人第一次按月数。 |
| 1955 | 56 岁。还在岗的拿工资，不是这本折子；未带孙占格。 |

现场：爷在银行玻璃外数，数的是进折子的那一行，一行约一千五，一千五要管肉、药、有时一份份子。城退的卡和折子并存，并存就怕拿错；机关的厚一截，厚的不在本卡主场，主场是企业那本。县里一样数，数完去菜场。乡下新农保若已有，薄得像意思，意思不够称三斤；没有本的仍靠地里和儿女寄。进城帮带的折子在老家，人在城，城里买菜用儿女塞的零，零花完了才想起那一行。远距的儿女电话问够不够，够不够两个字他答「行」，行不是行。奶在菜场按五花，按完看他脸色。1955 年生还在岗，岗上的信封不是折子，未带孙的只看见邻居排队。

**00后祖辈现在怎么提**：2011 那一行一千五，比后来调资口头清。城里人摸得到玻璃外数的手；乡下记得薄或没有。份子抽走的那一次，比肉价先在。

**当时广告 / 单位 / 生活版怎么说**：银行「代发养老金」。居委会通知领。生活版有调资消息，现场是数行。不写社论。

**当时家里怎么说**：爷：「这个月紧。」奶：「肉少称一斤。」儿女：「我给你添。」牌友：「又调了？」

**邻居牌友和其他说法**：谁家机关厚、谁家企业薄，牌桌上会比。乡的没有本，比不了。未见公开争论。

**祖辈自己的一对词**：先称肉 vs 先留份子。

**感官钩子**：玻璃外数；折子一行；五花按下去；薄本像意思。

**会吵什么**：帮儿女随一百，还是这个月肉少称——一行就这些。

**和父母库的接口**：择校钱不进折子，详见父母库 P-2011-02。旧库 2010 折子只点名。

### G-2011-05 毕业那桌他们主勺

**时间** 2011 年夏，小学毕业前后一顿｜**落在哪** 灶上｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：家里加两个菜；县：馆子或家里；乡留守：堂屋；进城帮带：灶对不上，菜是这边的；远距：寄钱，桌在老家

**事实核**：少年库毕业照、父母库谁订套系，本卡换手：毕业不是影楼，是灶上多两个菜。红烧、鱼，价钱按斤，口述待核。婆家奶奶主勺是一桌，娘家外婆另做或另请是另一桌，现场只演这两套。不写酒席行业。1955 未带孙写帮邻居洗一盆菜。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 71 岁。糖色还是她的。 |
| 1945 | 66 岁。鱼要有，没有不像过。 |
| 1950 | 61 岁。刚退的人第一次为孙的毕业翻勺。 |
| 1955 | 56 岁。未带孙的帮姐姐家洗菜。 |

现场：奶在灶上炒糖色，糖色深了怕糊，糊了这桌就不像毕业。城退的家里加两个菜，加的是鱼和一份凉，凉的是面子；馆子那桌若订了，订是儿女的账，勺仍要问她咸淡。县里家里或镇上馆子，馆子转盘油。乡下堂屋请或不请，不请也有红烧，红烧是年的做法挪到夏天。外婆那桌若另做，咸淡另一路，孙要吃两回，两回都说「毕业了」。进城帮带的灶对不上，对不上就用儿女的锅，锅里的糖色仍是她的手。远距寄钱回来，钱到桌不到人。爷只负责称鱼，称完洗手。1955 年生帮姐姐家洗一盆，洗完去上班，班不是这桌。孩子领结已还，还了仍要被夹一块肥。

**00后祖辈现在怎么提**：夏天那碗红烧比相册先在。城里后来比馆子；乡下记得堂屋热。哪一桌是婆家哪一桌是娘家，比菜名清。

**当时广告 / 单位 / 生活版怎么说**：生活版「成长宴」偶有。灶上没有广告。儿女口头「简单吃」。

**当时家里怎么说**：奶：「鱼也得有。」外婆：「来我家吃。」爷：「称三斤。」儿女：「别太费。」

**邻居牌友和其他说法**：谁家办了馆子，谁家只加两个菜。未见公开争论。

**祖辈自己的一对词**：加两个菜 vs 办一桌。

**感官钩子**：糖色怕糊；转盘油；堂屋热；两回咸淡。

**会吵什么**：在婆家灶上吃，还是去外婆那桌——孙只有一个晚上。

**和孩子 / 父母库的接口**：领结、订金详见少年库、父母库。不重写影楼。

### G-2011-06 麻将还是还在岗

**时间** 2011 年下午｜**落在哪** 自己的日子｜**称谓** 爷爷｜**谁家有** 城退：麻将馆或楼下；县：茶馆；乡留守：场坝或没有；进城帮带：牌友不熟；远距：没有局

**事实核**：接送换成初中门，下午还空不空，是自己的日子。1950 / 1955 很多人还在岗或刚退。未带孙的 1955 主场可以是打卡。禁止写成广场舞全民（2017 才深挖）。爷线打牌，奶线可在「去不去接」里出现。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 71 岁。腰不允许久坐，坐半场。 |
| 1945 | 66 岁。牌和凳抢下午。 |
| 1950 | 61 岁。刚退的人第一次把下午交给牌或门。 |
| 1955 | 56 岁。还在岗；未带孙的打卡是主场。 |

现场：爷把麻将牌码好，码好听见奶说「要去门口了」，门口是新的那扇，新的更远。洗牌的响还在桌上，他看了看腕上的表，表比放学铃慢一截。城退的茶馆风扇对着后颈，后颈汗，汗滴在牌上；去门口就缺一门，缺一门有人骂。县里茶馆一样，一样要选。乡下场坝有牌就打，没牌就蹲，蹲不是局。进城帮带的牌友不熟，不熟就只能看，看完去门口。远距没有局，局在电话里听别人胡。1955 年生打卡口玻璃还亮，亮着不是爷爷，是自己还在班上；未带孙的下午不属于凳。奶若去门口，爷的下午就完整；奶若不在，他先把牌推倒。推倒不是不爱孙，是腿已经答应了牌。推倒之后椅子还热，热着也要走，新门的缝不会等人。口袋里的茶钱币还没数清，数清也来不及再坐半圈。茶钱口述几块，待核到你所在茶馆。

**00后祖辈现在怎么提**：缺一门被骂的那一下，比胡牌先在。城里人摸得到风扇后颈；乡下记得场坝。刚退的人第一次选下午，比退休证清。

**当时广告 / 单位 / 生活版怎么说**：麻将馆茶钱口头。单位打卡铃还在。居委会不管牌。不是新闻。

**当时家里怎么说**：爷：「再来一把。」奶：「门口等着。」儿女：「你少打。」牌友：「差一门。」

**邻居牌友和其他说法**：谁家退了还去门口，谁家把下午给牌。未见公开争论。

**祖辈自己的一对词**：再来一把 vs 先去占缝。

**感官钩子**：牌上汗；风扇后颈；打卡玻璃；牌被推倒。

**会吵什么**：再打半场还是先去门口——新门更远，缺一门有人骂。

**和带孙的接口**：凳详见 G-2011-03。不写广场舞。

### G-2011-07 毕业照他们去不去

**时间** 2011 年春，照相那天｜**落在哪** 带孙现场｜**称谓** 外婆｜**谁家有** 城退：操场边或影楼外；县：操场；乡留守：有的没有影楼；进城帮带：去；远距：照片寄来

**事实核**：少年库领结、父母库订金，本卡写老人去不去现场、相册谁收。婆家奶奶若去，娘家外婆或去或在灶上等，现场演外婆在操场边 + 奶奶在家收样册这两套。不写影楼史。1955 未带孙写路过操场看一眼。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 71 岁。站不住，坐在边上看。 |
| 1945 | 66 岁。给孙理领结，理完手缩。 |
| 1950 | 61 岁。第一次被叫去「站后面」。 |
| 1955 | 56 岁。未带孙的路过，看别人家横幅。 |

现场：外婆站在操场边，土末沾鞋，鞋面她弯腰拍过一下，拍完灰还在缝里。横幅被风吹斜，她不在镜头里，镜头要齐的是孩子。快门一响，她才把手从眼睛上放下来。领结是她伸手理的，理完老师来系，系完她的手空着。城的影楼外也能等，等的是样册，样册不给她翻，翻是儿女签字。奶奶若不去现场，就在家里收后来的一本，本的封皮亮，亮的衣她没见过。乡下没有影楼的，只有操场一张，一张分到户，户里老人先看「像不像」。进城帮带的外婆人在城，城的操场她认路。远距的照片寄到厂或寄到老家，寄到的那张领结是假的。爷偶尔被叫站后面，站后面像多出来的。1955 年生路过，路过看见横幅，横幅不是自己家的。快门过后孩子跑过来，她只问「眼睛有没有红」，红不红比像不像先问出口。

**00后祖辈现在怎么提**：操场边土末沾鞋，比相册衣先在。谁理了领结，谁只收封皮，两边老人记得不一样。

**当时广告 / 单位 / 生活版怎么说**：影楼不管老人。老师喊排整齐。儿女口头「你们来看看」。

**当时家里怎么说**：外婆：「我去。」奶：「我收本。」爷：「站后面？」儿女：「别进镜头。」

**邻居牌友和其他说法**：谁家老人进了合影。未见公开争论。

**祖辈自己的一对词**：去操场边 vs 在家收本。

**感官钩子**：土末沾鞋；领结她理完手空；封皮亮；横幅吹斜。

**会吵什么**：外婆去现场，还是奶奶去——镜头后面只能站一个不进画的人。

**和孩子 / 父母库的接口**：领结、订金详见少年库 T-2011-02、父母库 P-2011-04。

### G-2011-08 开学谁送，婆家还是娘家

**时间** 2011 年秋，初中开学那两天｜**落在哪** 房与路｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：两家都想送；县：一样；乡留守：送寄宿行李；进城帮带：送的人在城；远距：送不上

**事实核**：父母库换门、少年库校服，本卡写哪家老人送进门、行李谁拎。两套：婆家奶奶送 + 娘家外婆送，不能两家同时进门卫。不写教育制度。1955 未带孙写看姐姐家送。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 71 岁。拎不动大包，跟在后面。 |
| 1945 | 66 岁。口袋钥匙和校徽，校徽是她别的。 |
| 1950 | 61 岁。刚退的人第一次送进另一所。 |
| 1955 | 56 岁。未带孙的看别人家行李绳。 |

现场：奶把校徽别在孙胸口，别针冰，冰一下才松手。行李是更大的书包，有的还有寄宿袋，袋上写号。城的两家都到门口，门口门卫只进一个老人，一个跟进去，一个在线外等，等的人看校服消失。县里一样挤。乡下寄宿的行李绳勒手，勒手的是送镇的那趟，趟是农用车或摩托，摩托后座夹着袋。进城帮带的人在城，城的门她认，认了也不一定被让进。远距的老人送不上，送不上就电话里问「进了没」，进了没是门，不是心。外婆若被让进，奶的手就空着，空着回灶上。爷拎袋，拎完站线外。1955 年生看姐姐家绳，绳不是自己的班。孩子脖子空了，空着被推进人流，人流不认哪家老人。

**00后祖辈现在怎么提**：线外等的那一个，比进门的先记得。寄宿的行李绳勒手还在。哪家被让进，比校名清。

**当时广告 / 单位 / 生活版怎么说**：学校「家长止步线」。居委会不管谁送。儿女口头「一个就行」。

**当时家里怎么说**：奶：「我送。」外婆：「我送。」儿女：「别都进。」孙：「别送了。」

**邻居牌友和其他说法**：谁家两家都到，谁家只有一个。未见公开争论。

**祖辈自己的一对词**：我跟进去 vs 我在线外。

**感官钩子**：别针冰；行李绳勒；止步线；人流不认。

**会吵什么**：奶跟进去还是外婆跟进去——门卫只放一个，孙只出一次门。

**和孩子 / 父母库的接口**：校服、换门详见少年库 T-2011-05、父母库 P-2011-05。
