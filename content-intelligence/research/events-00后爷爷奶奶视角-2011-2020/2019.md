**时间** 2019 年晚饭后，婆家客厅或县城家｜**落在哪** 器物｜**称谓** 奶奶｜**谁家有** 城退：有的机被竖在茶几；县：看谁被教会划；乡留守：常常电视更大；进城帮带：机是儿女的；远距：大字不在身边

现场：茶几上机竖着。大字已经占满一屏，屏上字自己往下滚，滚完下一条音浪比她耳背还响。她按中间，按完下一条已经出声。城退的有人被女儿按着划，划完她把手抽回；有人拍遥控器，拍完机不应。县里看谁被教会，会的也只会按中间。乡下留守堂屋常常电视更大，大了她不摸这只机。进城帮带的机是儿女的，儿女把机塞进她手里，手里壳滑。远距的奶看不见这条。爷说「关了」，关了她找不到键，键在背面。孙伸手要拨，拨完音量顶到头。1955 年生路过客厅，看见字在滚，他侧身去自己窗口。她把机扣上，扣上亮还从指缝漏。椅垫潮一层，潮的是她掌心汗。

**00后祖辈现在怎么提**：大字自己滚、按不住下一条比后来会划先在。乡下记得电视更大。谁把手抽回过，比曲名清。

**当时家里怎么说**：奶：「关了。」爷：「太吵。」女儿：「再看一条。」孙：「我划。」

**祖辈自己的一对词**：把机扣上走 vs 让孙拨到下一条。

**感官钩子**：大字占满屏；音浪比耳背响；遥控器拍一下不应；亮从指缝漏。

**会吵什么**：再看一条，还是先扣上——键已经找不到，字已经滚了。

### G-2019-02 柜顶那盒倒出两粒

**时间** 2019 年早上或晚饭后，婆家灶边柜顶｜**落在哪** 钱包｜**称谓** 奶奶｜**谁家有** 城退：有的柜顶一排盒；县：看谁被送过；乡：常常没有这盒；进城帮带：盒在儿女家柜；远距：盒不在身边

**事实核**：总表本年深挖保健品还在。商超礼盒口述一两百到三四百一档（口述、待核）。少年胶带箱、父母吊牌对图不演成本卡，详见 T-2019-03、P-2019-02。本年换手：柜顶、倒两粒、说明书字小。1955 未带孙写自己窗口边倒的是工间药，盒上没有孙的名。不写骗局标题。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 79 岁。盒沉，沉了倒一下也费腕。 |
| 1945 | 74 岁。她从柜顶把盒挪下来，倒出两粒。 |
| 1950 | 69 岁。说明书字小，她把盒对灯看。 |
| 1955 | 64 岁。自己窗口边倒工间药，盒上没有孙的名。 |

现场：柜顶一层灰。她把盒挪下来，挪完盖卡扣崩开，崩开倒出两粒，粒在掌心滚一下。婆家这头奶先倒，倒完温水送；娘家那头盒若在，在的是女儿买的另一盒。城退的有人一排盒，排上日期她分不清；有人拆了不吃，不吃盒仍在最高一层。县里看谁被送过，送过的说明书字小，小了她对灯看。乡下常常没有这盒两个字，字是灶上那罐。进城帮带的柜是儿女的，儿女的盒她也倒。爷说「太贵」，贵她不回。孙伸手要那粒，粒被按住。1955 年生自己窗口边倒的是工间那板，板上没有礼盒。水沿烫一下唇。找零没有，有的是儿女说「保你」。盒边潮，潮的是她掌心。她把盒推回柜顶，推完灰粘指。

**00后祖辈现在怎么提**：柜顶挪下来、掌心两粒比后来的日历药盒先在。乡下记得灶上那罐。谁对过灯看说明书，比品牌清。

**当时广告 / 单位 / 生活版怎么说**：盒上「每日两粒」。柜台不管老人倒不倒。儿女口头「保你」。

**当时家里怎么说**：奶：「倒了。」爷：「太贵。」女儿：「吃完我再买。」孙：「甜的吗。」

**邻居牌友和其他说法**：谁家柜顶一排，谁家拆了不吃。未见公开争论。

**祖辈自己的一对词**：对灯看完倒两粒 vs 把盒推回最高一层。

**感官钩子**：盖卡扣崩开；掌心滚两粒；说明书字小对灯；柜顶灰粘指。

**会吵什么**：再倒两粒，还是先推回去——水已经温了，灰已经粘了。

**和孩子 / 父母库的接口**：胶带箱详见少年库 T-2019-03。吊牌对图详见父母库 P-2019-02，本卡不演退货。折子 2011 已写，详见 G-2011-04。月供是 70 后的账，详见父母库。

**祖辈自己的一对词**：椅自己挪到阴里坐下 vs 让牌友来接他上楼。

**感官钩子**：椅脚刮地一道白；茶瓶烫手背；草帽边汗；椅面烫腿。

**会吵什么**：再挪一寸，还是先上楼——日头已经偏了，椅脚已经白了。

### G-2019-04 校门口孙要冰她掏纸

**时间** 2019 年放学，小学铁门外，2009 年生那扇｜**落在哪** 带孙现场｜**称谓** 奶奶｜**谁家有** 城退：有的奶来接；县：铁门外小卖部；乡：场坝冰柜；进城帮带：门是城里的；远距：门不在身边

**祖辈自己的一对词**：掏纸买一根 vs 说回家有把衣角拉开。

**感官钩子**：柜沿冰腕；湿叶子贴票；冰纸粘指甜；找零凉进掌心。

### G-2019-06 工卡绳磨出一道白

**时间** 2019 年工作日，1955 年生自己还在的岗｜**落在哪** 自己的日子｜**称谓** 爷爷｜**谁家有** 城：有的 64 岁仍在窗口；县：看单位；乡：常常没有绳；未带孙：这张更能站满

**事实核**：1955 年生本年 64 岁，很多人还在岗。2018 工卡按玻璃已写，详见 G-2018-06。本年换手：绳、磨白、自己的钟。未带孙占格。1940 / 1945 / 1950 若看见，看见是别人的绳。少年工牌绳是 19 岁那根，详见 T-2019-02。定位是 70 后的圈，详见 P-2019-03。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 79 岁。走廊看见别人脖子上绳，自己折子在口袋。 |
| 1945 | 74 岁。牌友去窗口，自己要去挪椅。 |
| 1950 | 69 岁。同龄有的已退，他看别人绳上那道白。 |
| 1955 | 64 岁。本年这张主核。他的工卡绳磨出一道白。 |

现场：64 岁的人把工卡绳从后颈扯下来，扯完一道白，白完他把绳挂回窗边钩上。城的有人这年仍在岗，岗上热纸还要撕；有人刚把绳交回，交回走廊空。县里看单位，单位若没有绳，绳是别针。乡下常常没有工卡两个字，字是自己守摊。未带孙的这张更能站满，满的是自己的钟。1940 年生路过，路过绳比自己折子轻。1950 年生若已退，退了去把椅挪到阴里。1955 年生把热纸撕下来，撕完边烫指，指完他按铃。绳面毛，毛扎一下后颈。窗口油烟气冲鼻。孙不在这扇窗。下班铃先到。钩上那道白对着他。

**00后祖辈现在怎么提**：绳上那道白、后颈一扯比后来的人脸进门先在。城里后来把 64 岁前移成全员已退；2019 年很多窗口仍有这根。谁扯过自己的绳，比食堂名清。

**当时广告 / 单位 / 生活版怎么说**：门口「请刷卡」。生活版写退休，现场是自己的一道白。

**当时家里怎么说**：自己：「我扯了。」窗口：「下一份。」儿女：「你还上。」牌友：「晚上来不来。」

**邻居牌友和其他说法**：谁还在窗口，谁已经交绳。未见全员已带孙。

**祖辈自己的一对词**：工卡绳挂回窗边钩 vs 把绳交回走廊。

**感官钩子**：绳磨出一道白；后颈毛扎；热纸边烫指；钩上那道白。

**会吵什么**：再顶一小时，还是先走——白已经磨出来了，铃已经到了。

**和带孙家的接口**：19 岁工牌绳详见少年库 T-2019-02。定位转圈详见父母库 P-2019-03。工卡按玻璃 2018 已写，详见 G-2018-06。未写成已经是奶奶。

### G-2019-07 编织袋口绳勒指

**时间** 2019 年寒暑假前后，车站或镇上长途点｜**落在哪** 房与路｜**称谓** 爷爷｜**谁家有** 城：有的送到站；县：更常；乡：堂屋装完再走；进城帮带：袋从儿女家出门；远距：袋托人带

**事实核**：2014 行李绳、2018 折子路费已写，详见 G-2014-03、G-2018-04。本年换手：袋口绳、勒指、给 19 岁路上。爷线。父母生活费是键上那笔，详见 P-2019-04。1955 未带孙写自己窗口装的是工间饭盒，盒上没有站名。门口接快递不前移。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 79 岁。袋沉，沉了勒一下也费。 |
| 1945 | 74 岁。他把袋口绳勒紧，勒完指缝红一道。 |
| 1950 | 69 岁。酱瓶子烫一下他掌，掌完他塞进袋。 |
| 1955 | 64 岁。自己窗口装饭盒，盒上没有站名。 |

现场：堂屋地上一股酱味。他把油纸包的酱瓶子塞进编织袋，塞完袋口绳勒进指缝，指缝红一道，红完他用牙咬紧绳头。城的有人送到站，站上广播噪；有人只送到单元门，门边袋放一下。县里更常送到长途点，点上土粘袋角。乡下堂屋装完再走，走完袋底潮。进城帮带的袋从儿女家出门，出门电梯里酱味冲。远距的爷把袋托人带，带完听筒问「沉不沉」。奶倒两粒的手不在这只袋上。孙若来送，送来把绳再勒一圈。1955 年生自己窗口把饭盒盖按严，按完去盛自己那份。绳头磨白。瓶盖油，油粘指。检票的灯白一下眼。他把手从袋口抽回来，抽回怕再勒。门开了，开完酱味还在指缝。

**00后祖辈现在怎么提**：袋口绳勒指、牙咬绳头比后来的真空袋先在。乡下记得堂屋装完再走。谁勒过那道红，比车次清。

**当时广告 / 单位 / 生活版怎么说**：站上「请排队」。柜台不管酱。儿女口头「别带太多」。

**当时家里怎么说**：爷：「勒紧。」奶：「别漏。」孙：「沉。」儿女：「我转钱就行。」

**邻居牌友和其他说法**：谁家送到站，谁家只送到门。未见全员一只袋。

**祖辈自己的一对词**：袋口绳勒紧送到站 vs 让儿女只转一笔。

**感官钩子**：袋口绳勒指缝；酱味冲；瓶盖油粘指；检票灯白眼。

**会吵什么**：再塞一瓶，还是先走——绳已经勒了，广播已经噪了。

**和孩子 / 父母库的接口**：生活费转账详见父母库 P-2019-04。行李绳 2014 已写，详见祖辈库。折子路费 2018 已写，详见 G-2018-04。

### G-2019-08 堂屋鞋位空了一双

**时间** 2019 年学期中，乡留守堂屋或远距门口｜**落在哪** 房与路｜**称谓** 奶奶｜**谁家有** 城：少，人在同一栋；县：有的周末空；乡留守：这张主场；进城帮带：鞋位在儿女家门口；远距：人也空

**事实核**：2016 阳台校服、2017 空席拍平、2018 听筒问考完没已写，详见 G-2016-08、G-2017-08、G-2018-05。本年换手：鞋位、空了一双、日常。父母铺太齐是城里那间，详见 P-2019-06。少年帘缝是学校那张床，详见 T-2019-01。1955 未带孙写自己工位鞋架，架上没有这一空。视频里看孙不前移。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 79 岁。门槛沉，沉了看一眼也费。 |
| 1945 | 74 岁。堂屋鞋位空了一双，她把空位扫一下。 |
| 1950 | 69 岁。她把另一双摆正，摆正像等人回。 |
| 1955 | 64 岁。自己工位鞋架，架上没有这一空。 |

现场：门槛那一排。她把空出来的鞋位扫一下，扫完土末进扫帚，进完另一双还在，在的是爷的。乡留守更常，常了电视仍开着，开着等下一声门轴。城的少这空，空的人在同一栋。县里有的周末空，空了她也扫。进城帮带的鞋位在儿女家门口，口上多的是别人的尺码。远距的奶看不见门槛，槛在另一座。爷从地里回来，回来把鞋踢到空位旁边，旁边她又摆正。孙若打电话，话里没有鞋。1955 年生自己工位鞋架一搁，搁完去盛自己那份。扫帚毛扎一下指。门槛潮，潮的是早上的水。她把灯拉亮，亮完空位更显。门轴不响。扫帚靠在门边，边上还是湿的。

**00后祖辈现在怎么提**：鞋位空了一双、扫一下土末比后来的监控先在。堂屋记得另一双还在。谁摆过正，比学期清。

**当时广告 / 单位 / 生活版怎么说**：儿女口头「我们回」。柜台不管鞋。居委会不教扫空位。

**当时家里怎么说**：奶：「空了。」爷：「摆正。」孙：「我在学校。」儿女：「别等门。」

**邻居牌友和其他说法**：谁家鞋位空，谁家周末能满。未见全员面对面。

**祖辈自己的一对词**：空位扫完把另一双摆正 vs 把整排鞋收进柜。

**感官钩子**：土末进扫帚；门槛潮；扫帚毛扎指；门轴不响。

**会吵什么**：再等一晚门，还是先拉灯——空位已经扫了，轴还没有响。

**和孩子 / 父母库的接口**：铺太齐详见父母库 P-2019-06。帘缝详见少年库 T-2019-01。听筒问考完没 2018 已写，详见 G-2018-05。空席拍平 2017 已写，详见 G-2017-08。阳台校服 2016 已写，详见 G-2016-08。
