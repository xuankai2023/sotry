# 2001：粥锅拦着，折子数肉

> 这一年要写的是 00 后爷爷奶奶外公外婆自己家里过的、手里带的。1940 年生大约 61 岁，城的多已退；1945 年生 56 岁，刚退或将退；1950 年生 51 岁，刚退或还在岗；1955 年生 46 岁，未带孙占格，写看别人领孙、自己孩子还没生。小孩的铁罐、乐园餐只钩子一句。70 后的早餐选择、假条只钩子一句。不写新闻。

## 这一年祖辈站在哪

- **1940 年生**：61 岁。城的折子进门几年了，本月够不够买肉他们自己数；乡的仍在地里。粥锅、空椅子、麻将去不去，多是他们的手。
- **1945 年生**：56 岁。城的刚退或将退；乡的还在田。有的本年第一次把会走的孩子接到手里，有的外出家里孩子一直留在堂屋。
- **1950 年生**：51 岁。本年主核。城的可能刚退，也可能还在打卡；乡的没有退休两个字。折子、牌桌和孙子抢同一段下午。
- **1955 年生**：46 岁。很多人还在上班。未带孙占格：看邻居拦枕、替邻居守一天、门口替人等半天。不要写成已经是奶奶。

## 这一年祖辈手里已经有的

粥锅、利乐枕（城柜上开始有，乡桌上多半没有）、空椅子、筷筒、折子（城的才有，乡的没有，新农保还没有）、麻将牌、早教磁带和收录机（他们按键不会）、门口塑料凳、温水瓶（水温详见 2000）、礼簿与品红（详见 2000）、脑白金蓝盒他们收下（详见 2000）、年猪与糖色（详见 2000）、联播遥控（详见 2000）、猪油还在灶上（详见 2002）、墙上座机（听筒接 IC 详见 2003）、单位退休证。月供不进他们钱包。营养快线还没有。黄金搭档还没有。旺仔铁罐、蓝猫详见儿童库，本年不重写。肯德基谁付钱详见父母库。

## 本年主卡（7 张）

### G-2001-01 粥锅拦着，利乐枕进不了灶

**时间** 2001 年清早灶上｜**落在哪** 灶上｜**称谓** 奶奶｜**谁家有** 城退：柜上开始有利乐枕，锅仍煮粥；县：豆浆摊和粥并存，他们守锅；乡留守：桌上仍是粥和咸菜；进城帮带：客厅灶对不上，他们自带米；远距：电话里只问喝粥没有

**事实核**：常温利乐枕 1990 年代末进柜，2000–2004 加速（已有研究《奶与早餐罐子》）。乡桌上奶多是奶粉冲，不是冰箱鲜奶。营养快线 2004 才上市，本年柜上没有。枕的标价口述一块多到两块，待核到你所在柜。未见「老人拦奶」民调，不编。豆浆油条还是牛奶面包是父母库 P-2001-01。本卡换手：谁点火、谁掀锅、谁把枕按回去。旺仔不是粥，详见儿童库，本年不重写。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 61 岁。天不亮添水下米，枕搁柜上她当软枕头，不让进锅。 |
| 1945 | 56 岁。城的刚退，第一次跟儿媳抢灶沿；乡的锅里仍是隔夜剩饭续的粥。 |
| 1950 | 51 岁。还在岗的赶早班，锅交给刚退的邻床；退下来的守到米开花才让人动勺。 |
| 1955 | 46 岁。未带孙。看同事领孙一早，米量按锅沿刻的，枕她不敢拆。 |

现场：奶奶五更把铁锅坐上，米下水，勺背刮锅底，怕糊。城退带孙那家，儿女从网兜掏出利乐枕要戳吸管，她用手背挡住，说「凉的伤胃」，枕被她塞回柜门，粥吹到不烫才盛；乡留守那家柜上没有枕，只有铁锅粥和一碟腌菜，孩子伸筷子她先吹凉，袋装粉若有，她冲给孩子，自己仍喝粥。

**00后祖辈现在怎么提**：铁锅沿那一圈焦米。勺背再刮到焦处，才想起枕被塞回柜门那年。

**当时广告 / 单位 / 生活版怎么说**：路牌喊每天一斤奶；母婴柜教戳吸管。单位不发粥谱。居委会不拦谁家煮什么。麻将馆口头：「她家孙子还喝粥。」

**当时家里怎么说**：奶奶：「热的才养。」爷爷：「奶是给小孩的。」儿女：「来不及了，戳一根。」孙：枕软，粥烫，伸手被挡。

**邻居牌友和其他说法**：谁家柜上码枕、谁家仍冒热气，楼道会比。假枕涨袋有，亲戚会捏。未见公开争论。

**祖辈自己的一对词**：锅里热气 vs 枕上那根吸管。

**感官钩子**：米开花的白汽；枕捏起来鼓；勺背刮焦；腌菜的酸腥。

**会吵什么**：粥先盛，还是枕先戳——盛了儿女说误点，戳了奶奶说没吃热的。

**和孩子 / 父母库的接口**：早饭选豆浆油条还是牛奶面包，详见父母库 P-2001-01。孩子嘴里那口烫或甜，详见儿童库。

### G-2001-02 空椅子他们收，筷少一双

**时间** 2001 年出门那天和此后的饭桌｜**落在哪** 房与路｜**称谓** 奶奶 / 爷爷｜**谁家有** 乡留守：堂屋椅叠到墙根；县：人去镇厂，晚饭椅还在；城退：儿女同城上班，中午那把空着；进城帮带：人在城，老家椅落灰；远距：一年回来才把椅再打开

**事实核**：家里少一个人去厂是父母库 P-2001-03。本卡换手：椅谁叠、筷谁抽、桌谁擦。不写招工启事。汇款单口述几十到几百，待核。椅是木的或塑料的，乡堂屋常见四把，走一个收一把。班车盒饭是父母的中午，详见父母库 P-2001-05，本卡不写盒子。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 61 岁。人一走，椅翻过来靠墙，怕潮。筷筒里抽掉一双。 |
| 1945 | 56 岁。爷爷把铺盖卷好塞柜，奶奶擦桌子上那一圈油。 |
| 1950 | 51 岁。还在岗的自己也走，椅留给更老的一辈收。 |
| 1955 | 46 岁。未带孙。帮姐家搬一把椅到墙根，自己桌上人还齐。 |

现场：乡留守那家，编织袋在门口一扎，人上了农用车，奶奶把那把木椅翻过来，四条腿朝天靠墙，筷筒里抽出一双洗过的筷，剩三双仍湿；爷爷用报纸盖住空出来的桌角，说「别落灰」。城退带孙那家儿女去厂，椅不叠，中午桌上仍摆着，奶奶盛饭少一碗，晚饭人回来再添，空的只是中午那一阵。墙上座机若响，他们只报「椅收了、饭吃了」，分钟贵，说不了走时那一声。

**00后祖辈现在怎么提**：墙根那叠椅腿上的土。椅面翻过来一摸，才想起人是哪天走的。

**当时广告 / 单位 / 生活版怎么说**：供销社不收旧椅。居委会不管谁家少一双筷。生活版教省长途，不教怎么收家具。

**当时家里怎么说**：奶奶：「椅翻过来。」爷爷：「筷抽了，省得数错。」儿女：「钱寄回来。」孙：围着空位转。

**邻居牌友和其他说法**：谁家墙根先叠起椅，村口会看。谁家椅一直摆着等，也会被问。谁家折子薄、人一走椅当天翻过来，闲话先到供销社。

**祖辈自己的一对词**：椅收到墙根 vs 晚饭还要摆齐。

**感官钩子**：椅腿蹭砖；筷筒空响；报纸盖桌的墨；编织袋扎口的塑料味。

**会吵什么**：椅先收了，还是留着等过年——收了爷爷说看着心烦，不收奶奶说落灰。

**和孩子 / 父母库的接口**：家里少一个人去厂、汇款怎么写，详见父母库 P-2001-03。孩子围着空位转，详见儿童库。

### G-2001-03 会走的孩子交到他们手里

**时间** 2001 年孩子会走之后的白天｜**落在哪** 带孙现场｜**称谓** 奶奶｜**谁家有** 城退：第一次从儿女手里接过会走的；县：两头送，周一婆家；乡留守：孩子一直留在堂屋，不是本年才走；进城帮带：客厅帘后他们看着迈步；远距：只在电话里听「会走了」

**事实核**：刚会走第一次留给谁是父母库 P-2001-07。本卡换手：手从谁手里接、门谁插、第一步谁跟着。外出家孩子一直留在堂屋，交手不是本年才发生。追着喂展开详见带孙专篇。金锁、相册详见儿童库。偏方、两套衣见带孙专篇。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 61 岁。城的第一次白天单独看会走的，门插上，怕出楼道。 |
| 1945 | 56 岁。奶奶跟着那两步，外婆若来会说「鞋穿反了」。 |
| 1950 | 51 岁。还在岗的中午赶回来看一眼，再去打卡。 |
| 1955 | 46 岁。未带孙。看邻居领着迈台阶，自己工号抄不上，不敢伸手。 |

现场：城退那家，儿女把会走的孩子往奶奶怀里一放，钥匙留下，奶奶把铁门插上，跟着那两步从堂屋到灶沿，怕磕到桌角；孩子要出门，她只让在门口塑料凳上坐一会儿。乡留守那家孩子一直在堂屋，不是本年才第一次留下，奶奶把裤带松一扣让他自己迈，爷爷在田头喊「看着」，椅已经少一把，人走的是大人，不是小孩。肯德基纸盒若进门，她骂浪费，仍把鸡块掰开喂一口。

**00后祖辈现在怎么提**：门口那张塑料凳磨白的边。边上一坐热起来，才想起铁门插上的那天。

**当时广告 / 单位 / 生活版怎么说**：母婴柜卖学步带；生活版教「别牵着手走」。单位不管谁看孩子。居委会不发接手通知。

**当时家里怎么说**：奶奶：「给我，你们走。」爷爷：「门插上。」儿女：「中午电话报一声。」外婆：「送到我这儿几天。」

**邻居牌友和其他说法**：谁家老人白天单独看、谁家仍请人，楼道会比。谁家外婆住进来接会走的，铁门插销当天就涩。

**祖辈自己的一对词**：第一次接手 vs 本来就在堂屋。

**感官钩子**：铁门插销的涩；塑料凳热；小鞋擦地；裤带松扣。

**会吵什么**：白天留奶奶这儿，还是送到外婆门口——留了外婆说女儿那边空，送了奶奶说路远。

**和孩子 / 父母库的接口**：刚会走第一次留给谁，详见父母库 P-2001-07。孩子自己迈那两步，详见儿童库。追着喂详见带孙专篇。

### G-2001-04 折子本月够不够买肉

**时间** 2001 年发退休金那几天到赶集｜**落在哪** 钱包｜**称谓** 爷爷 / 奶奶｜**谁家有** 城退：折子进门，本月数肉；县：机关事业折子厚一点；乡：多数没有折子，肉看地里和汇款；进城帮带：折子在老家，人在城花儿女的；远距：只听见电话里问肉买了没

**事实核**：2000 年企业人均退休金约 6142 元/年、月约 512 元（劳动统计年鉴口径，中国日报 http://www.chinadaily.com.cn/dfpd/2010qglianghui/2010-03/04/content_9534487.htm ），机关事业更高。农村多数没有折子，新农保 2009 年才试点，本年农村多数仍没有本。城镇猪肉约 7–9 元/斤量级（东莞鲜上肉约 13.78 元/公斤，https://tjj.dg.gov.cn/tjj/tjnj/19972009/2005/wj/content/post_3226766.html ），其他城口述待核。月供不进他们钱包。谁买几斤是父母库。本卡换手：折子谁拿、本月肉钱谁划。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 61 岁。城的折子在柜子里，本月划四十块买肉，剩的怕不够药。 |
| 1945 | 56 岁。刚退的第一次自己排队，章盖上才敢说「这个月有肉」。 |
| 1950 | 51 岁。还在岗的没有折子，肉钱仍从工资本；乡的靠卖菜。 |
| 1955 | 46 岁。未带孙。工位还在。看同事领折子盖章，自己没有那一页。 |

现场：城退那家，爷爷把折子从布包里抽出来，本子上盖着章，月约五百出头，他用圆珠笔在纸上划：肉三斤按八块是二十四，青菜另算，剩下还要水电；奶奶说「再买半斤给孩子」，他摁住封皮。乡那家没有折子，爷爷赶集卖一筐菜，口述二三十块待核，肉只砍一刀，猪油仍从年里那罐挖；儿女寄来的汇款单写「买肉」，他们先把钱压在席下，怕一次买光。

**00后祖辈现在怎么提**：折子封皮磨破的那一角。封皮一摁，才想起本月够不够三斤肉。

**当时广告 / 单位 / 生活版怎么说**：储蓄所玻璃窗「请排队」；生活版教省菜钱。乡信用社不办退休金。居委会有时通知城的去领。

**当时家里怎么说**：爷爷：「这个月紧。」奶奶：「孩子那半斤要买。」儿女：「寄了，别省肉。」牌友：「谁家折子厚。」

**邻居牌友和其他说法**：谁家每周有肉、谁家只赶集见荤，楼道和村口会比。谁家折子薄，半斤都要摁住封皮。

**祖辈自己的一对词**：折子上那一笔 vs 席下压着的汇款。

**感官钩子**：折子纸边起毛；章油未干；油纸渗油；圆珠笔划纸。

**会吵什么**：本月三斤还是两斤——多买奶奶说孩子要长，少买爷爷说折子见底。

**和孩子 / 父母库的接口**：买几斤从谁月工资扣，详见父母库。孩子嘴里那块肥，详见儿童库。2008 折子薄了另角度，本年只写够不够。

### G-2001-05 麻将馆去不去

**时间** 2001 年下午到晚饭前｜**落在哪** 自己的日子｜**称谓** 爷爷 / 外公｜**谁家有** 城退：单位老同事约馆；县：茶馆兼牌桌；乡：堂屋砌牌，没有馆；进城帮带：人在城，牌友在老家；远距：听不见这桌

**事实核**：麻将是这十年许多老人自己的下午，不是本年新发明。一圈输赢口述两块到十块，待核，未见「老人沉迷」民调，不编。不愿带、去麻将的展开详见带孙专篇。本卡只写去不去这一下。联播七点要静详见 2000，本年牌桌让不让七点。1955 未带孙，写跟去看一眼。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 61 岁。城的退下来有空，牌盒夹在自行车后座。 |
| 1945 | 56 岁。外公在娘家巷口茶馆等一桌，孙子若送来，他缺一门。 |
| 1950 | 51 岁。还在岗的只有休息日；退下来的第一次发现下午能出门。 |
| 1955 | 46 岁。未带孙。跟牌友坐半圈，家里还没有人要他守。 |

现场：城退那家，爷爷把麻将牌装进旧饼干盒，对外说「去一圈」，奶奶在门口喊「五点回来吃饭」；馆里电扇嗡，他摸牌，墙上钟过四点有人催「你家孙子醒了」，他缺一门还是走。乡那家没有馆，堂屋桌布一铺就是牌，孩子在桌下钻，爷爷用脚挡，说「别碰倒」；人少一双筷的日子，牌友仍来，墙根那把空椅不给外人坐，另搬一条凳。

**00后祖辈现在怎么提**：饼干盒里缺了一张的牌。缺角摸进掌心，才想起谁缺过一门回家。

**当时广告 / 单位 / 生活版怎么说**：晚报生活版偶有「娱乐适度」；居委会不发牌谱。单位老同事口头：「下午老地方。」茶馆门口写「茶位」。

**当时家里怎么说**：爷爷：「去一圈。」奶奶：「看着点钟。」儿女：「别赌大了。」孙：钻桌底。

**邻居牌友和其他说法**：谁家爷爷下午必出门、谁家守灶，巷口会比。谁先走看孙，会被笑。未见公开争论。

**祖辈自己的一对词**：去一圈 vs 缺一门回家。

**感官钩子**：牌撞击的脆；电扇的嗡；桌布茶渍；饼干盒铁盖。

**会吵什么**：下午去馆，还是留在门口看孙——去了奶奶说没人看，不去牌友说缺一门。

**和孩子 / 父母库的接口**：不愿带、去麻将的展开，详见带孙专篇。孩子钻桌底，详见儿童库。假条、加班不是本卡，详见父母库。

### G-2001-06 外婆门口等女儿把孩子送来

**时间** 2001 年周末或娘家约定的那天｜**落在哪** 房与路 / 带孙现场｜**称谓** 外婆｜**谁家有** 城：楼道口塑料凳；县：巷口；乡：村口或娘家堂屋台阶；进城帮带：外婆先到城，在单元门等；远距：一年等一次绿皮

**事实核**：四二一家里周末往娘家送，不是文件。刚会走留给谁是父母库 P-2001-07。本卡换手：外婆在门口等、凳谁搬、孩子从谁手里接到娘家。婆家那天若空堂，只在「谁家有」里点。两家抢带流程不展开，详见带孙专篇。绿皮、春运深挖见《留守与春运》，本年只写门口这一等。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 61 岁。凳搬到门口，眼睛盯楼道拐角。 |
| 1945 | 56 岁。外婆提着一篮蛋等，怕女儿改去婆家。 |
| 1950 | 51 岁。还在岗的请不出整天，只能中午在门口等一小时。 |
| 1955 | 46 岁。未带孙。帮姐在门口坐半天，自己还没有人要送过来。 |

现场：外婆把塑料凳搬到单元门口，手里捏着湿毛巾，城那家女儿下了班车把孩子往她怀里一放，她先摸后颈汗，再问「路上吃了没」，奶奶若跟来送到楼道，两家在门口让来让去，孩子的包换一次手。乡那家外婆在村口台阶等，土路扬尘，女儿从婆家堂屋把人送来，坐半日，临走外婆把蛋篮塞回，说「下周还送到我这儿」；人不送来的周末，凳仍搬出去，毛巾干了她再浸一回。

**00后祖辈现在怎么提**：门口那张塑料凳裂开的腿。腿一晃，才想起毛巾湿着等楼道拐角那天。

**当时广告 / 单位 / 生活版怎么说**：生活版有「周末回娘家」小文，不点名谁家抢。单位不管外婆的门口。居委会不调解送哪边。

**当时家里怎么说**：外婆：「送到我这儿。」外公：「我在门口看。」女儿：「婆家那边也要去。」奶奶：「别在门口争。」

**邻居牌友和其他说法**：谁家凳先搬到门口、谁家孩子两头跑，楼道会比。谁家外婆住进来，毛巾湿着也能等半天。

**祖辈自己的一对词**：门口等到人 vs 凳搬了人改去婆家。

**感官钩子**：塑料凳烫；湿毛巾的涩；班车刹车；土路尘。

**会吵什么**：周末先送娘家，还是先留婆家——送了奶奶说堂屋空，不送外婆说等白了。

**和孩子 / 父母库的接口**：孩子被送来那一段路，详见儿童库。第一次留给谁，详见父母库 P-2001-07。两家抢带详见带孙专篇。

### G-2001-07 磁带他们按键不会

**时间** 2001 年早教磁带进门之后的白天｜**落在哪** 器物｜**称谓** 奶奶 / 爷爷｜**谁家有** 城退：收录机在柜上，键他们不敢按；县：复读机是收据买的，他们只会开盖；乡：机少，磁带放潮；进城帮带：机在城，他们插不上电；远距：听不见这盘

**事实核**：早教磁带收据进门是父母库 P-2001-04。本卡换手：键谁按、带谁倒、响了谁关。机是收录机或复读机，价口述几十到几百，待核。英语带、故事带都有，内容不写玩法。蓝猫、动画片不重写，详见儿童库。机他们不会按，2004 文曲星另说。营养快线没有，不是早餐罐。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 61 岁。键上的英文她认不全，按下去带吐出来。 |
| 1945 | 56 岁。爷爷敢开盖，倒带转反，磁带散一地。 |
| 1950 | 51 岁。还在岗的中午回来替按一下，走了又停。 |
| 1955 | 46 岁。未带孙。看姐姐家抢着按键，自己不伸手，音量也不敢定。 |

现场：城退带孙那家，奶奶把磁带推进舱，手指悬在键上不敢按下，孩子哭着要听，她喊爷爷，爷爷按错成录音，里面那盘被绞成一缕，两个人蹲着往外掏；机子后来只在儿女回家时响。乡留守那家收据也进过门，机搁灶沿受潮，键发黏，奶奶只会开盖给孩子看那盘棕带，真正按键等周日电话里儿女教「中间那个」，教完仍停在半盘。墙上座机只报「听了」，不报倒到第几。

**00后祖辈现在怎么提**：绞出来的那缕磁带。缕一黏手，才想起谁按错成录音。

**当时广告 / 单位 / 生活版怎么说**：母婴柜「启蒙从听开始」；收据小票印店名。单位不教老人按键。电视里孩子跟着念，不教倒带。

**当时家里怎么说**：奶奶：「我不会。」爷爷：「再按要坏。」儿女：「中间那个键。」孙：要听，键不听她的。

**邻居牌友和其他说法**：谁家机响、谁家落灰，楼道会比。假带卡壳有，退货是儿女的事。未见公开争论。

**祖辈自己的一对词**：会开盖 vs 不敢按下。

**感官钩子**：舱盖弹簧；带被绞的黏；键上的字掉漆；灶沿潮气。

**会吵什么**：机留给老人白天开，还是等儿女回来再听——开了奶奶怕绞带，不开孩子哭。

**和孩子 / 父母库的接口**：磁带收据谁买，详见父母库 P-2001-04。孩子跟着念的那几句，详见儿童库。功效、听写不展开，详见带孙专篇。

## 本年不写

入世、申奥、客厅漏音的国家大事。肯德基谁付钱不进主卡。班车盒饭、随份子五十还是一百详见父母库，本年不重写。蓝猫、旺仔不重写。黄金搭档还没有。猪油改色拉油、菜场砍价、跟桌咸淡、小灵通他们不会回留给 2002。听筒接 IC 留给 2003。2008 折子薄了另角度，本年只写够不够买肉。
