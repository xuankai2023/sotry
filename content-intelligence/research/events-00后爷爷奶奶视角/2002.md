# 2002：猪油还在熬，听筒只问吃了没

> 这一年要写的是 00 后爷爷奶奶外公外婆自己家里过的、手里带的。1940 年生大约 62 岁，城的多已退；1945 年生 57 岁，刚退或将退；1950 年生 52 岁，班还在不在是主场；1955 年生 47 岁，未带孙占格，写看别人领孙、自己孩子还没生。小孩的铁罐只钩子一句。70 后的另找活、超市选择只钩子一句。不写新闻。

## 这一年祖辈站在哪

- **1940 年生**：62 岁。城的折子仍要数；乡的仍在地里。猪油谁熬、网兜谁提，多是他们的手。腰腿更响，听筒只问吃了没。
- **1945 年生**：57 岁。城的多已退；乡的还在田。跟桌咸淡开始定在他们勺上。
- **1950 年生**：52 岁。本年主核。城的班还在不在，乡的地还种不种，没有退休两个字的那家仍出工。
- **1955 年生**：47 岁。很多人还在上班。未带孙占格：看同事领孙、工会发一袋糖、自己孩子还没生。不要写成已经是奶奶。

## 这一年祖辈手里已经有的

铁锅和板油、金龙鱼桶（广告开始喊，他们嫌淡）、网兜、菜场秤、咸罐、墙上座机（本年只报吃了没，听筒接 IC 详见 2003）、小灵通（他们不会回）、工牌或锄头、黄金搭档金盒（下半年刚上柜，他们收下当补）、粥锅拦利乐枕（详见 2001）、折子买肉（详见 2001）、麻将牌（详见 2001）、空椅子（详见 2001）、温水瓶（详见 2000）、脑白金蓝盒（详见 2000）、礼簿（详见 2000）。营养快线还没有。月供不进他们钱包。新农保还没有。旺仔、蓝猫详见儿童库。信封另找活、加班面详见父母库。

## 本年主卡（7 张）

### G-2002-01 猪油他们熬，色拉油他们嫌淡

**时间** 2002 年杀猪后或赶集买回板油那天｜**落在哪** 灶上｜**称谓** 奶奶 / 爷爷｜**谁家有** 乡：铁锅熬到 2005 前后仍常见；县：半锅猪油半桶色拉；城退：桶装进门，他们仍要泼一勺猪油；进城帮带：客厅灶对不上，油渣他们想带回去；远距：过年才见那罐白油

**事实核**：金龙鱼第二代调和油 2002 年打「1:1:1」（格隆汇 https://www.gelonghui.com/p/417413 ）。乡下熬猪油持续到 2005 前后（已有研究《猪油改色拉油》）。散装油坊口述 2–3 元/斤，桶装小桶口述 20–30 元，待核。海天 2005 年才成全国龙头，本年柜上还不是海天的天下。猪油还是色拉油谁买单是父母库 P-2002-02。本卡换手：谁切板油、谁守锅、谁嫌淡。橄榄油不是日常。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 62 岁。乡的五更切板油，油渣撒盐留给孩子；城的闻桶装说「没味」。 |
| 1945 | 57 岁。奶奶守锅，爷爷在院里扇烟。 |
| 1950 | 52 岁。还在岗的买一桶回来，灶上仍被老人换成猪油。 |
| 1955 | 47 岁。未带孙。自己灶上还熬给父母，渣留给邻家孩子抢。 |

现场：乡留守那家，奶奶把板油切成丁下冷锅，滋滋响，她用铲翻，白油渐化，油渣捞起撒盐；爷爷在门口扇烟，怕糊。城退带孙那家，儿女把金龙鱼桶扛进门，广告念 1:1:1，奶奶炒菜仍从坛里挖一勺猪油泼进去，说「色拉油淡得像水」，桶装只拿来煎蛋，孩子伸手抢油渣，她挡，说「烫」。

**00后祖辈现在怎么提**：坛里结霜的白油，或桶上洗不掉的商标。油垢刮下来，才想起渣是谁捞的。

**当时广告 / 单位 / 生活版怎么说**：电视里 1:1:1 反复念；生活版开始写清淡。单位若发油，发的是桶不是板油。供销社油坊还打散装。

**当时家里怎么说**：奶奶：「淡。」爷爷：「还是猪油香。」儿女：「桶装干净。」孙：等油渣。

**邻居牌友和其他说法**：谁家楼道仍是猪油香、谁家已是色拉油烟，早起就能闻出来。假桶封口松，亲戚会捏一圈胶。牌友说「她家孙子抢油渣，比肉香」。

**祖辈自己的一对词**：锅里那勺猪油 vs 广告里的 1:1:1。

**感官钩子**：板油下锅的滋；油渣脆；白油结霜；桶盖的塑料味。

**会吵什么**：炒菜仍用猪油，还是改倒色拉油——改了奶奶说没味，不改儿女说油腻。

**和孩子 / 父母库的接口**：猪油还是色拉油谁买，详见父母库 P-2002-02。孩子抢的那把渣，详见儿童库。

### G-2002-02 菜场砍价是他们的手

**时间** 2002 年清早菜场｜**落在哪** 钱包 / 灶上｜**称谓** 奶奶｜**谁家有** 城退：网兜、热鲜肉他们砍；县：早市秤他们熟；乡：赶集砍一刀；进城帮带：人在城，仍认菜场不认条码；远距：买不了这摊

**事实核**：农贸市场这十年仍是生鲜主场（已有研究《菜场超市家乐福》）。热鲜摊冒气，冷链不是主流。超市条码他们不认。城镇猪肉约 7–9 元/斤量级，口述待核，见 2001 折子卡。菜场还是超市谁决定是父母库 P-2002-03。本卡换手：网兜谁提、价谁砍、秤星谁盯。2008 超市他们不进另写，本年只写手。未见「老人爱砍价」民调，不编。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 62 岁。网兜挽在腕上，瘦肉少买，肥的她要。 |
| 1945 | 57 岁。盯秤星，说「把刀口那块皮去掉」。 |
| 1950 | 52 岁。还在岗的赶早市买完再打卡；退下来的能磨到收摊。 |
| 1955 | 47 岁。未带孙。跟同事家属去早市，网兜她提，价不敢还。 |

现场：城退带孙那家，奶奶天不亮提网兜进菜场，热鲜肉还冒气，她砍三斤按八块，嘴上说「七块五」，秤星她盯到平，皮和骨要单算；超市门口灯亮着，条码嘀一声她当秤坏了，不进。乡留守那家逢集才去，网兜里先装青菜，肉只砍一刀，猪油仍在坛里，钱是席下那张汇款；摊主熟，少一两她也认，说「下集补」。

**00后祖辈现在怎么提**：网兜绳勒出的腕印，或秤星那一点铜亮。破了底的网兜翻出来，才想起集日那一刀。

**当时广告 / 单位 / 生活版怎么说**：晚报生活版「买肉看检疫章」；超市海报不进他们眼睛。居委会不管谁砍价。单位不发菜谱。

**当时家里怎么说**：奶奶：「我去砍。」爷爷：「肥的要。」儿女：「超市干净。」摊主：「老主顾，让一点。」

**邻居牌友和其他说法**：谁家网兜先满、谁家改推超市车，早市一眼能看出来。短斤两摊上就吵，不是楼道里的事。谁先认条码，会被说「不会买肉了」。

**祖辈自己的一对词**：盯秤星那一眼 vs 条码那一声。

**感官钩子**：网兜湿；热鲜肉的热气；秤星铜；靴底踩泥。

**会吵什么**：仍去菜场，还是跟儿女进超市——进了奶奶说贵且不能还，不去儿女说脏。

**和孩子 / 父母库的接口**：菜场还是超市谁拍板，详见父母库 P-2002-03。孩子跟在摊边看见的案，详见儿童库。

### G-2002-03 跟桌咸淡他们定

**时间** 2002 年晚饭同一张桌｜**落在哪** 带孙现场｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：孩子跟大人一桌，盐在奶奶勺上；县：另碗兑汤常见；乡留守：一锅到底；进城帮带：客厅灶咸淡对不上；远距：电话里只问咸不咸

**事实核**：孩子跟大人一桌还是另熬是父母库 P-2002-06。本卡换手：盐罐谁开、这碗咸不咸谁定。婆家跟桌兑汤、娘家口重浇汁，两套过法写在同一张，不再另开兑汤卡。抢勺抢衣详见带孙专篇，本年只落在咸。未见「跟桌比例」民调，不编。追着喂详见带孙专篇。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 62 岁。咸菜卤兑进粥，说「没盐不长力」。 |
| 1945 | 57 岁。奶奶舀一勺尝，再决定给孩子那碗要不要另兑。 |
| 1950 | 52 岁。还在岗的赶回来已盛好，咸淡由在家的定。 |
| 1955 | 47 岁。未带孙。看邻桌孩子皱眉，盐她不敢给人加。 |

现场：婆家那套，奶奶把孩子按在大人桌边，同一锅红烧，她用筷蘸汤尝，咸了就拔开水瓶兑一口进孩子碗，汁滗到自己碟里，说「跟桌才吃饭」；孩子唇干要另熬稀，她不另起锅，盐罐盖拍上。娘家那套，外婆盐放得靠前，腊肉汤直浇，说「我这儿要口重」，开水瓶搁得远，只在烫嘴时吹一吹，孩子喝完汤唇更干，她再添半勺。周一婆家周五娘家的，同一只碗两趟手，咸淡在门槛上就换了。

**00后祖辈现在怎么提**：盐罐受潮结块的盖，或碗底滗过的油痕。瓶塞一拔，才想起哪边兑、哪边浇。

**当时广告 / 单位 / 生活版怎么说**：生活版开始写少盐；广告里清淡油他们当耳旁风。单位食堂不管家里盐。居委会不发盐勺。

**当时家里怎么说**：奶奶：「跟桌。」外婆：「我这口重。」儿女：「另熬一锅吧。」孙：皱眉，仍被按着吃。

**邻居牌友和其他说法**：谁家孩子两头吃饭回来要喝水，楼道会笑。谁家一锅到底、谁家另碗，饭桌上就比出来。

**祖辈自己的一对词**：跟桌这一撮盐 vs 外婆那口重。

**感官钩子**：盐罐结块；瓶塞白汽；腊肉汤的咸腥；唇干。

**会吵什么**：跟桌吃咸的，还是两边都改淡——改了外婆说没家味，不改奶奶说回来要兑。

**和孩子 / 父母库的接口**：跟桌还是另熬谁决定，详见父母库 P-2002-06。抢勺展开详见带孙专篇。孩子嘴里那口咸，详见儿童库。

### G-2002-04 自己的地还种，班还在不在

**时间** 2002 年春耕或车间调班那几个月｜**落在哪** 自己的日子｜**称谓** 爷爷｜**谁家有** 乡：没有退休，地还在种；县：厂还在就还打卡；城：1950 / 1955 班还在不在是主场；进城帮带：地撂了，人在城；远距：地请人代种

**事实核**：农村多数没有折子，新农保 2009 年才试点。2000 年企业人均退休金月约 512，见 2001。全国城镇单位在岗职工工资另表，不拿来当老人日薪。信封没了另找活是父母库 P-2002-01，70 后的事。本卡换手：锄头还下不下、工牌还挂不挂。1955 未带孙，写自己班还在，看同事请半天。打卡和带孙抢详见 2000，本年换手到地和班还在不在。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 62 岁。乡的仍出工，孙绑背上；城的折子在，地没有。 |
| 1945 | 57 岁。城的多已退，第一次问「我还去不去厂门口」。 |
| 1950 | 52 岁。主场。班还在就打卡，地还在就下田。 |
| 1955 | 47 岁。未带孙。工号还在。看同事请假看孙，自己抄不上那一行。 |

现场：乡那家没有退休两个字，爷爷把锄头往肩上一扛，垄沟还要浇，孙坐在田埂土块上玩，他喊一声「别下田」；儿女在厂，汇款不顶这一季苗，他说「地不能荒」。城还在岗那家，1950 年生看班表上自己那一格还在，粉笔灰沾指头，他踩点进门，不敢请假；孙若在家，是刚退的人看，他只问「地谁浇、班谁顶」。田头篮怎么带是 2006 的手，本年只问地和班还在不在。

**00后祖辈现在怎么提**：锄头柄磨亮的那一段，或班表上自己那一格空了没。粉笔灰搓掉，才想起这月还在不在岗。

**当时广告 / 单位 / 生活版怎么说**：车间黑板「本月班次」；村广播喊浇水。居委会叫退下来的领孙。单位不解释地谁种。

**当时家里怎么说**：爷爷：「地还要种。」奶奶：「你去，孩子我看。」儿女：「荒了也行。」工头：「这月还有班。」

**邻居牌友和其他说法**：谁先撂地进城、谁还在岗把孙塞给邻家，村口和楼道会比。撂了的会被说「田荒了还好意思过年」。

**祖辈自己的一对词**：锄头还下田 vs 工牌还挂着。

**感官钩子**：锄头上肩；田埂土块；工牌绳；班表粉笔灰。

**会吵什么**：地还种，还是撂了进城帮带——种了儿女说累，撂了爷爷说不能荒。

**和孩子 / 父母库的接口**：信封没了另找活，详见父母库 P-2002-01。孩子放田头篮，详见儿童库。打卡抢上午详见 2000。

### G-2002-05 墙上座机只报吃了没

**时间** 2002 年晚饭前后那一响｜**落在哪** 器物｜**称谓** 奶奶 / 爷爷｜**谁家有** 城退：客厅座机准点响；县：机在灶边；乡留守：听筒在堂屋，那头分钟贵；进城帮带：机在城，老家另有一台；远距：一年少响

**事实核**：墙上座机是这十年报平安的入口。国内长途口述每分钟约八毛，IC / 201 卡怎么买、听筒怎么守留给 2003（已有研究《留守与春运》）。本年只写问句：吃了没。小灵通进家是父母库 P-2002-04，他们不会回见 G-2002-07。未见通话时长民调，不编。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 62 岁。铃一响先说「吃了」，别的来不及。 |
| 1945 | 57 岁。奶奶报「粥喝了」，爷爷抢过来说「肉也有」。 |
| 1950 | 52 岁。还在岗的赶不回来，机由在家的接。 |
| 1955 | 47 岁。未带孙。自己家里机是给父母报的，听筒不往孩子那边递。 |

现场：城退带孙那家，墙上座机铃响，奶奶抓听筒，听筒把还热，她先喊孩子过来，只说「吃了、睡了」，儿女还要问第几，她说「没批评」，分钟贵，水温几度不报。乡留守那家听筒在灶边，墙线晃，那头问「吃了没」，她答「吃了」，空椅子靠墙，报完她把听筒搁回，锅还开着，听筒把上全是油。卡怎么插、村口怎么排队，是明年听筒上的事。

**00后祖辈现在怎么提**：听筒把上磨亮的那一圈油，或墙线脱落的钉。摸到灶边那根线，才想起那一声「吃了」。

**当时广告 / 单位 / 生活版怎么说**：电信营业厅海报「装机」；生活版教省长途。居委会不管谁家先问吃了没。单位不发通话稿。

**当时家里怎么说**：奶奶：「吃了。」爷爷：「还有肉。」儿女：「盐重不重。」孙：被按到听筒口喊一声。

**邻居牌友和其他说法**：谁家铃响得勤、谁家半月才一声，楼道会数。半月不响的，会被问「人还在不在厂」。

**祖辈自己的一对词**：先报吃了 vs 还想说盐。

**感官钩子**：铃的尖；听筒热；墙线晃；锅盖还响。

**会吵什么**：铃响先报吃了，还是让孩子自己喊——让了奶奶说耽误钱，不让儿女说没听见人。

**和孩子 / 父母库的接口**：听筒接 IC、卡怎么买，详见 2003。孩子对着听筒那一声，详见儿童库。小灵通谁办，详见父母库 P-2002-04。

### G-2002-06 金盒他们收下，说给孙补

**时间** 2002 年下半年广告上柜，过年前后进门｜**落在哪** 钱包 / 器物｜**称谓** 奶奶 / 爷爷｜**谁家有** 城退：儿女送来金盒；县：体面的才见一盒；乡：墙上还在刷脑白金，金盒少；进城帮带：盒塞进行李；远距：托人带一盒，药片剩半板

**事实核**：黄金搭档 2002 下半年上央视黄金时段，维生素加矿物质，与脑白金交替播（央视 https://www.cctv.com/advertisement/special/C12982/20041011/101728.shtml ）。口述一盒八十上下，待核。2000 是蓝礼盒他们收下，本年换手：金盒、他们说给孙补、自己不一定吃。2008 电视购物自己按键另写。盖中盖巩俐事件不写。谁掏钱送礼详见父母库脑白金卡的后续篮子，本卡是收礼的手。不是药。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 62 岁。金盒放茶几，来客看见才像被惦记。药片她掰给孙，自己泡茶。 |
| 1945 | 57 岁。说「中央又在念」，收下，夜里并不一定吃。 |
| 1950 | 52 岁。还在岗的觉得一盒顶好几斤肉，仍让儿女别空着手。 |
| 1955 | 47 岁。未带孙。工会发过一袋糖，金盒还没轮到自己收。 |

现场：门铃响，奶奶接过金亮礼盒，比去年那只蓝盒更刺眼，说明书上的维生素她念不全，说「给孩子补」。城退那家把盒码在柜顶蓝盒旁边，来客问「今年换了没」，她指金的那只；药片她掰半片塞进孙嘴里，自己仍喝白开水。乡留守那家墙上还刷着脑白金那句，金盒是托人带回才见，铝箔撕开一股甜腥，爷爷说「跟糖豆似的」，剩半板压在灶沿。他们不进药店自己买——本年仍是收下。自己按购物键是 2008 的手。

**00后祖辈现在怎么提**：柜顶金盒褪色的边，或铝箔撕开的锯齿。半板药片结潮，才想起那年说给孙补。

**当时广告 / 单位 / 生活版怎么说**：联播后金盒和蓝盒交替念；药店堆头「补维生素」。单位不发黄金搭档。居委会不发保健品通知。

**当时家里怎么说**：奶奶：「给孙补。」爷爷：「中央说的。」儿女：「拿得出手。」孙：药片甜，伸手还要。

**邻居牌友和其他说法**：谁家茶几蓝盒换金盒，过年就会比。谁家仍是烟酒，会被说「不会送礼」。假盒掉漆有，亲戚会拆开对数。

**祖辈自己的一对词**：收下给孙补 vs 一盒顶好几斤肉。

**感官钩子**：金膜反光；铝箔锯齿；药片甜腥；柜顶两只盒挤着。

**会吵什么**：掰给孙吃，还是整盒摆着给来客看——吃了奶奶说浪费场面，不吃儿女说买来就是补的。

**和孩子 / 父母库的接口**：孩子会背新广告、摸不到瓶，详见儿童库。谁掏钱换篮子，详见父母库。蓝盒收下详见 G-2000-04。自己按键买详见 2008。

### G-2002-07 小灵通他们不会回

**时间** 2002 年小灵通进家之后｜**落在哪** 器物｜**称谓** 爷爷 / 奶奶｜**谁家有** 城：绿屏机在儿女口袋，他们不会回；县：信号格少，他们更不敢按；乡：多数还没有，只会等墙上座机；进城帮带：机在城，老家仍等铃；远距：机打不通就改寄话

**事实核**：小灵通 1998 进中国，1 分钟约 1 毛，信号差（人民政协网 http://www.rmzxw.com.cn/c/2018-09-11/2166888.shtml ）。小灵通进家谁办卡是父母库 P-2002-04。本卡换手：绿键他们按不按、回拨会不会、铃不响他们怎么办。峰值户数是后来的事，本年不是人手一部。没有视频这一路。寻呼机在儿女腰上已少，不展开。听筒深挖见 2003。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 62 岁。绿屏亮了她当收音机，不敢按。 |
| 1945 | 57 岁。爷爷按过一次，打到别人桌上，从此只等座机。 |
| 1950 | 52 岁。还在岗的自己可能有机，回家仍教老人等铃。 |
| 1955 | 47 岁。未带孙。自己会按，给父母写一张「只接不拨」压在茶几下。 |

现场：城退带孙那家，儿女把小灵通放到茶几上，说「有事打这个」，奶奶拿起来天线晃，绿屏上的数字她认不全，回拨键按成关机，此后机没电她也不充，只盯墙上座机；铃不响她就认为没事。乡留守那家柜上没有绿屏，只会等堂屋那台铃，那头若用小灵通打进来，她仍抓听筒报「吃了」，自己不会回过去。

**00后祖辈现在怎么提**：茶几上没电的绿屏，或墙上铃的锈。按成关机那一下，比机型先在手指上。

**当时广告 / 单位 / 生活版怎么说**：营业厅「无线市话便宜」；海报不教老人回拨。单位不管谁家机谁会按。居委会不代充。

**当时家里怎么说**：奶奶：「我不会回。」爷爷：「等座机。」儿女：「绿键就行。」孙：拿机当砖。

**邻居牌友和其他说法**：谁家老人会回、谁家机当摆设，楼道会比。信号差被骂，是儿女的事。机没电仍摆茶几的，会被说「买来给谁看」。

**祖辈自己的一对词**：会等铃 vs 不会回拨。

**感官钩子**：天线晃；绿屏亮；按成关机的黑；座机铃锈。

**会吵什么**：有事打小灵通，还是仍打墙上座机——打了奶奶说不会回，不打儿女说机买来没用。

**和孩子 / 父母库的接口**：小灵通进家谁办卡，详见父母库 P-2002-04。听筒接 IC 详见 2003。孩子拿机当砖，详见儿童库。
