# 2006：点头留下、村口绿皮，和折子垫的八十

> 这一年要写的是 00 后爷爷奶奶外公外婆自己家里过的、手里带的。1940 年生大约 66 岁；1945 年生 61 岁；1950 年生 56 岁；1955 年生 51 岁，未带孙仍占格。小孩的红领巾、点读机壳只钩子一句。70 后的车票、厂里十平米、收费窗只钩子一句。不写新闻。

## 这一年祖辈站在哪

- **1940 年生**：66 岁。城的折子还在用；乡的仍出工或看家。村口等车、汇款单按手印，多是他们的手。腰腿更响。
- **1945 年生**：61 岁。城的已退稳；乡的还在田。留下还是带走，点头常在这一年叠上。
- **1950 年生**：56 岁。本年主核。城的可能已退；乡的没有退休。地里和孙抢同一段上午。
- **1955 年生**：51 岁。很多人还在上班。有的开始带晚 00 后；未带孙占格：看别人点头留下、替邻居守一天、自己不垫校服那一行。

## 这一年祖辈手里已经有的

抢勺抢衣、电脑占线他们骂、压岁从折子或红布包抽、家长会后排、布尿布开水烫、麻将和开会条、电磁炉他们盯电表（均详见 2005）、水温、礼簿、猪油、座机、IC 卡（详见 2003）、折子城的才有（新农保还没有）、麻将牌、煤或罐。点读机广告进客厅，他们当砖。校服八十块有人从折子垫。腊肉还在檐下。每天一斤奶口号本年才密，他们觉得惯，不是 2000 已有。营养快线只点名。摩尔、赛尔未到。宽带深挖 2008。改菜谱主卡 2007，本年只翻腊肉。家电下乡尚未试点。红领巾怎么系详见儿童库。带不带去厂、绿皮车票、开学一份钱详见父母库。

## 本年主卡（7 张）

### G-2006-01 留下还是带走，他们点头留下

**时间** 2006 年进城或回乡的那次家里商量｜**落在哪** 房与路 / 带孙现场｜**称谓** 奶奶 / 爷爷｜**谁家有** 城退：本地双职工不碰上这题，他们点头的是暑假接不接；县：有人把孙送镇，他们点头；乡外出：核心；进城帮带：他们点头留下，人仍在老家堂屋；远距：一年一面，点头在电话里

**事实核**：带不带孩子去厂是儿女的选择，十平米、月租详见父母库 P-2006-01。本卡换手：老人点头留下、碗和铺谁认、电话里报吃了没。不写证件，不写文件。全国城镇单位在岗职工年平均工资 21001 元，月约 1750 元（https://www.stats.gov.cn/sj/tjgb/qttjgb/qgqttjgb/202302/t20230218_1913271.html ）；寄回的钱他们经手，不是他们出月租。已有研究《留守与春运》。IC 卡怎么打详见 2003。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 66 岁。点头很慢，说「留下我带」，铺已经在堂屋。 |
| 1945 | 61 岁。暑假接走一个月，开学前他们再点头送回。 |
| 1950 | 56 岁。乡的还在田，点头留下等于田头多一张篮。 |
| 1955 | 51 岁。未带孙。看姐姐点头留下外甥，自己还在岗，不敢应「我带」。 |

现场：堂屋灯下，儿女把蛇皮袋搁在门槛，问「带走还是留下」。奶奶点头，下巴一沉，说「留下，这边有学」，碗已经给孙留了位置，铺在里间。爷爷在门口抽烟，不拦，只补一句「寄钱回来」。乡外出那家，点头留下是主场：蛇皮袋出了门槛，堂屋多一只碗、里间多一铺。城退那家没有这道题，他们点头的是暑假接来几天，开学前再送回，客厅沙发腾一周。进城帮带若没成，是他们点头把人留在老家，不是儿女没买到票。电话里只报「吃了、睡了」，分钟贵，点头当时看不见。

**00后祖辈现在怎么提**：堂屋里多出来的那只碗，或里间铺的折叠痕。摸到折叠痕，才想起下巴一沉那一下。票在谁口袋是儿女的事，点头在他们下巴上。

**当时广告 / 单位 / 生活版怎么说**：厂门口「夫妻房」是儿女看的。生活版偶写打工子弟，他们不当新闻读。居委会不管谁点头。

**当时家里怎么说**：奶奶：「留下我带。」爷爷：「寄钱。」儿女：「这边上不了。」孙：攥衣角。

**邻居牌友和其他说法**：谁家点头留下、谁家让人接走，村口会比。留下的说接走是把人往城里扔，接走的说留下是老人扛不动还硬点头。

**祖辈自己的一对词**：点头留下 vs 让人接走。

**感官钩子**：下巴一沉；门槛蛇皮袋；里间铺折叠；听筒里只报吃了。

**会吵什么**：暑假让接走，开学还回不回——回了他们说带得动，不回碗空着。

**和孩子 / 父母库的接口**：孩子认不认城、睡脚窝，详见儿童库。十平米、带不带去厂，详见父母库 P-2006-01。IC 卡详见 2003。

### G-2006-02 村口等绿皮，编织袋先落地

**时间** 2006 年腊月到正月，或暑假那一班｜**落在哪** 房与路｜**称谓** 奶奶 / 爷爷 / 外公｜**谁家有** 城本地：不过这关；县：有人到镇站接；乡留守：村口等；进城帮带：人已在城，村口空；远距：一年一等

**事实核**：这十年春运是绿皮、硬座、站票。硬座口述 100–200 元（已有研究《留守与春运》）。车票、窗口、加班费是父母库 P-2006-04。本卡换手：村口谁等、编织袋谁接、人走后谁把凳收回屋。饭桌空椅、筷少一双详见 2001，本年只回声，不重写那一桌。听筒报吃了没详见 2003。不写高铁。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 66 岁。村口塑料凳坐到天擦黑，袋一落地才认人。 |
| 1945 | 61 岁。外公若从娘家村过来等，认的是女儿不是车次。 |
| 1950 | 56 岁。还在田的，等车和收工抢；人没下，锄还在肩上。 |
| 1955 | 51 岁。未带孙。帮姐到村口看一眼，自己不等自己的人。 |

现场：奶奶把两只塑料凳搬到村口，孙坐一只，她坐一只，眼盯土路尽头。绿皮到站在镇，人还要换车或走路，编织袋先鼓出来，绳勒成印，她接袋，不接话，先看瘦了没。爷爷在后头抽烟，认的是走路的肩。袋里是衣和火腿肠，不是车票——票在儿女口袋，详见父母库。人走那天，同一条路，袋再鼓一次，他们把凳收回屋，堂屋回声空一下，不在本年重写缺筷那一桌。乡留守是主场；城本地没有这道口。留厂的那年，村口等到的是汇款单，不是人，凳仍收回去。

**00后祖辈现在怎么提**：村口那只塑料凳腿上的泥，或编织袋绳勒出的印。摸到绳勒的印，才想起袋先落地、人后认全。人走后收凳的一下还在，饭桌那双筷是 2001 的。

**当时广告 / 单位 / 生活版怎么说**：铁路春运告示是儿女看的。乡镇广播报班车点。麻将馆口头：「谁家的人回了。」

**当时家里怎么说**：奶奶：「先坐着。」爷爷：「肩是他的。」儿女：「站票。」孙：盯土路。

**邻居牌友和其他说法**：谁等到人、谁等到汇款单，村口会数。黄牛、带进站不展开。等到单的说等人的是空欢喜，等到人的说单不能抱。

**祖辈自己的一对词**：等到袋落地 vs 等到一张汇款单。

**感官钩子**：塑料凳凉；袋绳勒掌；土路尽头的人影；收凳时堂屋的空响。

**会吵什么**：再等一班，还是先把孙领回去——等了天黑，不等又怕人扑空。

**和孩子 / 父母库的接口**：孩子认不认刚下车的人，详见儿童库。车票、站票，详见父母库 P-2006-04。空椅缺筷详见 2001。

### G-2006-03 校服八十块，他们从折子垫

**时间** 2006 年入学季收费通知到家里｜**落在哪** 钱包｜**称谓** 奶奶 / 爷爷 / 外婆｜**谁家有** 城退：折子取八十或一百五；县：同样垫，档口低一些；乡：无折子，卖粮或压箱；进城帮带：钱在老家他们垫，照寄出去；远距：汇款条写「校服」

**事实核**：运动校服口述城里一套 80–150 元，县乡 50–80 元，八十块口述、待核到你的收费单（父母库 P-2006-06 写掏钱选型）。红领巾勒脖子、书包轮子亮片，详见儿童库 C-2006-01。本卡换手：折子垫、乡的收成或压箱垫、垫完嘱咐「别买最贵的包」。企业退休金 2005 年底月均约 700，八十块他们要数。农村无折子。名牌鞋深挖 2007。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 66 岁。折子翻到取款页，写「八十」，或箱底数旧票。 |
| 1945 | 61 岁。外婆若垫，钱从娘家那本，嘱咐只买校服。 |
| 1950 | 56 岁。还在岗的用工资垫；乡的用卖菜的。 |
| 1955 | 51 岁。未带孙。工会发糖那一周，自己折子不写校服这一行。 |

现场：奶奶把收费通知按在灶台上，油星溅到「校服」那一行，她翻折子，取八十，口述、待核，票子用纸包好交给孙或交给来取的儿女，说「衣服要齐，包别买最贵」。城退那家一次垫得出；本月买肉她少称二两。乡留守那家没有折子，她从箱底或卖粮的信封抽，八十块是真少一截菜钱，旧包缝补，红领巾家里剪布——布在谁脖子上，详见儿童库，本年只写垫出的钱。外出那家汇款条写「校服」，他们代交，收据压在碗柜，开学照寄走，他们不对光看包是哪一只。

**00后祖辈现在怎么提**：折子取款页「八十」那一行，或收费单上的油星。摸到油星，才想起少称的二两肉、箱底那叠旧票。红领巾怎么系不在这本折子上。

**当时广告 / 单位 / 生活版怎么说**：学校通知「校服统一购买」。文具店灯箱是孩子看的。单位不报老人这笔。银行柜台不问取款用途。

**当时家里怎么说**：奶奶：「我垫。」爷爷：「包别贵。」儿女：「钱寄回去。」孙：摸拉链。

**邻居牌友和其他说法**：谁家新包、谁家旧包，校门口一眼分层。他们比的是垫得出垫不出。垫得出的说旧包寒碜，垫不出的说新包是把折子掏空给别人看。

**祖辈自己的一对词**：折子垫八十 vs 旧包先背。

**感官钩子**：通知上的油星；折子纸边起毛；旧票潮味；拉链冰手。

**会吵什么**：垫八十只买校服，还是再加一点给包——加了肉要少，不加孩子进门被看包。

**和孩子 / 父母库的接口**：红领巾勒脖子、包的轮子亮片，详见儿童库 C-2006-01。收费窗、选型，详见父母库 P-2006-06。

### G-2006-04 点读机他们当砖，掂完嫌沉

**时间** 2006 年步步高点读机进柜之后，机被抱进门｜**落在哪** 器物｜**称谓** 奶奶 / 爷爷｜**谁家有** 城退：中产家才见这台砖；县：广告先到，机后到；乡：基本无，去有机的那家摸一下；进城帮带：客厅柜上搁着；远距：广告会哼，手里没有

**事实核**：步步高点读机 T100 约 2006 年推出，一台口述 500–1500 元（已有研究《点读机复读机》）。乡下能顶两三个月。广告「哪里不会点哪里」本年进电视；「so easy」是 2009，不前移。谁买单、保修卡详见父母库 P-2006-02。功效、按着点，详见带孙专篇。本卡只写手和重、嫌贵、当砖搁。文曲星他们摸着嫌贵详见 2004，本年换这台更沉的壳。平板不属于这十年。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 66 岁。两手掂一下，说「跟半袋米似的」，搁柜上当砖。 |
| 1945 | 61 岁。电线绕手，棱磕到门框，她骂「这么贵还磕」。 |
| 1950 | 56 岁。还在岗的不管这台；退了的被叫来看孩子点，笔不会握。 |
| 1955 | 51 岁。未带孙。电器行路过掂一下，自己不往楼上抱。 |

现场：奶奶把灰白壳抱起来，腕子一沉，像搬砖，她立刻搁回柜顶，说「这么沉，还这么贵」。笔她不塞进孩子手里，怕点坏，壳上的键沾了灶油她用袖子擦。城退带孙那家，机在厅里，她当砖压柜，作业她盯不盯详见带孙专篇，本年她只嫌重、嫌贵、怕摔。乡留守那家客厅广告响，手里没有机，去有机的那家，孩子摸一下就被收回，她也只掂过别人的砖。假笔没声她不退——发票不在她口袋。爷爷说「以前一本字典」，砖仍在柜上吃灰。

**00后祖辈现在怎么提**：柜顶那圈灰，或壳棱磕过的门框白印。摸到白印，腕子还记得那一下沉。2009 那版广告不要记进本年手里。

**当时广告 / 单位 / 生活版怎么说**：电视里「哪里不会点哪里」；柜上样书。单位不发机。生活版教选择学习机，不教老人怎么搁砖。

**当时家里怎么说**：奶奶：「跟砖似的。」爷爷：「一本字典。」儿女：「学英语。」孙：要嘀一声。

**邻居牌友和其他说法**：谁家先抱上楼，班上会比。水货他们不认型号，只认沉。未见公开争论。

**祖辈自己的一对词**：当砖搁柜 vs 让孩子背出门。

**感官钩子**：腕子一沉；壳棱磕框；键上灶油；柜顶灰。

**会吵什么**：机放家里当砖，还是让孩子背去别人家——背了怕摔，不背孩子哭。功效详见带孙专篇。

**和孩子 / 父母库的接口**：壳、嘀、谁有谁没有，详见儿童库 C-2006-05。谁掏 980，详见父母库 P-2006-02。按着点详见带孙专篇。

### G-2006-05 鲜肉少了，他们翻檐下腊肉

**时间** 2006 年灶上那一盘，不是明年改菜谱｜**落在哪** 灶上｜**称谓** 奶奶 / 爷爷｜**谁家有** 城退：鲜肉还买，他们把腊肉当待客；县：赶集少称，檐下或阳台翻；乡：鲜的少，腊肉主荤；进城帮带：人在城，腊肉在老家；远距：过年才见整刀

**事实核**：城镇人均年购猪肉 2006 年 20.00 千克，农村人均食猪肉 15.46 千克（《中国统计年鉴》，https://www.stats.gov.cn/sj/ndsj/2008/html/J0909C.HTM ；https://www.stats.gov.cn/sj/ndsj/2010/html/J1029C.HTM ）。本年不是 2007 改菜谱主卡，不许写成全国没肉，也不写摊价新闻。2005–2006 年同款肉口述大约 6 元/斤，待核。本卡换手：他们蹬凳翻檐下那刀、油滴阶沿、咸的切片下锅。圈空若有，只写栏里没有哼声。已有研究《猪肉与菜谱》。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 66 岁。凳一蹬，手摸到腊肉硬边，翻一面再挂上。 |
| 1945 | 61 岁。切片的咸味先呛，她就着白饭蒸软。 |
| 1950 | 56 岁。乡的还养的，翻自己的；不养的，等寄钱才买鲜的。 |
| 1955 | 51 岁。未带孙。在自己父母檐下帮着翻，还不是这刀的主手。 |

现场：乡下奶奶把竹凳蹬稳，手伸进檐下，腊肉硬、油滴到阶沿，她翻一面，拍掉灰，切三片下锅，白饭一蒸，咸得要喝水。鲜肉这周少称或不称，不是晚报上的数，是栏里哼声没了，或寄来的钱先留着交校服。城退那家菜场还能称三两瘦肉，她仍把阳台或通风处那刀腊肉翻一回，待客才切厚；平时青椒先下，肉丝最后翻，腊肉是「还有」。西北若是羊，少的是凝白那层，他们翻的是风干的条。2007 改蛋改谱不在本年这刀上。

**00后祖辈现在怎么提**：檐下铁钩或竹竿油渍，比菜谱清楚。摸到油渍，才想起翻面、油滴阶沿。明年改谱是另一只碗。

**当时广告 / 单位 / 生活版怎么说**：电视菜单仍写荤素搭配；保健版偶写少吃腌腊，乡下当耳旁风。单位若发冻带鱼，灶上先安排鱼。不写社论。

**当时家里怎么说**：奶奶：「还有半扇。」爷爷：「鲜的少称。」儿女：「寄钱。」孙：咸得喝水。

**邻居牌友和其他说法**：谁家还挂、谁家空钩，村里会看。城里比盘里红多红少。未见公开争论。

**祖辈自己的一对词**：翻腊肉当荤 vs 再称三两鲜的。

**感官钩子**：油滴阶沿；硬边拍灰；咸呛鼻；凳腿蹭墙。

**会吵什么**：今天切腊肉，还是等赶集称鲜的——切了孩子喊咸，不切桌上没有红。

**和孩子 / 父母库的接口**：孩子掀饭盒看有没有肉，详见儿童库。桌上肉丝薄了、空圈，详见父母库 P-2006-03。改菜谱详见 2007。

### G-2006-06 地里带着孙，篮放田头

**时间** 2006 年农忙上午，乡的主场｜**落在哪** 自己的日子 / 带孙现场｜**称谓** 奶奶 / 爷爷｜**谁家有** 城退：没有这道田；县：城郊还有一小块；乡：主场；进城帮带：人在城，地托人；远距：地在，孙不在身边

**事实核**：乡的 1950 / 1955 没有退休两个字，地里和孙抢同一段上午。2000 年打卡和带孙抢是城的早上（G-2000-05）；本年换手：锄和篮。不写任何税和文件。田头篮、农用车周一送镇详见 2003 路上，本年写人在垄上。企业折子他们没有。已有研究《物质文化与日常》。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 66 岁。腰先响，多在田埂看篮，垄上是儿女或更年轻的。 |
| 1945 | 61 岁。孙绑在背上或放篮里，薅一行看一眼。 |
| 1950 | 56 岁。主场。锄头和哭声抢，篮放田头阴处。 |
| 1955 | 51 岁。未带孙。自己的地还在种；看同事领孙把篮放田头，自己中午只顾赶另一块地，不敢说「我带了」。 |

现场：奶奶把竹篮搁在田头树阴，垫一块旧衣，孙在篮里玩土块，她弯腰薅完一行，直起腰先看篮，哭了就喂一口凉开水，追着喂怎么追详见带孙专篇。爷爷在隔壁垄，锄头不放，喊「有我看着」。城退没有这道田，他们的上午是菜场或麻将，本年不是主场。乡外出那家，地还种，孙在篮里，汇款单压在灶上，人在垄上听不见电话。1955 年生看邻垄有篮，篮不是自己的，她只守到中午，自己还要去另一块地或赶班。晒斑在小臂，不是折子页。

**00后祖辈现在怎么提**：田头那只篮的裂篾，或旧衣上的土。摸到裂篾，才想起薅一行看一眼。腰响和哭声哪一个先停，他们还争。

**当时广告 / 单位 / 生活版怎么说**：乡镇广播报农时。供销社卖锄。居委会不管田头篮。生活版不教怎么把孙放垄上。

**当时家里怎么说**：奶奶：「篮放阴处。」爷爷：「有我看着。」儿女：「别晒着。」孙：吃土，被拍掉。

**邻居牌友和其他说法**：谁家田头有篮、谁家把孙交给邻垄，沟边会看。有篮的说交给邻垄是省事，邻垄的说篮一哭就得停锄。

**祖辈自己的一对词**：篮放田头 vs 留人在堂屋看。

**感官钩子**：裂篾扎手；土块拍掉；凉开水金属味；锄头磕垄。

**会吵什么**：孙带下地，还是留一个在屋——带了怕晒，留了垄上少一只手。

**和孩子 / 父母库的接口**：孩子记得土和晒，详见儿童库。周一送镇路上详见 2003。追着喂详见带孙专篇。

### G-2006-07 外婆汇款单按手印，印泥沾拇指

**时间** 2006 年女儿从厂里寄钱回来的那天｜**落在哪** 钱包 / 房与路｜**称谓** 外婆 / 外公｜**谁家有** 城退：少，钱走折子；县：邮局仍常见；乡：主场，娘家老人去局；进城帮带：单寄到老家，他们代领；远距：一年几张单

**事实核**：汇款单、邮局柜台、不会写字的按手印，是这十年娘家常见的手，金额口述几百，手续费口述几块，待核到你的存根。不写政策文件。本卡是外婆的拇指和单，不是儿女窗口买票。IC 卡报吃了没详见 2003。压岁他们给详见 2005。企业退休金他们若没有，这张单就是当月菜钱。已有研究《留守与春运》。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 66 岁。拇指按印泥，花名她认，后面的格不敢填。 |
| 1945 | 61 岁。外公跟着去局，单子他念，印她按。 |
| 1950 | 56 岁。字写得下的自己填，仍要按一下才给钱。 |
| 1955 | 51 岁。未带孙。帮姐去局跑腿，印不是自己的。 |

现场：外婆把通知条从灶缝里抽出，走到镇上邮局，柜台玻璃凉，她报女儿的名字，单子推过来，名字她描不齐，营业员把印泥盒打开，她拇指按下去，红印发糊，钱点三遍才装进贴身口袋。娘家是主场：钱是外孙的学和肉，她带回村，先交给奶奶或自己留下一截买菜，两家会让来让去。外公在门口等，不进柜台。乡无折子，这张单比红布包来得勤。城退那家少见手印，钱打进折子，她只在女儿回家时听一句「寄过了」。单上的字她不读文件，只认「能取」。

**00后祖辈现在怎么提**：存根上糊掉的拇指印，或贴身口袋的缝线。摸到糊掉的印，才想起柜台玻璃冰手。钱后来够不够肉，是另一月的单。

**当时广告 / 单位 / 生活版怎么说**：邮局窗贴「汇款须核对」；手续费牌小。单位不管外婆的印。生活版不教按手印。

**当时家里怎么说**：外婆：「我去取。」外公：「我在门口。」女儿：「寄了。」奶奶：「留给孩子。」

**邻居牌友和其他说法**：谁家单勤、谁家半年一张，村里会数。假单少见，多见印糊了再按一次。未见公开争论。

**祖辈自己的一对词**：按手印取回 vs 等女儿自己带回。

**感官钩子**：印泥沾拇指；玻璃柜台凉；贴身口袋布；存根纸薄。

**会吵什么**：钱外婆留下一截买菜，还是全交婆家——留了婆家说少，不留娘家说没经手。

**和孩子 / 父母库的接口**：孩子只看见后来桌上的菜。寄多少、厂里怎么寄，详见父母库汇款条。听筒报吃了没详见 2003。
