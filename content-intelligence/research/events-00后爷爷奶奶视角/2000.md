# 2000：堂屋的蛋、水温，和联播那一会儿

> 这一年要写的是 00 后爷爷奶奶外公外婆自己家里过的、手里带的。1940 年生大约 60 岁，城的多已退；1945 年生 55 岁，刚退或将退；1950 年生 50 岁，刚退或还在岗；1955 年生 45 岁，未带孙占格，写看别人领孙、自己孩子还没生。小孩的铁罐、金锁只钩子一句。70 后的桌钱、假条只钩子一句。不写新闻。

## 这一年祖辈站在哪

- **1940 年生**：60 岁。城的多已拿折子；乡的仍在地里。满月酒上礼簿、染蛋，多是他们的手。腰腿开始响，联播仍要准点看。
- **1945 年生**：55 岁。城的刚退或将退；乡的还在田。有的本年第一次把孙子交到手里，有的还在帮儿女看一天。
- **1950 年生**：50 岁。本年主核。城的可能刚退，也可能还在打卡；乡的没有退休两个字。打卡和带孙抢同一段上午。
- **1955 年生**：45 岁。很多人还在上班。未带孙占格：看邻居领孙、工会发糖、满月酒上递一盘蛋。不要写成已经是奶奶。

## 这一年祖辈手里已经有的

堂屋板凳、品红染蛋、礼簿、抓周米筛（周岁，1999 年生本年抓）、温水瓶、国产袋装奶粉、惠氏罐走百货他们少摸、脑白金蓝礼盒刚进门（他们收下，不是他们买）、黄金搭档还没有、年猪或菜场五花、糖色、收音机、新闻联播、墙上座机、寻呼机在儿女腰上、煤球炉或煤气罐、开水瓶、猪油还在灶上（详见 2002）、折子城的才有（乡的没有，新农保还没有）、麻将牌、单位退休证、居委会通知。月供不进他们钱包。营养快线还没有。小灵通少数城已有，本年不深挖。旺仔铁罐、金锁相册详见儿童库。桌钱、假条、单位信封详见父母库。

## 本年主卡（7 张）

### G-2000-01 堂屋办满月：蛋是他们染的，礼簿是他们管的

**时间** 2000 年孩子满月、百日；抓周是周岁｜**落在哪** 灶上 / 带孙现场｜**称谓** 奶奶｜**谁家有** 城退：帮儿女订桌、自己染蛋；县：家里或镇上馆子他们管礼簿；乡留守：堂屋他们办，儿女寄钱；进城帮带：人在城、酒在老家；远距：只看见后来寄来的照片

**事实核**：满月分红鸡蛋、办酒，不是本年新发明。城里饭店一桌口述 500–1500 元，县乡堂屋请厨师；随份子常见 50–200，体面到 100–500，口述、待核。品红染蛋，指甲缝会粉。桌钱、订几桌是父母库 P-2000-01；假条盖不盖得上是 P-2000-07。本卡换手：蛋谁染、礼簿谁管、板凳谁收。金锁、相册详见儿童库 C-2000-01。已有研究《酒席红包与体面》。不写扎堆生育论文。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 60 岁。礼簿摊开，圆珠笔「某某 一百」是他们写的。堂屋板凳不够，他们往院子搬。 |
| 1945 | 55 岁。品红兑温水，蛋还热，指头染一层粉。城的帮儿媳数桌，乡的自己请厨师。 |
| 1950 | 50 岁。有的刚退下来办这桌；还在岗的请半天，酒散了再赶回厂。 |
| 1955 | 45 岁。未带孙。帮姐或邻居递一盘蛋、看一眼礼簿，自己还没有孙子要染。 |

现场：奶奶在堂屋灶上数红鸡蛋，壳还温，品红兑在碗里，指头一捏就粉。乡留守那家儿女人在厂，汇款单写「满月」，她请厨师、收板凳、礼簿自己管，来客问「办几桌」，她只报数字，鞭炮把梁熏黑；城退那家饭店冷盘转起来，她仍把蛋篮提到后厨补染，礼簿不放心给人，圆珠笔写「某某 一百」，封对着灯看是不是新票。外婆若来，蛋篮会另分一筐带回娘家，两家老人在门口让来让去。抓周若是本年，米筛上摆书和钱，爷爷伸手想把小拳头拨向笔，人不在场的只听见电话里一句「抓了啥」。

**00后祖辈现在怎么提**：礼簿那一页墨水洇开的格。品红还在哪只旧碗底，翻出来才想起那年堂屋。

**当时广告 / 单位 / 生活版怎么说**：照相馆门口「满月艺术照」；晚报生活版教染红蛋；居委会不发桌数通知。供销社有时还能买到品红。麻将馆口头：「谁家孙子满月，礼簿她管。」

**当时家里怎么说**：奶奶：「蛋我来染。」爷爷：「礼簿别给人乱写。」儿女：「桌钱我们出。」外婆：「分一筐给我带回。」

**邻居牌友和其他说法**：谁家堂屋办、谁家饭店，满月酒上就比。镀金锁掉色会被说假，那是货，不是本卡主场。谁家礼簿薄、谁家外婆住进来分走一筐蛋，酒桌上就有闲话。

**祖辈自己的一对词**：蛋和礼簿在手里 vs 人在厂里只寄钱。

**感官钩子**：品红染到指甲缝；礼簿纸发潮；鞭炮后的硫磺；板凳腿蹭堂屋砖。

**会吵什么**：礼簿奶奶管还是让儿媳写——少让一边，来客问「谁当家」就会先响。

**和孩子 / 父母库的接口**：孩子被抱着传一圈、金锁冰到锁骨，详见儿童库 C-2000-01。订几桌、桌钱从哪个月工资扣，详见父母库 P-2000-01。假条详见父母库 P-2000-07。

### G-2000-02 冲奶水温他们定

**时间** 2000 年夜里和清早的日常｜**落在哪** 带孙现场｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：温水瓶在灶边，他们起夜；县：袋装粉他们冲；乡留守：整晚都是他们的勺；进城帮带：客厅帘后那只瓶；远距：电话里只问「吃了没」

**事实核**：只写家里哪罐、谁冲、水温谁定。口述价：国产 400 克袋常见十几到几十元；进口罐 400 克约 90–120 元，待核到你所在柜。城镇人均奶粉购买量 2000 年 0.49 千克/人，乡下更多奶粉冲，不是冰箱鲜奶（已有研究《奶与早餐罐子》）。谁买罐、深夜谁起来是父母库 P-2000-05。本卡换手：腕试水温、勺在谁手里。旺仔铁罐不是配方粉，详见儿童库 C-2000-02。换罐打假不写。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 60 岁。腕内侧试温，烫了兑一口凉，凉了再坐回瓶里。 |
| 1945 | 55 岁。奶奶冲一勺，外婆若来住会说「再兑一点」。 |
| 1950 | 50 岁。还在岗的夜里赶回来冲一瓶，再去赶早班。 |
| 1955 | 45 岁。未带孙。帮姐看一晚，水温仍按姐说的，自己不敢定。 |

现场：奶奶把温水瓶塞子拔开，水柱冲进奶瓶，腕内侧一试，烫了兑凉水，粉剂结块她用筷子捣。城退带孙那家儿女上夜班，瓶在她手里，墙上座机若响，她只报「吃了、睡了」，分钟贵，说不了水温几度；乡留守那家整夜都是她的勺，袋装粉放灶沿，孩子吐了她再冲一瓶，外婆隔一周来，会把她兑好的倒掉重冲，说「太烫伤胃」。进口罐他们少摸，摸到也说「还不是粉」。追着喂那一勺展开详见带孙专篇，本年只写腕和瓶。

**00后祖辈现在怎么提**：温水瓶塞子上那圈水垢。腕内侧那块茧一烫，才想起夜里兑凉水那一下。

**当时广告 / 单位 / 生活版怎么说**：母婴柜教「腕温、量勺」；袋上印着月龄表他们看不清。单位不发冲奶手册。电视里婴儿笑，不教老人怎么试。

**当时家里怎么说**：奶奶：「我腕子准。」外婆：「再兑一口。」儿女：「别太烫。」孙：只哼，不评温度。

**邻居牌友和其他说法**：谁家用进口罐、谁家仍袋装，楼道会比。水温烫着舌头，邻居会说「老人不会冲」。未见公开争论。

**祖辈自己的一对词**：腕试这一下 vs 儿女说的温度计。

**感官钩子**：塞子拔出的白汽；腕内侧一缩；筷子捣块的咯噔；袋口受潮的甜腥。

**会吵什么**：再兑一口凉，还是就这瓶喂——兑了奶奶说没营养，不兑外婆说烫。

**和孩子 / 父母库的接口**：孩子嘴里那口烫或甜，详见儿童库摇篮卡。谁买罐、谁起夜付钱，详见父母库 P-2000-05。追着喂详见带孙专篇。

### G-2000-03 年猪还杀，糖色是他们炒的

**时间** 2000 年腊月到正月｜**落在哪** 灶上｜**称谓** 爷爷 / 奶奶｜**谁家有** 城退：菜场买三斤五花，奶奶炒糖色；县：家里红烧他们主勺；乡：年猪爷爷请猪匠；进城帮带：人在城、肉在老家分；远距：过年才见整盘

**事实核**：城镇人均年购猪肉 2000 年 16.73 千克，农村食猪肉 13.28 千克（《中国统计年鉴》，见《猪肉与菜谱》）。东莞鲜上肉约 13.78 元/公斤、瘦肉约 18.04 元/公斤（https://tjj.dg.gov.cn/tjj/tjnj/19972009/2005/wj/content/post_3226766.html ），折合约 7–9 元/斤，其他城口述待核。杀年猪法律允许自宰自食；2000 年仍普遍，东部打工村开始撤。过年红烧、买几斤是父母库 P-2000-03。本卡换手：糖色谁炒、猪谁按、肉谁分。2007 改菜谱不前移。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 60 岁。乡的请猪匠、铁钩、分肉；城的守灶炒糖色，怕糊。 |
| 1945 | 55 岁。奶奶翻五花，爷爷在圈里或菜场按肥瘦。 |
| 1950 | 50 岁。还在岗的腊月二十六请假回家按猪，请不了就寄钱买肉。 |
| 1955 | 45 岁。未带孙。在自己父母桌上帮着劈柴、递盐，还不是这桌主勺。 |

现场：乡下爷爷五更起来烧开水，猪匠来了，烫毛、铁钩吊起，血留一碗，他按部位分鲜吃、送人、腌；奶奶在灶上炒糖色，冰糖下锅焦香差点糊，油溅手背，孩子伸筷子被挡。城退那家没有圈，奶奶仍要那碗红烧，菜场热鲜肉冒气，三斤按 8 元一斤是 24 元，她从折子里抽，说「没有红烧不像年」；五花下锅她不让儿媳抢铲。圈已经空了的，寄钱回来买几斤，爷爷仍把腊肉从檐下取下来翻。剩的那碗隔夜进罩子，是面子，不是剩菜。

**00后祖辈现在怎么提**：那口炒糖色的铁锅。锅沿一摸到焦糖痂，才想起那年冰糖差点糊。

**当时广告 / 单位 / 生活版怎么说**：电视烹饪教炒糖色；节前生活版「年夜饭硬菜」；乡镇广播提醒定点屠宰、自宰自食别上市。单位若发冻带鱼，灶上先安排一条鱼。

**当时家里怎么说**：爷爷：「今年还杀。」奶奶：「糖色我来。」儿女：「寄钱，别养了。」牌友：「谁家还响那一刀。」

**邻居牌友和其他说法**：谁家还杀、谁家改买肉，村里会比。城里比盘大不大。未见公开争论。

**祖辈自己的一对词**：过年必须有那碗 vs 平日有丝就行。

**感官钩子**：冰糖炒到深琥珀；开水烫毛的白汽；铁钩蹭梁；油溅手背。

**会吵什么**：还杀年猪，还是寄钱买三斤五花——杀了儿女说麻烦，不杀爷爷说不像年。

**和孩子 / 父母库的接口**：婴儿只闻油烟或被喂一小块肥，详见儿童库过年糖篮。买几斤、鱼也得有，详见父母库 P-2000-03。

### G-2000-04 蓝礼盒他们收下，不是他们买的

**时间** 2000 年起广告反复念，过年篮子进门｜**落在哪** 钱包 / 器物｜**称谓** 爷爷 / 奶奶｜**谁家有** 城退：儿女送来一盒；县：体面的才见一盒；乡：墙上刷了广告，篮里多半没有；进城帮带：盒塞进行李带回；远距：托人带一盒，口服液剩半打

**事实核**：零售常见口径 68 元/盒，礼品装有上到 168 元的说法（http://www.emkt.com.cn/article/251/25185-2.html ）。广告词「今年过节不收礼，收礼只收脑白金」，两个动画老人转圈；2000 年起轰炸，不要写成 1990 年代满街。黄金搭档 2002 下半年才有。盖中盖巩俐事件不写。父母库 P-2000-04 是谁掏钱送礼。本卡换手：他们怎么收、怎么搁、喝不喝。不是药，是保健礼盒。已有研究《保健品进客厅》。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 60 岁。盒放茶几正中，来客看见才像过年。口服液喝不完。 |
| 1945 | 55 岁。说「电视里都在要」，收下，夜里并不一定喝。 |
| 1950 | 50 岁。还在岗的觉得一盒顶好几斤肉，仍让儿女别空着手。 |
| 1955 | 45 岁。未带孙。给自己父母或师傅经手过一盒，还不是收礼的主位。 |

现场：门铃响，奶奶接过蓝礼盒，蓝光膜反光，瓶子撞出一声闷响，她不敢拆给孩子玩，说「不是糖」。城退那家把盒码在柜顶，来客问「今年收了没」，她指那一摞；乡留守那家墙上刷着同一句广告，篮里多半还是酒和旺旺，盒是托人带回才见，口服液剩半打发苦，爷爷仍说「中央台在念」。他们不进药店自己买——本年是收下。自己按电视购物键是 2008 的手，本年不要提前。

**00后祖辈现在怎么提**：储藏室那只空蓝盒，口服液纸托还在。盒盖一掀，才想起那年有人往柜顶塞过一盒。

**当时广告 / 单位 / 生活版怎么说**：联播后两个动画老人反复念；药店堆头「过节送礼」。单位不发脑白金，发的是油和鱼。居委会不发保健品通知。

**当时家里怎么说**：爷爷：「这个值钱。」奶奶：「搁柜顶。」儿女：「拿得出手。」孙：伸手被挡。

**邻居牌友和其他说法**：谁家茶几有蓝盒，谁家还是烟酒，过年就会比。谁家那只是假盒、掉漆盒，亲戚拆开看瓶子才散。

**祖辈自己的一对词**：收下才像过年 vs 一盒顶好几斤肉。

**感官钩子**：蓝光膜反光；瓶子撞盒；柜顶灰；广告声压过灶上的油。

**会吵什么**：盒拆开喝，还是整盒摆着给来客看——喝了奶奶说浪费场面，不喝儿女说买来就是喝的。

**和孩子 / 父母库的接口**：孩子会背广告、摸不到瓶，详见儿童库。谁掏 68 块，详见父母库 P-2000-04。

### G-2000-05 打卡还没完，孙子已经醒了

**时间** 2000 年工作日早上｜**落在哪** 自己的日子｜**称谓** 爷爷 / 奶奶｜**谁家有** 城：1950 / 1955 还在岗，打卡口和堂屋抢；县：厂和家同一条街；乡：没有打卡，地里和孙抢；进城帮带：人已退或请假进城，本卡少；远距：机在厂里响，孙不在身边

**事实核**：2000 年全国城镇单位在岗职工年平均工资 9371 元（https://www.stats.gov.cn/sj/zxfb/202303/t20230301_1920036.html ），日均约 26 元。企业人均退休金约 6142 元/年、月约 512 元（劳动统计年鉴口径，中国日报 http://www.chinadaily.com.cn/dfpd/2010qglianghui/2010-03/04/content_9534487.htm ），机关事业更高。农村多数没有折子。满月假是 70 后的条，详见父母库 P-2000-07。本卡写 50 岁上下自己还在不在岗。1955 未带孙写看别人领、帮一天。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 60 岁。城的多已退，折子进门；乡的仍出工，孙绑在背上。 |
| 1945 | 55 岁。城的刚退或将退，第一次发现上午空出来。 |
| 1950 | 50 岁。主场。打卡口玻璃窗和奶瓶抢同一段七点。 |
| 1955 | 45 岁。未带孙。工位还在。看见同事请半天回家看孙，自己工号抄不上那一行。 |

现场：爷爷把工牌从脖子上摘下来又挂回去，打卡口说「迟到扣半天」，约合十几块，口述、待核；家里奶瓶已经响，奶奶在灶边喊「你先走，我来」。城还在岗那家，上午两头不够，他把孙送到门口交给刚退的邻床，自己踩点进车间；乡没有打卡，锄头和孙在田埂抢，1950 年生把孩子放田头篮里，薅完一行再看一眼。1955 年生看同事请半天，自己工号抄不上。夜班回声留给 2003，本年只写早上这一抢。

**00后祖辈现在怎么提**：工牌绳磨亮的那一段。绳勒回脖子，才想起打卡窗和奶瓶抢过同一段七点。

**当时广告 / 单位 / 生活版怎么说**：车间黑板「请假提前一天写」；打卡口「无条按旷工」。居委会开始叫退休的来领孙。单位不解释孙子谁带。

**当时家里怎么说**：爷爷：「我先打卡。」奶奶：「你走，瓶我冲。」儿女：「假条我来请。」工头：「这月走不了。」

**邻居牌友和其他说法**：谁先退下来带、谁还在岗把孙塞给邻床，楼道会比。谁家折子还薄就整天守门口，牌友会嘀咕一句。

**祖辈自己的一对词**：工牌还挂着 vs 瓶已经响了。

**感官钩子**：打卡玻璃窗盖章的啪；工牌绳勒脖子；田头篮里的哭；奶瓶碰灶沿。

**会吵什么**：请半天扣工，还是把孙交给刚退的邻家——扣了折子薄，不请屋里没人。

**和孩子 / 父母库的接口**：满月假请不请得出，详见父母库 P-2000-07。孩子当时只记得被抱、被放篮，详见儿童库。

### G-2000-06 联播一响，孩子要静

**时间** 2000 年每晚七点前后｜**落在哪** 器物｜**称谓** 爷爷｜**谁家有** 城退：客厅电视准点开；县：天线雪花他们拍盒子；乡：收音机先响，电视后到；进城帮带：客厅是他们的床，遥控在他们手里；远距：听不见这台电视

**事实核**：新闻联播是这十年许多老人的准点仪式，不是本年新发明。脑白金常接在联播后广告里（见《保健品进客厅》）。收音机、评书仍在乡间。小孩要看的大风车、金龟子、蓝猫在下午档，详见儿童库 C-2000-03、C-2000-04。本卡只写七点谁拿遥控、谁被喝静。不要写成国家大事落到客厅。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 60 岁。七点坐到电视正中，孙子爬过来按键，手被拿开。 |
| 1945 | 55 岁。收音机先听完天气预报，再换电视。 |
| 1950 | 50 岁。还在岗的赶回家，联播已过半，仍要看完天气。 |
| 1955 | 45 岁。未带孙。在自己家看，邻家孩子来串门才喝一声静。 |

现场：墙上钟快到七点，爷爷把音量拧上去，奶奶把孩子从电视前挪到自己膝上，说「等爷爷看完」。城退带孙那家，下午少儿频道刚完，孩子还要蓝猫，遥控在爷爷手里，联播片头一响客厅就静；乡留守那家先是收音机，村里电不稳，电视雪花，他拍盒子，孩子在灶边玩铁罐，罐一响他就咳一声。广告里两个动画老人转圈，他信「中央说了」，孩子背广告词，他不关。福娃、开幕式本年没有，不要写。

**00后祖辈现在怎么提**：遥控磨亮的那几个键。指头再按到片头那一键，才想起七点客厅要静。

**当时广告 / 单位 / 生活版怎么说**：联播后脑白金同一句；电视报「今晚节目」。居委会喇叭有时跟七点抢。麻将馆口头：「联播完再来。」

**当时家里怎么说**：爷爷：「静一下。」奶奶：「抱走。」儿女：「让他看完卡通再开。」孙：按键被拿开。

**邻居牌友和其他说法**：谁家七点还开卡通，会被说没规矩。天线方向谁调，楼顶会争。未见公开争论。

**祖辈自己的一对词**：七点这台 vs 孩子要的那台。

**感官钩子**：片头喇叭；遥控按键的脆；拍电视盒子的灰；收音机调谐的沙。

**会吵什么**：联播看完再换，还是先让孩子看完卡通——让了爷爷说没大没小，不让孩子哭到门口。

**和孩子 / 父母库的接口**：下午大风车、蓝猫怎么看，详见儿童库 C-2000-03、C-2000-04。本卡不写片头玩法。

### G-2000-07 外婆要不要来住

**时间** 2000 年满月前后到断奶前后｜**落在哪** 房与路｜**称谓** 外婆 / 奶奶｜**谁家有** 城退：娘家老人挤一张沙发；县：两头住，周一婆家周五娘家；乡：外婆隔村送来一篮蛋；进城帮带：外婆先来城，奶奶后到；远距：外婆一年见一面

**事实核**：四二一家里两边老人抢第一年的床和灶，不是政策文件。谁订桌、谁请假是父母库。本卡换手：外婆的铺盖放哪、灶对不对得上、婆家让不让进门。进城睡客厅深挖可回声 2008 一头一脚、2010 回迁，本年只写来不来住。重男轻女两套标准不展开，详见带孙专篇。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 60 岁。奶奶觉得堂屋是婆家的，外婆来住要让铺。 |
| 1945 | 55 岁。外婆提着铺盖和一篮蛋进门，灶上盐放的位置就不对。 |
| 1950 | 50 岁。还在岗的外婆请不出长假，只能送一趟蛋再走。 |
| 1955 | 45 岁。未带孙。看姐姐家两边老人让铺，自己还没轮到。 |

现场：外婆把铺盖卷在编织袋里，城退那家客厅沙发腾出来，帘子一拉就是她的床，灶上她要淡粥，奶奶要咸，同一口锅两套盐；乡那家外婆不住下，隔村送来红蛋和土鸡，坐半日，临走把水温又定一遍，奶奶送到村口。儿女电话只问「你们别吵」，分钟贵，铺盖放哪他们看不见。抢勺展开见 2005，本年只写来住还是送一趟。

**00后祖辈现在怎么提**：客厅那张沙发套。套一掀到帘后的印，才想起外婆铺盖卸在门厅那天。

**当时广告 / 单位 / 生活版怎么说**：生活版开始有「月子谁来」小文，不点名婆家娘家。居委会不调解谁住。单位不管外婆的假。

**当时家里怎么说**：外婆：「我来住一段。」奶奶：「灶我熟。」儿女：「别当孩子面争。」外公：「送她去，我在家看门。」

**邻居牌友和其他说法**：谁家外婆住进来、谁家只送蛋，楼道和村口会比。住进来的那家盐罐当天换位置，送蛋的那家只坐半日。

**祖辈自己的一对词**：来住一段 vs 送一篮蛋就走。

**感官钩子**：编织袋卸在门厅；帘子拉上的灰；同一口锅两勺盐；村口土路送人。

**会吵什么**：外婆住满月，还是只白天来——住了奶奶说灶乱，不住外婆说女儿没人帮。

**和孩子 / 父母库的接口**：孩子被两边抱，详见儿童库。两边老人抢勺抢衣深挖 2005。桌钱、假条详见父母库。来住之后的偏方、两套衣，详见带孙专篇。

## 本年不写

入世、西部大开发、千年虫、申奥。盖中盖、巩俐广告不进主卡。黄金搭档还没有。阜阳、打假、换进口罐当公共事件不写。儿童库的旺仔、蓝猫、大风车、喜之郎、金锁相册不重写。父母库的满月桌钱、寻呼机、单位信封、满月假不重写。猪油改色拉油、菜场砍价、听筒接 IC、折子够不够买肉留给以后的深挖年。
