# 2004：焊花、洋字，和柜上刚有的白瓶

> 这一年要写的是 00 后爷爷奶奶外公外婆自己家里过的、手里带的。1940 年生大约 64 岁，城的多已退；1945 年生 59 岁，刚退或将退；1950 年生 54 岁，还在岗或刚退；1955 年生 49 岁，未带孙占格，写看别人领孙、自己孩子还没生。小孩的铁罐、套餐玩具只钩子一句。70 后的月供、换罐收据、假条只钩子一句。不写新闻。营养快线本年才上市。月供不进老人钱包。

## 这一年祖辈站在哪

- **1940 年生**：64 岁。城的多已拿折子；乡的仍在地里。贴砖、焊花多是他们监工，洋字他们不认。腰腿比四年前更响。
- **1945 年生**：59 岁。城的刚退或将退；乡的还在田。有的本年第一次摸到文曲星那块砖，有的还在帮儿女看一天。
- **1950 年生**：54 岁。本年主核。城的可能还在岗，机不会按，只会等墙上座机；乡的没有退休两个字。
- **1955 年生**：49 岁。很多人还在上班。未带孙占格：看邻居领孙、工会发糖、替人在焊花下递一砖。不要写成已经是奶奶。

## 这一年祖辈手里已经有的

堂屋板凳、礼簿（详见 2000）、温水瓶、国产袋装奶粉、进口罐他们反对、脑白金他们收下不是买（详见 2000）、黄金搭档已有不深挖、年猪糖色（详见 2000）、收音机联播（详见 2000）、墙上座机仍是主场、IC 卡那头是儿女（详见 2003）、小灵通天线他们不会回、寻呼机在儿女腰上、诺基亚按键他们不会、蜂窝煤乡下仍在、罐装煤气县城主流（详见 2003）、开水瓶还在灌（详见 2003）、排风扇他们说够了（详见 2003）、猪油还在（详见 2002）、折子城的才有（乡的没有，新农保还没有）、麻将牌、单位退休证、水泥沙、焊花、防盗网、汇款单按手印、营养快线刚上柜他们当补品塞、肯德基电视里有、城里表哥才去过。月供是儿女的账，不进折子。好记星广告他们听不懂功效。寄宿、点读功效详见带孙专篇。旺仔、套餐玩具详见儿童库。月供、换哪罐谁付钱、好记星收据、装修预算、换机详见父母库。

### G-2004-01 老家贴砖、焊防盗网，他们监工

**时间** 2004 年前后老家改脸，欧式石膏线这几年才有人跟｜**落在哪** 房与路｜**称谓** 爷爷 / 奶奶｜**谁家有** 城退：单位房翻新，他们盯工；县：贴砖、焊网开始有；乡：刷墙或自己砌，少吊顶；进城帮带：人在城、焊花在老家；远距：只看见后来寄来的半墙照片

**事实核**：父母库 P-2004-01 写月供第一次进饭桌，P-2004-05 写瓷砖吊顶谁付钱。本卡换手：老人监工、水泥、焊花。月供是 70 后的账，不要写成老人还贷，也不要写成房价社论。100 平装修 2000 年口述 2–3 万，2005 年口述 8–10 万，2004 年落在中间，工料价口述、待核。防盗网不锈钢焊在窗外，城楼房多见，乡平房多院墙和狗。整体橱柜仍不要写成家家有。寄回来的钱贴半墙，人还在娘家，见 G-2004-07。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 64 岁。乡的蹲沙堆数袋，城的在窗下看电焊。 |
| 1945 | 59 岁。爷爷用棍搅水泥，奶奶不让孩子踩未干的缝。 |
| 1950 | 54 岁。还在岗的请不出整天，下班回来摸砖缝空不空。 |
| 1955 | 49 岁。未带孙。帮姐在焊花下递一块砖，自己还不是这面墙的主家。 |

现场：乡下爷爷蹲在堂屋沙堆边，水泥袋拆开，他用棍搅，灰进领口，包工头报一个数他再砍，说「这墙我看着」；砖贴到腰线，上面仍刷大白，防盗网若焊，不锈钢凉，焊花溅到窗台，他用扫帚扫，扫不干净。城退那家窗外电焊直冒花，爷爷说「孩子别爬」，焊完像一排笼子，月供单不在他抽屉里，他只认焊渣和空鼓。外出寄一笔回来，老人把堂屋贴了半墙，人还在城中村，焊花不在自己窗下。首付、日历红圈详见父母库，本卡只写谁盯、谁搅。

**00后祖辈现在怎么提**：窗台上嵌着的一点焊渣。渣一硌指头，才想起那年扫帚扫不干净。

**当时广告 / 单位 / 生活版怎么说**：建材市场「装修就找谁」；不锈钢店「专业防盗网」。单位不发包工。不是楼市社论。生活版开始出现「轻装修」，他们听成「少花点」。

**当时家里怎么说**：爷爷：「这墙我看着。」奶奶：「缝没干别踩。」儿女：「钱我们汇。」包工头：「石膏线这年头时兴。」

**邻居牌友和其他说法**：谁家先焊网，谁家只贴腰线，同村就比。偷工、空鼓砖会吵，会换施工队。谁家折子薄只贴到腰线，半墙会让人问一句。

**祖辈自己的一对词**：沙堆这一搅 vs 日历上那一圈月供。

**感官钩子**：水泥灰进领口；焊花溅窗台；不锈钢管冰手；空鼓砖敲上去的闷。

**会吵什么**：砖贴满墙再焊网，还是只贴腰线——满了儿女说钱紧，不满爷爷说不像家。

**和孩子 / 父母库的接口**：孩子在空房跑、趴网看楼下，详见儿童库点名。月供谁还，详见父母库 P-2004-01。瓷砖吊顶预算详见父母库 P-2004-05。

### G-2004-02 进口罐他们反对，洋字他们不认

**时间** 2004 年喂养日常换罐，不是打假现场｜**落在哪** 带孙现场 / 钱包｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：超市铁罐和袋并列，他们拦铁罐；县：批发部袋装为主；乡留守：更便宜的袋、温水瓶冲；进城帮带：客厅帘后那只袋；远距：电话里只问「几勺」

**事实核**：只写家里哪罐、谁冲、水温谁定。禁止打假新闻。日常选择是国产袋还是进口罐。惠氏等进口 400 克口述约 90–120 元，待核到你所在柜；国产 400 克袋常见十几到几十元。水温回声 2000（G-2000-02），本年换手到「洋字他们不认」。谁买罐、收据进哪只抽屉是父母库 P-2004-02。旺仔铁罐不是配方粉，详见儿童库。农村没有农保折子，袋钱从收成或寄款出。城的折子若抽一罐进口，约合好几天肉。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 64 岁。腕内侧仍试温，罐上的洋字她念不出。 |
| 1945 | 59 岁。奶奶冲袋装，外婆若来住会说「还不是粉」。 |
| 1950 | 54 岁。还在岗的夜里赶回来冲一瓶，进口罐她不开。 |
| 1955 | 49 岁。未带孙。替邻居守一晚，水温仍按邻居说的，洋字她不敢认。 |

现场：奶奶把国产袋夹子夹上，勺磕到底，温水瓶倾一下，腕内侧一试，烫了兑凉，粉剂结块她用筷子捣；铁罐上的洋字她指着说「认不得，还不是粉」，九十到一百二她算成好几斤肉。城退带孙那家儿女把惠氏抱回来，她仍先开袋，铁罐搁柜顶给来客看，夜里不拆。乡留守那家整夜都是她的勺，袋放灶沿，孩子吐了她再冲，电话里儿女问「几勺」，她只报「吃了」，说不了段数。追着喂详见带孙专篇，本年只写洋字和腕。

**00后祖辈现在怎么提**：袋口夹子的塑料脆响。夹子一咬合，才想起洋字始终没念顺。

**当时广告 / 单位 / 生活版怎么说**：电视里笑脸宝宝；超市堆头「婴幼儿配方」；导购说「罐装拿得出手」。单位不发奶粉。生活版教冲调比例，不教打假。

**当时家里怎么说**：奶奶：「洋字我不认。」外婆：「还不是粉。」儿女：「进口的先缓缓。」孙：只哼，不评哪罐。

**邻居牌友和其他说法**：谁家柜顶有铁罐，谁家仍袋装，楼道会比。胀袋会换一家批发部。谁家假盒洋字掉漆，亲戚捏完才不信。不要写成后来的新闻。

**祖辈自己的一对词**：袋上这只夹 vs 罐上那排洋字。

**感官钩子**：勺磕袋底；腕内侧一缩；铁罐洋字摸上去的凹；袋口受潮的甜腥。

**会吵什么**：继续冲国产袋，还是拆开进口罐——拆了奶奶说浪费肉钱，不拆儿女说买来就是喝的。

**和孩子 / 父母库的接口**：孩子嘴里那口烫或甜，详见儿童库摇篮卡。谁买罐、收据多少钱，详见父母库 P-2004-02。水温详见 G-2000-02。追着喂详见带孙专篇。

### G-2004-03 文曲星他们摸着嫌贵，当砖重

**时间** 2004 年学习电器进抽屉，老人先摸壳｜**落在哪** 器物｜**称谓** 爷爷 / 奶奶｜**谁家有** 城退：商场柜台他们被拉去摸；县：有广告才问，不一定买；乡：少有，课本加磁带；进城帮带：寄钱让老人进店看一眼；远距：广告里的蜗牛进不了堂屋

**事实核**：年份篇只写手和钱、当砖重。功效、按着点、黄冈海淀不写，详见带孙专篇、父母库育儿。文曲星 2000 年前后已鼎盛，口述 200–500 元一台。好记星约 2004 年砸进央视，零售有往千元档走的口述，本年标价待核。谁掏钱、收据和月供抢抽屉是父母库 P-2004-03。本卡换手：老人摸着嫌贵、坠手腕、说以前一本字典。点读机中后期更密，本年不要写成步步高点读机家家有。四驱车、悠悠球不进本卡。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 64 岁。灰壳坠手，说「一本字典够了」。 |
| 1945 | 59 岁。爷爷按一下咔嗒，立刻松手，怕按坏。 |
| 1950 | 54 岁。还在岗的觉得三百顶好几天菜，仍让儿女别空着手。 |
| 1955 | 49 岁。未带孙。帮姐进店问一句价，机没有带回家。 |

现场：商场柜台上文曲星灰壳按键咔嗒，爷爷接过来，坠手腕，像一块砖，说「这么沉，三百？」；好记星更薄一点也更沉，导购把牛津标亮给看，他不认，只问「能当砖砸人」。城退那家儿女掏现金，机塞进书包坠一边，老人把收据翻过来看，说「顶好几斤肉」。乡下老人进店问一句就走，机没有带下乡，课本已经够沉，广告里的蜗牛进不了堂屋。功效怎么用，本年不写。

**00后祖辈现在怎么提**：灰壳按键磨亮的那几个。键一咔嗒，才想起坠手腕、说太沉。

**当时广告 / 单位 / 生活版怎么说**：央视黄金时段好记星广告；文具店海报「学英语」。单位不发学习机。生活版教「选哪一台」，不教怎么点书。

**当时家里怎么说**：爷爷：「太贵，沉。」奶奶：「字典就行。」儿女：「广告里都在买。」导购：「这台沉，功能多。」

**邻居牌友和其他说法**：谁家先有好记星，谁家还是文曲星，村口会比。买来不用、落灰的闲话已有。未见公开争论。

**祖辈自己的一对词**：手里这块砖 vs 以前那本字典。

**感官钩子**：灰壳按键咔嗒；机身坠手腕；收据纸压坑；书包坠一边。

**会吵什么**：三百块文曲星，还是近千的好记星——差价够一个月菜，老人两边都嫌贵。

**和孩子 / 父母库的接口**：孩子玩贪吃蛇、按键，详见儿童库点名。谁买单、功效怎么用，详见父母库 P-2004-03、带孙专篇。四驱车、悠悠球不进本卡。

### G-2004-04 机他们不会按，只会等墙上座机

**时间** 2004 年儿女换机之后的日常｜**落在哪** 自己的日子｜**称谓** 爷爷 / 奶奶 / 外公｜**谁家有** 城退：班上有人换成诺基亚，老人不会回；县：波导、二手 3310、小灵通更常见；乡：机少，仍靠墙上座机；进城帮带：机在儿女裤袋，听筒在老家；远距：厂里机响，老家仍接墙上

**事实核**：父母库 P-2004-06 写班上把腰上那只换成诺基亚。本卡换手：老人不会按、不会回短信、只会等墙上座机。3310 蓝白键，到 2004 年新机已少、二手更常见，港边口述有几百元档，待核；品牌机口述 1000–2000 元，波导 500–1000 元（已有研究《第一台电脑与诺基亚》）。小灵通 1 分钟约 1 毛，信号差（人民政协网口径）。墙上座机、IC 卡、小灵通，禁止视频通话。触屏十年末才轻轻出现。1955 未带孙写自己工位上的机，不是给孙回的。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 64 岁。诺基亚按键他认不出，铃声响了只喊「你来接」。 |
| 1945 | 59 岁。小灵通天线他拧来拧去，信号格少就骂。 |
| 1950 | 54 岁。主场。还在岗的可能有一部波导，仍把要紧事打到墙上。 |
| 1955 | 49 岁。未带孙。自己工位上开始有机，回家仍等座机，不是给孙回的。 |

现场：儿女把诺基亚拍在桌上，蓝白壳、键咔嗒，爷爷伸手按错，屏幕绿一下又灭，他推回去，说「有事打家里」；墙上座机线还在，听筒油，他守着匣子。城退那家科室先换齐按键机，皮套从腰带拔下空着，老人不会回短信，儿女呼了再打到墙上，三句仍是「吃了、睡了」。乡留守那家机在厂里响，奶奶不会回，仍要等灶边听筒。1955 年生帮同事看一眼机，贪吃蛇他不玩，自己还没有孙要报。全屋没有触摸屏。

**00后祖辈现在怎么提**：墙上座机匣子钥匙。钥匙一锈手，才想起按错键那一闪绿光。

**当时广告 / 单位 / 生活版怎么说**：「诺基亚，科技以人为本」；「波导手机，手机中的战斗机」；营业厅「预存话费送机」。单位开始要求「保持开机」，老人听成「家里那部别关」。生活版教短信，不是行业史。

**当时家里怎么说**：爷爷：「打家里。」奶奶：「机我不会。」儿女：「开机就行。」1955 那年的人：「我工位上有，家里还是座机。」

**邻居牌友和其他说法**：谁家老人先会回一个字，谁还在守匣子，牌友就比。假电池、水货机有，会去修配店。谁家先退下来才肯学按键，工号还在的不摸那排键。

**祖辈自己的一对词**：墙上这只听筒 vs 掌心里那排键。

**感官钩子**：按键咔嗒按错；小灵通天线拧涩；匣子钥匙锈；蓝白壳冰手。

**会吵什么**：逼老人学回一个字，还是继续打到墙上——学了他们怕按丢，不学儿女说呼了没人应。

**和孩子 / 父母库的接口**：孩子伸手要玩蛇，详见儿童库点名。谁换机、谁付钱，详见父母库 P-2004-06。听筒报吃了没详见 G-2003-03。

### G-2004-05 快线刚上柜，他们当补品塞

**时间** 2004 年娃哈哈营养快线上市，柜上开始有｜**落在哪** 灶上｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：小卖部刚出现白瓶，他们当补品塞给孙；县：部分柜到货；乡：多数代销点还没有；进城帮带：厂门口偶见，塞进行李；远距：托人带一瓶，甜水剩半瓶

**事实核**：营养快线 2004 年上市，「牛奶+果汁+15 种营养素」；2005 年「早餐喝一瓶，精神一上午」才打通场景（中国经济网 http://www.ce.cn/cysc/sp/info/201407/18/t20140718_3186884.shtml ）。本年只写柜上刚有、他们当补品塞给孙，不是学生早餐史，也不要写成人手一瓶。2003 年多数柜还没有，见父母库 P-2003-07、G-2003-04。零售口述约 3 元一瓶，待核到你所在柜。谁当赶路早餐买单是父母库 P-2004-07。本卡换手：老人当补品、塞进孙手里、说「补一补」。利乐枕、粥仍是家里更常见的。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 64 岁。白瓶冰手，说「这是补的，别当水喝」。 |
| 1945 | 59 岁。奶奶拧开大瓶口，先倒进杯里再塞给孙。 |
| 1950 | 54 岁。还在岗的下班顺手买一瓶，搁柜顶当脑白金那样摆。 |
| 1955 | 49 岁。未带孙。给姐的孩子塞一瓶，自己不喝，说「留给小的」。 |

现场：小卖部冰柜多出一排白瓶，奶奶问「这是什么」，老板说「新来的，牛奶加果汁，三块」；她当补品买，不是当早餐，拧开先倒进杯，甜水她自己不喝，塞给孙说「补一补」。城退带孙那家墙角利乐枕还在，粥锅还在，快线是柜上的新面孔，试一瓶、两瓶，楼里还没人天天拎；她把空瓶洗了当花瓶，蓝礼盒那种摆法。乡下代销点仍是袋奶和 AD 钙奶，快线箱子没卸，售货员不会背「精神一上午」——那句明年才打满。早餐仍是粥，白瓶盖还冰。

**00后祖辈现在怎么提**：洗干净当花瓶的那只白瓶。瓶底水渍一摸，才想起三块当补品塞给孙。

**当时广告 / 单位 / 生活版怎么说**：本年更多是终端推荐「新品种」；「早餐喝一瓶」大战在 2005。单位不发快线。生活版仍写「早晨喝奶」，奶多半指利乐枕。

**当时家里怎么说**：奶奶：「补一补。」爷爷：「三块当水？」儿女：「来不及就喝一瓶。」孙：抢甜口。

**邻居牌友和其他说法**：谁先买给孙当补，谁说「甜水」，巷口刚开始有闲话。未见公开争论。

**祖辈自己的一对词**：当补品这一塞 vs 当早餐天天买。

**感官钩子**：白瓶冰手；大瓶口甜；空瓶当花瓶的水渍；3 块硬币拍在玻璃柜上。

**会吵什么**：三块当补品塞给孙，还是省下来煮粥——塞了爷爷说浪费，不塞奶奶说柜上刚有要试试。

**和孩子 / 父母库的接口**：孩子抢甜口，详见儿童库饮料点名。谁当早餐买单，详见父母库 P-2004-07。2003 年柜上还没有，见 G-2003-04。

### G-2004-06 肯德基他们骂浪费，仍掏不掏

**时间** 2004 年后加速下沉，本年有的县刚挂招牌｜**落在哪** 带孙现场 / 钱包｜**称谓** 爷爷 / 奶奶｜**谁家有** 城退：早有店，仍是奖赏，他们骂仍掏；县：2004 后才密，有的本年第一家；乡：无店，电视里有、城里表哥才去过；进城帮带：暑假才带去坐一回；远距：纸盒是别人寄的照片

**事实核**：肯德基 1987 进京，2004 年后加速下沉（数食链 http://www.foodatalink.com/article_detail?id=333 ）。先写清这座城有没有店：没有就写电视里有、城里表哥才去过，或德克士、家乡鸡。儿童套餐口述 15–25 元，待核。谁付钱见父母库 P-2004-04、P-2001-02。本卡写他们骂浪费、仍掏不掏。洋快餐是奖赏不是主食。玩具收集详见儿童库，四驱车、悠悠球不进本卡。考完去、分换鸡详见带孙专篇，本年只钩子一句。不要写成日常晚饭。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 64 岁。说「洋人的饭」，纸盒烫手他仍掏一张十块。 |
| 1945 | 59 岁。奶奶骂浪费，爷爷把折子里一张票子抽出来。 |
| 1950 | 54 岁。还在岗的觉得二十块顶一顿红烧，仍让儿女别空着手。 |
| 1955 | 49 岁。未带孙。看同事领孙去排队，自己只在电视里见过招牌。 |

现场：这座城若已经挂了红白招牌，周末队伍转到路口，爷爷攥着一张十块，说「太贵，浪费」，仍把票子递进去，套餐十五到二十五，托盘上纸盒发烫，他不吃，看孙咬一口鸡，自己回去热剩菜。折子若在，抽的是他给孙的那一截，不是月供那一行。这座城若还没有店，电视里肯德基爷爷转，城里表哥过年才说「去过」，乡下堂屋没有纸盒，只有家乡鸡或德克士的油纸，老人仍骂「一顿顶几天菜」，掏不掏看折子薄不薄。玩具怎么拆，不在本卡。

**00后祖辈现在怎么提**：钱包夹层里那张套餐油纸。油纸一黏，才想起骂了仍把十块递进去。

**当时广告 / 单位 / 生活版怎么说**：店门口「儿童套餐」立牌；电视里肯德基爷爷。单位不发炸鸡券。生活版开始有「偶尔吃」的说法，不是社论。

**当时家里怎么说**：爷爷：「浪费。」奶奶：「就这一回。」儿女：「我们出。」孙：伸手要玩具。

**邻居牌友和其他说法**：谁家先排到新店，谁家还去家乡鸡，牌友就比。没有店的乡只在口头上比。未见公开争论。

**祖辈自己的一对词**：骂浪费这一句 vs 折子里仍抽一张。

**感官钩子**：红白招牌的光；纸盒烫手；油纸黏钱包；折子被抽出一格的空。

**会吵什么**：掏二十块进店，还是十块家乡鸡——差的十块是面子，也是这个月肉边那一点。

**和孩子 / 父母库的接口**：玩具拆包、集齐，详见儿童库。谁付钱，详见父母库 P-2004-04、P-2001-02。分换鸡详见带孙专篇。四驱车、悠悠球不进本卡。

### G-2004-07 外婆寄钱回来贴半墙，人还在娘家

**时间** 2004 年老家贴砖那几个月，汇款单往来｜**落在哪** 房与路 / 钱包｜**称谓** 外婆 / 外公｜**谁家有** 城退：娘家老人人在城、钱寄回乡下贴墙；县：外婆在娘家收砖，人不过来住；乡：汇款单按手印，堂屋贴半墙；进城帮带：人在城中村，墙在老家；远距：一年一面，只看见半墙

**事实核**：寄钱贴墙是家里账，不是政策文件。月供不进老人钱包。汇款单按手印可写，邮局柜台、手印、金额，不要写成农业税或补贴。谁装修、谁付工钱是父母库 P-2004-05。本卡换手：外婆人还在娘家、钱先到、墙贴一半、人没过来住。2000 外婆要不要来住是铺盖，本年是汇款和半墙。抢带流程不展开，详见带孙专篇。农村没有农保折子，寄的是儿女或外婆自己的收成。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 64 岁。外婆在娘家堂屋按手印，墨在指腹。 |
| 1945 | 59 岁。外公去邮局，单子上「贴墙」两个字是他写的。 |
| 1950 | 54 岁。还在岗的外婆请不出长假，只能寄钱，人不过来。 |
| 1955 | 49 岁。未带孙。看姐姐家汇款单按手印，自己还没有墙要贴。 |

现场：外婆在娘家灶边把铺盖卷好，人不过来住，邮局柜台上汇款单，她按手印，指腹一圈蓝，金额写「贴半墙」，备注怕柜员看不懂，只说「给女儿家」。钱到了，婆家爷爷搅水泥，砖贴到腰线停住，上面仍是大白；外婆不在场，焊花不在她窗下，她只在电话里问「贴了没有」，分钟贵，缝空不空她看不见。城退那家客厅沙发仍是她的床，墙是老家的，人在娘家收茄子，半墙照片后来才寄到。儿女月供日历不在这张单上。

**00后祖辈现在怎么提**：汇款单按手印那一页。指腹对着那圈蓝，才想起墙只贴到腰线。

**当时广告 / 单位 / 生活版怎么说**：邮局柜台「国内汇款」；建材市场不认汇款单，只认现金。居委会不调解谁寄。单位不管外婆的假。

**当时家里怎么说**：外婆：「钱我寄，人我不过去。」奶奶：「墙我看着贴。」儿女：「月供另算。」外公：「手印我按。」

**邻居牌友和其他说法**：谁家外婆只寄钱不来住，谁家来住还贴全墙，村口会比。谁家外婆住进来盯工，盐罐和沙堆同一周响。不要写成政策。

**祖辈自己的一对词**：人在娘家 vs 钱先贴半墙。

**感官钩子**：指腹手印的蓝；汇款单纸发潮；半墙砖缝的白；电话里问贴了没有。

**会吵什么**：外婆寄钱不来住，还是人过来盯工——来了奶奶说灶乱，不来外婆说墙贴歪了没人认。

**和孩子 / 父母库的接口**：孩子在半墙下跑，详见儿童库点名。装修谁付钱，详见父母库 P-2004-05。月供详见父母库 P-2004-01。来住详见 G-2000-07。监工详见 G-2004-01。
