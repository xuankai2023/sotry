# 2007：门口天黑、回力，和罩子里那碗

> 这一年要写的是 00 后爷爷奶奶外公外婆自己家里过的、手里带的。1940 年生大约 67 岁；1945 年生 62 岁；1950 年生 57 岁，城的多已退，乡的仍在地里；1955 年生 52 岁，可开始带晚 00 后，未带仍占格，写帮一天、看别人等。小孩脚上的标、4399 只钩子一句。70 后改菜谱、加班盒子、红包加码只钩子一句。不写新闻。

## 这一年祖辈站在哪

- **1940 年生**：67 岁。城的折子已拿多年；乡的仍出工。校门口等天黑、罩子、回力，多是他们的脚和手。腰腿更响。
- **1945 年生**：62 岁。城的多已退；乡的还在田。有的本年天天接，有的仍只帮儿女看一天。
- **1950 年生**：57 岁。本年主核。城的多已退，也有人还在打卡；乡的没有退休两个字。接送和自己的地抢同一段下午。
- **1955 年生**：52 岁。很多人还在上班。晚 00 后刚有的，开始接手；未带占格：看同事领孙、看邻居拎回力，自己还没有小学孙要接。

## 这一年祖辈手里已经有的

门口等到天黑、回力 / 飞跃 / 双星、红烧改蛋他们舍不得、份子从折子或压箱抽、夜班留的菜他们罩、外公自行车后座、十块他们拦着不给网吧。塑料凳可点名，铁门外写满留给 2010。空调他们嫌冷、费电，点到为止，先买哪样详见父母库。翻腊肉只回声，全过程详见 2006。礼簿、水温、糖色、脑白金收下、打卡抢孙、联播要静详见 2000。折子够不够买肉详见 2001。猪油、菜场砍价详见 2002。听筒报吃了没详见 2003。校服钱他们垫、点读机当砖详见 2006。家电下乡本年只在少数省试点听说，不是全乡换冰箱。旺仔、4399 玩法、脚上链详见儿童库。改菜谱、名牌鞋他们掏、加班接送、空调电脑、酒席加码、夜班盒饭、十块给网吧还是冰棍详见父母库。

## 本年主卡（7 张）

### G-2007-01 门口等到天黑

**时间** 2007 年工作日下午到天黑｜**落在哪** 带孙现场｜**称谓** 奶奶｜**谁家有** 城退：校门口等到路灯亮；县：车间铃和小学铃差一截，他们站着补；乡留守：村口或镇校门口；进城帮带：人在城、脚在铁门外；远距：听筒里问接到没有

**事实核**：小学常见下午三四点散，科室加班到七八点，口述、待核到你所在校和厂。本年写他们的脚和天黑，不是班点方案。塑料凳可点一下，铁门外写满留给 2010。加班和接送对不上是父母库 P-2007-03。本卡换手：谁站到天黑、脚肿不肿、座机怎么报。儿童库写孩子在门口等谁来。不写院子空的案件。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 67 岁。脚先肿。天黑了仍不走，说「人没来我不能先走」。 |
| 1945 | 62 岁。城的拎书包靠墙；乡的在村口数车灯。 |
| 1950 | 57 岁。还在岗的请不出，托刚退的邻床；退了的天天站。 |
| 1955 | 52 岁。未带或只帮一天。帮姐在门口等一晚，第二天自己赶早班，不说「我带了」。 |

现场：奶奶把重心从左脚换到右脚，鞋帮勒出印，天从黄换成黑，校门口第二轮人散完，她还在。城退带孙那家，铁门外有时拖一张塑料凳，本年凳子只是垫一下脚，人仍多是站着；墙上座机若响，她只报「还没来、灯亮了」，分钟贵，说不了等多久。乡留守那家没有车喇叭，她在镇校门口或村口土路等，书包带子勒手心，孩子脚冷她把外套解开裹上，天黑透了才往回走，路上踩到水坑也不骂。儿女回不来是他们的班，详见父母库；本年是老人的脚和天。

**00后祖辈现在怎么提**：鞋帮那一圈印，或天黑后路灯先照到的脚尖。摸到鞋帮勒印，书包带还像勒在手心。

**当时广告 / 单位 / 生活版怎么说**：校门口小店「代管写作业」；生活版开始有「接送难」，不写谁的脚。居委会不发等门通知。麻将馆口头：「她天天站到黑。」

**当时家里怎么说**：奶奶：「我再等一会儿。」爷爷：「脚肿了就先回。」儿女：「今晚回不了。」孙：「奶奶你怎么还不走。」

**邻居牌友和其他说法**：谁家老人站到路灯亮、谁家托对门，楼道会比。站到黑的说托人是不管，托对门的说天天站是要面子不要脚。

**祖辈自己的一对词**：再站一会儿 vs 脚先回去。

**感官钩子**：鞋帮勒印；天黄换黑；书包带勒手心；土路水坑溅裤脚。

**会吵什么**：等到天黑还站，还是先把孩子带回去吃饭——走了怕人来接空门，不走脚第二天抬不起来。

**和孩子 / 父母库的接口**：孩子在门口等谁来，详见儿童库院子与接送钩子。班点和铃对不上，详见父母库 P-2007-03。晚托、门口制度详见带孙专篇。铁门外塑料凳写满见 2010。

### G-2007-02 鞋他们买回力

**时间** 2007 年开学、换季｜**落在哪** 钱包｜**称谓** 爷爷 / 奶奶｜**谁家有** 城退：他们进店买回力或飞跃；县：供销社或街边鞋摊；乡留守：集上三十五也能跑；进城帮带：人在城、鞋寄回老家；远距：托人带一双，号可能小

**事实核**：回力、飞跃、双星这十年是便宜球鞋，口述 30–50 元一双，不是 2018 以后的潮牌（已有研究《衣服鞋与日化》；https://36kr.com/p/1181140268739457 ）。名牌童鞋一两百级是父母库 P-2007-02 掏的；脚上链、logo 正不正详见儿童库 C-2007-07。本卡换手：老人买哪双、说耐穿、差价他们舍不舍得从折子抽。城的企业折子 2005 年底月均约 700 元量级，回力 40 约合几天买肉钱，口述、待核。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 67 岁。捏鞋头，说「回力耐穿，白边洗洗还能穿」。 |
| 1945 | 62 岁。城的跟到店里付款；乡的在集上数三十五。 |
| 1950 | 57 岁。还在岗的自己工资买；退了的从折子抽一张。 |
| 1955 | 52 岁。未带。给侄子试一双双星，工会发糖那袋还在抽屉，自己孩子还没有要跑的鞋。 |

现场：爷爷把回力从纸盒里掏出来，橡胶味冲鼻子，白帆布一按就窝，他说「能跑就行」。城退带孙那家，孩子指橱窗里安踏、特步，标亮，他仍把四十块拍在柜上，收据不拿，说「有标的顶好几斤肉」；奶奶在旁边补一句「以前没牌子也穿到大」。乡留守那家集上摆飞跃、双星，三十五到五十，白边当天就沾土，他用手掌拍灰，说「耐穿」。仿标胶味更重，他不买，认老牌子的红标。儿女若另掏一两百，那是父母库的手；本年是老人口袋里的回力。

**00后祖辈现在怎么提**：鞋盒里那包干燥剂，或白边洗不掉的灰。摸到干燥剂沙沙响，才想起四十块拍在柜上。红标比后来的潮牌名先在手里。

**当时广告 / 单位 / 生活版怎么说**：电视里运动鞋广告他们当热闹；店招 logo 他们不认。供销社口头：「回力还有。」单位不发童鞋。

**当时家里怎么说**：爷爷：「回力耐穿。」奶奶：「白鞋耐脏。」儿女：「同学都有标。」孙：低头看别人的鞋。

**邻居牌友和其他说法**：谁家老人买回力、谁家儿女另买有标的，家长会门口能看出来。假红标一抠就掉。买回力的说有标是烧钱，买有标的说白边沾土进门就矮人一截。

**祖辈自己的一对词**：四十块耐穿 vs 一两百有标。

**感官钩子**：新鞋橡胶味；白帆布一按就窝；四十块拍柜；白边沾土用手掌拍。

**会吵什么**：买回力四十，还是让儿女去买有标的——买了孩子在班上低头，不买折子要再薄一截。

**和孩子 / 父母库的接口**：脚上怎么比、logo 正不正，详见儿童库 C-2007-07。安踏特步谁掏、校服同一笔，详见父母库 P-2007-02。

### G-2007-03 红烧改蛋他们舍不得

**时间** 2007 年春夏到年底，灶上｜**落在哪** 灶上｜**称谓** 奶奶 / 爷爷｜**谁家有** 城退：菜场少称精瘦，他们盯空着的糖色锅；县：一周一次荤他们记；乡：圈空了翻腊肉，仍念那碗红烧；进城帮带：人在城、肉钱寄回不够炒糖色；远距：电话里问「还有褐色没有」

**事实核**：不是没肉年，是改谱。农业部：2007 年 7 月猪肉均价 20.77 元/公斤（http://www.moa.gov.cn/gk/jcyj/xm/201006/t20100612_1550256.htm ）。36 城零售精瘦肉约 12.64 元/斤（http://finance.sina.com.cn/roll/20070806/15231586038.shtml ），菜场口述常见 12–14 元/斤，待核到你所在摊。城镇人均年购猪肉 2006 年 20.00 千克 → 2007 年 18.21 千克，农村食猪肉 15.46 → 13.37 千克（《中国统计年鉴》，见《猪肉与菜谱》）。改菜谱、加班面是父母库 P-2007-01。本卡换手：他们舍不得那碗红烧、铲还想炒糖色。翻腊肉全过程详见 2006，本年只回声檐下那一提。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 67 岁。糖色锅空着仍擦一遍，说「没有红烧不像家」。 |
| 1945 | 62 岁。城的把半斤精瘦放回去，改称一袋蛋；乡的掀腊肉。 |
| 1950 | 57 岁。还在岗的中午食堂见荤，晚上家里仍是蛋。 |
| 1955 | 52 岁。未带。在自己父母桌上帮炒蛋，还不是这口锅的主勺。 |

现场：奶奶在菜场铁钩下问完价，秤盘上薄薄一片，十二三块一斤，她把肉放回去，袋里换成蛋。城退带孙那家，灶上仍要那碗褐色，铲在锅边搁着，糖色不炒，蛋液下锅金黄，她说「也能撑」，眼神却在空锅上停一下；过年那碗往往还在，平日舍不得。乡留守那家圈空了，爷爷只把檐下腊肉取下一截，回声 2006 那一下，不重写烫毛铁钩；鲜的赶集才见，桌上仍念「往年红烧」。不是柜上没肉，是他们口袋和那口锅对不上。

**00后祖辈现在怎么提**：空着的糖色锅沿，或放回去那片肉的凉。摸到空锅沿，才想起蛋换了褐色、檐下少了一截。

**当时广告 / 单位 / 生活版怎么说**：晚报生活版「改菜谱」「荤素搭配」；食堂小黑板有的改素窗口。单位不发肉票。烹饪节目仍教炒糖色，不教他们放回去。

**当时家里怎么说**：奶奶：「排骨先缓缓。」爷爷：「没有红烧不像家。」儿女：「蛋也是荤。」孙：「怎么又是蛋。」

**邻居牌友和其他说法**：谁家还敢称排骨，谁家改带鱼，菜场就比出来。称排骨的说改蛋是穷，改蛋的说称排骨是把下月肉提前吃完。

**祖辈自己的一对词**：必须有那碗褐色 vs 蛋也能撑。

**感官钩子**：秤盘薄片放回去的凉；空锅沿一擦；蛋液下锅的金黄；檐下腊肉油渍入手。

**会吵什么**：半斤精瘦还称，还是改蛋把红烧留给年——称了折子紧，不称爷爷说灶上没面子。

**和孩子 / 父母库的接口**：孩子只看见碗里金黄，详见儿童库不展开。改谱、加班那袋面，详见父母库 P-2007-01。翻腊肉全过程详见 2006。

### G-2007-04 份子从折子里抽

**时间** 2007 年婚丧、满月、升学酒｜**落在哪** 钱包 / 自己的日子｜**称谓** 爷爷 / 奶奶｜**谁家有** 城退：折子取 200–500 帮儿女随；县：100–200 他们垫；乡：无折子，从压箱或卖粮抽；进城帮带：折子在老家，人在城托人取；远距：汇一笔，礼簿上仍写老人的姓

**事实核**：红包这十年从 50–100 往 200–500，城里涨快（已有研究《酒席红包与体面》）。2005 第一次涨进饭桌，本年写又厚一截，帮儿女随。父母库 P-2007-05 是 70 后自己钱包加码；本卡换手：票子从谁的折子或压箱出来。城的企业退休金 2005 年底月均约 700 元，2010 年约 1300 元，本年夹在中间，待核（劳动统计年鉴口径，http://www.chinadaily.com.cn/dfpd/2010qglianghui/2010-03/04/content_9534487.htm ）。一个 200 的包约合几天买肉钱。乡多数没有折子，新农保还没有。白事白包口述 50–200，待核。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 67 岁。折子翻到取款页，手抖着填 200，说「以前五十」。 |
| 1945 | 62 岁。城的陪儿女去柜面；乡的掀压箱底。 |
| 1950 | 57 岁。还在岗的先垫工资，回头再补折子。 |
| 1955 | 52 岁。未带。自己还在随别人的酒，工号抄不上满月那一格。 |

现场：爷爷把折子从柜门夹层抽出来，城退那家柜面填 200 或 500，帮儿子随同事的婚，礼簿写大写「贰佰」，他不进酒席主位，只把封交给儿女；本月买肉的格空一截，奶奶回来盯秤盘。乡留守那家没有折子，奶奶掀床下压箱，麦钱或卖猪的票子用报纸包着，抽出两张红的，50 变 100 也是涨，真给出去回不来；礼簿若在堂屋，仍是她写。不是他们办酒，是他们口袋替儿女撑体面。

**00后祖辈现在怎么提**：折子取款页那一行，或压箱报纸里少了的两张。摸到报纸潮，才想起柜面填完买肉紧一周。

**当时广告 / 单位 / 生活版怎么说**：酒店「喜宴套餐」；银行柜面「人情旺季」口头；生活版「随份子水涨船高」。单位工会薄礼不够一场。麻将馆口头：「她折子又薄一截。」

**当时家里怎么说**：爷爷：「以前五十。」奶奶：「从折子抽吧。」儿女：「这场我们出。」礼房：「写大写。」

**邻居牌友和其他说法**：谁家老人垫、谁家只让儿女随，散场就比。薄了会被记。未见公开争论。

**祖辈自己的一对词**：从折子抽 vs 让他们自己随。

**感官钩子**：折子夹层的潮；柜面复写纸；压箱报纸的霉；大写墨未干。

**会吵什么**：这场帮随 200，还是只出 100——少了儿女说拿不出手，多了本月肉停一周。

**和孩子 / 父母库的接口**：酒席上孩子抢丸子不展开。70 后自己加码，详见父母库 P-2007-05。礼簿管法回声 2000。

### G-2007-05 夜班留的菜他们罩

**时间** 2007 年夜班、值班、加班到后半夜｜**落在哪** 灶上｜**称谓** 奶奶｜**谁家有** 城退：罩子扣在灶上或进冰箱一层；县：没有冰箱就用纱罩；乡留守：留的菜等不到人，热给孙；进城帮带：客厅灶对不上，罩子仍是他们的；远距：电话里问「罩上了没」

**事实核**：夜班盒饭、窗口几元到十元是父母库 P-2007-06。本卡换手：罩子谁扣、隔夜谁热、热给谁。食堂盒子口述待核到你所在厂。家里罩子竹纱或塑料，冷油隔夜，回锅给孙子热一口，不是给盒子里的人表演。2003 夜班谁值另角度，不复读。方便面当正餐见已有研究，本年不写袋。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 67 岁。罩子一扣，灯留一盏，说「回来热」。人没回，早上热给孙。 |
| 1945 | 62 岁。城的会进冰箱一层；乡的只有罩，赶苍蝇。 |
| 1950 | 57 岁。还在岗自己也值，回来掀罩，菜已给孩子吃过。 |
| 1955 | 52 岁。未带。替邻居守一天灶，自己家里没有人要留。 |

现场：奶奶把中午剩的青菜和那一点蛋扣上罩子，竹圈压碗沿，灯留一盏，门别上。城退带孙那家，儿女夜班窗口吃了盒子，详见父母库；她早上掀罩，冷油结一层，回锅热给孙子，说「别浪费」。乡留守那家没有冰箱，纱罩赶苍蝇，人在厂里等不到这碗，她把隔夜菜热给孩子，电话里只报「吃了」，不报罩子边的油。盒子是班上的铁，罩子是灶上的手。糖色本年少了，罩子里更多是蛋。

**00后祖辈现在怎么提**：竹罩压碗沿那一圈印，或冷油揭开的膜。摸到碗沿那圈印，才想起赶苍蝇的手。人没回来，热给孙的那一口先在碗里。

**当时广告 / 单位 / 生活版怎么说**：生活版教剩菜回锅；食堂黑板「夜班窗口十点后」。单位不管家里的罩。纱罩在杂货铺论个卖。

**当时家里怎么说**：奶奶：「我罩上了，回来热。」儿女：「厂里吃过了。」爷爷：「别吵醒孩子。」孙：早上吃回锅，不问夜里。

**邻居牌友和其他说法**：谁家还有热的，谁靠盒子，楼道会比。罩子扣不严、菜馊了有，倒掉再吵。未见公开争论。

**祖辈自己的一对词**：罩上等人 vs 早上热给孙。

**感官钩子**：竹圈压碗沿；冷油揭膜；回锅滋啦；纱罩赶苍蝇。

**会吵什么**：留一碗等夜班，还是晚上先给孩子吃完——等了容易馊，不等等不到的人会问罩上了没。

**和孩子 / 父母库的接口**：孩子只听见门轴，看不见盒子。夜班盒饭详见父母库 P-2007-06。接送对不上详见 P-2007-03。

### G-2007-06 外公骑车来接

**时间** 2007 年工作日下午，娘家这条路｜**落在哪** 房与路 / 带孙现场｜**称谓** 外公｜**谁家有** 城退：自行车后座接外孙；县：车铃从巷子响到校门；乡：土路骑到镇，后座颠；进城帮带：人已在城，车停女儿单元门；远距：没有这辆车，只听电话

**事实核**：本年写外公的车、后座、娘家路，不是班点方案。婆家门口等到天黑见 G-2007-01。儿童库写后座风、书包撞后架，本卡写谁骑、住哪、车铃。车是二八或女式，口述、待核。1955 未带写帮一天。不写撤点文件。周一农用车送镇详见 2003，本年是自行车。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 67 岁。车铃生锈仍骑。后座绑一根皮带，怕外孙滑。 |
| 1945 | 62 岁。城的等绿灯；乡的土路颠，下车推一段。 |
| 1950 | 57 岁。还在岗的请不出，托外婆先接，他下班再转一趟。 |
| 1955 | 52 岁。未带。帮姐骑一趟接外甥，车还回去，不说「我带了」。 |

现场：外公把自行车从女儿单元楼下推出，车铃一拧，后座垫一块旧毛巾，外孙坐上去，书包撞后架。城退娘家这条，他从巷子骑到校门，奶奶若也在，两家老人让来让去，孩子跟外婆姓这边的车先走；他不进婆家灶，接完送回女儿家，铺盖在客厅不展开，本年只写车。乡留守那家土路，外公骑到镇校，颠得牙响，天黑一段他下车推，孩子脚蹬辐条他喝住。人在厂里的，听筒只问「接到没有」，车铃他们听不见。

**00后祖辈现在怎么提**：后座旧毛巾那一块油，或车铃生锈的一声。摸到毛巾上的油，才想起下车推的那一段。

**当时广告 / 单位 / 生活版怎么说**：车铺「补带两块」口头；生活版不写外公。居委会不管谁来接。单位不管娘家的车。

**当时家里怎么说**：外公：「我骑车去。」外婆：「皮带绑紧。」奶奶：「送到门口就行。」儿女：「接到了回个电话。」

**邻居牌友和其他说法**：谁家外公天天骑、谁家只外婆来，校门口会比。车铃掉了用嘴喊。天天骑的说只外婆来是娘家不管路，只外婆来的说骑到天黑是出风头。

**祖辈自己的一对词**：娘家这辆车 vs 婆家门口那双脚。

**感官钩子**：车铃锈；旧毛巾垫后座；书包撞后架；土路下车推的颠。

**会吵什么**：外孙跟外公车回家，还是送到婆家门口——跟了奶奶说灶乱，不跟外婆说女儿那边没人。

**和孩子 / 父母库的接口**：后座风、脚蹬辐条，详见儿童库不展开。班点对不上详见父母库 P-2007-03。抢带流程详见带孙专篇。

### G-2007-07 门帘里那股烟，他们不让进

**时间** 2007 年周末、放学后｜**落在哪** 自己的日子 / 带孙现场｜**称谓** 爷爷｜**谁家有** 城退：街对面站过；县：红纸门帘他们认；乡：多数还没有这帘，只闻过别人说的烟；进城帮带：人在城、仍拦帘；远距：寄话管不住钻

**事实核**：4399 / 矿工玩法详见儿童库 C-2007-01。网吧口述 2–5 元/小时，待核。父母库 P-2007-07 是爸妈抽十块问去不去。本卡换手：门帘、烟、红纸「禁止未成年人」，他们站在街对面拦人，不写十块对折、不写冰棍。点卡银层是 2008 的手，冰棍棍是 2010 的手。乡下多数还不会念这个网址。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 67 岁。门帘一掀烟扑脸，他说「伤眼睛」。 |
| 1945 | 62 岁。城的站在街对面拦；乡的只听过这股烟。 |
| 1950 | 57 岁。还在岗的路过，仍把人从帘边拽开。 |
| 1955 | 52 岁。未带。看邻居孙往帘里钻，自己工牌还在脖子上。 |

现场：爷爷站在街对面，网吧门帘一掀，烟和键盘声一起出来，红纸贴着「禁止未成年人」，字被油熏黄。城退带孙那家，孩子脚已经踩上门槛，他攥住书包带往后拽，不谈钱，只说「烟进肺」；帘里有人咳，他更不让进。乡留守那家本年多数没有这帘，听筒里儿女说「别进网吧」，他只懂拦门口那股说不清的烟，不懂玩法。主机拔线不在本卡。

**00后祖辈现在怎么提**：门帘布边熏黄的那一截，或红纸上油点子。烟味隔着街，比网址先在鼻子里。

**当时广告 / 单位 / 生活版怎么说**：门口红纸「禁止未成年人」，有的仍进。生活版开始有「别进网吧」，不教老人网址。单位不管帘里是谁。

**当时家里怎么说**：爷爷：「帘里有烟。」奶奶：「在家待着。」儿女：「你看着点门。」孙：「同学都在。」——后一句是钩子，玩法不写。

**邻居牌友和其他说法**：谁家老人能把人从帘边拽住，谁家孩子仍钻进去，楼里会传。门帘熏黄的，会被指给后来的人看。

**祖辈自己的一对词**：街对面这一站 vs 帘里那股烟。

**感官钩子**：门帘布熏黄；烟扑脸；红纸油点子；书包带往后拽。

**会吵什么**：死拦在帘外，还是让进坐十分钟——拦了孩子哭，进了他说烟进肺。

**和孩子 / 父母库的接口**：网址、矿工、门响切画图，详见儿童库 C-2007-01。爸妈十块怎么问，详见父母库 P-2007-07。作业写完才能上，详见带孙专篇。点卡银层详见 2008。冰棍棍详见 2010。
