# 2005：勺不放、占线，和电表那一圈

> 这一年要写的是 00 后爷爷奶奶外公外婆自己家里过的、手里带的。1940 年生大约 65 岁，城的多已退；1945 年生 60 岁；1950 年生 55 岁，刚退或还在岗；1955 年生 50 岁，开始有人带晚 00 后，未带孙仍占格。小孩的羊、杯子只钩子一句。70 后的电脑收据、红包加码、假条只钩子一句。不写新闻。

## 这一年祖辈站在哪

- **1940 年生**：65 岁。城的折子进门多年，腰腿更响；乡的仍出工，孙常在背上或灶边。抢勺、烫布、坐家长会，多是他们的手。
- **1945 年生**：60 岁。城的已退稳；乡的还在田。两边老人若轮住，换家那天勺和围嘴最响。
- **1950 年生**：55 岁。本年主核。城的可能刚退，也可能还在打卡；乡的没有退休两个字。麻将和开会抢同一段下午。
- **1955 年生**：50 岁。很多人还在上班。开始有人带晚 00 后；未带孙占格：看别人抢勺、帮姐烫一天布、自己工号还抄不上家长会那一行。

## 这一年祖辈手里已经有的

堂屋板凳、礼簿、温水瓶、袋装粉、脑白金他们收下（详见 2000）、猪油还在灶上（详见 2002）、墙上座机接 IC（详见 2002、听筒深挖 2003）、折子城的才有（乡的没有，新农保还没有）、麻将牌、单位退休证、居委会通知、开水瓶、煤或罐。电脑开始进部分城家，口头禅是儿女的「为了学习」，他们碰上的是占线；宽带还少，深挖 2008。电磁炉开始进客厅，他们怕电表。纸尿裤城有乡少，布还在烫。点读机广告露头，买单深挖 2006。营养快线柜上已有，只点名。每天一斤奶的口号还没有，不要写成 2000 已有。摩尔、赛尔未到。月供不进他们钱包。旺仔、喜羊羊详见儿童库。假条、红包档口、电脑城报价详见父母库。

## 本年主卡（7 张）

### G-2005-01 两个奶奶抢勺：碗往谁怀里转

**时间** 2005 年四二一家里最响的那一顿｜**落在哪** 带孙现场｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：两边轮住，周一婆家周五娘家；县：一家住进来，一家周末提保温盒；乡留守：几乎全是他们的勺；进城帮带：客厅帘后抢同一只碗；远距：电话里才听见抢

**事实核**：独生父母家庭由祖辈照料的约 45.7%，有报道称约 5000 万城市家庭里，三分之二的子女教育依赖或求助于老人（央视 2006-04-28，http://news.cctv.cn/news/society/20060428/101769.shtml ）。本卡换手：勺柄谁握死、碗口朝谁、咸淡谁先抿。衣服只写围嘴谁系、袖口谁挽，不写儿女眼里那套套衣。跟桌咸淡 2002 只点到咸，本年展开抢勺。追着喂怎么追，详见带孙专篇。谁订桌、谁请假详见父母库。已有研究《独生子女与压岁钱》。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 65 岁。勺柄磨出的槽是自己的茧。碗转到膝上，不让另一家接。 |
| 1945 | 60 岁。轮住那天保温盒一进门，咸淡就开战。 |
| 1950 | 55 岁。还在岗的中午赶回来抢这一勺，抢完再去打卡。 |
| 1955 | 50 岁。未带孙的看姐姐家两只碗对峙；已带晚 00 后的，第一次发现勺不能放。 |

现场：婆家灶上，奶奶右手勺不放，左手掌按住碗沿，搪瓷碗转到自己膝上，她先舀一勺自己抿，说「就这咸，我带大了你」，孩子张嘴，勺已经送进去，外婆伸手要接，她腕子一沉，碗口对着自己胸口。娘家那头，外婆把大碗往怀里一扣，另盛半碗白粥，勺背刮掉刚才那口，说「咸了明天肿」，围嘴从她围裙口袋掏出来系，袖口挽到肘，怕溅到新衣；奶奶要把自己裤腰里抽出的旧布罩上，两人抢的是系带不是衣架。进城帮带的客厅，帘后同一只碗，盐罐被挪来挪去。追着喂怎么追，详见带孙专篇。

**00后祖辈现在怎么提**：搪瓷碗沿那一圈牙印。牙印一硌唇，才想起勺柄不离掌那天。

**当时广告 / 单位 / 生活版怎么说**：母婴柜教量勺、看月龄；生活版开始讲「祖辈带养」。居委会不调解谁握勺。单位不管中午这口咸淡。

**当时家里怎么说**：奶奶：「勺在我手里。」外婆：「太咸。」儿女：「别当孩子面抢。」孙：只张嘴，不评哪只碗。

**邻居牌友和其他说法**：谁家奶奶不放勺、谁家外婆周末提保温盒，楼道和村口会比。谁家外婆住进来，碗当天就转进另一怀。

**祖辈自己的一对词**：勺不放 vs 碗让给另一家。

**感官钩子**：勺柄茧；碗沿烫掌心；保温盒揭盖的汽；围嘴带子勒脖。

**会吵什么**：这口粥谁喂完——少让一边，换家那天保温盒就先响。

**和孩子 / 父母库的接口**：孩子嘴里那口咸淡，详见儿童库。儿女看见的抢喂抢衣，详见父母库 P-2005-01。追着喂、两套衣怎么定，详见带孙专篇。

### G-2005-02 电脑一拨，听筒占线他们骂

**时间** 2005 年城里第一台台式进门之后的白天｜**落在哪** 器物｜**称谓** 奶奶 / 爷爷｜**谁家有** 城退：厅里有主机，墙上座机先占线；县：有学龄孙的家才见；乡：少，多数没有机；进城帮带：客厅既是床也是机位；远距：他们骂的是打不通的忙音

**事实核**：城镇每百户家用电脑 2005 年约 41.5 台，农村仅约 2.1 台（统计年鉴，https://www.stats.gov.cn/sj/ndsj/2007/html/J1010C.HTM ）。不是家家有，更不是家家宽带——宽带装机深挖 2008。本年仍有拨号：一上网，座机占线。品牌机口述 4000–6000 元，兼容机 3000–4000 元，钱是儿女出的，口头禅「为了学习」详见父母库 P-2005-02。本卡换手：他们摘听筒听见忙音、对着房门骂、电表转一圈点到为止。企业退休金 2005 年底月均约 700 元（劳动统计年鉴口径）。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 65 岁。听筒一贴耳就是忙音，骂「又占线」，要打给另一家问吃了没。 |
| 1945 | 60 岁。主机风扇一响，她觉得屋子在发热，电表那格她盯。 |
| 1950 | 55 岁。还在岗的中午回家，机占着线，自己的电话打不出去。 |
| 1955 | 50 岁。未带孙。在自己家碰见儿女上网，听筒同样忙，还不是守孙的人。 |

现场：奶奶把墙上座机摘下来，线拽直，耳边一串忙音，她对着房门喊「又占线了，我要打给你舅」。门缝里漏出拨号嘶嘶，键盘膜还在，孩子已经戳键。城退带孙那家，她要问外婆今天谁接，线占死，三分钟打不出去；爷爷蹲到电表箱前，玻璃里跳字，说「这玩意也吃电」，费电点到为止，包年绿灯留给 2008。乡留守那家厅里没有主机，忙音是他们打进城才碰上的：村口小卖部 IC 卡嘀一声，那头说「占线，再打」，他们以为儿女不接，其实是机占着电话。没有机的家，本年不装宽带。

**00后祖辈现在怎么提**：座机底座磨亮的那一块。底座一贴耳，才想起忙音和门缝里的嘶。

**当时广告 / 单位 / 生活版怎么说**：联想店招「为了学习」是儿女听的；电信账单按分钟。居委会不教老人怎么挂机。麻将馆口头：「谁家又占线。」

**当时家里怎么说**：奶奶：「占线！」爷爷：「电表转。」儿女：「学习用。」孙：不评忙音。

**邻居牌友和其他说法**：谁家先抬主机，楼道会跟。假内存他们不拆，只骂通不了话。未见公开争论。

**祖辈自己的一对词**：听筒要通 vs 机占着线。

**感官钩子**：忙音嘟嘟；拨号嘶；听筒线拽直；电表玻璃跳字。

**会吵什么**：先挂机让他们打电话，还是让孩子再上一会儿——挂了儿女说学习断了，不挂另一家问不到吃了没。

**和孩子 / 父母库的接口**：孩子抢键、要装游戏，详见儿童库。谁抬主机、口头禅学习，详见父母库 P-2005-02。宽带费电详见 2008。

### G-2005-03 压岁钱从折子里抽，塞进孙口袋

**时间** 2005 年除夕到正月初二｜**落在哪** 钱包｜**称谓** 奶奶 / 爷爷 / 外婆｜**谁家有** 城退：折子取现，红包塞口袋；县：一百常见，体面的到二百；乡：无折子，红布包或卖粮的票，十块二十块真给；进城帮带：人在城，包从老家布里掏；远距：托人带一包，或汇一笔让他们转给孙

**事实核**：压岁这十年从几十涨到几百。2005 年山西河津口述：村里 5 元、10 元，城里 50、100、几百（青岛新闻网 https://www.qingdaonews.com/content/2005-02/16/content_4294405.htm ）。数字加码、礼簿二百是父母库 P-2005-03；儿女收走嘀咕留给 2008。本卡换手：城的从折子抽、乡的从红布包或压箱抽，塞进孙的裤袋再按住袋口。农村多数没有折子。企业退休金月约 700，抽一百他们要数两遍。已有研究《独生子女与压岁钱》。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 65 岁。折子本本翻到取款页，或箱底红布解开，票子对着灯看。 |
| 1945 | 60 岁。塞进孙口袋，再把袋口按死，怕掉。 |
| 1950 | 55 岁。还在岗的用工资信封抽；退了的用折子。 |
| 1955 | 50 岁。未带孙。给外甥或姐的孩子塞一小包，自己还没有孙要按袋口。 |

现场：城退那家，奶奶把折子递给柜台，取一百，新票对灯，回家压进红纸，除夕夜里塞进孙的棉裤口袋，手按住袋口，说「自己拿着」，孩子要拆，她又按回去。爷爷在旁边数剩下的，本月买肉还够不够，他心里过一遍。乡留守那家没有折子，奶奶从箱底掏出红布包，里面是卖粮或卖菜留下的旧票，十块、二十块，同样塞进口袋，袋口用别针别一下；檐下若有收成，她说「今年玉米换的」。远距那家托人带一包，他们只负责把包转到孙手里，不负责礼簿上的二百。广东利是若只有五块十块，他们仍按袋口，不比城里一百。

**00后祖辈现在怎么提**：箱底红布的褪色。布一展开，才想起袋口按死、别针别过那一下。

**当时广告 / 单位 / 生活版怎么说**：银行「压岁钱存起来」；晚报写水涨船高。居委会不发红包档。供销社不卖红纸也有人用旧报纸包。

**当时家里怎么说**：奶奶：「塞口袋。」爷爷：「别拆。」儿女：「我们先收着。」孙：摸厚度。

**邻居牌友和其他说法**：谁家塞一百、谁家十块，初二就会比。假票少见，多见「少了下次记得」。谁家折子薄只塞十块，红布包一打开就被问。

**祖辈自己的一对词**：塞进口袋按死 vs 让儿女代收。

**感官钩子**：新票对灯；袋口按进掌心；红布褪色；别针凉一下。

**会吵什么**：包塞给孙自己拿，还是先交给儿女——塞了怕丢，交了他们觉得没给到人。

**和孩子 / 父母库的接口**：孩子只看见红纸厚度，详见儿童库。礼簿从一百往二百，详见父母库 P-2005-03。儿女收走详见 2008。

### G-2005-04 家长会他们去坐，回来只说没批评

**时间** 2005 年幼儿园或小学低年级家长会那天｜**落在哪** 带孙现场 / 自己的日子｜**称谓** 奶奶 / 爷爷 / 外婆｜**谁家有** 城退：他们去坐后排；县：厂扣工，老人去的更多；乡：村小或镇小，他们骑车去；进城帮带：人在城，第一次进这道门；远距：去不了，电话里只问老师怎么说

**事实核**：幼儿园家长会来的多是爷爷奶奶，和隔代带养同一条线（央视同上）。假条、扣工是父母库 P-2005-05。门口怎么站、联系本怎么签、座位表，详见带孙专篇，本年不写门口制度。本卡换手：他们坐哪、听不懂哪句、回家只会复述「没批评」。听写他们认不全拼音，只钩子一句，详见带孙专篇。企业退休金月约 700，车费和误工口述、待核。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 65 岁。坐后排或边上，眼镜够不着黑板上的拼音。 |
| 1945 | 60 岁。本子递过来，名字能写，后面那栏不敢填。 |
| 1950 | 55 岁。还在岗的请不出，让刚退的邻床去；退了的自己坐。 |
| 1955 | 50 岁。未带孙。工位还在，看见同事请半天，自己不是去坐的人。 |

现场：奶奶把布包里的通知掏出来，校门口人挤，她被让到后排或靠墙的位子，桌上没有她的名签。老师讲评语、讲配合，她只抓住一句「孩子还行」，黑板拼音她认不全，课件翻页她跟不上。散场有人围着问第几，她不问，挤到门口，骑车或走路回家，进门只说「没批评」。爷爷若去，坐得更靠边，回来同样一句。乡那家骑车到镇小，车筐里还放着菜，会散了菜叶蔫了。外出那家电话打到墙上，他们只会讲「老师没批评」，第几问不出来。

**00后祖辈现在怎么提**：布包里那张通知折痕。折痕一展开，才想起后排凳粘裤、嘴里只有「没批评」。

**当时广告 / 单位 / 生活版怎么说**：学校通知「请家长准时到」——写的是家长，来的常是老人。车间不管老人座。生活版教沟通，不教后排怎么坐。

**当时家里怎么说**：奶奶：「没批评。」爷爷：「我听不懂。」儿女：「本子呢？」老师：「下次让家长来。」

**邻居牌友和其他说法**：谁家老人去、谁家父母去，楼道会比。代签、坐错教室有，会补一顿问。谁家先退下来才坐得住后排，工号还在的请不出。

**祖辈自己的一对词**：去坐后排 vs 不去只等电话。

**感官钩子**：后排凳粘裤；黑板拼音发虚；本子油星；车筐菜叶蔫。

**会吵什么**：老人去坐，还是逼儿女请假——去了只会说没批评，不去门口空着。门口制度详见带孙专篇。

**和孩子 / 父母库的接口**：孩子只看见来的是奶奶还是妈。假条详见父母库 P-2005-05。听写、联系本、老人座展开，详见带孙专篇。

### G-2005-05 布尿布他们烫，开水糊一窗

**时间** 2005 年夜里和清早，晚 00 后仍在尿布上｜**落在哪** 带孙现场｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：纸的进了门，他们仍要烫几块布备用；县：纸布并用；乡：布为主，开水是规矩；进城帮带：客厅脸盆烫；远距：电话里只问干了没

**事实核**：纸尿裤这十年才进普通家，一包口述 30–60 元；乡下仍觉贵，布加开水烫（已有研究《衣服鞋与日化》）。雕牌、谁买单是父母库 P-2005-06。夜里谁换纸详见父母库 2008。本卡换手：洗、拧、开水烫、晾，尿骚在手上。卫生巾可点名，不另开卡。帮宝适箱盖他们少揭。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 65 岁。布片叠三角，锅里水开了才肯下。 |
| 1945 | 60 岁。拧完的水淌过脚背，窗上糊一层汽。 |
| 1950 | 55 岁。还在岗的清早烫一锅再出门；退了的整晚都是这只盆。 |
| 1955 | 50 岁。未带孙。帮姐看一晚，布按姐说的叠，自己不敢改纸。 |

现场：奶奶把湿布在脸盆里揉，尿骚贴手背，拧到布心发白，再投入开水壶倒出的水，蒸汽糊住窗户，她用筷子挑，烫手也不放。城退那家抽屉里已有一包纸，儿女夜里撕魔术贴，她仍坚持白天烫几块布，说「纸的屁股会烂」；盆沿皂沫是雕牌，颗粒沙掌心。乡留守那家没有纸箱，整晚都是布，别针在灯下咬合，开水是铁锅烧的，尿骚和柴烟混在灶间，晾绳上的布冬天硬，她用炉边烤软再叠。进城帮带的客厅，脸盆搁在帘后，烫完的汽贴到天花板。夜里谁换纸，详见父母库 2008。

**00后祖辈现在怎么提**：脸盆沿那圈皂垢。垢一涩手，才想起开水糊窗、布片烫过。

**当时广告 / 单位 / 生活版怎么说**：电视里纸尿裤「干爽一整夜」；母婴柜教魔术贴。单位不发布片。生活版教科学选用，不教开水怎么烫。

**当时家里怎么说**：奶奶：「布才透气。」外婆：「再烫一遍。」儿女：「夜里用纸。」孙：只哼，不评干潮。

**邻居牌友和其他说法**：满月酒上比谁用纸、谁用布。假粉结块、布没烫干，邻居会闻出来。未见公开争论。

**祖辈自己的一对词**：开水烫布 vs 一包纸少洗几次。

**感官钩子**：尿骚贴手背；开水白汽糊窗；别针咬合；硬布烤软的焦味。

**会吵什么**：再烫一锅布，还是让儿女买纸——烫了他们说费火，不烫他们说费钱。

**和孩子 / 父母库的接口**：孩子身上的干或潮、勒痕，详见儿童库。雕牌和纸谁买单，详见父母库 P-2005-06。夜里谁换纸，详见父母库 2008。

### G-2005-06 麻将桌子热了，开会的条还在口袋

**时间** 2005 年工作日下午｜**落在哪** 自己的日子｜**称谓** 爷爷 / 外公｜**谁家有** 城退：麻将馆和居委会抢；县：茶馆牌桌；乡：堂屋或小卖部后桌；进城帮带：人在城，牌友不熟，开会条更对不上；远距：听不见这张桌

**事实核**：麻将馆去不去 2001 已深挖过「去不去」；本年换手：同一下午，居委会或村委会把人叫去开会，牌友已经占了位子。茶钱口述几块，待核到你的馆。企业退休金月约 700，输一圈他们能算成几斤肉。1950 / 1955 有的还在岗，没有这张下午。不写任何文件名，不写社会新闻。奶奶追着喂不在本卡。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 65 岁。口袋里那张开会条揉了，牌已砌好，他仍要去坐后排。 |
| 1945 | 60 岁。外公若来城，茶馆不熟，开会条他看不懂，蹲门口抽烟。 |
| 1950 | 55 岁。刚退的才碰上这题；还在岗的下午在厂，牌和会都不是他的。 |
| 1955 | 50 岁。未带孙。工位还在。看见老同事退下来打牌，自己工号抄不上。 |

现场：爷爷把居委会或村委会那张纸条从口袋掏出来，字他认不全，日期是今天下午。牌友在楼下喊「三缺一」，桌面已热，茶钱几块搁在角上。城退那家，他先去开会，坐后排听完「领个啥、签个字」，回来位子没了，只剩茶渣；有的先打牌，开会条揉进裤袋，事后被门房点名。乡那家小卖部后桌，条是村长让小孩送来的，他摸一把牌又放下，说「去应一下」，孙在旁边玩铁罐，罐一响他咳一声，牌不打了，带孙的手把下午切开。外公算爷线：娘家那头，他骑车去镇上看女儿，牌桌不是他的，开会若是村里的，人已在城，条作废。进城帮带的客厅没有熟牌友，纸条对不上人，他宁可去门口站一会儿。

**00后祖辈现在怎么提**：口袋里揉皱的那张条。条一展开，才想起牌桌位子热了、回来只剩茶渣。

**当时广告 / 单位 / 生活版怎么说**：居委会黑板「下午两点开会」；麻将馆口头「三缺一」。单位退休科不管牌桌。生活版偶写娱乐，不写这张条。

**当时家里怎么说**：爷爷：「我应一下会。」牌友：「位子不留。」奶奶：「孙还在家。」外公：「我去镇上。」

**邻居牌友和其他说法**：谁先开会、谁先入桌，馆里会数。输了说「开会误事」，赢了不提条。谁家先退下来下午必在馆，工号还抄着的不入这桌。

**祖辈自己的一对词**：去开会应一下 vs 位子热了先打。

**感官钩子**：纸条揉皱；牌桌茶渍；后排凳响；小卖部后桌的烟。

**会吵什么**：先去开会，还是先入桌——去了位子没了，不去门房点名。

**和孩子 / 父母库的接口**：孩子只记得被带到牌桌边或门口。麻将馆去不去的旧账，详见 2001。不愿带去麻将，详见带孙专篇。

### G-2005-07 电磁炉红灯亮，他们盯电表

**时间** 2005 年零售抬头，客厅或灶边多了一台黑面板｜**落在哪** 灶上｜**称谓** 奶奶 / 爷爷｜**谁家有** 城退：新楼先有，他们怕电表；县：双职工跟，老人盯跳字；乡：少，灶上仍是煤或罐；进城帮带：走廊有时抱一台小的；远距：过年才在镇上碰见红灯

**事实核**：2005 年电磁炉零售量同比约 +55.85%（中怡康口径，http://www.bjjdwx.com/xinwen/200906/4271.html ），机身口述 200–500 元，不是 1990 年代就普及。家电下乡 2009 才把电磁炉写进补贴，本年没有乡补。儿女买来涮或热饭，详见父母库 P-2005-04。本卡换手：他们怕电表转、嫌没明火、红灯一跳就去看玻璃。一度电口述四五毛，待核。企业退休金月约 700，电费单他们要对照上月。已有研究《灶煤球油烟机》《大件电器》。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 65 岁。红灯一亮就去楼道看电表，说「这不也是钱」。 |
| 1945 | 60 岁。没有锅气她不认，热奶可以，炒菜仍开罐。 |
| 1950 | 55 岁。还在岗的不管这台；退了的周末被叫来看火，火却是灯。 |
| 1955 | 50 岁。未带孙。在自己父母桌上见红灯，还不是这台的看守。 |

现场：奶奶把黑面板按一下，红灯跳，锅底嗡嗡，她不看锅，先听楼道电表那一声嘀或看玻璃跳字。城退那家儿女周末涮白菜豆腐，蒸汽贴瓷砖，她把功率往下调，说「转这么快」，肉卷她只许薄薄一层；罐气她仍留着炒蛋，说「没明火不像做菜」。乡那家厅里没有这台，灶上仍是蜂窝煤或柴，过年才在镇上亲戚家看见红灯，她伸手试面板烫不烫，回来跟爷爷讲「用电也要钱」。进城帮带的走廊，小功率机热奶，她仍兑一口凉，水温老规矩，机只是少点一次煤。电费单月底对照，上月多了几块，她能指到那几顿红灯。

**00后祖辈现在怎么提**：电表玻璃没擦净的那一格。玻璃一跳字，才想起红灯下调功率那年。

**当时广告 / 单位 / 生活版怎么说**：美的、九阳「用电比用气省」是儿女听的；卖场堆头红灯。单位不发机。家电下乡横幅本年还没有。

**当时家里怎么说**：奶奶：「电表转。」爷爷：「没火不像菜。」儿女：「省罐。」孙：伸筷烫舌。

**邻居牌友和其他说法**：谁家客厅先涮，楼道能闻到。杂牌板裂、不认锅，会退回。未见公开争论。

**祖辈自己的一对词**：红灯热一顿 vs 电表那几格。

**感官钩子**：红灯一跳；锅底嗡；电表玻璃跳字；面板烫手又缩。

**会吵什么**：再涮一顿，还是开罐炒——涮了他们说费电，不涮儿女说机白买。

**和孩子 / 父母库的接口**：孩子抢肉、烫舌，详见儿童库。谁买机、客厅涮，详见父母库 P-2005-04。宽带费电是 2008 另一只表。
