# 2009：门槛上的座、户口本，和折子够不够随

> 这一年要写的是 00 后爷爷奶奶外公外婆自己家里过的、手里带的。1940 年生大约 69 岁；1945 年生 64 岁；1950 年生 59 岁，城的可能还在岗或刚退；1955 年生 54 岁，很多人还在上班，未带孙占格，写看别人领、帮一天。小孩的点卡小屋不写。70 后的月供、收据、出门鞋、财政所、工位只钩子一句。不写新闻。

## 这一年祖辈站在哪

- **1940 年生**：69 岁。城的折子在口袋里；乡的仍在地里或看门。年夜饭门槛、户口本排队，多是他们的手。腰腿更响，联播仍要准点看。
- **1945 年生**：64 岁。城的多已退；乡的还在田。催年夜饭在这边坐、伸手接孙，常是这一档。
- **1950 年生**：59 岁。本年主核。城的可能还在岗被少班，也可能刚退；乡的没有退休两个字，地里还种。
- **1955 年生**：54 岁。很多人还在上班。未带孙占格：看邻居领孙、工会发糖、门槛上递一回孩子。不要写成已经是奶奶。

## 这一年祖辈手里已经有的

堂屋圆桌、门槛、户口本、标识卡夹在说明书里、折子城的才有（乡多数仍没有，新农保本年才试点，不要写成人人有本）、地里收成、麻将牌、墙上座机、2006 那台点读机壳还在（当砖只点名）、门口等到天黑详见 2007、一头一脚那张床详见 2008、电视购物自己买详见 2008、脑白金收下详见 2000。月供不进他们钱包。出门鞋、电视开着人要走详见父母库。家电下乡 2007 试点，本年前后才进更多村，写购物办户口，不写工程。微信、移动支付、高铁日常化没有。报班流程详见带孙专篇。

## 本年主卡（7 张）

### G-2009-01 年夜饭必须在这边

**时间** 2009 年除夕到初一｜**落在哪** 带孙现场｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：圆桌已摆，门槛不松；县：两头催，他们守一桌；乡留守：堂屋他们办，儿女电话里吵；进城帮带：人在城、酒在哪边他们盯；远距：只听见听筒里「必须在这边」

**事实核**：四二一家里过年回男方还是女方、孩子跟哪边坐，是这十年常见场面（已有研究《独生子女与压岁钱》）。城里人情一年口述 2000–5000 元，县乡 500–2000 元；体面门常见 200–500（婚礼纪 https://www.hunliji.com/bai_ke/detail_55413 ）。本卡不写出门鞋、不写后座桔子袋，那些是父母库 P-2009-03、P-2009-06。换手：老人门槛、必须在这边坐、碗已经盛上。不写台上节目。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 69 岁。圆桌转盘他们摆正，孩子的凳他们按住。 |
| 1945 | 64 岁。电话一响就说「菜热了，过不去」。 |
| 1950 | 59 岁。还在岗的请不出整晚，仍要人坐在自己这边。 |
| 1955 | 54 岁。未带孙。帮姐守一晚门槛，自己桌上没有孙子要按。 |

现场：奶奶把孩子的碗盛满，门一响先说「坐下，别走」，门槛里那把凳已经热。婆家这套：堂屋灯亮，她把孩子按在自己右手边，听筒里外婆催「去年已经在那边了」，她只回「菜热了」；娘家这套：外婆同样把圆桌摆开，说「必须在我这边坐一顿」，门槛上两家老人让来让去，孩子只有一个座位。进城帮带的老人守的是城里这张桌，老家堂屋空着也要电话里报「人在这边」。儿女先去哪一门、鞋换不换，详见父母库，本卡停在这把椅子。

**00后祖辈现在怎么提**：门槛里那把凳腿磨亮的皮，比年夜饭照片先摸到。摸到磨亮的皮，听筒里那句过不去还在。碗沿上的油渍一刮，才想起谁按住了人。

**当时广告 / 单位 / 生活版怎么说**：超市「年货一站」不教回谁家。居委会不调解哪边坐。麻将馆口头：「年夜饭她不放人。」

**当时家里怎么说**：奶奶：「必须在这边。」外婆：「去年已经在那边了。」儿女：「我们转一趟。」爷爷：「人坐下再吵。」

**邻居牌友和其他说法**：谁家两桌都留住、谁家只守男方，初二牌桌上就比。两桌都留的说只守男方是偏心，只守男方的说两桌是把孩子当礼。

**祖辈自己的一对词**：人必须在这边坐 vs 让他们转一趟。

**感官钩子**：转盘蹭桌布；门槛风灌进袖口；听筒里两边同时催；碗沿油刮手指。

**会吵什么**：年夜饭就这一顿在婆家，还是匀给娘家——匀了奶奶说桌空，不匀外婆说明年不来。

**和孩子 / 父母库的接口**：出门鞋、后座跟哪边，详见父母库 P-2009-03、P-2009-06。孩子被两边抱，详见儿童库过年糖篮。抢带流程详见带孙专篇。

### G-2009-02 冰箱下乡，户口本在他们手里

**时间** 2009 年二月起更多村能办下乡购物｜**落在哪** 器物｜**称谓** 爷爷 / 奶奶｜**谁家有** 乡留守：本年主场，他们排队；县：农村户口才能办；城退：柜上早有冰箱，不走这套；进城帮带：户口本在老家，人在城；远距：寄钱，老人持本去镇

**事实核**：家电下乡是购物。2007 年十二月少数省试点，2009 年二月一日起更多村能办，补贴销售价百分之十三，冰箱（含冰柜）限价 2500 元（财政部 https://www.mof.gov.cn/zhengwuxinxi/zhengcejiedu/2009nianzhengcejiedu/200902/t20090223_115944.htm ）。买时出示户口本、身份证，说明书上有标识卡。农村每百户冰箱 2010 年 45.19 台，不是家家已有（《中国统计年鉴》2012 表 10-30 https://www.stats.gov.cn/sj/ndsj/2012/html/J1030e.htm ）。2009 年农村居民人均纯收入 5153 元，月约 429 元（统计年鉴 2011 表 10-20 https://www.stats.gov.cn/sj/ndsj/2011/html/J1020C.HTM ）。一台 2000–2500 元约合乡下五到六个月纯收入。财政所怎么交详见父母库 P-2009-04。本卡换手：户口本谁拿、表谁填、他们会不会写。不写工程。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 69 岁。户口本从柜里抽，户主页边已经磨毛。 |
| 1945 | 64 岁。排队，店员催填表，握笔手抖。 |
| 1950 | 59 岁。还在岗的请半天去镇；乡的自己赶集去店。 |
| 1955 | 54 岁。未带孙。帮父母或姐搬纸箱、递本，自己不是户主。 |

现场：爷爷把户口本拍在镇店柜台上，户主页翻毛，店员推过一张表，购买人、身份证号他抄错一行就重来，奶奶在旁边说「你写，我看着卡」。乡留守那家儿女人在厂，汇款单写「冰箱」，他们自己排队，标识卡夹进说明书怕丢，压缩机第一声嗡堂屋都静；进城帮带那家被儿女拉去，户口本在儿女口袋里，他们只负责按手印，补贴那一行看不懂。城里柜上早已有冰箱，不走这套。财政所复印件怎么交，详见父母库，本卡停在本和笔。

**00后祖辈现在怎么提**：户口本磨毛的边，比压缩机那一声先被摸到。摸到磨毛的边，才想起表抄错一行、标识卡夹在哪一页。纸箱绳勒过掌心的印，翻本才想起来。

**当时广告 / 单位 / 生活版怎么说**：店招「下乡产品，带户口本」；容声「容声容声，质量保证」。乡镇广播提醒带本。不是工程报道。

**当时家里怎么说**：爷爷：「表我不会填。」奶奶：「卡别丢。」儿女：「本带上。」店员：「按户口上的名写。」

**邻居牌友和其他说法**：谁家先嗡、谁家还用井水泡菜，村里会比。假标识、非中标机有，表退回过。先嗡的说井水泡菜是跟不上，井水的说先嗡是把半年收成砸进铁盒子。

**祖辈自己的一对词**：本和卡在手里 vs 表上的字写不对。

**感官钩子**：户主页磨毛；圆珠笔戳破表格；标识卡塑料边扎手；纸箱绳勒掌心。

**会吵什么**：爷爷填表，还是让识字的邻居代写——代写怕名不对，自己写怕又抄错。

**和孩子 / 父母库的接口**：孩子开关门玩，详见儿童库点名。去财政所、付全款，详见父母库 P-2009-04。

### G-2009-03 报班他们说读学校就行

**时间** 2009 年学期初看见抽屉里那叠收据｜**落在哪** 钱包｜**称谓** 奶奶 / 爷爷｜**谁家有** 城退：看见收据嫌贵；县：跟风一两张他们嘀咕；乡留守：多数没有班，只有课本；进城帮带：钱是儿女的，嘴是他们的；远距：电话里只问「交那么多干什么」

**事实核**：本年只写他们嫌贵、说学校够。一学期一份班口述常见几百到一千多元，待核到你所在街；2009 年全国城镇非私营单位在岗职工年平均工资 32736 元，月约 2728 元（国家统计局 https://www.stats.gov.cn/sj/zxfb/202303/t20230301_1919209.html ），两张收据叠起来能顶小半个月，对折子更沉。谁签字谁付钱详见父母库 P-2009-02。教室怎么走、联系本怎么签，详见带孙专篇。本卡不写报名流程。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 69 岁。把八百听成好几斤肉，说学校自己读。 |
| 1945 | 64 岁。收据往上叠，他们在门口嘀咕。 |
| 1950 | 59 岁。还在岗的觉得一学期顶自己好几天班。 |
| 1955 | 54 岁。未带孙。看姐家抽屉那一叠，自己还没轮到嘀咕。 |

现场：奶奶看见抽屉里牛皮纸袋鼓起来，复写纸紫印还在，说「学校不够读吗」，八百一千她按菜场秤。城退带孙那家儿女在前台签字，她不进辅导班玻璃门，只在家门口说「贵」，旧机壳还在柜上，她觉得书自己看就行；乡留守那家没有这本子，只有开学那一笔，听筒里儿女说报名，她说「课本自己看」，汇款单她想写成「生活」。教室、杯赛不写，详见带孙专篇。

**00后祖辈现在怎么提**：抽屉夹不住的那一叠边，比班名叫什么先被摸到。摸到那一叠边，才想起自己在门口说贵、没进玻璃门。紫印蹭到指腹，才想起那年嘴硬。

**当时广告 / 单位 / 生活版怎么说**：辅导班玻璃门「名额有限」，他们不读。居委会不发报班通知。麻将馆口头：「学校读不就行了。」

**当时家里怎么说**：奶奶：「读学校就行。」爷爷：「一学期顶肉钱。」儿女：「同学都报了。」孙：书包又鼓一截。

**邻居牌友和其他说法**：谁家老人拦、谁家老人掏，楼道会比。拦的说掏是惯，掏的说拦是不管前途。流程不写。

**祖辈自己的一对词**：学校够 vs 再交一张。

**感官钩子**：复写纸紫印；牛皮纸袋鼓起的棱；柜上旧机壳；听筒里报名两个字。

**会吵什么**：这学期拦下来，还是让儿女再交——拦了怕门口被问，不拦折子那一格空。

**和孩子 / 父母库的接口**：签字付钱详见父母库 P-2009-02。教室怎么走详见带孙专篇。孩子被送进哪间屋，详见儿童库点名。

### G-2009-04 还在岗被少班，地里还种

**时间** 2009 年车间班次表和田埂｜**落在哪** 自己的日子｜**称谓** 爷爷 / 奶奶｜**谁家有** 城：1950 / 1955 还在岗，少班或调包装；县：集体厂少开；乡：没有工位，地里还种；进城帮带：人已退或请假进城，本卡少；远距：机在厂里响，地在老家

**事实核**：只写老人自己的班还在不在、地还种不种。不写宏观标题。儿女工位、调令小黑板详见父母库 P-2009-05。企业人均退休金 2010 年月均约 1300（劳动统计年鉴口径，中国日报 http://www.chinadaily.com.cn/dfpd/2010qglianghui/2010-03/04/content_9534487.htm ），本年折子口述略低于后来那档，待核；农村多数没有折子，新农保本年试点，多数村仍没有本。少班不是放假，是这个月菜钱紧。1955 未带孙写帮一天。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 69 岁。城的多已退，看儿女少班；乡的仍出工。 |
| 1945 | 64 岁。城的已退带孙；乡的田还在自己手里。 |
| 1950 | 59 岁。主场。城的少班或刚退；乡的地里还种。 |
| 1955 | 54 岁。未带孙。工位还在。自己工号抄不上带孙那一行，中午只把邻床的孩子送到门口。 |

现场：爷爷把工牌翻过来看，班次表上自己的名被水笔划淡，少开一天少一格菜钱。城还在岗那家，1950 年生提早回家看孙，又怕工位没了，奶奶说「你先留着班」，他把孙送到刚退的邻床再踩点；乡没有工位两个字，锄头和孙在田埂抢，麦苗还要浇，孩子放田头篮里，薅完一行再看一眼。1955 年生工号抄不上，中午送回，自己赶晚班，只说「看一下」。儿女车间那块小黑板，详见父母库，本卡停在老人自己的牌和锄。

**00后祖辈现在怎么提**：工牌绳磨亮的那一段，或锄把磨滑的皮。摸到磨亮的绳，才想起名被划淡那几天。退休证第一页若后来才盖，盖章前的班还在手上。

**当时广告 / 单位 / 生活版怎么说**：车间黑板「本周少开」；打卡口「无条按旷工」。居委会不管老人还种不种。单位不解释孙子谁带。

**当时家里怎么说**：爷爷：「我这周少班。」奶奶：「地还得种。」儿女：「工位先留着。」工头：「名单下午看。」

**邻居牌友和其他说法**：谁先退下来带、谁还在岗把孙塞给邻床，楼道会比。未见公开争论。

**祖辈自己的一对词**：班还留着 vs 地还不能荒。

**感官钩子**：水笔划名的一道；工牌铁夹的凉；田头篮里的土；锄把磨滑的皮。

**会吵什么**：少班也留着工位，还是回地里整天带——留了怕下个月还少，回了城的折子薄。

**和孩子 / 父母库的接口**：儿女工位还在不在，详见父母库 P-2009-05。孩子被放篮、被送邻床，详见儿童库。

### G-2009-05 孩子跟哪边坐，他们先伸手

**时间** 2009 年腊月二十到初五，车或摩托停在门槛｜**落在哪** 带孙现场｜**称谓** 奶奶 / 外婆｜**谁家有** 城退：台阶上先伸手；县：两道门槛抢抱；乡：男方堂屋先接，女方要争；进城帮带：城里这道门他们守；远距：听筒里问接到没有

**事实核**：父母库 P-2009-06 写出门、后座、桔子袋、谁抱下车。本卡换手：老人站在门槛伸手、往里带、往自己这边的凳上按。年夜饭必须在这边坐详见 G-2009-01，本卡只写手这一下。红包数字详见父母库，不写出门鞋。已有研究《独生子女与压岁钱》。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 69 岁。台阶上站稳，手先出，人后问。 |
| 1945 | 64 岁。外套还没脱，孩子已在自己胳膊弯里。 |
| 1950 | 59 岁。还在岗的赶到门槛才伸手，晚一步就被另一家接走。 |
| 1955 | 54 岁。未带孙。看姐家两边老人同时伸手，自己帮着递外套。 |

现场：车或摩托刚停，奶奶已经站在台阶上，不问先去哪家，手先伸出去，孩子外套拉链还没拉，人已被接到胳膊弯里，往里带，往自己这边的凳上按。婆家这套：门槛风灌袖口，她把人按住，说「先坐热」；娘家这套：外婆在另一道门槛同样伸手，编织袋里还有桔子，说「跟我坐」。进城帮带守的是城里这道门，老家门槛空着也要听筒里报「接到了」。后座怎么睡、先去哪一门，详见父母库，本卡停在这双手。

**00后祖辈现在怎么提**：台阶上那块磨凹的砖，比车里桔子袋先被踩到。踩到磨凹的砖，才想起手先出、人后问。袖口灌过的风，站回原处才有。

**当时广告 / 单位 / 生活版怎么说**：超市年货不教谁先抱。居委会不站门槛。麻将馆口头：「谁先伸手谁留住。」

**当时家里怎么说**：奶奶：「先到我这边。」外婆：「跟我坐。」儿女：「别当孩子面抢。」孙：外套还挂在一只袖子上。

**邻居牌友和其他说法**：谁家门槛先热、谁家只接到一半，初二就传。未见公开争论。

**祖辈自己的一对词**：手先伸出去 vs 让他们自己抱进来。

**感官钩子**：台阶砖磨凹；袖口灌风；拉链卡在一半；编织袋口的桔子皮。

**会吵什么**：进门先跟奶奶坐，还是先跟外婆坐——孩子只有一双手，两边同时够。

**和孩子 / 父母库的接口**：出门、后座、先去哪一门，详见父母库 P-2009-06。年夜饭这把椅子详见 G-2009-01。孩子认不认人，详见儿童库。

### G-2009-06 折子加一笔，够不够随

**时间** 2009 年婚丧、满月、升学酒前后｜**落在哪** 钱包｜**称谓** 爷爷 / 奶奶｜**谁家有** 城退：从折子抽一笔加码；县：一百加到二百他们数；乡留守：多数无折子，随收成或卖猪的钱；进城帮带：折子在老家，人在城托人带；远距：汇一封，礼簿别人写

**事实核**：份子从折子里抽深挖在 2007（总表点名），本年换手：加一笔够不够随。红包这十年从五十、一百涨到二百、五百量级（婚礼纪 https://www.hunliji.com/bai_ke/detail_55413 ；已有研究《酒席红包与体面》）。企业人均退休金 2010 年月均约 1300，本年口述略低，待核。新农保 2009 年试点，不要写成全国农村已经人人有折子；多数村仍没有本，随的是粮食、卖猪或儿女寄回的一笔。月供不进他们钱包。儿女出门随礼详见父母库 P-2009-03。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 69 岁。折子翻到余额，加一笔到二百还是五百，他们先数。 |
| 1945 | 64 岁。礼簿「某某 二百」是他们写，还是让儿女写，要争。 |
| 1950 | 59 岁。还在岗的从工钱里抽；乡的从粮袋里量。 |
| 1955 | 54 岁。未带孙。帮父母封一回，自己还不是主随的人。 |

现场：爷爷把折子摊在灶沿，圆珠笔把余额描深，份子要从一百加到二百，体面门要五百，他问奶奶「这个月肉还买不买」。城退那家从折子抽一叠新票，封好写名，说「少了不像话」，本月买肉那一格空；乡留守那家多数仍没有折子，新农保本年才试点，多数村还没有本，奶奶用粮袋或卖猪的钱折成五十、一百，礼簿让识字的人写。进城帮带的托人带一封，听筒里只问「写上了没有」。2007 怎么抽只点名，本年停在加一笔够不够。

**00后祖辈现在怎么提**：折子余额被描深的那一行，或粮袋口扎绳的结。摸到扎绳的结，才想起哪一袋粮食少了一截。礼簿墨水洇开的格，比红包皮先在。

**当时广告 / 单位 / 生活版怎么说**：银行柜面「新钞换红包」；生活版「人情涨了」。居委会不发份子标准。麻将馆口头：「这个数拿得出手。」

**当时家里怎么说**：爷爷：「加一笔紧。」奶奶：「少了不像话。」儿女：「我们出一部分。」牌友：「谁家随了五百。」

**邻居牌友和其他说法**：谁家加了、谁家还一百，酒桌上就比。假钞、破钞会被退回。未见公开争论。

**祖辈自己的一对词**：加一笔才像话 vs 余额那一行空。

**感官钩子**：折子纸发潮；新钞的涩；粮袋口的麻绳；礼簿墨未干。

**会吵什么**：随二百还是随五百——少了门槛上难看，多了这个月肉停。

**和孩子 / 父母库的接口**：儿女出门随的礼、电视开着人要走，详见父母库 P-2009-03。孩子收的压岁详见 2008 点名。

### G-2009-07 so easy 他们听不懂

**时间** 2009 年晚饭电视广告加码｜**落在哪** 器物｜**称谓** 爷爷 / 奶奶｜**谁家有** 城退：旧机还在，新广告砸耳朵；县：广告先到，机后来；乡：客厅有声，手里常没有；进城帮带：纸箱托运回去他们拆；远距：只听见听筒里「开关在哪」

**事实核**：步步高点读机约 2006 年已有 T100 一类，他们当砖详见总表 2006，本年不重写压菜谱、当砖全过程。高君雨「哪里不会点哪里，so easy」那版广告更熟的是本年（维基 https://zh.wikipedia.org/zh-hans/高君雨 ；行业回顾 https://www.dnzp.com/jy/202310/231018.html ）。主流机口述 500–800 元，高的到 1000–1500 元（已有研究《点读机复读机》）。2009 年平均月工资约 2728 元，一台 800 约合十天工钱，对折子更沉。他们听不懂英文，把 so easy 咬成「搜一搜」「什么易」。按着点、好不好使详见带孙专篇与父母育儿。旧机还买不买详见父母库 P-2009-07。平板不属这十年。

**00后祖辈当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1940 | 69 岁。广告里的音咬不准，问「她说啥」。 |
| 1945 | 64 岁。摸旧壳说还不是那块，新词听不成句。 |
| 1950 | 59 岁。还在岗的觉得八百顶好几天班，仍听不懂那句。 |
| 1955 | 54 岁。未带孙。帮姐把旧机充上电，英文自己也不念。 |

现场：晚饭油烟还在，女孩的声音进灶间，爷爷把音量拧低又拧高，问「so 是啥」，奶奶说「什么易，听不清」。城退带孙那家柜上 2006 那台旧壳还在，当砖只点名，本年不写怎么压、怎么当，只写他们摸壳听广告，英文咬不成句，儿女要再买，他们说「书自己读」；乡留守那家客厅天天响同一句，手里没有机，他们把英文当热闹，听筒里儿女问开关在哪，他们找电池仓找不着。拆箱不会装，详见父母库那头，本卡停在耳朵。

**00后祖辈现在怎么提**：旧壳键上的灰，比广告词先摸得着。摸到键上的灰，才想起自己把那句咬成搜一搜。笔线缠成疙瘩的那一截，翻出来才有音。

**当时广告 / 单位 / 生活版怎么说**：「哪里不会点哪里，so easy」「妈妈再也不用担心我的学习」。电器城堆头。单位不发点读机。生活版有报价，不教老人怎么听。

**当时家里怎么说**：爷爷：「她说啥。」奶奶：「书自己读不行吗。」儿女：「新款教材多。」营业员：「旧的加点钱。」

**邻居牌友和其他说法**：谁家换了第二台，谁家还用旧壳，家长会门口老人也听一句。假笔点了没声。未见公开争论。功效不写。

**祖辈自己的一对词**：那句英文听不成 vs 旧壳还在柜上。

**感官钩子**：广告童声压过油烟；旧键上的灰；电池仓盖涩；英文音咬不准。

**会吵什么**：再花八百换新的，还是旧壳将就——广告在耳朵里，折子和报班在抽屉里。

**和孩子 / 父母库的接口**：旧机还买不买、谁开票，详见父母库 P-2009-07。当砖全过程详见 2006 点名。按着点详见带孙专篇。儿童库 C-2006-05 只点名。

## 本年不写

阅兵、甲流、躲猫猫、口罩接送。出门鞋、电视开着人要走不重写（父母库 P-2009-03）。财政所交卡不重写现场（父母库 P-2009-04）。工位小黑板不重写（父母库 P-2009-05）。后座桔子袋不重写（父母库 P-2009-06）。点读机当砖全过程不重写（2006）。家电下乡当工程、当政策解说不写。新农保不写成全国农村人人有折子。微信、触屏全班、移动支付、高铁日常化没有。世博不写。报班教室、杯赛流程不展开。
