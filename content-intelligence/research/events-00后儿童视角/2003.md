# 2003：哪吒、光和幼儿园的小椅子

> 这一年 2000 年生大约 3 岁，幼儿园小班前后；2003 年生出生。下午《哪吒传奇》能把遥控钉住。奥特曼的光和盘已经在家里转，皮带留给摊上的塑料。智慧树要到年底才开。营养快线还在研发，嘴里日常仍是钙奶和豆浆。留守的孩子等的是电话，不是车票新闻。

## 这一年孩子站在哪

- **2000 年生**：约 3 岁。会要看哪吒、会藏光棒、会在小椅子上睡不着。开始有「班上有人有」。
- **2003 年生**：0 岁。摇篮、奶、被举高。哪吒和皮带是后来哥哥的课间。
- **2006 年生**：未出生。
- **2009 年生**：未出生。

## 这一年童年里已经有的

哪吒传奇（本年六一首播）、奥特曼影碟 / 神光棒 / 摊货「皮带」、幼儿园小椅子午睡豆浆、盗版动画碟摊、芭比及换装衣（正版贵、摊货多）、智慧树 12 月底开播、大风车 / 动画城（详见 2000）、天线宝宝幼幼回声（详见 2002）、蓝猫继续（详见 2000）、猫和老鼠重播（详见 2001）、干脆面三国 / 西游卡回声（详见 2001，不写水浒当 00 后主卡）、AD 钙奶 / 旺仔（详见 2001 / 2000）、QQ 糖 / 绿舌头（详见 2002）、跳皮筋沙包还在（详见 2002）、营养快线尚未大规模进柜（2004 上市，详见待核）、IC 卡 / 电话亭、花园宝宝不要写进本年。

## 本年童年代表（8 件）

### C-2003-01 哪吒传奇

**时间** 2003-06-01 起在央视一套《大风车》首播｜**落在哪** 眼睛｜**谁家有** 城：一套傍晚能守到；县：能收一套就热；乡：堂屋公共电视；留守：跟着看，自己喊「哪吒」

**事实核**：央视青少中心动画片部制作，52 集，陈家奇、蔡志军执导。2003-06-01 六一在央视一套《大风车》播第一集《哪吒出世》，当时报道称吸引大批儿童守到约 18 点。后在动画城等栏目续播。主题曲、混天绫、风火轮、莲花是小孩抓住的物件，不是封神论文。出处：维基 https://zh.wikipedia.org/zh-cn/哪吒传奇 ；人民网 / 江南时报 2003-06-02 http://ent.sina.com.cn/v/2003-06-02/1531152653.html 。喜羊羊未开播，禁止提前。

**00后当时怎么玩/吃/看**：

| 出生年 | 当时 |
|--------|------|
| 2000 | 守点、学哪吒喊、要红绫一样的红布。怕石矶，不怕剧情解释。 |
| 2003 | 出生。当时是奶和哭，哪吒是后来相册外被哥哥安上的。 |
| 2006 | 未出生。 |
| 2009 | 未出生。 |

再写一层：2003-06-01 一套大风车开播。3 岁要哪吒、怕龙王，跟着吼。2000 年生约 3 岁，能跟上动作，讲不清封神。城里守点；乡下碰上或靠碟。周边进柜月待核。女孩也可站龙女一边。不要写成 2000 年就有。作业换台只钩子，详见考试专篇。

还要一层：片头一响就蹲到电视前，遥控器在谁手里，这一集能不能看完。

**00后现在怎么提**：事后记忆。短视频把哪吒和 2019、2025 电影混成一条。2003 年现场是电视里的莲花小孩，不是院线。城里有人买到周边剑；乡下更多是自己找根红绳当混天绫。

**当时广告和少儿节目怎么说**：大风车报幕；片头哪吒出世。文具店随后出现哪吒贴画，具体哪一月进二线**待核**。广告缝里仍是钙奶和果冻。

**当时大人怎么说**：妈：「国产的，能看。」爸：「别学打。」奶奶：「哪吒闹海我知道。」老师：「回家别迟到，哪吒会等你」——有的小班用它当哄。

**同学和其他说法**：班上比谁会唱主题曲。未见禁播。后来有人嫌画风「土」，那是事后口味，不是 3 岁的话。

**小孩自己的一对词**：守到哪吒 vs 被换成新闻预告。

**感官钩子**：片头鼓点；红绫；莲花座的粉；晚饭锅铲和主题曲抢。

**会吵什么**：看哪吒还是放奥特曼碟——一台电视，3 岁要莲花，哥哥要光。

**和考试的接口**：无。

### C-2003-02 奥特曼的光、棒和盘

**时间** 2002 影碟已铺垫，2003 年 3 岁开始要自己的「光」｜**落在哪** 手 / 眼睛｜**谁家有** 城：玩具摊神光棒、人偶、卡；县：同样有，正版少；乡：碟比玩具先到；留守：堂哥带回一只断头人偶

**事实核**：迪迦等平成奥特曼在大陆以影碟、地方台、盗版盘传播。迪迦变身器在片中是神光棒（スパークレンス），举手发光，**不是 2008 铠甲勇士那种皮带召唤器**。小孩和摊主把发光棒、塑料腰带、电池盒统称「奥特曼」「变身」「皮带」，本年深挖的是这套口语和摊货，不写成万代正版皮带年（正版皮带节点**待核**）。光：电池、红灯、会响。盘：一部碟循环一个暑假。价格口述、待核：摊货棒几元到十几元，人偶几元，正版贵数倍。铠甲勇士 2008 才热，禁止提前。出处：迪迦设定见维基 https://zh.wikipedia.org/zh-cn/超人迪迦 ；碟摊生态见已有研究《物质文化与日常》。

**00后当时怎么玩/吃/看**：

| 出生年 | 当时 |
|--------|------|
| 2000 | 举棒、学姿势、要换电池。盘比剧情熟。皮带若有，是松紧带配塑料盒。 |
| 2003 | 出生。光是刺眼，不是收藏。 |
| 2006 | 未出生。 |
| 2009 | 未出生。 |

再写一层：光、棒、盘，课间对打，电池没了就手势。3 岁要亮，6 岁才要比全套。摊货灯暗。乡下看碟学姿势。不同于 2008 铠甲腰带工业。女孩也可以拿棒，常被说是男的。一套几十到过百，口述、待核。老师抽屉开始收这些。

**00后现在怎么提**：事后记忆。容易和铠甲勇士皮带、赛罗眼镜混年。2003 年现场是光棒和花碟，不是专柜。城里谁有会亮的，谁只有纸人；乡下常是看碟不会买棒。

**当时广告和少儿节目怎么说**：少儿栏目不一定播正片，家里靠碟。摊位海报手写「奥特曼」。电池广告比正版授权先到。

**当时大人怎么说**：妈：「吵。」爸：「又费电池。」奶奶：「怪物吓人。」老师：「不准带去幼儿园。」

**同学和其他说法**：真假看会不会亮。老师抽屉里的没收盒从光棒开始满。未见全国禁播奥特曼幼儿节目的童年现场，只有家规。

**小孩自己的一对词**：会亮 vs 不会亮。

**感官钩子**：红灯；劣质喇叭；碟片虹光；松紧带勒肚。

**会吵什么**：买会亮的还是买人偶——零花只够一样，3 岁要亮。

**和考试的接口**：无。

### C-2003-03 幼儿园：小椅子、午睡、豆浆

**时间** 2003 年城市小班 / 乡镇学前班陆续把 2000 年生收进去｜**落在哪** 小孩的日子 / 脚与院子｜**谁家有** 城：幼儿园小床、统一水杯；县：学前班、折叠椅；乡：村小附幼或没有；留守：跟着奶奶，或寄在镇上学前班

**事实核**：这不是开播年，是 00 后第一次「自己的座位」。小椅子写名字、午睡毛巾、豆浆或牛奶、表演时的花裙子。入园年龄各地不同，**不是全国 3 岁一刀切，待核本城**。豆浆是嘴里的日常，不写配方粉事件。表演只写假笑和花，六一深挖留给 2005，本年只作钩子。不写停课、口罩当主卡。

**00后当时怎么玩/吃/看**：

| 出生年 | 当时 |
|--------|------|
| 2000 | 认自己的椅子、午睡装睡、豆浆甜才喝。表演时被人摆手。 |
| 2003 | 出生，不上学。 |
| 2006 | 未出生。 |
| 2009 | 未出生。 |

现场：小椅子写名字，午睡毛巾盖脸，豆浆有皮就不喝。表演时被人摆手，假笑留给 2005 六一，本年只作钩子。入园年龄各地不同，不是全国 3 岁一刀切。没上过园的是空白。不写停课、口罩。园里开始问「会不会数」，一句，详见考试专篇。

再写一层：小椅子写名字，午睡毛巾盖脸，豆浆有皮就不喝。入园年龄各地不同。没上过园是空白。不写停课口罩。园里问会不会数，一句，详见考试专篇。城里统一床；乡镇桌子拼。假笑留给 2005 六一。3 岁被摆手，不是自己选节目。

**00后现在怎么提**：事后记忆。短视频爱用「小椅子排队」。城里是统一床；乡镇是桌子拼、毛巾盖脸。没上过园的 00 后，这段是空白，不是「全民幼儿园」。

**当时广告和少儿节目怎么说**：园门口海报「双语」「艺术」——3 岁只看见卡通字。少儿节目里的幼儿园比真的干净。

**当时大人怎么说**：妈：「听话，午睡。」老师：「眼睛闭起来。」奶奶：「园里能学东西。」园厨：「豆浆喝完。」

**同学和其他说法**：谁带的是卡通水杯，谁是不锈钢缸。尿床是秘密。未见公开争论。小班还没有红领巾。

**小孩自己的一对词**：装睡 vs 真睡着。

**感官钩子**：消毒液；小床塑料布；豆浆皮；椅子腿刮地。

**会吵什么**：午睡必须躺——想看窗外的树，被老师走过来挡。

**和考试的接口**：园里开始问「会不会数、会不会背」——一句，详见考试专篇。

### C-2003-04 盗版动画碟摊

**时间** 2003 年暑假，摊比电视台更肯循环｜**落在哪** 眼睛 / 手｜**谁家有** 城：电脑城、桥洞、周末市；县：电影院门口、书店旁；乡：赶集一筐；留守：少，或托人带两张

**事实核**：一张碟几元到十元（口述、待核），一部看一个暑假：哪吒、奥特曼、蓝猫、不知名日本片、两部拼一盘。封套错字、音画不同步、播到一半广告。2008 年若回声，只能写「循环片」，不重复摊史。正版贵，家庭道德是「小孩看的，买盗版」。出处：已有研究《物质文化与日常》盗版条。不写扫黄打非新闻。

**00后当时怎么玩/吃/看**：

| 出生年 | 当时 |
|--------|------|
| 2000 | 选封套最亮的、回家循环到封套磨白。不管第几集。 |
| 2003 | 出生。碟是光，不是选择。 |
| 2006 | 未出生。 |
| 2009 | 未出生。 |

现场：选封套最亮的，一部看一个暑假，封套磨白。哪吒、奥特曼、蓝猫、两部拼一盘，音画不同步也循环。几元到十元。2008 年若回声，只写循环片，不重复摊史。没摊的乡靠堂屋电视碰运气。不写扫黄打非。3 岁看颜色，不看版权。

再写一层：选最亮的封套，一部看一个暑假。哪吒、奥特曼、蓝猫拼一盘，音画不同步也循环。几元到十元。2008 若回声只写循环片。没摊的乡靠堂屋电视。不写扫黄打非。3 岁看颜色。网盘不要前移。

还要一层：塑料袋一热就粘手，封套上的字被摸到认不出来，仍要再看一遍。

**00后现在怎么提**：事后记忆。有人把网盘前移。2003 年现场是摊、塑料袋、手写价。没摊的乡，是堂屋电视碰运气。

**当时广告和少儿节目怎么说**：摊主喊「全新」「合集」；封套盗用哪吒、奥特曼脸。电视正播哪吒，摊上已经在卖「全集」。

**当时大人怎么说**：妈：「买两张够了。」爸：「别买黄的。」奶奶：「看不清。」摊主：「小孩能看。」

**同学和其他说法**：谁家碟多，谁家下午开放。马赛克和错集是共同语言。未见小孩讨论版权。

**小孩自己的一对词**：摊上那张 vs 电视等到的那集。

**感官钩子**：塑料袋热；油墨；仓门吐碟；同一句配音暑假听臭。

**会吵什么**：买哪吒还是买奥特曼——只准一张，3 岁看封套颜色。

**和考试的接口**：无。

### C-2003-05 芭比和换装

**时间** 2003 年前后美泰加力中国渠道，正版进商场，摊货早已满街｜**落在哪** 手｜**谁家有** 城：商场柜、谁有正版一眼能看；县：批发市场「芭芘」；乡：便宜塑料娃娃；留守：几乎没有，或表姐留下一个断腿

**事实核**：芭比不是 2003 年才发明。2002 年前后美泰在华设公司、商超专柜；2003-05 有六一网上专卖、限量款的报道。正版贵，盗版批发价可差数倍。3 岁女孩真正上手的是换鞋子、梳不动的头发、贴纸换装本（成套「魔力贴」书更晚，约十年后才常见，**本年以娃娃和散装贴纸为主，书标待核**）。出处：2003 年易趣六一首拍报道见《声屏世界》2003 年第 10 期转述；盗版价差见后来行业回顾，不作 2003 精确民调。男孩线是奥特曼，本卡是女孩线。

**00后当时怎么玩/吃/看**：

| 出生年 | 当时 |
|--------|------|
| 2000 | 脱鞋、戴发、把裙子反过来穿。贴纸贴在娃娃脸上也贴在自己手上。 |
| 2003 | 出生。娃娃是别人手里的粉。 |
| 2006 | 未出生。 |
| 2009 | 未出生。 |

再写一层：换裙子、梳不开的头发、鞋丢一只。正版贵，摊货关节硬。贴纸本更便宜，本年可和娃一起写。乡下自制纸娃。男孩也有偷偷换的。3 岁要粉，不管品牌年。价格口述、待核：娃几十到过百，贴纸几元。不要写成 1990 年代才有的唯一记忆。

**00后现在怎么提**：事后记忆。短视频把正版柜写成全民。城里中产可能有一只正版；多数是摊货「芭芘」，关节硬、头发粘。没娃娃的女孩用纸人换装。

**当时广告和少儿节目怎么说**：商场柜粉红灯光；广告里娃娃会眨眼。少儿节目较少教换装，同伴教。

**当时大人怎么说**：妈：「太贵。」爸：「玩物。」奶奶：「针别扎手。」阿姨：「女孩都有。」

**同学和其他说法**：正版鞋能脱，盗版鞋是模子。谁有「会眨眼的」，谁只有硬塑料。未见公开争论。男孩碰一下会被笑，也有女孩用奥特曼衣服给娃娃穿——两套玩法。

**小孩自己的一对词**：能换鞋 vs 鞋是粘死的。

**感官钩子**：塑料发丝；关节咔；贴纸胶；粉红包装的刺鼻。

**会吵什么**：买娃娃还是买换装衣——大人只出一份钱，3 岁要能脱的鞋。

**和考试的接口**：无。

### C-2003-06 早餐罐子：钙奶还在，营养快线还没进柜

**时间** 2003 年研发营养快线，2004 年才正式上市｜**落在哪** 嘴｜**谁家有** 城：早餐仍是豆浆油条 / AD 钙奶 / 利乐奶；县：钙奶塑料瓶；乡：粥、馒头、偶见钙奶；留守：奶奶煮粥，罐子少

**事实核**：娃哈哈营养快线 2003 年研发，**2004 年上市**，「早餐喝一瓶，精神一上午」广告主打在 2005 年。本年 3 岁嘴里的日常罐子仍是 AD 钙奶、旺仔、豆浆，不是快线。总表把营养快线放在 2003 深挖，故写清「还没进多数小卖部」，避免提前一年写成人手一瓶。出处：中国经济网 http://www.ce.cn/cysc/sp/info/201407/18/t20140718_3186884.shtml ；已有研究《奶与早餐罐子》。2007 年只点名回声。

**00后当时怎么玩/吃/看**：

| 出生年 | 当时 |
|--------|------|
| 2000 | 要甜罐子，拒绝白奶。豆浆有皮就不喝。快线还不是选项。 |
| 2003 | 出生。奶瓶和勺。 |
| 2006 | 未出生。 |
| 2009 | 未出生。 |

现场：3 岁要甜罐子，拒绝白奶。豆浆皮、吸管漏、旺仔铁腥是回声。营养快线 2003 年研发、**2004 年才上市**，「早餐喝一瓶」主打在 2005。本年柜台上多数还没有快线，不要写成人手一瓶。乡下仍是粥和冲奶粉。总表放在 2003 深挖，故写清「还没进多数小卖部」。

### C-2003-08 给爸妈打电话：IC 卡和电话亭

**时间** 2000–2008 留守通话的主力年，2003 年 3 岁已能被抱到话筒前｜**落在哪** 小孩的日子｜**谁家有** 乡留守：村口小卖部 / 学校门口 IC 亭；县打工家庭：201 卡；城：少，是另一套；对照：城里同龄在打学步车，不在排队打电话

**事实核**：手机未普及前，IC 插卡、200 / 201 预付密码是常用办法，201 校园卡有折扣说法。国内长途口述约每分钟 0.80 元，20 元卡打不了多久，分几次。2003 年 2000 年生 3 岁：被奶奶抱着，喊「爸」「妈」，听得见电流。不是春运新闻，是等电话和打完卡。2006 年只胶囊回声，不重复深挖。出处：已有研究《留守与春运》；201 电话公开介绍 https://baike.baidu.com/item/201电话/2994249 。不写春运绿皮车专章。

**00后当时怎么玩/吃/看**：

| 出生年 | 当时 |
|--------|------|
| 2000 | 攥卡、听嘟声、不会说「想」，只会应「听话」。卡打完就哭。 |
| 2003 | 出生。电话是别人的事。 |
| 2006 | 未出生。 |
| 2009 | 未出生。 |

**00后现在怎么提**：事后记忆。短视频爱拍「红电话亭」。有的村是小卖部柜上那部机，不是亭。城里 00 后没有这条线，不要写成全民。2006 年后小灵通 / 手机渐多，IC 才淡。

**当时广告和少儿节目怎么说**：电信「亲情卡」一类广告；少儿节目很少出现这部电话。现场广告是亭上褪色的「IC」。

**当时大人怎么说**：奶奶：「去给你爸打。」爸（话筒）：「听话。」妈：「想没想妈。」小卖部：「卡没钱了。」

**同学和其他说法**：谁家有座机，谁还在亭里排队。未见小孩的公开争论。后来有人把这段写成「懂事」，3 岁现场只是冷和嘟声。

**小孩自己的一对词**：还能再说一句 vs 卡没了。

**感官钩子**：卡插入咔嗒；电流；呵气；塑料听筒的腥。

**会吵什么**：再打一次还是省下来买本子——20 元是很久的零花，3 岁没有票权，只有哭。

**和考试的接口**：电话里开始问「在园听不听话」——一句，详见考试专篇。
