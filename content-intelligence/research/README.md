写 2021–2026 主卡前，先打开 [`events-00后2021-2026-校准/00-索引.md`](events-00后2021-2026-校准/00-索引.md)，再打开该年总表。一次只写一年、三本一起。不要把校准段落搬进现场。2011–2020 三本默认不再扩写。

写新卡时走 skill，不要直接改提示词当成品：

- 2021–2026 三本：`events-00hou-2021-2026`（一次一年，少年 / 父母 / 祖辈一起写）
- 2011–2020 三本：`events-00hou-2011-2020`（一次一年；成品默认不改）
- 2000–2010 父母：`events-00hou-parents`（禁微信 / 外卖 / 移动支付的铁律只用于旧库）
- 2000–2010 祖辈：`events-00hou-grandparents`
