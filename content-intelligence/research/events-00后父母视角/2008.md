# 2008：宽带绿灯、薄信封和自己的床

> 这一年要写的是 00 后爸妈自己家里过的、班上干的。1975 年生大约 33 岁，存折和工位叠在同一笔；1970 年生 38 岁，班上已经有工位；1980 年生 28 岁，晚 00 后刚有或未育；1985 年生 23 岁，部分刚结婚、刚有晚 00 后，未育仍占格。小孩的小屋和谁家绿灯只钩子一句。不写新闻。

## 这一年父母站在哪

- **1970 年生**：38 岁。单位或柜台工位已稳。孩子多已小学。钱包先对宽带月费、压岁钱、信封厚薄。
- **1975 年生**：33 岁。本年主核。装线、收红包、夜里换尿布、孩子有没有自己的床，多从这一年叠上。
- **1980 年生**：28 岁。厂、柜台、科室。已育的多是晚 00 后还小；未育的还不是这张卡的付款人。
- **1985 年生**：23 岁。刚进厂或刚结婚。部分刚有晚 00 后，未育仍占格，还不是多数主卡的付款人。

## 这一年父母家里和班上已经有的

ADSL 猫、门缝进的线、绿灯、拨号嘶嘶只作对照（那是 2000 年的）、电脑「为了学习」回声（详见 2005、2007）、信封比往年薄、班上更晚走、盒饭、压岁钱收走或给存、存折、夜里谁换、布尿布谁洗（堆头只点名）、菜场仍买菜、工位刷新菜地、同事请客那顿、孩子和老人一张床或自己的小床、摩尔点卡十块、文具店门口一片黄（喜羊羊只点名）、改菜谱回声（详见 2007）、月供若已进门详见 2004。家电下乡扩面不是全乡换冰箱（详见 2009）。进口罐若换，只当家里账。不写新闻。

## 本年主卡

### P-2008-01 宽带装了，说是为了学习

**时间** 2008 年城市家庭 ADSL 更常见，仍不是家家有｜**落在哪** 家里器物｜**谁家有** 城：分层，有的绿灯有的还去别人家；县：晚、慢；乡：少；外出：厂里能上网，老家多数还没有

**事实核**：拨号嘶嘶是 2000 年前后的现场，本年写宽带。ADSL 2003 年后进城，2005 年前后城市用户超过拨号，2008 年仍分层，不是家家都有（已有研究《第一台电脑与诺基亚》）。城镇每百户电脑 2005 年 41.52、2009 年 65.74，不是人人一台。儿童库写谁家猫绿灯、谁还去别人家看，详见 C-2008-07；本卡写谁办、月费谁掏、口头禅「为了学习」。月费各地差大：一线城 1M 口述常见百元出头到一百五，强县包年折月可能几十到一百，初装 / 调测另算，待核到你所在电信或网通柜台（北京网通 1M 包月曾见 150 元档口述，http://www.myprice.com.cn/internet/2006/0925/56818.shtml ）。2008 年城镇单位在岗职工年平均工资 29229 元，月约 2436，日均 111.99 元（https://www.stats.gov.cn/sj/zxfb/202303/t20230301_1919501.html ）。月费 120 约合一天出头正式日工资，是固定扣，不是一次性。乡下 2010 年电脑才约 10 台/百户，本年多数还没有这根线。

**00后父母当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1970 | 38 岁。有的已经办过，知道月费从哪一笔扣。 |
| 1975 | 33 岁。装维从门缝进线，妈说学习，爸看账单。 |
| 1980 | 28 岁。已育的为了「以后上学」；未育的为自己办，或还去网吧。 |
| 1985 | 23 岁。多数用单位或网吧。刚有晚 00 后的，线还不一定进门。 |

现场：装维把细线从门缝塞进来，猫的灯先红后绿，妈签字的单子写着包月，口头禅是「给孩子学习」，不是给自己挂机。城双职工有的家绿灯已经亮了一年，有的本年才办，月费和菜钱、份子同一本账。拨号那阵嘶嘶占线是前几年的事，本年有宽带的家电话可以同时打。密码贴在主机侧面，爸说「学习用完就拔」，猫还是绿着。线从门缝进的那天，楼道能看见那根细的。另一套是乡下和外出：多数没有这根线，孩子要看只能去镇上有机的亲戚家；厂里能摸到单位电脑，老家墙上仍是座机，绿灯不在自己屋里。

**00后父母现在怎么提**：门缝里那根细线还在，猫的灯先红后绿。月费从菜钱里扣，「为了学习」四个字谁先说出口还记得。2008 年城里仍分层，乡下多数没有这根线，厂里能摸到机，绿灯不在自己屋里。包月单的复写纸还夹在抽屉，楼道看得见那根细的。

**当时广告 / 单位 / 生活版怎么说**：电信 / 网通营业厅「宽带上网，助力学习」；小区广告「ADSL 包月」。单位不管家里那根线。生活版教防病毒，不教装到哪一层楼。

**当时家里怎么说**：妈：「装了好学习。」爸：「每个月都要交。」爷爷：「电话费又多一笔。」装维：「线从门缝进就行。」

**同事邻居和其他说法**：谁家绿灯，谁家孩子还去别人家换拖鞋，楼道会传。假套餐、被扣错月费有，去营业厅吵。未见公开争论。

**父母自己的一对词**：为了学习先装 vs 月费先缓缓。

**感官钩子**：门缝里那根细线；猫灯红转绿；包月单的复写纸；主机侧面的密码条。

**会吵什么**：这个月办 1M，还是再去网吧——月费是固定扣，网吧是零花，两头都从同一张工资里出。

**和孩子 / 育儿的接口**：谁家绿灯、谁还去别人家看，详见儿童库 C-2008-07。小屋玩法不写。作业写完才能上，详见育儿专篇。

### P-2008-02 信封薄了，班上更晚走

**时间** 2008 年下半年到腊月，车间、科室、柜台｜**落在哪** 自己班上｜**谁家有** 城：年终那封薄了，夜班多了；县：集体厂少发、晚走；乡：本来就没有厚信封；外出：工钱点在手上，盒子当饭

**事实核**：只写加班、少发、盒饭。单位过年还发不发油和鱼，2000 年已写过；信封没了另找活详见 2002。本年写同一只信封更薄、人更晚走、食堂盒子更常见。2008 年月均约 2436 元，日均 111.99 元，这是全国城镇单位口径，私营厂、临时工、计件往往更薄，禁止编成统一数。年终奖口述从一两个月工资瘦到半个月或一张感谢信，待核到你所在单位。夜班窗口、盒饭几元到十元，详见 2007 另一角度，本年写「更常吃盒子」。不写四个字的宏观标题，不写裁员文件名。

**00后父母当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1970 | 38 岁。知道自己单位是「还发一点」还是「只剩条」。 |
| 1975 | 33 岁。信封瘦了，班点拉长，回家更晚。 |
| 1980 | 28 岁。临时工、计件先薄。已育的怕盒子当晚饭。 |
| 1985 | 23 岁。学徒或新合同，信封本来就薄。未育的只养自己。 |

现场：财务室门口排队，牛皮纸比往年透字，里面工资条加几张票子，年终那一截有的只剩半个月，有的改成购物券，有的口头「今年先这样」。打卡机晚上还在啪，组长说再留一会，食堂窗口十点后只剩盒子，米饭边硬，菜是炒蛋。城双职工两个人都晚走，孩子已经跟老人睡了。爸把薄信封压在柜子底层，妈数完说「红包还是得随」。不是第一年加班，是本年盒子更常见、人更晚散。另一套是乡下和外出：本来没有这套信封，赶集卖的钱更紧；工头把工钱点在手上，没有「单位」两个字，钱要寄回给宽带和老家，自己吃袋面。

**00后父母现在怎么提**：牛皮纸比往年透字，柜子底层那封摸得出薄。孩子睡了人还没进门，窗口十点后只剩盒子，米饭边硬。乡下很多人从来没有厚信封，赶集的钱更紧；临时工领不到的那一行，工资条上少了，比大词先在手里。

**当时广告 / 单位 / 生活版怎么说**：工会通知「年货按人头，带袋子」——袋子有时空；食堂「夜班窗口照常」。生活版教省钱菜谱。车间小黑板加班名单比往年密。

**当时家里怎么说**：爸：「今年这封薄。」妈：「盒子当饭也行。」奶奶：「人回来就好。」组长：「再留一小时。」

**同事邻居和其他说法**：铁路、机关还被说成「有点」；私营厂、摊位「没有这套」。假券、缺斤的油有，当场翻。未见公开争论。

**父母自己的一对词**：还在发 vs 今年只剩条和盒子。

**感官钩子**：牛皮纸透字；打卡机夜里还啪；盒子边的硬饭；柜子底层那封的薄。

**会吵什么**：薄了的那一截先交月费还是先随份子——两头都在腊月，盒子决定灶上还缺不缺。

**和孩子 / 育儿的接口**：孩子看不见信封，只看见人更晚进门。接送对不上详见 2007。无。

### P-2008-03 压岁钱收走还是给存

**时间** 2008 年春节前后｜**落在哪** 家里钱包｜**谁家有** 城：红包被收进存折；县：收走一大部分，留十块；乡：现金少、糖多；外出：电话里说寄了，手里没有

**事实核**：儿童库 C-2006-06 是孩子侧：抽屉空了、烟花棒。本卡写父母怎么收、怎么存、存折写谁的名。城里压岁钱这十年从 50–100 涨到 200–500，乡下 10–50，广东利是常只 5–10，口述、待核（已有研究《独生子女与压岁钱》；2005 年河津口述见 https://www.qingdaonews.com/content/2005-02/16/content_4294405.htm ）。2008 年月均约 2436 元，一个 200 的包约合两天不到正式日工资。银行柜面有「压岁钱存折」广告，不是政策年。不写捐款，不写任何公共事件标题。亲戚间城里仍是换钱，乡下仍是真给。

**00后父母当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1970 | 38 岁。孩子已经会数，收的手法更熟。 |
| 1975 | 33 岁。妈说先帮你存，存折进抽屉。 |
| 1980 | 28 岁。已育的晚 00 后刚会抓红包；未育的给侄子外甥，自己不收。 |
| 1985 | 23 岁。多数还在给弟弟妹妹的孩子。刚有晚 00 后的，红包薄，仍收。 |

现场：孩子把红包数完塞进抽屉，妈等他睡了把信封抽走，票子理齐，第二天去银行开一本薄存折，户名有的写孩子，印鉴在大人手里。城双职工这边给 200、那边还 200，等于没给，存折上的数字是「保管」。爸说「太危险，炮不行」，那是烟花，钱的事是妈先开口。存折夹进工资条旁边，利息几乎看不见，两边老人给的包先汇到同一本；妈把零头留下买棒，整票进柜。抽屉第二天还在，信封是空的，存折回单夹进工资袋。另一套是乡下和外出：红包本来薄，桌上更多是糖；电话里说「给你寄了」，钱到老人手上，孩子手里没有纸，只有忙音。

**00后父母现在怎么提**：抽屉里空信封还在，印鉴盒是凉的，存折封面有一点红。城里这边给 200、那边还 200，存折上是「保管」；外出电话里说寄了，钱到老人手上，孩子手里没有纸，只有忙音。印鉴在谁口袋，比存折广告先想起来。回单夹进工资袋。

**当时广告 / 单位 / 生活版怎么说**：银行「压岁钱存起来，给孩子一个未来」；柜面小礼品。单位不管压岁钱。生活版教「怎么跟孩子谈钱」，不教捐。

**当时家里怎么说**：妈：「我帮你存着。」爸：「留十块就行。」奶奶：「给孩子点零花。」银行柜员：「开一本小孩的。」

**同事邻居和其他说法**：谁家能留下零头，过年就会比。假存折、把钱挪去随份子的有，家里吵。未见公开争论。

**父母自己的一对词**：先帮你收着 vs 留在他自己抽屉。

**感官钩子**：空信封还在；存折封面的红；印鉴盒的凉；电话里的忙音。

**会吵什么**：全部进存折，还是留十块——留了怕乱花，收光了孩子会翻抽屉，外出那家连抽屉都没有。

**和孩子 / 育儿的接口**：抽屉空了、烟花棒烫鞋，详见儿童库 C-2006-06。不写捐款。无报班。

### P-2008-04 夜里谁换，布尿布谁洗

**时间** 2008 年夜里换、白天洗｜**落在哪** 带娃现场 / 家里钱包｜**谁家有** 城：双职工纸尿裤，夜里谁下床；乡：布尿布奶奶洗；外出：父母不在场，电话里问洗了没

**事实核**：2005 是雕牌 / 纸尿裤进门（详见 P-2005-06），本年换手：夜里谁起、布谁洗。纸尿裤一包口述 30–60 元；布尿布加雕牌 1.5 元档洗衣粉，开水烫、绳上晾。2008 年月均约 2436 元，一包 50 约合大半天正式日工资，晚 00 后家里的硬支出；1970 / 1975 孩子已到小学的，夜里不再换，最多帮弟弟家看一眼。超市堆头可以路过一句，主场是盆和布。不写抵制，不写店名新闻。生鲜仍多在菜场。已有研究《衣服鞋与日化》。

**00后父母当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1970 | 38 岁。自己孩子多已不用尿布，夜里若帮弟弟家看一下，知道该谁起。 |
| 1975 | 33 岁。有的还有幼的，夜里轮流撕纸；没有幼的，洗的是侄子那块布。 |
| 1980 | 28 岁。晚 00 后才把夜里谁换变成班次；未育的只听见隔壁哭。 |
| 1985 | 23 岁。刚有晚 00 后的，自己下床撕魔术贴；未育的帮工友看一眼，不洗那盆。 |

现场：灯啪一声，城双职工抢的是谁先下床。妈把纸尿裤从床下纸箱抽出，魔术贴一撕，湿的团进桶，干爽一层贴上，手还带着睡意。爸说明早有早班，妈说你上周已经连着三夜没起——一包 50 出头，能用两周，堆头路过能看见，买完就回到这张床。小学那家夜里不换，桶是空的。另一套是乡下和外出：脸盆里泡着布片，雕牌颗粒沙手，奶奶在灯下叠成三角，别针咬合，开水烫过的蒸汽糊窗户；晾衣绳上湿布沉甸甸，风干一层皂膜。父母在厂里，电话问「洗了没、夜里谁起」，听筒里是水声，人不在场。布洗得动就继续洗，纸的托人捎一包，尺码错了只能将就。

**00后父母现在怎么提**：脸盆沿上还结着皂膜，魔术贴撕开那一声，或晾衣绳上湿布沉甸甸的。城里记得夜里谁先下床换纸，床下纸箱还在；乡下和外出记得奶奶洗布、雕牌泡着。超市堆头只是路过，主场是盆和绳，开水烫过的汽也还在。

**当时广告 / 单位 / 生活版怎么说**：电视里纸尿裤「干爽一夜」；雕牌仍在打。超市堆头「本周特价」路过一句。单位不发尿布。生活版教换尿布步骤，不教你夜里谁起。

**当时家里怎么说**：妈：「你去换。」爸：「我明天早班。」奶奶：「布我来洗。」促销员：「这包能用两周。」

**同事邻居和其他说法**：谁家夜里爸起、谁家全是奶奶洗布，满月后还会问。纸的漏、布的勒，会换一包或加一块。未见公开争论。

**父母自己的一对词**：夜里撕纸 vs 白天洗布。

**感官钩子**：魔术贴一撕；盆沿皂膜；晾衣绳上湿布沉；开水烫布的汽。

**会吵什么**：再买一包纸的，还是夜里起来洗布——城双职工争谁下床，乡下和外出争的是老人洗不洗得动。

**和孩子 / 育儿的接口**：纸尿裤在身上是孩子的，详见儿童库不展开。2005 日化进门详见 P-2005-06。无报班。

### P-2008-05 工位偷菜，同事请客

**时间** 2008 年入冬起，科室和有电脑的工位｜**落在哪** 自己班上｜**谁家有** 城：有外网的科室先刷新；县：网管机、财务机；乡：少；外出：网吧或宿舍，不是自己的工位

**事实核**：本年入冬工位上才开始有人刷新菜地，不是全年、不是人人。开心网当工位打发：到点点一下、隔座喊「熟了」，下班有人请客吃盒饭或馆子。不写平台年表、不上线月、不写用户数。本城科室何时进浏览器，待核。2008 年月均约 2436 元，馆子一顿口述二三十，盒子几元，请客往往是薄信封之后的那顿热的。单位电脑谁有权用详见 2006，本年写工位上那几分钟。孩子接手菜园最多钩子一句，不写小屋玩法。不写互联网史。

**00后父母当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1970 | 38 岁。有的科室有机，刷新两下就关。 |
| 1975 | 33 岁。隔座一喊，下班有人说我请。 |
| 1980 | 28 岁。年轻人先会点。未育的晚上还能多留一会。 |
| 1985 | 23 岁。工位上刷新最勤，号还写在自己工资条背面。 |

现场：浏览器缩在角落，到点刷新，隔座有人低声「熟了」，鼠标点两下，领导走过就切到表格。不是人人有机，财务室、有外网的科室先有，车间多数没有这页。下班有人拍肩膀「今晚我请」，馆子一顿二三十，或窗口多打一份盒子——请客的人信封不一定厚，请的是热的那一顿。城双职工回家晚，孩子已经睡了，菜园还挂在工位。孩子若伸手要「那个菜园」，号写在工资条背面塞给他。爸的手在工位，妈的手在灶上。另一套是外出：在网吧或宿舍点，不是自己的单位机，请客那顿更常是盒子。

**00后父母现在怎么提**：浏览器缩在角落，隔座那一声「熟了」还在，鼠标连点过两下，领导走过就切表格。2008 年入冬，有外网的工位才开始刷新；车间从来没有这页。请客那顿盒子是热的，薄信封还在抽屉里，号写在工资条背面。馆子也有过热气。

**当时广告 / 单位 / 生活版怎么说**：单位口头「工作时间不要开无关网页」；网管贴条。生活版后来才教「别上瘾」，本年多数还是同事之间的玩笑。食堂不管菜园。

**当时家里怎么说**：爸：「工位上点两下。」妈：「回来吃饭。」同事：「熟了，我请。」网管：「别占线。」

**同事邻居和其他说法**：谁请了客、谁只刷新不掏钱，科室会笑。号被改密码有，当场急。未见公开争论。

**父母自己的一对词**：工位打发 vs 下班那顿请不请。

**感官钩子**：角落里的浏览器；隔座低声；鼠标连点；馆子热气或盒子边。

**会吵什么**：下班请一顿热的，还是省下来交月费——请的人面子在，薄信封还在抽屉里。

**和孩子 / 育儿的接口**：孩子接手菜园最多钩子一句，不写玩法。摩尔小屋详见儿童库 C-2008-01。无报班。

### P-2008-06 孩子有没有自己的床

**时间** 2008 年日常睡觉，搬家前的那张床｜**落在哪** 家里房与路｜**谁家有** 城：两居有的有自己房间；县：有床无房，客厅隔一下；乡：和父母或老人一张床；外出：和奶奶一张床

**事实核**：城里双职工 90 平两居，孩子有的有自己房间；县城 60 平两居，孩子和父母一床到上学，或客厅沙发、布帘隔一下；乡和父母 / 老人一床到十几岁；留守和奶奶一床（已有研究《商品房月供装修》）。2005 年城镇人均住房建筑面积约 27 平米，农村自建房面积数字更大，质量不同。上海等地年轻夫妻仍有高比例与父母同住，城里也不等于人人分房。小床、高低床、婴儿床口述几百到一两千，待核到你所在家具店。2008 年月均约 2436 元，一张小床 800 约合十天出头工资。2010 搬家、回迁、城中村可回声，本年只写睡在哪。月供第一次进门详见 2004，加码详见 2009。

**00后父母当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1970 | 38 岁。孩子已小学，有的开始争自己的床。 |
| 1975 | 33 岁。两居还是一床，布帘是不是房间。 |
| 1980 | 28 岁。晚 00 后还在婴儿床或大床边；未育的和老人挤。 |
| 1985 | 23 岁。刚结婚的多半还在老人房。刚有晚 00 后的，孩子还没有自己的床。 |

现场：晚上关灯，城两居有的把次卧给孩子，门能关上，防盗网外面是楼道灯；更多是一张大床睡三个，或客厅用布帘隔出一张小床，帘一拉算分床，不算分房。家具店高低床广告喊「给孩子独立空间」，一张小床和宽带、份子抢。1985 刚结婚的，自己还没有一间，更谈不上给孩子。爷爷说「我们那辈一屋几个」，妈说「大了得有自己的」。2010 若搬家，这张床会不会跟着走，本年先问有没有。另一套是乡下和外出：炕或木床，和父母、奶奶同一被窝，脚伸到别人小腿上；留下的孩子和奶奶一头一脚，电话里问「盖严了没」。自建房再大，也常是一床。

**00后父母现在怎么提**：客厅那道布帘一拉沙沙响，算分床，不算分房。城里有的次卧能关门，防盗网外是楼道灯；乡下炕上和奶奶一头一脚，脚伸到别人小腿，电话里问盖严了没。自建房再大，也常是一床，不是儿童房装修。小床栏杆凉过手。

**当时广告 / 单位 / 生活版怎么说**：家具店「给孩子一个独立空间」；育儿版「分床睡」。售楼处沙盘是另一笔，详见月供年。单位不分床。

**当时家里怎么说**：妈：「大了得有自己的床。」爸：「先住下再说。」爷爷：「一屋睡几个也过了。」家具店：「高低床省地方。」

**同事邻居和其他说法**：谁家次卧给孩子，谁家客厅隔帘，串门就看出来。假实木、掉漆床有。未见公开争论。

**父母自己的一对词**：关得上门 vs 和老人一张床。

**感官钩子**：布帘沙沙；大床中间的体温；小床栏杆的凉；楼道灯从防盗网进来。

**会吵什么**：花 800 买小床隔客厅，还是再挤一年——隔了仍不是房间，不隔孩子脚还在大人腿上。2010 搬家可回声。

**和孩子 / 育儿的接口**：孩子要关门的房间，是感觉不是方案。无报班。回迁和城中村详见 2010。

### P-2008-07 摩尔点卡十块给不给

**时间** 2008 年起校门口开始有点卡｜**落在哪** 家里钱包｜**谁家有** 城：有宽带才用得上卡；县：卡有、网慢；乡：少；外出：寄十块，管不住买的是卡还是糖

**事实核**：小屋、换衣服、农场玩法详见儿童库 C-2008-01，本卡只写十块给不给。点卡口述常见十元档，校门口摊、小卖部进货，待核到你所在校门口何时开始喊。2008 年月均约 2436 元，十块是正式日工资的一小时出头，对孩子是一周零花。有宽带才进得去，没线的家给了卡也转圈。喜羊羊 2008 才满街，父母卡只点名：文具店门口一片黄，不写剧情，不写开播史。赛尔号未到。4399 零花详见 2007，本年换手：给的是点卡不是网吧小时费。不写福娃。

**00后父母当时怎么过**：

| 出生年 | 当时 |
|--------|------|
| 1970 | 38 岁。孩子会要点卡，给不给从宽带月费旁边挤。 |
| 1975 | 33 岁。十块从钱包里抽，问卡还是冰棍。 |
| 1980 | 28 岁。晚 00 后还小，要的是黄的那一摊；未育的不经手。 |
| 1985 | 23 岁。最多给弟弟妹妹的孩子塞一张十块，自己不进小屋。 |

现场：校门口摊主喊「摩尔卡」，银层刮开的粉不在父母手上——父母只听见「十块」。妈从钱包抽出一张，边角软，问「给卡还是给冰棍，只能一样」。城有绿灯的家，十块能换一张进小屋的密码，爸说「虚的」，还是给了，因为同学都有号；没宽带的家给了卡也进不去，钱更可能换成文具店门口那一片黄里的笔或拖鞋。文具店门口一片黄，摊上先看见拖鞋和笔，卡在旁边另成一叠。另一套是乡下和外出：多数没有摊，十块仍是糖；把十块打到老人手上，管不住买的是卡还是黄书包。

**00后父母现在怎么提**：点卡封套银层未刮，父母只看见十块，边角软了。有绿灯的家换一张密码；没线的家给了也转圈，人已经不在。乡下很多人只见过文具店门口那一片黄，没见过卡。十块给不给，比小屋先在钱包里。摊主喊过进货了。

**当时广告 / 单位 / 生活版怎么说**：摊主「进货了」；点卡封套。文具店门口一片黄，店员喊「今年最火」。单位不管点卡。少儿节目不教充值。

**当时家里怎么说**：妈：「又买卡。」爸：「虚的。」奶奶：「买双拖鞋不好吗。」摊主：「十块一张。」

**同事邻居和其他说法**：谁家给卡，谁家只给黄的那一摊，家长会门口会比。假卡、刮花的银层有，整周进不去。未见公开争论。

**父母自己的一对词**：十块给卡 vs 只给门口那一片黄里的笔。

**感官钩子**：十块边角软；封套银层（父母只看见未刮的）；文具店门口的黄；小卖部进货纸箱。

**会吵什么**：这十块给点卡还是给文具店那一片黄里的拖鞋——给了卡怕虚，不给怕在班上没号。

**和孩子 / 育儿的接口**：小屋、刮银层、换装，详见儿童库 C-2008-01。喜羊羊书包拖鞋详见 C-2008-04，本年父母只点名门口一片黄。作业写完才能上，详见育儿专篇。
