# 社会性格类型 · AI 丰富提示词

> **这是一份提示词文件，不是成品人设库。**
> 上面先把社会里常见的性格底色收成一张总表；下面每段提示词单独喂给 AI，让它把这种性格写厚。
>
> **和已有文件的分工**
> - `70后80后世代画像-AI分步描述提示词.md`：写的是人生位置（父母、丁克、离异、剩男剩女）
> - `00后爷爷奶奶-2000至2010-AI分步描述提示词.md`：写的是祖辈位置（带孙、留守、严管、宠溺）
> - **本文件**：写的是性格底色。同一种家庭位置、亲戚位置、邻里位置可以叠不同性格。
>
> **使用规则**
> 1. 先从总表选类型，再复制对应提示词，一次只喂一种性格。
> 2. 四个维度互不掺杂：底色 / 内外两张脸 / 事件习惯 / 命运形状。
> 3. 落到具体人时只补：世代、年龄、城市/县城/农村、家庭位置、关系位置（儿媳、舅舅、邻居、同学、旧情人）。
> 4. **不要用职业当性格。** 禁止按医生、教师、中介、司机、班主任、包工头拆形象。饭局、单位只是场合，不是人。
> 5. 性格不是骂人，也不是诊断。禁止写成病名、鸡汤、网暴标签。每个人都要有自己的道理。
> 6. 输出语言：中文。物件、口头禅、渠道按你指定的年代写；没指定就按 2015–2026 的当代社会写。

## 一、先看总表：社会里这些人，到底是什么性格

社会上的人看起来千奇百怪，写的时候不要从「好人/坏人」切，要从八条轴切：

| 轴 | 问的是 | 常见走法 |
|----|--------|----------|
| 对人 | 别人靠近时，他先保护谁 | 讨好 · 控制 · 回避 · 越界热心 · 精致利己 · 谁都不得罪 |
| 对面子 | 被看见时，他怕什么 | 要面子 · 显摆 · 藏拙 · 势利 |
| 对利益 | 资源来了，他怎么伸手 | 精算 · 吃亏忍让 · 老油条推责 · 卷 · 躺 |
| 对自我 | 没人盯着时，他跟自己怎么过 | 内耗 · 巨婴 · 牺牲当债 · 淡 · 社恐 · 社牛 · 杠 · 吃瓜 |
| 对感情 | 亲密来了，他抓住什么 | 玻璃心 · 恋爱脑 · 备胎 · 慕强 · 卖惨 |
| 对道德 | 他用什么当通行证 | 道德绑架 · 两面派 · 双重标准 · 护短 · 记仇 |
| 对阶层 | 他觉得自己该在哪一层 | 新富不安 · 破落怀旧 · 怨气怀才 · 认命 · 狠人 · 通吃关系 |
| 对做事 | 他把努力做成了什么 | 表演努力 · 完美洁癖 · 专业清高 · 市侩滑头 |

44 种性格不是 44 种人。一个人通常是「主性格 + 1 个影子性格」。主性格决定他平时怎么活，影子性格决定他破防时露出什么。1–24 是第一批，25–44 是第二批，专补感情、面具、阶层和做事气质。

**叠加配方（写人物时用）**

```
人物 = 世代位置 + 家庭/关系位置 + 主性格 + 影子性格
例：70后儿媳 + 讨好型 + 内耗
例：县城席上要体面的那一个 + 显摆型 + 要面子
例：农村舅舅 + 要面子型 + 老好人
```

同一种性格落在不同关系位置，味道不一样。讨好型长兄是「什么都自己扛」；讨好型儿媳是「夹着嗓子说话」。不要写成同一张脸。不要写成某种职业的脸。

## 三、通用「丰富性格」总提示词（可套任何类型）

把总表里的一行，或你自己观察来的一个人，填进大括号后发给 AI。

```
你是一位人物性格画像师。请把下面这种社会性格写厚，写成一个能直接进小说或人物小传的性格档案。不要写成点评，要写成一个人。

【性格类型】{从总表选，或自拟}
【临时人物】{姓名 / 可空}
【社会位置】{世代 + 家庭角色 + 关系位置，可空。不要填职业}
【城市层级】{一线 / 新一线 / 地级市 / 县城 / 乡镇农村，可空}
【时间锚定】{默认 2015–2026}
【已知要点】
{贴总表里的「一句话本质 / 表面像 / 骨子里 / 最怕」，或你自己的观察}

请按下面 11 栏输出，每栏写实，不要空话：

1. 性格关键词：3-5 个，每个 1-2 句。
2. 一句话本质：像墓志铭，但先别写命运。
3. 想要 / 需要 / 缺陷：各一句。想要是他嘴上要的，需要是他真正缺的，缺陷是卡住前两样的那块石头。
4. 对外人设 vs 对内真相：各一段。别人开会/饭桌上看到的，和他关上门对自己说的，必须打架。
5. 核心心理冲突：只留一对，写清楚两边各有什么好处。
6. 语言习惯：他常说的 6-8 句口头禅或句式；他绝对不说的 3 句；他生气时语言怎么变。
7. 破防触发器：3 个具体场面。每个场面写他身体先怎么动，嘴上先怎么圆。
8. 展示事件：6-8 条，分「关键事件」和「日常习惯」。每条 2-4 句，只展示不评判，末尾用半句点出暴露了什么。
9. 化学反应：任选总表里另外 2 种性格，写他们碰到一起时，第一周和三个月后各会发生什么。
10. 性格墓志铭：一句。
11. 命运底色：一句，只写「这种性格最容易把人带去哪儿」，不要编完整生平。

约束：
- 必须有自我合理化：他做这些事，在他自己看来是对的。
- 必须有时代物：微信群、饭局、物业群、班级群、亲戚席、红包、朋友圈，选符合他家庭/邻里位置的，不要堆。不要用职业定义他是谁。
- 不要写成「全坏」或「全惨」，给他一个真正的优点，这个优点也要能伤人。
- 输出语言：中文。
```

# 轴 A · 对人的方式

# 人物 1 · 讨好型（林晚）

**位置锚**：家里排老二的女儿或儿媳，谁的脸色都要看。32 岁左右。不要写成某种职业。

### ① 性格底色

```
你是一位人物性格画像师。请专门描述【讨好型】的性格底色。只写心理层，不写日常清单，不写命运。

【性格类型】讨好型
【临时人物】林晚
【已知画像要点】
- 别人一皱眉，她先检查自己是不是做错了
- 会提前把别人的需要猜完，再把自己的需要藏起来
- 拒绝别人比被拒绝更难受
- 表面好说话，心里记每一笔没说出口的委屈
- 最怕关系里突然冷下来，冷下来她会加倍殷勤

要求：
1. 先给 3-5 个性格关键词，每个配 1-2 句；
2. 指出这种性格在当代社会里的典型性，以及林晚这种人的独特性；
3. 只留一对核心冲突（如「用顺从换安全 vs 越顺从越看不见自己」）；
4. 写清她对上级、对家人、对关系一般的朋友，分别卡在哪一层；
5. 末尾写一句性格墓志铭。

输出语言：中文。
```

### ② 内外两张脸与说话方式

```
你是一位人物性格画像师。请专门写【讨好型·林晚】的内外两张脸和说话方式。只写这一维度。

【已知画像要点】
- 外面是懂事，里面是恐慌
- 口头禅多是软的、垫的、先认错的
- 真正生气时不是爆发，是把自己缩得更小

要求：
1. 对外人设一段，对内真相一段，两段必须打架；
2. 列出她常说的 6-8 句话，和绝对不说的 3 句；
3. 写她在微信里、饭桌上、被当众批评时，三套不同的话术；
4. 点出她哪一句话其实是请求，听的人却当成客气；
5. 末尾用一句话概括：别人以为她好说话，她自己以为自己在干什么。

输出语言：中文。
```

### ③ 事件 / 习惯

```
你是一位人物性格画像师。请为【讨好型·林晚】设计反映性格的事件与习惯。只展示，不评判命运。

要求：
1. 输出 6-10 个事件/习惯，每个 2-4 句；
```

## 五、怎么把性格叠到具体人身上

写小说、写小红书人物、写头条故事时，不要只丢一个类型名。按这格填完，再去喂第三节的总提示词或第四节对应人物：

```
【性格类型】主性格 + 影子性格
【世代位置】60后 / 70后 / 80后 / 90后 / 00后
【关系位置】儿媳 / 长兄 / 舅舅 / 邻居 / 同学 / 旧情人 / 家族和事佬
【城市层级】一线 / 新一线 / 地级市 / 县城 / 乡镇农村
【时间锚定】2000–2010 / 2015–2026 / 其他
【已知观察】你见过的 3 条具体细节（比类型名重要）
```

可直接叠到已有画像上，例如：

- 70 后权威传统型母亲 + 牺牲筹码型 + 要面子
- 00 后祖辈进城帮带奶奶 + 热心越界型 + 老实吃亏
- 80 后鸡血妈妈 + 卷王 + 精神内耗
- 县城席上要体面的那一个 + 要面子型 + 推责老油条
- 90 后把恋爱当天气的人 + 恋爱脑型 + 玻璃心
- 钱突然来了的人 + 新富不安型 + 显摆
- 从前风光的叔叔 + 破落怀旧型 + 认命安分
- 街坊里什么都吃得开的那一个 + 市侩滑头型 + 关系通吃

已有世代文件管「他站在哪一代、什么位置」；本文件管「他用什么性格活在这个位置上」。两套一起用，人物才不像标签。

## 六、喂给 AI 的最短操作

1. 从总表选定 1 个主性格，必要时再选 1 个影子性格。
2. 复制该人物的 ①，等输出完再发 ②③④，一次一个维度。
3. 若只要一份完整档案、不等分步：复制第三节「通用丰富性格总提示词」，把总表那一行贴进去。
4. 产出不满意时，不要换类型，先补 3 条你亲眼见过的细节再重跑 ③。
5. 写进故事前，再问一句：这个优点会怎么伤人？伤人的那一面写出来，性格才立得住。
6. 不要按职业拆人、不要让 AI 输出「医生性格」「中介性格」。人落在儿媳、舅舅、邻居、同学上，不落在工牌上。
