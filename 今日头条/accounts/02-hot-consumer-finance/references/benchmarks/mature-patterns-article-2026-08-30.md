# Mature Patterns - 今日头条 普通人财经 / 消费趋势

- Platform: 今日头条
- Direction: 普通人财经 / 消费趋势
- Valid basis: 30 public article signals
- Hard rule: no investment advice, no return promises, no unsupported financial rumors, no copied data framing or author identity.

## Direction Rules

1. 现金流先行：标题和开篇尽量连接工资、存款、债务、刚性支出、消费信心。
2. 数据口径要清楚：居民存款、贷款、消费、人均数据都要写明来源等级和时间范围。
3. 事实/解释/判断分开：不要把单一数字直接推成宏大结论。
4. 不给买卖建议：房产、股票、基金、理财、保险只能写风险框架和决策变量。

## Reusable Article Structure

- Headline: 反常识数字或生活现象 + 普通人疑问。
- Opening: 解释这个数字为什么和普通家庭有关。
- Section 1: 先把事实口径讲清楚。
- Section 2: 拆原因：收入预期、债务、刚性支出、风险储备、消费习惯。
- Section 3: 写普通家庭会怎么调整，不替读者做投资决定。
- Section 4: 给反例或限制条件，避免单边情绪。
- Ending: 引导读者讨论自己的消费变化或家庭现金流压力。

## Strong Patterns

- data anomaly explainer: 异常数字 -> 口径澄清 -> 钱的流向 -> 普通人影响。
- household cashflow explainer: 房贷/教育/医疗 -> 可支配收入 -> 消费选择。
- phenomenon list: 4-5 个可见现象 -> 原因 -> 自我对照。
- authority-backed explainer: 权威来源 -> 普通话翻译 -> 本文判断边界。
- policy execution guide: 政策变化 -> 谁适用 -> 怎么确认 -> 风险提醒。
- consumption mindset explainer: 生活场景 -> 消费标准变化 -> 渠道变化 -> 评论问题。

## Reject

- 未注明口径的宏观数字。
- 鼓励买卖、加杠杆或抄底。
- 用恐慌语言替代解释。
- 把个别家庭故事写成普遍规律。
