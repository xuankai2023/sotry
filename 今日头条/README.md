# 今日头条内容库

这个文件夹用于记录今日头条账号的长期内容资产，重点沉淀选题角度、论证结构、标题测试和发布复盘。

## 文件结构

- `accounts/`: 5 个今日头条账号方向，每个方向都有独立记录。
- `account-bible.md`: 账号定位、文章领域、观点边界、写作风格。
- `topic-bank.md`: 选题池、热点角度和文章状态。
- `content-calendar.md`: 发布排期和内容进度。
- `articles/`: 已写或待发布的文章。
- `reviews/`: 发布后的数据复盘和改进记录。
- `assets/`: 资料、截图、数据来源、参考链接说明。

## 命名建议

文章草稿放在 `articles/`:

```text
YYYY-MM-DD-选题关键词.md
```

复盘放在 `reviews/`:

```text
YYYY-MM-DD-选题关键词-review.md
```

## 账号矩阵

- `accounts/01-hot-ai-tech/`: 热门方向，AI 科技解读。
- `accounts/02-hot-consumer-finance/`: 热门方向，普通人财经 / 消费趋势。
- `accounts/03-hot-career-education/`: 热门方向，职场与教育深度。
- `accounts/04-cold-rural-economy/`: 冷门蓝海，三农 / 县域经济。
- `accounts/05-cold-silver-digital/`: 冷门蓝海，银发数字生活 / 养老政策。
