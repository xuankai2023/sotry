## Direction Learnings

- Strong hooks: “小户型也能”“一个柜子多装一倍”“有娃/有宠家庭别这样装”“这类智能家居不是智商税”。
- Useful structures: 痛点场景 -> 原因拆解 -> 低成本改法 -> 适用家庭 -> 不适合情况；空间位置 -> 常见错误 -> 改造清单 -> 图片卡片顺序。
- Visual packaging: 封面要出现具体空间，如厨房、玄关、卧室、宠物区；卡片用前后对比、尺寸、动线箭头和清单。
- Risk boundary: 不夸大产品效果，不制造家庭焦虑，不使用虚假前后对比，图片只做参考不直接复用。

## Skill Update Candidates

- Add benchmark rule: 每篇家居内容必须明确“适用户型/家庭成员/预算级别/施工难度”。
- Add title pattern: “空间 + 人群 + 一个具体收益”，例如“小厨房多收纳一倍”“有猫家庭这样留清洁动线”。
- Add image rule: 引用外部家居图时只能做结构分析，发布图必须自有、授权或生成。
