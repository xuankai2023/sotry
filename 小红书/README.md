# 小红书内容库

这个文件夹用于记录小红书账号的长期内容资产，写作前先看 `account-bible.md`、`topic-bank.md` 和 `content-calendar.md`，写作后把成稿和复盘补回来。

## 文件结构

- `accounts/`: 5 个小红书账号方向，每个方向都有独立记录。
- `account-bible.md`: 账号定位、人设、栏目、风格、禁区。
- `topic-bank.md`: 选题池和选题状态。
- `content-calendar.md`: 发布排期和内容进度。
- `posts/`: 已写或待发布的小红书笔记。
- `reviews/`: 发布后的数据复盘和改进记录。
- `assets/`: 图片、封面、参考素材说明。

## 命名建议

笔记草稿放在 `posts/`:

```text
YYYY-MM-DD-选题关键词.md
```

复盘放在 `reviews/`:

```text
YYYY-MM-DD-选题关键词-review.md
```

## 账号矩阵

- `accounts/01-hot-skincare/`: 热门方向，精简护肤 / 问题肌避坑。
- `accounts/02-hot-home-living/`: 热门方向，家居收纳 / 适宠适童智能家。
- `accounts/03-hot-ai-workflow/`: 热门方向，AI 工具 / 职场效率。
