# Chapter Outline · Psychological Debt

只写**具体章节大纲**。不重写全书总纲。不改 `novel-style-psychological-debt`。

先读 `../novel-chapter-structure/SKILL.md`。本 skill 只管这一风格怎么拆一章。

## 作用

把一章写成一笔账：谁付、谁记、孩子怎样少欠一点。

## 工作流

```
章纲 Progress · 心理债务:
- [ ] 1. 读 chapter-structure，确认三圈已排
- [ ] 2. 读 风格总纲/03-心理债务.md 只作方向
- [ ] 3. 写出本章账本：爱的动作 / 暗中要回来的
- [ ] 4. 点名外圈谁让这笔记得更响（随礼、问第几、夸懂事）
- [ ] 5. 写章纲
- [ ] 6. 过门：不把母亲写成坏人；不靠道歉销账
```

**Step 3** 每个温柔动作问一句：她要什么回来？收据、名次、一句「妈妈好」、别告诉别人。  
**Step 4** 外圈是账的证人，不是新债主线。  
**Step 6** 叙述里出现「原生家庭伤害」标签，改回具体纸或菜。

## 本章要看见

- 林倩或另一个记账的人，这一笔记在哪
- 外圈一句「你们家真舍得 / 第几名」，怎样把账钉死
- 晓宁用什么办法少欠（配合、撒谎、说没事）

## 章纲模板

```markdown
# 第X章 · [账上的物件]

## 这章主线
[哪一笔爱变成债]

## 房间 / 钟

## 三圈在场
- 内圈：
- 中圈：
- 外圈：[谁看见这张收据或这口菜，说了什么]

## 账本
- 付出：[假条 / 鱼肚子 / 报班 / 红包]
- 要回来的：[看见我 / 别输 / 别让娘家矮]
- 孩子怎么结：[乖、说还行、说没事]

## 谁先伸手

## 人物事件
[冷细节。手、纸、碗。不解释心理]

## 不可逆
[这笔记上了，不能装没发生]

## 孩子学会什么
[怎样回答才安全]

## 接到下一章
```

## 禁

审母、一场道歉结清、内心独白讲缺口、外圈变成第二个主角。
