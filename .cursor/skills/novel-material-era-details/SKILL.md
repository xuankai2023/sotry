# Novel Material: Era Details

## Role

本 skill 只生成年代生活细节材料。不要写中纲，不要排章节，不要写完整正文。

若项目文件里有暂名或工作名，只作为当前工程上下文，不把它当成最终书名或唯一适用对象。

年代不是主角。2000-2010 的东西只能通过饭桌、门口、听筒、收据、孩子物件、单位假条进入家庭。每类必须写背景变化：它进来之后，屋里谁有权、哪样东西、哪条规矩变了；以及它逼谁的手差一寸。见 `novel-thought-ground`。

新闻只能当窗外声音。不要把公共事件写成剧情发动机。

- 孩子玩具与零食
- 学校用品
- 补课与成绩
- 家庭电器
- 住房与月供

- 交通接送
- 老人带孙
- 红包压岁钱
- 菜市场
- 医院小病小痛
- 电脑与宽带
- 电视声音
- 亲戚往来

## Era Rules

必须遵守：

- 2000 年不能写微信、外卖、移动支付、触屏手机日常。
- 宽带默认 2008 左右进入这扇门。
- 摩尔庄园 2008、赛尔号 2009、洛克王国 2010。
- 父亲是本市工作缺席，不写成广东长线打工。
- 奶粉只写罐、说明书、水温、进口字，不写公共奶粉事故主线。
- 2008 公共新闻只能是电视声音、捐款、冰箱和红包的家庭反应，不写灾区剧情。

如需事实确认，提醒用户对照项目事件库，不要凭印象编硬事实。

## Output Template

```markdown
# 年代生活细节校准库

## 使用边界

- 只供正文调用。
- 不写中纲。
- 不写新闻主线。
- 不把年代物件写成展览。

## 通讯工具

### 这个年代能出现什么
- [物件 / 用法]

### 不能提前出现什么
- [禁用项]

### 通常在谁手上
[人物 + 原因]

### 会带来什么家庭选择
[选择必须具体]

### 不能写成什么新闻梗
- [禁区]

### 可直接入正文的生活细节
- [至少 10 条]

### 思想落地
- 思想：[这类细节逼出的家庭问题，不是新闻主题]
- 人物变化：[谁因此改手、改路线]
- 背景变化：[通讯/钱/班/门哪一条规矩变了]
```

## Material Rules

- 年代细节必须带来家庭选择：谁请假、谁付钱、谁接送、谁解释、谁等待。
- 每条材料都要能落到一件物或一个动作。
- 可以写电视声音，但电视不能接管剧情。
- 可以写社会变化，但必须压回一个家庭动作。

## Quality Gate

生成后检查：

- 每类都有“能出现”和“不能提前出现”。
- 每类都有具体人物持有或使用。
- 每类都能造成家庭选择。
- 没有把年代写成怀旧清单。
- 没有硬编公共事实。

## Default Prompt

```text
请为当前小说工程或我指定的小说，生成年代生活细节校准库。

禁止写中纲，禁止安排章节，禁止写完整正文，禁止写新闻主线，禁止写年代物件展。

请覆盖：
通讯工具、孩子玩具与零食、学校用品、补课与成绩、家庭电器、住房与月供、单位请假、交通接送、老人带孙、红包压岁钱、菜市场、医院小病小痛、电脑与宽带、电视声音、亲戚往来。

每类按以下项目输出：
这个年代能出现什么、不能提前出现什么、通常在谁手上、会带来什么家庭选择、不能写成什么新闻梗、可直接入正文的生活细节。

要求：
1. 每类至少 10 条可直接写进正文的生活细节。
2. 年代只通过饭桌、门口、听筒、收据、孩子物件、单位假条进入家庭。
3. 每条材料都要带来一个动作或选择。
4. 不确定的年代事实要标注“需对照事件库确认”。
```
