# Chapter Outline · Critical Realism

只写**具体章节大纲**。不重写全书总纲。不改 `novel-style-critical-realism`。

先读 `../novel-chapter-structure/SKILL.md`。本 skill 只管这一风格怎么拆一章。

## 作用

把一章里那句正当的话找出来，看谁执行、孩子怎样配合。不骂人。

## 工作流

```
章纲 Progress · 批判现实:
- [ ] 1. 读 chapter-structure，确认三圈已排
- [ ] 2. 读 风格总纲/06-批判现实.md 只作方向
- [ ] 3. 写下本章「为你好」的变体
- [ ] 4. 标明谁是小执行者（常是外圈或中圈）
- [ ] 5. 写章纲
- [ ] 6. 过门：叙述不审判；结构章末还在转
```

**Step 3** 变体只能是家里的话：为了身体、为了以后、为了这个家、别不懂事、听话。  
**Step 4** 外圈把这句话说得像公共规矩：门口夸胖、班上问第几、亲戚说懂事。  
**Step 6** 每段后作者站出来骂，删。看懂了，规矩仍在。

## 本章要看见

- 那句正当的话
- 话后面要孩子交出什么
- 孩子先学会配合，不是先学会反抗

## 章纲模板

```markdown
# 第X章 · [那句正当的话]

## 这章主线
[「为你好」怎样变成这一章的规矩]

## 房间 / 钟

## 三圈在场
- 内圈：
- 中圈：
- 外圈：[谁把这话讲成常识]

## 正当的一句
[原文能上饭桌的那句]

## 要交出来的
[身体、零花、名次、听话、不哭]

## 谁先伸手

## 人物事件
[几乎正常。外面看不出残酷]

## 不可逆
[孩子又学会一条配合]

## 孩子学会什么
[怎样听「为你好」才不会让谁受伤]

## 接到下一章
```

## 禁

控诉腔、把老人写蠢写坏、章末觉悟后结构消失、外圈变成反派帮凶脸谱。
