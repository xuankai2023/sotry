# 2011–2020 事件卡 · 质量门

写完或优化后过这张表。不过就改本年被点名的那一张，不要顺手改邻年。

## 交之前必须过

1. 三本各 6–8 张，每张 600–1000 汉字。
2. 总表本年深挖都落了。别年深挖只在胶囊点名。
3. 城 / 县或乡 / 留守都出现。
4. 现场没有「不写……」「禁止……」，也没有作者挡明年的嘴。
5. 2006 / 2009 不是关口评论员。1980 / 1985 不是全员供本年主核孩子。1955 不是全员已退已带孙，且格子里的动作等于现场。
6. 小说、旧库、专篇、下一年都没被打开改写。

跑：

```bash
python .cursor/skills/events-00hou-2011-2020/scripts/validate.py YYYY
```

脚本过了仍要人工看换手。脚本只能抓字数、禁令和空格。

## 换手（2014 推倒重写就是栽在这里）

补题不是「上年那张再写一遍，加更晚 / 更厚」。

| 错 | 对 |
|----|----|
| 课间 QQ 再开一张 | 打印店热纸、压岁还要交 |
| 联系本再开一张 | 工位群里五块 |
| 工位盒饭再开一张 | 辅导班门口，盒饭在包里 |
| 圆键不会再开一张 | 给孙仍是纸包 |
| 平板桌上锁 + 平板肩上勒写成同一只手 | 拆空间：桌上是锁，肩上是带 |
| 少年看红包、祖辈点不开、婆家娘家再喊打不开 | 祖辈一张点不开；另一张谁先塞纸包 |

同一物件两年必须换手：2012 看见圈 ≠ 2013 按住出声；2013 盒饭刮油 ≠ 2014 包里那层白。

## 现场禁令（作者口）

现场里不要出现这些写法。要挡明年，写进文末「本年不写」或事实核。

- 「不写……」「禁止写成……」
- 「不是骑手 / 黄袋 / 配送 / 绑卡 / 给你红包」
- 「不是校门口那盏 / 不是十四岁的灯 / 不准对着卷」
- 「去年的嘴」
- 校准原文、产品年表、全国工资或养老金精确月数（一千八、2061、56360）

改法：留下手和钟。门口是车铃，杯壁凝水，门响是钥匙。折子只写「比去年厚一点」。

## 分龄空格

| 空 | 补 |
|----|----|
| `2009 \| 4 岁。` | 绳冰一下就松手 / 机壳贴脸 / 数字跳一下就关 |
| `1985 \| 还不是付款人。` | 看自己的机、摊自己的入园材料、打自己加班那一单 |
| `1955 \| 59 岁。` | 还在岗，路过看见邻居被按手 / 打卡 |

1955 格写「未带孙」而现场写他在喂孙，算没写完。

## 三本接口

别人已深挖，本卡只留钩子一句 + `详见 T-/P-/G-YYYY-NN` 或 `详见某某库`。

不要三张卡同时演「红的方块」。孩子看、大人绑、老人点不开，各留一只手，其余一句接口。

## 年代门（只拦提前，细节以总表和校准为准）

朋友圈不进 2011。红包不进 2013。春晚客厅摇红包不进 2014。外卖晚饭不进 2011–2014。家校群不进 2011–2014。拍题、王者不进 2014。抖音不像 2016 全班。共享单车不进 2015 满街。音箱不进 2016。刷脸不进 2017 铺店。查理九世不进 2011 摊上主货。疫情四个字不进 2020 现场。

试卷、志愿、家校群怎么管、拍题怎么提分，年份只留钩子。

## 优化时怎么改

用户说「优化 2013 的其他的不用」：只动点名的处。

用户说「写的不够好继续优化」：先报弱项（抄上年、三张抢一物、现场作者口、分龄空格），再改本年三本。不要开下一年。

补字：补进已有节拍的手、物、钟。不要另开第二主场。
