# Platform Playbooks

## 小红书

### When to Use

Use for种草、经验分享、教程、避坑、清单、探店、生活方式、个人成长、产品体验、知识卡片 and any request mentioning 小红书, note, 笔记, 标题党但不低俗, 封面文案, hashtags.

### Intake

Capture or infer:

- 记录来源: read `小红书/account-bible.md`, `小红书/topic-bank.md`, and `小红书/content-calendar.md` before drafting when available.
- 目标读者: 新手、进阶用户、同城人群、学生、职场人、宝妈、创作者等。
- 内容目的: 收藏、评论、转粉、成交、引流、品牌认知。
- 账号人设: 专业顾问、真实体验者、朋友分享、测评人、成长记录者。
- 素材: 亲身经历、产品卖点、步骤、对比、图片内容、注意事项。
- 风险边界: 不夸大功效、不虚构经历、不承诺收益、不碰医疗金融硬承诺。

### Output Structure

Produce:

1. 3-8 个标题候选。
2. 封面文案: 6-16 字，强利益点或强反差。
3. 正文:
   - 开头 1-3 行: 痛点、反差、结果、场景或身份钩子。
   - 主体: 分点写，每点先给结论，再给细节、例子或步骤。
   - 结尾: 评论问题、收藏理由、下一步行动。
4. 标签: 8-15 个，混合大词、细分词、场景词、身份词。
5. 发布建议: 图片/封面/评论区引导，如用户需要再展开。
6. 记录建议: if keeping records, create or update a draft in `小红书/posts/` and update `小红书/topic-bank.md` / `小红书/content-calendar.md`.

### Title Patterns

- “我终于把[痛点]讲明白了”
- “[人群]别再[错误做法]了，先看这篇”
- “用了[时间]，我总结出[数量]个真相”
- “[低成本/高效率]搞定[目标]的方法”
- “不是[常见认知]，而是[新认知]”

### Body Rules

- 像朋友讲经验，不像广告通稿。
- 多写真实场景: “早上赶地铁前”, “第一次做账号时”, “预算只有 100 元”.
- 每个小标题最好能单独截图传播。
- 用“适合谁 / 不适合谁 / 怎么做 / 注意什么”降低读者决策成本。
- 可以有情绪，但不要攻击群体或制造焦虑。

### Final Check

- 标题有信息增量，不只靠情绪词。
- 开头能让目标读者觉得“这说的是我”。
- 正文有可执行步骤或具体判断标准。
- 标签没有堆砌无关热词。
- 没有虚假体验、绝对化承诺或无法证明的数据。
- 账号定位、栏目和禁区与 `小红书/account-bible.md` 一致。

## 今日头条

### When to Use

Use for 今日头条, 头条号, 长文, 热点评论, 观点文, 故事化文章, 知识科普, 社会观察, 财经/科技/教育解读, or content intended for feed-based long-form reading.

### Intake

Capture or infer:

- 记录来源: read `今日头条/account-bible.md`, `今日头条/topic-bank.md`, and `今日头条/content-calendar.md` before drafting when available.
- 读者: 泛人群还是垂直人群。
- 文章目标: 信息解释、观点说服、讨论互动、账号涨粉、内容变现。
- 选题角度: 热点、争议、知识差、普通人利益、趋势变化。
- 证据来源: 用户素材、公开事实、个人经验、案例。
- 立场边界: 哪些不能断言，哪些只是推测。

### Output Structure

Produce:

1. 3-6 个标题候选:
   - 一个信息型。
   - 一个冲突型。
   - 一个利益型。
   - 一个故事型 if applicable.
2. 摘要或导语: 80-150 字，交代冲突、对象、结论方向。
3. 正文:
   - 开头: 用事件、问题、反常识或利益冲突进入。
   - 背景: 用普通读者能懂的语言补足上下文。
   - 分析: 2-4 个小节，每节一个判断。
   - 例子: 用案例、类比、数据或生活场景支撑。
   - 结尾: 回到读者利益，抛出可讨论问题。
4. 评论区引导: 1-2 个开放问题。
5. 记录建议: if keeping records, create or update an article in `今日头条/articles/` and update `今日头条/topic-bank.md` / `今日头条/content-calendar.md`.

### Headline Patterns

- “[事件]背后，真正值得注意的是[核心变化]”
- “为什么越来越多[人群]开始[行为]？”
- “[现象]不是偶然，三个原因很现实”
- “看懂[热点]，就明白[行业/生活]正在变”
- “[人物/公司]的选择，给普通人提了个醒”

### Body Rules

- 先讲清楚“发生了什么”和“跟读者有什么关系”。
- 观点要有层次: 事实、解释、判断分开写。
- 少用悬浮大词，多用例子和因果链。
- 对争议话题保留边界: “更可能”, “从现有信息看”, “不能简单归因”.
- 避免洗稿、标题与正文不匹配、煽动对立、未经证实的爆料。

### Final Check

- 标题不空泛，正文能兑现标题承诺。
- 前 200 字给出继续读的理由。
- 论点有支撑，不是单纯情绪输出。
- 小标题串起来就是完整逻辑。
- 结尾能激发讨论但不刻意挑事。
- 账号定位、栏目和观点边界与 `今日头条/account-bible.md` 一致。
