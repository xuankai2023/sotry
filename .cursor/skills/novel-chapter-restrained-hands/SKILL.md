# Chapter Outline · Restrained Hands

只写**具体章节大纲**。不重写全书总纲。不改 `novel-style-restrained-hands`。

先读 `../novel-chapter-structure/SKILL.md`。本 skill 只管这一风格怎么拆一章。

## 作用

把一章交给手：修、盛、洗、绑、放正。话少。外圈也用手，不用讲道理。

## 工作流

```
章纲 Progress · 克制留白:
- [ ] 1. 读 chapter-structure，确认三圈已排
- [ ] 2. 读 风格总纲/04-克制留白.md 只作方向
- [ ] 3. 选定本章主手和主物件
- [ ] 4. 写出故意不说的那一句
- [ ] 5. 写章纲
- [ ] 6. 过门：能用手的句子删掉；外圈只留一个动作
```

**Step 3** 主手优先钱厚德、周志刚，桂芳的洗碗、晓宁的关门可作辅。  
**Step 4** 那句话永远不要出现在对话里。  
**Step 6** 出现「他其实很爱」，删，改回物件用法变了。

## 本章要看见

- 哪双手做完了
- 外圈递工具、让座、或只站着看
- 章末物件意思变了，人不解释

## 章纲模板

```markdown
# 第X章 · [工具或手]

## 这章主线
[手做完了什么，话没说]

## 房间 / 钟

## 三圈在场
- 内圈：
- 中圈：[哪双手]
- 外圈：[一个动作，不要一段评价]

## 主手 / 主物
[谁，拿什么]

## 故意不说的一句
[写在大纲里，禁止写进对话]

## 人物事件
[只写手。对话每人都短]

## 不可逆
[这件东西以后不能再当原来的意思]

## 孩子学会什么
[他看见了手，还不会命名]

## 接到下一章
```

## 禁

抒情解释、田园装饰腔、把沉默写成冷酷、外圈发表感慨。
