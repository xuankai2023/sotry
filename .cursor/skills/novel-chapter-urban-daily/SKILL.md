# Chapter Outline · Urban Daily

只写**大章纲或具体场卡**。不写完整正文，不重写全书总纲，不改 `novel-style-urban-daily`。

先读 `../novel-chapter-structure/SKILL.md` 与 `../novel-character-craft/SKILL.md`。大章包含 5–7 场并承担不可逆；单场承担一次日程状态变化。本 skill 只管这一风格怎样排大章和场卡。正文转 `novel-prose-from-outline`。大章纲要有本章人物，场卡要有身世一寸和声音差。

## 作用

把一场写成一段日程：哪一截路线断了，谁的权空了。写大章时，让 5–7 场依次完成立钟、撞钟、选择、后果和新日程，不能重复五次迟到。

## 工作流

```
章纲 Progress · 市民日常:
- [ ] 1. 读 chapter-structure，确认三圈已排
- [ ] 2. 读 风格总纲/02-市民日常.md 只作方向
- [ ] 3. 画出本章路线：床→灶→菜场→铁门→班→桌
- [ ] 4. 标明哪一截断了，谁因此丢权
- [ ] 5. 写章纲
- [ ] 6. 过门：冲突来自撞钟，不是演讲；外圈在路上或门口
```

**Step 3** 本章只走这条路线里的两到三站，不要全城跑。  
**Step 4** 断的是锅点、接人点、晾衣次序或联播点。外圈常是菜场、铁门、石凳上的姐妹。  
**Step 6** 出现「时代变迁」概括句，删掉，改回几点几分谁在哪。

## 本章要看见

- 主日程是谁的（默认桂芳）
- 外圈比较或让路，怎样校准她的钟
- 章末日程改了哪一拍

## 大章规则

先写大章问题、起始日程、目标不可逆，再排 5–7 场：立钟 → 外压 → 撞钟 → 选择 → 后果 → 新日程。至少两次社会压力进入，不强制每场出现外圈真人。

## 场卡模板

```markdown
# [大章X-场Y] · [日程里的物件]

## 这场主线
[哪一段日程断了，权力怎样换手]

## 上一场结果 / 下一场问题

## 房间 / 钟
[路线上的两到三站。写时刻]

## 三圈在场
- 内圈：
- 中圈：
- 社会压力：[在哪一站碰到，或由班表 / 门 / 电话怎样进入]

## 本日程
[几点锅、几点出门、几点等人]

## 撞钟
[谁的班、谁的门、谁的菜篮撞上]

## 人物事件
[每人只写手和脚，少写心]

## 状态变化
[本场之后哪一拍不能再照旧，或谁开始改走一段路]

## 思想一寸 / 人物变化 / 背景变化
[按 novel-thought-ground 三栏写满]

## 孩子学会什么
[他跟谁的路线，或不跟了]

## 接到下一场
```

## 禁

政策总结、颂扬奶奶、零食清单、一场没有时刻表、外圈只当背景板。
