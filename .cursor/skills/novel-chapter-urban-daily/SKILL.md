# Chapter Outline · Urban Daily

只写**具体章节大纲**。不重写全书总纲。不改 `novel-style-urban-daily`。

先读 `../novel-chapter-structure/SKILL.md`。本 skill 只管这一风格怎么拆一章。

## 作用

把一章写成一段日程：哪一截路线断了，谁的权空了。

## 工作流

```
章纲 Progress · 市民日常:
- [ ] 1. 读 chapter-structure，确认三圈已排
- [ ] 2. 读 风格总纲/02-市民日常.md 只作方向
- [ ] 3. 画出本章路线：床→灶→菜场→铁门→班→桌
- [ ] 4. 标明哪一截断了，谁因此丢权
- [ ] 5. 写章纲
- [ ] 6. 过门：冲突来自撞钟，不是演讲；外圈在路上或门口
```

**Step 3** 本章只走这条路线里的两到三站，不要全城跑。  
**Step 4** 断的是锅点、接人点、晾衣次序或联播点。外圈常是菜场、铁门、石凳上的姐妹。  
**Step 6** 出现「时代变迁」概括句，删掉，改回几点几分谁在哪。

## 本章要看见

- 主日程是谁的（默认桂芳）
- 外圈比较或让路，怎样校准她的钟
- 章末日程改了哪一拍

## 章纲模板

```markdown
# 第X章 · [日程里的物件]

## 这章主线
[哪一段日程断了，权力怎样换手]

## 房间 / 钟
[路线上的两到三站。写时刻]

## 三圈在场
- 内圈：
- 中圈：
- 外圈：[在哪一站碰到，说了哪句比较或让路]

## 本日程
[几点锅、几点出门、几点等人]

## 撞钟
[谁的班、谁的门、谁的菜篮撞上]

## 人物事件
[每人只写手和脚，少写心]

## 不可逆
[以后不能再按原来的钟走]

## 孩子学会什么
[他跟谁的路线，或不跟了]

## 接到下一章
```

## 禁

政策总结、颂扬奶奶、零食清单、一章没有时刻表、外圈只当背景板。
