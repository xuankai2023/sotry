# Novel Thought Ground

先整体后局部。总纲、中纲之后到人物、环境、事物的描写，需要在这里就表达出思想，人物会有什么变化，背景有什么变化，这些都要写出来。这些有思想有深度的落地，再交给 `novel-article-assemble` 落实成某人遇见什么事情。

本 skill 不写 3300 字正文，不改冻结矩阵，不另开主线。它给描写层上锁，给文章包当合同，给正文批注当校验底本。

## 在链路里的位置

```text
novel-master-outline / novel-mid-outline / novel-chapter-structure   整体：全书/部分/本章方向
novel-character-change                           总纲/中纲：性格变化骨头与本部分进/出
本 skill                                         描写层/单场：思想、人物变化、背景变化
novel-character-craft / novel-material-*         按三栏写人、场、物
novel-article-assemble                           某人遇见什么事，必须能指回三栏
novel-prose-from-outline                         正文批注必须对上场卡三栏
```

全书或一部的性格怎么变：走 `novel-character-change`。本 skill 只写单场/描写层进/出，必须继承总纲/中纲已锁的那一寸，不准当场另起一种性格。

用户要人物、环境、事物描写：先在本 skill 把三栏写出来，再进对应材料 skill。  
材料 skill 每条条目也必须带这三栏，不能只交「可入正文」细节。  
三栏空着，不准拼文章包，不准开正文。

## 三栏

思想不是口号。变化必须看得见。

1. **思想**：读者在这个具体家里躲不开的问题。一句刺人的问句，不要「体现亲情 / 时代变迁 / 原生家庭」。
2. **人物变化**：谁从什么变成什么。差必须落在手、嘴、答话长度、路线，不许写「他成长了」。
3. **背景变化**：屋里谁有权、哪样东西换位置、外压哪一句进来或离开。场景不能只换天气。

00 后三代默认北星：

> 他们都在爱孩子，但没有一个人只是在爱孩子。

本场思想必须是这句的一寸，不能另起鸡汤。

## 尺度

| 尺度 | 写多深 | 禁 |
|---|---|---|
| 全书 | 开篇→终局，每人一寸；主场权力怎么挪 | 写完十年弧光 |
| 大章 | 本章只挪一寸思想、一寸人、一寸背景 | 把全书主题说完 |
| 场 / 一条材料 | 本场/本条只压一寸 | 一条材料写完主题论文 |

## 模板

描写层、场卡、文章包都用这一格。空一栏即退回。

```markdown
## 思想落地

### 思想
[一句具体问题。能指向手、物或门，不能指向抽象时代。]

### 人物变化
- 进场：[谁，哪只手 / 哪句嘴]
- 出场：[同一人，差在哪一寸]
- 可见证据：[动作 / 物件 / 路线，演员做得出]

### 背景变化
- 进场：[谁有权；哪样东西在哪；外压有无]
- 出场：[权力、物件位置或外压哪句变了]
- 可见证据：[碗、纸、门、钟、座位、假条……]

### 禁止用下面交差
- 体现亲情 / 表现成长 / 时代洪流 / 他更懂事了
```

### 全书例（对照，不要抄进场卡）

- 思想：谁在用孩子证明自己还被需要。
- 人物：桂芳从「能把席面交出去」变成「蛋篮不换手」；建军从「人到了」变成「人是用班表缺口换来的」。
- 背景：客厅还是那一桌，但同事那头变成必须另送的蛋；窗口的条从口袋进了缺口。

### 单场例

- 思想：在场要用半天津贴去换，空位子比薄工资更难说。
- 人物：建军进场还想等刘哥挡话；出场是自己把条按进窗口。
- 背景：交接窗从关着到拉开一条缝；条从掌心到章垫旁；津贴栏从「还没问」到「按缺算」。

## 工作流

```text
思想落地 Progress:
- [ ] 1. 锁定对象：全书 / 大章 / 一场 / 一条人场物材料
- [ ] 2. 从总纲、中纲抄已有方向，不另起主题
- [ ] 3. 写满三栏，每栏有可见证据
- [ ] 4. 过门：删掉口号后故事还在
- [ ] 5. 交回人物 / 环境 / 事物 skill，或交给文章包
```

## 过门

任一为真，描写层没过：

- 思想可以换成另一章而不别扭
- 人物变化只写心情词，没有手、嘴、路线
- 背景变化只写天气、年代标签或「气氛变了」
- 三栏互相不咬合：思想说债，变化却在夸牺牲
- 用作者判断句代替可见证据

通过后：

- 用户只要思想合同：交付三栏，停。
- 用户要描写：把三栏嵌进对应 `novel-material-*` / `novel-character-craft`。
- 用户要开写：文章包必须抄本场三栏，并写成「某人遇见什么事」。
- 用户要正文：`novel-prose-from-outline` 的批注必须能指回场卡三栏，并摘到正文原句。

## 不要做

- 不把思想写成章末升华讲稿
- 不提前写出物件末次意义
- 不改三份冻结矩阵
- 不让外圈替作者讲道理
