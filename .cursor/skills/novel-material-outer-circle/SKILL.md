# Novel Material: Outer Circle

## Role

本 skill 只生成外圈人物材料。不要写中纲，不要排章节，不要写完整正文。

若项目文件里有暂名或工作名，只作为当前工程上下文，不把它当成最终书名或唯一适用对象。

外圈人物必须是活人，但不能有自己的十年主线。他们只负责把家里的私事公开、比较、钉住或推向选择。每类必须写：走后人物变哪一寸、屋里背景变哪一寸；外圈不替作者讲思想。见 `novel-thought-ground`。

## Outer Circle Types

默认覆盖：

- 同楼退休姐妹
- 热心越界的邻居
- 门卫
- 菜场摊贩
- 林倩同事
- 周建军搭班
- 班主任
- 科任老师
- 同学
- 同学妈妈
- 校门口冰柜老板
- 亲戚席面远亲
- 医院护士
- 银行柜台
- 中介或居委会人员
- 偶尔来的舅或姨

每类只保留一个功能，不开副线。

## Function Pool

外圈人物只能承担这些功能：

- 比较：谁家孩子胖、乖、第几、报什么班。
- 公开：把家里私事变成楼道话题。
- 制度：假条、门禁、报名、排队、签字。
- 面子：随礼、席位、红包、亲戚看法。
- 时间：催班、催接、催交、催走。
- 见证：看见谁等、谁没来、谁先伸手。

## Output Template

```markdown
# 外圈人物材料库

## 使用边界

- 只供正文调用。
- 不写中纲。
- 不给外圈人物开成长线。
- 外圈走后，屋里必须变一点。

## 同楼退休姐妹

### 出现场所
[楼道 / 门口 / 菜场 / 公园石凳]

### 她最常看见周家的什么
[具体事]

### 最常说的一句话
“[一句]”

### 这句话表面是
[表面]

### 实际给谁造成压力
[人物 + 压力]

### 她走后屋里哪样东西会变
[碗 / 纸 / 门 / 灯 / 凳 / 收据]

### 她的动作或随身物
- [至少 5 条]

### 不能给她写什么
- [禁止项]

### 可直接入正文的细节
- [至少 6 条]

### 思想落地
- 思想：[外压逼出的问题，禁止外圈口吐主题]
- 人物变化：[内圈谁的手/嘴差一寸]
- 背景变化：[走后碗/纸/门/灯/凳哪样变了]
```

## Material Rules

- 外圈人物要有一句话或一个动作，不能只有身份。
- 外圈人物不能替作者讲道理。
- 外圈人物出现后，内圈至少一个人要改变动作。
- 外圈人物越真实，越要克制，不要写成脸谱坏人。

## Quality Gate

生成后检查：

- 每类外圈都有明确功能。
- 每类外圈都有场所、口头禅、动作或随身物。
- 每类外圈都能给内圈造成压力。
- 没有给外圈开独立命运线。
- 没有变成亲戚群像大百科。

## Default Prompt

```text
请为当前小说工程或我指定的小说，生成外圈人物材料库。

禁止写中纲，禁止安排章节，禁止写完整正文，禁止给外圈人物开独立主线。

请覆盖：
同楼退休姐妹、热心越界的邻居、门卫、菜场摊贩、林倩同事、周建军搭班、班主任、科任老师、同学、同学妈妈、校门口冰柜老板、亲戚席面远亲、医院护士、银行柜台、中介或居委会人员、偶尔来的舅或姨。

每类人物按以下项目输出：
出现场所、最常看见周家的什么、最常说的一句话、这句话表面是什么、实际给谁造成压力、走后屋里哪样东西会变、动作或随身物、不能给他/她写什么、可直接入正文的细节。

要求：
1. 每类至少 6 条可直接写进正文的细节。
2. 外圈人物必须像活人，但不能抢主线。
3. 外圈人物只负责递比较、面子、制度、时间、公开压力或见证。
4. 外圈走后，周家屋里必须有一个动作或物件改变。
```
