# 中纲落盘模板

一份中纲按这个顺序写。栏名不要改。空栏用「本部分不碰」占住，不要删栏。

```markdown
# 中纲 · [部名或大章区间]

覆盖：第 X 部 / 大章 A–B  
年段：  
主风格：家庭现实主义（若有副风格，只写质感）  
状态：计划 / 已有正文后的总结

## 这一部分写什么

一段：这个部分让家里哪一种能力丢掉，换来哪一种暂时有用的办法。对准 `00-全书结构.md` 的六部损失线，不要另起主题。

写这一段必须先结合总纲和以前的中纲。段内先写清：总纲本区间只许哪一寸；以前的中纲出到哪、本份进部对哪一句；哪些已锁场面本份不得重写。没有以前的中纲，写「此前无中纲，进部对总纲开篇 / 已锁正文」。

## 结构层面

### 三幕式/英雄之旅等叙事框架搭建

- 三幕落点：建立日常 = ；外力与选择 = ；付账与回声 = 。各落在哪一、两个大章，不落在抽象「中段」。
- 英雄之旅对照（只标功能，不当主线）：离家 / 试炼 / 回归各是哪道门、哪顿饭、哪张纸。
- 本部分波形：迟爆 / 早选迟付 / 其他。与三幕哪里重叠、哪里错开。

### 多线叙事的交织与节奏控制

| 线 | 谁扛 | 本部分要什么 | 与主线交在何物/何门 | 本部分停在哪 |
|---|---|---|---|---|
| 内圈 1 |  |  |  |  |
| 内圈 2 |  |  |  |  |
| 中圈 |  |  |  |  |

- 张：哪一章最紧。弛：哪一章允许喘息。回声：哪一章把轻松收紧。
- 禁止五场同一种冲突重复；中纲只标章与章的压力换源。

### 伏笔埋设与回收的设计

| 物件或办法 | 埋 | 本部分只挪一寸 | 回收（部内 / 留给后部） | 禁止提前写完 |
|---|---|---|---|---|
|  | 大章 x |  |  |  |

只登记会被手碰到的物和办法。不登记「亲情」「时代」。

## 人物层面

### 人物小传与动机深挖

每人只写本部分：进部状态、本部分欲望、缺口怎样扭曲爱、章末只挪哪一寸。不写十年履历。

- **姓名：** 进部 → 出部。欲望。手。嘴。年段门。

### 本部分性格变化

总纲已定（栏目或散文都算）：以总纲为主，按 `novel-character-change` 的 `extract.md` 抽进/出。总纲未标主变则写「总纲未标，不补」。总纲此人完全没有开篇→终局才按该 skill 补，并标明。本部分不出场的人写「本部分不碰」。

- **姓名：** 进部（这个年段的办法/手/嘴）。主变。被哪一章压到。出部只挪。可见证据。不许完成。下一部分才能碰。

### 人物关系网的构建与张力设计

- 表面争什么小事。
- 真正怕失去什么位置。
- 谁先伸手，谁慢半拍，谁替谁回答。
- 每组主要关系：帮在哪，伤在哪。没有纯帮或纯伤。

### 对话风格区分，让每个角色"说自己的话"

遮住姓名仍能分开。写口头禅、句长、不说的那半句。本部分若衰减，写清从整句收到半句或动作。

| 人 | 本部分会说 | 不会说 | 遮名辨认 |
|---|---|---|---|
|  |  |  |  |

## 文本层面

### 场景描写的情绪渲染

本部分主场不超过四个（如客厅、门口、听筒两头、后座）。每个主场一种情绪来源：钟、灯、气味、谁有权走动。不写风景清单。

### 叙事视角的选择与切换

- 本部分可限知：
- 不可限知：
- 换限知必须换场。本部分限知顺序（按大章）：

### 文风调性的统一或变化

- 统一：家庭现实主义，选择又帮又伤，变化落在手和物。
- 变化：哪一章呼吸拉长（路、风），哪一章收成半拍（门槛、称呼）。只换呼吸，不换发动机。

## 创作辅助

### 卡文时帮你拆解问题、找突破口

本部分最容易卡在哪一口钟、哪只手、哪句没出口的话。突破口必须是一个可见动作，不是「写得更感人」。

### 帮你审视情节逻辑漏洞

列出：已锁事实会不会被本部分踩破；下一章会不会因本部分无法发生；限知会不会逼正文跳头。

### 从经典作品中提炼可复用的技法

每条只写功能：谁的哪一手、落到本部分哪一物。不抄原句，不列书单充数。至多三条。

## 接到下一部分

下一部分不得不接的新问题（一句）。本部分禁止提前写完的场面。
```
