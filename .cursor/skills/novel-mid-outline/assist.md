# 中纲创作辅助

用户只要卡文、审洞或抽技法时用本页。不必重写整份中纲。先读总纲和以前的中纲，再读该部分已有中纲；没有则先标卡在哪一场，再拆。以前的中纲已锁的不可逆，不准当本场新卡点重写。

## 卡文时帮你拆解问题、找突破口

按这个顺序问，停在第一个答不上的：

1. 上一场留下的手、物、未说完的话是什么？
2. 限知人物此刻具体想拿到什么（勺、门、假、路、一声称呼）？
3. 谁或什么挡住他？这个阻力是否也真的有用？
4. 他能做的最小可见选择是什么？
5. 选择之后，哪只手、哪件物、哪句答话变了？

突破口只准是：换主物件、收第二主场、把解释改成手、把金句改成未出口的半句。不准加车祸、坦白大会、新反派。

00 后三代常见卡点：

- 想写懂了 → 写成看鞋、看勺、看脸色，不写结论。
- 想写两边都爱 → 写成先伸的那一只手。
- 想写时代 → 写成月供那一行、班点、园门口有人看。

## 帮你审视情节逻辑漏洞

只判阻断：

- 与 `story-bible.md`、已锁定 ledger 打架。
- 场序对调后因果仍成立（说明没咬死）。
- 限知人物知道了他不可能听见的单位内情。
- 伏笔在本部分被解释完全书意义。
- 孩子使用了年段外的概念。
- 建军外地厂、林倩过早有个人手机、厚德上楼坐实女婿茶几等硬边界。

非阻断（记下，不立刻改矩阵）：状态变化略像作者解释、波形标签未重贴、措辞不统一。

## 从经典作品中提炼可复用的技法

每条格式：

> 技法：〔功能一句话〕  
> 来处：〔书名 / 作者，不引原文〕  
> 落到本部分：〔哪一物、哪一只手、哪一句不说〕

只抽功能。家庭现实主义优先抽：饭桌权力、门口等待、纸证明在场、爱做成合格品。不要用技法证明主题正确。
