# Novel Mid Outline

中纲是**小说一个部分的总结**，不是总纲，不是大章纲，不是文章包，不是正文。

总纲锁全书骨头。中纲锁这一截怎么走、谁在说话、线在哪交、伏笔埋在哪、回收在哪、性格本部分只挪哪一寸。大章纲 / 场卡拆 5–7 场。文章包才写某人遇见什么。

写人物层面时必须打开 `../novel-character-change/SKILL.md`，按中纲模板交本部分进/出。不要把十年弧光写进一部。

**总纲性格变化已定：以总纲为主，该 skill 为辅。** 散文也算已定，不要求有「主变」栏。00 后三代先读 `总纲-大师写法.md` 的扛戏的人、总结构、不可逆，按该 skill 的 `extract.md` 抽本部分进/出。不准用 `sandai-arcs.md` 覆盖总纲。总纲此人完全没有开篇→终局，才按该 skill 补，并标明「总纲未锁」。

00 后三代默认一份中纲 = **一部**（3 个大章）。用户点名区间（如大章 7–10）则按区间写一份。不改三份冻结矩阵。

## 每次写中纲必须结合总纲和以前的中纲

每次写中纲都要使用到以前的中纲和总纲。不结合，不准落盘。

1. **先开总纲。** 00 后三代打开 `番茄/00hou-sandai/总纲-大师写法.md` 的一句话、三个扛戏的人、六个不可逆、总结构该部、结尾禁令。本份只许发生总纲允许这一截的一寸。不准另起主题，不准用 `sandai-arcs.md` 覆盖。
2. **再开以前的中纲，全部打开，不是只读上一份。** 已落盘的 `番茄/00hou-sandai/中纲/部分/` 除 `00-用法.md` 外都读。还没有部分中纲时，`中纲/01-05.md` 也算以前的中纲。跨部区间要把重叠或紧挨的那些一起读。
3. **结合着写。** 进部必须对上以前的中纲出部（或 `01-05` 已锁变化、已锁正文出章）。总纲点名的不可逆，以前的中纲写过的，本份不得再当新不可逆写一遍。以前的中纲说「下一部分才能碰」的，本份才能碰，且只挪一寸。伏笔表先抄以前的中纲「留给后部」的物，再登记本份新埋的。
4. **写进「这一部分写什么」。** 段内先写清：总纲本区间只许哪一寸；以前的中纲出到哪；哪些已锁场面本份不得重写。没有以前的中纲，写「此前无中纲，进部对总纲开篇 / 已锁正文」。

没打开总纲，停。有以前的中纲却没读，退回。进部对不上上一份出部，退回。

## 本 skill 不做

- 不改 `中纲/01`–`03` 场景矩阵
- 不重写 `story-bible.md` 或全书总纲
- 不把一场扩成 3300 字正文
- 不预建空的 `正文/` 目录
- 不把三幕式 / 英雄之旅写成屠龙升级，替代家庭现实主义发动机
- 不整段搬经典作品原文

## 必须写出来的四层

按用户给定的合同，一份中纲必须覆盖：

结构层面：
三幕式/英雄之旅等叙事框架搭建
多线叙事的交织与节奏控制
伏笔埋设与回收的设计
人物层面：
人物小传与动机深挖
本部分性格变化（进部 / 出部 / 可见证据；总纲已定则总纲为主，`novel-character-change` 为辅）
人物关系网的构建与张力设计
对话风格区分，让每个角色"说自己的话"
文本层面：
场景描写的情绪渲染
叙事视角的选择与切换
文风调性的统一或变化
创作辅助：
卡文时帮你拆解问题、找突破口
帮你审视情节逻辑漏洞
从经典作品中提炼可复用的技法

四层缺一层，中纲不算齐。栏目释义与落盘模板见 [template.md](template.md)。卡文 / 审洞 / 技法只开创作辅助时见 [assist.md](assist.md)。

## 00 后三代对照（框架当镜子，不当新主线）

- **三幕式**对准一部：建立日常 → 外力与选择 → 付账与回声。可与全书波形（迟爆、早选迟付等）叠看，不另起一套场序。
- **英雄之旅**只标功能落点：离家 = 谁被抽走或谁出门；试炼 = 门口、饭桌、听筒、纸；回归 = 人回来了但位置变了。禁止写成打怪升级。
- **多线**只织已有内圈 / 中圈。交点必须是同一物件、同一门口或同一顿饭，不新开十年线。
- **伏笔**从总纲、以前的中纲、矩阵和 `scene-ledger.md` 已锁事实摘。先接上一份「留给后部」，再登记本份新埋的。写清：埋在哪一章、回收在哪一章、本部分只挪一寸。回收不得提前写完全书意义。
- **视角**服从一场一个限知。中纲只规定本部分谁可限知、换限知必须换场。
- **文风**跟这本书已锁的主风格。00 后三代已写大章 1–5 是家庭现实主义，中纲默认这条竖线。本部分若要局部副风格，只写质感，不换发动机，不另写一套风格中纲。

已锁定正文的部分：中纲总结**已发生**，接到下部。未写的部分：中纲是开写前合同，仍不代替文章包。

## 工作流

```text
中纲 Progress:
- [ ] 1. 锁定部分：哪一部，或哪几个大章
- [ ] 1.5 打开总纲；打开已经落盘的全部以前的中纲；写出接到哪、不得重写哪
- [ ] 2. 读圣经、全书结构、覆盖该部分的矩阵、ledger、已有文章包 / 通读稿
- [ ] 3. 写结构三栏：框架落点、多线交织、伏笔埋/收
- [ ] 4. 写人物栏：本部分小传与动机、本部分性格变化（总纲散文也算已定，按 `extract.md` 抽）、关系网张力、对话声音差
- [ ] 5. 写文本三栏：主场情绪、限知顺序、文风统一或哪一寸变
- [ ] 6. 写创作辅助：本部分卡点、逻辑洞、可复用技法（功能，不搬原文）
- [ ] 7. 过门；用户要求落盘再写入 中纲/部分/
```

### Step 1 · 锁定部分

- 未点名：00 后三代写**下一未齐的一部**。现况见 `番茄/00hou-sandai/README.md`。
- 点名「第 5–10 章」：按大章号写一份，标题写清覆盖区间，不要假装等于一部。
- 一次只写一份。不要六部中纲一次铺开。

### Step 2 · 必读

顺序不可倒。总纲和以前的中纲没打开，后面的文件先别读完就写。

1. `番茄/00hou-sandai/README.md`
2. `番茄/00hou-sandai/总纲-大师写法.md`（全文方向：一句话、扛戏的人、六个不可逆、总结构该部、结尾。已定则性格以此为主）
3. 以前的中纲，全部打开：
   - `番茄/00hou-sandai/中纲/部分/` 里除用法外的已有文件
   - 部分中纲未齐时，加读 `番茄/00hou-sandai/中纲/01-05.md`
   - 在工作过程里列出：上一份出部 → 本份进部；本份不得重写的已锁场面；上一份「下一部分才能碰」本份碰哪一寸
4. `番茄/00hou-sandai/story-bible.md`
5. `番茄/00hou-sandai/中纲/00-全书结构.md`（六部损失线、该部章头）
6. 覆盖该部分的场景矩阵（只打开需要的那一份）
7. `番茄/00hou-sandai/scene-ledger.md`（只继承定稿 / 大章锁定）
8. `番茄/00hou-sandai/中纲/人物志/`
9. 该部分已有文章包或通读稿（有则读；用户声明旧稿不作已发生时，不继承）

和矩阵、圣经打架：停，写明冲突，不暗改矩阵。  
和总纲已定性格变化打架：停，写明冲突，不暗改总纲，也不用 `novel-character-change` 默认弧覆盖。  
和以前的中纲出部对不上：停，写明引用了哪一份哪一句，不暗改上一份，也不假装本份是开篇。

### Step 3 · 过门

任一为真，退回：

- 只有场序摘要，没有框架落点、多线交点、伏笔表
- 人物小传抄成全书履历，或主要角色对白可以互换
- 性格变化把全书弧光写完，或只有「他更懂事了」，没有进部/出部的手和嘴
- 没打开总纲，或「这一部分写什么」指不回总纲该部 / 该区间不可逆
- 有以前的中纲却没打开，或进部对不上上一份出部 / `01-05` 已锁变化
- 把以前的中纲已经完成的不可逆再写一遍当新不可逆
- 总纲已有开篇→终局或六部走向（含散文），中纲却因没有「主变」栏重开合同，或用默认弧覆盖总纲
- 宣布「床位就是资格」「看鞋就是选边」一类主题
- 用英雄之旅改掉已锁不可逆
- 把未写大章的文章包或正文提前写了
- 创作辅助只给鸡汤，不指出卡在哪一口钟、哪只手、哪句没出口的话

### Step 4 · 落盘

00 后三代写入：

```text
番茄/00hou-sandai/中纲/部分/
  00-用法.md
  01-证据.md
  02-缺席.md
  …
  大章07-10.md   # 仅当用户点名跨部区间
```

一份一个文件。用法见该目录 `00-用法.md`。
