# Novel Material: Scenes

## Role

本 skill 只生成场景材料。不要写中纲，不要排章节，不要写完整正文。

若项目文件里有暂名或工作名，只作为当前工程上下文，不把它当成最终书名或唯一适用对象。

场景不是风景。场景必须让人物站位、说话资格、等待时间、物件归属发生变化。每个场景必须写 `novel-thought-ground` 三栏：思想、人物在这里会变什么、背景会变什么。只交声味光、不写变化，退回。

## Core Scenes

默认覆盖：

- 厨房、饭桌、客厅、客厅加床、阳台
- 楼道、家门口、铁门口、门卫室
- 菜市场、单位走廊、厂门口
- 电话两头、幼儿园门口、小学校门口、晚托教室门口
- 医院走廊、亲戚席面、邻居门口、孩子自己的房间

每个场景都要绑定一类压力：灶、纸、门口、钱、学校、单位、屏幕。

## Scene Logic

每个场景必须回答：

1. 谁在这里有权。
2. 谁在这里不自在。
3. 什么小动作会让关系变紧。
4. 外圈能不能从这里进入。
5. 场景结束后，屋里的哪样东西变了。

## Output Template

```markdown
# 场景材料库

## 使用边界

- 只供正文调用。
- 不写中纲。
- 不写纯风景。
- 每个场景必须推动关系。

## 厨房

### 空间里最重要的物件
- [5 个]

### 常有的声音
- [声源，不写抽象嘈杂]

### 常有的味道
- [味道必须落到具体物]

### 光从哪里来
[自然光 / 灯 / 灶 / 屏幕 / 门缝]

### 谁通常站着，谁通常坐着
[人物站位]

### 谁在这里有权
[人物 + 原因]

### 谁在这里最不自在
[人物 + 原因]

### 最容易爆发的小动作
- [至少 6 条]

### 适合写哪类心理
[心理必须转成动作]

### 可直接入正文的场景细节
- [至少 10 条]

### 思想落地
- 思想：[这个房间逼出的具体问题]
- 人物变化：[谁在这里手/嘴会差哪一寸]
- 背景变化：[结束后哪样东西、谁有权、外压哪句变了]
```

## Material Rules

- 一条场景材料要能看见位置、听见声音、闻到味道、知道谁有权。
- 天气和光必须改变行动：出门慢、饭凉、门关、凳湿、纸皱。
- 场景不能只是背景，必须逼人物做一个小选择。
- 同一场景可反复出现，但每次只能改变一寸。

## Quality Gate

生成后检查：

- 每个场景都有权力结构，不是装饰。
- 每个场景都有至少一个物件和一个动作。
- 每个场景都有一个适合进入的外圈人物或一句外圈压力。
- 没有写成旅游式环境描写。
- 没有一口气把三个场景混在一起。
- 每个场景都有思想、人物变化、背景变化，且背景变化不是天气。

## Default Prompt

```text
请为当前小说工程或我指定的小说，生成场景材料库。

禁止写中纲，禁止安排章节，禁止写完整正文，禁止写纯风景。

请覆盖这些场景：
厨房、饭桌、客厅、客厅加床、阳台、楼道、家门口、铁门口、门卫室、菜市场、单位走廊、厂门口、电话两头、幼儿园门口、小学校门口、晚托教室门口、医院走廊、亲戚席面、邻居门口、孩子自己的房间。

每个场景按以下项目输出：
空间里最重要的物件、常有的声音、常有的味道、光从哪里来、谁通常站着谁通常坐着、谁在这里有权、谁最不自在、最容易爆发的小动作、适合写哪类心理、可直接入正文的场景细节。

要求：
1. 每个场景至少 10 条可直接写进正文的细节。
2. 场景必须推动关系变化。
3. 声、味、光都要落到具体物上。
4. 不要写成风景描写或年代展览。
```
