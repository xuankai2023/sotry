# 00 后父母 · 2000–2010 家庭与工作事件

这是一份**书写工作流**，不是成品库。一次只写一年。不要一次生成十一年。

**一句话**：只写 00 后爸妈这十年自己家里过的、班上干的。不写小孩课间，不写爷爷奶奶单位史，**不写新闻，不写国家大事**。

判断口诀：要打开新闻联播才能解释？删掉。能用「今晚加班回不回得了 / 这个月还贷 / 奶粉换哪罐 / 孩子留给谁带 / 红包给多少」写完？留下。

## 先分清三套本子

| 库 | 路径 | 本 skill 怎么用 |
|----|------|-----------------|
| 小孩本子 | `content-intelligence/research/events-00后儿童视角/` | **禁止再写**。玩具、动画片、冰柜只许钩子一句 + `详见儿童库` |
| 社会本子 | `tools/storygen-skill-src/samples/linglinghou-decade-one/research/2000.md` … `2010.md` | **整库禁止再写**。不许用「落到饭桌」当借口把新闻塞回来 |
| 祖辈本子 | `content-intelligence/research/prompts/00后爷爷奶奶-2000至2010-AI分步描述提示词.md` | **禁止写成爷爷奶奶主卡**。老人只当「带不带、听不听」的第三者 |
| 人物画像 | `content-intelligence/research/surveys/70后80后世代画像调研.md`、`content-intelligence/research/personas/` | 可对照性格，**不要把林倩/鸡血妈妈写成事件主卡** |

年代器物以已有研究为准，不要另编一套。写年前先读对应篇，见 [decade-table.md](decade-table.md)。

## 写的是谁（写错年龄就是写错人）

00 后的父母，这十年主体是 **70 后**，辅以 **早 80 后**。不是 40 后 / 50 后祖辈。

| 父母出生年 | 2000 | 2005 | 2010 | 这十年里的位置 |
|------------|------|------|------|----------------|
| 1970 | 30 | 35 | 40 | 70 后前半。孩子多已入园 / 小学 |
| 1975 | 25 | 30 | 35 | 主核。从产房到小学中年级 |
| 1980 | 20 | 25 | 30 | 早 80 后。十年中后才当爸妈的多 |
| 1985 | 15 | 20 | 25 | 多数还不是 00 后主父母。未当爸妈也占格 |

分龄四格必须写全：1970 / 1975 / 1980 / 1985。未结婚、未生育写「还不是这张卡的付款人」，不要假装全员已育。

城乡至少两种：城双职工 / 县城或乡镇 / 外出把孩子留给老人。没有「谁家有、谁家没有」，视为没写完。

每年至少一张**妈线**和一张**爸线**，或同一物件两套（妈管罐和灶，爸管信封和夜班）。不要写成只有一条线。每年至少一张**自己工作**（信封、夜班、班车、工位、请假），不要十一年只写带娃。

## 什么能进主卡

同时满足至少两条：

1. **家里碰到了**：付、换、煮、送、藏收据、在门口等、跟老人争。
2. **班上碰到了**：加班、信封、夜班盒饭、班车、工位电脑、请假条、同事请客。
3. 同事 / 邻居 / 亲戚会跟风或会吵。
4. 成年后的 70 后 / 80 后提起带 00 后的十年还会先说它。
5. **删掉所有新闻还站得住。**

每年至少 **5** 张，必须 **6–8** 张。5 张太容易写成「奶粉 / 红包」复读。六类里至少 **4** 类：

| 类型 | 写什么 | 例子（方向） |
|------|--------|--------------|
| 家里灶 | 改菜谱、油换了、方便面当正餐、过年桌 | 红烧留给年、猪油还是色拉油 |
| 家里钱包 | 月供、红包、奶粉钱、开学一份钱、压岁钱上交 | 这个月还贷、红包给 200 还是 50 |
| 家里房与路 | 分房尾巴、装修、城中村、春运绿皮、孩子有没有自己的床 | 咬牙买还是再等 |
| 自己班上 | 信封、夜班、盒饭、班车、工位、请假接孩子 | 加班回不了家 |
| 带娃现场 | 谁冲奶、隔代争喂、接送、满月抓周 | 留给奶奶还是带去厂 |
| 家里器物 | 寻呼机→小灵通→诺基亚、第一台电脑、点读机他们买单 | 机是学习用的 |

## 质量下限（不达标就重写这一张）

- 每张 **600–1000 汉字**（只数 `[\u4e00-\u9fff]`）。低于 500 视为目录。
- **一部深挖**。禁止「加班/月供/奶粉」糊成一段生活年鉴。
- 必须有玩法：怎么付、怎么换、怎么值夜班、怎么在门口等。不能只写物件名。
- 有价钱或等价（几天工资）。没有公开数字写「口述、待核」。禁止编民调。
- 分龄四格写全。城乡至少两种。
- 每张只留 **一段**「现场」。禁止「再写一层 / 还要一层 / 补一句」叠同义反复。
- 现场只写手、嘴、钱包、班上、城乡、价钱。禁止把「禁止写成……」写进现场。
- 感官要有动作（拉环、倒油、盖章、打卡），不要词单。

## 字段（必须写全）

```text
### P-YYYY-NN 标题

**时间** …｜**落在哪** 家里灶 / 家里钱包 / 家里房与路 / 自己班上 / 带娃现场 / 家里器物｜**谁家有** 城 / 县 / 乡 / 外出把孩子留下

**事实核**：年份、价格或等价、出处 URL 或待核。和儿童库的分工一句说清。不要挂钩新闻标题。

**00后父母当时怎么过**：（表）1970 / 1975 / 1980 / 1985 四格

现场：一段。手、嘴、钱包、班上、城乡、价钱、两套过法。

**00后父母现在怎么提**：事后记忆。哪些被短视频说滥，哪些城乡不同。

**当时广告 / 单位 / 生活版怎么说**：广告词、车间通知、超市海报。不是新华社。

**当时家里怎么说**：至少三种声音（妈、爸、老人、车间、售楼处等）。

**同事邻居和其他说法**：跟风、假货、谁家先有。没有写「未见公开争论」。

**父母自己的一对词**：A vs B。

**感官钩子**：四个带动作的。

**会吵什么**：一个具体选择。

**和孩子 / 育儿的接口**：钩子一句 + `详见儿童库` 或 `详见育儿专篇`。没有写「无」。
```

卡号：年份篇 `P-2000-01` 起；育儿专篇 `EP-01` 起。不要和儿童库 `C-` / `E-` 混号。

## 育儿专篇（硬规则）

年份篇禁止展开：排名、小升初操作、奥数杯赛流程、联系本怎么签、点读机好不好使。

「考完去肯德基」「作业写完才能玩」在年份篇只许钩子一句 + `详见育儿专篇`。

点读机 / 文曲星 / 好记星：年份篇只写谁买单、广告、壳有多重；按着点、黄冈海淀、报班进 `育儿.md`。

儿童库的 `考试.md` 写孩子的身体和嘴。本库育儿专篇写**付钱的人、门口等的人、改作文的人**。不要两套抄成一段。

## 绝对不要写

**社会新闻、国家大事、灾难、案件、宏观，全部禁止**，包括但不限于：

千年虫、西部大开发、申奥、入世、911、十六大、孙志刚、非典、伊拉克、神五神六、阜阳大头娃娃当公共事件、海啸、马加爵、反日游行、农业税、黑砖窑、华南虎、股市、纸馅包子、汶川、火炬、抵制家乐福、三鹿当公共事件、金融危机、甲流、阅兵、躲猫猫、李刚、3Q、谷歌、富士康、玉树舟曲、世博当国家工程、校园案。

看见就删。不许用「客厅漏音 / 倒醋 / 捐压岁钱 / 换罐打假」把它们塞回来。

**也不要**：

- 把儿童库主卡再写一遍（旺仔玩法、喜羊羊开播、摩尔小屋、赛尔仓）。
- 把祖辈写成主角（单位退休、偏方、麻将馆主卡）。
- 把 80 后大学、网吧通宵、魔兽公会安成 00 后父母的日常——主体是带娃和上班的人。
- 微信、短视频现场、外卖日常、移动支付、全班 iPhone、高铁日常化、平板学习机、海淀鸡娃成熟期、拼多多。
- 同一物件两年各开一张同角度主卡。分年分角度必须换手：2004 月供第一次进门 ≠ 2009 月供加码；日常换罐 ≠ 打假新闻。

福娃、海宝如果要写，只许写成手里的毛绒、文具店货架，不许写成奥运 / 世博报道。写不稳就不要写。

## 年代铁律（和已有研究打架时，以已有研究为准）

1. 营养快线 **2004 上市**。2003 卡须写清多数柜还没有。
2. 奶粉只写家里哪罐、谁冲、多少钱。禁止写成打假新闻。日常罐和后来换进口罐是两张生活卡，不要糊成「奶粉事件」。
3. 月供当家里账：2004 前后才常见进门，2009 才有人加码。不要 2001 年就全员还贷。不要写成房价社论。
4. 肯德基 / 麦当劳是奖赏不是主食。先核这座城这年有没有店。
5. 上好佳是菲律宾品牌。梦龙不当日常。
6. 通讯：寻呼机尾巴 → 小灵通 → 诺基亚按键。触屏十年末轻轻出现，禁止全班 iPhone。
7. 电脑：城镇百户拥有量 2000 约 9.7、2009 约 65。禁止 2003 年家家宽带。装电脑 / 宽带的口头禅常是「给孩子学习」。
8. 摩尔 2008、赛尔 2009、洛克 2010。父母卡只写点卡钱，不写小屋玩法。
9. 喜羊羊 2005 开播、2008 才满街。父母卡最多写「文具店门口一片黄」。
10. 点读机中后期广告；好记星约 2004 砸央视；so easy 女孩是 **2009**。平板不属于这十年。
11. 家电下乡：2007 试点，2009 前后才进更多村。不要提前写成全乡换冰箱。
12. 怀旧短视频只作线索，不作年代依据。禁止编民调、编不存在的引言。

## 工作流

用户没指定年份时，从缺的一年开始，一次一年。用户说「只写 skill / 先别写正文」，停在本文件，不要落盘事件。

```text
读 decade-table.md
→ 读该年对应的物质研究
→ 对照总表勾本年深挖（只点名的不准再开主卡）
→ 联网核年份 / 价格 / 进哪一层城市（核生活，不核新闻）
→ 写 6–8 张主卡进成品目录（至少 5 张，必须有家庭也有自己班上）
→ 单年自检
→ 十一年写完再写 育儿.md
→ 总检（只检查，用户没要求就不重写）
→ 用户要求时才写 00-索引.md
```

**成品目录**（已定，不要另开无关文件）：

`content-intelligence/research/events-00后父母视角/2000.md` … `2010.md`，`育儿.md`，`00-索引.md`。

文件头先写这一年 1970 / 1975 / 1980 / 1985 各站在哪，再写「这一年父母家里和班上已经有的」胶囊，再写主卡。文末：本年不写、和总表对照、待核。

输出完整简体中文 markdown，直接落盘。不要问答体，不要「下面为您整理」。不要改儿童库、社会库、`source-registry.md`、本 skill 自己（除非用户要改 skill）。

## 单年自检

写完一年，先过这张表再停下：

1. 有没有写成新闻、社论、儿童课间？
2. 是否至少 5 张、实际 6–8 张、至少 4 类、有爸线也有妈线、有至少一张自己班上？
3. 有没有低于 500 字，或「再写一层」叠字？
4. 字段是否写全？现场是否一段？
5. 1980 / 1985 有没有被写成全员已育？
6. 有没有偷写育儿制度？搬去育儿专篇。
7. 总表本年深挖是否都落了？别年深挖是否只点名？
8. 留守 / 外出那种家有没有至少出现一次（十年里至少深挖一张电话或春运）？

总检十条和索引要求见 [decade-table.md](decade-table.md)。
