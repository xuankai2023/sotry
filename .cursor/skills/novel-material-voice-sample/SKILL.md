# Novel Material: Voice Sample

## Role

本 skill 只生成正文语气样本。不要写中纲，不要排章节，不要生成完整小说正文。

1200–1800 字只用于诊断叙述口气，不是正式场景的字数标准。用户要写正式第 X 章、正式场景、续写或把章纲扩成正文时，转 `novel-prose-from-outline`；正式正文按项目结构尺度执行并回填 Scene ledger。

若项目文件里有暂名或工作名，只作为当前工程上下文，不把它当成最终书名或唯一适用对象。

语气样本用于测试：这本书落到正文时像不像真实家庭，是否太解释，是否像素材拼贴，心理是否落在动作上。

## Sample Choices

默认可选片段：

1. 林倩把收据折好，准备去接孩子却又被单位叫住。
2. 周桂芳天还没黑就搬塑料凳去门口。
3. 周晓宁听见大人讨论“留下还是带走”，假装在玩。
4. 两个奶奶同时伸勺，孩子先看哪只手。
5. 晚托散场，孩子被接到，但心已经回到屏幕里。

用户没指定时，先选最能测试当前问题的一段。不要一次写五段，除非用户明确要求。

## Writing Constraints

默认约束：

- 1200-1800 字。
- 第三人称限知。
- 一个主场。
- 一口钟。
- 一个主物件。
- 一个主动作。
- 对话 6-12 句。
- 心理描写 0-1 段。
- 结尾落在动作或物件变化上，不要升华。

## Output Template

```markdown
# 正文语气样本：[片段名]

## 样本设定

- 主场：
- 钟：
- 主物件：
- 主动作：
- 限知视角：
- 主要测试：

## 正文样本

[1200-1800 字正文]

## 自检

1. 心理有没有写成动作？
2. 有没有说破主题？
3. 物件意义有没有变化？
4. 对白有没有太解释？
5. 这一段像不像真实家庭，而不是素材拼贴？
6. 是否只守住一个主场、一口钟、一个主物件？
7. 哪一句应该删，因为它像作者在解释？
```

## Voice Rules

- 不仿名家腔，只用家庭现实主义的看法。
- 句子不要过度漂亮，优先让动作准确。
- 成人可以复杂，孩子不能假懂。
- 不要在正文里说“他被爱压住了”，要写他如何不接话、如何看门缝、如何说“还行”。
- 不要让结尾总结主题。结尾只改变一个动作、一个物件位置或一句话的重量。

## Quality Gate

生成后检查：

- 正文不是大纲扩写。
- 没有解释人物设定。
- 没有超出孩子年龄的理解。
- 对白没有演讲腔。
- 主物件在开头和结尾的意义有一寸变化。
- 读者能从动作看出心理，而不是被作者告知心理。
