# Novel Material: Psych Action

## Role

本 skill 只生成人物心理动作材料。不要写中纲，不要排章节，不要写完整正文。

若项目文件里有暂名或工作名，只作为当前工程上下文，不把它当成最终书名或唯一适用对象。

核心任务：把心理词翻译成可见动作。心理必须落在手、纸、碗、门、听筒、收据、塑料凳、书包、灯、路线和沉默上。每人必须带 `novel-thought-ground` 三栏：思想、人物变化、背景变化。只交动作清单、不写变化，退回。

如果用户只要求本库，不要转 `novel-chapter-structure`，也不要拆章。性格和身世以 `novel-character-craft` 与 `番茄/00hou-sandai/中纲/人物志/` 为准；本库只把已立住的心理落成手，不另造人。

## Core Rule

不要写：

- “林倩很愧疚”
- “周桂芳害怕被抛下”
- “周晓宁渴望自由”

要写：

- 林倩把收据对折，又展开，最后塞进包最里面那层。
- 周桂芳天还没黑就把塑料凳搬到铁门边，抹了两遍凳面。
- 周晓宁先说“还行”，再把门带上，只留一条灯缝。

## People

必须覆盖：

- 周晓宁
- 林倩
- 周桂芳
- 赵玉梅
- 周建军
- 周志刚
- 钱厚德

内圈三人材料最多：周晓宁、林倩、周桂芳。中圈只做镜子，不另开主线。

## Quality Gate

生成后检查：

- 每个人至少有 1 个“有用但伤人”的动作。
- 每个人至少有 1 个“爱里带债”的动作。
- 每个人至少有 1 个“嘴上说小事，手上露真心”的材料。
- 没有使用“原生家庭、创伤、控制欲、焦虑、缺爱”等标签代替描写。
- 没有把孩子写成早熟哲学家。
- 每个人都有思想、人物变化、背景变化三栏，且变化落在手上。

## Default Prompt

```text
请为当前小说工程或我指定的小说，生成人物心理动作库。

禁止写中纲，禁止安排章节，禁止写完整正文，禁止大段心理剖析。

请把周晓宁、林倩、周桂芳、赵玉梅、周建军、周志刚、钱厚德的心理，全部翻译成动作、物件、沉默、路线和口头禅。

核心主题：
他们都在爱孩子，但没有一个人只是在爱孩子。

要求：
1. 内圈三人写得最细：周晓宁、林倩、周桂芳。
2. 每个人都要有“他说自己想要什么 / 真正怕什么 / 不敢承认什么 / 不能直接写什么 / 应该写成什么动作”。
3. 每个人至少给 12 条可直接写进正文的动作材料。
4. 心理必须落在手、纸、碗、门、听筒、收据、塑料凳、书包、灯、路线和沉默上。
5. 不要用抽象词总结，要给具体动作。
```
