# Novel Chapter Structure

本 skill 位于中纲与文章包之间，只管大章纲和场卡。全书方向走 `novel-master-outline`；部分总结走 `novel-mid-outline`；人物性格与身世走 `novel-character-craft`；描写层走 `novel-thought-ground`；完整正文走 `novel-prose-from-outline`。大章纲必须写出本章/本场三栏，不能只排场序。

先判断用户要的是**大章纲、场卡还是正文**，再路由。一次只走一个主风格。

## 四层尺度

对 00 后三代现行工程，先读 `番茄/00hou-sandai/中纲/00-全书结构.md`。默认尺度：

- **部**：全书六部，控制生命阶段和总转折。
- **大章**：全书 18 个，每部 3 个；每章 5–7 场，必须完成一次不可逆关系转折。
- **场**：一个限知视角、一个主场、一口钟、一个主物件、一个主动作、一次状态变化。
- **正文**：按场写，按日落盘。每个正文 md 听该书日更（《差不多》7000，00 后 6000），一天一个文件。写后回填 `scene-ledger.md`。

一房、一钟、一物、一动作约束的是**场**，不是一两万字的大章。  
不可逆约束的是**大章**；单场只需改变人物知识、误会、物件归属、答话长度、路线或关系账。

## 分工

| Skill | 作用 |
|---|---|
| `novel-workflow` | 先整体后局部的节点顺序 |
| `novel-master-outline` | 全书总纲、六部走向、18 大章骨架 |
| `novel-mid-outline` | 中纲：一部或一段大章的总结 |
| `novel-style-*` | 某风格的全书看法，不写具体场 |
| **本 skill** | 划分大章与场卡，检查因果和三圈 |
| `novel-chapter-*` | 按单一风格写大章纲或具体场卡，不写正文 |
| `novel-character-craft` | 性格、身世、手、嘴、年段；总纲人物志与中纲本章人物 |
| `novel-character-change` | 总纲/中纲：性格变化合同；大章只继承，不另起弧光 |
| `novel-thought-ground` | 描写层：思想、人物变化、背景变化 |
| `novel-fine-outline` | 细纲：把场卡拆成拍，按日切开 |
| `novel-article-assemble` | 某人遇见什么；抄三栏；不写正式正文 |
| `novel-prose-from-outline` | 按照中纲、细纲、场卡写正文、批注校验、回填状态账 |
| `novel-material-*` | 补特定材料，每条带三栏；不排章、不写完整正文 |

## 路由门

1. 用户要全书方向、主题、六部结构：转 `novel-master-outline`。
1.5. 用户要中纲 / 部分总结 / 部纲 / 这一部怎么收：转 `novel-mid-outline`。该部分中纲未齐时，先补中纲再排场卡。
2. 用户要「第 X 大章怎么安排」「章纲」「场卡」「谁上场」：留在本 skill，随后进入一个 `novel-chapter-*`。已写章看文章包主风格；00 后三代大章 1–6 及后文默认 `novel-chapter-family-realism`。
2.5. 用户要「细纲」「把场卡拆成拍」「日更怎么切」：场卡齐后转 `novel-fine-outline`。场卡未齐先补场卡。
3. 用户要「怎么写第 X 章」「按架构拼这一篇」「开写包」「材料怎么拼进这一章」：转 `novel-article-assemble`。
4. 用户要「写第 X 章正文」「续写」「扩写成正文」「改这一章正文」：先确认中纲、场卡、细纲都在，再转 `novel-prose-from-outline`。场卡未齐先补场卡；细纲未齐先转 `novel-fine-outline`。文章包不是正文入口。
5. 用户只要心理动作、物件、场景、潜台词等素材：先转 `novel-thought-ground` 补三栏，再转对应 `novel-material-*`，不要顺手排章。
6. 用户要「人物性格 / 身世 / 人物志 / 人设」：转 `novel-character-craft`。中纲里的人仍按该 skill 写，不要只排物件。
6.5. 用户要「性格变化 / 人物弧光」或正在写总纲/中纲的人物变化：转 `novel-character-change`。
7. 用户要思想落地、单场人物变化、背景变化：转 `novel-thought-ground`。中纲场卡必须抄三栏。
8. 用户说「第 X 章」但没说大纲还是正文：从上下文判断；仍然会改变交付物时只问这一项，不连问风格和长度。
9. 用户要工作流 / 思维导图 / 先整体后局部：转 `novel-workflow`。

## 三圈人物

### 内圈 · 扛戏

周晓宁、周桂芳、林倩。大章的不可逆必须落在这三人之一或两人关系上。

### 中圈 · 镜子

赵玉梅、周建军、周志刚、钱厚德。上场是为了照出内圈缺口：娘家资格、本市缺席、规矩、手上的爱。可以扛一场，不能另开一套十年发动机。

### 外圈 · 社会网

亲朋、邻里、同事、同学、老师、门卫和摊贩让私人选择拥有社会压力。外圈必须像活人，但只点火，不另开主线。

- **楼里 / 门口：** 同楼退休姐妹、热心越界的邻居。给桂芳递比较，给满月酒和铁门造观众。
- **班上 / 家长：** 林倩的同事、爱问排名的家长、建军厂里一个搭班。逼出假条、面子、信封。
- **孩子身边：** 一个一起玩的、一个会比零花的；入学后再加班主任、校门口冰柜。让晓宁的乖和撤退有人看见。

外圈节奏：

- 每个大章至少有两次外圈或社会规则进入。
- 单场不强制出现外圈真人；电话、通知、班表、旧话也可携带外压。
- 连续两场可以无外圈，第三场必须让单位、学校、邻里、亲戚或公共规矩进入。
- 外圈离场后，座位、钟、纸、门、物件归属或内圈做法必须变一点。

## 大章必须有的七件

1. 一个具体问题，不是「表现亲情」。
2. 5–7 场因果相连，不能按年份并排。
3. 至少一个选择场和一个后果场。
4. 内圈承担不可逆，中圈只照缺口。
5. 至少两次社会压力进入。
6. 章末产生下一章不得不接的新问题。
7. **本章人物**：限知与主要对手各有进章状态、身世一寸、手、嘴；章末性格只挪一寸。模板见 `novel-character-craft`。
8. **本章思想**：一句具体问题，不是「表现亲情」。写法见 `novel-thought-ground`。
9. **人物变化**：进章谁 → 章末谁，差在手、嘴、路线。
10. **背景变化**：屋里谁有权、哪样东西、外压哪句变了。
11. **松紧位置**：至少标出一场喘息或余波，让照顾、快乐、安稳或合作先真实成立；不是每场都压迫、证明和点题。

## 场卡必须有的十件

1. 上一场直接结果。
2. 一个限知视角。
3. 一个具体即时欲望。
4. 一个主场或明确的两头结构。
5. 一口钟。
6. 一个主物件及其出现次数。
7. 一个主动作或小选择。
8. 一次状态变化。
9. 下一场的新问题。
10. 身世本场只露；声音差（遮住姓名仍能分开两个人）。
11. 思想一寸（本场落地的问题）。
12. 人物变化（进场 / 出场，可见证据）。
13. 背景变化（进场 / 出场，可见证据）。

因果句必须能补完整：

> 因为上一场发生了【结果】，所以【人物】现在必须【行动】；他原想【欲望】，却被【阻力】挡住，于是做了【选择】，导致【状态变化】，逼出下一场的【问题】。

只写「到了第二年」「后来又发生」，不算因果。

## 工作流

```
章节结构 Progress:
- [ ] 1. 判断交付物：大章纲 / 场卡 / 细纲 / 文章包 / 正文
- [ ] 2. 对齐部、大章和场号
- [ ] 3. 写清上一场结果与下一场问题
- [ ] 4. 排内圈、中圈和社会压力
- [ ] 5. 读 novel-character-craft，写本章人物与场卡声音差
- [ ] 6. 锁视角 / 房间 / 钟 / 物件 / 动作 / 状态变化
- [ ] 6.5 写思想一寸、人物变化、背景变化（见 novel-thought-ground）
- [ ] 6.6 安排本章松紧：选择场、后果场、喘息 / 余波场各自承担什么
- [ ] 7. 选择一个主风格，进入对应 novel-chapter-*
- [ ] 8. 场卡齐后写细纲转 novel-fine-outline；拼「这一篇怎么写」转 novel-article-assemble；写正文再转 novel-prose-from-outline
```

### Step 1 · 判断尺度

- 大章纲：先列 5–7 场及不可逆。
- 场卡：只做一场，不扩成正文。
- 细纲 / 把场卡拆成拍：转 `novel-fine-outline`。
- 怎么写这一篇 / 拼材料：转 `novel-article-assemble`。
- 正文：必须已有细纲、文章包或场卡；无材料库且无细纲则先转 `novel-fine-outline`；有材料库且无文章包则先转 `novel-article-assemble`。

### Step 2 · 对齐状态

00 后三代必须读取：

- `番茄/00hou-sandai/story-bible.md`
- `番茄/00hou-sandai/中纲/00-全书结构.md`
- `番茄/00hou-sandai/scene-ledger.md`
- `番茄/00hou-sandai/中纲/人物志/`
- 已有相关中纲或场卡
- `../novel-character-craft/SKILL.md`

不得从 archive 拼回旧主线。

### Step 3 · 风格路由

- 家庭现实主义 → `novel-chapter-family-realism`
- 市民日常 → `novel-chapter-urban-daily`
- 心理债务 → `novel-chapter-psychological-debt`
- 克制留白 → `novel-chapter-restrained-hands`
- 劳动社会 → `novel-chapter-labor-social`
- 批判现实 → `novel-chapter-critical-realism`
- 冷叙荒诞 → `novel-chapter-cold-absurd`
- 温柔成长 → `novel-chapter-warm-growth`

未指定风格时，00 后三代默认 `novel-chapter-family-realism`。

### Step 4 · 结构门

退回重排的情况：

- 一场里跳两个限知视角
- 把大章不可逆提前塞进第一场
- 每场都让外圈进门说一句
- 只有材料，没有人物即时欲望
- 物件第一次出现就解释完末次意义
- 场末没有状态变化
- 下一场与本场可以任意对调
- 大章纲没有本章人物，或场卡没有身世露出和声音差
- 大章纲或场卡没有思想、人物变化、背景变化三栏
- 主要人物对白可以互换
- 场序对了就当合同齐；限知 / 钟 / 主物件 / 帮与伤未锁
- 主物件只被碰到，真正挪位置的是另一件物
- 一场里另开第二主场
- 状态变化只写作者判断，手和物上没有可见证据
- 五场全是重压和证明，没有喘息或余波，导致正文只能越写越密
- 每场都安排强物件点题，没有哪一场让人物的办法先真实好用

专业合同见 `novel-workflow`。场序对了不要直接开写。

本 skill 不写完整正文。场卡通过后，先交给 `novel-fine-outline` 写细纲；有材料库再交给 `novel-article-assemble` 拼文章包。正式正文交给 `novel-prose-from-outline`。

新闻辫状样本不要当发动机。
