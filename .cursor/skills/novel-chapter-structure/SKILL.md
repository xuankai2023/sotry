# Novel Chapter Structure

这不是大纲 skill。全书总纲走 `novel-master-outline` 和 `novel-style-*`。本 skill 只在写**具体章节**时用。

先定结构，再进对应风格的章节大纲 skill。一次只走一个风格。

## 分工（不要混）

| Skill | 作用 |
|---|---|
| `novel-master-outline` | 全书总纲 / 大段中纲 |
| `novel-style-*` | 某风格的全书总纲。已有，不要改，不要在这里重写总纲 |
| **本 skill** | 单章怎么立住：房间、钟、三圈人、不可逆 |
| `novel-chapter-*` | 某风格的**具体章节大纲**工作流 |

用户只要总纲：停，转大纲 skill。  
用户要第几章、章纲、这一章谁上场：从本 skill 做完第 1–3 步，再进一个 `novel-chapter-*`。

## 你对的，我对的

写进结构，后面每章都按这个用人。

**你对的：**  
长篇市民家庭不能只围着家里几口转。亲朋好友、邻里、同事、同学必须进场。满月谁来随、门口谁比较孙子、班上谁问第几、幼儿园谁抢铁门，都是生活本身。没有这圈人，面子、收据、察言观色都悬空。哪个大师写三十万字单位楼，也不会让三个人在厨房里完成一部长篇。少的是扛主线的人，不是出场的人。

**我对的：**  
扛主线的人仍然只能三四个。亲朋好友要有名字、有一句口头禅、有一次具体出手，但没有自己的十年弧光。不要把画像库里每种性格都开成主线。路遥人再多，发动机还是少安少平；王安忆弄堂再密，命运还是王琦瑶的。

两句合成一条规矩：**外圈必须有活人，内圈才能扛戏。**

## 三圈人物

### 内圈 · 扛戏

周晓宁、周桂芳、林倩。  
一章的不可逆，必须落在这三个人的关系上。

### 中圈 · 镜子

赵玉梅、周建军、周志刚、钱厚德。  
上场是为了照出内圈缺口：娘家资格、本市缺席、规矩、手上的爱。不要给他们另开十年。

### 外圈 · 社会网（每章至少一人进场或在门口说话）

不是每章把外圈写全。一章只用能压这一章的人。

- **楼里 / 门口：** 同楼退休姐妹、热心越界的邻居。给桂芳递比较，给满月酒和铁门造观众。
- **班上 / 家长：** 林倩的同事、爱问排名的家长、建军厂里一个搭班。逼出假条、面子、信封。
- **孩子身边：** 一个一起玩的、一个会比零花的；入学后再加班主任、校门口冰柜。让晓宁的乖和撤退有人看见。

娘家再留一个偶尔来的舅或姨就够。不要再添一整支亲戚团。  
外圈的人走了，屋里关系必须变一点。只来串门、不留下压力的，删掉。

## 一章必须有的四件

1. **一个房间**（或门口、听筒这两头）。不要一章换三个场。
2. **一口钟**。从几点到几点，或从一顿饭到下一趟班。
3. **一次不可逆**。章末有一种关系回不到原样。
4. **三圈里各有位置**：内圈谁扛，中圈谁照，外圈谁递一句或伸一次手。

不要用「体现时代」「表现亲情」当章任务。

## 工作流

复制并勾进度：

```
章节结构 Progress:
- [ ] 1. 确认是写具体章节，不是重写全书总纲
- [ ] 2. 锁一章：年 / 房间 / 钟 / 不可逆落在谁身上
- [ ] 3. 排三圈：内圈谁扛，中圈谁照，外圈谁进门（至少一人）
- [ ] 4. 选定一个风格，只进对应 novel-chapter-*
- [ ] 5. 不要回头改 novel-style-* 总纲 skill
```

**Step 1**  
若用户在要全书方向、八套总纲、一句话主题：转 `novel-master-outline` 或 `novel-style-*`，本 skill 停。

**Step 2**  
写下：这章在哪、从什么钟到什么钟、章末哪句关系回不去。缺一项就还没立住。

**Step 3**  
内圈点名。中圈能不上场就不上，上场必须照缺口。外圈点一个名字和一句作用。没有外圈，退回补人。

**Step 4** 风格路由（只选一个）：

- 家庭现实主义 → `novel-chapter-family-realism`
- 市民日常 → `novel-chapter-urban-daily`
- 心理债务 → `novel-chapter-psychological-debt`
- 克制留白 → `novel-chapter-restrained-hands`
- 劳动社会 → `novel-chapter-labor-social`
- 批判现实 → `novel-chapter-critical-realism`
- 冷叙荒诞 → `novel-chapter-cold-absurd`
- 温柔成长 → `novel-chapter-warm-growth`

未指定风格时，00 后三代默认 `novel-chapter-family-realism`。

**Step 5**  
本 skill 不产出章纲正文。章纲由 Step 4 那个 skill 按它的工作流写。
