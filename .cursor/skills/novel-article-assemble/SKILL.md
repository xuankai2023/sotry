# Novel Article Assemble

把现行架构和材料**拼成一篇具体小说内容的开写包**。不重写全书总纲，不改冻结矩阵，不生产新材料库，不写 6000 字正式正文。

正式正文走 `novel-prose-from-outline`：按照中纲、细纲、场卡写，不准只凭本包开写。

## 在链路里的位置

```text
novel-workflow                           先整体后局部的节点顺序
novel-master-outline / novel-style-*     全书方向，不写这一篇
novel-mid-outline                        中纲：该部分总结
novel-chapter-structure + novel-chapter-* 大章纲 / 场卡结构
novel-fine-outline                       细纲：按日切开、每拍手物嘴
novel-thought-ground                     思想、人物变化、背景变化
本 skill                                 某人遇见什么；抄三栏
novel-prose-from-outline                 按照中纲、细纲、场卡写正文 + 批注校验
novel-material-*                         只补材料，每条带三栏，不排章
```

用户要「第 X 章怎么安排 / 谁上场」且还没有场序：该部分中纲未齐则先 `novel-mid-outline`；再 `novel-chapter-structure`，回本 skill 拼包。  
用户要细纲 / 把场卡拆成拍：转 `novel-fine-outline`，不要用本 skill 冒充细纲。  
用户要「写第 X 章正文 / 写某一场」：该部分中纲未齐则先 `novel-mid-outline`。场卡未齐先补场卡。无细纲先 `novel-fine-outline`。再转 `novel-prose-from-outline`。正文必须再打开本部分中纲、本场场卡和细纲，不准只凭本包开写。  
用户只要心理动作、物件、场景：转 `novel-material-*`。  
用户要性格 / 身世：转 `novel-character-craft`；本包必须抄本场露出，不许只写物件。  
本包必须写清**某人遇见什么具体事情**，并抄 `novel-thought-ground` 三栏：思想、人物变化、背景变化。只交场序、指不回三栏，退回描写层。

材料不是参考，是必开。文章包里登记的事件卡、画像、心理动作、场景、词库，装配时必须真正打开对应文件，记下抽了哪几条功能。只写卡号不打开，退回。

00 后三代未指定风格时，默认家庭现实主义。一次只挂一个主风格。

## 本 skill 不做

- 不改 `中纲/01-第一二部-场景矩阵.md` 等三份冻结矩阵
- 不对全书矩阵再跑六维复核
- 不从 `archive/` 拼回旧主线
- 不把新闻辫状样本当发动机
- 不整包搬运材料库「可入正文」原句
- 不把文章包冒充正式章节正文
- 不预先创建空的 `正文/` 目录

## 工作流

```text
文章装配 Progress:
- [ ] 1. 锁定目标：哪一部、哪一章、一场还是整章
- [ ] 2. 读架构真源，核对冻结与连续性
- [ ] 3. 从矩阵抽出本章因果，不改矩阵
- [ ] 4. 按一个 novel-chapter-* 把核心场补成正式场卡
- [ ] 5. 按预算抽材料：必须打开事件卡、画像、风格材料、描写卡，记下功能
- [ ] 5.5 读 novel-character-craft 与中纲人物志，写入本场人物功能
- [ ] 5.6 抄思想落地三栏，写成「某人遇见什么事」；缺则退回 novel-thought-ground
- [ ] 6. 写出文章包：章问题、场序、场卡、材料功能、人物功能、禁写、起笔、遇见、三栏
- [ ] 6.5 补写作合同：场内节拍、帮与伤、声音差、收束；见 [craft.md](craft.md)
- [ ] 6.6 标出本章松紧和密度预算：哪一场喘息，哪一场少物件、少解释、让生活先成立
- [ ] 7. 过装配门；用户要正文再交风格内容 skill
```

### Step 1 · 锁定目标

从用户话里取出大章号或场号。没说时，00 后三代默认**大章 1**。

一次只拼：

- **整章包**：5–7 场因果 + 每场场卡要点 + 全章禁写
- **单场包**：一场的完整场卡 + 本场材料预算 + 起笔

不要五场一起写成正文。

### Step 2 · 读架构

必读顺序和冲突优先级见 [architecture-map.md](architecture-map.md)。

最低限度：

1. `番茄/00hou-sandai/README.md`（含当前冻结）
2. `番茄/00hou-sandai/story-bible.md`
3. `番茄/00hou-sandai/中纲/00-全书结构.md`
4. `番茄/00hou-sandai/中纲/部分/` 覆盖该部的中纲（没有则先转 `novel-mid-outline`）
5. 目标大章所在场景矩阵
6. `番茄/00hou-sandai/scene-ledger.md`

`中纲/01-05.md` 只作第一部锚点对照。和矩阵打架时，以矩阵和 `story-bible.md` 为准。

发现硬设定互相打架、下一场无法发生、限知会逼正文跳头、年代制度落不了地：只修被点名的那一项，修完即停。其余一致性问题写进文章包的「开写时再碰」，不顺手改矩阵。

### Step 3 · 抽出本章合同

从全书结构和矩阵抄出，不要发明另一套场序：

- 大章问题
- 起始状态 / 目标不可逆
- 主要限知（本章最多两个；满月等群像特例三个，一场内部不跳）
- 张力波形（与上一章不同）
- 社会压力至少两次
- 5–7 个核心场：限知、主场钟、主物件、欲望、阻力、选择、状态变化、接下场
- 禁止提前写出的后段意义

补完整因果句：

> 因为上一场发生了【结果】，所以【人物】现在必须【行动】；他原想【欲望】，却被【阻力】挡住，于是做了【选择】，导致【状态变化】，逼出下一场的【问题】。

只能写成「到了第二年」「后来又发生」，退回结构层，不要靠材料硬写。

矩阵「状态变化」若仍是规划语或非限知内心，转场卡时改成可见动作。不要因此回头润色整份矩阵。

### Step 4 · 场卡

场卡九件和三圈规则跟 `novel-chapter-structure`。  
场卡口气跟一个 `novel-chapter-*`，模板见该 skill，不要八套混用。

| 主风格 | 场卡 skill | 风格总纲 | 材料目录 | 描写卡 |
|---|---|---|---|---|
| 家庭现实主义 | `novel-chapter-family-realism` | `风格总纲/01-家庭现实主义.md` | `小说材料库/按风格拆分/01-家庭现实主义/` | `描写手法调用库/01-家庭现实主义.md` |
| 市民日常 | `novel-chapter-urban-daily` | `02-市民日常.md` | `02-市民日常/` | `02-市民日常.md` |
| 心理债务 | `novel-chapter-psychological-debt` | `03-心理债务.md` | `03-心理债务/` | `03-心理债务.md` |
| 克制留白 | `novel-chapter-restrained-hands` | `04-克制留白.md` | `04-克制留白/` | `04-克制留白.md` |
| 劳动社会 | `novel-chapter-labor-social` | `05-劳动社会.md` | `05-劳动社会/` | `05-劳动社会.md` |
| 批判现实 | `novel-chapter-critical-realism` | `06-批判现实.md` | `06-批判现实/` | `06-批判现实.md` |
| 冷叙荒诞 | `novel-chapter-cold-absurd` | `07-冷叙荒诞.md` | `07-冷叙荒诞/` | `07-冷叙荒诞.md` |
| 温柔成长 | `novel-chapter-warm-growth` | `08-温柔成长.md` | `08-温柔成长/` | `08-温柔成长.md` |

只读一张风格总纲作方向，不扩成新总纲。  
大章不可逆必须落在晓宁、桂芳、林倩之一或两人关系上。

### Step 5 · 抽材料

规则和年份对照见 [material-budget.md](material-budget.md)。

原则：材料只提供**功能**（手怎么动、物在哪、外压哪一句），正文 skill 必须重写句法。

每场最多：

- 事件库：本年父母卡 1 张、祖辈卡 0–1 张、儿童卡 0–1 张；只取现场钩子，不搬 600 字主卡
- 画像：限知人物 1 张，对手最多再 1 张
- 风格材料：心理动作 2–3 条，关系 1 组，物件当前阶段，场景站位 + 一声一触，潜台词功能 6–12 句
- 描写：先 `长篇-描写总谱.md`，再一张风格卡；事物名词只开 1 个分文件
- 词库：只开 1 个分文件，抽 2–4 个词

禁止：八套风格材料混读；把「可入正文」整句写入文章包当成品句；为展示材料加场。

缺材料时在文章包里写「缺什么、哪张卡缺」，不要顺手新造事件库。用户要补库再转 `novel-material-*` 或 `events-00hou-*`。

### Step 6 · 交文章包

按 [article-pack.md](article-pack.md) 输出。必须让下一手内容 skill 能直接开写，不必再猜场序。

文章包要写清：

1. 这一篇的具体问题，不是「表现亲情」
2. 场与场为何不能对调
3. 每场一个主物件、一口钟、一个小选择
4. 从哪几张旧材料取功能（必须写出打开了哪个文件、抽了哪条功能）
5. 本场人物功能：身世一寸、手、嘴；见 `novel-character-craft`
6. 本篇绝对不能提前写的后文
7. 第一场从哪个正在发生的动作起笔
8. 每场 5–7 个节拍、帮与伤、声音差、收束动作
9. 某人遇见什么具体事情（不是主题句）
10. 本场思想、人物变化、背景变化三栏，且能被第 9 项碰到
11. 本章松紧预算：至少说明哪一场让照顾、快乐、安稳或合作先成立；哪几处主动少用物件链和段尾解释

只交结构、不交第 7 项，正文写得出「对的大纲腔」，写不出好文章。写法见 [craft.md](craft.md)。本 skill 仍然不写 6000 字正文。三栏空着或遇见指不回三栏，退回 `novel-thought-ground`。

### Step 7 · 装配门

任一为真，退回重拼，不要交给正文 skill：

- 场序与冻结矩阵核心场对不上，又不是用户点名的阻断修补
- 缺即时欲望、阻力、选择或状态变化
- 一场两个限知
- 大章不可逆被塞进第一场写完
- 物件第一次出现就被解释完末次意义
- 抽了后一大章的锚点（勺、空椅子、加床、听筒、IC 卡等）到本章
- 文章包里出现材料库完整原句当「正文示范」
- 把已写日更或通读整段贴进包里当「可直接写」（功能可回声，原句不能搬；见 `novel-chapter-prose/cannot-copy.md`）
- 写成主题论文或材料清单
- 场卡没有 5–7 个节拍，或节拍只是同一选择换说法
- 主要人物缺「帮」或缺「伤」的可见动作
- 没有声音合同、好/坏起笔对照、未解释的收束动作
- 材料只写了卡号，没有打开文件抽出功能
- 没有本场人物功能，或声音合同只写「家庭现实主义」五字
- 两个人物的嘴可以互换
- 没有「某人遇见什么事」，或遇见只是主题句
- 没有思想、人物变化、背景变化，或三栏与遇见对不上
- 场序对了就当包齐；主物件只被擦到、真正挪位的是另一件物；或一场另开第二主场
- 状态变化靠作者宣布，手和物上看不见
- 五场全是压迫、证明、亏欠和物件位移，没有一场让人物的照顾真实好用
- 每场都安排多个强象征物，导致正文只能写成方法展示

专业合同见 `novel-workflow`。细则见 [craft.md](craft.md)。

通过后：

- 用户只要「怎么写」：交付文章包，停。建议下一场先写第 1 场正文。
- 用户要正文：转 `novel-prose-from-outline`。本包不是入口；正文必须再打开中纲、场卡、细纲。
- 用户要求落盘：一大章一个文件夹，写入 `番茄/00hou-sandai/中纲/文章包/大章NN-工作名/`。章头用 `00-大章.md`，每场一份 `场NN-物件名.md`。不要写成单文件长文，不要写进 `正文/`。

## 00 后三代默认

- 发动机：家庭线，不是新闻辫。
- 父亲：本市班与信封，不是广东长线打工。
- 满月：林倩在产假，换班压力在建军。
- 住房：同一套二室一厅单位房。
- 晓宁 2000 年只有身体；2003 才主动删短；2005 才看脸色张嘴。
- 正文路径要等第一场正式开写再创建，见 `novel-prose-from-outline`。
