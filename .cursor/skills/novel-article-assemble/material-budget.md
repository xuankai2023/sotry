# 材料预算

文章包只登记「取哪张卡的哪一种功能」。不把事件卡、材料库整段粘进包里，更不写进正文。

材料必开。文章包登记的每一张卡，装配和正文都必须打开对应文件，抽出功能后重写。凭记忆写卡号、或只读 bible 不打开材料，退回。

## 抽卡顺序

一场只走这一条，不要八库并行：

1. 本章年份的事件索引，再只开点名的那几张主卡
2. 限知人物画像 1 张（需要对手缺口再加 1 张）
3. 主风格材料目录里，按用到的类各抽限额
4. `描写手法调用库/长篇-描写总谱.md` + 一张风格卡
5. 主物件对应的 1 个事物分文件
6. 词不够时，主风格词库只开 1 个分文件

综合材料库 `小说材料库/01`–`09` 只在风格分库不够时补一条。不要风格库和综合库整包对读。

## 事件库

路径：

- 儿童：`content-intelligence/research/events-00后儿童视角/`
- 父母：`content-intelligence/research/events-00后父母视角/`
- 祖辈：`content-intelligence/research/events-00后爷爷奶奶视角/`

先读该库 `00-索引.md` 锁定卡号，再读年份篇里的那一张。禁止把社会新闻库 `linglinghou-decade-one` 当主卡。

只取：感官钩子、会吵什么、当时家里怎么说。  
不取：分龄四格论文、广告史、「现在怎么提」的短视频句。

## 风格材料限额

主风格目录：`番茄/00hou-sandai/小说材料库/按风格拆分/0N-风格名/`

| 库 | 每场 |
|---|---|
| 01 心理动作 | 视角 2–3 条，其他主要人物各 0–1 |
| 02 关系 | 只开本场最主要一组 |
| 03 物件 | 只读该物当前出现阶段，登记「下次不得提前」 |
| 04 场景 | 站位 + 一种声音 + 一种味或触 |
| 05 潜台词 | 6–12 句的功能，不搬整组 |
| 06 外圈 | 0–1 个真人，或纸 / 班表 / 旧话 |
| 07 年代 | 只校验本场会碰到的器物 |
| 08 语气样本 | 只对密度，禁止换人名复用段落 |
| 09 词句 / 词库 | 1 个分文件，2–4 个词 |

文章包里写成：

```text
- 事件：P-2000-07 → 玻璃窗盖章、条上写小孩满月、不求整天
- 心理：建军「洗手/抽烟式回避」→ 本场改成窗口外退半步，不抄原句
- 物件：换班条第 1 次；下次意义（用桌数补班）留给 1-2
```

## 描写卡

1. `番茄/00hou-sandai/描写手法调用库/00-索引.md` 只用来选文件
2. `长篇-描写总谱.md`：年段、节令、物件第几次、单场配额
3. 一张风格卡
4. 需要名词时，环境 / 人物 / 物件事物库各最多开 1 个分文件

大章 1 常见物件分文件：`物件描写-事物/01-纸件账本.md`（换班条、信封、礼簿、返岗纸）。红鸡蛋走食器或满月现场，不要再开通讯、屏幕。
