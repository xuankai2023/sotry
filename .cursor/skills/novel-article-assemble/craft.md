# 文章包怎样才够写好

本 skill 不写 3300 字正文。好文章靠 `novel-prose-from-outline`，按照中纲、细纲、场卡写。  
装配若只交「欲望 / 选择 / 不要写」，正文仍会写成正确的说明书。场卡必须再锁六件：**节拍、帮与伤、声音、收束、某人遇见什么、思想三栏**。三栏见 `novel-thought-ground`。

更专业的地方不在词藻，而在先把一场能写的合同锁死，再动手。场序对了还不够。总控原文见 `novel-workflow` 的「专业合同」。

## 专业过门

任一为真，退回重拼：

- 一场两个限知，或一口钟里另开第二主场（音像柜问价再写客厅，等于两场）
- 主物件只被擦到、抹到，真正换位置的是另一件物（围裙只抹平，动的却是说明书）
- 选择只有帮或只有伤
- 状态变化靠作者宣布（「日常落到谁手里」「纸开始替人到场」），手上、物上看不见
- 五场可以对调
- 只写了材料卡号，没打开文件抽功能；或把「可入正文」原句当成品句
- 思想是口号，换到另一章也不别扭

## 分界

| 有这些，只能算不跑偏 | 有这些，才够开写成篇 |
|---|---|
| 场序对、限知对、物件对 | 3300 字怎么走完，而不是在选择点上打转 |
| 禁写后文锚点 | 每个主要动作既帮人又伤人，两边都看得见 |
| 材料卡号 | 材料已改成连续动作，不是清单 |
| 「从窗口起笔」 | 好 / 坏起笔对照过；收束落在一个未解释的动作 |
| 主题句 | 某人遇见一件具体事；此事能碰到思想、人物变化、背景变化 |

缺后一列，退回重拼，不要交给正文 skill。

## 松紧与呼吸预算

文章包不能只保证「不跑偏」，还要防止正文过密、过硬、方法太显。

整章包必须标出：

- 哪一场是**喘息场**：照顾、快乐、安稳、合作先真实成立，代价延后，不当场解释破。
- 哪一场是**重压场**：钱、班、门、纸或关系账真正压到选择。
- 哪一场是**余波场**：选择后的物件位置和答话变化，不再重复制造新冲突。
- 哪一场主动**少用一个象征物**：只守主物件，其他材料退成背景。

喘息场不是废场，也不是鸡汤。它仍要改变状态，例如：建立期待、让一段路真的好走、让一件物真的好用、让孩子真的舒服一会儿。过门：如果这场删掉后读者仍相信人物彼此有爱，喘息不足；如果这场刚暖起来就立刻被作者解释成债，呼吸不足。

## 场内节拍

一场默认 3300–4000 字，不能只有「进场 → 选择 → 结束」。写成 5–7 个节拍，每个节拍换一件可见的事：

1. **带伤进场**：上一场结果已经压在手上、纸上或钟上
2. **欲望露出来**：他要的是具体的半个班、一桌、一篮蛋，不是心情
3. **阻力进来**：人、钱、班、纸、门里的一样
4. **试一次失败或改小**：原计划缩一寸
5. **小选择**：手先动
6. **当场后果**：物件位置、名单、答话、谁抱着孩子
7. **逼出下一场**：他已经不得不去做下一件，但下一件不在本场做完

节拍不是五段抒情。删掉任一节拍，如果故事还能成立，那个节拍就是注水。

迟爆场把选择放后；早选场把代价放后。不要五场都在中间爆发。

## 帮与伤

每个人物事件必须能改写成一对可见动作，不能停在「他爱孩子也控制孩子」。

```text
帮：【动作】真的解决了【哪件生活事】
伤：同一动作让【谁】失去【位置 / 时间 / 解释权 / 一句没说出口的话】
```

大章 1 对照：

- 建军换到几小时：酒能开席；在场变成班表缺口，后面只能用钱补。
- 家里只摆一桌：客厅不像饭店；同事那头变成必须另送的蛋，林倩看见日期。
- 桂芳蛋篮不换手：席面交得出去；孩子先成为她能带的证明。
- 玉梅补记：娘家当天不矮；两套账开张。
- 林倩不叫醒：孩子被心疼；镜头先摆上桂芳的蛋和锁，她只伸进一只手。

缺「帮」或缺「伤」，人物扁。

## 声音合同

文章包要写本场怎么说话，不要写「家庭现实主义」五个字交差。

锁这几项：

- **句长**：短、手、物；还是日程句；还是更冷的白描
- **叙述句法**：这一场的句子怎样转弯。只换物件、不换句法，不算声音差。
- **对话**：大约几句，说什么家常，真话放在句后哪一下
- **禁用**：主题词、年代开场、心理翻译、材料库标志句、套用「不是 A，是 B」当段尾解释
- **限知耳朵**：只能听见这个人听得见的

家庭现实主义默认：

- 先被看见的是手、衣边、纸、窗，不是表情鉴定
- 一句家常后面跟一个手部动作
- 动作写准后，不跟「他知道这意味着……」
- 同段最多一个「像」
- 外圈一句就走，走后屋里的纸、蛋、座位要变一点
- 声音必须按 `novel-character-craft` 分开：建军最短，桂芳跟篮和锅，林倩跟纸，玉梅跟数字。五场同一种顿挫，声音合同没过。
- 叙述呼吸也要分开：建军按工号、钟点和缺口走；桂芳按数、匀、盖、刮等工序走；林倩按纸、日期和手进不进画面走；玉梅按封、灯、数字和簿角走。
- 「不是 A，是 B」只可作为作者理解关系的草稿，不可当文章包示范句式交给正文套用。好 / 坏起笔、收束对照也不能靠这种句式显得高级。
- 不要让每场都用同一种微动作密度。重压场可以细，喘息场要让句子松一点，允许较长的自然动作和少量未被解释的普通生活。
- 物件链不要过于整齐。主物件必须动，副物件能不动就不动；如果一段同时安排纸、碗、门、灯、包、鞋，删到只剩会改变选择的那一两样。

## 起笔与收束

起笔三行必须让人留下：有人正在做一件来不及解释的事。

坏：`2000 年夏天，江州的单位楼里添了一个千禧宝宝。`  
好：`玻璃窗里伸出一只手。周建军把换班条送进去，又用指头按住，怕被风刮回来。`

收束只做一件事，并且不解释：

- 条被贴进缺口
- 信封按住，座位纸折起来
- 蛋篮换手时收回
- 礼簿翻回正面
- 手进入画面，孩子没醒

禁止用收束宣布「从此他是证据」。

## 材料怎样变成句子

禁止：文章包抄「品红染到指甲缝」当成品句，正文再抄一遍。

允许：

```text
功能：品红在指甲缝
本场用法：桂芳把蛋递给同楼时，指头先在围裙上蹭一下，蹭不掉
下次禁用：再写一遍同一句「指甲缝里的粉」
```

事件卡 600 字里只借一个会吵的选择、一处触感。画像只借一个习惯手势，改成这场房间里的手势。装配时必须打开文件，不能凭记忆写卡号。人物志决定谁会做，材料库决定手怎么做，两边都要。

## 3300 字从哪来

靠节拍里的阻力、试探、改小、选择后的生活后果。  
不靠：轮流写七人内心、年代商品清单、邻居进门点题、同一心理换三个比喻。

扩写只问：这个选择之前还缺哪一层压力？选择之后屋里哪样东西的位置变了？

如果一场已经够重，补字优先补：

- 人物先把事情做成的过程
- 孩子或老人短暂舒服、好玩、安心的一刻
- 选择后的普通余波

不要继续补更多象征物、更多段尾短句、更多「冷 / 热 / 空 / 紧」同义反复。
