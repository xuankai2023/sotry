# 00 后祖辈 · 2000–2010 家庭与带孙事件

这是一份**书写工作流**，不是成品库。一次只写一年。不要一次生成十一年。

**一句话**：只写 00 后爷爷 / 奶奶 / 外公 / 外婆这十年自己家里过的、手里带的。不写小孩课间，不写 70 后加班月供主卡，**不写新闻，不写国家大事**。

判断口诀：要打开新闻联播才能解释？删掉。能用「今晚谁喂 / 退休金本月够不够 / 孩子留给婆家还是娘家 / 麻将去不去 / 电话里报吃了没」写完？留下。

## 写的是谁（写错年龄就是写错人）

00 后的祖辈，这十年主体是 **40 后 / 50 后**，也就是 70 后的父母。不是 70 后本人。

| 祖辈出生年 | 2000 | 2005 | 2010 | 这十年里的位置 |
|------------|------|------|------|----------------|
| 1940 | 60 | 65 | 70 | 40 后前半。城的多已退，乡的仍在地里。身体开始响 |
| 1945 | 55 | 60 | 65 | 40 后后半。城的刚退或将退，乡的还在田 |
| 1950 | 50 | 55 | 60 | 主核。城的可能还在岗或刚退，乡的没有退休 |
| 1955 | 45 | 50 | 55 | 50 后前半。很多人还在上班。未带孙也占格 |

分龄四格必须写全：1940 / 1945 / 1950 / 1955。1955 年生 2000 年 45 岁，未带孙写具体动作（看别人领孙、帮姐带一天），不要假装全员已是爷爷奶奶。

**称谓不要混**：奶奶带的是儿子的孩子，外婆带的是女儿的孩子。每年至少一张**婆家**和一张**娘家**，或同一现场两套过法。每年至少一张**奶线**和一张**爷线**（外公算爷线）。不要写成只有奶奶追着喂。

城乡 / 居住至少两种：城退带孙 / 县城 / 乡留守 / 进城帮带 / 远距一年一面。没有「谁家有、谁家没有」，视为没写完。

每年至少一张**自己的日子**（还在岗、刚退、退休金、麻将、地里），不要十一年只写带孙。

## 什么能进主卡

同时满足至少两条：

1. **手里碰到了**：喂、接、染蛋、灌瓶、接听筒、收椅子、垫钱。
2. **自己口袋碰到了**：退休金、地里收成、红包给孙、帮儿女随、保健品。
3. 儿女 / 另一家老人 / 牌友会跟风或会吵。
4. 后来提起带 00 后的十年，老人还会先说它。
5. **删掉所有新闻还站得住。**

每年至少 **5** 张，必须 **6–8** 张。六类里至少 **4** 类：

| 类型 | 写什么 | 例子（方向） |
|------|--------|--------------|
| 灶上 | 隔夜菜、猪油、年猪、咸淡、追着喂的那一勺 | 糖色谁炒、腊肉谁翻 |
| 钱包 | 退休金、压岁、垫学费、帮儿女随份子、保健品 | 本月折子够不够买肉 |
| 房与路 | 进城帮带睡客厅、留守堂屋、两头住、周一送镇 | 外婆要不要来住 |
| 自己的日子 | 还在岗、刚退、麻将馆、地里、单位老同事 | 打卡和带孙抢 |
| 带孙现场 | 冲奶、接送、门口塑料凳、电话里报吃了没 | 水温谁定 |
| 器物 | 收音机、联播、座机、膏药、脑白金他们收下 | 机不会按 |

## 质量下限（不达标就重写这一张）

- 每张 **600–1000 汉字**（只数 `[\u4e00-\u9fff]`）。低于 500 视为目录。
- **一部深挖**。禁止「带孙/退休金/喂饭」糊成一段生活年鉴。
- 必须有玩法：怎么喂、怎么接、怎么数折子、怎么等绿皮。不能只写物件名。
- 有价钱或等价。没有公开数字写「口述、待核」。禁止编民调。
- 分龄四格写全。城乡 / 居住至少两种。
- 每张只留 **一段**「现场」。现场只演 **两套**过法（优先：城退带孙 + 乡留守；或婆家 + 娘家）。另外两套放到「谁家有」。
- 现场只写手、嘴、口袋、门口、城乡、价钱。禁止把「禁止写成……」写进现场。
- 感官要有动作（染蛋、灌瓶、盖章、摇农用车），不要词单。
- 「现在怎么提」换事后入口：折子 / 礼簿 / 听筒 / 塑料凳 / 麻将牌。禁止「短视频爱」「被说滥的是」「没被说够的是」「事后记忆。」套话。

## 字段（必须写全）

```text
### G-YYYY-NN 标题

**时间** …｜**落在哪** 灶上 / 钱包 / 房与路 / 自己的日子 / 带孙现场 / 器物｜**称谓** 奶奶 / 爷爷 / 外婆 / 外公｜**谁家有** 城退 / 县 / 乡留守 / 进城帮带 / 远距

**事实核**：年份、价格或等价、出处 URL 或待核。和儿童库、父母库的分工一句说清。不要挂钩新闻标题。

**00后祖辈当时怎么过**：（表）1940 / 1945 / 1950 / 1955 四格

现场：一段。手、嘴、口袋、门口、两套过法。

**00后祖辈现在怎么提**：一种事后入口。城乡可以一句对照。

**当时广告 / 单位 / 生活版怎么说**：广告词、居委会、供销社、麻将馆口头。不是新华社。

**当时家里怎么说**：至少三种声音（奶、爷、儿女、孙、牌友）。

**邻居牌友和其他说法**：跟风、假货、谁家先带。没有写「未见公开争论」。

**祖辈自己的一对词**：A vs B。

**感官钩子**：四个带动作的。

**会吵什么**：一个具体选择（常和 70 后吵，或两家老人吵）。

**和孩子 / 父母库的接口**：钩子一句 + `详见儿童库` 或 `详见父母库` 或 `详见带孙专篇`。没有写「无」。
```

卡号：年份篇 `G-2000-01` 起；带孙专篇 `GS-01` 起。不要和儿童库 `C-` / 父母库 `P-` 混号。

## 带孙专篇（硬规则）

年份篇禁止展开：偏方仪式单、重男轻女制度、听写怎么教、两家抢带的流程。

「追着喂」「作业他们盯不盯」在年份篇只许钩子一句 + `详见带孙专篇`。

儿童库写孩子的身体和嘴。父母库写付钱的人、加班的人。本库带孙专篇写**碗在谁手里、门在谁守、偏方谁偷做、孙子孙女两套标准**。不要三套抄成一段。

## 绝对不要写

**社会新闻、国家大事、灾难、案件、宏观，全部禁止**，包括但不限于：

千年虫、西部大开发、申奥、入世、911、十六大、孙志刚、非典、伊拉克、神五神六、阜阳当公共事件、海啸、马加爵、反日游行、农业税文件、黑砖窑、华南虎、股市、纸馅包子、汶川、火炬、抵制家乐福、三鹿当公共事件、金融危机、甲流、阅兵、躲猫猫、李刚、3Q、谷歌、富士康、玉树舟曲、世博当国家工程、校园案。

看见就删。不许用「客厅漏音 / 倒醋 / 捐压岁钱」把它们塞回来。

**也不要**：

- 把儿童库主卡再写一遍。
- 把父母库加班、月供、假条再写一遍（只许钩子）。
- 把 17 种画像人物写成事件主角。
- 把全体写成 70 岁已退老太太。1950 / 1955 很多人还在岗。
- 微信、短视频现场、外卖、移动支付、高铁日常化、拼多多、广场舞成熟期当本年现场。
- 同一物件两年各开一张同角度主卡。分年必须换手：2000 脑白金他们收下 ≠ 2008 电视购物他们自己买；2003 听筒接 IC ≠ 2006 村口等绿皮。

## 年代铁律（和已有研究打架时，以已有研究为准）

1. 企业人均退休金约：2000 年 6142 元/年（约 512 元/月），2005 年底月均约 700，2010 年约 1300（劳动统计年鉴口径；中国日报 http://www.chinadaily.com.cn/dfpd/2010qglianghui/2010-03/04/content_9534487.htm ）。机关事业更高。农村多数没有折子，**新农保 2009 年试点**，不要 2000 年就全员领农保。
2. 营养快线 **2004 上市**。2003 卡须写清多数柜还没有。
3. 奶粉只写家里哪罐、谁冲、水温谁定。禁止打假新闻。
4. 月供是 70 后的账。祖辈写盖房、贴砖、进城睡客厅，不要写成老人还贷。
5. 通讯：墙上座机、IC 卡、小灵通。禁止视频通话。
6. 家电下乡：2007 试点，2009 前后才进更多村。
7. 脑白金 2000 年起广告；黄金搭档 2002 下半年。盖中盖巩俐事件不写。
8. 怀旧短视频只作线索，不作年代依据。禁止编民调。

## 单年自检

1. 有没有写成新闻、儿童课间、父母加班主卡？
2. 是否 6–8 张、至少 4 类、有奶线也有爷线、有婆家也有娘家、有至少一张自己的日子？
3. 有没有低于 500 字，或「再写一层」叠字？
4. 字段是否写全？现场是否一段、是否只两套过法？
5. 1955 有没有被写成全员已带孙？
6. 有没有偷写偏方仪式、重男轻女制度？搬去带孙专篇。
7. 总表本年深挖是否都落了？别年深挖是否只点名？
8. 留守 / 进城帮带有没有至少出现一次？

总检和索引要求见 [decade-table.md](decade-table.md)。
