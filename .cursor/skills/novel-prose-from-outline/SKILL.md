# 按照中纲细纲场卡写正文

正式正文只听这三份。中纲锁该章只许哪一寸。场卡锁这场合同。细纲锁每一拍，也锁这一日写几场、写多少字。不准只凭文章包、材料库或印象开写。

本 skill 写正文。不写中纲、不补场卡、不拆细纲、不拼文章包。质量门和禁搬门仍用 `../novel-chapter-prose/quality-gates.md` 与 `../novel-chapter-prose/cannot-copy.md`。

## 平台真人投稿边界

如果用户目标是起点等明确限制 AI 替代核心正文的平台，本 skill 不提供“改到查不出来”“过 AI 检测”“伪装真人写作”的服务。该场景下，正文只能走真人稿模式：

- 用户先给出自己手写 / 口述 / 逐段改出的正文草稿。
- 本 skill 只做结构诊断、阻断项标注、删改建议和局部问题说明，不直接生成整段可投稿正文。
- 可以改错字、指出因果断链、标出接力复述和模板词；不得把 AI 正文洗成投稿稿。
- 若需要真正投稿，必须保留真人过程账：手写提纲、草稿版本、口述记录、逐段修改记录和每日日志。
- 任何由本 skill 直接生成或大幅改写的读者叙事，都应视为 AI 辅助文本，不得当成纯真人原创投稿。

## 真人素材输入门

无论是否投稿，想减少流水线腔，开正文前必须有真人素材。没有素材，只能先补采访 / 口述 / 观察笔记，不直接写日更。

每一场至少交 3 条：

- 作者自己的口述句或手写草稿句，不要求漂亮，可以别扭；不得来自他人作品、公开文章或素材库原句。
- 一个不是为了点题而存在的生活细节：错拿、忘记、脏、响、排队、找不到、临时改口。
- 一个真实不整齐的动作顺序：先做错一步、停一下、被旁人打断、回头补一句。
- 一个场外杂音或无用物：邻居、柜门、票据边角、饭凉后的处理，不承担象征。
- 一句人物会说但大纲不会写的话。

正文只把这些素材当事实来源，不直接搬成金句。缺真人素材时，输出改为“素材追问清单”，不得补成完整投稿正文。

## 人工三遍修订

拟真人稿不接受一稿直出。每个日更至少经过三遍人工修订，记录在文末批注或 `scene-ledger.md`：

1. **口述 / 粗稿遍**：作者用自己的话把这一场说一遍，允许乱序、重复和口头病句。保留 2–3 句原始说法。
2. **结构遍**：只改因果、站位、动作顺序和对白去留，不润色成金句。
3. **去机腔遍**：专门删接力复述、匀句串、过密物件、主题翻译句和每段都点题的收束。

缺任一遍，只能标“编辑中”，不得标定稿。若是平台真人原创目标，缺三遍记录则退回真人稿评审。

## 先认哪本书

字数听这本书的日更。不要用 00 后的 6000 去写别的书，也不要按场再写一个日更。

| 书 | 路径 | 日更（读者叙事） | 普通章 | 不可逆章 | 只说「写正文」时 |
|---|---|---|---|---|---|
| 《差不多》 | `番茄/90hou-chabuduo/` | 7000（6800–7200） | 3 日 ≈ **21000**（20400–21600） | 4 日 ≈ 28000 | **现行开写**。交 ledger 下一未写日 |
| 00 后三代 | `番茄/00hou-sandai/` | 6000（5800–6200） | 一场一日 | — | **冻结**。未点名不写、不润色 |
| 其余 | 该项目目录 | 听该项目中纲 | 听细纲日切 | 听中纲 | 先抄日更再写 |

番茄一天一个 md。禁止把两天的量塞进同一个文件。`第X章.md` 只作通读。

**场是结构单位（一限知、一钟、一物）。日是文件和字数单位。** 细纲写「日01 = 场01 约 3000 + 场02 约 4000」时，落一个过日更门的 `日01.md`。不要把每场写成 6000，也不要只写一场就交稿。

整章字数 = 该章细纲日数 × 该书日更。用户说「这一章 21000」= 《差不多》普通章三日交齐，不是一个文件。

## 三份各管什么

| 文件 | 管什么 | 正文怎么用 |
|---|---|---|
| **中纲** | 该部 / 该章只许哪一寸、禁止提前、进部出部、波形 | 没许的事件、不可逆、后段意义一律不写 |
| **场卡** | 限知、钟、主场、主物件、因果句、状态、三栏、声音、帮与伤 | 合同缺一项不开写；不得改场序 |
| **细纲** | 日切、每场约数、每拍手 / 物 / 嘴 / 停在、起笔、收束、对白许可 | 按拍写；按日切配额写满 |

打架：`story-bible` 硬边界 > 中纲 > 已锁正文账 > 场卡 > 细纲。细纲不得发明场卡没有的事件。场卡不得发明中纲没许的一寸。文章包若在，只补材料功能，不得另起节拍或主题。

## 缺哪一层

| 缺 | 先走 | 不准 |
|---|---|---|
| 中纲 | `novel-mid-outline` | 开正文 |
| 场卡 | `novel-chapter-structure` + `novel-chapter-*` | 用细纲发明场序 |
| 细纲 | `novel-fine-outline` | 只凭场卡或文章包开写 |

有材料库、用户只要开写包：`novel-article-assemble`。文章包不是正文入口。

## 任务判定

1. **一日**（默认）：按细纲日切写满本日所有场，落一个日更 md。未过日更下限，不得写下一日，不得称交齐。
2. **整章**：用户点名一章，或点名约 21000 / 28000。按细纲日切把各日写满再交；每日过门后再写下一日。
3. **单场**：用户点名一场，且细纲该日只有这一场。该日还有另一场，必须两场写进同一日 md，按细纲每场约数分配。
4. **扩写**：旧稿低于该书日更下限。字只补进已有拍，先砍第二主场。禁止用单句凑字，禁止另开半成品文件。
5. **续写**：接未写完的日尾，或细纲下一未写日。承接上一场已发生的手、物、未完问题。
6. **改稿**：先修中纲 / 场卡 / 细纲打架，再改句子。
7. **真人稿评审**：用户目标是起点真人原创时，只标问题和给改法，不代写可投稿段落。
8. **试写**：只在聊天交稿，不回填正式账；试写不得声明为真人原创投稿稿。

00 后三代未点名：停。不要默认交一场 6000。

## 开写抓手

缺一项不开写：第一场具体空间、第一只手、第一件物、一口钟、一个限知。

还必须从细纲日切表抄到：本日几场、每场约多少字、本日停在哪、该书日更窗口。抄不到不开写。

开写前必须先答完：谁进场要什么、谁挡住、本场选择帮了谁又伤了谁、场末哪只手或哪件物挪了。答案必须能从场卡和细纲抄到，不准另编。

任一为真，退回：

- 只写「亲情 / 缺席 / 控制 / 他懂了」，没有当场动作
- 换人名后还能套进任意家庭文
- 变化只在批注里成立，正文看不见手、物、路线
- 一场另开第二主场，或作者宣布主题
- 没打开中纲，或另起中纲未许的一寸
- 有细纲却另铺一套节拍
- 按场写满一个日更，或只写并日里的一场就停

## Required Reads

打开目标书之后只开这些：

1. 该书中纲：该章只许哪一寸、禁止提前、日更口径
2. 该章 `00-大章.md` + 本日每一场场卡
3. 该章 `细纲.md`：先抄文首日切表，再取本日每场拍表
4. `scene-ledger.md` + 上一场正文末尾（第一场读上一大章结尾）
5. `../novel-chapter-prose/cannot-copy.md`
6. 真人素材：作者草稿、口述、观察笔记或本场手写碎片；目标是投稿时缺此项不开正文

按场需要再开人物志一寸。文章包、材料库不是必开；场卡或细纲点名了才打开，只抽功能，不搬原句。不要读 archive。

《差不多》章中纲：`中纲/大章NN-*.md`。部分中纲按部：`中纲/01-话先落在人身上.md` 起共五部。

00 后三代另加：先读 `番茄/00hou-sandai/README.md` 冻结；硬边界打架才深读 `story-bible.md`。部分中纲：1–3 `01-证据.md`，4–6 `02-缺席.md`，7–9 `03-争夺.md`，10–12 `04-安排.md`，13–15 `05-撤退.md`，16–18 `06-回看.md`；跨部加读 `大章06-10.md`。

- [ ] 3. 打开中纲，抄该章只许哪一寸、禁止提前、进部出部
- [ ] 4. 打开本日每一场场卡，抄合同；缺一项则停
- [ ] 5. 打开细纲本日每场表，锁拍、起笔、收束、对白许可
- [ ] 6. 开写抓手已锁：空间 / 手 / 物 / 钟 / 限知
- [ ] 7. 按拍写；两场并一日则按细纲约数接写进同一个 md
- [ ] 8. 文末写批注：改变、道理、点睛之笔；摘原句，对上场卡三栏
- [ ] 9. 跑 count_hanzi.py；未进窗口只补已有拍，禁止用接力复述滚字；再跑，直到字数和节奏都过门

未跑计数脚本，或脚本报低于下限：这一日未完成。禁止把 1900、6400 当进度交出去。

## Step 1 · 抄中纲

工作过程里写下，不写进读者叙事：

- 打开的中纲文件
- 该章只许哪一寸
- 禁止提前写出的后段意义
- 进部接到哪、出部交到哪

正文不得写出中纲说「下一部分才能碰」的物、称呼、不可逆。中纲与已锁正文打架，听 ledger，回头改中纲总结栏，不改矩阵。

## Step 2 · 锁场卡合同

从场卡抄，不要另起一套。本日有几场，就抄几份。以下缺一项，退回，不开正文：

```markdown
- 场 ID / 所属部与大章
- 打开的中纲 / 该章只许哪一寸
- 上一场直接结果
- 限知 / 即时欲望 / 阻力
- 主场 / 钟 / 主物件及第几次出现
- 主动作 / 小选择 / 帮与伤
- 预定状态变化 / 下一场问题
- 禁止提前
- 身世本场只露 / 声音合同
- 某人遇见什么（场卡「这场主线」或因果句）
- 思想一寸 / 人物变化（进/出）/ 背景变化（进/出）
- 细纲拍序（5–7）与收束停在
- 本日日切：几场、每场约数、本日停在
- 真人素材 3 条：作者自己的口述句或草稿句 / 不点题细节 / 不整齐动作；目标是投稿时缺此项不开正文
```

一场一个限知。视角人物只能写自己能看见、听见、闻到、摸到、记得和推测的。婴儿写身体、声音、温度、被转手。幼儿不说「隔代抚养、控制、缺席、创伤」。换限知必须换场，也必须换嘴。两场并一日可以换物、换拍，不换限知除非细纲写明换场换头。

## Step 3 · 按细纲拍写

细纲是开写拍表，不是可粘贴正文。每一拍的「手 / 物 / 嘴 / 停在」只锁功能，必须按这个限知的嘴重写。

- 一场一件事。主物件必须换位置或换用法。
- 从细纲「起笔」的正在发生的动作进，不要年代开场，不要先解释主题。
- 严格按拍序：带伤 → 欲望 → 阻力 → 改小 → 选择 → 后果 → 收。不准调换，不准合并成主题段。
- **拍字数 = 该场细纲约数 ÷ 拍数。** 七拍撑满的是这场的约数，不是永远 6000。
  - 《差不多》日01 场01 约 3000 → 每拍约 400；场02 约 4000 → 每拍约 550；合计过 6800。
  - 日02 单场 7000 → 每拍约 1000。
  - 00 后一场一日 6000 → 每拍约 850。
- 字补进这一拍已有的走、坐、试、热、等，不补新冲突、不另开第二主场、不加新人物弧、不用单句凑字。
- 不准用接力复述凑字。禁止「A。A，B。B，C」往下滚。字不够时换一条没写过的手的路径、一次等的空隙、旁边人的一句家常，或把两句并成一句有过程的长句。
- 连续五句汉字数都在 7–13，必须拆一条更短的，或并一条超过 20 字的。
- 每场至少保留一个不服务主题的普通动作。它可以只让人吃上、坐稳、找东西、等水开；不许事事都变成证据和象征。
- 对白只许细纲「对白许可」里的短句。真正诉求放在句后动作。
- 拍 5 的选择必须同时帮人又伤人，且是同一动作。
- 收束只停在细纲写明的那个动作或物件位置，不解释。本日最后一场停在日切表的「停在」。
- 两拍物还在同一处，后一拍是注水，删掉重写这一拍的手。
- 喘息场：办法先真好用。重压场：主物件易手，句法短。余波场：不再制造新冲突。

扩写旧稿：先对照细纲标出哪几拍只有一句；先砍第二主场；字只补进已有拍；补完立刻再跑计数脚本。

## Step 4 · 冷却

四遍细则见 `quality-gates.md`。正文里只做这些：

- 只写场卡因果句和细纲七拍。删掉一截故事仍成立，那一截就是注水。
- 抽象位置换成手和物。每个主要动作问：怎样真的帮了人，又怎样真的伤了人。
- 开头从动作、物件或钟进入。结尾落在动作、物件位置、答话长度或路线上。
- 删作者解释、重复心理、只为漂亮的比喻、功能相同的对话。搜「不是」「而是」「要紧」「就够」「才算」「仍是」；动作已成立的后句整句删。
- 搜接力复述：上一截末 2–4 字是否就是下一截开头。第三处起删后半截。搜「空着空着」「还在还在」「半寸」「掌心」；功能留下，原词抽掉一半。

## Step 5 · 句法

- 句子平实。同一段最多一个明显比喻。一个动作写准后，不再跟一句心理翻译，也不跟一句把末词接走的复述。
- 「不是 A，是 B」每场最多一处；只是解释动作就删。
- 接力复述每场最多 2 处。默认写法是把过程写完再换句，不要「门开大，纸才会出来。出来时……」。
- 句长要有长短：一场里既有 4 字以下，也有 20 字以上。连续五句都在 7–13 字，拆或并。
- 本场主题词第一次可立住，之后衰减到动作、物件或答话里。不要靠「空着 / 还在 / 半寸 / 掌心」反复加重。
- 换限知必须换句法，不只是换物件。
- 不使用「原生家庭、控制欲、焦虑感、情绪价值、时代洪流」。不仿名家句腔。
- 物件必须被拿、放、洗、折、付、藏、修、等或避开。普通生活可以只是普通生活。

## Step 6 · 批注校验

正文写完、定稿前，文末必须有批注。不进读者叙事。两场并一日，批注仍写在同一个 md 末尾，改变要能分开指到两场的手和物。

```markdown
## 批注（校验）

### 此事
[某人遇见了什么具体事。从场卡主线抄，用正文里发生的事核对。]

### 改变
[谁从什么变成什么。必须落在手、嘴、物、路线上。]

### 道理
[一句刺人的问题，对上场卡思想一寸。不是鸡汤。]

### 点睛之笔
- 「正文原句」——点的是【思想 / 人物变化 / 背景变化的哪一寸】
```

过门：改变、道理都能在正文里找到对应动作；点睛 1–3 处，必须是原句，优先摘动作、物件位置、答话长度和路线；批注对上场卡三栏，对不上先改正文，不准改批注去圆；禁止「体现亲情 / 他成长了 / 时代洪流」。无批注不得定稿。

读者叙事止于正文。一个 md = 一天，只计读者叙事（去掉标题、空白、文末批注）。不到下限：补进已有拍的手、物、钟。超过上限：在自然停顿处拆下一个 md。

保存后立刻跑：

```text
python3 .cursor/skills/novel-prose-from-outline/scripts/count_hanzi.py 日NN.md
```

整章三日再加：

```text
python3 .cursor/skills/novel-prose-from-outline/scripts/count_hanzi.py 日01.md 日02.md 日03.md --chapter 21000
```

脚本按路径认书：《差不多》7000，00 后 6000。别的书加 `--daily`。退出码非 0，这一日不得定稿。

回填 `scene-ledger.md`：

- 实际选择与实际结尾
- 人物新知道、误会或停止期待的内容
