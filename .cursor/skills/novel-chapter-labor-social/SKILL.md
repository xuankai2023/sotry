# Chapter Outline · Labor Social

只写**大章纲或具体场卡**。不写完整正文，不重写全书总纲，不改 `novel-style-labor-social`。

先读 `../novel-chapter-structure/SKILL.md` 与 `../novel-character-craft/SKILL.md`。大章包含 5–7 场并承担不可逆；单场只让钱、班、人中的一项形成主要缺口。正文转 `novel-prose-from-outline`。大章纲要有本章人物，场卡要有身世一寸和声音差。

## 作用

把一场压进物质：假条、信封、月供、路、班。社会压力来自单位和门口。写大章时，5–7 场让缺口转移：这场缺人，下场用钱补，补钱又让班更紧。

## 工作流

```
章纲 Progress · 劳动社会:
- [ ] 1. 读 chapter-structure，确认三圈已排
- [ ] 2. 读 风格总纲/05-劳动社会.md 只作方向
- [ ] 3. 点明本章钱、班、人哪一样付不出
- [ ] 4. 点名班上或门口谁看见这份付不出
- [ ] 5. 写章纲
- [ ] 6. 过门：工作不是背景；没有逆袭成功
```

**Step 3** 三样都想付的人，是林倩或建军。缺的那一样必须落到孩子身上。  
**Step 4** 外圈：同事催班、搭班换班、家长问报了什么班。  
**Step 6** 「穷人但幸福」删掉。写菜单、路程、口气、睡眠哪一项变了。

## 本章要看见

- 尊严怕当众丢的是哪一样
- 外圈怎样让这份丢更公开
- 孩子付的是等待、懂事、或少问

## 大章规则

先写起始的三项平衡和目标不可逆，再排 5–7 场：试图三项全付 → 单位施压 → 缺一项 → 用另一项补 → 孩子承担后果 → 新缺口进入下一章。
