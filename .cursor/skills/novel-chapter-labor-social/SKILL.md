# Chapter Outline · Labor Social

只写**具体章节大纲**。不重写全书总纲。不改 `novel-style-labor-social`。

先读 `../novel-chapter-structure/SKILL.md`。本 skill 只管这一风格怎么拆一章。

## 作用

把一章压进物质：假条、信封、月供、路、班。外圈是单位和门口的证人。

## 工作流

```
章纲 Progress · 劳动社会:
- [ ] 1. 读 chapter-structure，确认三圈已排
- [ ] 2. 读 风格总纲/05-劳动社会.md 只作方向
- [ ] 3. 点明本章钱、班、人哪一样付不出
- [ ] 4. 点名班上或门口谁看见这份付不出
- [ ] 5. 写章纲
- [ ] 6. 过门：工作不是背景；没有逆袭成功
```

**Step 3** 三样都想付的人，是林倩或建军。缺的那一样必须落到孩子身上。  
**Step 4** 外圈：同事催班、搭班换班、家长问报了什么班。  
**Step 6** 「穷人但幸福」删掉。写菜单、路程、口气、睡眠哪一项变了。

## 本章要看见

- 尊严怕当众丢的是哪一样
- 外圈怎样让这份丢更公开
- 孩子付的是等待、懂事、或少问

## 章纲模板

```markdown
# 第X章 · [假条 / 信封 / 路]

## 这章主线
[三样里哪样付不出，缺口记在谁身上]

## 房间 / 钟
[家和班两头，仍只主写一个房间或门口]

## 三圈在场
- 内圈：
- 中圈：[建军或林倩的班]
- 外圈：[同事、搭班、问报班的家长]

## 物质压力
- 钱：
- 班：
- 人：

## 谁先伸手

## 人物事件
[请不出、交不起、赶不上。不要抽象焦虑]

## 不可逆
[这个月或这天的缺，以后要用什么补]

## 孩子学会什么
[等待、不打电话、把饿说成不饿]

## 接到下一章
```

## 禁

励志翻盘、把班写成回忆、靠天赋跳出阶层、给外圈开创业线。
