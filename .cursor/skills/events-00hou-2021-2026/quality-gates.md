# 2021–2026 事件卡 · 质量门

写完或优化后过这张表。不过就改本年被点名的那一张，不要顺手改邻年。

## 交之前必须过

1. 三本各 6–8 张，每张 600–1000 汉字。
2. 总表本年深挖都落了。别年深挖只在胶囊点名。
3. 城 / 县或乡 / 留守都出现。
4. 现场没有「不写……」「禁止……」，也没有作者挡明年的嘴。
5. 现场没有疫情、清零、封控、放开、双减、二十大。
6. 2006 / 2009 不是考研高考评论员。1980 / 1985 不是全员供 2000 年生考研租房。1955 不是全员已带孙，且格子里的动作等于现场。
7. 小说、旧库、2011–2020 成品、专篇、下一年都没被打开改写。

跑：

```bash
python .cursor/skills/events-00hou-2021-2026/scripts/validate.py YYYY
```

脚本过了仍要人工看换手。脚本只能抓字数、禁令和空格。

## 换手

补题不是「上年那张再写一遍，加更晚 / 更厚」。

| 错 | 对 |
|----|----|
| 额温枪再开一张 | 自己把绿的举高 |
| 纸袋堆门再开一张 | 柜门热一下、取餐码 |
| 一张桌再开一张 | 合租门禁贴、押金条 |
| 门口屏再开一张 | 绿的要她举高、被人按 |
| 三张同时演举机亮绿 | 少年自己举；父母帮按；祖辈被按 |

同一物件两年必须换手：2020 堆门 ≠ 2021 柜门；2020 门口屏 ≠ 2021 被按亮绿。

## 现场禁令（作者口）

现场里不要出现这些写法。要挡明年，写进文末「本年不写」或事实核。

- 「不写……」「禁止写成……」
- 「不是骑手 / 黄袋 / 配送 / 绑卡 / 给你红包」
- 「不是校门口那盏 / 不是十四岁的灯 / 不准对着卷」
- 「去年的嘴」
- 疫情、清零、封控、放开、双减、二十大
- 校准原文、产品年表、全国工资或养老金精确月数

改法：留下手和钟。门口是绿的、柜门热、锁扣冰一下。折子只写「比去年厚一点」。

## 分龄空格

| 空 | 补 |
|----|----|
| `2009 \| 12 岁。` | 码亮一下就松手 / 柜门热一下 / 带宽勒一下 |
| `1985 \| 还不是付款人。` | 看自己的园、自己小学门口、自己班上群 |
| `1955 \| 66 岁。` | 返聘窗口、看门、地里、路过看见邻居被按手 |

1955 格写「未带孙」而现场写他在喂孙，算没写完。1955 不要默认还在岗。

## 三本接口

别人已深挖，本卡只留钩子一句 + `详见 T-/P-/G-YYYY-NN` 或 `详见某某库`。

不要三张卡同时演「绿的方块」。自己举、帮人按、被人按，各留一只手，其余一句接口。

## 年代门（只拦提前，细节以总表和校准为准）

天天核酸亭不进 2021 满城。抗原两道杠不进 2021。堂食不用亮码不进 2021–2022。对话框写作业不进 2021–2022。短剧自动下一集不进 2023 以前当全班。痛包不进 2023。DeepSeek 不进 2024。2026 不编 9 月之后。

试卷、志愿、家校群怎么管，年份只留钩子。

## 优化时怎么改

用户说「优化 2021 的其他的不用」：只动点名的处。

用户说「写的不够好继续优化」：先报弱项（抄上年、三张抢一物、现场作者口、分龄空格），再改本年三本。不要开下一年。

补字：补进已有节拍的手、物、钟。不要另开第二主场。
