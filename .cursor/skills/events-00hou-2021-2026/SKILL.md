# 00 后 · 2021–2026 三本事件卡

这是书写工作流，不是成品库。一次只写一年，三本一起交。下一笔等用户点头。

**一句话**：只写这六年自己家里过的、手里碰到的。删掉新闻还站得住才开卡。

## 先分清本子

| 库 | 路径 | 本 skill |

| **父母** | `content-intelligence/research/events-00后父母视角-2021-2026/YYYY.md` | 写。卡号 `P-YYYY-NN` |

| 校准 | `content-intelligence/research/events-00后2021-2026-校准/` | 只核年、层、价、谁家还没有。禁止搬进现场 |
| 总表 | 各库 `decade-table.md` | 本年深挖必须落；别年深挖只点名 |
| 上一本 2011–2020 | `events-00后少年视角/`、`events-00后父母视角-2011-2020/`、`events-00后爷爷奶奶视角-2011-2020/` | **禁止再写**。只许钩子 + `详见 T-/P-/G-2020-NN` 或 `详见某某库` |

| 专篇 / 索引 | 考试.md、育儿.md、带孙.md、`00-索引.md` | 六年后再写。用户没点名不要开 |

密度样卡：2011–2020 少年 `2011.md` / `2020.md`（只读密度和换手，不回头改）。上年三本只读换手。

## 三种活

| 用户说 | 做 |
|--------|----|
| 写 YYYY / 按 2021 做 | 本年三本落盘。别年、小说、旧库、专篇都不动 |
| 优化 / 继续改 | 只改被点名的年或被点名的处。不要顺手改邻年 |
| 看看 / 总检 | 只检查。用户没要求就不重写 |

用户没指定年份：报已写成的最晚一年，等点头。不要自己开下一年。

## 写年前必读（按这个顺序，不要扩读）

1. 本文件 + [quality-gates.md](quality-gates.md)
2. 三本 `decade-table.md` 的**本年行**和「只点名 / 禁止提前」
3. 校准 [`00-索引.md`](../../../content-intelligence/research/events-00后2021-2026-校准/00-索引.md) + 本年深挖对应的通讯 / 钱 / 路 / 嘴 / 学 / 玩 / 家 / 账
4. 上年三本（换手）。2021 年读 2011–2020 三本 `2020.md`。密度翻 2011 或 2020 一张
5. 联网只核生活：哪一年进哪一层城、大约多少钱、谁家还没有。不核新闻标题

不要打开小说、旧库年份篇、2000–2010 skill。不要改 2011–2020 成品。

## 选题先过，再写

列 8+8+8 标题，过完再落盘。不过就换题，不要写完再推倒。

1. 三本总表本年深挖都占位。
2. 补题必须是**同类型生活题 + 新的一只手**。标题里不要出现「还在 / 更厚 / 更晚 / 仍是 / 又」。
3. 同一物件本年最多一张主卡。要拆，必须换空间（自己举码 ≠ 帮人按码），不能一张壳写两遍。
4. 三本不要三张抢同一只绿码、同一袋团购、同一盏校门口灯。别人的本子用钩子。
5. 每本 ≥4 类；城 / 县或乡 / 留守都要出现。
6. 少年有一张女孩或两套玩法。父母有妈线、爸线、一张自己班上。祖辈有婆家、娘家、奶线、爷线、一张自己的日子。

## 写的是谁

写错年龄就是写错人。四格必须写满，格子里要有动作，不要只写「N 岁。」

| 本 | 四格 | 主核 | 不要写成 |
|----|------|------|----------|
| 少年 | 2000 / 2003 / 2006 / 2009 | 2000 | 2006 / 2009 当考研高考评论员 |
| 父母 | 1970 / 1975 / 1980 / 1985 | 1975 | 1980 / 1985 全员供 2000 年生考研租房 |
| 祖辈 | 1940 / 1945 / 1950 / 1955 | 1950 | 1955 全员已带孙。1955 格必须等于现场里他在干什么 |

2009：身体记忆（冰、沉、亮一下就关）。1985：自己的班、自己的园、自己小学门口。1955：返聘、看门、地里、路过看见、帮一天。不要默认还在岗，也不要默认已是爷爷。

## 质量下限（一张不过就重写这一张）

- 每张 **600–1000 汉字**（只数 `[\u4e00-\u9fff]`）。低于 600 补进已有手、物、钟，不要单句凑、不要另开半成品。
- **一部深挖**。有玩法：怎么点、怎么交、怎么等、怎么勒。
- 价钱或等价。没有公开数字写「口述、待核」。禁止编民调。
- 现场只留**一段**。优先两套过法（城 + 乡留守，或婆家 + 娘家）。另外两套放「谁家有」。
- 现场只写手、嘴、口袋、门口、钟、城乡、价钱。校准句、全国工资/养老金精确月数、作者禁令都不进现场。
- 感官四个，带动作。一对词是具体选择。

## 字段（三本都必须写全）

少年 `T-`：

```text
### T-YYYY-NN 标题
**时间** …｜**落在哪** 嘴 / 手 / 眼睛 / 脚与路 / 穿与身上 / 自己的日子｜**谁家有** 城 / 县 / 乡 / 留守
**事实核**：年、层、价或待核、和另两本分工。不挂钩新闻标题。
**00后当时怎么过**：（表）2000 / 2003 / 2006 / 2009
现场：一段。
**00后现在怎么提** / **当时广告和少儿节目怎么说** / **当时大人怎么说**
**同学和其他说法** / **小孩自己的一对词** / **感官钩子** / **会吵什么**
**和父母 / 祖辈 / 上一本的接口**
```

父母 `P-`：落在哪用 家里灶 / 家里钱包 / 家里房与路 / 自己班上 / 带娃现场 / 家里器物。表 1970 / 1975 / 1980 / 1985。接口钩子到少年、祖辈、2011–2020 父母库。

祖辈 `G-`：多写 **称谓** 奶奶 / 爷爷 / 外婆 / 外公。落在哪用 灶上 / 钱包 / 房与路 / 自己的日子 / 带孙现场 / 器物。表 1940 / 1945 / 1950 / 1955。接口钩子到少年、父母、2011–2020 祖辈库。

## 单年自检

写完先跑校验脚本，再人工过 [quality-gates.md](quality-gates.md)。不过就改本年那一张。

## 绝对不要做

- 写新闻、国家大事、产品发布会。现场不写疫情、清零、封控、放开、双减、二十大。
- 把下一年总表深挖提前写成满城日常。2021 不写天天核酸亭满城。2026 不编当年 9 月之后的事。
- 改 2000–2010 旧库、改 2011–2020 成品、改小说、开专篇、另写一套总纲。
- 一次生成两年或六年。
- 把校准段落、全国年平均工资、全国月均养老金写成这家的工资条 / 折子。现场只写「比去年厚一点」「这个数在桌上像什么」。
