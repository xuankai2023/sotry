# 大作家怎样写性格和身世

本文件只给方法。00 后三代的现成合同见 [sandai-cast.md](sandai-cast.md)。

## 先立骨头，再露一寸

作家不在开场交代履历。他们先让人做一件只有这个人才会做的事，身世从这件事的来路上露出一角。

- 路遥：人被班、路、钱压住；身世是他为什么不能停。
- 张爱玲：爱是账；身世是谁先欠谁，细节冷，不哭诉。
- 汪曾祺：少话，手会做事；身世在修、洗、绑、放正里。
- 鲁迅：正当的话伤人；身世是他为何必须说「为你好」。
- 王安忆：日程就是命运；身世是她的钟为什么不能乱。

不要仿句。要仿：这个人此刻为什么只能这样伸手。

## 身世怎么写

写到开篇为止的来路，不写未来剧透。

够用的身世只有四件：

1. **缺过什么**（看见、规矩、时间、资格）
2. **靠什么活下来**（班、碗、纸、车、少说话）
3. **这套办法现在还在用**
4. **这套办法会伤谁**

写成履历表（生年、学历、工龄、属相）而不压本场选择，删掉。

一场只准露一寸。检验：删掉这句身世，他还会不会做同一个选择？不会，才留下。

## 性格怎么写

性格 = 重复的手 + 不肯说的话 + 别人的误认。

每人只给一个核心办法：

| 办法 | 帮 | 伤 |
|---|---|---|
| 用班换在场 | 酒能开席 | 人变成缺口 |
| 用碗证明有用 | 孩子被喂饱 | 孩子没有空隙 |
| 用纸证明尽过力 | 钱和假条留下 | 人抽得走 |
| 用礼簿留下资格 | 娘家当天不矮 | 两套账开张 |
| 往正在喂的那边歪 | 不被放下 | 自己没有地方 |

禁止给一个人并列六个标签。标签多了，正文就会变成轮流解释。

## 声音差

遮住姓名，只看句长、先说的词、句后的手，应能认出是谁。

写声音时锁四项：

- **句长**：几个字，停在哪
- **先说什么**：班、桌、蛋、日期、坐直，还是不说
- **不说什么**：愧疚、孤独、我累了、为了这个家
- **句后手**：洗手、翻簿、折纸、递蛋不递篮

五个人都写「X。X就X。他仍要Y。」就是作者腔，不是人物。

## 年段

身世可以早存在，句子不能早说。

- 婴儿：热、响、被转手。无性格。
- 幼儿：看鞋、看碗、看谁先伸手。不总结家。
- 入学：会藏、会配合、会比较。结论仍来自奖惩。
- 成人尾声：可以分辨，不审判全家。

大人也有年段。2000 年的林倩只有返岗纸，没有点读机演讲；2000 年的桂芳还没有完整灶权，不能写成已经赢了十年的奶奶。

## 中纲怎样塑造，而不是复述总纲

总纲写骨头。中纲写**这一章哪根骨头被压到**。

错误：把总纲人物段复制进每一场。  
正确：大章 1 建军只露「用班换在场」；林倩只露「看日期」；桂芳只露「蛋和桌要像合格品」。少年宫、重考母职、听筒删短，全部留给它们自己的章。

## 和材料的关系

人物志决定**谁会做**。  
材料库决定**手怎么做**。

没有人物志，材料会把所有人写成同一套「半寸、慢半拍」。  
没有材料，人物志会停在说明书。两边都要，先人后材。
