# Novel Character Craft

把人写成**会自己做选择的活人**，不要写成功能标签。

本 skill 不改冻结矩阵，不写 3300 字正文，不另开一套主线。它给总纲立人物志，给中纲锁本部分小传，给大章纲锁本章露出，给文章包和正文锁声音差。材料库只提供手怎么动；性格和身世必须先在这里立住。

全书/部分性格怎么变：转 `novel-character-change`（总纲骨头、中纲本部分进/出）。单场进/出三栏：见 `novel-thought-ground`。人物志仍要能回答开篇手嘴；变化合同不要在这里另起一套。

## 在链路里的位置

```text
novel-workflow                         先整体后局部
novel-master-outline / novel-style-*   总纲：必须交人物志
本 skill                               性格、身世、手、嘴、年段门
novel-character-change                 总纲/中纲：性格怎么变
novel-thought-ground                   单场：思想、人物变化、背景变化
novel-mid-outline                     中纲：本部分小传与声音差
novel-chapter-structure + novel-chapter-*  大章纲：必须交本章人物
novel-article-assemble                 把本场露出、三栏和遇见写进包
novel-prose-from-outline               按这个人的手和嘴写；文末批注校验
novel-material-*                       只补动作库，不替代人物志
```

用户要「人设 / 性格 / 身世 / 人物志」：留在本 skill。  
用户要「性格变化 / 人物弧光 / 开篇到终局会变成什么样」：转 `novel-character-change`。写总纲或中纲时，人物志用本 skill，变化合同用那一个。  
用户要全书方向：转 `novel-master-outline`，但总纲里的人必须按本 skill 写完，性格变化按 `novel-character-change` 写完。  
用户要一部 / 几章的中纲：转 `novel-mid-outline`，人物小传按本 skill 只取该部分一寸。性格进/出：总纲已定以总纲为主，`novel-character-change` 为辅。  
用户要第 X 章怎么排：转 `novel-chapter-structure`，大章纲必须带回本 skill 的「本章人物」。  
用户只要心理动作条目：转 `novel-material-psych-action`。

## 大作家规矩

细则见 [writer-method.md](writer-method.md)。开写只守这六条：

1. **身世不是简历。** 只写此刻选择的来路。一场只露一寸，且必须压在本场手上。
2. **性格不是形容词。** 「回避」「要面子」不准单独出现；要写成洗手、改条、不回寻呼。
3. **每人只有一个核心办法。** 爱人和伤人是同一套动作。
4. **遮住姓名仍能认出。** 换限知必须换句长、口头禅、先伸哪只手。
5. **年段门。** 2000 年的林倩不能说后文的「妈妈小时候没有」；婴儿没有性格，只有身体。
6. **不写完十年。** 总纲锁骨头；中纲只锁本章会压到的那一寸；后文缺口留给后章。

## 工作流

```text
人物 Progress:
- [ ] 1. 判断尺度：总纲人物志 / 中纲本章人物 / 单场露出
- [ ] 2. 读圣经、总纲、已有人物志，不从 archive 另造人
- [ ] 3. 按模板写身世、缺口、办法、手、嘴、年段门
- [ ] 4. 每人写清帮与伤是同一动作
- [ ] 4.5 思想一寸留给宿主；全书/部分性格变化走 `novel-character-change`；单场进/出走 `novel-thought-ground`
- [ ] 5. 过门：遮名能认；身世能压选择；没有主题词；变化看得见
```

### 总纲要交什么

每个扛戏的人、每个会限知的中圈，交一份人物志。模板见 [portrait-template.md](portrait-template.md)。

00 后三代默认七人合同见 [sandai-cast.md](sandai-cast.md)。新开故事也用同一模板，不要把本项目人名搬过去。

总纲人物志必须能回答：

- 开篇之前他过的是怎样的日子？
- 他用什么办法爱人？
- 同一办法怎样伤人？
- 他的手和嘴与别人有何不同？
- 哪一年才能露出哪一寸身世？
- 开篇的手和嘴是什么？（变化骨头交给 `novel-character-change`）

只有「要证明自己」「事业家庭冲突」五个字，退回重写。

### 中纲要交什么

写大章纲或场卡时，不准只排物件和因果。必须加「本章人物」：

- 限知进章时是哪种人，不是十年后的他
- 本章会压到的身世一寸
- 本章专属的手和嘴
- 对手用什么不同的手
- 章末性格只许挪一寸，不许完成弧光
- 本章思想一寸、人物变化、背景变化里「人」那一栏；见 `novel-thought-ground`

场卡再缩成「身世本场只露」+「声音差」+「人物变化进/出」。缺这三项，场卡不算齐，不准交给 `novel-article-assemble`。

### 文章包和正文怎么用

装配时把人物志改成**本场功能**，不要整份粘进包：

```text
限知：周建军
身世一寸：父亲的规矩压过他的软；他只会用班和纸换在场
手：改条、洗手、烟夹出来又夹回去
嘴：中。满月。家里一桌。不解释为什么不在
材料：必须打开本场列出的画像和心理动作库，记下抽了哪几条
思想 / 人物变化：必须抄本场三栏，见 novel-thought-ground
```

正文必须先打开这些材料再写。写完后，遮住姓名应仍能认出是这个人。五场同一种短句顿挫，退回按人重写，不要先加字数。

## 过门

任一为真，人物层没过：

- 用「自卑补偿型」代替手
- 一场把童年讲完
- 婴儿有成人式判断
- 两个人物可以互换对白而不别扭
- 中圈另开十年发动机
- 为了展示身世加一场没有因果的回忆
- 被要求写总纲/中纲性格变化时没有走 `novel-character-change`，或变化只写心情
- 没有思想一寸，或思想是口号

通过后：

- 用户只要人物：交付人物志，停。
- 用户要总纲：把人物志嵌回 `novel-master-outline` 的「三个扛戏的人」；性格变化按 `novel-character-change` 另交。
- 用户要中纲：带回 `novel-mid-outline` 的本部分小传与声音差；本部分性格进/出按 `novel-character-change`。
- 用户要大章纲：带回 chapter skill 的「本章人物」。
- 用户要求落盘：00 后三代写入 `番茄/00hou-sandai/中纲/人物志/`。不改三份冻结矩阵。

## 不要做

- 不改 `中纲/01`–`03` 场景矩阵
- 不从画像里把朋友圈、视频查岗、触屏搬进 2000 年
- 不把社会性格库的标签写进正文
- 不给晓宁 2000 年写「他学会了当证据」
