# 人物模板

总纲用完整人物志。中纲用「本章人物」。场卡再用两行露出。不要三层都写十年。

## 总纲 · 人物志

```markdown
# [姓名] · [在书里的位置]

## 身世（到开篇为止）
[缺过什么，靠什么活下来。不列履历表。]

## 此刻要什么
[具体到班、碗、纸、位子，不要「证明自己」。]

## 真正护什么
[伤口。他自己不一定承认。]

## 爱的办法 / 伤人的同一办法
- 帮：[动作] 解决 [哪件生活事]
- 伤：同一动作让 [谁] 失去 [什么]

## 手（3 个习惯，可进不同年段）
1.
2.
3.

## 嘴
- 常说：
- 不说：
- 句长：

## 别人怎么误认
[家里人把他看成什么，他实际在做什么]

## 年段门
- 2000：只能露
- 2003：可以加
- 2005–2007：可以加
- 2010 / 尾声：可以加
- 全书不要提前：

## 限知怎么看世界
[他只看见什么；别人的真相要换场]

## 思想一寸
[他身上压着哪一句具体问题，不要性格标签]

## 人物变化
全书/部分怎么变，按 `novel-character-change` 写满合同，不要只留三行。人物志这里可留骨头：
- 开篇的手 / 嘴：
- 终局只许差的一寸：
- 可见证据：
```

## 中纲 · 本章人物

写在大章纲里，内圈和本场会限知的中圈都要有。

```markdown
## 本章人物

### [限知姓名]
- 进章状态：[这个年段的他，不是十年后]
- 本章压到的身世一寸：
- 本章的手：
- 本章的嘴：
- 章末只许挪：[一寸]；不许完成：[十年弧光]
- 本章思想一寸：
- 人物变化进/出：

### [对手或镜子]
- 用什么不同的手：
- 本章不能让他抢走发动机：
```

## 场卡 · 两行必填

```markdown
## 身世本场只露
[限知：哪一寸，压在哪个动作上。其他人各最多半句，或无。]

## 声音差
- [姓名]：[句长 / 口头禅 / 句后手]
- [姓名]：[必须能和上一行分开]

## 人物变化
- 进场：
- 出场：
```

## 文章包 · 本场用法

```markdown
## 本场人物功能
- 限知：
- 身世一寸：
- 手：
- 嘴：
- 打开的画像：
- 打开的心理动作（功能，不抄原句）：
- 思想一寸 / 人物变化进/出：
```

## 禁

- 把画像全文粘进总纲
- 中纲重复总纲人物段
- 场卡写「她是自卑补偿型」
- 为了身世单独开一场回忆
