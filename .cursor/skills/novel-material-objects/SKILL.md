# Novel Material: Objects

## Role

本 skill 只生成物件变意材料。不要写中纲，不要排章节，不要写完整正文。

若项目文件里有暂名或工作名，只作为当前工程上下文，不把它当成最终书名或唯一适用对象。

物件不是怀旧标签。物件必须被人拿、洗、藏、折、递、付钱、修理、等待、避开，并在后文改变关系。每个物件必须写 `novel-thought-ground` 三栏：它压着哪一句思想、让人物变哪一寸、让背景变哪一寸。只交细节、不写变化，退回。

## Core Objects

默认覆盖：

- 碗、勺、奶粉罐
- 听筒、IC 卡、小灵通、诺基亚、电脑、宽带线
- 假条、收据、礼簿、成绩单、联系本、存折
- 红包、工资袋、月供单
- 门、钥匙、灯、塑料凳
- 书包、红领巾、铅笔刀、床
- 自行车、车铃、菜篮、围裙、工装

可按用户要求缩小范围。

## Object Arc

每个物件至少有四次变意：

1. 第一次：只是日常物。
2. 第二次：被某个人拿来证明自己。
3. 中段：开始伤到关系。
4. 末次：旧物还在，人和关系已经变了。

不要在第一次出现时把末次意义说完。

## Output Template

```markdown
# 物件变意材料库

## 使用边界

- 只供正文调用。
- 不写中纲。
- 不写怀旧清单。
- 每个物件都要能改变关系。

## 碗

### 最早它只是
[普通用途]

### 谁最常碰它
[人物 + 为什么]

### 它代表的权力
[灶 / 纸 / 门口 / 钱 / 学校 / 屏幕]

### 第一次出现
[只写日常，不解释象征]

### 第二次变意
[谁用它证明自己]

### 中段变意
[它如何伤到关系]

### 后段变意
[它如何变成隔阂或退场]

### 末次收法
[旧物位置 + 人已不同]

### 不能写成
- [俗套象征]

### 可直接入正文的细节
- [至少 8 条]

### 思想落地
- 思想：[这件物逼出的具体问题，不要「象征亲情」]
- 人物变化：[谁拿它之前 / 之后，手差哪一寸]
- 背景变化：[它换位置、归属或用法后，屋里谁有权变了]
```

## Material Rules

- 物件必须有位置、朝向、使用痕迹、归属变化。
- 每个物件必须连接一个人物缺口。
- 同类物件不要重复功能：碗管身体，纸管证明，门管进出，听筒管压缩的爱，屏幕管撤退。
- 一条材料里最好有一个动词：端、放、折、塞、擦、锁、递、藏、数、修。

## Quality Gate

生成后检查：

- 每个物件都不是单纯年代标签。
- 每个物件都有“第一次”和“末次”的意义差。
- 每个物件都关联至少一个人物和一种关系。
- 没有写成“象征亲情 / 象征时代 / 象征成长”。
- 没有让公共新闻抢走物件。
- 每个物件都有思想、人物变化、背景变化三栏。

## Default Prompt

```text
请为当前小说工程或我指定的小说，生成物件变意材料库。

禁止写中纲，禁止安排章节，禁止写完整正文，禁止写怀旧清单。

请覆盖这些物件：
碗、勺、奶粉罐、听筒、IC卡、小灵通、诺基亚、电脑、宽带线、假条、收据、礼簿、成绩单、联系本、存折、红包、工资袋、月供单、门、钥匙、灯、塑料凳、书包、红领巾、铅笔刀、床、自行车、车铃、菜篮、围裙、工装。

每个物件按以下项目输出：
最早它只是、谁最常碰它、它代表的权力、第一次出现、第二次变意、中段变意、后段变意、末次收法、不能写成什么、可直接入正文的细节。

要求：
1. 每个物件至少 8 条可直接写进正文的细节。
2. 每个物件都要被人拿、洗、藏、折、递、付钱、修理、等待或避开。
3. 每个物件都要让关系变一寸。
4. 不要写成时代物件展。
```
