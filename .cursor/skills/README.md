## 小说

不要混用。总纲是总纲，章节是章节。

| Skill | 干什么 |
|---|---|
| `novel-master-outline` | 全书总纲 / 大段中纲 |
| `novel-style-*` | 某风格的全书总纲。八个已有，不要改 |
| `novel-chapter-structure` | 写具体章节时的结构总控：三圈人、一房、一钟、一不可逆 |
| `novel-chapter-*` | 某风格的具体章节大纲。八个，与 style 一一对应 |
| `storygen` | 另开新故事，或用户明确要求 Braintrust |

`novel-chapter-*` 对应：`family-realism` / `urban-daily` / `psychological-debt` / `restrained-hands` / `labor-social` / `critical-realism` / `cold-absurd` / `warm-growth`。

现行小说稿在 `番茄/00hou-sandai/`，不在 skill 目录里。
