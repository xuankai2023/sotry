# Novel Fine Outline

把**已锁场卡**拆成正文能跟着走的拍。不写正式正文，不改总纲 / 中纲 / 场序，不另起事件凑字。

场卡锁合同：限知、钟、主物件、帮与伤、三栏。  
细纲锁开写：这一日停在哪、每一拍手往哪放、物在哪、能说哪一句。  
文章包锁材料：打开哪张卡、抽哪条功能。有材料库时文章包仍走 `novel-article-assemble`，不替代本 skill。

## 路由

| 用户要 | 走 |
|---|---|
| 中纲 / 部分总结 | `novel-mid-outline`。不要把细纲写成又一份中纲 |
| 大章怎么排 / 场卡 / 谁上场 | `novel-chapter-structure` + `novel-chapter-*` |
| 细纲 / 把场卡拆成拍 / 日更怎么切 | **本 skill** |
| 怎么写、开写包、抽材料 | `novel-article-assemble` |
| 正文 | `novel-prose-from-outline`。必须按本份细纲拍写 |

场卡未齐：先补场卡，不准用细纲发明场序。  
中纲未齐：先 `novel-mid-outline`。

## 在链路里

```text
中纲 → 大章纲 / 场卡 → 本 skill（细纲）→（有材料库则）文章包 → 正文
```

00 后三代已有文章包的章，用户没点名，不补细纲。  
《差不多》等无事件库的书：场卡齐后默认写细纲，再开正文。

## 本 skill 不做

- 不写 6000 / 7000 字正文，不拆空的 `日NN.md`
- 不改已锁场序、主物件、限知、称呼时序
- 不把细纲里的功能句写成可直接粘贴的成品段
- 不抽材料库原句当示范正文
- 不为凑字加第二主场、新人物、新不可逆

## 工作流

```text
细纲 Progress:
- [ ] 1. 打开该章中纲、00-大章、各场场卡
- [ ] 2. 按项目日更字数切日，只切呼吸，不另起几天
- [ ] 3. 每场只要一件事；主物件必须换位置或换用法
- [ ] 4. 每场 5–7 拍，每拍写成：手 / 物 / 嘴 / 停在
- [ ] 5. 小选择拍写帮与伤（同一动作）
- [ ] 6. 过门；文首给中纲 / 大章纲加一行指针
```

### Step 1 · 读真源

必开：该章中纲、大章纲、本场场卡。有上一章出部则核对接手。  
只继承。发现场卡和中纲打架：停，只报被点名的一项，不顺手改矩阵。

### Step 2 · 切日

日更字数听项目：00 后三代一天 **6000**；《差不多》一天 **7000**；其余看该项目中纲。

普通章几日听中纲。三日只切呼吸，故事仍是同一条钟。  
哪一场单独占一日，字补进已有生活过程（走、坐、吃、热），不补新冲突，也不把拍写成「A。A，B。B」接棒链。  
两场并一日，文首日切表写明每场约数，合计等于该书日更。正文按日配额写满，不要让后手把每场再写成一个日更。  
重压场不要拆到前一日提前做完。

投稿或拟真人稿：日切表下必须加“真人素材槽”，每场至少 3 条：一句作者口述、一个不点题生活细节、一个不整齐动作顺序。缺素材槽时，细纲只能标“待采样”，不得进入正文。

### Step 3 · 每场一张表

模板见 [template.md](template.md)。

每拍必须换一件看得见的事。两拍物还在同一处，后一拍删。  
起笔只写正在发生的动作，不写年代开场。收束只停在一个未解释的动作或物件位置。

对白只列许可短句，不写对话段。  
作者判词不准进拍：不要「他知道这意味着」「场面在等」「当天贴上」。
每场至少留一个不承担象征的普通动作：吃上、坐稳、找东西、擦桌、等水开、有人插话。没有这类动作，正文会写成全员替主题服务。

### Step 4 · 松紧

喘息场：办法先真好用（真吃上、真被夸、路真走完）。  
重压场：主物件易手。句法短。  
余波场：不再制造新冲突，门外不开第二场。

夸、称呼、口头禅各锁一次出口，后场不复述。

### Step 5 · 落盘

```text
…/中纲/场卡/大章NN-工作名/细纲.md
```

不要另起一份中纲，不要写进 `正文/`。  
只在该章中纲和大章纲文首加一行指针。

## 过门

任一为真，退回重拆：

- 场序与场卡对不上，或一场两个限知
- 主物件只被擦到，真正挪位的是另一件物
- 拍与拍物在同一处；或拍只是同一选择换说法
- 小选择只有帮或只有伤
- 状态靠作者宣布，手和物上看不见
- 为凑满一日另开第二主场或新事件
- 把后章锚点、并排命名、续茶说满等提前写完
- 细纲写成可粘贴正文

## 优化细纲

用户要「优化细纲」时留在本 skill。先砍作者判词和重复禁写，再并同状态的拍，再补喘息场的生活过程。不改场序。

通过后：用户要正文，转 `novel-prose-from-outline`，并把本份细纲当 Required Read。
