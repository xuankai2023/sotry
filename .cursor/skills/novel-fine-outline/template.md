# 细纲模板

一场一张表。日更切法写在文首。

```markdown
# 细纲 · 大章 NN · [章名]

年段 / 限知 / 日更字数
状态：开写前细纲。场序听场卡。

| 日 | 场 | 字 | 停在 |
|---|---|---:|---|
| 日01 | | | |

## 日0X · 场0Y [物件]

只要：一件事。
句法：本场怎么转弯（勒摸挪停 / 问报夸齿 / 热按卸伸碗）。
起笔：正在发生的动作。不要年代句。

| 拍 | 手 | 物 | 嘴 | 停在 |
|---|---|---|---|---|
| 1 带伤 | | | | |
| 2 欲望 | | | | |
| 3 阻力 | | | | |
| 4 改小 | | | | |
| 5 选择 | | | | |
| 6 后果 | | | | |
| 7 收 | | | | |

帮与伤（拍 5）：同一动作。
对白许可：短句。后场不复述的词在此锁死。
```

样例（功能，不是成品句）：

| 拍 | 手 | 物 | 嘴 | 停在 |
|---|---|---|---|---|
| 4 改小 | 想推门，改去包侧，隔布按角 | 角在拉链里，拉链不拉 | 零句 | 门仍关 |
| 5 选择 | 包转到身前 | 手按关着的拉链头 | 零句 | 纸还在他这边 |
