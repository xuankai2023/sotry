# Novel Chapter Prose

按照中纲细纲场卡写正文，走 `../novel-prose-from-outline/SKILL.md`。本 skill 不再写正文流程。字数听该书日更，不要用本目录旧的 6000 去卡《差不多》。

留下的门：

- 禁搬：[cannot-copy.md](cannot-copy.md)
- 写后阻断项：[quality-gates.md](quality-gates.md)

用户问抄袭、查重、下架：先读 cannot-copy。只报风险或改被点名的重合段，不要为了本门去全文改已锁定章。
写完正文后的结构与语言门：先读 quality-gates。字数和接力复述都听 `../novel-prose-from-outline/scripts/count_hanzi.py`。
