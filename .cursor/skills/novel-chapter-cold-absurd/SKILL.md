# Chapter Outline · Cold Absurd

只写**具体章节大纲**。不重写全书总纲。不改 `novel-style-cold-absurd`。

先读 `../novel-chapter-structure/SKILL.md`。本 skill 只管这一风格怎么拆一章。

## 作用

把一章里人人认真做的小事写平。荒唐自己冒出来。外圈一起认真，才更荒唐。

## 工作流

```
章纲 Progress · 冷叙荒诞:
- [ ] 1. 读 chapter-structure，确认三圈已排
- [ ] 2. 读 风格总纲/07-冷叙荒诞.md 只作方向
- [ ] 3. 锁定人人遵守的普通规矩
- [ ] 4. 写出重复句或重复动作
- [ ] 5. 写章纲（平说，不解释）
- [ ] 6. 过门：不煽情；孩子不是天才观察者；日子还要继续
```

**Step 3** 例如：孩子是中心，但不问他；来得最多的人被说落后；懂事被夸奖的瞬间正是他不再指望。  
**Step 4** 外圈重复那句「真懂事」「真胖」「吃了没」。  
**Step 6** 诗意苦难、社会评论旁白，全删。

## 本章要看见

- 普通规矩
- 遵守它怎样伤人
- 章末生活照常，这就是疼

## 章纲模板

```markdown
# 第X章 · [被认真执行的小事]

## 这章主线
[人人正确，叠在一起哪里荒唐]

## 房间 / 钟

## 三圈在场
- 内圈：
- 中圈：
- 外圈：[同样认真的一句或一个动作]

## 普通规矩
[大家都觉得对的]

## 重复
[哪句话、哪件事本章出现两次以上]

## 谁先伸手

## 人物事件
[白描。不写「他很难过」]

## 不可逆
[重复又深了一寸，仍没人停]

## 孩子学会什么
[他的「没事」更顺]

## 接到下一章
[日子继续]
```

## 禁

哭腔、把荒诞讲成道理、让孩子口吐主题、给外圈开滑稽戏。
