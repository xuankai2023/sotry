# Chapter Outline · Cold Absurd

只写**大章纲或具体场卡**。不写完整正文，不重写全书总纲，不改 `novel-style-cold-absurd`。

先读 `../novel-chapter-structure/SKILL.md` 与 `../novel-character-craft/SKILL.md`。大章包含 5–7 场并承担不可逆；单场只让一种普通荒唐加深一寸。正文转 `novel-prose-from-outline`。大章纲要有本章人物，场卡要有身世一寸和声音差。

## 作用

把一场里人人认真做的小事写平。荒唐自己冒出来。社会压力也认真执行，才更荒唐。写大章时，同一规则要经历重复、加深、产生后果和照常继续，不能只是重复台词。

## 工作流

```
章纲 Progress · 冷叙荒诞:
- [ ] 1. 读 chapter-structure，确认三圈已排
- [ ] 2. 读 风格总纲/07-冷叙荒诞.md 只作方向
- [ ] 3. 锁定人人遵守的普通规矩
- [ ] 4. 写出重复句或重复动作
- [ ] 5. 写章纲（平说，不解释）
- [ ] 6. 过门：不煽情；孩子不是天才观察者；日子还要继续
```

**Step 3** 例如：孩子是中心，但不问他；来得最多的人被说落后；懂事被夸奖的瞬间正是他不再指望。  
**Step 4** 外圈重复那句「真懂事」「真胖」「吃了没」。  
**Step 6** 诗意苦难、社会评论旁白，全删。

## 本章要看见

- 普通规矩
- 遵守它怎样伤人
- 章末生活照常，这就是疼

## 大章规则

先写哪种普通规矩最终造成不可逆，再排 5–7 场：第一次认真执行 → 外圈重复 → 更正确地执行 → 孩子配合 → 后果 → 日子照常。

## 场卡模板

```markdown

## 这场主线
[人人正确，叠在一起哪里荒唐]

## 上一场结果 / 下一场问题

## 房间 / 钟

## 三圈在场
- 内圈：
- 中圈：
- 社会压力：[外圈或规则同样认真的一句 / 一个动作]

## 普通规矩
[大家都觉得对的]

## 重复
[哪句话、哪件事本章出现两次以上]

## 谁先伸手

## 人物事件
[白描。不写「他很难过」]

## 状态变化
[重复深了一寸，谁更熟练地配合或停止指望]

## 思想一寸 / 人物变化 / 背景变化
[按 novel-thought-ground 三栏写满]

## 孩子学会什么
[他的「没事」更顺]

## 接到下一场
[日子继续]
```

## 禁

哭腔、把荒诞讲成道理、让孩子口吐主题、给外圈开滑稽戏。
