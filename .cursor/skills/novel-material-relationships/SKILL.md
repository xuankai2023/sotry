# Novel Material: Relationships

## Role

本 skill 只生成人物关系材料。不要写中纲，不要排章节，不要写完整正文。

若项目文件里有暂名或工作名，只作为当前工程上下文，不把它当成最终书名或唯一适用对象。

关系材料不是人物介绍。它要回答：两个人在一起时，谁欠谁，谁怕谁看见，谁用小事绕开大事，哪一个动作会让关系变形。每组必须写 `novel-thought-ground` 三栏：这组账压着哪一句思想、两人各变哪一寸、常用场会变哪处背景。

## Core Rule

每组关系都必须有两面：

- 对方确实给了有用的东西。
- 对方也把自己的缺口压了过来。

不要写成谁全对、谁全错。

## Output Template

```markdown
# 人物关系材料库

## 使用边界

- 只供正文调用。
- 不写中纲。
- 不给关系下结论。
- 每组关系都要落到动作、物件、空间和一句日常话。

## 周晓宁 — 林倩

### 表面关系
[一句]

### 真正的账
[谁欠谁什么，谁以为什么能还]

### 谁觉得自己有理
[具体理由]

### 谁觉得自己被亏待
[具体理由]

### 常谈的小事
- [小事]

### 避开的真话
- [真话]

### 关系紧时的动作
- [至少 8 条]

### 关系松时的动作
- [至少 5 条]

### 反复出现的物件
- [物件：如何变意]

### 最危险的一句话
[一句日常话，不要喊主题]

### 最疼的一句话
[一句日常话]

### 可直接入正文的关系细节
- [至少 10 条]

### 思想落地
- 思想：
- 人物变化：
- 背景变化：

## 周晓宁 — 周桂芳
[同模板]
```

## Material Rules

- “关系紧”不要只写吵架，可以写夹菜停住、钥匙放错、门口不等、收据没拿出来。
- “关系松”不要写和解，可以写少催一句、灯多留一会儿、碗没往前推。
- 每组必须有一个常用场：灶边、饭桌、门口、听筒、单位、客厅帘后、校门口。
- 每组必须有一个常用物：碗、纸、门、钱、听筒、书包、凳、车铃。

## Quality Gate

生成后检查：

- 每组关系都有具体的“账”，不是泛泛亲情。
- 每组关系都有至少一句表面日常、底下很重的话。
- 每组关系都有动作材料，不只写心理。
- 没有给外圈人物开完整主线。
- 没有让人物突然把心里话说透。
- 每组都有思想、人物变化、背景变化。

## Default Prompt

```text
请为当前小说工程或我指定的小说，生成人物关系材料库。

禁止写中纲，禁止安排章节，禁止写完整正文。

请覆盖这些关系：
周晓宁—林倩、周晓宁—周桂芳、周晓宁—赵玉梅、周晓宁—周建军、周晓宁—周志刚、周晓宁—钱厚德、林倩—周桂芳、林倩—赵玉梅、林倩—周建军、周桂芳—赵玉梅、周桂芳—周志刚、赵玉梅—钱厚德。

每组关系都按以下项目输出：
表面关系、真正的账、谁觉得自己有理、谁觉得自己被亏待、常谈的小事、避开的真话、关系紧时的动作、关系松时的动作、反复出现的物件、最危险的一句话、最疼的一句话、可直接入正文的关系细节。

要求：
1. 每组至少 10 条可直接写进正文的关系细节。
2. 每组都要体现“有用但伤人”。
3. 每组都要落到一个场景和一个物件。
4. 不要让人物说破主题。
```
