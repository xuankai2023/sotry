# Chapter Outline · Warm Growth

只写**具体章节大纲**。不重写全书总纲。不改 `novel-style-warm-growth`。

先读 `../novel-chapter-structure/SKILL.md`。本 skill 只管这一风格怎么拆一章。

## 作用

把一章写成一次有限靠近：伤口仍在，有人多做半步。外圈可以看见，但不来主持和解。

## 工作流

```
章纲 Progress · 温柔成长:
- [ ] 1. 读 chapter-structure，确认三圈已排
- [ ] 2. 读 风格总纲/08-温柔成长.md 只作方向
- [ ] 3. 写明本章伤口仍在
- [ ] 4. 写明哪一个有限修补（只许一个，只许小）
- [ ] 5. 写章纲
- [ ] 6. 过门：没有「原来都是为我好」；大人不全体道歉
```

**Step 4** 修补是：晚到但仍到、红包少收一次、终于问一句想不想。不是原谅大会。  
**Step 6** 外圈若夸「你们家真和睦」，让内圈听着不对劲，不要顺着圆。

## 本章要看见

- 伤口具体在哪
- 修补小到第二天仍可能故态
- 晓宁分辨力长一寸，不是胜利

## 章纲模板

```markdown
# 第X章 · [一次小的不同]

## 这章主线
[靠近一点，什么仍不结案]

## 房间 / 钟

## 三圈在场
- 内圈：
- 中圈：
- 外圈：[看见修补或看见未修，不要来主持和解]

## 仍在的伤口
[具体]

## 有限修补
[一个动作。不许升成转折演讲]

## 谁先伸手

## 人物事件
[温，但不洗白]

## 不可逆
[有人做过一次不同；不等于家好了]

## 孩子学会什么
[不再把一切叫伤害，也不把一切叫爱]

## 接到下一章
```

## 禁

全体忏悔、成功证明往事值得、感恩教育、外圈当和事佬把账抹平。
