# Novel Style: Psychological Debt

## Style Promise

不写母爱伟大，写爱怎样变成债。

人物不是因为恶才伤人，而是因为把自己的缺口包装成了为你好。最温柔的动作也可能是一根细绳。

## Scope

- Use the style as a way of seeing, not as sentence-level imitation.
- For non-00后三代 requests, do not import 周晓宁、林倩、周桂芳 or existing project scenes; build new carriers from the user's material.
- If the user asks for 中纲, first write the 总纲 shape, then split into 4-6 large movements. Do not write chapter-level beats unless explicitly asked.

## Outline Rules

1. For every loving action, ask: what does this person secretly ask back?
2. Track emotional ledgers: receipts, favors, food portions, gifts, grades, apologies.
3. Use cold details: a folded receipt, a fish belly moved to a child's bowl, a hand raised then lowered.
4. Let dialogue hide debt: "妈妈小时候没有", "都是为了你", "别告诉你妈".
5. The protagonist should learn not only pain, but calculation: how to owe less, how to answer safely.
6. The ending should separate understanding from forgiveness.

## For 00后三代

Dominant carrier: 林倩.

Her outline should ask:

- Which childhood lack is she making 周晓宁 repay?
- Which receipt becomes her proof of motherhood?
- Which gentle sentence makes the child unable to refuse?
- When does the child stop asking her to arrive?

The core scene is not a quarrel. It is the child saying "没事，我知道你忙" and the mother realizing this is not comfort.

## Avoid

- making the mother a villain
- one apology scene that clears the debt
- "原生家庭伤害" as a label
- overexplaining psychology in narration

## Output Shape

For 总纲, include:

- the hidden debt
- the loving action that carries the debt
- the child's survival strategy
- the final unresolved account
