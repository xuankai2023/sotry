# Novel Material: Dialogue Subtext

## Role

本 skill 只生成对话潜台词材料。不要写中纲，不要排章节，不要写完整正文。

若项目文件里有暂名或工作名，只作为当前工程上下文，不把它当成最终书名或唯一适用对象。

对话不负责解释主题。对话只负责让人物绕开真话，同时让读者听见真话。每人必须补 `novel-thought-ground` 三栏：这些短句压着哪一句思想、说完后此人嘴/手差哪一寸、屋里背景哪句外压或哪样东西变了。思想写在材料里，禁止写进台词。

## Core Rule

家庭对话要短。最重的话常常伪装成：

- 吃了没
- 还行
- 我马上
- 听话
- 没事
- 别告诉你妈
- 你们忙
- 第几名
- 都是为了你
- 先这样

不要让人物说：

- “我是在补偿自己的童年”
- “你们的爱让我窒息”
- “这是代际创伤”

## Output Template

```markdown
# 对话潜台词库

## 使用边界

- 只供正文调用。
- 不写中纲。
- 不写人物演讲。
- 台词短，句后必须有动作或沉默。

## 周晓宁

### 常说短句
- “[短句]”

### 短句拆解
#### “[短句]”
- 表面意思：
- 底下藏着：
- 通常对谁说：
- 什么情况下说：
- 对方会怎么误解：
- 句后适合接的动作：
- 句后适合接的沉默：

### 不能说出口的话
- [真话]

### 适合他的半句
- [半句]

### 思想落地
- 思想：[这些短句绕开的具体问题]
- 人物变化：[说完后嘴/手差哪一寸]
- 背景变化：[屋里哪句外压或哪样东西变了]

## 林倩
[同模板]
```

## Pair Dialogue

输出末尾补一组“关系对话种子”，不写成完整场景：

```markdown
## 关系对话种子

### 周晓宁 — 林倩
- 表面谈：[小事]
- 真正避开：[真话]
- 可用短句：
  - A：“”
  - B：“”
- 句后动作：

### 林倩 — 周桂芳
[同模板]
```

重点关系：

- 周晓宁—林倩
- 周晓宁—周桂芳
- 林倩—周桂芳
- 周桂芳—赵玉梅
- 林倩—周建军

## Quality Gate

生成后检查：

- 每个人至少 15 句短句。
- 每句都有表面意思和底下意思。
- 每句后面能接动作或沉默。
- 没有心理学标签。
- 没有长篇控诉、道歉、原谅演讲。
- 每个人都有思想、人物变化、背景变化；思想没有写进台词。

## Default Prompt

```text
请为当前小说工程或我指定的小说，生成对话潜台词库。

禁止写中纲，禁止安排章节，禁止写完整正文，禁止人物演讲。

请覆盖：
周晓宁、林倩、周桂芳、赵玉梅、周建军、周志刚、钱厚德、同楼邻居、林倩同事、班主任、同学家长、校门口小贩或冰柜老板。

每个人都要输出：
常说短句、每句表面意思、底下藏着什么、通常对谁说、什么情况下说、对方会怎么误解、句后适合接的动作、句后适合接的沉默、不能说出口的话、适合他的半句。

要求：
1. 每个人至少 15 句短句。
2. 台词要像中国家庭日常说话。
3. 多用“吃了没”“还行”“我马上”“听话”“没事”“别告诉你妈”“你们忙”“第几名”“都是为了你”这一类短句。
4. 不要把主题说穿。
```
