# Chapter Outline · Family Realism

只写**大章纲或具体场卡**。不写完整正文，不重写全书总纲，不改 `novel-style-family-realism`。

先读 `../novel-chapter-structure/SKILL.md` 与 `../novel-character-craft/SKILL.md`。大章包含 5–7 场并承担不可逆；一房、一钟、一物、一动作只约束单场。本 skill 只管家庭现实主义怎样排大章和场卡。人物性格与身世按 character-craft 塑造，不要只排物件。

## 作用

把已锁的总纲落成：

- **大章纲**：5–7 场形成「日常—施压—选择—后果—回声」，章末关系回不去；必须有本章人物。
- **场卡**：一场里谁想要什么、谁阻止、做了什么小选择、状态怎样改变；必须有身世一寸和声音差。

场卡齐后写细纲：转 `novel-fine-outline`。怎么写这一篇、按材料拼开写包：转 `novel-article-assemble`。完整正文统一转 `novel-prose-from-outline`。

## 工作流

```
章纲 Progress · 家庭现实主义:
- [ ] 1. 读 chapter-structure，确认用户要大章纲还是场卡
- [ ] 2. 读 番茄/00hou-sandai/风格总纲/01-家庭现实主义.md 只作方向，不扩成新总纲
- [ ] 3. 大章先锁不可逆与 5–7 场因果；单场再锁房间、钟、小选择
- [ ] 4. 写本章人物：进章状态、身世一寸、手、嘴、章末只挪一寸
- [ ] 4.5 写本章/本场思想、人物变化、背景变化（见 novel-thought-ground）
- [ ] 5. 写大章纲或场卡（含身世本场只露、声音差、三栏）
- [ ] 6. 过门：社会压力进入；不可逆在内圈；没有狗血事故；遮名能认人；三栏不是口号
```

**Step 1** 大章缺社会压力或不可逆，退回 structure；单场缺即时欲望或状态变化，也退回。  
**Step 2** 风格承诺：真实家庭，不写狗血。力气在小选择。  
**Step 3** 单场只做一个主选择：先端碗、请不出假、收下红包、站门口、说没事。大章要让选择产生后果和反弹，不能重复 5 次同一动作。  
**Step 4** 按模板交稿。  
**Step 5** 有绝症、出轨、大吵翻桌、新闻抢戏，重写。

## 本章要看见

- 小选择堆在谁身上
- 外圈那一句比较或随礼，怎样让内圈更难退
- 人人有用，也人人伤人

## 大章附加结构

写大章纲时，先列：

```markdown
# 大章X · [章名]

## 大章问题
[本章逼人物面对什么]

## 起始状态 / 目标不可逆

## 5–7 场因果
1. [日常场：状态]
2. [外压或误认场：状态变化]
3. [选择场：小选择]
4. [后果场：关系变化]
5. [反弹或回声场：逼出下一章]

## 社会压力
[至少两次，但不强制每场都出现外圈真人]

## 本章人物
[按 novel-character-craft。每人：进章状态 / 身世一寸 / 手 / 嘴 / 章末只许挪的一寸]

## 本章思想 / 人物变化 / 背景变化
[按 novel-thought-ground 三栏写满]

## 接到下一大章
```

再为需要开写的每一场填下面的场卡。

## 场卡模板

```markdown
# [大章X-场Y] · [物件名]

## 这场主线
[一句。小选择造成什么关系变形]

## 上一场结果 / 下一场问题

## 房间 / 钟
[一个场。从何时到何时]

## 三圈在场
- 内圈：[谁扛]
- 中圈：[谁照，或无]
- 社会压力：[外圈真人，或电话 / 纸 / 班表 / 旧话；无则说明本场为何可以留白]

## 事件
[一件家里的事，不是主题]

## 谁先伸手
[具体手]

## 人物事件
[每人两三句：要什么，做了什么，伤了谁。必须能看出是这个人的办法，不是通用家长。]

## 身世本场只露
[限知哪一寸，压在哪个动作上。禁止童年全文。]

## 声音差
- [限知]：句长 / 常说 / 句后手
- [在场对手]：必须能和上一行分开

## 状态变化
[场末谁知道、误会、停止等待，或哪件物件换了归属]

## 思想一寸
[本场落地的具体问题]

## 人物变化
- 进场：
- 出场：

## 背景变化
- 进场：
- 出场：

## 孩子学会什么
[身体或嘴上的办法。不许假懂国家]

## 接到下一场
[本场结果怎样逼出下一场]
```

## 禁

亲情大团圆、老人落后扁平三角、物件展览、单场换三个主场、每场机械安排邻居、给外圈开十年弧光、把场卡直接冒充正文、大章纲没有本章人物、场卡没有身世一寸或声音差、大章纲或场卡没有思想/人物变化/背景变化。
