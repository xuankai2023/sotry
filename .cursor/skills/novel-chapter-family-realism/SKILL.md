# Chapter Outline · Family Realism

只写**具体章节大纲**。不重写全书总纲。不改 `novel-style-family-realism`。

先读 `../novel-chapter-structure/SKILL.md`。结构（三圈、一房、一钟、一不可逆）以那个 skill 为准。本 skill 只管这一风格怎么把一章拆开。

## 作用

把已锁的总纲，落成能开写的一章：谁在场、做什么、哪一下回不去。

## 工作流

```
章纲 Progress · 家庭现实主义:
- [ ] 1. 读 chapter-structure，确认三圈已排
- [ ] 2. 读 番茄/00hou-sandai/风格总纲/01-家庭现实主义.md 只作方向，不扩成新总纲
- [ ] 3. 锁本章：房间、钟、小选择
- [ ] 4. 写章纲（用下面模板）
- [ ] 5. 过门：外圈有人；不可逆在内圈；没有狗血事故
```

**Step 1** 缺外圈或不可逆，退回 structure，不要往下编。  
**Step 2** 风格承诺：真实家庭，不写狗血。力气在小选择。  
**Step 3** 本章只做一个小选择：先端碗、请不出假、收下红包、站门口、说没事。  
**Step 4** 按模板交稿。  
**Step 5** 有绝症、出轨、大吵翻桌、新闻抢戏，重写。

## 本章要看见

- 小选择堆在谁身上
- 外圈那一句比较或随礼，怎样让内圈更难退
- 人人有用，也人人伤人

## 章纲模板

```markdown
# 第X章 · [物件名]

## 这章主线
[一句。小选择造成什么关系变形]

## 房间 / 钟
[一个场。从何时到何时]

## 三圈在场
- 内圈：[谁扛]
- 中圈：[谁照，或无]
- 外圈：[谁进门或在门口说话，干什么，走后留下什么]

## 事件
[一件家里的事，不是主题]

## 谁先伸手
[具体手]

## 人物事件
[每人两三句：要什么，做了什么，伤了谁]

## 不可逆
[章末哪句关系回不去]

## 孩子学会什么
[身体或嘴上的办法。不许假懂国家]

## 接到下一章
[只写下一章的房间或选择，不写全书]
```

## 禁

亲情大团圆、老人落后扁平三角、物件展览、一章换三个场、给外圈开十年弧光。
