# 性格变化栏位

栏名不要改。空栏用「本部分不碰」或「总纲未标，不补」占住。不要把总纲栏抄进中纲，也不要把中纲写成场卡进/出。

## 总纲

只在写总纲、或总纲此人完全没有开篇→终局时用。已有散文总纲，不要为了对齐本表而整段改写，除非用户点名。

嵌进 `novel-master-outline` 的「人物变化」。扛戏的人写满；会限知的中圈可短，但终局一寸、可见证据不能空。中圈几乎不变也准。

```markdown
## 性格变化（全书）

### [姓名]
- 开篇性格（手 / 嘴 / 办法）：
- 主变（只选一种）：加硬 / 裂缝 / 换物 / 嘴缩 / 手收 / 误认 / 长出
- 伴随（可空，只写证据，不另起弧）：
- 核心办法始终是：
- 压变的不可逆场面（2–4 个，只点名）：
- 各部一寸：
  - 一部：
  - 二部：
  - 三部：
  - 四部：
  - 五部：
  - 六部：
- 终局只许差的一寸：
- 可见证据：
- 不许完成 / 不许变成：
- 压在哪一句思想上：
```

各部一寸每部半句。不经过此人的部写「本部分不碰」。后部本领不准写进前部。

### 压缩写法（仅当用户只要短总纲）

```markdown
- **[姓名]**：开篇〔手/嘴〕→ 主变〔一种〕→ 终局〔一寸〕。压变：〔场面名〕。证据：〔动作/物〕。不许：〔〕。
```

## 中纲

总纲已定（散文也算）：以总纲为主。先读 [extract.md](extract.md)，再填栏。主变有则抄，无则写「总纲未标，不补」。

```markdown
## 本部分性格变化

### [姓名]
- 进部：这个年段的办法 / 手 / 嘴
- 本部分主变：〔抄总纲 / 总纲未标，不补〕
- 被哪一件不可逆或哪一章的选择压到：
- 出部只挪：
- 可见证据：
- 本部分不许完成：
- 下一部分才能碰：
```

进部对上一部出部。第一部对总纲开篇。对不上总纲原句：停，不暗改。

## 禁

- 总纲各部一寸写成六场细纲
- 中纲重复总纲人物志或把终局搬进前部
- 因总纲没有主变栏就重开合同
- 用默认弧覆盖总纲散文
- 可见证据写成「内心更强大」
- 主变栏写两个以上；伴随升成第二条弧
