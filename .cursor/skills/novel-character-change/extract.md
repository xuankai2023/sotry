# 从总纲抽出中纲一寸

总纲已定（栏目或散文都算）时用本页。本 skill 为辅：只抽取，不设计。

## 四步

1. **抄终局，先锁死。** 总纲此人最后只许差哪一寸、不许变成什么。中纲出部必须比终局小。最后一部才能碰到终局，仍不准写完审判/和解。
2. **抄该部总结构，不是抄全书人物段。** 总纲「总结构 / 第 X 部」写这部丢掉或换上什么。人物段里的终局句子，本部用不上就别搬。
3. **只取落在本部的不可逆。** 总纲点名、时间或位置属于这部的场面，才是压变。后部的场面写「下一部分才能碰」。
4. **写成进/出各一句。** 进部 = 上一部出部；第一部进部 = 总纲开篇。出部 = 总纲允许这部发生的那一寸。可见证据必须是本部主场的手、嘴、物。

总纲没有「各部一寸」表：用第 2、3 步推，不要去填一份假的全书表。  
总纲没有主变标签：中纲不补。  
对不上总纲：停，写明引用了总纲哪一句、卡在哪，不暗改。

## 对照例（00 后三代）

真源是 `总纲-大师写法.md`。下面只示范抽取，不要把例当第二份总纲。

### 例 A · 中纲第一部「证据」· 晓宁

总纲已定：这部分重点不是孩子成长，是被命名、被拍照、被分配。开篇只有身体。终局才是关门、说还行。

```markdown
### 周晓宁
- 进部：热、响、奶腥、被转手。无性格。
- 本部分主变：总纲未标，不补
- 被哪一件压到：满月酒被写下
- 出部只挪：身上多了蛋、簿、条、合影；仍不会看家
- 可见证据：被抱去桌边、被写进格、手从外侧伸进画面时他没醒
- 本部分不许完成：看脸色、撒谎、关门、懂事
- 下一部分才能碰：空椅子、听筒、他把一天说完
```

错：一部写出「他先配合后撒谎」。那是全书句子，不是本部。

### 例 B · 中纲第二部「缺席」· 林倩

总纲已定：她用纸当在场；怕缺席却在缺席边上跑；终局才是晚托那句「我知道你忙」。二部是班和钱把人抽走，电话切成两头。听筒落在这部。

```markdown
### 林倩
- 进部：罐和说明书还想插进灶；人还在，纸已比手硬
- 本部分主变：总纲未标，不补
- 被哪一件压到：听筒 / 打卡纸 / IC 卡
- 出部只挪：在场改走听筒和假条；孩子的完整一天被她删短
- 可见证据：灶边听筒、卡在走、话停在「吃了没」
- 本部分不许完成：少年宫全文、晚托「我知道你忙」、悔过
- 下一部分才能碰：抢勺时她不在场的那一层
```

错：把主变改成「手收」并重写她会变成什么样。纸换听筒是本部；人抽光、孩子判她，是后部。

### 例 C · 中纲第二部「缺席」· 桂芳

总纲已定：日常才是权力；她用带孙证明还能用；终局是孩子关门，她输给时间，不是输给林倩。

```markdown
### 周桂芳
- 进部：蛋和桌已经像合格品，灶权还未写死
- 本部分主变：总纲未标，不补
- 被哪一件压到：第一把勺
- 出部只挪：勺和日常落到她手里；说明书压得住字，压不住胳膊
- 可见证据：水温她试、孩子在她臂弯不哭、林倩把话咽下去
- 本部分不许完成：抢勺赢解释权、别告诉你妈、守塑料凳
- 下一部分才能碰：两只勺同时伸过来
```

## 自检

- 把出部句子放到终局，故事是不是提前结束了？是，就删。
- 把出部换到另一部，是否仍然成立？是，说明没抽到本部。
- 有没有出现总纲禁止的变成（反抗英雄、悔过妈妈、开明奶奶）？有，退回。
