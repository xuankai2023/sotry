# Novel Character Change

性格变化不是换标签，不是「他成长了」。是**同一套爱的办法**被不可逆场面压出看得见的一寸差。

不写场卡，不写正文，不改冻结矩阵。打开本 skill ≠ 重写骨头。

## 主辅 · 何谓已定

**总纲性格变化一旦定了，写中纲以总纲为主，本 skill 为辅。**

已定，不看有没有「主变」二字。下面任一为真，就已定：

- 总纲用栏目写了开篇手/嘴、终局一寸、不许变成
- 总纲用散文写了此人开篇是谁、终局差哪一寸、不许变成什么（00 后三代：`总纲-大师写法.md` 的扛戏的人 + 总结构 + 结尾 + 六个不可逆）
- 总纲六部/四至六段走向里，已经写明这部这个人丢掉或换上什么

缺独立「性格变化」标题、缺主变标签、缺「各部一寸」表，**仍算已定**。中纲不得因格式不齐重开合同，也不得用 [sandai-arcs.md](sandai-arcs.md) 覆盖总纲散文。

| 阶段 | 主 | 本 skill 只做 |
|---|---|---|
| 总纲此人完全没有开篇→终局 | 本 skill 出合同 | 交给 `novel-master-outline` 收栏 |
| 总纲已定（栏目或散文） | **已落盘总纲** | 栏位、过门、从总纲**抽出**该部进/出 |

总纲没写到的人，中纲可补短栏，标明「总纲未锁，中纲暂补」，不得抢走已定的人的发动机。和总纲打架：停，写明冲突，不暗改总纲。

中纲怎么抽，见 [extract.md](extract.md)。栏位见 [template.md](template.md)。类型见 [change-types.md](change-types.md)。

## 和别的 skill 怎么分

| Skill | 管什么 |
|---|---|
| `novel-character-craft` | 此人是谁（身世、办法、手、嘴） |
| **本 skill** | 此人会怎么变；总纲未定时出骨头，已定时只抽一寸 |
| `novel-thought-ground` | 单场进/出，必须继承总纲/中纲 |
| `novel-master-outline` / `novel-mid-outline` | 宿主。总纲收合同；中纲收抽出的进/出 |

人物志没有核心办法，先回 `novel-character-craft`。  
00 后三代默认弧只在总纲**完全没写此人变化**时对照，见 [sandai-arcs.md](sandai-arcs.md)。它不是第二份总纲。

## 核心规矩

1. **性格 = 重复的手 + 不肯说的话 + 别人的误认。** 禁止「回避型 / 他成长了」。
2. **人不换，办法被压出形状。** 爱人和伤人仍是同一套动作。
3. **变化必须被不可逆场面压出来。** 不准「他想通了」。
4. **看得见。** 差在手、嘴、句长、路线、物件。
5. **总纲不写完弧光。** 中纲只挪本部分一寸。
6. **年段门。** 婴儿没有性格。大人不提前说后文的话。
7. **中纲不另起骨头。** 已定总纲只落地，不改终局，不换压变场面。

## 主变一种，伴随最多一种

每人全书只锁一种主变。伴随（如换物的人同时手收）只写进可见证据，不另起第二条弧，不换主变名。

| 主变 | 意思 |
|---|---|
| 加硬 | 办法更密、更不松手 |
| 裂缝 | 办法还在，手停半拍 |
| 换物 | 缺口不变，改抓另一件物 |
| 嘴缩 | 整句收成半句或动作 |
| 手收 | 先伸的手变成后伸或空着 |
| 误认 | 别人更把他当功能，他靠那层皮 |
| 长出 | 只给孩子：从身体长出办法 |

总纲是散文、没有主变标签：中纲**不必补标签**。只写进/出。补标签容易和总纲打架。

中圈可以几乎不变。写「本部分不碰」或「嘴更短半寸」即可，不准为了填表硬造弧光。

## 总纲必须交

只在**写总纲**或总纲此人完全没有开篇→终局时用。模板见 [template.md](template.md)。

每人要有：开篇手/嘴/办法；一种主变；始终那一套办法；2–4 个压变不可逆（只点名）；各部半句（不碰的部写「本部分不碰」）；终局一寸 + 可见证据；不许变成；压在哪一句思想上。

新写总纲用栏目。已有散文总纲不要为了对齐本 skill 而整段改写成表，除非用户点名要补栏。

## 中纲必须交

先判定已定，再按 [extract.md](extract.md) 抽。模板见 [template.md](template.md)「中纲」。

只交：进部、被哪一章/哪件不可逆压到、出部只挪、可见证据、本部分不许完成、下一部分才能碰。主变有则抄，无则空着或写「总纲未标，不补」。

## 工作流

```text
性格变化 Progress:
- [ ] 1. 宿主：总纲 / 中纲
- [ ] 2. 此人在总纲里算不算已定（散文也算）
- [ ] 3. 总纲未定：选一种主变，写全书合同
- [ ] 4. 总纲已定：跳过选主变；按 extract.md 只抽该部
- [ ] 5. 过门；嵌回宿主；停
```

### 嵌在总纲（仅未定时）

1. 人物志先有核心办法。
2. 按模板写「人物变化」。
3. 每个不可逆至少压一个扛戏的人。
4. 交回 `novel-master-outline`。

### 嵌在中纲（已定为主）

1. 打开总纲此人段 + 该部总结构 + 落在本部的不可逆。不要先打开 `sandai-arcs.md`。
2. 按 [extract.md](extract.md) 写成进/出。
3. 出部嘴必须对得上中纲声音差。
4. 交回 `novel-mid-outline`。

## 过门

任一为真，没过：

- 「他成长了 / 更懂事了」代替手和嘴
- 开篇和终局对白可以互换
- 没有压变场面，或场面与办法无关
- 核心办法换成另一套人格；或把伴随升成第二条主变
- 总纲写完原谅 / 和解 / 审判全家
- 中纲把终局手/嘴提前用完
- 总纲已定（含散文），中纲改终局、改压变，或用默认弧覆盖
- 因总纲没有「主变」栏就重开性格合同
- 婴儿有成人式判断
- 两人合同对调后仍成立
- 中圈被硬造十年弧光

通过后嵌回宿主。用户只要变化：交合同或抽出的进/出，停。00 后三代落盘：总纲已有散文则中纲变化写进 `中纲/部分/`；不改三份冻结矩阵；不把散文总纲擅自改成表。

## 不要做

- 不套好莱坞受伤→顿悟→新人
- 不写改过自新
- 不用外圈宣布某人变了
- 不改冻结矩阵
- 不把 `sandai-arcs.md` 当成总纲
- 已定之后不用本 skill 重写此人会变成什么样
