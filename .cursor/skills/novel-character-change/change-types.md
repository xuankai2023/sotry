# 性格变化类型

只在**写总纲**或总纲此人完全未定时选主变。类型是合同，不是心理学诊断。例里的物是对照，新书换成该书的物。

伴随（换物的人同时手收等）写进可见证据，不另起弧，不换主变名。中纲若总纲未标主变，不要用本页补标签。

## 加硬

办法还在，用得更密、更不松手。别人会觉得他「还是那样」，只是更难劝。

- 开篇：手还会停一下，还会把东西交出去。
- 终局：同一只手按住不放；嘴更短。
- 验：删掉「更固执」，只看他多做了几次同一动作。
- 典型伤：有用的办法把空隙吃光。

## 裂缝

办法还在，但手会停半拍，或做完自己也知道不够。

- 开篇：伸手不犹豫。
- 终局：仍伸手，晚了、轻了，或做完把东西放回原处多停一秒。
- 验：他没有改行，只是旧动作裂开。
- 禁止写成顿悟后改过自新。

## 换物

伤口还是那个，抓的东西换了。

- 开篇：用蛋、桌、假条证明自己。
- 终局：改用收据、班、门、折子证明同一件事。
- 验：把物换回开篇那件，他要证明的话仍然成立。
- 禁止写成「她找到了新爱好」。

## 嘴缩

整句收成半句、数字、或句后的手。

- 开篇：还能把一天说完，或还能问一句整的。
- 终局：只剩「还行」「中」「吃了没」，或只动手。
- 验：遮住姓名，句长必须比开篇短，或不说的那半句变长。
- 禁止用内心独白补回他说出口的话。

## 手收

先伸的手变成后伸、只伸到外侧、或空着。

- 开篇：人到了就伸手。
- 终局：人还在场，手在膝上、在包盖、在门缝外。
- 验：场面还需要他，他的手不再完成那一下。
- 禁止写成离家出走或当上冷漠反派。

## 误认

家里越来越把他看成一种功能，他也越来越靠那层皮活。

- 开篇：别人偶尔看错他。
- 终局：别人固定用一个称呼/差使他；他用同一套动作坐实误认。
- 验：变化发生在别人怎么使唤他，以及他怎么配合。
- 禁止写成「摘下面具，真我出现」。

## 长出

只给孩子用。从热、响、被转手，长出一套自己的办法。

- 开篇：没有性格，只有身体。
- 中间：看碗、看鞋、看谁先伸手；谁喂往谁那边歪。
- 终局：有了关门、撒谎、说还行这一寸办法。不是反抗宣言。
- 验：每一部只长出一种可见本领，不能一部写完「他懂了家」。
- 禁止婴儿有成人式判断。

## 怎么配不可逆场面

| 场面做了什么 | 通常压出 |
|---|---|
| 同一办法第一次公开成功 | 加硬 |
| 同一办法救了场却伤了人 | 裂缝或加硬（选一个） |
| 旧物不够用，换一件纸/门/钱 | 换物 |
| 话说完会破家，所以删短 | 嘴缩 |
| 人在，资格不在 | 手收 |
| 外圈给了一个功能名 | 误认 |
| 孩子第一次会藏、会配合、会关门 | 长出 |

一个场面可以压两个人，但每人仍只走自己的主变。
