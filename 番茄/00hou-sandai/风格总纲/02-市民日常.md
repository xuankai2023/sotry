# 市民日常总纲

对应 skill：`novel-style-urban-daily`

## 一句话

周桂芳把带孙过成一份没有考勤机的班：锅、粥、菜场、阳台、铁门、联播；后来孩子不再走这条路线，她的一天还在，权力却空了。

## 这本书真正写什么

不喊命运。写江州单位楼里一个退休女人的日程怎样变成全家的钟。

女人不是符号。她们管时间、管食物、管面子、管等待。冲突来自钟点撞上，不来自演讲。

## 主场与路线

主场：厨房、阳台、校门口、客厅加床。

日常路线：起床 → 起锅 → 菜场 → 铁门 → 联播 → 饭桌。

林倩的路线是另一条：单位 → 假条 → 超市收据 → 晚归。两条线每天在门口错过。

## 谁扛戏

**周桂芳**为主。日程是她的骨头。她怕的不是累，是闲下来像被退掉。

**林倩**用另一套城市时间对抗：买、签、报、催。她改得了超市，改不了粥点。

**周晓宁**开始跟着奶奶的路线走，后来改走房间和屏幕。他一改走，奶奶的班还在，岗位却空了。

赵玉梅是另一条晾衣竿：衣服晾在最外一排，夜要留在娘家。钱厚德送到楼下就走。周建军的喇叭偶尔打断路线，打断完就走。

## 哪条日程断了

断的不是国家，是孩子不再跟她去门口、不再坐在联播旁边、不再让她先伸勺。

谁丢权：重复做事的人。新路线：孩子关门，母亲继续叠纸，奶奶继续准点到达一个不再需要她那么紧的门口。

## 总结构

立钟 → 两条路线并行 → 钟点开始撞 → 孩子改道 → 旧路线空转 → 房子还在，走法换了。

## 结尾留下的问题

一个女人把一生最准的时间都给了这个家。家还在，她的钟还在响，听的人却换了地方。这算胜利，还是退场？
