# 心理债务 · 正文词句语料扩展库
> 只供写 `心理债务` 正文时调用。供临时抽取，不要整段照搬，选一个动作、一个物件、一个短句即可。
## 风格定位
- 主视角重心：林倩。
- 核心写法：爱是账，懂事是结账。收据、鱼肚子、报名表都带着“你要知道”。
- 观察入口：付出和记账。
- 句子气质：句子冷一点，账不明说，纸、钱、好菜和半句谢谢自己压住人。
- 禁区：不要直写愧疚、亏欠、补偿心理；让纸、钱和好菜替人物开口。
## 抽取顺序
1. 先定这一场谁先伸手，谁慢半拍。
2. 抽一个动作或物件位置。
3. 抽一句家常话或外圈轻话。
4. 用声味光或放回动作收束。
5. 细词不够时，只进 `词库/00-索引.md` 里一个分文件。

## 本风格句式

- “你要知道。”说完，收据没有动。
- “都是为了你。”说完，报名表没有动。
- “不贵。”说完，鱼肚子没有动。
- “我没说累。”说完，红包袋没有动。
- “给你存着。”说完，工资袋没有动。
- “以后就懂了。”说完，月供单没有动。
- “不用谢。”说完，存折没有动。
- “这钱该花。”说完，补课单没有动。
- 给得越多，越希望别人记住；记住以后，爱就变成账。
- 这一场不解释付出和记账，只让手和物件自己露出。

## 禁用替代表

- 不写“焦虑”，写“收据被又挪了半寸”。
- 不写“控制”，写“报名表已经到了孩子面前”。
- 不写“愧疚”，写“鱼肚子被放下却没人问想不想”。
- 不写“疏离”，写“他说嗯，眼睛看门缝”。
- 不写“成长”，写“他第一次自己把东西放回去”。
- 不写“时代变迁”，写“包内夹层换了位置”。
- 不写“和解”，写“这次没人追问第二句”。
- 不写“懂事”，写“他先看脸色再答”。
