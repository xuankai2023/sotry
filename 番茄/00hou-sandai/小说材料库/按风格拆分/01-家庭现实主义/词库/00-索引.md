# 家庭现实主义 · 词库索引

> 从 `09-正文词句语料扩展库.md` 分出来的细词库。一场只开 1 个分文件，抽 2–4 条。不要整包读，不要和其他风格词库混用。

## 怎么抽

1. 先锁这场看哪里：手 / 脸 / 鞋 / 碗 / 门 / 纸 / 灯。
2. 打开对应分文件，先从「可用词」取 1 个主词、1 个配件。
3. 再从「搭配」取一组，最后才取 1 句「可入正文」。
4. 句后必须还能接一个小选择：先伸、慢半拍、放回、说没事。

## 分文件

1. [部位衣着](01-部位衣着.md)：每部有可用词、搭配、可入正文。发、五官、手、脚、衣、鞋、包。
2. [物件部位](02-物件部位.md)：碗沿碗底、门缝锁舌、纸的折痕栏、听筒卡角、车铃棉垫。
3. [声味光天气](03-声味光天气.md)：声源词、气味词、灯种、触感；雨热冷改接送或关门。
4. [按人动词](04-按人动词.md)：通用动词 + 每人常用动词，再按力度取句。
5. [句式变奏](05-句式变奏.md)：槽位词、半句、开场收束、十年链条。

## 禁

- 不写美丑鉴定、慈祥刻薄。
- 不写象征亲情、象征时代。
- 天气不单独美，必须改凳、鞋、饭、门。
- 一场不用两套变奏链。
