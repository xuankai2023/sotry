# 家庭现实主义 · 声味光天气词库

> 声、味、光、天气必须改变动作：出门慢、饭凉、门关、凳湿、纸皱。先抽词，再抽一句。不写抽象嘈杂，不写单独的季节美。

## 怎么抽

1. 从「可用词」取 1 个声源或气味源。
2. 落到一件物上：门、鞋、饭、凳、纸。
3. 再从「可入正文」取 1 句。

## 室内声

### 可用词

- 灶上：锅盖、锅沿、勺刮碗边、碗底碰桌、水壶冒气、电饭煲跳闸、水龙头滴、煤气打火
- 桌上：筷子点碗沿、椅子腿拖地、转盘吱声、酒瓶碰杯
- 水电：热水瓶塞、冰箱门吸住、洗衣机（少用）、扫帚
- 纸包：塑料袋揉团、书包拉链、笔帽、假条滑出、报纸翻页
- 门灯：声控灯咔哒、钥匙找锁孔、锁舌、合页、门碰、猫眼盖
- 屏幕：电视广告、新闻联播、收音机、电话铃、忙音、按键、键盘、主机风扇、鼠标滚轮、遥控器磕玻璃
- 床帘：帘环、加床腿展开、折叠床响

### 搭配

- 锅盖响 + 有人把话咽了 / 话题换了
- 忙音 + 比孩子的话早到
- 电视笑 + 饭桌不跟
- 拉链拉到最头 + 不想再被问
- 声控灯灭 + 后半句没地方落
- 锁舌响 + 门没摔
- 键盘声 + 盖住作业写了吗

### 可入正文

- 锅盖碰锅沿，像有人替她接了话。
- 锅盖响一下，话题换了。
- 勺刮碗边，话被刮回去。
- 碗底碰桌面，比不高兴更明显。
- 筷子点碗沿，一下就够。
- 椅子腿在水泥地上拖出短声。
- 转盘吱一声，菜到孩子面前。
- 热水瓶塞被拔开。
- 水龙头没拧死，厨房还在滴。
- 煤气打火“噗”一声，她又摸旋钮。
- 电饭煲跳起，人还没齐。
- 冰箱门吸住，只从剩菜和红包上擦过。
- 塑料袋被揉成一团。
- 书包拉链卡住，他低头拉了很久。
- 拉链拉到最头，是不想再被问。
- 笔帽扣得很响。
- 假条从文件夹滑出一角。
- 报纸翻页，他不再问第二句。
- 声控灯在楼道里咔一下灭了。
- 钥匙在门外找锁孔。
- 锁舌响了一声，门没有摔。
- 合页紧，虚掩也有声音。
- 电视广告忽然变响。
- 电视里的人笑，饭桌没人跟着笑。
- 新闻联播一开始，桌上的话要停。
- 电话铃响到第三声才有人接。
- 忙音比孩子的话更早到。
- 按键声和单位人声叠着。
- 键盘声盖住门外的脚步。
- 主机风扇热起来，客厅的声音退后一步。
- 鼠标滚轮停住。
- 遥控器磕在茶几玻璃上。
- 帘环响一下，门里门外两套话。
- 加床腿展开，探望变成占位。
- 拖鞋声比“我在”先到厨房。

## 室外声

### 可用词

- 校门：放学铃、书包扣子相撞、孩子喊、铁门、门卫报纸翻页、圆珠笔点本子
- 冰柜：冰柜电机、掀盖、找零钱
- 菜场：剁肉、称砣碰秤盘、讨价、塑料袋、雨棚滴水
- 车：车铃、刹车气声、公交车门、自行车链、喇叭、厂车
- 楼：楼上喊吃饭、邻居门响、电钻、风灌楼道、雨打窗、雨打台阶
- 单位：打卡声、传呼、高跟鞋敲走廊

### 搭配

- 车铃 + 按两下才响 / 蹭门柱不清楚
- 冰柜电机 + 等人的时间能听出来
- 邻居门响 + 屋里提前换表情
- 打卡声 + 那边也放学
- 电钻 + 自家门关得更早

### 可入正文

- 校门铃声散出来。
- 自行车铃按了两下才响。
- 车铃蹭到门柱，响得不清楚。
- 冰柜电机低低地嗡。
- 小店老板掀冰柜盖。
- 门卫亭里报纸翻页。
- 圆珠笔点在登记本上。
- 菜场剁肉声一下一下落着。
- 称砣碰上秤盘。
- 塑料袋在雨棚下响。
- 公交车刹车时一阵气声。
- 公交车门开合，她还在看假条。
- 自行车链涩一下，后座有人。
- 雨水从伞骨滴到台阶。
- 雨打窗，饭熟得更早。
- 风灌楼道，空篮子更轻。
- 孩子们跑过铁门，书包扣子互相撞。
- 楼上有人喊孩子回家吃饭。
- 邻居门响，屋里的人提前换表情。
- 电钻从隔壁传来，自家的门关得更早。
- 打卡声落下去，电话那头安静了一秒。
- 传呼在厂门口喊人。
- 高跟鞋敲单位走廊，比钟整齐。
- 铁门把准时和不准时分开。

## 味道

- 饮食：油烟、炒菜、米汤、粥、奶粉甜、蒜、葱、醋、酱油、鱼腥、血水、隔夜菜、煤气、酒、烟、二手烟
- 清洁潮霉：肥皂、洗衣粉、洗洁精、霉味、潮味、雨水味、泥土味、樟脑丸、刚洗的头
- 人与物：新书包塑料味、红领巾汗味、铅笔屑、红包印刷味、新床木头味、主机热塑料、机油、铁锈、油漆
- 单位医院：纸和墨水、药水、酒精、消毒水、碘酒、输液胶布
- 席面：烟酒、橘子皮、热油

### 搭配

- 米汤味 + 贴在厨房门口
- 油烟 + 钻进袖口 + 洗不淡
- 奶粉甜 + 洗洁精 + 同一块抹布

- 葱味 + 暴露她去过市场
- 机油 + 先于父亲进门
- 红包印刷味 + 比钱记得清
- 药水味 + 谁都说话小声

### 可入正文

- 米汤味贴在厨房门口。
- 油烟钻进袖口，洗了也淡不下去。
- 炒菜味起来，空椅子更显。

- 奶粉甜味和洗洁精味在同一块抹布上。
- 蒜和葱在菜篮里，她说买葱。
- 醋味从电视新闻里过来，桌上仍谈谁接。
- 鱼腥味还在，鱼肚子已经进了孩子碗里。
- 隔夜菜味说明有人没回来。
- 煤气味让她又摸一遍旋钮。
- 烟味先于周建军进门。
- 葱味暴露她确实去过市场。
- 肥皂味在她说手洗过了的时候。
- 洗衣粉味在阳台衣服上，加床更占地方。
- 潮墙味一层一层往上爬。
- 楼道烟味比人先到。
- 雨伞水和楼道潮味混在一起。
- 泥土味在布鞋上，她仍说顺路。
- 樟脑丸味在柜里旧碗旁边。
- 新书包的塑料味压过铅笔屑。
- 红领巾汗味在领口。
- 红包纸有一点印刷味，孩子记得比钱清楚。
- 新床的木头味让旧屋子显得更旧。
- 电脑主机热塑料味，大人进不去。
- 工装上的机油味先于父亲进门。
- 铁锈味在铁门边，塑料凳靠着。
- 办公室纸味和墨水味，家里那头是饭。

## 光线

### 可用词

- 自然光：晨光、窗光、斜光、阴天灰光、雨天窗光、灶火、路灯、夕光
- 室内灯：顶灯、吊灯、台灯、声控灯、灯缝、门缝光
- 屏幕：电视蓝光、电脑屏幕光、手机背光（诺基亚）
- 户外：门卫亭白光、铁门斜光、广告灯（少写）

### 搭配

- 灶火 + 照红手腕 + 水温谁说了算
- 顶灯 + 照收据 + 金额比菜亮
- 门缝光 + 落在脚边 + 没说完的话
- 声控灯 + 只亮一小截 / 灭得快
- 台灯 + 只照本 + 不照门外的脚
- 屏幕亮 + 眼睛不再看饭桌
- 门卫亭白光 + 迟到没处藏

### 可入正文

- 早晨窗光窄，桂芳已经在盛粥。
- 灶火把手背照红，也照出水温是谁说了算。
- 顶灯白，照得饭菜没有热气。
- 顶灯照着收据，金额比菜亮。
- 吊灯照桌面，电视光照到没动的菜。
- 电视蓝光把爷爷的脸照得更硬。
- 门缝光落在孩子脚边。
- 灯缝像一句没说完的话。
- 声控灯只亮一小截楼梯。
- 楼道灯亮得慢，脚步已经到了门口。
- 楼道灯灭得快，没人愿意再咳一声。
- 台灯只照作业本，不照门外的脚。
- 屏幕亮起来，孩子的眼睛不再看饭桌。
- 屏幕光亮起来，客厅的声音像退后了一步。
- 诺基亚背光比人先到家。
- 下午斜光照在塑料凳裂纹里。
- 路灯亮得早，等人的影子短。
- 门卫亭的白光让迟到没有地方藏。
- 雨天窗光灰，饭熟得更早。
- 阴天灯开得早，门关得早。
- 阳台衣服挡住一部分窗，加床更暗。
- 席面灯亮，孩子被照成证据。
- 夕光在铁门上，凳子还没人坐，她已经坐下。

## 触感

### 可用词

- 烫：碗沿、锅、灶台、塑料凳面、听筒壳、热水袋
- 冰：钥匙、门把手、铁门、搪瓷杯冬天
- 湿：伞水、袜口、裤脚、潮墙、湿地砖、抹布
- 勒：菜篮提手、塑料袋、包带、红领巾、绑绳、皮筋
- 硌：钥匙齿、凳脚短腿、车架、拉链牙
- 黏：油墨、汗、IC卡、油烟袖口
- 软硬：纸角软了、红包袋硬、棉垫、折痕

### 搭配

- 凳面发烫 + 贴手臂 + 不挪

- 红领巾 + 勒喉 + 不说
- 纸角软 + 折过太多次
- 油墨 + 粘指腹

### 可入正文

- 碗沿烫，他仍说不烫。

- 凳脚短的那只，坐下要先踩住。

- 钥匙齿硌进掌心。
- 门把手冬天冰一下。
- 铁门冷，她把手缩回袖里，凳子仍搬出来。
- 菜篮提手勒出红印。
- 塑料袋勒在手上，回家还在。
- 包带勒着肩。
- 红领巾勒喉，他不说。
- 棉垫绑绳勒出两道印。
- 雨伞水滴到肩上，凉的。
- 潮墙用手一摸就知道等不久。
- 湿地砖粘脚，菜场回家。
- 抹布拧干，水滴在地砖上。
- 纸角软了，折过太多次。
- 油墨粘指腹。
- 袜口湿一圈，像路上赶过。
- 车把上的手掌是热的，楼是冷的。
- 红包袋硬，钱已经不在。
- 折痕留在桌面上，纸走了。

## 节令与钟点词

### 可用词

- 节令：满月、春节、年夜饭、开学、家长会、端午、中秋、生日、寒假、暑假
- 节令物：红鸡蛋、礼簿、红包、粽子、月饼、蛋糕（少写）、作业
- 钟点：四点二十、放学点、打卡点、晚饭熟了、联播开始、晚托散场、夜里

### 搭配

- 春节 + 红包进谁口袋
- 开学 + 谁签字谁送谁系红领巾
- 家长会 + 座位空过一次
- 四点二十 + 凳子已经下楼
- 打卡声 + 那边也放学
- 联播一开始 + 桌上的话要停

### 可入正文

- 春节：红包进谁口袋，孩子的年换主人。
- 满月：礼簿比孩子醒没醒更受注意。
- 开学：谁签字，谁送，红领巾谁系。
- 端午：谁占灶，粽子是谁的口。
- 中秋：一盒饼能不能代替回家。
- 生日：孩子是被问过还是被展示。
- 年夜饭：必须在哪边，孩子先看勺。
- 家长会：座位空过一次，后面每次都像补考。
- 寒假作业：监督权摊开的方向。
- 暑假：谁有空，谁只有电话里的喝水了没。
- 四点二十，凳子已经下楼。
- 饭熟的时候，人没有齐。
- 打卡声响时，孩子那边也放学。
- 电话响的时候，锅里的水正开。
- 广告换了，他还没问第二句。
- 路灯亮得早，等人的人已经占好位置。
- 晚托散场，空教室比迟到更重。
- 新闻联播一开始，桌上的话要停。
- 夜里两个人都醒着，谁也不先问明天谁去。
- 第二天，那只碗又被摆到同一个位置。
