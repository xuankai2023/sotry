# 家庭现实主义 · 物件部位词库

> 物件写部位、朝向、谁碰过。一场一个主物件。先抽词，再抽一句。章末同一物件用法或位置必须变一寸。

## 怎么抽

1. 从「可用词」取主物件 1 个、部位 1 个。
2. 从「搭配」取谁碰、怎么放。
3. 从「可入正文」取 1 句。

## 碗勺盘

### 可用词

- 碗：饭碗、小碗、瓷碗、搪瓷碗、汤碗、空碗、扣着的碗
- 碗的部位：碗沿、碗口、碗底、碗壁、豁口、掉瓷处、热气、水印、米汤痕
- 勺：勺子、汤勺、喂勺、铁勺、瓷勺
- 勺的部位：勺背、勺头、勺柄、勺边
- 筷盘：筷子、筷尖、筷头、筷架、盘子、菜碟、鱼盘、汤盘、转盘
- 吃的：鱼肚、鱼尾、鱼刺、好菜、单独那一块、剩饭、剩菜、粥、米糊、馒头、蛋黄、肉末蒸蛋、排骨

### 搭配

- 碗沿 + 米汤干痕 + 拇指擦
- 碗底 + 碰桌面
- 碗口 + 对着谁
- 豁口 + 常用那边
- 勺背 + 蛋黄 + 孩子盯着看
- 勺头 + 停在嘴边
- 勺柄 + 两只手碰上
- 半空 + 停住的勺
- 筷尖 + 停在鱼盘上方
- 碗拉近半寸 + 自己守住吃饭

### 可入正文

- 碗沿有一圈米汤干痕。
- 碗口对着谁，谁就暂时有孩子的身体。
- 碗底碰桌面，比一句不高兴更明显。
- 碗壁上的油圈凉了。
- 豁口在常用的那边，桂芳用拇指避开。
- 掉瓷处卡着一粒饭。
- 热气少了一截，人还没齐。
- 水印刚擦过，她又推半寸。
- 小碗没变，是孩子手变大。
- 空碗扣着，像还在等人。
- 搪瓷碗磕在灶边，她不换瓷的。
- 碗被拉近半寸，像先守住吃饭。
- 碗放回原处时比端出去时轻。
- 汤碗里的油圈对着空椅子。
- 勺背粘着蛋黄，孩子盯着看，不看人。
- 勺头停在嘴边。
- 勺柄上两只手碰上。
- 勺边刮一下，像把话刮回去。
- 半空停住的勺，比骂人更重。
- 谁先放下勺，谁当天像让了一步。
- 铁勺烫手，她仍说不烫。
- 筷子尖停在鱼盘上方。
- 筷头点碗沿，一下就够。
- 筷子横在碗口，说先吃饭。
- 菜碟被转到孩子面前，又转回中间。
- 鱼盘上的肚子走了，尾巴还在。
- 转盘吱一声，周志刚不解释。
- 鱼肚子在孩子碗里，鱼尾在母亲碗边。
- 鱼刺挑到盘里，鱼肉已经不太热。
- 单独那一块排骨，桂芳说给孙子。
- 剩菜过夜，空椅子的人只能吃这个。
- 馒头是冷的，周建军自己拿。
- 粥在锅里闷着，人已经下楼。
- 米糊在小碗里，说明书在抽屉里。
- 蛋黄散开，两只勺都还在伸。

- 电饭煲跳起，人还没齐。

- 对折线越来越深。
- 包内夹层是她藏纸的地方。
- 超市小票和报名表叠着，谁都没先拿开。
- 发票边卷起来，她又压平。
- 存折塑料皮被老花镜压住。
- 打印行比话清楚。

- 柜台章一盖，亲情变成用途。
- 工资袋放桌上，人又去换工装。
- 信封没拆先放包里。
- 月供单和补课单叠在一起，谁都没先拿开。

- 排名被折到最里面。
- 老师评语是家长多陪。
- 家长签字处空着，像又要请假。
- 折进书页的边和收据折痕长得像。
- 试卷订正比作业先被问。
- 奖状被按在玻璃下，和报名表抢位置。
