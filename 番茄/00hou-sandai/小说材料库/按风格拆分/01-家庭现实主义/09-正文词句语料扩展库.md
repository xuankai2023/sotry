# 家庭现实主义 · 正文词句语料扩展库

> 只供写 `家庭现实主义` 正文时调用。供临时抽取。不要整段照搬，选一个动作、一个物件、一个短句即可。

## 风格定位

- 主视角重心：晓宁 + 桂芳 + 林倩。
- 核心写法：小选择堆出关系变形。饭桌、门口、厨房里的动作，比大事件更能推进人物。
- 观察入口：看谁先伸手、谁慢半拍、谁把东西放回原处。
- 句子气质：句子平实，有生活重量；不拔高，不判案。
- 禁区：不要写成婆媳大战、母子控诉或一场大吵后的顿悟。

## 抽取顺序

1. 先定这场谁先伸手。
2. 抽一条手部或饭桌 / 门口动作。
3. 抽一个物件位置变化。
4. 抽一句家常话，句后必须接动作或沉默。
5. 用一个收束动作结束，不用主题句。

细词不够时，不要在本文件里硬翻，去 [词库/00-索引.md](词库/00-索引.md) 只开 1 个分文件：

- 写人身上：`词库/01-部位衣着.md`
- 写碗门纸灯：`词库/02-物件部位.md`
- 写声味光雨：`词库/03-声味光天气.md`
- 写谁做什么：`词库/04-按人动词.md`
- 写开场收束和十年变奏：`词库/05-句式变奏.md`

## 本风格句式

- “还行。”他说完去拉书包。
- “能去就去，不能去我也在。”这句话没错，林倩脸却淡了一下。
- “先吃饭。”说完，桌上的纸没有人拿开。
- 同一件东西换人拿，关系就变一寸。
- 短句像家常话，句后动作承担真意思。
- 他把东西往那边挪了一点，像是把话也挪开了。
- 这事没人说严重，可从那天以后，他再也没有先伸手。
- 他不是不爱，是那天他先说了没事。
- 谁都没错，所以那一下更难躲。
- 她说的是饭，别人听见的是资格。
- 他拿的是钱，递出去的是迟到。
- 孩子没有选边，只选了最不伤人的姿势。
- 这句话轻得像随口，落在屋里却有重量。
- 那个动作以前是照顾，现在像验收。
- 人没变，站的位置变了。
- 家里的事最怕有人看见，看见以后就成了说法。
- 他不是不懂，只是懂了也不能说。
- 她不是要赢，她是怕自己被证明没用。
- 两个人都笑，只有孩子知道哪边先紧了一下。
- 东西没有变，换的是碰它的人。
- 那件东西先到，人才像跟着补上来。
- 它被放回原处，比拿起来时轻。
- 到后来，没人再用它争了，它才像真正旧了。

## 禁用替代表

- 不写“焦虑”，写“她把收据又折了一道”。
- 不写“控制”，写“碗已经推到孩子面前”。
- 不写“愧疚”，写“她买了东西，却没问想不想要”。
- 不写“疏离”，写“他说嗯，没抬头”。
- 不写“压抑”，写“电视声忽然被调大”。
- 不写“成长”，写“他第一次把门带上”。
- 不写“亲情”，写“鱼刺挑完，鱼肉凉了”。
- 不写“时代变迁”，写“宽带线沿墙角钉过去”。
- 不写“代际冲突”，写“两只勺都没有退”。
- 不写“和解”，写“她这次没有追问第几”。
- 不写情绪词，改写动作。
- 不写时代变迁，改写物件换手。
- 不写和解，改写少追问一次或多留一条门缝。
- 不写“创伤”“控制欲”“愧疚感”“被爱压迫”“原生家庭”“缺爱”。
- 不写慈祥、刻薄、贤惠、狼心一套鉴定词。
- 不写一场大吵后的顿悟。

## 一场配额

- 一个主场。
- 一个主物件。
- 一个先伸手的人。
- 一个慢半拍。
- 一句外圈或一句家常话。
- 一个放回或关门的收束。
- 不要把本目录和其他七个风格的句式连着堆。
