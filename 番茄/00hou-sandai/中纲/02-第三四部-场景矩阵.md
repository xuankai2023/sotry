# 第三、四部场景矩阵（2005–2007 正月）

> 覆盖大章 7–12，共 30 个核心场。  
> 承接第二部：晓宁已经会看门口的鞋决定先叫谁，但尚未明确理解爱的输赢。第三部让身体办法变成安全套话；第四部再把套话推成假装、藏和主动隐瞒。

## 总约束

- 2005 年晓宁五岁，能看脸、称呼、座位和食物，不能分析抚养结构。
- 2006 年六岁，能听懂大人在讨论「他」，开始知道自己会被安排。
- 「留下还是带走」是江州划片入学与邻县娘家接走，不写外地打工留守。
- 电脑 2005 年可以以「为了学习」进客厅；宽带、摩尔和赛尔不能提前。
- 压岁钱被代收的完整后果落在入学后的第一个年，即 2006 冬至 2007 正月。
- 成长顺序：身体配合 → 「都亲」套话 → 假装没听见 → 在自己身上做小动作 → 藏钱和少报。

# 第三部 · 争夺

## 大章 7 · 两把勺（2005）

- **大章问题：** 两个奶奶都在喂，他为什么先看脸色再张嘴？
- **起始状态：** 晓宁只会看鞋、先叫稳的一边。
- **不可逆：** 他第一次明确用身体让一边先赢，再补另一边。
- **主要限知：** 周晓宁、周桂芳。
- **社会压力：** 园门口同楼姐妹；楼道一句「这孩子懂事」。

### 7-1 · 换家那天的保温盒（日常）

- **年 / 限知 / 主场钟：** 2005 春，周桂芳；窄厨房到饭桌，玉梅到来的周六中午。
- **物件 / 欲望：** 保温盒。桂芳想按自己的咸淡把这顿喂完。
- **阻力 / 选择：** 玉梅另盛半碗白粥，孩子已经会看鞋；桂芳让座、让橘子，勺不放。
- **状态变化：** 两套勺同时获得资格，碗有两边，孩子还没有回答。
- **接下场：** 勺不让，玉梅会转去园门口争「谁接到」。

### 7-2 · 铁门两双手（外压）

- **年 / 限知 / 主场钟：** 2005 春，周晓宁；幼儿园铁门，从放学铃到人散。
- **物件 / 欲望：** 书包带或两只伸来的手。他只想尽快被接稳。
- **阻力 / 选择：** 两双手同时伸，同楼姐妹在旁边看；他先把手给气味更熟的桂芳，又回头看玉梅。
- **状态变化：** 普通回头被外圈解释成「认人」；选边第一次成为公开的事。
- **接下场：** 园门口的「认人」必须在饭桌上被一口粥坐实。

### 7-3 · 抢勺（选择 / 锚点）

- **年 / 限知 / 主场钟：** 2005，周晓宁；晚饭桌，从粥烫好到联播前。
- **物件 / 欲望：** 两把勺。他想吃蛋黄，也不想任何一边把他放下。
- **阻力 / 选择：** 两只勺停在碗上方，林倩在灶边重煮淡粥也阻止不了；他先看谁脸色紧，再往近的、有蛋黄的一边歪过去。
- **状态变化：** 身体替大人做了裁判；爱第一次拥有方向、输赢和旁观者。
- **接下场：** 赢的一边更敢喂，输的一边会用衣服和围嘴反弹。

### 7-4 · 围嘴带子（后果）

- **年 / 限知 / 主场钟：** 2005，周晓宁；客厅到阳台，晚饭后到天擦黑。
- **物件 / 欲望：** 围嘴。他想把勒住脖子的带子扯松，也想赶快离开两边都看着他的饭桌。
- **阻力 / 选择：** 玉梅先换上娘家带来的围嘴，桂芳又拿旧布罩来，林倩只说换换口味；他没有说选哪一条，只用手指勾住新围嘴的带子。
- **状态变化：** 娘家痕迹留在他身上，孩子开始用小动作而不是语言处理争夺。
- **接下场：** 第二天桂芳会用「他吃惯这个」把碗重新拿回来，孩子还要再配合一次。

### 7-5 · 歪完再要抱（回声 / 章不可逆）

- **年 / 限知 / 主场钟：** 2005，周晓宁；早餐桌到家门口，赶园前。
- **物件 / 欲望：** 勺和出门时的手。他想快点吃完，让两边都别再伸第二勺。
- **阻力 / 选择：** 桂芳的勺已经到嘴边，玉梅的保温盒还在，楼道又夸他懂事；他先张嘴，出门再去找没喂到的一边要抱。
- **状态变化：** 「先让一边赢，再补另一边」焊进身体，主动选边正式成立。
- **接大章 8：** 大人会把这种身体办法解释成跟谁亲，称呼、衣服、相册和团圆饭开始验收他属于谁家。

## 大章 8 · 谁家的孩子（2005 夏–初秋）

- **大章问题：** 衣服、叫法、团圆饭和相册怎样把孩子分成两家的证据？
- **起始状态：** 晓宁会用身体补偿两边，还没有稳定的语言套话。
- **不可逆：** 「都亲」成为安全答案，嘴与身体开始分开。
- **主要限知：** 周晓宁、林倩。
- **社会压力：** 席面亲戚问跟谁亲；中秋前后翻相册。

### 8-1 · 椅背上的衣服（日常）

- **年 / 限知 / 主场钟：** 2005 夏，周晓宁；客厅，玉梅离开后的上午。
- **物件 / 欲望：** 娘家带来的亮衣服。他想穿颜色更亮的那件。
- **阻力 / 选择：** 桂芳本想把它叠进里面，看见孩子一直摸袖口，最后替他把扣子扣好，带他下楼玩，没有提是谁买的。
- **状态变化：** 晓宁穿着自己喜欢的颜色跑完一个上午，桂芳也真的只管他热不热。这场让喜欢和照顾完整成立到场末。
- **接下场：** 下一次亲戚看见这件衣服，才会问是谁买、跟谁亲，把普通喜欢重新变成资格。

### 8-2 · 席面替他答（外压）

- **年 / 限知 / 主场钟：** 2005 夏，林倩；娘家或婆家一桌酒，从下午到散席。
- **物件 / 欲望：** 座位和夹菜的筷子。她想让孩子叫对，又不让任何一边觉得被抢。
- **阻力 / 选择：** 一边问跟奶奶亲不亲，一边催叫外婆；她先替孩子说「都亲」，再把人推向正在夹菜的手。
- **状态变化：** 林倩第一次替孩子给出「都亲」这个答案；下一场晓宁可以在相似追问里直接复用，不需要本场进入他的内心。
- **接下场：** 下一次不能只由母亲替答，团圆饭必须让他自己说。

### 8-3 · 团圆饭跟哪边坐（选择 / 锚点）

- **年 / 限知 / 主场钟：** 2005 年中秋前后，周晓宁；单位楼饭桌，从摆菜到吃到一半。
- **物件 / 欲望：** 已摆好的碗和座位。他想两边都说他是好孩子。
- **阻力 / 选择：** 玉梅想接去邻县过节，桂芳已经把碗摆好，志刚只说孩子姓周；被问想在哪吃时，他说「都亲」「都行」，坐进已经安排好的位置。
- **状态变化：** 嘴说两边，身体留一边；语言开始替身体遮掩。
- **接下场：** 人留在周家，相册会把两套亲近重新做成证据。

### 8-4 · 两本相册（后果）

- **年 / 限知 / 主场钟：** 2005 年中秋次日，林倩；客厅茶几，亲戚来坐的上午。
- **物件 / 欲望：** 两本相册。她想把两边照片放在一起，证明自己没有偏向。
- **阻力 / 选择：** 玉梅带来娘家照片，桂芳把周家相册翻到自己抱孩子的那页；林倩让两本并排，手却没有替任何一本压住另一边。
- **状态变化：** 晓宁同时成为两本相册的证据，母亲示范的「都亲」被固定成两套图像。
- **接下场：** 照片不能解决每天进门先叫谁，他必须把套话用到门口。

### 8-5 · 先看鞋，再补叫（回声 / 章不可逆）

- **年 / 限知 / 主场钟：** 2005 中秋后，周晓宁；家门口，从钥匙响到换鞋。
- **物件 / 欲望：** 两双鞋。他想进门而不被追问跟谁亲。
- **阻力 / 选择：** 屋里两个人都等称呼；他先看鞋、先叫稳的一边，再补叫另一边，并加一句「都亲」。
- **状态变化：** 身体办法与语言套话合并，嘴和真正偏向分开。
- **接大章 9：** 套话能挡住亲疏，挡不住胖瘦、花钱和学习的公开验收。

## 大章 9 · 日常被验收（2005 深秋）

- **大章问题：** 父母、老人和外圈怎样用胖瘦、到场、花钱验收抚养？
- **起始状态：** 晓宁已经会说安全答案。
- **不可逆：** 他发现被夸也可能是在替别人交成绩。
- **主要限知：** 林倩、周晓宁。
- **社会压力：** 园门口比较胖瘦；单位假条；电脑城「为了学习」。
- **硬边界：** 电脑可以进客厅，宽带不能进门。

### 9-1 · 接园被问瘦了没（日常）

- **年 / 限知 / 主场钟：** 2005 深秋，周晓宁；幼儿园门口到回家路上。
- **物件 / 欲望：** 书包带。他只想回家吃东西，不想再被两边问跟谁亲。
- **阻力 / 选择：** 同楼姐妹当着他说瘦了，桂芳立刻说在我这就胖；他摸了一下肚子，没有说自己饿不饿。
- **状态变化：** 晓宁第一次听见身体也能替别人交一张成绩，夸奖不再只是给他的。
- **接下场：** 老人用胖瘦验收，林倩会转向学校和纸抢回解释权。

### 9-2 · 假条写了仍去不成（外压）

- **年 / 限知 / 主场钟：** 2005 深秋，林倩；单位打卡口，家长会当天下午。
- **物件 / 欲望：** 假条。她想亲自坐进家长会，不再只听老人说「没批评」。
- **阻力 / 选择：** 假条会扣半天，材料又临时压下来；她把条交了仍去不成，电话请桂芳代去。
- **状态变化：** 当天学校解释权落到老人嘴里，纸再次只能证明她想来。
- **接下场：** 缺席被公开验收，她必须买一件能长期摆在家里的「学习」。

### 9-3 · 电脑，为了学习（选择 / 锚点）

- **年 / 限知 / 主场钟：** 2005，林倩；电脑城到客厅，一个周末下午。
- **物件 / 欲望：** 兼容机和小票。她想把学习摆进家里，让婆家和邻居看见自己补过。
- **阻力 / 选择：** 价格挤月供，桂芳怕占电话线，建军要挑便宜配置；她坚持把主机抬进客厅，反复说给孩子学习。
- **状态变化：** 电脑以学习名义取得合法位置，密码仍掌握在大人手上。
- **接下场：** 电脑真正开机后，周建军会先教孩子握鼠标；这件被大人命名为学习的东西，暂时也能让父子坐在同一张凳旁。

### 9-4 · 父亲教他握鼠标（喘息 / 错误胜利）

- **年 / 限知 / 主场钟：** 2005，周晓宁；电脑进门后的第一个晚上，从周建军开机到一局纸牌结束。
- **物件 / 欲望：** 鼠标。他想让箭头听自己的手，不再总滑出图标。
- **阻力 / 选择：** 建军的手太大，先握着他的手腕教；后来慢慢松开，让他自己点中。桂芳站在后面看，林倩没有立刻问学了什么。
- **状态变化：** 电脑先带来一次父子共同完成的小成功，周建军后半线也有真实温度；这一晚不立即揭成补偿或验收。
- **接下场：** 第二天外圈夸「真舍得，给孩子学习」，这份快乐才会被重新要求证明用途。

### 9-5 · 在对的图标上停一下（回声 / 章不可逆）

- **年 / 限知 / 主场钟：** 2005，周晓宁；晚饭后客厅，从开机到被叫吃饭。
- **物件 / 欲望：** 鼠标或图标。他想点会动、会响的画面。
- **阻力 / 选择：** 林倩要求识字软件，桂芳说伤眼，邻居又夸电脑是给学习；大人在时他停在学习图标，人走后才偏向会动的画面。
- **状态变化：** 被夸时他把鼠标移回学习图标，等大人走后再点别的；配合从饭桌上的张嘴变成屏幕前的切换。
- **接大章 10：** 谁带得好已经转成要把孩子带到哪里，入学前「留下还是带走」不可避免。

# 第四部 · 安排

## 大章 10 · 留下（2006）

- **大章问题：** 所有人的理由都正确时，为什么只有孩子没有理由？
- **起始状态：** 晓宁会用「都行」避开亲疏问题。
- **不可逆：** 他听见自己可以被讨论、搬动和决定。
- **主要限知：** 周晓宁、林倩。
- **社会压力：** 江州对口入学材料；邻县借读材料和费用；楼下二八车；邻里一句去哪所学校。

### 10-1 · 材料单上的油星（日常）

- **年 / 限知 / 主场钟：** 2006 春，林倩；灶台，从入学通知摊开到早饭结束。
- **物件 / 欲望：** 入学摸底材料单。她想先弄清户口簿、房改产权证明和预防接种证，不向任何一边表态。
- **阻力 / 选择：** 晓宁户口随建军在江州，对口学校手续更少；玉梅电话里说邻县可以办临时监护和借读，但要另交材料与费用。林倩把两套要求分别抄在纸背。
- **状态变化：** 「留下」尚未出口，制度成本已经不等重；春季只查材料，不提前缴秋季学费。
- **接下场：** 娘家方案若要成为真正选项，必须有人亲自去邻县学校问清借读。

### 10-2 · 邻县学校门口那辆车（外压）

- **年 / 限知 / 主场钟：** 2006 春，林倩；邻县对口学校门口，从办事窗开到关。
- **物件 / 欲望：** 借读材料清单。她想确认孩子住在玉梅家是否真的能入学，让两边方案都可执行。
- **阻力 / 选择：** 晓宁户口不在邻县，需要临时监护材料和借读费，日后接送也由娘家承担；她把清单收进包，没有当场提交。
- **状态变化：** 带走不再只是一句「我来带」，而是有纸、有钱、有路的真实方案；她再不能用「还没问清」拖延。
- **接下场：** 推迟不能再维持，家里必须当着孩子谈一次。

### 10-3 · 留下还是带走（选择 / 锚点）

- **年 / 限知 / 主场钟：** 2006，周晓宁；客厅，晚饭后到联播前。
- **物件 / 欲望：** 玩具车。他想继续玩，不被所有人盯着回答。
- **阻力 / 选择：** 班、钱、划片、老人身体和路程都成为正确理由；他把玩具车推到桌底，装作没听，最后只说「都行」。
- **状态变化：** 他第一次知道句子里的「他」是可以被搬动、安排的自己；乖开始带自保。
- **接下场：** 他没有反对，必须有人点头把选择做实。

### 10-4 · 下巴一沉（后果）

- **年 / 限知 / 主场钟：** 2006，周晓宁；同一客厅后半场。
- **物件 / 欲望：** 门边的包。他想让大人停止重复自己的名字，继续把玩具车推出来。
- **阻力 / 选择：** 玉梅的包还在，林倩不愿承担决定，志刚只点一下头；桂芳说留下，这边有学。晓宁没有抬头，只把车从桌底拉回来。
- **状态变化：** 他看见包被钱厚德拎下楼，第二天仍从这扇门去学校；「留下」以物件位置成为事实。
- **接下场：** 被留下的孩子要去报名、穿校服，学校的纸开始进入家。

### 10-5 · 假装刚醒（回声 / 章不可逆）

- **年 / 限知 / 主场钟：** 2006，周晓宁；祖父母大房里靠墙的临时小床，次日早晨。
- **物件 / 欲望：** 枕头或衣服。他不想接「留下来跟奶奶」这句话。
- **阻力 / 选择：** 桂芳叫他起床，想把安排说成福气；他假装刚醒，只伸胳膊让人穿衣。
- **状态变化：** 配合里第一次加入主动假装；听见的话开始往身体里面吞。
- **接大章 11：** 家庭安排完成后，学校会用红领巾、签字、名次和接送继续安排他。

## 大章 11 · 学校进门（2006 秋）

- **大章问题：** 家庭抚养权怎样换成学校签字权、名次和接送权？
- **起始状态：** 晓宁已学会假装没听见家庭安排。
- **不可逆：** 学校的纸第一次接管饭桌。
- **主要限知：** 周晓宁、林倩。
- **社会压力：** 收费窗口；建队日前后老师当众重系红领巾；秋游费、家长签字和作文批语。

### 11-1 · 收费窗，只能抱走一只包（日常）

- **年 / 限知 / 主场钟：** 2006 秋，林倩；文具店，报名手续办完后的上午。
- **物件 / 欲望：** 书包。她想亲自买下孩子一直看着的那一只，让入学这天留下一个不只属于收费单的高兴。
- **阻力 / 选择：** 预算只够普通款，建军没来，桂芳又嘱咐别买最贵；她放回带轮子的，买下亮片那只。
- **状态变化：** 晓宁在店门口当场背上书包，这份喜欢先完整成立到场末；它以后会不会变成补偿，留给后场。
- **接下场：** 包和校服进校门，红领巾必须由另一个权力重新整理。

### 11-2 · 当众重系（外压）

- **年 / 限知 / 主场钟：** 2006 年 10 月建队日前后、入队后的第一周，周晓宁；教室，早读前。
- **物件 / 欲望：** 红领巾。他只想结不歪、不被全班看。
- **阻力 / 选择：** 领口勒，布又涩，老师当众拆开家里系的结；他站着不动，不说是谁系的。
- **状态变化：** 家里系好的结在教室被拆开。第二天再有人伸手时，他会先摸一下领口，却不告诉任何人老师改过谁的结。
- **接下场：** 第二天出门，家里两只手都会抢着把结系对。

### 11-3 · 红领巾谁系（选择 / 锚点）

- **年 / 限知 / 主场钟：** 2006，周晓宁；家门口，上学前最后几分钟。
- **物件 / 欲望：** 红领巾。他想不勒，到校又不被老师重新拆。
- **阻力 / 选择：** 林倩系得紧，桂芳伸手要松，两只手碰上；他等两双手离开，出门后自己把结松半寸。
- **状态变化：** 第一次在自己身体上做一件不告诉大人的小事，主动隐瞒开始出现。
- **接下场：** 红领巾仍只是身体，联系本会直接要求「家长签字」。

### 11-4 · 第一次家长签字（后果）

- **年 / 限知 / 主场钟：** 2006，林倩；晚饭桌，从她晚归到联系本摊开。
- **物件 / 欲望：** 夹着秋游费通知的联系本。她想亲笔签全名，把家长位置从老人手里写回来。
- **阻力 / 选择：** 桂芳已经听孩子念过，只能复述没批评；林倩赶回来签字，却没把通知读完。
- **状态变化：** 名义签字权回到母亲，实际解释权仍停在老人嘴里；纸第一次压住饭。
- **接下场：** 学校开始把金额、要求和家庭叙述一起带回家；下一张纸会直接让孩子写「我的家」。

### 11-5 · 我的家只写谁来接（回声 / 章不可逆）

- **年 / 限知 / 主场钟：** 2006 秋，周晓宁；书桌到晚饭前，从作文纸发下到门外叫吃饭。
- **物件 / 欲望：** 作文《我的家》。他想赶快写完，又不知道应该写妈妈、奶奶还是每天来接的人。
- **阻力 / 选择：** 老师要求写具体，纸只能交一份；他只写「奶奶每天来接我」，把妈妈买的书包写在下一句，最后一行留空。
- **状态变化：** 学校第一次要求他把一家人写成一套说法；他把作文夹进作业本，没有主动拿到饭桌。
- **接大章 12：** 大人以为他适应得好，下一步会替他保管红包和安排钱的用途。

## 大章 12 · 钱不是自己的（2006 冬–2007 正月）

- **大章问题：** 红包、零花和学习支出分别是谁的钱？
- **起始状态：** 晓宁已经会隐瞒领巾和学校里的半句话。
- **不可逆：** 他把两边的钱分开放，开始主动少报。
- **主要限知：** 周晓宁、林倩。
- **社会压力：** 校门口冰柜和同学零花；过年亲戚问给了多少。
- **硬边界：** 2008 年存折的角度不在本章写完。

### 12-1 · 袜筒里那一张（日常）

- **年 / 限知 / 主场钟：** 2006 冬，周晓宁；楼下车旁，钱厚德送来又要走的黄昏。
- **物件 / 欲望：** 两张零钱。赵玉梅在「留下」之后改了办法，让厚德转话：一张交给妈妈买本子，一张自己拿着。
- **阻力 / 选择：** 上楼一定有人把两张一起收走；他照外婆教的分法，一张放外袋，一张塞进袜筒。
- **状态变化：** 隐瞒不是凭空成熟，而是娘家失去日常后留下的新策略；赵玉梅从抢住、抢带改成直接给孩子一小笔选择权。
- **接下场：** 藏住的钱会在校门口被花掉，包装和气味可能出卖他。

### 12-2 · 夹层里的红油（外压）

- **年 / 限知 / 主场钟：** 2006 冬，周晓宁；小学校门口，从放学到同学散开。
- **物件 / 欲望：** 藏钱或零食包装。他想体验一次无需报账的购买。
- **阻力 / 选择：** 同学比零花，家里不许买，钱又来自隐瞒；他买下，把包装塞进作业本夹层，回家先洗手。
- **状态变化：** 桂芳翻作业时先看见油印，追问钱从哪里来；他只承认外婆给过一张。大人由此认定孩子已经会乱花，过年的大红包必须当面收走。
- **接下场：** 红油不是悬空线索，它直接提高了压岁钱被代收的正当性。

### 12-3 · 压岁钱被代收（选择 / 锚点）

- **年 / 限知 / 主场钟：** 2007 正月初二，周晓宁；自己的抽屉，从林倩拿着空信封进门到数完钱离开。
- **物件 / 欲望：** 红包和空信封。他想至少留下十块。
- **阻力 / 选择：** 林倩说帮他存，建军这月紧，祖辈也说孩子会丢；她当面从抽屉数钱时，他把几张先压到作业本下面，没有出声阻止，最后只把收空的信封叠好。
- **状态变化：** 他第一次知道「我的」会隔夜消失；分开放从试探变成必要。
- **接下场：** 大人必须给代收的钱一个正当去处，学习用品会替钱回来。

### 12-4 · 给你存着，变成保修卡（后果）

- **年 / 限知 / 主场钟：** 年后，林倩；客厅柜，点读机或学习设备抱上楼的晚上。
- **物件 / 欲望：** 保修卡。她想证明代收仍然是为孩子。
- **阻力 / 选择：** 设备沉，孩子只想听响声，桂芳也觉得占地方；她把保修卡压到电脑学习小票下面，说钱给他买了学习。
- **状态变化：** 林倩把代收的钱重新命名成学习支出，并把保修卡与旧小票叠在一起；孩子的后续反应留给下一场限知。
- **接下场：** 他会一边要设备响，一边开始虚报自己练过多少。

### 12-5 · 少报的那一句（回声 / 章不可逆）

- **年 / 限知 / 主场钟：** 2007 正月，周晓宁；饭桌，亲戚问压岁钱去向。
- **物件 / 欲望：** 两个不同口袋。他想保住没被找到的几张。
- **阻力 / 选择：** 亲戚问外婆给了多少，「都亲」已挡不住数字；他说「就那些」「存了」，主动少报。
- **状态变化：** 分开放与主动隐瞒正式成立；孩子从身体配合走到会藏、会少报。
- **接大章 13：** 他已经会藏钱、少报数字，但仍会在门口等父母出现、仍认为迟到的人应该给一句理由；下一部才处理「等」怎样变化。
