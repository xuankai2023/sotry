# 第五、六部场景矩阵（2007–2010 与成年尾声）

> 覆盖大章 13–18，共 31 个核心场。  
> 承接第四部：晓宁已经听见自己会被安排，也开始把钱、学校里的话和身体动作藏起来。第五部写撤退怎样成为生存办法；第六部写这种办法同时拿走了什么。

## 总约束

- 撤退必须同时成立两面：它帮助晓宁活下来，也让他失去被问、被等或被理解的一部分关系。
- 不写网瘾说教。屏幕的功能是提供一套不要求他照顾大人失望的秩序。
- 2008 年公共灾难只可作为电视漏音，不进入家庭主线，不用于煽情。
- 摩尔庄园从 2008 年起，赛尔号从 2009 年起，不能提前。
- 2010 年晓宁十岁，可以说「我知道你忙」，但不会总结三代家庭结构。
- 成年尾声才允许完整反思；理解不等于原谅或洗白。

# 第五部 · 撤退

## 大章 13 · 门口对不上（2007）

- **大章问题：** 谁接到孩子，为什么已经不能证明谁更在场？
- **起始状态：** 晓宁仍认为迟到的人应该给他一个理由。
- **不可逆：** 他第一次把「为什么晚」从嘴上移到看鞋、看钟和留意门声里；期待还在，只是不当场问。
- **主要限知：** 周晓宁、周桂芳。
- **社会压力：** 同楼姐妹说又是奶奶来；同学母亲问「你妈呢」。

### 13-1 · 铃先散（日常）

- **年 / 限知 / 主场钟：** 2007 春，周桂芳；小学校门口，从第一轮放学到第二轮人散。
- **物件 / 欲望：** 书包带。她想准点接到，证明自己的门口班仍在。
- **阻力 / 选择：** 同楼姐妹说「又是你来」，孩子出来先扫一遍有没有第二个人；她提前占位，把书包先卸到自己胳膊上。
- **状态变化：** 接到人仍是她的岗位；她第一次看见晓宁出门后先扫了一遍人群，才把书包递给自己。
- **接下场：** 空位被别人问出口以后，会变成孩子需要遮掩的事。

### 13-2 · 你妈呢（外压）

- **年 / 限知 / 主场钟：** 2007，周晓宁；校门口冰柜到铁门，放学后十几分钟。
- **物件 / 欲望：** 门口各家的鞋或车。他想等母亲出现，好让同学觉得自己也有人来接。
- **阻力 / 选择：** 同学母亲问你妈呢，桂芳已经伸手接书包；他说「奶奶接」，不说「她还没来」。
- **状态变化：** 他开始用奶奶挡住外圈追问，心里仍留着要向母亲问晚的那一句。
- **接下场：** 那句还没有问出口，天会先黑。

### 13-3 · 门口等到天黑（选择 / 锚点）

- **年 / 限知 / 主场钟：** 2007，周晓宁；校门口，从第二轮人散到路灯亮。
- **物件 / 欲望：** 桂芳从厨房门后夹出来的蓝色塑料凳。他想等父母出现，问一句为什么晚。
- **阻力 / 选择：** 冰柜关灯，桂芳从凳上站起，把同一张凳夹回胳膊下，电话里只有「马上」；灯亮后他先跟奶奶走，走出几步仍回头看了一次。
- **状态变化：** 他第一次把问题延后，而不是彻底放弃；期待从公开询问移到回家后的门声和鞋。
- **接下场：** 晚到的人打电话时，他仍在饭桌边听，问题只是没有当场出口。

### 13-4 · 马上变成空门（后果）

- **年 / 限知 / 主场钟：** 2007，周桂芳；家门口座机到饭桌，天黑后。
- **物件 / 欲望：** 罩着冷菜的碗。她想把这天圆成「人已经接到」。
- **阻力 / 选择：** 林倩来电问到家没，建军还会更晚；桂芳替孩子答吃了、回来了，不让为什么晚上桌。
- **状态变化：** 桂芳用「接到了」结束电话；她看见晓宁的筷子停到忙音响完才重新落进碗里，却没有追问。
- **接下场：** 电话没有多说，他会转而看玄关的鞋和墙上的钟，保留一条无人知道的期待。

### 13-5 · 问题移到鞋上（回声 / 章不可逆）

- **年 / 限知 / 主场钟：** 2007，周晓宁；晚饭桌到玄关，夜里。
- **物件 / 欲望：** 门口的鞋。他想确认今晚是否还会有人回来，仍希望那个人主动说明。
- **阻力 / 选择：** 建军晚归只掀开菜罩，林倩仍不在；他没有问为什么，只在睡前又看了一次空鞋位。
- **状态变化：** 问题没有消失，只从嘴上移到物件上；这保护了当晚的饭桌，也让大人误以为他已经不等。
- **接大章 14：** 门口的鞋无法保存没说出口的话，他开始需要一张床、一个抽屉，把等待和真话放到别处。

## 大章 14 · 自己的床（2008）

- **大章问题：** 拥有一张床，是否等于拥有自己的空间？
- **起始状态：** 晓宁不再从门口追要解释。
- **不可逆：** 他开始把真话、成绩单和钱藏进自己的范围。
- **主要限知：** 周晓宁、林倩。
- **社会压力：** 家具店说独立空间；同学问能不能关门；过去外婆短住用的帘和折叠床已收进阳台。

### 14-1 · 床是补的（日常）

- **年 / 限知 / 主场钟：** 2008，林倩；单位房小房，从新床送到到客厅折叠床铺开。
- **物件 / 欲望：** 小床和收据。她想补自己没有在门口等待的那一截。
- **阻力 / 选择：** 房改补款、菜钱和份子都紧，桂芳说一屋也能睡；林倩仍把夫妻用的小房让给孩子，自己和建军改睡客厅折叠床。
- **状态变化：** 这次照料先完整成立：晓宁得到一张真正属于自己的床和一扇门，父母也付出看得见的睡位代价；边界问题留到后场。
- **接下场：** 床一进门，外圈马上会问这算不算自己的房间。

### 14-2 · 收起的旧帘（外压）

- **年 / 限知 / 主场钟：** 2008，周晓宁；客厅到床边，一个傍晚。
- **物件 / 欲望：** 门或收在阳台的旧布帘。他想告诉同学自己有床、有房门。
- **阻力 / 选择：** 过去给外婆短住用的帘和折叠床已经收起，父母现在睡客厅另一张折叠床；同学只问能不能关门，大人仍会进来整理。他只说有床。
- **状态变化：** 他知道「有床」不等于「不被看见」。
- **接下场：** 要藏的东西不能继续放在床面和书包表层。

### 14-3 · 抽屉和虚掩门（选择 / 锚点）

- **年 / 限知 / 主场钟：** 2008，周晓宁；自己的床和书桌，从放学到晚饭前。
- **物件 / 欲望：** 抽屉。他想把成绩单、糖纸、压岁零头和那篇最后一行空着的《我的家》从书包转移到只有自己知道的夹层。
- **阻力 / 选择：** 门外有脚步，过去的钱已经被代收；他第一次虚掩门，把纸和钱压进抽屉。
- **状态变化：** 真话第一次拥有固定地址；不是饭桌，而是抽屉。
- **接下场：** 床铺如果被重新叠得太齐，就说明这块地址仍被大人进入。

### 14-4 · 铺太齐（后果）

- **年 / 限知 / 主场钟：** 2008，林倩；孩子房间门口到饭桌，晚饭前。
- **物件 / 欲望：** 过分齐整的床铺。她想验收床、作业和书包，证明花钱买到了秩序。
- **阻力 / 选择：** 桂芳已经进房叠过被、摆正枕头，抽屉也没有完全合严；林倩看见成绩单，却没有拿走那篇作文，只把成绩纸带到饭桌。
- **状态变化：** 谁进入和整理已经明确：桂芳仍把房间当日常的一部分，林倩也只让出了一半；作文作为晓宁自己的家庭版本留在夹层。
- **接下场：** 晓宁必须改变藏法，门仍不敢真正关死。

### 14-5 · 再看一眼抽屉（回声 / 章不可逆）

- **年 / 限知 / 主场钟：** 2008，周晓宁；床上，关灯前。
- **物件 / 欲望：** 抽屉夹层。他想确认没有被全部翻过。
- **阻力 / 选择：** 被角太齐，枕头也被拍过；他用橡皮筋换一种压法，门仍只留一条缝。
- **状态变化：** 藏成为日常，虚掩既是界也是不敢完全断开的关系。
- **接大章 15：** 门缝仍能让所有叫声进来，他需要一个叫了也不必立即应的地方。

## 大章 15 · 屏幕里面（2008–2010 春）

- **大章问题：** 宽带为什么既是父母买来的机会，也是孩子撤退的门？
- **起始状态：** 晓宁已经用抽屉和虚掩门保存真话。
- **不可逆：** 屏幕成为第一个不要求他照顾大人失望的地方。
- **主要限知：** 周晓宁、林倩。
- **社会压力：** 装维、电信单、校门口点卡摊、班上摩尔与赛尔的分层。

### 15-1 · 线从门缝进（日常 / 锚点）

- **年 / 限知 / 主场钟：** 2008，林倩；家门口到主机旁，装维上门的下午。
- **物件 / 欲望：** ADSL 宽带线。她想签下「为了学习」，把自己的缺席补成机会，也把 2005 年一直在客厅占电话线的电脑移进孩子的小房。
- **阻力 / 选择：** 月费挤菜钱，桂芳盯电表，建军说装了也是玩；她仍签字，把密码贴在主机侧面。
- **状态变化：** 电话线经分离器接进猫和网线，电脑的位置从公共客厅变成孩子房间；学习成为这次空间迁移的通行证。
- **接下场：** 绿灯一亮，班上立刻分成有号和没号的人。

### 15-2 · 米米卡和别人的会员（外压）

- **年 / 限知 / 主场钟：** 2008 年 4 月 28 日后，周晓宁；校门口卖卡的小摊，放学后到同学散开。
- **物件 / 欲望：** 米米卡。他已经可以免费注册、进入自己的小屋，却想要同学展示的超级拉姆或付费家具。
- **阻力 / 选择：** 十块钱只能买卡或冰棍，普通账号也能玩，只是班上比较的东西不同；他选择米米卡。
- **状态变化：** 虚拟账号第一次比成绩更容易与同学交谈，新的差距从有没有号变成会员、家具和装扮。
- **接下场：** 米米卡带回家，父母仍会把屏幕理解为学习。

### 15-3 · 小屋里不看脸色（选择 / 锚点）

- **年 / 限知 / 主场钟：** 2008，周晓宁；自己房间屏幕前，从饭锅响到桂芳叫第二声。
- **物件 / 欲望：** 摩尔庄园的小屋。他想把一局做完。
- **阻力 / 选择：** 门外叫吃饭，桂芳只会拔插头，林倩仍说查资料；他没有立刻应，先把音量拧小，门缝留一条。
- **状态变化：** 屏幕里的角色不会因他先点谁而脸色变紧；他第一次把门外的第二声呼唤留到一局结束后才回答。
- **接下场：** 林倩必须决定拔掉，还是继续用学习把晚应合法化。

### 15-4 · 学习把撤退签了字（后果）

- **年 / 限知 / 主场钟：** 2008 年宽带装好后的第一个周末，林倩；房间门外，从晚饭盛好到汤凉。
- **物件 / 欲望：** 门外的碗或学习小票，正式场卡时二选一。她想叫孩子出来，又保住自己买电脑的正当性。
- **阻力 / 选择：** 孩子晚应，同事家的孩子也玩；她若发火就等于承认电脑不是学习，于是只说作业写完可再玩一会儿，不推门。
- **状态变化：** 林倩第一次没有推门，只把「作业写完」当作继续玩的条件；她在门外等到孩子迟来的应声，仍把这次退让解释为学习安排。
- **接下场：** 许可证跨到 2009 年，摩尔的小屋会换成赛尔的精灵仓。

### 15-5 · 赛尔年代，应慢半拍（回声 / 章不可逆）

- **年 / 限知 / 主场钟：** 2009 年 6 月 12 日后，周晓宁；房间屏幕，从课间对号后的晚饭点开始。
- **物件 / 欲望：** 赛尔号精灵仓。他想先确认账号里的东西还在。
- **阻力 / 选择：** 粥已经上桌，桂芳拔过插头，林倩又问成绩；他应慢半拍，说「马上」，先看一眼屏幕。
- **状态变化：** 他先查看精灵仓，再回答门外；屏幕里的东西不会追问他跟谁亲，灶上的碗却第一次因等他而凉。
- **接下场：** 家里人的「马上」已被他学会使用；2010 年春外公再来接一次，旧后座会照见孩子的注意力已经换了地方。

### 15-6 · 后座还在（喘息 / 人物回声）

- **年 / 限知 / 主场钟：** 2010 年春，周晓宁；钱厚德二八车后座，从校门口到家属院。
- **物件 / 欲望：** 修补过的棉垫。他仍喜欢车铃和春风，也急着回家查看账号。
- **阻力 / 选择：** 厚德骑得比 2004 年慢，上坡仍让他下来走几步；晓宁没有催，重新上车后只把书包抱到胸前。
- **状态变化：** 外公的后座仍然稳，照顾没有失效；变化只在孩子一路想着回去上线。温暖与错开同时存在，不需要站队。
- **接大章 16：** 到 2010 年秋，接人路线仍在，但晚托散场会让「谁来」与「他还等不等」最后一次碰到一起。

# 第六部 · 回看

## 大章 16 · 晚托散场（2010）

- **大章问题：** 人终于接到了，为什么孩子已经不再等待解释？
- **起始状态：** 晓宁会说「马上」，也会把心先撤回屏幕。
- **不可逆：** 他说出「没事，我知道你忙」，并真正停止等待。
- **主要限知：** 周晓宁、林倩、周建军。全书高潮章允许三种限知，但每场不跳。
- **社会压力：** 组长加班名单；校外小饭桌的接人名条；楼下铁门外一排接人凳。

### 16-1 · 凳往前挪（日常）

- **年 / 限知 / 主场钟：** 2010 年秋，周晓宁；校外小饭桌二楼教室窗到楼下铁门，目标日前一周的一次散场。
- **物件 / 欲望：** 同一张蓝色塑料凳。桂芳从厨房门后带来，他想快点回家开机，也仍会扫一眼凳旁有没有母亲。
- **阻力 / 选择：** 桂芳起身替他接书包时，他顺手扶了一下刚空出的凳面，掌心感觉到余温；林倩电话里答应下周五自己来，他只把日期记在课程表边上。
- **状态变化：** 2007 年移到物件上的期待被一个具体日期重新点亮，但大人看不出来。
- **接下场：** 到约定的周五，林倩必须在打卡和晚托散场之间再选一次。

### 16-2 · 还没打卡（外压）

- **年 / 限知 / 主场钟：** 2010 年秋的约定周五，周建军；厂里交接处，从林倩来电到打卡机响。
- **物件 / 欲望：** 打卡卡片。他听见林倩也被报表扣住，想替她赶去一次，让孩子看见父亲不只剩喇叭。
- **阻力 / 选择：** 自己提前走会丢当班津贴并把交接压给搭班；他盯着卡片，最后仍留在交接处，亲自打电话让桂芳从家里赶去。
- **状态变化：** 建军再次选择用班和钱撑家，也第一次清楚知道这个选择把接人交回母亲；他的「撑住」与孩子的空等在同一刻相连。
- **接下场：** 桂芳接到电话时已经晚，教室将先散；晓宁仍会看一次铁门外约定的人是否出现。

### 16-3 · 晚托散场（选择 / 锚点）

- **年 / 限知 / 主场钟：** 2010 年秋，周晓宁；校外小饭桌二楼教室到楼下铁门，灯亮着但椅子已空。
- **物件 / 欲望：** 课程表边上记过的周五日期。他想看见答应来的人，也想快点结束等待。
- **阻力 / 选择：** 小饭桌经营者留在教室核对最后一名孩子，铁门外先空着；桂芳后来夹着蓝凳气喘着赶到，在名条上签字。晓宁看过路口一次，把书包自己背好，和奶奶下到铁门内侧。
- **状态变化：** 期待尚未被语言结束，但约定已经以空门兑现；他把最后的判断留到母亲真正赶到时。
- **接下场：** 林倩会在他们尚未离开小饭桌楼下铁门时赶到，母亲解释、奶奶补位和晚托散场仍压在同一个地点。

### 16-4 · 我知道你忙（后果 / 锚点）

- **年 / 限知 / 主场钟：** 2010，林倩；校外小饭桌楼下铁门内侧，她赶到时，桂芳、蓝凳和经营者的接人名条都还在。
- **物件 / 欲望：** 仍压在肩上的包。她想解释自己为什么晚，把母亲位置坐回来。
- **阻力 / 选择：** 孩子没有哭，桂芳刚签完接人名条，蓝凳仍夹在胳膊下；林倩刚说「单位临时……」，晓宁只回「没事，我知道你忙」，低头重新提好书包。她没有把准备的解释说完。
- **状态变化：** 母亲第一次发现自己的解释没有被索取；这句话的意义不由场卡替读者判定，后果留给下一场的行为。
- **接下场：** 回家路上，他问的不会是迟到，只会是电脑还能不能开。

### 16-5 · 先问能不能开（回声 / 章不可逆）

- **年 / 限知 / 主场钟：** 2010，周晓宁；铁门到家门口，天擦黑。
- **物件 / 欲望：** 主机灯。他只想确认回去还能不能上线。
- **阻力 / 选择：** 桂芳把蓝凳夹回厨房门后，母亲脚步也在身边；晓宁没有像 2007 年那样再看空鞋位，也没有查看课程表上的周五，只问电脑还能不能开。
- **状态变化：** 「不再等待」第一次由连续动作完成，而不是提前宣布：具体日期、路口和鞋位都不再需要确认。家仍在，他不再把解释当作回家的必要部分。
- **接大章 17：** 如果屋里仍要用作业、饭和收据验收，他只能把门进一步带上。

## 大章 17 · 门关上（2010）

- **大章问题：** 关门是反抗、逃生，还是把爱也挡在外面？
- **起始状态：** 晓宁不再等待解释，但门仍常常虚掩。
- **不可逆：** 门第一次完整合上；桂芳把水留在门外，林倩没有推门，晓宁到第二天才拿走凉杯。三个动作共同完成边界，不用人物宣告。
- **主要限知：** 周晓宁、周桂芳。
- **社会压力：** 同楼闲话「又关着」；联系本和报班纸从门缝进入。

### 17-1 · 进来前先敲一下（日常 / 暂时有效）

- **年 / 限知 / 主场钟：** 2010，周晓宁；自己房间，从晚托回来到晚饭。
- **物件 / 欲望：** 门把。他想把一局做完，又不想用摔门把人都惹恼。
- **阻力 / 选择：** 林倩伸手要进来问作业；他第一次说「进来前敲一下」。林倩停住，真的敲了两下，等他应声才推门。
- **状态变化：** 一个不用关死的边界暂时有效，晓宁也第一次体验到直接说要求可能被听见。
- **接下场：** 桂芳没有听见这条新规则，仍会按过去叠被、送水的习惯推门；暂时成功因此要接受真正考验。

### 17-2 · 又关着（外压）

- **年 / 限知 / 主场钟：** 2010，周桂芳；楼道到房门外，晚饭前后。
- **物件 / 欲望：** 水杯。她想把饭、水和自己仍在岗的证明送进去。
- **阻力 / 选择：** 同楼说你家又关着，门内风扇声不停；她停了一下，仍像过去叠被那样把门推开一掌宽，把水放到桌角。
- **状态变化：** 桂芳仍把虚掩理解成可以进入；晓宁立即缩小窗口，把椅子往门边挪了一点。
- **接下场：** 这次进入让他确认虚掩不算边界，下一场必须做一个不能再被误解的动作。

### 17-3 · 门一带上（选择）

- **年 / 限知 / 主场钟：** 2010，周晓宁；房门内，从门外停步到钥匙声响。
- **物件 / 欲望：** 门。他想保住屏幕里那块不必看脸色的秩序。
- **阻力 / 选择：** 桂芳刚刚把虚掩当作可以进入，林倩的钥匙声又在外面；他把门完整合上，让锁舌第一次发出清楚的一声，不用摔门。
- **状态变化：** 门第一次成为不需猜测的界。晓宁保住了屏幕，也听不见饭桌上后来少了哪一句；生存和损失都落在可见后果里。
- **接下场：** 门外的人必须选择推门还是放下东西。

### 17-4 · 水杯放门口（后果 / 锚点）

- **年 / 限知 / 主场钟：** 2010，周桂芳；关闭的房门外，从水热到逐渐凉。
- **物件 / 欲望：** 水杯。她还想保有一件能做的事。
- **阻力 / 选择：** 门内屏幕声不断，门把没有像过去那样自动让开；她伸过一次手又收回，把水杯放在门口，只说水在外面，回去擦灶台。
- **状态变化：** 她第一次没有把照顾送进房间，爱从进门改成留在门外；变化由手收回和杯的位置完成。
- **接下场：** 水在门外，晓宁必须决定开不开；林倩也会到门前作同样选择。

### 17-5 · 三个人都不进（回声 / 章不可逆）

- **年 / 限知 / 主场钟：** 2010，周晓宁；门缝光到屏幕光，夜里。
- **物件 / 欲望：** 逐渐凉下去的水杯。他想确认门外还在，又不想开门。
- **阻力 / 选择：** 林倩隔门只说别太晚，也没有推；他当晚不开门，第二天早晨才把凉杯拎进去。
- **状态变化：** 两个人都没有推门，他到第二天才拿走凉杯。门已经成为界；这一晚屋里屋外都没有再补一句话。
- **接大章 18：** 这块进不去的地方要等成年后才能被命名，不能在十岁时变成控诉或和解。

## 大章 18 · 旧物不作证（成年尾声）

- **大章问题：** 清理旧屋时，成年晓宁带走什么、留下什么，才能不再让旧物替任何人交成绩？
- **起始状态：** 他仍习惯用一句「都过去了」跳过旧屋，也可能把全部东西当成一套证明带走。
- **不可逆：** 当天下午废品回收者会带走不保留的旧纸。他把整袋收据放进废纸捆，只带走童年那篇最后一行空着的《我的家》，并在多年后补上一句具体事实。
- **主要限知：** 成年周晓宁；第一人称只在本大章使用。
- **社会压力：** 同楼人问回来住几天；母亲递收据袋；老人仍问吃了没。
- **硬边界：** 成年职业保持未定，只写整理旧物与开始书写。

### 18-1 · 回来是收东西（日常）

- **年 / 限知 / 主场钟：** 成年，周晓宁；单位老楼旧屋，一个白天。
- **物件 / 欲望：** 打开的旧抽屉。他想在下午五点收废纸的人来前清完，不在旧屋多住一晚。
- **阻力 / 选择：** 抽屉深处夹着那篇《我的家》，最后一行仍空着；他没有立刻扔进废纸箱，把它放到桌边。
- **状态变化：** 童年写作种子从第 11、14 章得到回收；他仍没有解释，只多留下一张纸。
- **接下场：** 林倩会把另一袋纸递给他，并告诉他那些钱都花在了哪里；剩下的纸五点前必须分成保留和回收两堆。

### 18-2 · 袋子递过来（外压）

- **年 / 限知 / 主场钟：** 成年，周晓宁；客厅到门口，下午。
- **物件 / 欲望：** 林倩递来的收据袋。他想让清屋继续，不把客厅变成旧账说明会。
- **阻力 / 选择：** 林倩逐张说点读机、床和宽带花了多少，桂芳仍问他吃没吃；他接住袋子，却没有装进自己的行李，只放到待回收的纸堆旁。
- **状态变化：** 母亲看见他没有立刻带走，手停在袋口；两个人之间出现一个真实但没有说破的不悦。
- **接下场：** 收废纸的人已经到楼下，清屋必须作出不可撤回的取舍。

### 18-3 · 只带走一张（选择 / 锚点）

- **年 / 限知 / 主场钟：** 成年，周晓宁；旧饭桌，从相册背面到礼簿摊开。
- **物件 / 欲望：** 收据袋与旧作文。他必须在装箱前决定哪些纸由自己带走。
- **阻力 / 选择：** 收据确实记录了家里为他付过的钱，旧作文却只写了谁每天来接；他把作文放进箱子，把收据袋压进已经扎好的废纸捆。林倩没有说好，也没有替他抽出来。
- **状态变化：** 选择有现实代价：母亲把沉默留在桌边，晓宁也放弃一整套证明自己被尽力爱过的凭据；收据一旦被楼下的人称走，就不能再回来。
- **接下场：** 他要把废纸捆送到楼下，蓝凳恰好挡在楼道转角，两个旧物在同一次搬运里完成去留。

### 18-4 · 凳子回到墙边（后果）

- **年 / 限知 / 主场钟：** 成年，周晓宁；单位楼楼道到铁门内侧，废纸回收者等在楼下的傍晚。
- **物件 / 欲望：** 塑料凳。它横在楼道转角，他只想让搬东西的人通过。
- **阻力 / 选择：** 蓝凳挡住废纸捆，桂芳说凳子留着能坐；他先把凳搬回铁门内侧原来的墙边，再把扎着收据袋的废纸交给回收者称走。
- **状态变化：** 收据离开，选择不可反悔；同一张蓝凳没有被当纪念品带走，也没有被扔掉，只回到仍可坐人的位置。
- **接下场：** 箱子里只剩旧作文。回到自己的桌前，他必须处理那一行空白。

### 18-5 · 开始写（回声 / 全书不可逆）

- **年 / 限知 / 主场钟：** 成年，周晓宁；自己现在的桌，夜里。
- **物件 / 欲望：** 旧作文最后一行。他想把空白补完，而不是写一篇关于童年的结论。
- **阻力 / 选择：** 原来的句子只有「奶奶每天来接我」「妈妈给我买了书包」；我停了很久，补上一句具体事实：「奶奶站起来以后，我摸过那张蓝凳，凳面还是热的。」
- **状态变化：** 全书不以判词结束，只以一张旧作文多出一行结束。写作被前文建立，也由现实选择触发。
- **收束：** 停在旧作文多出的那一行，不再补主题问句。
