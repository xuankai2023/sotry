# 部分中纲 · 用法

中纲是**一部或一段大章的总结**。不是总纲，不是场景矩阵，不是文章包。

写法走 skill `novel-mid-outline`。模板见该 skill 的 `template.md`。本部分性格变化：总纲已定以总纲为主，`novel-character-change` 为辅，只写进/出一寸。

每次写中纲都要使用到以前的中纲和总纲。先读 `总纲-大师写法.md`，再读本目录已有文件和（部分未齐时）`../01-05.md`，结合着写进部、伏笔和不得重写的场面。不结合不准落盘。

```text
中纲/部分/
  00-用法.md
  01-证据.md      # 大章 1–3（已锁总结）
  02-缺席.md      # 大章 4–6（已锁总结；大章 6 不另拆，听跨部区间 + ledger 第十二节）
  03-争夺.md      # 大章 7–9（已锁总结；7–9 不另拆场序，听跨部区间 + 已锁正文）
  04-安排.md      # 大章 10–12（已锁总结）
  05-撤退.md      # 大章 13–15（已锁总结）
  06-回看.md      # 大章 16–18（计划；16-1 已定稿，下一手写 16-2）
  大章06-10.md    # 用户点名：2004–2006 春，大章 6–10（已锁总结；部级另见 02 / 03 / 04）
```

用户点名跨部区间时，另存 `大章NN-NN.md`，不要拆进两部里各写一半却不标覆盖。现行跨部见 [大章06-10.md](大章06-10.md)。大章 6–10 均已锁定；场序听跨部，部级进出听 `02-缺席.md` / `03-争夺.md` / `04-安排.md`。冲突听 ledger，不回改矩阵。

查阅顺序：`01-证据.md` → `02-缺席.md` → `03-争夺.md` → `大章06-10.md`（只取大章 10）→ `04-安排.md` → `05-撤退.md` → `06-回看.md`。

## 和别的文件怎么分

| 文件 | 管什么 |
|---|---|
| `story-bible.md` / `总纲-大师写法.md` | 全书骨头 |
| `00-全书结构.md` + 三份场景矩阵 | 部、大章、91 场位（矩阵冻结） |
| **本目录** | 这一部分怎么走：框架、多线、伏笔、人、声音、卡点 |
| `人物志/` | 性格与身世；中纲只取本部分一寸 |
| `文章包/` | 开写：某人遇见什么 |
| `正文/` + `scene-ledger.md` | 已发生事实 |

冲突时：圣经与冻结矩阵优先。中纲不得回改矩阵。已锁定正文与中纲计划不一致，以 ledger 为准，回头改中纲总结栏。

## 何时写

- 开写某部第一章的文章包之前，该部中纲应齐。
- 一部正文锁定后，把中纲的「计划」改成「已有正文后的总结」，只改被正文改掉的那几栏。
- 卡文、审逻辑、抽技法：可只跑创作辅助，不必重写整份。
