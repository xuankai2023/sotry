# 第一、二部场景矩阵（2000–2004）

> 覆盖大章 1–6，共 30 个核心场。  
> 本文件是全书中层矩阵，不是正式场卡，也不是正文。正式写作前仍须把目标场写入 [`../scene-ledger.md`](../scene-ledger.md)，补齐物件次数、上一场已定稿事实和文件路径。

## 总约束

- 2000 年晓宁没有成人式限知，只有温度、声音、气味和被转手的身体。
- 2001 年普通转头会被大人解释成「跟谁亲」，正文不能让孩子已懂选边。
- 2002 年只记住名字从听筒里出来、嘴张开就断。
- 2003 年开始有完整一天想讲，第一次主动删短。
- 2004 年开始看门口的鞋，再决定先叫谁；「爱有边」仍留给 2005 抢勺。
- 建军始终在江州本市上班，不写外地留守。
- 一场一个主物件。时代物件只在改变选择时进入。

# 第一部 · 证据

## 大章 1 · 被写下（2000）

- **大章问题：** 孩子还不会说话，谁已经在用他证明自己？
- **起始状态：** 晓宁只是一个需要喂养的婴儿。
- **不可逆：** 他成为婆家体面、娘家资格、母亲尽责和父亲面子的共同证据。
- **主要限知：** 周建军、周桂芳、林倩。满月群像章允许三种限知，但一场内部不跳。
- **社会压力：** 单位盖章；同楼问办几桌；席面随礼和称呼。

### 1-1 · 换班条（日常 / 外压）

- **年 / 限知 / 主场钟：** 2000 年 7 月，周建军；单位交接窗口，从早班点到换班名单贴出。
- **物件 / 欲望：** 换班条第一次出现。他想换掉满月酒当天的半个班，至少在席面开场时像一个在场的父亲。
- **阻力 / 选择：** 搭班也有家事，少上半天会少津贴；他不再求整天，只换开席前后那几个小时。
- **状态变化：** 父亲的在场第一次被压成班表上的一个缺口；他决定用桌数和随礼把短缺撑圆。
- **接下场：** 班只让出几个小时，他必须提前订桌、封钱，把自己赶不到的时间换成体面。

### 1-2 · 一桌坐谁与信封（外压）

- **年 / 限知 / 主场钟：** 2000 年 7 月，周建军；单位房客厅，酒前一晚从饭后算到灯熄。
- **物件 / 欲望：** 信封和一张座位纸。他想在二室一厅客厅里摆好一桌，把真正不能不来的亲家、长辈和同楼见证人坐下。
- **阻力 / 选择：** 一桌坐不下所有同事，菜钱、奶粉和礼金又挤同一只信封；林倩仍在产假，坐在旁边看自己的返岗日期；建军决定家里只摆一桌，其余同事另送红蛋，不把客厅写成饭店。
- **状态变化：** 孩子未醒，账已经成立；父亲用钱补班，母亲第一次看见自己能在家的日子有截止日期。
- **接下场：** 座位写下以后，桂芳要把红鸡蛋做成这家真正交得出去的东西。

### 1-3 · 红鸡蛋（选择 / 锚点）

- **年 / 限知 / 主场钟：** 2000，周桂芳；单位楼客厅，从下午摆酒到天黑。
- **物件 / 欲望：** 红鸡蛋。她要让同楼姐妹看见孩子由她照料，蛋和桌都不能出错。
- **阻力 / 选择：** 玉梅盯着礼簿，林倩从里屋抱着孩子出来，建军还在算钱；桂芳先端染好的蛋，蛋篮不换手。
- **状态变化：** 晓宁第一次被抱出来、递来递去，先成为桌上的证据；名字和希望先于他本人。
- **接下场：** 蛋交出去以后，席面还要看礼簿上谁先被写下。

### 1-4 · 礼簿一角（后果）

- **年 / 限知 / 主场钟：** 2000 年 7 月，周桂芳；同一客厅，酒过半到人散。
- **物件 / 欲望：** 礼簿。桂芳想把席面收稳，也看见玉梅要把娘家几笔写清。
- **阻力 / 选择：** 志刚只把桌摆正，厚德不争，玉梅不抢第一抱，只按住红封皮一角补记；桂芳没有抽走簿，只把自己记的那页翻回正面。
- **状态变化：** 两套资格账正式开张；桂芳第一次知道，娘家不会只做来客。
- **接下场：** 礼簿给了两家位置，林倩还想留下一张不由礼金决定的母子合影。

### 1-5 · 相册未醒（回声）

- **年 / 限知 / 主场钟：** 2000 年 7 月，林倩；酒散后的客厅，从客人离开到摄影的人收机。
- **物件 / 欲望：** 相册的第一张底片。她想与孩子同框，不只做照片边上的产妇。
- **阻力 / 选择：** 孩子睡着，桂芳先把红蛋和金锁摆到襁褓旁；林倩没有叫醒孩子，坐到床边，让自己的手进入画面。
- **状态变化：** 她确实得到一张母子合影，也同时看见返岗前的日子正在倒数；温暖先成立，代价留到产假结束。
- **接大章 2：** 到 2000 年秋返岗前夜，她会把新罐和说明书放在灶边，试图让自己的方法留在家里。

## 大章 2 · 日常落到谁手里（2000–2001）

- **大章问题：** 出钱的人和每天端碗的人，谁拥有抚养的解释权？
- **起始状态：** 林倩仍相信购买和说明书能证明自己是日常的人。
- **不可逆：** 灶上日常落到桂芳手里；林倩开始用纸和购买反弹。
- **主要限知：** 林倩、周桂芳。
- **社会压力：** 楼道一句「奶奶带得好」；音像柜或同事一句「别输在起跑」。

### 2-1 · 说明书摊开（日常）

- **年 / 限知 / 主场钟：** 2000 年秋，林倩；窄厨房，返岗前一晚从孩子睡下到水壶凉。
- **物件 / 欲望：** 新奶粉罐和仍平整的说明书。她想把第二天每一勺、每一格水温先写清，让自己的办法留在家里。
- **阻力 / 选择：** 桂芳记的是腕子和孩子哭不哭，不是说明书；林倩把纸压在罐下，没有强迫她当夜照做。
- **状态变化：** 购买和方法进入厨房，实际执行权仍未交接；她还有一晚可以抱着孩子，伤害不在这场立刻发生。
- **接下场：** 第二天清早返岗钟真正响起，谁先伸勺才会成为不能重赛的选择。

### 2-2 · 第一把勺（选择 / 锚点）

- **年 / 限知 / 主场钟：** 2000 年秋，林倩；同一厨房，返岗清晨出门前最后十分钟。
- **物件 / 欲望：** 勺。她想把勺接回来，说一句「给我」。
- **阻力 / 选择：** 孩子在奶奶胳膊里不哭，她马上要走；她摸到罐身，抬起的手又放下。
- **状态变化：** 花钱买到罐，买不到日常；安静被大人当成「认人」，桂芳取得灶上解释权。
- **接下场：** 私下的一把勺还可被说成帮忙，必须等外圈公开夸一次，岗位才会被焊实。

### 2-3 · 楼道那句（外压 / 误认）

- **年 / 限知 / 主场钟：** 2000 年末或 2001 年初，周桂芳；厨房窗或楼道，上午粥点后。
- **物件 / 欲望：** 围裙。她想听见别人承认自己还没用废。
- **阻力 / 选择：** 邻居说「还是奶奶带得好」，儿媳说明书仍在柜上；她笑着认下「我带」，把说明书折进柜。
- **状态变化：** 灶上日常被社会网验收为奶奶的岗位；她更难把碗让出去。
- **接下场：** 岗位有了人，父母更容易被班抽走；晚饭必须决定等不等空椅子。

### 2-4 · 空椅子（后果 / 锚点）

- **年 / 限知 / 主场钟：** 2001，周桂芳；晚饭桌，从粥熟到父母仍没回来。
- **物件 / 欲望：** 空椅子旁扣着的碗。她要让日子不塌，孩子按时吃上。
- **阻力 / 选择：** 林倩只留下水温和「别追着喂」，建军夜班；桂芳不等人齐，先把饭开了。
- **状态变化：** 家第一次在少一双筷子时照常运转；她的第二份班从帮忙变成事实。桂芳看见孩子吃完热粥后不再闹，先把这晚过稳，不替孩子解释感受。
- **接下场：** 日常交干净后，林倩必须寻找新的在场证明。

### 2-5 · 磁带收据（反弹 / 回声）

- **年 / 限知 / 主场钟：** 2001，林倩；商场音像柜或客厅，一个周末下午。
- **物件 / 欲望：** 早教磁带收据。她想把「我尽心」重新买回来。
- **阻力 / 选择：** 这个月紧，孩子听不懂，桂芳也不会按；她仍买下，把收据压进抽屉。
- **状态变化：** 纸正式开始替人到场；母亲从争勺转向争购买和规划。
- **接大章 3：** 碗在婆家，纸在母亲，娘家那一头仍空着；玉梅只有住进来，资格才不只在礼簿上。

## 大章 3 · 一套房子，两头家（2001–2002）

- **大章问题：** 父母被班抽走后，谁来补位，补位又占了谁的位置？
- **起始状态：** 桂芳拥有灶上日常，玉梅只有礼簿和探望资格。
- **不可逆：** 娘家资格进入客厅；家被座机切成灶边和工位两头。
- **主要限知：** 林倩、周桂芳。
- **社会压力：** 邻居看见外婆来住；工位同事催促电话结束。
- **禁止提前：** 晓宁不能已经理解爱有边，也不能主动删短完整一天。

### 3-1 · 会走交给谁（日常 / 外压）

- **年 / 限知 / 主场钟：** 2001，林倩；家门口，赶班前第一次把会走的孩子留下。
- **物件 / 欲望：** 钥匙和门插销。她想让白天有人看，又不伤两边母亲。
- **阻力 / 选择：** 桂芳要把门插好，玉梅说可带去住几天；林倩把孩子先放进桂芳怀里，只说「以后住几天」。
- **状态变化：** 白日日常完成交手；娘家若不占到夜，仍然像客人。
- **接下场：** 玉梅必须把铺盖放下，才能让「住几天」变成事实。

### 3-2 · 加床（选择 / 锚点）

- **年 / 限知 / 主场钟：** 2001，林倩；客厅，一个傍晚。
- **物件 / 欲望：** 角落的包或加床，正式场卡时二选一。她想让母亲住下，又不撕破婆家的日常。
- **阻力 / 选择：** 玉梅要夜和称呼，桂芳只让座不让作息，建军不当裁判；林倩点头「住几天」，帮着铺床。
- **状态变化：** 短住从探望变成占位；林倩只看见孩子在两套胳膊之间被换抱，不能替孩子总结他记住了什么。
- **接下场：** 包留下后，衣服、盐和碗的位置都会发生变化。

### 3-3 · 阳台那件衣（后果）

- **年 / 限知 / 主场钟：** 2001，周桂芳；客厅加床和阳台，短住后第一个早晨。
- **物件 / 欲望：** 晾在最外面的娘家衣服。她想保住水温、粥点和叫法。
- **阻力 / 选择：** 邻居问「外婆也来了」，玉梅的夜已经进门；桂芳让座、让橘子，不让碗，把碗柜叠得更齐。
- **状态变化：** 两家开始记住夜、衣服和叫法；资格账从礼簿搬进客厅。
- **接下场：** 玉梅短住结束时把衣服留下一件，临走只说有事打电话；同一周林倩返岗后的晚班加长，屋里从两套胳膊重新少回一套，座机因此成为两家补位后的唯一共同入口。

### 3-4 · 吃了没（选择 / 锚点）

- **年 / 限知 / 主场钟：** 2002 年初，周桂芳；玉梅离开后的一个晚班日，墙上座机从晚饭前响到工位催促。
- **物件 / 欲望：** 听筒。她要把「吃了」报稳，让儿女放心，也证明这屋没塌。
- **阻力 / 选择：** 孩子声音尚未成形，那头有人催；她先替孩子答，替父母解释忙。
- **状态变化：** 家切成灶边和工位两头；桂芳看见晓宁听到名字后张嘴，忙音却先响起来。
- **接下场：** 新通讯工具进门，但老人不会使用，话只会更短。

### 3-5 · 小灵通不会回（回声）

- **年 / 限知 / 主场钟：** 2002，周桂芳；客厅茶几，周建军把自己的小灵通临时留在家中的一个下午。
- **物件 / 欲望：** 小灵通绿屏。她想有事时能直接回给儿子，不必一直守墙上铃。
- **阻力 / 选择：** 按键小、菜单不熟，回拨被按成关机；她把机收回建军的袋里，仍守墙上座机。
- **状态变化：** 小灵通有明确主人，老人没有因此取得移动通讯权；家庭语言仍被座机和班点压短。
- **接大章 4：** 2003 年林倩自己仍没有移动电话，只能用单位大厅 IC 卡机打回家；孩子开始会讲，小椅子和豆浆皮仍只有几分钟。

# 第二部 · 缺席

## 大章 4 · 说不完（2003）

- **大章问题：** 孩子开始会说，为什么完整的一天仍没有地方放？
- **起始状态：** 大人替晓宁删短，晓宁尚未主动删。
- **不可逆：** 他第一次自己把后半句咽掉。
- **主要限知：** 周晓宁、林倩。
- **社会压力：** 幼儿园午睡纪律；本市工位排队、催班和打卡。
- **硬边界：** IC 卡场是江州本市工位或厂门口打回家，不写村口电话亭和外地留守。

### 4-1 · 小椅子上的一天（日常）

- **年 / 限知 / 主场钟：** 2003，周晓宁；幼儿园，从午前坐小椅子到午睡。
- **物件 / 欲望：** 写了名字的小椅子。他想把豆浆皮、哪吒和谁抢椅子带回家讲。
- **阻力 / 选择：** 老师要闭眼，毛巾盖脸；他装睡，把要说的话先含着。
- **状态变化：** 他第一次拥有一段属于自己的完整日常，并期待有人听。
- **接下场：** 父母能不能到园门口，决定这一天有没有听众。

### 4-2 · 夜班还是门口（外压）

- **年 / 限知 / 主场钟：** 2003，林倩；单位打卡口到办公室电话，放学点前后。
- **物件 / 欲望：** 班表或打卡纸。她想亲自接到孩子、听他说完。
- **阻力 / 选择：** 打卡已过点，请假扣工，建军也在班上；她让桂芳去接，只许诺晚上打电话。
- **状态变化：** 接送承诺第一次被单位公开截断；在场改成「晚上听筒见」。
- **接下场：** 电话回来时，桂芳会先把平安报完，孩子的话仍轮不上。

### 4-3 · 替答（误认）

- **年 / 限知 / 主场钟：** 2003，周晓宁；灶边座机，晚饭前后。
- **物件 / 欲望：** 听筒。他想讲小椅子和午睡。
- **阻力 / 选择：** 桂芳怕儿女担心，先说吃了、没发烧、没挨批；孩子嘴张开，只点一下头。
- **状态变化：** 完整一天先被成人删短；他开始察觉后半句没有位置。
- **接下场：** 下一次电话直接交给他，时间和卡余额将逼他自己删。

### 4-4 · IC 卡（选择 / 锚点）

- **年 / 限知 / 主场钟：** 2003，周晓宁；工位或厂门口磁卡电话与家中灶边两头，从插卡到跳字结束。
- **物件 / 欲望：** IC 卡。他想把幼儿园的一天讲完。
- **阻力 / 选择：** 数字在跳，后面有人催，那头先问吃了没、听不听话；他只说「吃了」「听话」，自己吞掉后半句。
- **状态变化：** 第一次主动删短；他仍不知道什么叫缺席，只知道新话会让时间不够。
- **接下场：** 挂断后粥照常开，大人会用购买许诺来补没听完的话。

### 4-5 · 忙音后粥仍开（后果 / 回声）

- **年 / 限知 / 主场钟：** 2003，林倩；电话挂断后的工位，或她晚归后的饭桌。
- **物件 / 欲望：** 没放稳的听筒。她想补问一句「想妈妈吗」。
- **阻力 / 选择：** 班点已到，孩子也不再讲，桂芳只说吃了；她把问题改成以后买东西。
- **状态变化：** 她确认人回不来时，只能让钱和物先回；亏欠开始寻找罐和信封。
- **接大章 5：** 说不完的一天将被换罐、工资袋和「妈妈来接」偿还，但偿还仍可能失约。

## 大章 5 · 钱先回来（2004）

- **大章问题：** 父母不在场时，罐、信封和物品能不能替人到家？
- **起始状态：** 林倩已开始用购买许诺补电话里的缺席。
- **不可逆：** 林倩和建军把购买、信封和「马上」当作在场。
- **主要限知：** 林倩、周建军。
- **社会压力：** 超市比价；园门口锁门；来客看柜顶铁罐。

### 5-1 · 工资袋先于人（日常 / 外压）

- **年 / 限知 / 主场钟：** 2004，周建军；家门口，发薪日傍晚进门后的几分钟。
- **物件 / 欲望：** 牛皮纸工资袋。他想让房改补款、奶粉和接送都不断，让家里先看见钱到了。
- **阻力 / 选择：** 信封薄，交班电话又响，桂芳问的却是回来吃饭没有；他把钱放下，不拆工装，又转身回单位。
- **状态变化：** 信封开始替人进门；钱被误认成在场。
- **接下场：** 信封必须变成一件能被看见的照顾，奶粉罐成为下一张证明。

### 5-2 · 换罐（选择）

- **年 / 限知 / 主场钟：** 2004，林倩；超市奶粉架，一个周末午前。
- **物件 / 欲望：** 新铁罐。她想用价格和标签证明自己补过了。
- **阻力 / 选择：** 差价挤房改补款和菜钱，桂芳也不认洋字；她仍抱回铁罐，把收据留下。
- **状态变化：** 购买权进一步加重，开不开罐仍不在她手上。
- **接下场：** 罐进厨房后，桂芳必须决定是否改变原来的冲法。

### 5-3 · 柜顶铁罐（后果）

- **年 / 限知 / 主场钟：** 2004，林倩；厨房，换罐后的第一个夜里回家。
- **物件 / 欲望：** 柜顶仍未拆封的铁罐。她想看见桂芳已经照说明换了冲法。
- **阻力 / 选择：** 桂芳仍用原来的袋装粉和腕内侧试温，孩子也没有哭；林倩没有把旧袋扔掉，只把新罐从柜顶挪到灶边。
- **状态变化：** 她看见新方法尚未进入日常，下一步只能把争夺转向自己能真正到场的接送。
- **接下场：** 纸和罐都不够，林倩只能把战场转到接送。

### 5-4 · 妈妈来接（选择）

- **年 / 限知 / 主场钟：** 2004，林倩；单位走廊，从下午四点半到园门将锁。
- **物件 / 欲望：** 鞋跟或打卡纸。她想亲自出现在门口，不再靠铁罐。
- **阻力 / 选择：** 早晨已经答应孩子今天来接，临时材料却压到下班点，建军也在另一班；她回到工位，打电话让桂芳再去接。
- **状态变化：** 「马上」正式成为家庭在场句；这次不是没有许诺，而是先许再失约。
- **接下场：** 孩子最后等到的只会是一声喇叭或一件先到家的东西。

### 5-5 · 喇叭与一瓶（回声）

- **年 / 限知 / 主场钟：** 2004，周建军；家属院铁门，天擦黑后停留的几分钟。
- **物件 / 欲望：** 车喇叭。他想替林倩把失约补上一点，也让孩子看见父亲回来过。
- **阻力 / 选择：** 桂芳已经接到，饭也盛好，他还要回去交班；他按一声喇叭，把一瓶饮料递给孩子，没有上楼坐下。
- **状态变化：** 周建军独立选择用物和声音补人，父亲线第一次不再是「或许由谁」；孩子拿到东西，仍会在门口等一眼车是否掉头。
- **接大章 6：** 物能替人进门，床位和路不能；娘家若只寄钱，仍像柜顶铁罐一样有份但不在。

## 大章 6 · 床位和路（2004）

- **大章问题：** 谁能住进客厅，谁又永远只能送到楼下？
- **起始状态：** 玉梅曾短住，但娘家常被重新压回寄钱和探望。
- **不可逆：** 晓宁开始看门口的鞋，决定先叫谁。
- **主要限知：** 林倩、周晓宁。
- **社会压力：** 汇款窗口；邻居问外婆来不来；门房看见二八车停一下就走。
- **禁止提前：** 不写两把勺同时停住，不写孩子已经明确看脸色张嘴。

### 6-1 · 寄钱还是来住（外压）

- **年 / 限知 / 主场钟：** 2004，林倩；听筒或客厅，一个晚上。
- **物件 / 欲望：** 汇款单。她想让娘家有份，又不打乱婆家灶上日常。
- **阻力 / 选择：** 玉梅更想亲自来，桂芳怕作息乱，月供也紧；林倩先劝母亲寄钱。
- **状态变化：** 娘家资格再次变成纸；玉梅更不能接受只做汇款的人。
- **接下场：** 钱寄出后，人仍会带着铺盖来，加床记忆重新被翻开。

### 6-2 · 铺盖再卸门厅（选择）

- **年 / 限知 / 主场钟：** 2004，林倩；客厅，玉梅再次短住的傍晚。
- **物件 / 欲望：** 编织袋或加床。林倩想让母亲住，又希望少占一点。
- **阻力 / 选择：** 桂芳让座不让灶，邻居已经看见，建军不作判断；她再次点头「住几天」。
- **状态变化：** 加床从一次短住变成可反复使用的娘家资格。
- **接下场：** 人既然来了，玉梅必须提出把外孙带回邻县住一晚，路成为新的账。

### 6-3 · 回娘家没回成（后果）

- **年 / 限知 / 主场钟：** 2004，周晓宁；家门口，原定出发的上午。
- **物件 / 欲望：** 已收好的小包。他想坐外公的车去十二公里外的邻县城关镇。
- **阻力 / 选择：** 林倩临时被单位叫回，桂芳不肯让四岁的孩子只跟老人走这段路；行程明确取消，小包重新放回椅背。
- **状态变化：** 路第一次成为可被成人工作取消的安排；他记住的是包收好又被放回。
- **接下场：** 取消以后玉梅不肯只等下次全家有空，钱厚德会在下一周单独骑车来接一次白天短住。

### 6-4 · 外公后座（选择 / 喘息）

- **年 / 限知 / 主场钟：** 2004，周晓宁；从家属院到邻县城关镇，次周上午四十五到六十分钟的一段后座。
- **物件 / 欲望：** 二八车棉垫。他只想看路边、听车铃，终于把上周没走成的路走完。
- **阻力 / 选择：** 路不短，厚德只在坡前让他下车走几步，再重新绑紧棉垫；这场不问跟谁亲，也不立即转成资格冲突。
- **状态变化：** 晓宁得到一次完整、安稳且无需回答的路程；这份安全先在场末成立，代价留到回城进门。
- **接下场：** 傍晚厚德把他送回楼下就走，门内两双等待称呼的鞋才重新把轻松收紧。

### 6-5 · 门口的鞋（回声 / 章不可逆）

- **年 / 限知 / 主场钟：** 2004，周晓宁；家门口，进门的半分钟。
- **物件 / 欲望：** 鞋。他想先叫一个不会马上让场面变紧的人。
- **阻力 / 选择：** 两双鞋都在，或只有奶奶的鞋；他先看鞋，再决定先叫奶奶还是外婆。
- **状态变化：** 身体开始用门口判断家；这还不是完整选边，却成为下一年抢勺的生存准备。
- **接大章 7：** 当两把勺同时伸来时，他会把门口学到的办法用到嘴上：先看脸色，再张嘴。
