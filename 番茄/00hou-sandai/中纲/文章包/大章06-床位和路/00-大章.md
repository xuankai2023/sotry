## 这一篇写什么

谁能住进客厅，谁又永远只能送到楼下？

## 某人遇见什么

晚上林倩在客厅对着墙上听筒，玉梅要亲自来，桂芳怕作息乱，月供那一行还在，她劝先寄，把汇款单折进抽屉，不写窗口汇出、不写款已入账。几天后傍晚玉梅仍带着编织袋进门厅，桂芳让座不让灶，邻居已经看见，建军在班上不评，林倩再次点头住几天，袋卸下，加床再铺。原定回邻县的上午，晓宁小包已经收好，林倩被单位叫回，桂芳不肯让四岁只跟老人走这段路，行程取消，小包放回椅背。次周上午钱厚德单独骑二八车来接，后座棉垫绑紧，晓宁走完上周没走成的路，不问跟谁亲。傍晚厚德送到楼下就走，晓宁进门先看鞋，再叫一声。

## 思想 / 人物变化 / 背景变化

### 思想
钱能折成纸，铺盖能再卸，路却说取消就取消，进门该先叫谁？

### 人物变化
- 进章：林倩刚用罐和马上当过在场；玉梅仍常被压回寄钱；晓宁会删短，还不会用门口判断家。
- 章末：娘家资格可反复占床；路可被班取消，也可被外公骑完；晓宁开始看门口的鞋再叫人。
- 可见证据：单折进抽屉；袋卸在门厅、加床再开；小包收回椅背；棉垫上走完十二公里；鞋在门槛里，称呼晚半拍。

### 背景变化
- 进章：物能替人进门，床位和路的账还没翻开。
- 章末：客厅床位可反复给娘家；楼下是厚德的终点；门口的鞋开始替孩子选第一声。
- 可见证据：加床第二次铺开；车铃在楼下停一下就走；他先看口，再叫一声。

## 起始 / 不可逆

- **年段：** 2004。晓宁约四岁。房改补款 / 月供挤钱包，不当社论。
- **波形：** 迟爆。前两场纸和床像能把娘家安顿住；取消、后座、门口的鞋才把路和称呼的账付上。与大章 5 早选错开。
- **起始：** 5-5 瓶进门、车掉头；物能替人进门，床位和路不能。3-2 加床已铺过一次，「住几天」不是第一次出口。林倩仍无个人移动电话。
- **不可逆：** 晓宁开始看门口的鞋，再叫人。不锁「先叫奶奶、第二声没出」当已发生句。
- **本章只丢一寸：** 路被班取消，得到看鞋。抢勺、看脸色张嘴、「都亲」「还行」全部不进。
- **主要限知：** 林倩 → 林倩 → 晓宁 → 晓宁 → 晓宁。一场内部不跳。玉梅、厚德、桂芳不当本章限知。
- **主风格 / 场卡 skill / 正文 skill：** 家庭现实主义 / `novel-chapter-family-realism` / `novel-chapter-prose`

## 全章因果

因为 5-5 物能替人进门、床位和路还不能，2004 年娘家仍常被压回寄钱和探望；林倩原想让娘家有份又不打乱灶上日常，玉梅要亲自来、桂芳怕乱、月供也紧，于是她先劝寄钱、折单进抽屉，娘家资格再次变成纸，人更不肯只做汇款。因为纸没有按住人，玉梅带着铺盖来，林倩原想少占一点，邻居看见、桂芳让座不让灶、建军不评，她再次点头住几天，加床从一次短住变成可反复使用的娘家资格。因为人来了，玉梅提出带回邻县，原定出发的上午林倩被单位叫回，桂芳不肯让四岁只跟老人走这段路，小包收回，路第一次被班取消。因为取消以后玉梅不肯只等全家有空，次周厚德单独骑车来接白天短住，晓宁走完那条路，安全先成立。因为傍晚厚德送到楼下就走，门内的鞋把轻松收紧，他先看鞋再叫一声，身体开始用门口判断家，逼出大章 7：两把勺伸来时，先看再张嘴。

## 本章人物

只取寄钱与再住、路被取消、后座走完、看鞋再叫这一寸。全文见 `中纲/人物志/七人.md`。

- **林倩：** 进章刚用物和马上当过在场。身世只露怕缺席也怕娘家没份。手：折汇款单、点头、被叫回。嘴：先寄；住几天；今天走不成。不说我亏欠、少年宫。章末只变成班取消了路。
- **周晓宁：** 进章还不会用门口判断家。身世只露他被安排上路又被收回。手：抓小包、抓棉垫绳、看鞋。嘴：短；走；一声称呼。不讲资格。章末只变成看鞋再叫。
- **赵玉梅：** 不当限知。手：要来、卸袋、提带回邻县。嘴：我来住一段；你们忙，孩子我带。
- **钱厚德：** 不当限知。手：绑棉垫、坡前让他走几步、送到楼下就走。嘴：随你；头低一点。茶不喝。
- **周桂芳：** 不当限知。手：让座不让灶；按住小包。嘴：灶我熟；这路他不能只跟你们走。
- **周建军 / 周志刚：** 本章可不进或一句。建军 6-2 在班，不评床。

## 本章声音

- 句长：林倩跟纸、袋、袖口走；晓宁跟包、棉垫、鞋走，短，身体先于判断。
- 叙述句法：五场必须换呼吸。6-1 / 6-2 纸和袋的迟疑；6-3 包的收与放；6-4 铃和风拉长；6-5 鞋和称呼的半拍。不要五场都用「短事实。短复述。不是/才是」。
- 对话：先寄、住几天、走不成、随你、一声称呼。真话在折单、卸袋、放回包、绑绳、叫晚半拍。
- 禁用：资格、选边、补偿；「不是 A，是 B」当段尾；把「马上」「回头买」整句从大章 4–5 搬来当收束。
- 旧稿起笔禁用：汇款单的角还翘着；加床还折着，靠墙；门槛里有一双鞋。
- 主题词各场只立一次，随后衰减到动作：6-1 单；6-2 袋；6-3 包；6-4 棉垫；6-5 鞋。
