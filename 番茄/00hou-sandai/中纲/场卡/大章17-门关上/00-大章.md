## 大章问题

门还虚掩着，为什么先要人敲一下，后来又必须合死？

## 起始状态 / 目标不可逆

- **起始：** 16-5 先问灯，不看鞋位；门仍虚掩；解释不再被要。
- **不可逆：** 门第一次完整合上；桂芳把水留在门外，林倩没有推门，晓宁到第二天才拿走凉杯。三个动作共同完成边界，不用人物宣告。
- **本章只丢一寸：** 门成为界，水留在门外。
- **主要限知：** 周晓宁 → 周桂芳 → 周晓宁 → 周桂芳 → 周晓宁。一场内部不跳。
- **必到锚点：** 进来前敲一下；一掌宽把第一只杯送进桌角；锁舌一声；第二只杯放门槛外、水在外面；第二天拎凉杯。
- **已锁杯账：** 17-2 掉瓷搪瓷杯进桌角；17-3 仍在桌角；17-4 另倒蓝沿第二只放门槛外；17-5 拎第二只进桌角，与第一只并排。禁止一只杯穿墙。

## 5–7 场因果

1. [日常 / 喘息](场01-门把.md)：说进来前敲一下；她敲了，暂时有效。门未合严。
2. [外压](场02-水杯.md)：同楼说又关着，仍推开一掌宽，第一只杯进桌角。
3. [选择](场03-门.md)：锁舌一声，不摔，门完整合上。
4. [后果 / 锚点](场04-门口的杯.md)：手收回，第二只杯留在门外。
5. [回声 / 章不可逆](场05-凉杯.md)：当晚不开；第二天拎凉杯。

五场不能对调：没有 17-1 的敲被听见，17-3 关死没有暂时成功对照；没有 17-2 的一掌宽，关死会像突然反抗；没有 17-3 的锁舌，17-4 的杯在门外没有来路；没有 17-4 的杯在门外，17-5 没有可见界；没有 17-5 的拎凉杯，18 的旧物命名没有十岁的身体来路。

## 本章思想 / 人物变化 / 背景变化

### 思想
关门是反抗、逃生，还是把爱也挡在外面？

### 人物变化
- 进章：16-5 先问能不能开，门仍虚掩；会说作业，仍让人直接推。
- 章末：锁舌一声；水在门外；两个人都不推；第二天拎凉杯。不锁清屋、第一人称。
- 可见证据：门把被按住；两下敲门；一掌宽被缩小；锁舌；门口的杯从热到凉。

### 背景变化
- 进章：小房门仍常常虚掩；水还能送进桌角。
- 章末：门成为不需猜测的界；爱从进门改成留在门外。
- 可见证据：门缝先有、后无；第一只杯锁在桌角；第二只杯在门口再被拎进；同楼一句又关着。

## 松紧位置

- **喘息 / 日常：** 17-1。敲门被听见先真实成立到场末。不当场揭成独立宣言。
- **外压：** 17-2。同楼「又关着」。第一只杯进桌角。
- **重压 / 选择：** 17-3。锁舌一声。
- **后果：** 17-4。手收回，水在外面。
- **回声 / 章不可逆：** 17-5。隔门别太晚；第二天拎凉杯。不再制造新冲突。
