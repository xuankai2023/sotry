## 大章问题

人终于接到了，为什么孩子已经不再等待解释？

## 起始状态 / 目标不可逆

- **起始：** 15-6 后座仍稳，不催，一路想上线。接人路线还在。会马上，门仍虚掩，仍会等理由。未写晚托。
- **不可逆：** 他说出「没事，我知道你忙」，并真正停止等待：不再检查约定的日期、路口和鞋位。不锁门完整合上、水杯放门口、收据审判。
- **本章只丢一寸：** 不再检查。得到那句没事和先问开机。
- **主要限知：** 周晓宁 → 周建军 → 周晓宁 → 林倩 → 周晓宁。一场内部不跳。桂芳、玉梅、厚德、志刚不当限知。
- **必到锚点：** 余温与周五；打卡留下；自己背书包；没事我知道你忙；先问开机。

## 5–7 场因果

1. [日常 / 喘息](场01-蓝凳.md)：扶过余温，把周五记在课程表边上。照料先成立到场末。
2. [外压](场02-打卡卡片.md)：盯着打卡卡片仍留下，打电话让桂芳从家里赶去。
3. [选择 / 锚点](场03-课程表.md)：看过路口一次，自己背好书包，下到铁门内侧。
4. [后果 / 锚点](场04-肩上的包.md)：单位临时说不完；听见没事我知道你忙。
5. [回声 / 章不可逆](场05-主机灯.md)：不看日期、路口、鞋位，先问能不能开。

五场不能对调：没有余温和日期，16-5 的不再检查没有来路；没有打卡留下，空等只剩母亲，建军又变透明；没有空椅和自己背书包，16-4 的没事会像作者教的；没有那句没事，16-5 先问开机没有对手；没有先问开机，17 的关门没有「心已经回去」。

## 本章人物

只取余温与日期、打卡留下、自己背书包、没事我知道你忙、先问开机这一寸。全文见 `中纲/人物志/七人.md`。

- **周晓宁：** 16-1 / 16-3 / 16-5 限知。进章会马上，仍会等理由。身世只露怕一局做不完，也怕当众没有答应来的那个人。手：扶凳面；记周五；自己背书包；先问开机。嘴：16-4 才说没事我知道你忙；16-5 能不能开。不说你怎么才来、还行、我被安排。章末只变成：不再检查日期、路口、鞋位。
- **周建军：** 16-2 限知。进章柜前、解释常不在。身世只露怕这个点再丢津贴，也怕孩子只记得喇叭。手：盯卡片；打电话。嘴：中。你让妈从家里去。不说为了这个家、对不起。章末只变成：人仍留在交接处。
- **林倩：** 16-4 限知。进章会签学习，不推门。身世只露怕解释权作废。手：包压在肩上；解释伸到一半停住。嘴：单位临时……（说不完）。不说少年宫、我是坏妈妈。章末只变成：解释没有被索取。
- **周桂芳：** 不当限知。可夹凳、赶去、名条签字、凳夹回门后。不说我还能用、别告诉你妈、他已经不等。
- **赵玉梅 / 钱厚德 / 周志刚：** 本章不碰。

## 本章思想 / 人物变化 / 背景变化

### 思想
人终于接到了，为什么孩子已经不再等待解释？

### 人物变化
- 进章：15-6 后座仍稳，他会说马上，仍会在门口等理由；门仍虚掩。
- 章末：「没事，我知道你忙」出口；日期、路口、鞋位都不再检查；先问能不能开。不锁门完整合上、水杯放门口。
- 可见证据：凳面余温；课程表边上的周五；打卡卡片留下；空椅；自己背书包；那句没事；凳夹回厨房门后。

### 背景变化
- 进章：接人路线还在；晚托未写；马上是屏幕里的词。
- 章末：校外小饭桌的接人名条签过；约定的周五以空门兑现；家仍在，解释不再是回家的必要部分。
- 可见证据：蓝凳、名条、铁门、主机灯。

## 松紧位置

- **喘息 / 日常：** 16-1。掌心余温与记下日期先真实成立到场末。不当场揭成心死。
- **外压：** 16-2。打卡、津贴、交接。组长加班名单。
- **重压 / 选择：** 16-3。灯亮椅空，自己背书包。
- **后果：** 16-4。解释说不完。
- **回声：** 16-5。三个不再检查的动作 + 先问开机。不再制造新冲突。门外不开第二场。
