# 长篇描写总谱

写三十万字以上家庭长篇时先读本文件，再读一张风格卡。本谱跨风格共用：管十年怎么铺、单场写多少、同一物件如何变、多场如何不重复。风格气质仍由 `01`–`08` 决定。

## 结构单位

本谱只管**场**的描写配额，不决定全书只有多少章。

对 00 后三代现行工程：

- 6 部
- 18 个大章
- 每个大章 5–7 场
- 每场默认 3300–4000 字
- 约 90–126 场，总量约 30–50 万字

大章承担不可逆关系转折；单场只需一次状态变化。一房、一钟、一物、一动作均为单场规则。

各风格卡后半的多场变奏只是一组防重复示范，不代表固定场数，也不要求每一项都使用。

人名地名用【占位】。可套任何中国家庭长篇，不绑定某一本书。

## 短卡不够用的原因

风格卡解决的是「这一场像不像这种风格」。长篇还要解决：

- 十年里人的身体、口气、路线会变，描写词库必须换代
- 同一只碗、同一扇门要出现十几次，每次意思只能挪一寸
- 春节、开学、家长会会循环，不能每年写成同一场
- 外圈必须轮换，不能多场都是同一个邻居说同一句
- 开篇密、中段省、收束准，密度不能从头到尾一样

缺这一层，写到第十章就会开始自我重复。

## 长篇调用顺序

1. 本谱：定本章在十年哪一段、一年哪一节、用哪件主物件的第几次出现。
2. 风格卡：定这一场的手法、句式、禁区。
3. 基础卡：只在要换手法类型时读。
4. 写完过「防重复七问」。

不要八张风格卡整包读。一次一书一个主风格。

## 单场描写配额（长篇用）

一场只配：

| 配额 | 数量 | 说明 |
|---|---|---|
| 主场 | 1 | 房间或门口 / 听筒，不换三个场 |
| 钟 | 1 口 | 几点到几点，或一顿饭到一趟班 |
| 主物件 | 1 | 本章被改意思或被重复的那件 |
| 主动作 | 1 | 谁先伸手、谁停、谁把门带上 |
| 肖像 | 最多 2 人各 1 处 | 新人上场才写，老人只用手或鞋提醒 |
| 对话有效句 | 6–12 句 | 其余用动作和沉默 |
| 外圈 | 0–1 人 1 句或 1 个动作 | 每个大章至少两次社会压力进入；无真人时写清外压载体 |
| 自然 | 0–1 处 | 必须改出门、等人、饭凉 |
| 心理 | 0–1 段 | 很多风格应是 0 |

超配额就在重复。三十万字靠「场数 × 配额」，不靠一场写尽。

## 开篇 / 中段 / 收束的密度

**开篇（约前 4–6 万字）**  
空间要立住：座位、抽屉、门口、谁的杯。物件第一次出现，先当普通物，不解释象征。外圈可以密一点，把家嵌进楼里。

**中段（约 6–22 万字）**  
少写新空间，多写旧物第 N 次。同一手法要变奏：上次先端勺，这次是不先端；上次听筒，这次是不接。外圈轮换工种，不轮换功能——永远只负责把家里的事公开或钉死。

**收束（约最后 4–6 万字）**  
不再开新主物件。只让旧物改最后一寸意思。描写更短。禁止用风景升华，禁止新外圈进来总结全书。

## 十年五段：身体和描写必须换代

不要十年都用「小小的手」「清澈的眼睛」。按段换词。

### 一段 · 婴幼儿（满月到会走）

**看**：襁褓、奶味、被转一圈的身体、谁的手臂、谁的勺、谁先抱。  
**孩子还不会**：关门、撒谎、说没事。他是被展示、被喂、被安排的物体兼人口。  
**成人露出**：抢抱、抢喂、抢叫法、席面上的证据。  
**禁**：给婴儿写早熟内心。

### 二段 · 幼儿园（会叫人到入学前）

**看**：小凳、手绢、被拉的衣领、接送的铁门、晚托、比较胖瘦。  
**孩子开始会**：看谁的鞋在、跟谁走、把好吃的叫成谁给的。  
**新场**：园门口、班级门口、第一次被问「妈妈呢」。  
**禁**：写成天才观察日记。

### 三段 · 小学低年级（入学到八九岁）

**看**：红领巾、铅笔刀、作业本封面、零花、谁签字、谁开家长会。  
**孩子会**：配合、把两边的话记成两本账、开始说「还行」。  
**新场**：教室、校门口冰柜、第一次成绩单进抽屉。  
**身体**：换牙、近视苗头、鞋总小一号。

### 四段 · 小学高年级（十到十二）

**看**：钥匙、第一扇能带上的门、手机或电话的使用权、被问第几。  
**孩子会**：撒谎、少问、先看脸色再进门。  
**新场**：自己的抽屉、楼上同学家、第一次独自回家。  
**身体**：个子过老人、声音开始变、不肯当众被喂。

### 五段 · 少年（十三到十八，或书的「现在」）

**看**：门缝、灯、屏幕、不再跟的那条路线、听筒里的敷衍。  
**孩子会**：关门、说没事并停催、把自己从席面的证据里抽走。  
**新场**：自己的房间逻辑、同学的点、不再坐联播旁边。  
**禁**：口吐主题、突然变成哲学家。

一段换代，词库、主场、外圈工种一起换。中段不要退回一段的襁褓词，除非在回忆里，且回忆也要用现在的眼睛看旧物。

## 一年节令：循环但不能复制

每年可回一次，必须换「谁的手 / 谁缺席 / 物件第几次」。

| 节令 | 描写入口 | 每年必须换的一寸 |
|---|---|---|
| 春节 / 年夜 | 红包路线、叫人、席位、压岁钱进谁口袋 | 收钱的人、孩子敢不敢要、外圈比谁家厚 |
| 元宵 / 灯 | 出门权、谁牵谁、谁先累 | 孩子还让不让牵 |
| 清明 / 上坟 | 谁请假、谁买纸、车上的沉默 | 来的人少一个，或多一个只拍照的人 |
| 端午 | 谁包粽、灶被谁占、香味到哪一层 | 占灶的人换了，味还在 |
| 暑假 | 回没回老家、谁的屋、表哥同住 | 床位、作业监督权 |
| 开学 | 校服、书包、签字、接人点 | 谁送、谁已经不送 |
| 中秋 | 谁回家、月饼从哪家来、阳台 | 缺席用一盒饼代替 |
| 国庆 / 长假 | 单位放不放、旅游有没有、家是否更挤 | 假条比风景重要 |
| 冬至 / 腊八 | 谁记得吃、谁在单位加班 | 一碗汤圆的归属 |
| 生日（孩子） | 仪式重不重、谁买单、谁缺席 | 礼物比人先到，或人到了不问想要什么 |
| 生日（老人） | 谁到场、拍不拍照、红包 | 用不用来证明孝 |
| 满月 / 周岁（回忆或新生儿） | 展示、随礼、叫法 | 孩子是证据还是人 |

同一节日在书里最多浓写 2–3 次。其余年份用一句物件带过：红包又进了同一个口袋。

## 生命事件入口（不是狗血，是描写门）

每件只当一场的钟和生活入口，不当全书发动机。

1. 满月 / 百日 / 周岁：展示与叫法  
2. 断奶 / 第一口饭：勺的主权  
3. 入园 / 入学：门口的钟第一次对学校  
4. 第一次请假接孩子：假条 vs 日常  
5. 第一次成绩单：抽屉权  
6. 换牙 / 近视 / 长个：身体被评论  
7. 转学 / 换班：外圈重置，内圈旧物还在  
8. 搬家 / 装修 / 加防盗门：空间重排，权力重排  
9. 单位变班 / 下岗传闻 / 换工作：钱和人哪样先断  
10. 买房 / 月供第一年：信封上桌  
11. 老人住院（小事或手术，不写绝症抢戏）：谁陪夜、谁出钱、谁在班上  
12. 孩子发烧（普通烧）：谁请得出假  
13. 亲戚留宿 / 表哥住下：加床、孩子被挪  
14. 家长会：当众第几  
15. 第一次独自在家  
16. 第一串钥匙  
17. 第一部电话/手机归谁  
18. 中考或小升初：报班、排名、假期消失  
19. 丧事（可有，白描流程，不当煽情高潮）  
20. 婚宴 / 满月酒做客：外圈席面，回家后屋里变一点  
21. 停水停电：秩序露出骨头  
22. 老鼠、漏、换窗：谁出钱谁动手  
23. 邻居装修 / 搬家：比较被激活  
24. 暑假作业大战：监督权  
25. 第一次说「没事」且停催  

选事件先问：它改了座位、门口、纸，还是钟？改不了这四样，就还不是一场。

## 主物件十年变意（通用底表）

风格卡会改气质，变意逻辑可共用。每件在全书计划出现 4–8 次，每次只挪一寸。

| 物件 | 一次 | 二次 | 三次 | 末次 |
|---|---|---|---|---|
| 碗 | 喂 | 抢着喂 | 孩子自己端 | 旧碗还在，人不在这桌 |
| 勺 | 第一口 | 两只勺打架 | 孩子躲勺 | 勺挂回墙上 |
| 门 | 家人进出 | 验收谁接到 | 孩子带上 | 留缝或关死 |
| 钥匙 | 大人的 | 孩子被允许开 | 孩子自己有一串 | 有人进不来 |
| 听筒 | 报平安 | 吃了没 | 敷衍 | 不接 / 屏幕代替 |
| 纸 | 在场证明 | 缺席证明 | 没人看 | 抽屉最下层 |
| 红包 | 给孩子 | 被代收 | 孩子不要 | 钱的名分已换主人 |
| 鞋 | 门口有谁 | 先看鞋再喊 | 孩子的鞋自己摆 | 少一双 |
| 凳 | 门外等人 | 岗位 | 空转 | 还在原点搬出 |
| 灯 | 家里亮 | 等谁 | 门缝光 | 留一盏或不留 |
| 车 / 铃 | 接 | 心不在后座 | 铃还响 | 不再坐 |
| 校服 | 被叠好 | 自己找 | 嫌被人管 | 不再穿 |
| 存折 / 信封 | 秘密 | 上桌 | 变薄 | 数字赢了人 |
| 成绩单 | 被展示 | 被收走 | 孩子先藏 | 不再交 |

开篇不要把末次意思写出来。

## 身体与肖像按年龄换代

| 阶段 | 孩子 | 管日常的老人 | 走班的父母 |
|---|---|---|---|
| 婴幼 | 被转的身体、奶味、软的后脑 | 手臂的稳、围裙 | 抱得不会、香水或烟压过奶味 |
| 幼儿园 | 被拉的领、小手绢、鼻涕 | 蹲下的膝、铁门边的肩 | 高跟鞋或工装对不上园门口的泥 |
| 小学低 | 换牙、红领巾斜、鞋小 | 手开始被嫌热 | 签字的笔迹、开会的衬衫 |
| 小学高 | 不肯当众喂、钥匙凉 | 要仰头看孙子 | 眼熬薄、进门先换衣 |
| 少年 | 门缝里的耳朵、变声 | 背更直或更弯，看还要不要被需要 | 包更沉或更空，鞋仍晚 |

同一个人十年里至少改 3 次肖像入口，不能十年都写同一道皱纹。

## 关系对白总库（表面 / 底下）

写对话先选关系，再选一句。风格卡决定软、硬、平、还是不说。

**老人 → 孩子**：吃、再来一口、穿够不够、作业拿来、听话、别跟妈妈说我惯你、快、奶奶（爷爷）在。  
底下：我还没用废；你是我的重考；跟我才算亲。

**孩子 → 老人**：要、不要、我吃过了、我自己来、你别去门口了、没事。  
底下：热、烦、安全、停催。

**母亲 / 主付出者 → 孩子**：都是为了你、我小时候没有、别告诉他、妈妈好不好、第几、班报了、礼物。  
底下：看见我；别说我不管。

**孩子 → 母亲**：还行、我知道你忙、不用回来、挺好的、老师没说。  
底下：少欠；两边都不哭。

**父亲 / 付钱者 → 家里**：我马上、这个月先这样、路上、你先吃、假批不下来。  
底下：我在撑；别验我的在场。

**夫妻之间**：你请、我请不下来、钱你收、别让老人看笑话、孩子跟谁。  
底下：三项里缺的那一样推给对方。

**婆媳 / 两代女人**：粥点、校服、谁的锅、谁的纸、谁的门口。  
底下：日常权 vs 证明权。

**亲戚 → 家**：真胖、真听话、真舍得、像谁、第几、红包我先给。  
底下：公开比较，逼站队。

**邻居 / 同事 / 家长**：又等啊、又加班、报了什么班、今天谁接。  
底下：把私事变成楼道新闻。

长篇里同一关系的口头禅要有衰减：前半本说全，后半本只剩半句或一个动作。

## 外圈多场轮换

外圈功能不变：比较、随礼、问第几、催班、让路。人必须换。

建议工种池（单场最多一个外圈焦点）：

楼里姐妹、门卫、摊贩、同楼小孩家长、班主任、科任、同学、同学妈、同事、搭班、舅/姨偶尔一个、席面上的远亲、校门口冰柜、保安、护士、银行柜台、中介（偶用）、居委会（偶用）。

规则：

- 连续三章不要同一张外圈脸
- 同一个人全书最多 4–6 次，且口头禅要变短
- 外圈走后，座位、门口、纸、钟四样里必须动一样
- 禁止给外圈开十年弧光

## 声、味、光 · 四季（必须推动行动）

**春**：潮墙、霉、柳絮进门缝、换季衣服谁叠——出门慢，假更难请。  
**夏**：油烟更重、楼道馊、铁门烫、蝉、汗把纸洇——等人的凳要垫布，饭容易馊，脾气在灶边。  
**秋**：校服新、梧桐叶进楼道、月饼盒——开学的钟和单位的钟一起紧。  
**冬**：铁门风、哈气、手套、药味、早黑——灯开得早，门关得早，谁接变成资格赛。

雨：接送变成资格赛。雪：路和班更对不上。阴：灯早开。大晴：阳台成为面子。

一季在书里要反复，但每场只选一个感官推动一个行动。

## 四种场面类型（长篇要轮着来）

1. **群像**：席面、家长会、饭桌加人。写秩序图，不写热闹。  
2. **两人**：门口、灶边、听筒。写谁先动。  
3. **单人**：空屋、独自回家、等人。写物件位置和钟。  
4. **两头**：听筒、短信、门里门外。写压缩后的爱。

连续三章不要都是群像，也不要都是单人。

## 防重复七问（每场写完必过）

1. 主物件是第几次出现？和上次比，意思挪了哪一寸？
2. 主动作和上两章是否同一个（又先端、又说没事）？能变奏就变奏。
3. 外圈是不是上一张脸？
4. 肖像入口换了没有？（手 / 鞋 / 领 / 包）
5. 有没有新开第三个场？有则删。
6. 有没有超配额的心理或风景？
7. 这一场若抽掉，人物状态或十年变意表里会不会少一格？少一格才该留。

## 长篇提示（跨风格）

请先根据【年段/节令/生命事件】从长篇描写总谱选定主场、主物件第几次和社会压力载体，再按 style_key=【风格】写【大章 X / 场 Y】。遵守单场配额，过防重复七问。不要把风格卡里的场面配方当作固定章节清单。
