# 市民日常描写调用卡

不喊命运，写日程。人物的命运藏在重复路线里：几点起锅、几点接人、衣服晾哪一排、谁先占厨房。

通用：任何城市家庭、单位楼、老小区、县城街巷、双职工+老人带孙、女性管时间的小说都可套。路线、钟点、摊位名用【占位】替换，不绑定某一座城、某一组人。

先读本卡。冲突必须来自钟点撞车，不来自演讲。

## 和相邻风格的差别

| 别混成 | 差别 |
|---|---|
| 家庭现实主义 | 这里发动机是路线和钟，不是单个道德小选择 |
| 劳动社会 | 这里写城市肌理和家里的钟；班是撞上车的另一条线，不是全书压力系统 |
| 克制留白 | 这里手很忙，但忙是为了走完日程，不是为了把话说掉 |

## 写之前锁定（八问）

1. 本日程是谁的骨头？（默认管时间、食物、面子、等待的那个人）
2. 主路线走哪两到三站？不要全城跑。
3. 几点到几点？哪一站必须准点？
4. 另一条城市时间（单位、超市、晚归、培训班）在哪一站错过？
5. 主物件是锅、杯、袋、凳、绳、校服里的哪件？
6. 外圈在哪一站碰到：摊位、铁门、石凳、门卫、校门口？
7. 哪一截断了？谁因此丢了家里的节奏权？
8. 孩子还跟谁的路线，还是改走房间和屏幕？

## 默认路线与站点

床 → 灶 → 楼道 → 菜场 → 铁门 → 校门口 / 单位 → 阳台 → 联播 → 饭桌。

一场只走两到三站。每站写时刻、物件、谁的脚先到。

| 站点 | 钟 | 看什么 |
|---|---|---|
| 床 / 帘后 | 五点半到六点 | 谁先醒，谁把家从夜里打开 |
| 灶 / 厨房 | 六点到七点 | 谁占灶，粥点能不能改 |
| 菜场 | 七点到八点 | 讨价、听闲话、谁家媳妇请不出假 |
| 铁门 / 石凳 | 放学点前后 | 凳挪近多少，谁准点 |
| 校门口 | 放学铃 | 两条路线撞上：老人的钟对父母的班 |
| 阳台 | 午前或晚饭后 | 哪一排衣服最外面，谁的能过夜 |
| 联播饭桌 | 晚上 | 音量是谁的规矩，孩子坐不坐 |

可替换成县城早市、单位食堂、地铁口、培训班楼下、城中村巷口，逻辑不变：重复路线=权力。

## 人物描写全谱

### 肖像

人是被路线塑造的。

**词库**：菜篮勒手的红印、灶边油点子、围裙洗薄的边、塑料拖鞋、头巾、表、等人时端着的肩、晾衣时仰起的脖子、包带勒痕、风吹干的额发。

**按人**：

- 管日程的人：手和脚比脸重要；身上有灶、篮、绳的痕迹。
- 走另一条城市时间的人：包、工牌、超市袋、高跟鞋或 commuter 鞋，和家里的拖鞋对不上。
- 孩子：书包拉链、校服领，看他跟谁的路线出门。
- 摊位 / 石凳上的人：比较时的下巴、看别人篮里的眼。

### 动作

少写心，多写手脚。重复本身就是权力。

**动词**：起锅、舀粥、讨价、过秤、把最外面一排衣服翻进去、把凳挪近半寸、隔门听脚步、占灶、让灶、拧干、算账、改道、关门看电视。

**句式**：

- 每天【时间】，她都先去【地点】，再把【物件】放到【位置】。
- 家里的规矩不是说出来的，是被【人物】一趟一趟走出来的。
- 那条路他走了很多年，后来不走了，家里才像少了一根线。

### 语言

谈价、问点、催人、比孙子。少抒情。

**口头禅库**：

- 几点了 / 锅开了 / 粥稠了 / 还没回来
- 今儿贵 / 少一两 / 自家吃的
- 又等啊 / 快了 / 你家也这个点
- 联播到了 / 先洗手 / 别占着灶
- 校服换了没 / 袋装好

外圈常句：谁家孙子胖、谁家媳妇晚、谁家阳台最齐、谁家孩子不跟老人走了。

### 心理

不总结命运。写她怕的不是累，是闲下来像被退掉；写他改道以后，旧钟还在响。

### 神态

看表、听楼道、用新闻声判断谁回来了、隔着门把脚步听成「是」或「不是」。

## 环境描写全谱

**自然**：必须改行动。雨天菜场泥、夏天楼道馊、冬天铁门边的凳要垫布、傍晚路灯决定再等不等。  
**社会**：摊位规矩、门卫眼色、校门口不能停车的线、联播音量、居委会通知贴在哪——只写碰到脚的那一条。  
**声味光**：新闻、锅盖、讨价、车铃、油烟、肥皂、潮墙、灶火、屏幕。

**禁**：抽象城市、政策段、怀旧风景明信片。

## 细节全谱

搪瓷杯、塑料袋、盆、毛巾、小板凳、晾衣绳、粥锅、校服、菜篮、肥皂头、旧闹钟、门后挂钩、电视遥控器。

物件必须有人伺候过：谁洗的杯、谁装的袋、谁不许动的凳。孩子改走房间后，旧物件还在原位，这就是丢权。不要开零食清单。

## 通用人物类型

**管时间的女人（不限奶奶/母亲）**：日程是骨头。怕闲，不怕累。权力来自重复。  
**走班点的人**：改得了超市和单位，改不了粥点。两条线在门口错过。  
**孩子**：先跟着家里的钟走，后来改走房间、屏幕、同学的点。他一改走，旧班还在，岗位空了。  
**另一根晾衣竿 / 另一门亲戚**：衣服晾最外、夜留在另一家，把路线扯弯。  
**摊位、石凳、门卫、同楼姐妹**：校准她的钟，也公开她的等待。

女人不是符号，是时间、食物、钱、面子、等待的管理人。

## 场面配方

1. **起锅**：谁先占灶，谁的粥点不能改。
2. **过秤**：一两里的面子，闲话里的媳妇。
3. **铁门等人**：凳挪近半寸，楼上问「又等啊」。
4. **两条线错过**：老人准点，父母的鞋往另一个门口。
5. **阳台翻衣**：最外面一排是给谁看的。
6. **联播音量**：规矩在遥控器上，孩子不坐旁边，钟空转。
7. **占灶冲突**：下班的人和起锅的人抢同一口灶。
8. **校服早上**：谁叠、谁找、谁迟到，一天的权从领口开始。
9. **袋的路线**：菜场袋进门，超市袋晚到，两种城市场在桌上打架。
10. **石凳比较**：一句「不跟你走了吧」，岗位被当众空出来。
11. **雨天接人**：伞和钟比脾气先乱。
12. **周末改点**：家里的钟乱一天，比工作日更能看见谁真的校准全家。
13. **搬凳回楼**：人接到了，凳还在门外，像班还没下班。
14. **屏幕改道**：孩子关门，锅还准点，听的人换了地方。
15. **节日多出一站**：上坟、逛庙会、单位发油，路线被加长，权仍看谁走完。

## 句式库

1. 每天【时间】，她都先去【地点】，再把【物件】放到【位置】。
2. 家里的规矩不是说出来的，是被【人物】一趟一趟走出来的。
3. 那条路他走了很多年，后来不走了，家里才像少了一根线。
4. 【钟点】撞上【另一条路线】时，先乱的不是心情，是【锅/门/凳】。
5. 她的一天还在，只是听钟的人换了地方。
6. 楼上问「又等啊」，她说「快了」，其实那双鞋不是往这个门口来。
7. 粥点改不了，假条改得了超市，改不了灶。
8. 最外面那排衣服过夜，像把面子晾给全楼看。
9. 遥控器在谁手里，晚饭就按谁的点开始。
10. 菜篮放在门后，等于明天的班已经排好。
11. 他改走房间以后，铁门边的凳还是那个点搬出去。
12. 雨把放学铃拉长，两条路线在伞下仍对不齐。
13. 搪瓷杯每天洗，洗的人在，喝的人换了。
14. 石凳上的人比她自己更早知道她的钟空了。
15. 城市很大，可她的城只有这三站。
16. 新闻声开到某格，楼道脚步才肯变成「回来了」。
17. 塑料袋洗过晾在椅背，像一份没有公章的考勤。
18. 孩子不跟了，锅还准点，这算胜利还是退场，她不问。
19. 另一条晾衣绳伸过来，她家的阳台就窄了一截。
20. 周末的点一乱，才看见平时是谁在把日子走直。

## 开场与收束

**开场**：时刻 + 第一站 + 一件被放回原位的物。  
**收束**：某一截不再被走、凳还在、钟还响、听的人换地方。不要「时代变了」。

## 混搭

主冲突必须是撞钟和路线断裂。副用家庭现实主义的小选择、劳动社会的班和路、克制留白的手。不要写成政策史，也不要写成命运宣言。

## 改写对照

差：改革开放以来，这座城市发生了翻天覆地的变化，女人默默付出。  
好：六点她把锅坐上。楼道里还没有第二双拖鞋。七点二十凳子再挪近半寸。

差：她突然感到自己被这个家抛弃了。  
好：孩子不坐在联播旁边了。她还是把音量开到那一格。汤匙碰碗的声音变得很清。

## 长篇层 · 这风格怎么撑三十万字

先读 `长篇-描写总谱.md`。市民日常的长篇发动机是「同一条路线走十年，哪一截先空」。不要每年开学都写成同一场铁门。

### 十年五段 · 路线怎么换代

| 年段 | 主路线 | 孩子在哪一站 | 空掉的先兆 |
|---|---|---|---|
| 婴幼 | 床→灶→晒被→门 | 被抱着走完 | 另一条班线在门口错过 |
| 幼儿园 | 灶→园门→铁门凳 | 跟管钟的人 | 放学铃对不上假条 |
| 小学低 | 灶→校门→联播桌 | 还坐在钟旁边 | 有时被另一袋超市袋带走 |
| 小学高 | 自己走一段 | 开始抄近路 | 联播旁边的座位空 |
| 少年 | 房间/屏幕 | 不跟三站 | 旧钟空转，锅还准点 |

### 节令 = 加站或改点

春节多一站（买、祭、席）；开学改接人点；暑假路线拉长或回老家；梅雨让晾衣权变成面子；冬至多一碗，点仍不能乱。节日不是主题，是日程被加长。

22. 管道煤气 / 换灶：粥点短暂大乱  
23. 周末早市 vs 工作日摊  
24. 培训班楼下新增一站  
25. 孩子自己坐车 / 自己走  
26. 联播改频道或关掉  
27. 阳台封窗：晾衣绳的面子消失

### 关系对白

管钟的人：几点了、锅开了、还没回来、先洗手、别占灶。  
走班的人：我晚一点、袋在门口、你们先吃。  
孩子：我不去了、我自己回来、联播关一会儿。  
石凳 / 摊位：又等啊、你家也这个点、不跟你走了吧。

后半本：问句缩短成看表、听脚步、把音量开到旧的一格。

### 多场路线变奏

不要多场都写铁门等人。链：立钟 → 两条线并行 → 雨天撞钟 → 孩子抄近路 → 少跟一站 → 联播座位空 → 旧钟空转 → 节日加站仍空 → 听钟的人换房间。  
同一站点（菜场）变奏：讨价 → 听闲话 → 摊主换人 → 孩子不跟 → 篮还在门后。
