# 克制留白描写调用卡

少解释，多看手。情感在修、盛、洗、绑、放、抹里，不在嘴上。读的时候轻，放下才重。

通用：任何少言亲情、手艺人、老人、父亲、修车、做饭、睡前盖被的小说都可套。主手和主物件用【占位】。故意不说的那一句只写在构思里，不写进对话。

## 和相邻风格的差别

| 别混成 | 差别 |
|---|---|
| 市民日常 | 这里手不是为了走完日程，是为了把不说的话做完 |
| 家庭现实主义 | 这里不解释小选择的道德，只让物件换意思 |
| 温柔成长 | 这里靠近也只能用手，不能问出口的抒情 |

## 写之前锁定（八问）

1. 主手是谁的？
2. 主物件是碗、车、灯、刀、棉垫、门、工具里的哪件？
3. 主情绪对应哪个手部动作？
4. 故意不说的那一句是什么？（禁止出现在对话）
5. 这场每人最多几句话？（默认不超过三句）
6. 外圈只留哪一个动作？
7. 停顿写在哪：半空的手、拧到一半的布、按下去又松开的铃？
8. 章末物件哪一点朝向、位置、用法变了？

## 人物描写全谱

### 肖像

从手进入身体。脸可以模糊，手必须清楚。

**词库**：指节、茧、湿袖口、油点子、擦不干的水、抖、停在半空、指甲缝、烫伤旧印、拧布的筋。

### 动作（主手法）

每种主情绪落到手上。

| 情绪 / 关系 | 手 |
|---|---|
| 接 | 绑棉垫、按铃、送到楼下 |
| 给位置 | 碗放正、筷子摆齐、把凳拉开 |
| 有话 | 洗碗很响、抹布多拧一遍 |
| 疼但不说 | 半夜盖被、把灯留一条缝 |
| 界限 | 把门带上，灯还漏 |
| 退出 | 茶不喝、送到就走、工具收进箱 |
| 准备前程 | 削铅笔、把车铃调响 |

**动词**：修、递、放、洗、绑、抹、削、摆正、拧、盖、收、按、松开、停。

停也是动作：手在半空、抹布拧到一半、铃按下去又松开。

### 语言

能删就删。留下的像工具一样短。

**准许的短句**：吃、行、到了、不喝、自己来、好了、热、慢点、坐。

**故意不说的库存**（只存在构思里）：

- 我其实很爱你
- 我怕没用了
- 我想你问我一声
- 我已经不等了
- 你把碗端走也可以
- 我送到这里就够了

这些话如果写进对话，这场就浅了。

### 心理

几乎不写内心词。用重复劳动和没说出口的那一句代替分析。悲伤轻写在页上，沉在读完之后。

### 神态

不看镜头。低头、侧脸、看物件、手停在半空。

## 环境与细节

空间是干活的地方：灶边、洗碗池、车后座、灯缝、工具箱、车棚、门缝。不要田园明信片，不要空灵月光段。

**换意思示例**：

- 碗：喂 → 抢 → 孩子自己端走
- 车：接到 → 心不在后座 → 铃还响
- 门：进出 → 界限 → 仍留灯缝
- 刀 / 扳手：有用 → 没人来拿 → 仍擦干净收好

同一物件必须在章末还在，只是朝向、位置或主人变了。

## 通用人物类型

**少言的手艺人 / 老人 / 父亲**：爱的长度等于手的长度：送到楼下、碗放到面前、棉垫绑紧。  
**洗碗很响的人**：话在水声里。  
**折纸的手**：爱在档案里，不在体温里。  
**孩子的手**：后来学会另一只手——把门带上，或把碗自己端走。  
**外圈**：递工具、让座、站着看。不发表感慨。

## 场面配方

1. **绑棉垫 / 修车**：送到就走，茶不喝。
2. **放正饭碗**：不讲为什么，位置即态度。
3. **洗碗很响**：话在水声里。
4. **削铅笔**：给前程的手，不说前程。
5. **关门留灯**：界限出现，光还在。
6. **半夜盖被**：人醒着也不问。
7. **茶不喝**：进门的情分到此为止。
8. **工具借出又收回**：外圈只这一下。
9. **把凳拉开**：请坐，请完就去干活。
10. **擦车铃**：铃还响，人已经不坐后面。
11. **把药放杯盖上**：不说忌口，只放。
12. **雨里等**：伞递过去，自己湿着。
13. **孩子第一次自己端碗**：旧碗换主人，没人宣布。
14. **送行不到站台**：路的长度即爱的长度。
15. **物件朝向变了**：人走后，只剩这一寸变化。

## 句式库

1. 他没接话，只把【物件】重新【动作】了一遍。
2. 那只手停在半空，后来落到【物件】上。
3. 【人物】走后，【物件】还在原来的地方，只是朝向变了。
4. 话在喉咙里转了一下，最终变成【手上的动作】。
5. 灯还从门缝里漏出来，像一句没人接的话。
6. 水声停了，屋里才显出刚才有一句没接住。
7. 茶沏上，他不喝，帽子已经拿在手里。
8. 碗口朝里转了半寸，没人解释。
9. 送到楼下，铃响一声，人就拐进巷子。
10. 抹布拧到一半，停住，再拧干。
11. 他应了一个字：行。其余的在扳手里。
12. 棉垫绑紧，带子收进掌心，像把话也收进去。
13. 孩子把门带到还留一条缝的地方，手就松开了。
14. 铅笔尖削齐，灰吹掉，不说「好好念」。
15. 盖被的手很轻，床板却响了一下。
16. 工具箱扣上，今天能做的都做完了。
17. 她洗碗洗得很响，脸上不给。
18. 他看的是物件，不是人，可物件正对着那个人。
19. 沉默不是冷，是他们只会这一种给法。
20. 没人演讲。这家里已经爱过，也已经错过。

## 开场与收束

**开场**：一只手碰到物件。  
**收束**：物件用法或朝向微变，人不说破。禁止「他其实很爱」。

## 混搭

主场必须是手和省略。副可借市民日常的灶、家庭现实主义的门口、温柔成长的灯缝。不要借心理债务的长独白，不要借批判现实的审判句。

## 改写对照

差：他其实很爱这个家，只是不善于表达，眼里含着热泪。  
好：他没应。抹布拧了两下，把碗沿抹平。孩子走后，碗口朝里转了半寸。

差：夕阳西下，田园风光宁静美好，亲情如酒。  
好：车棚里油点子还在。铃按下去，又松开。

## 提示词模板

1. 请按克制留白写【人物】的情感，不说爱，只写手在修、递、放、洗、绑、抹中的变化。
2. 请围绕【物件】写一场安静的亲情戏，让物件在结尾改意思，人物不说破。
3. 请写短对话，台词每人不超过三句，其余通过手、工具和停顿完成。
4. 请先写下故意不说的那一句，再写这场戏；那句话禁止出现在对话里。
5. 请从手进入肖像，脸可以模糊。
6. 请让外圈只留一个动作：递工具、让座或站着看，禁止感慨。
7. 请写停顿：半空的手、拧到一半的布、按下去又松开的铃。
8. 禁止抒情解释、田园装饰腔、把沉默只写成冷酷。

## 长篇层 · 这风格怎么撑三十万字

先读 `长篇-描写总谱.md`。克制留白的长篇最怕「每场都洗碗」。要换手、换物、换那句不说出口的话，让同一双手十年只被看清三次。

### 十年五段 · 手怎么换代

| 年段 | 主手 | 主物 | 故意不说 |
|---|---|---|---|
| 婴幼 | 绑、摇、试奶温 | 棉垫、碗沿 | 我怕我不会 |
| 幼儿园 | 送到、等、擦泥 | 车铃、手绢 | 我送到这里就够 |
| 小学低 | 削、改作业格、放正 | 刀、碗 | 好好念（不说） |
| 小学高 | 留灯、盖被、修 | 灯缝、工具 | 我想你问我一声 |
| 少年 | 送到楼下、茶不喝、收箱 | 门、旧铃 | 我已经不等了 |

孩子的手后半本才进主场：端走碗、带上门、把灯留一条缝。

### 节令：手的加班日

年夜多一双洗碗的手；端午占灶的手；冬至搓汤圆的手；开学削铅笔的手。节令只加劳动，不加台词。

### 关系对白（极少）

准许：吃、行、到了、不喝、自己来、好了、热、慢点、坐。  
禁止补成：我其实很爱你、爷爷不容易、你要感恩。  
外圈：把凳让开，或把扳手递过去，不说话。

后半本可以整章零对话。

### 多场手的变奏

不要多场洗碗。链：试温 → 绑 → 送 → 削 → 修 → 盖 → 留灯 → 孩子自己端 → 送到楼下 → 箱扣上。  
同一物（碗）变奏：喂沿 → 放正 → 抢过手 → 孩子端走 → 朝向变。  
不说出口的话全书只换 3–4 句，不要每场换一句新格言。

### 长篇提示

## 禁用

「他其实很爱」、情绪演讲、田园装饰、把沉默写成冷酷、外圈抒情、对话里提前点破伤口、每人长段心理、每场都洗碗、每场都留灯。
