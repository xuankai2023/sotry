# 劳动社会现实描写调用卡

人物被班、钱、房子、路和面子拖着走。尊严和钱同样重要。工作不是背景，是谁能出现在家里的条件。

通用：双职工、夜班、工厂、文员、司机、服务员、进城务工、房贷、补课费、老人补位，都可套。点明【钱/班/人】哪一样付不出，缺口记在谁身上。

## 和相邻风格的差别

| 别混成 | 差别 |
|---|---|
| 市民日常 | 这里发动机是物质三项付不全，不是城市钟点美学 |
| 家庭现实主义 | 这里缺席首先是班和路造成的，不是单纯家里抢勺 |
| 批判现实 | 这里不审「为你好」，审的是谁也打不满的三项责任 |

## 写之前锁定（八问）

1. 钱、班、人，这一场缺哪一样？
2. 谁想三项都付清？（通常是父母里的一个或两个）
3. 尊严怕当众丢掉的是哪件：请不出假、红包薄、门口没人、工装来不及换？
4. 外圈谁看见了这份付不出：同事、搭班、门卫、问报班的家长？
5. 老人补的是日常，还是路，还是面子？
6. 孩子付的是等待、少问、还是把饿说成不饿？
7. 物质变化落到哪一项日子：菜单、口气、睡眠、路程？
8. 结尾有没有人成功到能抹掉这些年？如果有，删掉。

## 压力系统（通用）

单位要人。学校要家长。老人要日常不断。孩子要人在。钱要面子。这几样不能同时成立。没有人坏，是同时成立不了。

劳动怎么分（可改，但要写明）：老人做日常；父母做钱和班；孩子做配合。谁都觉得自己在扛。

## 人物描写全谱

### 肖像与服饰

工装、油点、起球毛衣、换下来的皮鞋、来不及卸的厂牌/工牌、洗白的袖、表带印、熬薄的脸。人要体面，所以进门先换衣服、先洗手、先把信封放平。不要脏乱展览。

**词库**：工装、油点、厂牌、衬衫领、换鞋、包里的打卡条、夜班的眼、雨里的车票、洗不掉的袖口。

### 动作

赶、数、塞、换、请、顶、转班、卡点、先放工装再开口。

| 动作 | 露出什么 |
|---|---|
| 数两遍再塞回 | 连这点也要算清楚 |
| 进门换鞋换衣 | 两个身份分开，怕把灰带进饭桌 |
| 请不出假 | 班赢了，人输了 |
| 夜路赶校门口 | 人在本市，仍晚 |
| 不当众数钱 | 尊严 |
| 孩子不打电话 | 学会的省：不问就不用听解释 |

### 语言

短，带数字和钟点。不要阶层宣言。

**口头禅库**：

- 我转一班 / 假批不下来 / 这个月先这样
- 你先吃 / 路上 / 我马上
- 补课先欠着 / 月供不能断
- 别让人看见 / 红包先薄着
- 加班 / 顶夜 / 卡点

外圈：又加班啊、报了什么班、假还没下来、门口又没人。

### 心理

不写抽象焦虑。写他怕当众丢的是哪一样。写孩子怎样把缺席合理化。

### 神态

进门先看桌上有没有人；说话前先把气喘匀；被问到假时笑一下；数钱时侧身。

## 环境描写全谱

家和班两头可以同时存在，主场仍只写一个房间或门口。

**场**：单位走廊、厂门口、打卡机、校门口、夜路、车站、饭桌、抽屉、换鞋处、医院挂号窗、中介或银行柜台（只写碰到数字的一下）。

**两口钟**：门口的钟和单位的钟对不上，就是这一场。

社会环境要具体到一张假、一笔月供、一趟赶不上的车，不写「底层人民的艰辛」。

## 细节全谱

请假条、工资袋、存折、车票、补课单、饭菜变少、信封变薄、工装油点、换下的鞋、夜灯、打卡条。

物质必须改日子：菜少一道、睡眠短一截、口气硬一点、路多一站。

## 通用人物类型

**文员 / 服务员 / 销售**：时间被假条和客户撕开，用花钱证明尽责。  
**厂 / 夜班 / 司机**：总在这座城，总晚到。能掏钱，不能掏钟点。  
**补位的老人**：退休金和第二份班补上父母付不出的「人」。补得越稳，父母越像账本。  
**孩子**：成长绑在谁加班、谁垫钱、谁准点上，不绑在天赋逆袭上。  
**搭班 / 同事 / 问报班的家长**：让付不出变得公开。

## 场面配方

1. **假条**：单位不放，学校要人。
2. **信封上桌**：数字公开，菜单和口气一起变。
3. **夜班对校门口**：钱在，钟不在。
4. **换鞋进门**：两个世界的交界。
5. **问报班**：私事变面子。
6. **月供日**：桌上先少菜，再少话。
7. **换班失败**：搭班也要养家，人情不够用。
8. **病假 vs 事假**：尊严看请哪一种。
9. **红包薄**：席面上被看见。
10. **夜路**：车票、路灯、还在路上。
11. **孩子不打电话**：等待被训练成懂事。
12. **老人垫钱**：补位越稳，父母越像数字。
13. **单位聚餐 vs 家长会**：同一晚只能出一个人。
14. **存折被翻**：面子在家里先破。
15. **成功没来**：年终奖薄一点，十年不被抹掉。

## 句式库

1. 他把【钱物】数了两遍，又塞回【地方】，像是连这点也要算清楚。
2. 那天他没说累，只是【饭菜/睡眠/语气】比昨天少了一点。
3. 【人物】从单位回来，把【信封/工装/鞋】放好，才开口说话，像是要先把自己摆正。
4. 不是不想回，是【班/路/钱】把他卡在【地点】。
5. 那张【请假条/收据】比他的解释先到家里。
6. 人在本市，仍晚。
7. 三项里他付了两样，缺的那一样记在孩子身上。
8. 门口有人笑「又这么晚」，他应「路上」。
9. 孩子没有打电话。这是省：不问，就不用听解释。
10. 工装叠到椅背，两个身份才肯说话。
11. 月供不能断的日子，汤先断。
12. 她能改超市，改不了打卡机。
13. 老人把人补上了，父母看起来就像只出钱。
14. 报班的问句一出口，补课费就从私事变成面子。
15. 假批不下来，家里把缺席过成了日常。
16. 他不当着人面数，侧过身，数完再笑。
17. 夜路把鞋底磨薄，也把口气磨硬。
18. 谁也不能被看见请不出假、红包薄、门口没人——三样里他已占两样。
19. 责任若用钱、时间、在场打分，谁打得满分？
20. 没有人成功到能把这些年一笔勾掉。

## 开场与收束

**开场**：工牌、车票、假条、换鞋处。  
**收束**：菜单/睡眠/口气变了一点；压力还在。禁止逆袭成功。

## 混搭

主冲突必须是物质三项里缺一样。副可借市民日常的路线、家庭现实主义的门口、心理债务的纸。不要借温柔成长把压力过成感恩，不要借励志把孩子写成天才。

## 改写对照

差：他们虽然穷，但很幸福，后来孩子争气考上名校改变命运。  
好：信封对齐，数了两遍。今晚那道菜没有。他先洗手，把工装叠好，才问作业。孩子没打电话。

差：他感到生活压力巨大，阶层像一座山。  
好：假批不下来。校门口的钟和他厂里的钟对不上。老人已经在铁门边把凳挪近了。

## 长篇层 · 这风格怎么撑三十万字

先读 `长篇-描写总谱.md`。劳动社会的长篇是十年里钱、班、人轮流缺，不是一场加班戏写几十遍。每场只压住一个主要缺口，记下缺口落在谁身上。

### 十年五段 · 三项怎么轮缺

| 年段 | 常见缺 | 落到谁 | 日子哪一项变 |
|---|---|---|---|
| 婴幼 | 人（假请不出） | 老人补位开始 | 奶粉钱 vs 在场 |
| 幼儿园 | 人 + 钟 | 铁门对班点 | 接送成为第二份班 |
| 小学低 | 钱冒头（兴趣班） | 信封开始上桌 | 菜单微变 |
| 小学高 | 钱 + 面子（补课、房） | 外圈问报班 | 睡眠和口气 |
| 少年 | 人已被合理化 | 孩子不问 | 三项习惯性付不全 |

### 节令 = 钱和假的高峰

春节红包薄不薄；开学交费；长假单位放不放；冬病假 vs 事假。节日先写假条和信封，不写团圆辞。

### 关系对白

劳动者：假批不下来、我转一班、这个月先这样、路上、你先吃。  
家里：今天谁去、钱你收、别让人看见。  
孩子：不问、说不饿、作业写了。  
外圈：又加班、报了什么、假还没下来、门口又没人。

后半本：解释更短，数字更具体，孩子的不问更熟练。

### 多场三项变奏

不要多场都晚归。链：假请不出 → 老人补位 → 兴趣班 → 月供 → 公开的薄 → 孩子不问 → 两项能付一项永远缺。  
同一物（信封）变奏：秘密 → 上桌 → 变薄 → 数字赢人。  
尊严怕丢的那件要轮换：假、红包、门口、工装，不要章章都是加班。
