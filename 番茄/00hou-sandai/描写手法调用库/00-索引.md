# 描写手法调用库索引

用途：先用本文件判断小说段落适合哪种风格，再只读取对应风格文件，减少 token 消耗。

## 使用建议

短场：索引 → 一张风格卡。  
长篇：索引 → `长篇-描写总谱.md` → 一张风格卡的「长篇层」。

风格卡前半是单场手册；后半长篇层有十年换代、场面 16–35、句式 21–40、关系对白衰减、多场变奏链。人名地名【占位】。

跨风格手法定义读 `基础-描写手法.md`。够不够写长篇，看总谱的配额、物件十年表和防重复七问，不要只靠每张卡前面那 15 个场面。

## 快速判断

- 想写三代家庭里长期积累的关系变形：用 `family_realism` → `01-家庭现实主义.md`
- 想写城市生活肌理、日程、菜市场、小区和厨房：用 `urban_daily` → `02-市民日常.md`
- 想写母爱、亏欠、补偿、情感算账：用 `psychological_debt` → `03-心理债务.md`
- 想写少说话、靠手和物件表达感情：用 `restrained_hands` → `04-克制留白.md`
- 想写钱、班、房贷、单位、阶层尊严：用 `labor_social` → `05-劳动社会.md`
- 想写“为你好”背后的权力结构：用 `critical_realism` → `06-批判现实.md`
- 想写越痛越平、生活本身荒唐：用 `cold_absurd` → `07-冷叙荒诞.md`
- 想写温暖但不强行原谅的成长：用 `warm_growth` → `08-温柔成长.md`
