# 家庭现实主义描写调用卡

写真实家庭，不写狗血家庭。关系变形来自长期小选择：谁先端碗、谁请不出假、谁站门口、谁说没事。

通用：任何三代同堂、两代分居、老人带孙、双职工家庭都可套。把【人物】【房间】【物件】【小选择】换成当前书里的人与物即可。不要绑定某一组人名。

先读本卡。需要跨风格的手法定义时再读 `基础-描写手法.md`。

## 和相邻风格的差别

| 别混成 | 差别 |
|---|---|
| 市民日常 | 这里力气在「谁先做了小选择」；日常路线是辅，不是主发动机 |
| 心理债务 | 这里人人有用也伤人；不把一场写成单边记账 |
| 批判现实 | 这里不审结构，只让选择自己堆出变形 |
| 温柔成长 | 这里不负责靠近和修补，只负责把回不去写清楚 |

## 写之前锁定（八问）

1. 主场是哪个普通房间，还是门口、听筒两头？
2. 一口钟：从哪顿饭 / 哪趟班 / 哪个放学点到哪个点？
3. 谁先做了哪个小选择？（先端、请不出、收下、留下、说没事）
4. 这个选择帮了谁，伤了谁？两边都要有。
5. 主物件是碗、纸、门、钱、钥匙、听筒里的哪一件？
6. 外圈谁说了一句比较或随礼？走后屋里哪一点变了？
7. 孩子（或弱位置的人）学会了哪个体上的办法？
8. 章末哪句关系或哪件物件回不到原样？

## 人物描写全谱

### 肖像

不写美丑鉴定。写被家里长期劳动、等待、让位磨出来的姿态。

**词库**：围裙边、洗薄袖口、站门口的鞋后跟、听电话歪着的肩、被拉直的衣领、加床上的印、门牙缝里的烟黄、手背的热、领口的扣、洗白的膝、塑料拖鞋磨出的声。

**按人**：

- 老人：手比脸先进入画面；站得住，是因为还要被需要。
- 母亲：包、纸、鞋跟；体面要撑给外圈看。
- 父亲：进门换没换衣服，决定他今天像家里人还是像路过的人。
- 孩子：衣领和鞋是否被别人的手整理过。
- 亲戚：进门目光先落在冰箱、孩子脸、还是墙上的奖状。

**句式**：

- 【人物】站在【位置】，先被看见的是【衣着/手/脚】，不是表情。
- 那件【衣服】被【人物】穿得很认真，像今天不能在别人家里丢脸。

**禁**：慈祥、刻薄、贤惠、狼心一套鉴定词。

### 动作

一个动作必须同时有用和有伤。

| 动作 | 有用 | 有伤 |
|---|---|---|
| 端碗 / 先端勺 | 喂饱、日常不断 | 占位、别人变成客人 |
| 收红包 / 收压岁钱 | 保管、怕孩子丢 | 收走资格 |
| 站门口 | 接到人 | 验收谁赢当天 |
| 请不出假 | 保住班和面子 | 家里只剩纸 |
| 把门带上 | 给孩子一个界 | 把还想问的人挡在外 |
| 说没事 | 让场面过下去 | 停催、停等、停被看见 |

**优先动词**：端、放、收、留、站、带上、塞回、抹平、先伸、后让、挂上、推回去、按住、松开。

**句式**：

- 他把【物件】往【方向】挪了一点，像是把话也挪开了。
- 这事没人说严重，可从那天以后，【人物】再也没有【动作】。
- 他不是不爱，是那天他先【小选择】了。

### 语言

短句、口头禅、没说完的半句。表面谈饭、假、钱、第几，底下是资格和位置。

**口头禅库**：

- 吃了没 / 穿够不够 / 作业写了没
- 没事 / 算了 / 差不多行了 / 别添乱
- 我忙 / 我马上 / 假请不下来
- 你还小 / 听话 / 以后就懂了
- 今天谁接 / 红包我先收着 / 别告诉他

**潜台词**：

- 「今天谁接」= 谁赢当天的在场权
- 「红包我先收着」= 钱的名分归谁
- 「你还小」= 你没有投票权
- 「没事」= 请把追问停在这里

**对话写法**：两人谈一件小事，第三句开始露出位置。外圈只准一句，这一句负责把选择钉死。

### 心理

少分析。写人物怎样说服自己「这样最省事」，再做一个回不去的小动作。

**路径**：不适 → 给自己一个理由 → 咽下期待 → 笑一下 / 说没事 / 把门带上。

**禁**：他感到被忽视、他缺少爱、原生家庭伤害。

### 神态

要能被误读。笑一下被当成懂事，低头看碗被当成害羞，装作没听见被当成乖。

**词库**：笑了一下、嘴角停住、眼皮垂下、装作没听见、低头看碗、脸色慢慢淡下去、先看鞋再喊人、眼睛在两个人之间过一趟。

## 环境描写全谱

### 室内主场（一场只守一个）

| 场 | 看什么 |
|---|---|
| 厨房 / 灶台 | 谁占灶、谁的勺先伸、谁被请去坐着 |
| 饭桌 | 谁坐哪、谁站着、谁的碗被添满、谁先放下筷子 |
| 门口 / 铁门 | 谁先到、谁的鞋在、谁把人领走 |
| 加床 / 帘后 | 谁没有自己的房间，谁把家当成班 |
| 听筒两头 | 爱被压成哪一句，两头人都不在一张桌上 |
| 亲戚席面 | 孩子先是证据还是人口；随礼和比较 |
| 楼道 | 邻居一句怎样把家里的事变公开 |

### 自然只作压力

湿冷让人在门口多等；闷热让饭桌上更烦；雨让接送变成资格赛；阴天让灯开得早，门关得早。不要单独写季节美。

### 社会只落一张纸、一笔礼、一句比较

假条、成绩单、压岁钱、随礼、晚托、门卫、排名。不写「改革开放以后」「房价时代」。

## 细节全谱

**必须能复现并改意思的物件**：碗、勺、纸（假条/收据/成绩）、门、钥匙、听筒、红包、压岁钱、鞋、加床、小板凳。

**改意思示例**（通用，换你家的物）：

- 同一只碗：喂 → 抢 → 孩子自己端走
- 同一扇门：家人进出 → 验收当天 → 孩子的界限
- 同一张纸：在场证明 → 缺席证明 → 没人再看
- 同一部电话：报平安 → 压缩成吃了没 → 孩子不再接

## 描写角度

**正面**：写手、写座位、写谁先动。  
**侧面**：邻居问「今天谁接的」、亲戚说「这孩子真听话」、老师问「家长来了没」。  
**场面**：不是热闹，是秩序图——谁坐、谁站、谁先说、谁沉默、外圈那句落在谁头上。

## 通用人物类型（套任何书）

**老人**：要被需要。日常不断是他的骨头。爱是喂和接，伤是孩子没有空隙。  
**母亲**：要证明自己不是坏的那个。爱是买、夹、催、纸，伤是用证明代替在场。  
**父亲**：要撑住。爱是钱和「我马上」，伤是总在本市却总晚到。  
**孩子**：要自己的零花、自己的门、不被问到答错。先配合，后撒谎，再关门。  
**娘家 / 婆家亲戚**：把「也有一份」拿出来，逼出抢。  
**邻居 / 同学家长 / 同事**：比较、随礼、问第几。走后屋里更难退。

每个人必须既有用又有伤害性。缺一边，重写。

## 场面配方（通用，可替换物件）

1. **饭桌先端**：谁的勺先动，谁就校准今晚的家。
2. **门口接人**：人接到了，心在不在，看孩子进门先看谁的鞋。
3. **收红包**：保管还是收资格，外圈一句「该家长管」。
4. **假条到桌**：人没到，纸先到；或纸也没有，只剩「我马上」。
5. **听筒报平安**：两头都问吃了没，没人问想不想回家。
6. **席面展示**：孩子被转一圈，先成为证据。
7. **晚托散场**：最后一个被领走的人，学会不站在最亮处。
8. **成绩单进抽屉**：谁有权先看、谁有权收走、谁被当众问第几。
9. **加床让位**：来客时谁睡哪，家的中心临时搬家。
10. **钥匙换手**：谁能开门，谁只能在楼下等。
11. **生病小事**：不是大病，是谁请得出假、谁熬夜、谁把药放在谁的杯盖上。
12. **过年分钱**：压岁钱的路线暴露家里真正的账房。
13. **亲戚留宿**：哪张床让出去，孩子听见自己可以被安排。
14. **门口比较胖瘦**：外圈一句，内圈今晚的勺就更勤或更空。
15. **说没事的那天**：场面过了，等待停了，关系翻过去了。

## 句式库

1. 他把【物件】往【方向】挪了一点，像是把话也挪开了。
2. 这事没人说严重，可从那天以后，【人物】再也没有【动作】。
3. 屋里最先变的不是声音，是【物件/位置】。
4. 【外圈】只说了一句【比较/随礼】，【内圈】的手就停住了。
5. 他不是不爱，是那天他先【小选择】了。
6. 【人物】进门先看【鞋/包/灯】，再决定喊不喊人。
7. 那张【纸】比【人物】的解释先到家里。
8. 碗还是那只碗，只是从这天起不再从【人物A】手里传到【人物B】手里。
9. 门开着的时候家是一家，门带上以后，有人就只剩听筒。
10. 他笑了一下，屋里的人把这笑收成懂事。
11. 谁先端，谁就有权说「再吃一口」。
12. 加床一收，来客看见的是体面，孩子看见的是自己可以被挪开。
13. 红包进了【谁】的口袋，孩子的年就换了主人。
14. 电话里的「吃了没」很轻，挂上以后屋里的椅子重了。
15. 他们都尽了力。可【人物】还是学会了【没事/关门/先看脸色】。
16. 站着听完，他才被允许坐下。
17. 钥匙在【人物】手里转了一圈，没交出去。
18. 别人家的孩子被拿来比的时候，这桌饭就不再只是饭。
19. 他请不出假，家里却把他的缺席过成了日常。
20. 这选择很小，小到第二天还能装没发生；可装不了第三年。

## 开场与收束

**开场**：物件位置、谁先进门、一句吃了没、门口的鞋。不要主题句。  
**收束**：同一物件用法变了、一句没事、门缝、第二天还有人站在原处。不要道歉大会。

## 和别的风格混搭

主风格必须是家庭现实主义：小选择造成关系变形。  
副风格只能改质感：市民日常借路线和钟点；克制留白借手和停顿；劳动社会借假条和路。  
不要把副风格的冲突逻辑（销账、为你好审判、生活继续的荒诞收束）整段搬进来。

## 改写对照

差：他觉得这个家不爱他，心里很难过。  
好：他进门先看鞋。鞋不在，他就把书包放低一点，再决定喊不喊。

差：一家人爆发了激烈争吵，亲情破裂。  
好：没人提高声音。门口那人只问「今天谁接的」，屋里的勺子停了一下。从那天起，有人不再先端。

差：奶奶很慈祥，母亲很自私，孩子是受害者。  
好：老人每天接到人，也每天把孩子的空隙填满；母亲的纸证明她来过，也证明她总不在；孩子被喂饱，也学会先看脸色。

## 提示词模板

1. 请按家庭现实主义写【场景】，从一个普通房间开始，用饭桌、门口、碗、纸或电话，让【人物关系】在小选择里变形。
2. 请写一段家庭场面，不制造狗血，只通过谁先端碗、谁站门口、谁说没事，表现【家庭权力变化】。
3. 请用动作和物件细节写【人物A】与【人物B】，不要解释感情，让读者从小动作里看出长期积累的伤。
4. 请写【人物】在【日常小事】里做一个回不去的小选择，外圈只需一句比较或随礼，把选择钉死。
5. 请正面写【房间】里的秩序：谁坐、谁站、谁先动；再侧面用【邻居/亲戚/同事】一句话把这秩序公开。
6. 请写【老人/母亲/父亲/孩子】同场，每人既有用又有伤害，禁止扁平三角。
7. 请让【碗/门/纸/红包】在场景前后改意思，人物不点破。
8. 请写听筒两头的一场：爱被压成【吃了没/我马上】，两头人都不在一张桌上。

## 长篇层 · 这风格怎么撑三十万字

先读 `长篇-描写总谱.md` 定年段、节令、物件第几次，再用下面的变奏，不要把前面 15 个场面写成全书仅有的 15 章。

### 十年五段 · 小选择怎么换代

| 年段 | 典型小选择 | 孩子还不会 / 开始会 | 回不去的一寸 |
|---|---|---|---|
| 婴幼 | 谁先抱、谁先端第一勺、席面把孩子转一圈 | 不会说话，是证据 | 他先成为证据，再成为人 |
| 幼儿园 | 跟谁走、叫谁、晚托谁接 | 开始看鞋 | 爱被发现有边 |
| 小学低 | 谁签字、红包谁收、成绩谁先看 | 会说还行 | 纸比人有权 |
| 小学高 | 谁有钥匙、谁被留下过夜 | 会先看脸色 | 听见自己可以被安排 |
| 少年 | 说没事、把门带上、不跟路线 | 会停催 | 人接到了，心不在门口 |

### 节令在这风格里看什么

春节看红包进谁口袋；开学看谁签字谁送；端午看谁占灶；中秋看谁用一盒饼代替回家；生日看孩子是被问过还是被展示。每年换手，不换主题演讲。

### 场面续编（16–35，与总谱生命事件对上）

16. 断奶 / 第一口饭：勺的主权第一次落地  
17. 入园第一周：门口的钟对上园铃，谁请得出假  
18. 第一次家长签字：笔在谁手里  
19. 换牙被当众评论：身体变成席面话题  
20. 近视：谁决定戴不戴，谁的面子  
21. 转学：外圈重置，旧碗旧门还在  
22. 搬家 / 加防盗门：座位重排  
23. 亲戚孩子来住：加床，自己被挪  
24. 普通发烧：谁陪夜，谁在班上用电话问  
25. 老人住院（非绝症高潮）：陪夜、钱、班三项露出  
26. 第一次独自在家：物件位置比人齐  
27. 第一串钥匙：开门权  
28. 停水停电：谁会找蜡烛、谁抱怨、谁把秩序维持住  
29. 暑假作业：监督权在谁  
30. 小升初 / 中考报名：孩子在不在场  
31. 婚宴做客回家：外圈比较带回屋里  
32. 换窗 / 漏水：谁出钱谁动手谁有资格骂  
33. 邻居装修：比较被激活，自家门口更紧  
34. 第一次说没事且停催  
35. 旧物第 N 次：碗还在，人不在这桌

### 句式续编（21–40）

21. 襁褓在【人物】手里转了一圈，席面上的人先看见证据，后看见孩子。  
22. 第一口饭进谁的勺，后来的饭桌就认谁。  
23. 园门口的泥只沾一种鞋，另一种鞋在单位。  
24. 签字的笔比到场的人先有权。  
25. 牙掉了，被说成「长大了」，长大的意思是更好管。  
26. 眼镜戴上那天，有人说体面，有人说没用好眼睛。  
27. 新学校的铃是新的，旧碗的缺口还在。  
28. 防盗门安上，家更安全，进出的资格更清楚。  
29. 加床一铺，他自己的夜就被卷起来。  
30. 烧退了。假条没有。电话里的「喝水了没」代替了人。  
31. 病房的陪护椅比家里的加床更说明谁有空。  
32. 钥匙凉，门却是热的——里面有人等他用对的那一种进法。  
33. 停水那天，谁先去找桶，谁就还在当这家的骨头。  
34. 作业本摊开的方向，就是今晚监督权的方向。  
35. 报名表填完，他才被允许看自己的名字。  
36. 喜酒带回的比较，比喜酒先上桌。  
37. 漏从角上开始，骂从资格开始。  
38. 邻居的电钻一响，自家的门关得更早。  
39. 没事两个字落地，追问就停了。这比吵更回不去。  
40. 碗洗干净挂着。桌还在。坐的人换了算法。

### 关系对白（这风格的短句）

老人→孩子：再来一口、跟我、作业拿来、红包奶奶收着。  
孩子→老人：要、不要、我自己来、你别去了。  
母→孩：签字我来、别告诉奶奶、妈妈周末带你。  
孩→母：还行、不用、我跟奶奶。  
父→家：我马上、假请不下来、钱在抽屉。  
两代女人：他跟我惯了 / 你们老请不出假。  
外圈：今天谁接、这孩子真听话、红包我先给。

后半本把整句收成半句或动作：老人只把碗推过去，孩子只看鞋。

### 多场使用同一手法怎么变奏

「先端」不要写三十次。变奏链：先端 → 故意后放 → 不伸 → 让孩子伸 → 孩子不伸 → 碗自己端走 → 桌上不再为这事停。  
「门口」变奏：等人 → 验收 → 先看鞋 → 不喊 → 门带上 → 门缝 → 鞋少一双。  
「没事」变奏：学舌 → 让场面过 → 停催 → 自己也信了 → 别人用他的没事安心。

一场只用链上的一环。
