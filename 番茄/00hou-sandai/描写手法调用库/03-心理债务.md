# 心理债务描写调用卡

不写爱伟大，写爱怎样变成债。最温柔的动作也可能是一根细绳：看见、听话、成绩、别让付出的人显得没管。

通用：母子、父子、婆孙、养育补偿、离婚后抢证明、隔代把孙当重考，都可套。记账的人不必是母亲。把【付出者】【孩子】【账本物件】换成当前书的人与物。

先读本卡。不要把付出者写成反派，也不要用一场道歉销账。

## 和相邻风格的差别

| 别混成 | 差别 |
|---|---|
| 家庭现实主义 | 这里主轴是一笔账，不是人人互伤的小选择网 |
| 批判现实 | 这里审的是爱里的索取，不审公共规矩本身 |
| 温柔成长 | 这里理解可以发生，原谅和销账都不发生 |

## 写之前锁定（八问）

1. 谁在记账？缺口是自己没被看见、没被好好养、还是怕被说成不管？
2. 这个温柔动作暗中要回来什么？
3. 账记在哪张纸、哪口菜、哪件礼物、哪句夸奖上？
4. 外圈谁让这笔记得更响（真舍得、第几名、这么懂事）？
5. 孩子用配合、撒谎还是「没事」来少欠一点？
6. 另一本账是否在抢同一个孩子？（老人的日常账 vs 父母的买办账）
7. 核心场面吵起来了吗？优先不吵。
8. 章末这笔记上了，不能装没发生——但账不许结清。

## 人物描写全谱

### 肖像

体面本身是防卫。头发齐、衣服对、纸叠正，都在证明「我有管」。不要妖艳或刻薄脸谱。

**词库**：叠得齐的纸、夹得准的菜、笑得刚好的嘴、包里分层的收据、礼物的包装比人先到、妆补过的眼、指甲修得很短。

### 动作

每个温柔动作问一句：要什么回来？

| 动作 | 表面上 | 暗中常要 |
|---|---|---|
| 夹鱼肚 / 好菜 | 疼你 | 谢、表情、承认我比别人好 |
| 折收据 / 假条 | 有管 | 看见我、别说我不管 |
| 送礼 / 报班 | 为以后 | 成绩、听话、别让我丢脸 |
| 道歉 | 我也不容易 | 立刻被原谅、停止追问 |
| 手举起又放下 | 我忍了 | 你看我克制，你更要乖 |

**动词**：折、夹、递、停、放下、叠、催、报、买、按住、松开、咽回去。

### 语言

短、软、沉。越像体贴，越要藏索取。

**债务句库**：

- 都是为了你 / 妈妈（爸爸/奶奶）小时候没有
- 别告诉你妈 / 别告诉他，省得又说我
- 你要争气 / 你看我多不容易
- 我这都是为了这个家 / 你要体谅
- 妈妈好不好 / 是不是最爱妈妈
- 我买都买了 / 票都开了 / 班都报了

**安全回答库**（孩子）：

- 没事 / 我知道你忙 / 还行
- 不用回来 / 我吃过了 / 我自己可以
- 挺好的 / 老师没说什么
- 别生气 / 我没要

最后一句常常不是顶嘴，是停催。

**潜台词**：

- 「我小时候没有」= 你要替我过一遍
- 「别告诉你妈」= 家里有两本账，你来保密
- 「没事我知道你忙」= 请停止用补偿打扰我

### 心理

禁止作者做心理咨询。只写计算。

**孩子的计算**：说哪句两边都不哭；少要一样就不会欠；期待降到零最安全；先配合，后撒谎，再沉默。聪明是账房的聪明。

**付出者的计算**：怎样证明自己不是坏的那个；怎样让纸和菜比人先到；怎样把缺口包装成爱。

**禁**：她其实很空虚、原生家庭伤害、他缺少安全感。

### 神态

冲突经常没有声音。

**词库**：笑意没到眼里、脸上空了一下、眼睛躲开、把话咽回去、笑得太快、手在包里按那张还没拿出来的单子、听懂事时先松后僵。

核心神态：孩子说「没事我知道你忙」，对方脸上的笑停住——这不是安慰。

## 环境与细节

家是账房。抽屉、碗、门口的等待、包的夹层。

**账本物件**：收据、假条、成绩单、礼物盒、红包、补课单、超市小票、单独那块好菜、包装袋、奖状复印件。

**证人句**（外圈）：真舍得、第几名、这么懂事、你们家管得真细、到底像谁。

旁人一句比内心独白更能把账钉死。

## 通用人物类型

**记账的养育者**：不是恶人。怕缺席，却总在缺席边上跑。把纸叠成证明。  
**孩子**：学会少欠、安全回答、让两边都不哭。  
**另一本账**：日常喂养的人用胖和听话收利息。  
**缺席的付钱者**：用钱和「我马上」平账面，人心上不平。  
**外圈**：账的证人，不是新债主线。

## 场面配方

1. **夹菜**：好的过去了，要回一个表情或一句谢。
2. **折纸**：收据进夹子最上层，像档案。
3. **报班问第几**：钱和名次互保，外圈一问就公开。
4. **迟到补偿**：礼物比人先到。
5. **懂事判词**：没事我知道你忙——催停了，账没结。
6. **两本账抢人**：买办和日常同时伸手，孩子选安全的那句。
7. **秘密句**：别告诉他，孩子成为账房的锁。
8. **道歉索取**：对不起说完，眼睛还在等「没关系」。
9. **过生日**：仪式越重，孩子越不敢伸手。
10. **成绩出来**：数字被翻译成爱有没有被浪费。
11. **生病小事**：陪伴用支出来比，谁陪谁花谁赢。
12. **电话里的软**：声音越软，要回来的在场证明越硬。
13. **当众认人**：叫谁、跟谁、像谁，名分即债务。
14. **退班 / 退货**：钱退了，账还在，因为「我都为你想过」。
15. **不再等**：孩子不站门口的那天，付出者才听见停催。

## 句式库

1. 她把【物件】给他时，像是同时递来一张不用签字的欠条。
2. 他先说【安全回答】，不是因为懂事，是因为这句话最不欠人。
3. 那一点好处被放得太郑重，反而让他不敢伸手。
4. 【外圈】只问了一句【第几/真舍得】，这笔记得比【物件】本身更清楚。
5. 他看懂了账，可看懂不是销账。
6. 纸对折两次，边对齐，像怕把数字弄皱。
7. 「还行」两个字最不欠人。
8. 礼物比人先到，人用纸证明自己来过。
9. 她不是恶，她只是把自己的缺口包装成了为你好。
10. 两边都哭的时候，他选让场面先停的那句。
11. 鱼肚过去了，谢如果慢半拍，桌上的气就会紧。
12. 别告诉他——家里从此有了第二本账，钥匙在孩子手里。
13. 道歉停在空中，等一句没关系来落地。
14. 他开始计算：少要一样，就能少欠一样。
15. 懂事被夸奖的时候，他正好把催停掉。
16. 夹子最上面那层永远是最新的证明。
17. 她怕被说不管，于是把管做成了可以出示的东西。
18. 孩子的聪明不在题目上，在怎样答才安全。
19. 两本账抢同一个孩子，孩子只好把自己分成两句好话。
20. 理解可以发生。原谅不必发生。账还在，人不结。

## 开场与收束

**开场**：一只手把纸折好，或一块好菜换碗。  
**收束**：安全回答落地；账钉上；人不和解。禁止清零。

## 混搭

主冲突必须是爱变成债。副可用克制留白的手、家庭现实主义的饭桌、批判现实的「为你好」（只作债务句，不上升结构审判）。不要写成审母大会。

## 改写对照

差：她是一个有原生家庭创伤的控制型母亲，孩子深受伤害。  
好：她把薄纸对折两次，塞进夹子最上层。孩子说「还行」。外面有人问「又报了啥」。

差：经过一次长谈，母子和解，误解消除。  
好：她说对不起。他点头。收据还在。第二天他仍先说「我知道你忙」。

## 提示词模板

1. 请按心理债务写【付出者】对【孩子】的爱，表面是照顾，底层藏着索取；用收据、食物、礼物或一句温柔话表现这笔账。
2. 请写【孩子】在【事件】后学会少欠一点，不喊受伤，只写他怎样计算、怎样回答才安全。
3. 请用神态和物件写一场没有吵起来的亲情冲突，让读者看见爱怎样变成债。
4. 请写一笔账：付出是【假条/鱼肚/报班/红包】，要回来的是【被看见/别输/一句好】，孩子用【乖/还行/没事】结账。
5. 请安排外圈说【真舍得/第几名/这么懂事】，把账钉死，但不要给外圈另开债线。
6. 请写两本账抢同一个孩子，孩子只选最安全的一句。
7. 请写「没事我知道你忙」被说出口的瞬间，对方听出这不是安慰。
8. 禁止审母、禁止标签、禁止道歉销账；理解可以有，账必须留下。

## 长篇层 · 这风格怎么撑三十万字

先读 `长篇-描写总谱.md`。心理债务的长篇不是一场母子对峙，是一本账翻十年：同一笔要回来的东西换载体。

### 十年五段 · 账本换代

| 年段 | 付出记在 | 要回来的 | 孩子结账法 |
|---|---|---|---|
| 婴幼 | 奶粉、金饰、满月酒 | 叫法、像谁、被看见管过 | 还不会结，被当凭证 |
| 幼儿园 | 园服、接送证明、零食 | 跟谁、叫得亲不亲 | 开始把好吃的归到谁名下 |
| 小学低 | 报兴趣、礼物、假条 | 成绩苗头、妈妈好不好 | 还行、配合 |
| 小学高 | 补课单、手机、面子宴 | 第几、保密（别告诉他） | 撒谎、少要 |
| 少年 | 更大的单、更软的道歉 | 别停催我、承认我尽过力 | 没事我知道你忙（停催） |

两本账可以并行十年：日常账要亲，买办账要证明。孩子越长大，越会选安全的那本应付。

### 节令是加账日

生日、春节、开学、家长会、中考年，都是加账。每年换载体：去年礼物，今年报班，后年一趟旅行。不要每年都用同一盒礼物。

### 场面续编（16–35）

16. 金饰 / 满月礼：物比人先成为证明  
17. 第一次「妈妈好不好」  
18. 两家抢叫法  
19. 园里比较谁接得多  
20. 兴趣班退费：钱退了，账不退  
21. 礼物拆开比人到场更郑重  
22. 成绩短信先发给谁  
23. 当众认人：像谁  
24. 保密游戏：别告诉他  
25. 补偿性旅游或大餐  
26. 孩子把礼物转送或收进柜底  
27. 道歉等「没关系」  
28. 孩子开始少要  
29. 孩子把两边的话写成两套  
30. 付出者发现纸没有人看  
31. 停催的第一句没事  
32. 另一本账（老人）用胖和听话收息  
33. 缺席者用钱平账面  
34. 外圈「真舍得」把新账钉死  
35. 理解发生，账仍不结

### 句式续编（21–40）

21. 金饰比手温先证明有人管过。  
22. 「妈妈好不好」不是问句，是收款。  
23. 叫错一个音，席面上的账就响一下。  
24. 谁接得多，园门口的闲话就替谁记账。  
25. 退费单很干净，话里的「我都为你想过」洗不掉。  
26. 包装比人郑重，人就成了附件。  
27. 短信先到谁的手机，数字就先属于谁。  
28. 像谁——这是当众开的一张新欠条。  
29. 别告诉他。孩子的嘴成了锁。  
30. 大餐的骨头里有一行未写的：你看我补了。  
31. 礼物进柜底，比退回去更安全。  
32. 对不起停在空中，等没关系落地。没关系没来，账就多一日息。  
33. 他少要一样，屋里的催就少一样。  
34. 同一件事他有两套说法，两套都不欠人。  
35. 夹子最上层积灰，证明开始没人查。  
36. 没事我知道你忙——催停了，账进长期。  
37. 胖和听话是日常账的利息，收得比纸还稳。  
38. 钱一到，账面平了，门口的鞋仍不在。  
39. 「真舍得」三个字，比收据盖章还快。  
40. 他看懂了。他没有销。谁也不许替他销。

### 关系对白

付出者：都是为了你、我小时候没有、别告诉他、班都报了、妈妈好不好、对不起（等回）。  
孩子：还行、我知道你忙、不用、挺好的、我没要。  
另一本账：跟我亲、是我带大的、她那是花钱。  
外圈：真舍得、第几名、这么懂事、到底像谁。

后半本：付出者的句子更软更短，孩子的回答更标准，直到标准本身变成拒绝。

### 多场关系账变奏

不要多场都夹鱼肚。链：买 → 夹 → 折纸 → 问第几 → 保密 → 道歉索取 → 孩子少要 → 礼物进柜底 → 停催 → 理解不销账。  
同一载体（纸）变奏：假条 → 收据 → 成绩 → 没人看的旧夹。

## 禁用

审母/审父脸谱、原生家庭标签、一场痛哭清零、大段人格分析、外圈变第二条主债、把孩子写成控诉者、十年同一盒礼物、节日变成感恩晚会。
