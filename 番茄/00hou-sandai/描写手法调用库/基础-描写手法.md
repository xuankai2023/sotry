# 描写手法基础卡

跨风格共用。先在这里选定写人、写环境、写细节还是写角度，再回对应风格卡取词库、句式和禁区。本文件不代替风格卡，也不和八套风格整包同读。

人名、地名一律用【占位】替换。适用于任何中国家庭、单位楼、县城、小区、出租屋，不绑定某一本书。

    "环境描写必须推动情绪、秩序或冲突，不写无用景物。",
    "细节描写必须典型、可重复、能改变读者对人物或关系的理解。",
    "一场只守一个主场、一口钟、一次关系微变。",
    "外圈必须是活人：一句比较、一次随礼、一次让路，走后屋里要变一点。"

## 怎么调用

1. 定本场主描写：人物 / 环境 / 细节 / 角度，只主攻一种，其余作辅。
2. 定人物类型：老人、母亲、父亲、孩子、亲戚、邻居、同事、同学、老师。
3. 定空间：厨房、饭桌、门口、楼道、阳台、菜场、校门口、单位、席面、听筒两头、医院走廊、出租屋。
4. 回风格卡，取该风格的词库、句式、场面配方。
5. 写完检查：有没有堆形容词、有没有空景物、物件会不会在后文改意思。

## 人物描写

### 肖像描写

**功能**：容貌、衣着、姿态、声音露出处境和性格，不是美丑鉴定。  
**格式**：外部特征 + 被生活压力磨出的痕迹 + 暗示关系位置。

**看哪里**：衣角、袖口、领口、鞋跟、鞋带、头发、鬓角、脸色、眼神、背影、嗓音、手背、指节、皱纹、围裙、旧外套、校服、工装、厂牌、塑料拖鞋、表带印、洗白的膝。

**按人怎么看**：

| 类型 | 优先看 |
|---|---|
| 老人 | 围裙边、洗薄的袖、站门口的脚、手上的热、背微驼却站得直 |
| 母亲 | 包里的纸、鞋跟的高度、妆淡不淡、笑是否到眼 |
| 父亲 | 工装/衬衫换没换、烟味、进门先放哪只包 |
| 孩子 | 被拉直的衣领、不合脚的鞋、书包拉链、被按过的头发 |
| 亲戚邻居 | 进门先看哪里、手里的袋、比较时的下巴 |

**句式**：

- 【人物】的【衣着/手/背影】先说明他过的是哪种日子，再让他开口。
- 那件【衣服】不新，可被【人物】穿得像不能出错。

**禁**：一出场用漂亮/丑陋/慈祥/刻薄给道德打分。

**提示**：请用肖像描写刻画【人物】，不要写成漂亮或丑陋的静态介绍，而要通过【衣着/姿态/声音】看出他被【生活压力】改变的痕迹。

### 动作描写

**功能**：做什么、怎么做，露出性格、关系和权力。  
**格式**：具体动作 + 力度/迟疑/重复 + 他人反应 + 关系微变。

**通用动词**：端起、放下、塞回、抹平、攥住、避开、推开、递过去、停了一下、又重复一遍、没抬头、把门带上、把碗放正、先伸、后收、站着、坐下、让开、关上、虚掩、数一遍、对折、擦干。

**力度等级**：先做 / 重做 / 停住 / 假装没看见 / 做完就走。同一动作换力度，关系就换了。

**句式**：

- 他【动作】的时候没看人，可屋里的【物件】先响了。
- 那一下不重，可从这天起【人物】不再【动作】。

**禁**：用摔碗、砸门、扇耳光当唯一冲突；动作用来炫技而不改关系。

**提示**：请用动作描写表现【人物】对【冲突】的态度，少解释心理，让动作的迟疑、重复或力度暴露他真正的想法。

### 语言描写

**功能**：对话和半句独白露出身份、情绪、隐藏诉求。  
**格式**：短句 + 日常口头语 + 没说出口的意思 + 对方的沉默。

**通用口头禅**：吃了没、没事、听话、别添乱、都是为你好、以后就懂了、你还小、我忙、算了、别告诉他、差不多行了、我马上、还行、先这样、都是这样。

**潜台词对照**：

| 嘴里 | 底下常是 |
|---|---|
| 吃了没 | 我只能管到这一层 |
| 没事 | 别再追问 / 我已停催 |
| 听话 | 按我的秩序来 |
| 我忙 | 我不能同时在场 |
| 你还小 | 你没有资格决定 |
| 算了 | 这事记下了，不当面撕 |
| 别告诉他 | 家里有两本账 |

**禁**：把道理说穿；用演讲收场；每人长篇内心独白冒充对话。

**提示**：请写一段【人物A】和【人物B】的对话，表面谈【日常小事】，实际透露【隐藏矛盾】，台词要短，避免把道理说穿。

### 心理描写

**功能**：当下感受、自我解释、不敢承认的念头、随后的行动选择。  
**格式**：感受 → 自我说服 → 压下的期待 → 选一个最省事的动作。

**通用入口**：他忽然明白、他不敢问、他先笑了一下、他把话咽回去、他觉得自己欠了什么、他开始计算、他不再等、他知道这样最省事。

**禁**：直接喊痛、贴「原生家庭」「被忽视」标签、作者替人物做心理咨询。

**提示**：请写【人物】在【事件】后的心理描写，不要直接喊痛，要写他怎样说服自己、压下期待，并形成新的自我保护方式。

### 神态描写

**功能**：微表情和即时反应，突出当下情绪，常被误读。  
**格式**：微表情 + 停顿 + 掩饰动作 + 他人误读。

**词库**：笑了一下、嘴角停住、眼皮垂下、脸僵了、眼睛亮了一瞬、皱眉、抿嘴、装作没听见、低头看碗、脸色慢慢淡下去、笑意没到眼里、脸上空了一下、眼睛躲开、眉头松得太快。

**提示**：请用神态描写写【人物】听到【一句话】后的反应，只写表情、停顿和掩饰动作，让读者自己判断他的情绪。

## 环境描写

### 自然环境

**格式**：时间/天气 + 空间感受 + 人物行动受影响 + 情绪暗示。  
**词库**：傍晚、清晨、湿冷、闷热、雨停以后、楼道风、窗外光、蝉声、雪水、雾气、阴天、路灯、灰尘、潮的墙、晒透的被。  
**原则**：天气必须改变出门快慢、等人长短、饭菜凉热、门开不开，不单独写景。

### 社会环境

**格式**：一个制度/习俗/人情 + 对家庭日常的影响 + 人物被迫选择。  
**词库**：单位、请假条、晚托班、补课费、压岁钱、房贷、厂门口、小区门卫、菜市场、亲戚席面、成绩单、电话听筒、存折、随礼、排名、门卫登记。  
**原则**：不概括「时代变了」，只写一张假、一笔礼、一句比较怎样逼出选择。

### 通用空间清单

厨房、灶台、饭桌、加床、客厅帘后、阳台、晾衣绳、楼道、铁门、门卫室、菜场摊位、校门口、单位走廊、厂门口、亲戚席面、医院走廊、听筒两头、出租屋、自行车棚、晚托教室门口。

一场只选一个主场。门口和听筒算场，不算「路过」。

### 声、味、光（必须推动行动）

- 声：新闻、锅盖、楼道脚步、车铃、讨价、小孩哭、门碰、电话忙音。
- 味：油烟、肥皂、烟、药水、塑料袋、刚洗的头。
- 光：灯缝、路灯、阴天窗、灶火、屏幕亮、门卫亭的白光。

## 细节描写

**总原则**：一个细节要能重复出现，并在后文改意思。

| 类型 | 功能 | 通用词 |
|---|---|---|
| 动作细节 | 小动作揭示关系 | 把鱼肚夹过去、把收据折好、把灯留着、把门虚掩、把碗往前推、把钱塞进抽屉、把鞋摆正 |
| 表情细节 | 压抑或误会 | 笑意没到眼里、脸上空了一下、眼睛躲开、嘴角抖了抖、装作没听清 |
| 服饰细节 | 处境与体面 | 洗白的袖口、起球的毛衣、不合脚的鞋、褪色围裙、校服拉链、工装油点、毛边裤脚 |
| 物件细节 | 记忆、债务、权力、温情 | 搪瓷杯、存折、收据、饭碗、塑料袋、听筒、钥匙、车铃、铅笔刀、小板凳、请假条、补课单 |

**提示**：请围绕【一个物件/一个动作】写细节描写，让它在场景前后意义发生变化，并暗示【人物关系】。

## 描写角度

**正面**：直接写对象，但每句透露处境，不写空泛形容。  
**侧面**：旁人一句话、物件变化、空间反应，不直接评价人。  
**场面**：多人在同一时空的秩序——谁坐哪、谁先说、谁沉默、谁掌握行动权。热闹不是目的。

## 一场描写的最低配置

1. 一个房间或门口 / 听筒。
2. 一口钟（几点到几点，或一顿饭到一趟班）。
3. 一个主物件或一个主动作。
4. 一次关系微变（谁先伸手、谁不再等、谁把门带上）。
5. 明确社会压力从哪里来：可以是外圈一句或一个动作，也可以是电话、纸、班表、旧话；亲密留白场可暂不让外压入场，但同一大章至少两次。

缺一项，先补结构，再堆句子。

## 通用开场 / 收束

**开场优先**：物件位置、钟点、谁先进门、一句口头禅、天气怎样拖住脚。  
**收束优先**：同一物件朝向变了、一句「没事」、门缝里的光、第二天路线还在、账没结。

不要用升华句、不要用作者评论、不要用天气预报式时代总结收束。
