## 结构尺度

- 全书六部：证据 → 缺席 → 争夺 → 安排 → 撤退 → 回看。
- 每部 3 个大章，共 18 个大章。
- 每个大章 5–7 场，完成一次不可逆关系转折。
- 每场只守一个限知视角、一个主场、一口钟、一个主物件、一个主动作和一次状态变化。
- 正式正文每个 md 约 **6000 字**（5800–6200），对应番茄一天只能发 6000 字。一个文件就是一天的更新。
- 一房、一钟约束的是场；不可逆约束的是大章；6000 字约束的是发布文件。
- `第X章.md` 只作通读，不拿整章当发布文件。发布用各章目录下的 `日01.md` / `日02.md` / `日03.md`。
- 大章 1–8 已按日更拆开。往后仍按此落盘。
- 目标体量约 30–50 万字。

## 正文工作流

先整体后局部。节点与顺序见 skill `novel-workflow`。

1. 读 `story-bible.md`、`总纲-大师写法.md`、`中纲/00-全书结构.md`、`中纲/部分/`、`中纲/人物志/` 和 `scene-ledger.md`。总纲骨头认 `总纲-大师写法.md`；中纲从它抽该部，不要另起总纲。
2. 该部中纲未齐：用 `novel-mid-outline` 先写部分总结（必读 `总纲-大师写法.md`），再往下。
3. 用 `novel-character-craft` 确认限知的性格、身世、手、嘴和年段门。
4. 用 `novel-chapter-structure` 与对应 `novel-chapter-*` 补大章纲和场卡，必须写本章人物，以及本章思想、人物变化、背景变化。已写章看文章包「主风格」，对上再写；大章 1–8 走 `novel-chapter-family-realism`。
5. 人物、环境、事物描写必须先走 `novel-thought-ground` 把三栏写出来，再打开材料。
6. 场卡齐后用 `novel-fine-outline` 写成细纲。有材料库再拼文章包；文章包不是正文入口。
7. 用 `novel-prose-from-outline` 按照中纲、细纲、场卡写正文；每个正文 md 写满约 6000 字再存（一天一更）；文末写批注校验（改变、道理、点睛之笔）；修订并回填状态账。不准只凭文章包或印象开写。
8. 一个大章**正文**完成后，做结构、情绪、人物、世界、张力、声音六维复核。不要对未开写的全书矩阵再跑一轮。
9. `正文/` 只在第一场正式开写时创建，不预先建空目录。
