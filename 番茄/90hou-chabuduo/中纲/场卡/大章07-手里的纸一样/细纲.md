# 细纲 · 大章 07 · 手里的纸一样

年段：2000，三人约十岁。限知先赵小满，换场后陈守方，再换场后周建国。一场内部不跳。  
状态：开写前细纲。场序、纸的五寸、称呼时序听 `00-大章.md`。本份只拆手、物、嘴。  
日更：3 日 × 约 7000 字。06 过夜后的同一天上学到还没散的放学，只切呼吸。

开写抓手：赵家门口沿到教室再到 01–02 楼道；第一只手去拎椅背上的包；第一件物是还开着一条缝的门；一口钟从再出门到三家门不开。

| 日 | 场 | 字 | 停在 |
|---|---|---:|---|
| 日01 | 01 带 + 02 看 | 7000 | 她坐下，手按桌沿，那一摞还在前面 |
| 日02 | 03 塞 | 7000 | 手回到桌沿，后座的纸还在传 |
| 日03 | 04 夹 + 05 翻 | 7000 | 三家门关着，一只书包用书按着外侧，一只往里坠 |

日01 不拆纸。日02 不换限知、不夹、不翻。日03 不重写她塞进去，不进三家晚饭。每拍必须换一件看得见的事；两拍物在同一处，后一拍删。纸从场 03 才出现。

口头禅各锁一次：3 都行。4 还行，可跟我带回去。5 没事。后场不复述。

## 日01 · 场01 门（约 3000）

只要：把门带上；盒留在屋里；人不回头按盒。  
句法：拎、挎、迈、带。主物件是再带上的门。

**起笔：** 她从屋里往门走。门还开着一条缝。  
不要用：2000 年、单亲、算了从此开始、纸已经在包里。

| 拍 | 手 | 物 | 嘴 | 停在 |
|---|---|---|---|---|
| 1 带伤 | 从屋里走，去拎椅背上的包 | 门开着一条缝。盒在屋里 | 零句 | 人还在门里 |
| 2 欲望 | 把包挎上肩，带子勒一下 | 包到肩上。肥皂水或鞋只一处 | 零句 | 要先出门 |
| 3 阻力 | 眼往屋里偏 | 盒还在原处，没到门口 | 无 | 盒没动 |
| 4 改小 | 想回头伸向盒，脚先迈出门沿 | 脚在门外。盒还在屋里 | 无 | 人不回头 |
| 5 选择 | 把门带上 | 门从开着一条缝到合上 | 无 | 门在合 |
| 6 后果 | 手离开门沿 | 门轴响一下。门在身后合死 | 无 | 门关着 |
| 7 收 | 在门外把鞋踩实 | 人在门外。盒没出来 | 无 | 换呼吸进 02，不换日 |

拍 2 必须把包挎上。拍 5 必须把门带上。拍 3 盒只被看见，不按。拍 7 不写另外两只书包。

**帮与伤（拍 5）：** 门带上，盒留在屋里；同一只手不回头按盒。

对白许可：零句。

补字只许在拍 1–2、拍 7：拎包、挎肩、踩鞋。

## 日01 · 场02 书包（约 4000）

只要：看见一只平、一只手按着；不叫名；不问第几；进教室，纸还没有。  
句法：走、看、闭、进、坐。纸不拆开。

**起笔：** 门在身后关着。她走那条楼道。路上还没有另外的包。  
不要重写带门。不要问第几。

| 拍 | 手 | 物 | 嘴 | 停在 |
|---|---|---|---|---|
| 1 带伤 | 往楼道走 | 门在身后。包在自己肩上 | 零句 | 人在路上 |
| 2 欲望 | 走几步，带子勒紧 | 肥皂水或座热只一处 | 无 | 要先走到教室 |
| 3 阻力 | 目光停住 | 一只书包平着 | 无 | 平着的包挡住路 |
| 4 改小 | 想开口，手回到自己带子上 | 另一只有手按着 | 无 | 两只都看见了 |
| 5 选择 | 跟着走，不叫，不问 | 三只书包在同一条路上 | 无 | 人不分开 |
| 6 后果 | 侧身进教室门 | 座位在。粉笔灰在。那一摞还在前面 | 无 | 人进了同一间 |
| 7 收 | 按座位坐下，手按桌沿 | 那一摞没拆开。桌上没有纸 | 无 | 日01 停 |

拍 3、拍 4 各看见一只，不要写在同一拍。拍 7 纸还没有。不要叫他们的名。

**帮与伤（拍 5）：** 路走完；同一双眼睛只看，不叫。

对白许可：零句。别人可一声回家了，叫的是别人的名。

补字只许在拍 2、拍 6–7：走几步、座热、找座位、坐下坐稳。

## 日02 · 场03 最里面（约 7000）

只要：按座位接到；看一眼没有多的；塞进最里面；纸还在往后传。  
句法：坐、挂、传、看、塞。不换限知。不夹。不翻。

**起笔：** 她坐下。手按着桌沿。那一摞还在前面。不要重写进门。

| 拍 | 手 | 物 | 嘴 | 停在 |
|---|---|---|---|---|
| 1 带伤 | 手还按着桌沿 | 那一摞还在前面。桌上没有纸 | 无 | 纸还没到 |
| 2 欲望 | 把包从腿上挂到椅背，坐正 | 包在椅背上。粉笔灰落到桌 | 无 | 人坐稳 |
| 3 阻力 | 眼看前面 | 那一摞被拆开。纸按座位传来 | 「一人一份。」「带回去签个字。」 | 纸在传 |
| 4 改小 | 接到，先看旁边，再看回执栏 | 只有这一张。回执栏空着。纸上没有金额 | 无 | 纸在她手上 |
| 5 选择 | 塞进书包最里面 | 纸从手上到最里面 | 「都行。」 | 纸离开手 |
| 6 后果 | 把拉链拉上 | 包往里坠一点 | 无 | 拉链拉上 |
| 7 收 | 手回到桌沿 | 后座的纸还在传 | 无 | 日02 停。不换人 |

拍 2 只坐稳、挂包，不写先不当自己的。拍 4 锁死：没有多的。拍 5 必须塞进最里面。拍 6、拍 7 物不在同一处：一份在她包里，一份还在后座传。  
补字只许在拍 1–3、拍 6：坐稳、粉笔、前座递过的手、拉链头。不要加第二摞表。

**帮与伤（拍 5）：** 没有多的一份进了最里面；刚到手的那张离开手。

对白许可：一人一份。带回去签个字。都行。

|---|---|---|---|---|

| 2 欲望 | 把书边抹平 | 书摊着，边平了 | 无 | 书边平了 |

## 日03 · 场05 翻（约 4000）

只要：先翻背面找数；没有金额，折进内侧；旧条不掏；走回楼道；门不开。  
句法：翻、顶、折、拉、走、停。门外不开第二场。

**起笔：** 旁边书还夹着。纸到这边。不要重写他怎么夹。

| 拍 | 手 | 物 | 嘴 | 停在 |
|---|---|---|---|---|
| 1 带伤 | 接住传到的纸 | 旁边书还夹着。旧条在另一袋 | 无 | 纸在这边 |
| 2 欲望 | 先把纸翻过去 | 背面朝上 | 无 | 背面朝上 |
| 3 阻力 | 眼找「交」「费」 | 背面没有金额。回执栏空着 | 无 | 没有数 |
| 4 改小 | 另一只手指顶住旧条那一袋，不掏 | 旧条只顶着手指。新纸还在手上 | 无 | 旧条没出来 |
| 5 选择 | 把新纸折进内侧 | 纸进内侧。旧条仍在另一袋 | 「没事。」 | 新纸离开桌面 |
| 6 后果 | 把拉链拉死，站起来往楼下走 | 他的包拉死。课散了 | 无 | 人在还没散的放学里 |

拍 2 只翻面，不写还要不要钱。拍 3 必须没有金额。拍 4 旧条不准掏。拍 7 必须门不开。本场不说够、我自己来。  
补字只许在拍 6–7：走几步、还能走的那点亮、自行车座或肥皂水只一处。不要加第二主场。

**帮与伤（拍 5）：** 纸进了内侧；背面先被翻过。

对白许可：没事。
