# 细纲 · 大章 03 · 没事

年段：2000，周建国约十岁。限知只他。可以换空间，不换耳朵。  
状态：开写前细纲。场序、物的五寸、称呼时序听 `00-大章.md`。本份只拆手、物、嘴。  
日更：3 日 × 约 7000 字。02 带到门口的同一晚，晚饭从无到有，只切呼吸。

开写抓手：周家门口到饭桌；第一只手攥带跨门沿；第一件物是从关到开的门；一口钟从门口到晚饭未散。

| 日 | 场 | 字 | 停在 |
|---|---|---:|---|
| 日01 | 01 松 + 02 热 | 7000 | 围裙在门外，他也在门外，秤还没上 |
| 日02 | 03 算 | 7000 | 肉提起，邻家门口一闪，碗没推 |
| 日03 | 04 短 + 05 静 | 7000 | 筷停在碗沿，他没有问 |

日01 不数钱。日02 不把没事说圆。日03 不重写摊上的算。每拍必须换一件看得见的事；两拍物在同一处，后一拍删。

## 日01 · 场01 门（约 3000）

只要：门开了；带攥着跨过门沿；屋里有热，桌上没有肉。  
句法：停、开、跨、攥。不去摊。

**起笔：** 手还按在门板上。带子勒着掌心。门还关着。  
不要用：那年父亲下岗。

| 拍 | 手 | 物 | 嘴 | 停在 |
|---|---|---|---|---|
| 1 带伤 | 手按在门板上 | 门关着。带攥着，勒出印 | 可有「能吃苦」的尾巴 | 人在门上 |
| 2 欲望 | 五指扣住门沿 | 门还关着。门缝里有热、有锅响 | 无 | 要进门 |
| 3 阻力 | 门被推开，或他自己推 | 门开了。桌上没有那块肉。椅子还在 | 「回来了。」 | 门开着，桌空着这块 |
| 4 改小 | 想问，手先把带再勒紧 | 带更深进掌心。屋里锅响 | 无 | 人还在门沿 |
| 5 选择 | 攥着带跨过门沿 | 门在身后 | 无 | 脚过门沿 |
| 6 后果 | 脚站到桌这边 | 椅子、热气。桌上没有肉 | 无 | 桌空着这块 |
| 7 收 | 带还不放，挂在手里 | 屋里有热，这块不在 | 无 | 换呼吸进 02，不换晚 |

不要写「这顿饭像没事」。

**帮与伤（拍 5）：** 人进了屋；同一只攥紧的带跟进来。

## 日01 · 场02 围裙（约 4000）

只要：围裙从桌边走到门口；他跟着出去。钱不数。  
句法：走、跟、跨。秤不上。

**起笔：** 围裙还在桌边。桌上没有肉。带子还在他手里。

| 拍 | 手 | 物 | 嘴 | 停在 |
|---|---|---|---|---|
| 1 带伤 | 人在桌这边，带还攥着 | 桌上没有肉。屋里有热 | 无 | 人在屋里 |
| 2 欲望 | 眼看灶口 | 锅盖着，没有那块。热气在 | 无 | 饭还要做 |
| 3 阻力 | 脚还没动 | 围裙离开桌边，往门口走。布边擦过椅背 | 「这个少要一点。」「回头再买。」「够吃。」 | 围裙在走 |
| 4 改小 | 想坐下等，屁股离椅，脚先落地 | 椅子空了 | 无 | 人开始跟 |
| 5 选择 | 跟着，带仍攥 | 围裙到门口 | 无 | 不问去哪 |
| 6 后果 | 跟过门沿，带子晃一下 | 围裙在门外。他也在门外。楼道还亮着 | 无 | 两个人都出门 |
| 7 收 | 带还不放 | 摊在前面。秤还没上 | 无 | 日01 停 |

拍 6 必须两个人都到门外。不要数钱。

**帮与伤（拍 5）：** 他跟着；同一只攥着的带跟到门外。

对白许可：少要一点。回头再买。够吃。

补字只许在拍 1–2、拍 6：屋里热、跟几步、楼道嗡。

## 日02 · 场03 秤（约 7000）

只要：钱过一次手；他不伸手；少抓一块；提肉路过邻家门口，碗不推。  
句法：走、开缝、过手、停秤、少抓、提、闪。摊上不说圆没事。

**起笔：** 围裙到了秤边。秤盘空着。他的手还在带子上。不要重写出门。

| 拍 | 手 | 物 | 嘴 | 停在 |
|---|---|---|---|---|
| 1 带伤 | 跟到摊上，带勒着掌心 | 秤盘空着。鞋边有土。摊还在出货 | 无 | 人在摊边 |
| 2 欲望 | 眼看秤，看哪一块 | 摊热、腥。哪一块还没被拿走 | 无 | 要称出今晚那一点 |
| 3 阻力 | 手不伸 | 内袋开一条缝。零钱摊在秤边，走过一次 | 无 | 钱在眼前 |
| 4 改小 | 想按住要滚的硬币，手改按回带子 | 带按住。内袋不掏空 | 无 | 他的手不碰钱 |
| 5 选择 | 看她把一块放回去 | 秤停一下。肉少了一块 | 无 | 肉变少 |
| 6 后果 | 跟着往回走，手还在带子上 | 肉进网兜或手里。摊声落在身后 | 「老师家的有出息。」 | 肉在往回走的路上 |
| 7 收 | 手还在带子上 | 邻家门口闪过一个人，没有碗推出来 | 无 | 日02 停 |

拍 3 钱只露这一次。拍 5 必须少抓。拍 6 把往回走的几步写完。拍 7 留给 04。

**帮与伤（拍 5）：** 袋没有翻空；同一停，他的手没伸出去。

对白许可：老师家的有出息。

补字只许在拍 1–2、拍 6：走到摊、看货、提起、往回走。不要再数第二遍。

## 日03 · 场04 肉（约 4000）

只要：父亲说没事，不看他，把那一点肉拨进他碗。  
句法：上桌、不看、拨、过碗沿。桌上不再数钱。

**起笔：** 那一点肉到了桌中间。父亲的筷还没动。不要重写秤。

| 拍 | 手 | 物 | 嘴 | 停在 |
|---|---|---|---|---|
| 1 带伤 | 把带挂到椅背上 | 肉到了桌边。椅背勒着带 | 无 | 肉还没进他碗 |
| 2 欲望 | 眼看那一点肉 | 碗里有饭。热气上来 | 无 | 这顿要吃上 |
| 3 阻力 | 抬头，对不上父亲的眼 | 父亲眼睛看着碗 | 「没事。」「家里还能供。」 | 话对着桌 |
| 4 改小 | 想问，嘴先收短 | 肉还在桌心 | 「够。」 | 问没出口 |
| 5 选择 | 不问，看父亲的筷 | 肉被拨进他碗 | 无 | 肉过碗沿 |
| 6 后果 | 自己的筷还搁着 | 父亲的筷离开他的碗沿。眼仍看着碗 | 无 | 肉在他碗里 |
| 7 收 | 筷拿起来，还没伸 | 桌上没有零钱 | 无 | 换半拍进 05，不换桌 |

父亲拨肉比看儿子更先。能吃苦最多应一声，不当新喊。

**帮与伤（拍 5）：** 肉进碗，饭真热；同一下父亲没看他。

对白许可：没事。家里还能供。够。

## 日03 · 场05 筷（约 3000）

只要：筷伸出去，少夹一下，停在碗沿。不问。  
句法：伸、停、少夹。不新喊没事。门外不开场。

**起笔：** 肉在碗里。筷子伸出去。

| 拍 | 手 | 物 | 嘴 | 停在 |
|---|---|---|---|---|
| 1 带伤 | 筷还搁在桌边 | 肉在他碗里 | 无 | 肉已经在 |
| 2 欲望 | 筷伸向这块 | 晚饭还热 | 无 | 要吃上 |
| 3 阻力 | 眼看着碗 | 父亲仍不看他 | 无 | 脸对不上 |
| 4 改小 | 想多夹，筷先停在碗沿 | 筷尖抵着沿 | 无 | 还没夹 |
| 5 选择 | 少夹一下，停住 | 筷离开肉，回到碗沿 | 「我自己来。」 | 不问 |
| 6 后果 | 低头把这一口送进去 | 饭还热 | 无 | 他真吃上 |
| 7 收 | 筷停在碗沿 | 肉还在碗里 | 无 | 日03、本章停 |

拍 6 必须让他吃上这一口。不要让肉、缴费条。

**帮与伤（拍 5）：** 少伸筷，这顿像够；同一停，问没有出口。

对白许可：我自己来。
