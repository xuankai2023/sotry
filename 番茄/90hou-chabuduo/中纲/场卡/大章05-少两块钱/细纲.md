# 细纲 · 大章 05 · 少两块钱

年段：2000，周建国约十岁。限知只他。可以换空间，不换耳朵。  
状态：开写前细纲。场序、物的五寸、称呼时序听 `00-大章.md`。本份只拆手、物、嘴。  
日更：3 日 × 约 7000 字。04 过夜后的同一上学日，条从没有到叠小，只切呼吸。

开写抓手：楼道到摊；第一只手按空口袋出门；第一件物是已关的邻家门；一口钟从出门上学到条叠小。

| 日 | 场 | 字 | 停在 |
|---|---|---:|---|
| 日01 | 01 松 + 02 热 | 7000 | 条在掌心，还平 |
| 日02 | 03 走 | 7000 | 条到摊边，围裙还在出货，内袋没开 |
| 日03 | 04 短 + 05 静 | 7000 | 条叠很小，在掌心 |

日01 不数钱。日02 不掏内袋。日03 不重写路上的走。每拍必须换一件看得见的事；两拍物在同一处，后一拍删。钱只数这一回。条只叠这一回。

口头禅各锁一次：去上学（01）。资料费这周交齐 / 老师家的交过了 / 我自己来（02）。交了没（03）。等一下 / 差一点儿 / 够（04）。没事 / 先拿我的烟钱垫 / 家里还能供（05）。后场不复述。

## 日01 · 场01 过门（约 3000）

只要：出门；按空口袋；经过已关的邻家门，不推。条还没有。  
句法：出、按、过。不进教室门口。

**起笔：** 他还从那条楼道往外走。邻家那扇门关着。  
不要用：那年要交资料费。

| 拍 | 手 | 物 | 嘴 | 停在 |
|---|---|---|---|---|
| 1 带伤 | 跨出自家门槛 | 邻家门在前面，关着 | 无 | 人在自家门槛 |
| 2 欲望 | 书包上肩，往楼道走 | 楼道灯或脚步只一处。书包在肩上 | 可有「去上学」 | 人在楼道 |
| 3 阻力 | 手按口袋 | 口袋是空的 | 无 | 口袋扁 |
| 4 改小 | 走到门边，手抬一下，不按上门板 | 门近了，仍关着 | 无 | 手离开门 |
| 5 选择 | 侧身经过，手不推 | 人和门错开 | 无 | 门没开 |
| 6 后果 | 继续往前 | 门落到身后 | 无 | 门在身后 |
| 7 收 | 往学校走，书包带晃一下 | 楼道还在。书包在肩上 | 无 | 换呼吸进 02，不换日 |

拍 2 必须让人真走到楼道。拍 7 必须把这段路走完。不要看见碗。不要提前写条。

**帮与伤（拍 5）：** 人过了门；同一只手没推。

对白许可：去上学。

补字只许在拍 2、拍 7：门槛、书包上肩、楼道灯、脚步。

## 日01 · 场02 条（约 4000）

只要：教室门口，条第一次发到他手里；不摊。  
句法：站、发、接、按。不走去摊。

**起笔：** 他站到教室门口。手里没有条。不要重写过门。

| 拍 | 手 | 物 | 嘴 | 停在 |
|---|---|---|---|---|
| 1 带伤 | 站到门口，脚站稳 | 门口没有他的条。粉笔灰可有 | 无 | 人在门口 |
| 2 欲望 | 眼看名单 | 名单上有他的格 | 无 | 格在 |
| 3 阻力 | 手还空着 | 王老师把条发下 | 「资料费这周交齐。」 | 条在老师手里 |
| 4 改小 | 手先伸向自己那张，不伸向旁人的袋 | 自己的条到指尖 | 无 | 条刚到手 |
| 5 选择 | 接住，拿到自己这边，不摊开 | 条在掌心 | 「我自己来。」 | 条在自己这边 |
| 6 后果 | 手按住掌心那张 | 旁人钱袋递过 | 「老师家的交过了。」 | 钱袋过去了 |
| 7 收 | 从门口退半步 | 条还平，贴在掌心 | 无 | 日01 停 |

拍 2 必须让名单格被看见。拍 5 必须让条到他手里。拍 6 必须让那一句过去。

**帮与伤（拍 5）：** 条到自己这边；同一只手把条接住，不摊。

对白许可：资料费这周交齐。老师家的交过了。我自己来。

补字只许在拍 1–2、拍 6：站稳、粉笔灰、钱袋声。不要写成中学办公室。

## 日02 · 场03 跟（约 7000）

只要：同一张条从门口跟到摊边；不摊给旁人；经过已关的门，不推。  
句法：走、按、过门、到摊。内袋不开。

**起笔：** 条还在掌心。他往校门外走。不要重写发条。

|---|---|---|---|---|
| 1 带伤 | 离开教室门口 | 条在掌心，还平 | 无 | 人出教室门口 |
| 2 欲望 | 出校门，往前走 | 条在手里。校门落到身后。路上有热、有土 | 无 | 人在校门外 |
| 3 阻力 | 手把条按紧 | 有人侧过来 | 「交了没。」 | 条还在明处 |
| 4 改小 | 想展开再看一眼，改按进身前 | 条贴着身，不摊开 | 无 | 条不在明处 |
| 5 选择 | 按住，继续走 | 条在自己这边。楼道在前面 | 无 | 人还在走 |
| 6 后果 | 经过邻家门，手不推 | 门关着。走廊可一闪 | 无 | 门不开 |
| 7 收 | 走到摊边，站住 | 围裙还在出货。菜味上来。条还在他这边。内袋没开 | 无 | 日02 停 |

拍 2 必须把出校门走完。拍 5 必须让楼道还在走。拍 7 必须让围裙真的在出货。不要掏袋。不要看见碗。

**帮与伤（拍 4+5）：** 条自己拿回去；同一张条跟到摊边。

对白许可：交了没。

补字只许在拍 2、拍 5、拍 7：出校门、热、土、楼道、摊热、菜味。

## 日03 · 场04 袋（约 4000）

只要：内袋第一次为这张条掏出来；数到少两块；他不报。  
句法：递、开缝、数、停。烟不垫。条不叠。

**起笔：** 条到了围裙边上。内袋还没有打开。不要重写路上的走。

| 拍 | 手 | 物 | 嘴 | 停在 |
|---|---|---|---|---|
| 1 带伤 | 把条递到围裙边 | 条在围裙边上 | 无 | 袋还没开 |
| 2 欲望 | 人站到围裙边上 | 围裙还在出货。条平着 | 无 | 人在摊边 |
| 3 阻力 | 手不伸进袋 | 内袋开一条缝。一卷零钱对着条 | 无 | 零钱出来 |
| 4 改小 | 看她数 | 零钱一张一张过去 | 无 | 还没数完 |
| 5 选择 | 看到少两块，嘴不报 | 零钱停在差两块的位置 | 「够。」 | 少的没出口 |
| 6 后果 | 看她的手按住那一卷 | 零钱不再往下数 | 「等一下。」「差一点儿。」 | 她的手停住 |
| 7 收 | 手还在自己这边 | 少两块摊着。条还平 | 无 | 换半拍进 05，不换摊 |

拍 5 必须让少两块停住。拍 6 是她的手停，不是他再报一次。不要说回头补。不要重称肉。

**帮与伤（拍 5）：** 少的没报给摊上；同一双眼睛看见差两块。

对白许可：够。等一下。差一点儿。
