# 番茄短故事

本 skill 把一篇短故事从选题写到复盘。工程只在 `番茄/短故事/`。一篇一个完整情绪弧，走信息流，不是日更长篇。

它不是：

- 长篇总纲 / 中纲 / 场卡 skill
- 材料库生成 skill
- 把长篇某一场扩成短篇的快捷方式

## 隔离（先执行）

- 只读写 `番茄/短故事/`。
- 禁止打开长篇工程。
- 禁止调用任何 `novel-*` skill。
- 禁止套用长篇的场、人物、句子、一天 6000 字日更。
- 长篇日更规则不适用。单章 1000–2000 字，按篇完结。

## 术语

- **三锁**：基调、一句冲突、微创新。没锁不准开正文。
- **平台分类**：投稿五维，主分类 / 情节 / 角色 / 情绪 / 背景。听 `分类.md`。主分类同时是文件夹：`故事卡/主分类/`、`正文/主分类/`。标签是货架，不是故事卡。
- **故事卡**：一篇的合同。模板是 `故事卡/_模板.md`。
- **开写抓手**：第一场具体空间、第一只手、第一件物、前 300 字读者追问。没有抓手，卡再完整也不能开正文。
- **导语**：正文前三拍，150–250 字。最后一句是未结束的动作。
- **卡点**：约 6–8 千字处切断。卡点前加压，卡点后消解。
- **章**：文件里的 `## 01` 一节。一次反转 + 一句台词 + 一条新信息 + 章末钩子。
- **强度评分**：开写前和改稿前给故事卡打分，低于 8 分不准写正文。
- **台账**：`作品台账.md`。篇目、篇幅、状态、平台分类。
- **资料库**：`资料库/`。只提供事件避雷、人物动作、关系、场景物件、对话潜台词、词语和句法功能，不提供可直接搬进正文的句子。

## 防泛化门

短故事卡不是题材简介。任一为真，退回重写：

- 只写“误会 / 反击 / 成长 / 和解”，没有具体空间、物和当场动作。
- 只用平台标签凑题：打脸逆袭、大女主、虐心婚恋，没有谁在什么场面被什么卡住。
- 书名换掉人名后还能套进任意婚恋、职场、亲情文。
- 一句冲突里没有“谁在什么场面被什么卡住”。
- 微创新只换职业、身份、道具或城市，没有改变事件发动方式、人物选择或后果。
- 反转真相只靠一句解释，不能在前文找到 3 个生活证据。
- 章切只有 1–2 章，撑不起 1.2–1.8 万字。
- 每章升级都是“更生气 / 更误会 / 更心疼”，没有新信息和新动作。

故事卡必须先回答四个具体问题：

1. 第一场在哪里开？读者第一眼看见谁的哪只手碰哪件物？
2. 前 300 字同时到场的反常、冲突、秘密是哪两样？
3. 卡点前哪 5–8 件事逐级加压，不能对调？
4. 卡点后主角做了哪个不同的选择，而不是等别人解释？

## 平台强度门

短故事不是慢热短篇。故事卡、导语、正文任一阶段低于 8 分，先退回上一层，不做句子美容。

| 项 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|
| 书名和一句冲突 | 15 字内有反差，能直接看见当场卡住 | 有题材但冲突不够当场 | 换名可套任意故事 |
| 前 300 字 | 反常、冲突、秘密至少两项在场上发生 | 只有一项真正发生 | 靠作者解释背景 |
| 卡点 | 第 5–6 章有不可逆动作或证据落地 | 只揭一半信息 | 只是人物解释真相 |
| 每章推进 | 每章有新动作、新台词、新信息 | 有新信息但动作重复 | 只换情绪词 |
| 基调兑现 | 虐有疼点、爽有反击、甜有选择、悬疑有回扣、现实有代价、轻喜有错位、温情有边界 | 兑现滞后或偏软 | 只靠留白和讲理 |
| 结尾余味 | 最后仍有选择或证据，不把话说满 | 情绪成立但降温早 | 鸡汤、散文化收束 |

强度不够时按顺序修：

1. 先重做事件发动方式或人物选择。
2. 再重排章切和卡点动作。
3. 再改章末最后一句。
4. 最后才润语言。

## 原创事件门（开写前）

短故事可以使用公共题材和热门情绪，但**不能抄袭，不能有雷同事件**。雷同不只看句子，也看事件链、反转机制、伤害方式、钩子顺序和结局处理。

开故事卡前必须先做：

- 拆出本篇 3–5 个核心事件：开篇当场冲突、第一次升级、卡点动作、反转真相、结局动作。
- 对照 `作品台账.md`、本目录已有 `故事卡/` 和 `正文/`。已有篇目中若有 2 个以上核心事件同构，换题或重做微创新。
- 对网上小说、榜单文、短剧梗同样处理：能换名复述事件链的，视为雷同，不准写。
- 扫榜只许拆结构，不许复用对方的事件组合：同一个开场伤害 + 同一个中段误会 + 同一个结尾补偿，视为洗稿。
- 微创新必须改变事件发动方式、人物选择或后果，不接受只换职业、名字、道具、城市。
- 在故事卡写明「避开了哪些雷同事件」和「本篇独有生活证据」。没写不得开正文。

## 资料库调用规则

资料库是辅助，不是正文来源。每次使用必须先读 `资料库/00-索引.md`，再只打开本任务需要的分文件。

抽取上限：

- 扩主题 / 出选题：先读 `资料库/主题库/00-索引.md`，最多打开 2–3 个主题文件，每个主题只抽主题边界、冲突类型和避雷点。
- 选题：只用 `03-事件避雷与微创新库.md`，确认不撞事件链。
- 填卡：最多抽人物心理动作 1–2 条、关系 1 组、场景物件 1 组、对话功能 1 组。
- 写正文：每章最多抽词语库 1 个分文件、语法库 1 个分文件；词语抽 2–4 个词类，语法只抽句法方向。
- 按基调写：先选虐 / 爽 / 甜 / 悬疑反转 / 现实扎心 / 轻喜讽刺 / 温情成长一个主基调；副基调只许调味，不能改变冲突发动机。

禁止：

- 把资料库模板句、网上小说句、热门稿句改几个词搬进正文。
- 一次打开所有资料库后拼贴。
- 为了显得丰富新增无因果事件。
- 把长篇 00 后的人物、情节、句子移入短故事。

## 路由

### 只说「写小故事」，没有三锁

先读 `资料库/主题库/00-索引.md` 和 `分类.md`，从不同主题里出 3 个选题。每个只带：主题方向、书名、基调、主分类、情绪、一句冲突、微创新、避雷说明。避雷说明只写本题避开了哪类常见雷同事件。问他锁哪一个。不要连问篇幅和人称。默认超短、第一人称，除非他说要中短或第三人称。

锁了再填故事卡，卡满再开正文。不要跳卡直接写。

### 选题 / 扫榜

读 `风向.md`、`分类.md` 和 `资料库/03-事件避雷与微创新库.md`。热门只拆结构：开篇怎么钩、卡点在哪、人设反差在哪、进的是哪个主分类。不抄书名、设定、句子、事件链。扫完把当天备忘写回 `风向.md`。选题必须过 `红线.md`。

### 填故事卡

复制 `故事卡/_模板.md` 为 `故事卡/主分类/篇名.md`。空栏填满。按 `资料库/00-索引.md` 抽少量功能，写清事件指纹、避开的雷同事件和本篇独有生活证据。按 `分类.md` 填平台分类并落进对应文件夹。

故事卡交付前必须补满：

- 平台分类：主分类 1 个，情绪对得上基调，情节 / 角色能空则空，选类理由写清读者进店冲着什么。
- 开写抓手：具体空间、第一只手 / 第一件物、前 300 字到场信息、读者追问、本篇不写什么。
- 卡点前：至少 5 件，优先 6–8 件，每件只升一档，顺序不能随便换。
- 章切：超短默认 8–10 章；每章必须有升级、新台词、新信息和钩子类型。
- 原创性：事件指纹必须是“开篇伤害 / 第一次升级 / 卡点动作 / 反转真相 / 结局动作”，不能只写主题。
- 强度评分：六项总分至少 8 分；低于 8 分退回重填，不准开正文。

红线自检为「否」不准开写。原创性自检为「否」或没填，不准开写。回填台账状态为「卡已填」。

### 写导语

三拍：背景 → 当场冲突 → 未结束的动作。150–250 字。写在 `正文/主分类/篇名.md` 最前，书名后面。简介另写三句：现在多惨 / 转机 / 更大的翻。

### 写正文

只写一章，除非用户点名写几章。落 `正文/主分类/篇名.md`，章用 `## 01` 起两位序号。一篇一个文件。

正文第一句接导语未结束的动作，不要重开场。章法、钩子见 `写法.md`。先读故事卡里点名的资料库分文件，抽功能后重写。写完过 `quality-gates.md`。过门再写下章，回填台账「写作中」。

超短目标 1.2–1.8 万，必须写完一篇再开下一篇。中短按故事卡篇幅。

### 续写

先读故事卡、上一章末尾、台账。从上一章钩子接下去，不用作者概括重新开机。续写是下一章，不是把已写章掺水。

### 改稿

先判断卡、节奏、钩子、红线、语言哪一层坏了。先修上层。卡没改对，不做句子美容。先给强度批注，再说改了哪一刀，最后给改后正文。

改稿批注必须写：

- 前 300 字钩住了什么，缺哪一钩。
- 第 5–6 章爆在哪个动作，不接受只写“真相揭开”。
- 第 8 章兑现了什么选择、证据或关系变化。
- 哪一章章末最后一句太软，需要改成未完成动作、未揭真相、关系翻脸或证据落地。

### 复盘

发文后按 `复盘/00-用法.md` 另存 `复盘/主分类/篇名.md`。下一篇只改一件事。

```text
隔离

→ 主题库（无三锁则从不同主题出 3 个选题）
→ 三锁
→ 平台分类
→ 原创事件门
→ 红线
→ 填故事卡
→ 导语
→ 按章写正文（一章一门）
→ 回填台账
→ 复盘（有发文再写）
```

跳步退回。没有故事卡不准开正文。红线未过不准开写。

## 正文硬规则

- 前 300 字：反常、冲突、秘密至少两样到场。
- 每章：一次态度反转或背叛升级 + 一句更狠或更软的台词 + 一条新信息。
- 章末钩子四类轮换：秘密切断 / 危机落地 / 局面突塌 / 不该出现的人进画。结尾要急，最后一句必须让读者还有一个动作、证据或人没看完。
- 卡点前 5–8 个事件，每条只升一档。卡在情绪最高处。
- 卡点后：延续 → 消解 → 成长或反击 → 留白。第 7–8 章不能连续降压，结尾前仍要有一次选择或证据兑现。
- 2–4 人。每人「嘴上说 / 手里做」。虐文双向有情，不要一边纯恶一边纯惨。
- 情绪词后面必须接这个场景独有的手或物。
- 过场一句带过。不搬别人成稿，不过 `cannot-copy.md` 不得定稿。
- 不写雷同事件链。若开篇伤害、升级误会、卡点反转、结局补偿与网上小说、热门稿或本目录旧篇能换名复述，退回故事卡重做。
- 资料库只抽功能，不抽成句；词语库只抽词类，语法库只抽句法方向，不生成固定指纹。

## 故事卡硬规则

- 先写第一场，不先写道理。第一场必须有门、桌、柜台、病床、工位、校门、厨房、快递柜等可见空间。
- 每个人物都要有“嘴上说 / 手里做”的反差；没有反差的人删掉。
- 生活证据必须进入事件链，不能只列在自检里。
- 章切不许重复钩子类型超过两章；连续两章都靠解释推进，退回重排。
- 爽文反击要靠证据、手续、选择，不靠天降贵人。虐文要双向有情，不靠单方受虐。甜文要靠互相选择，不靠误会拖满篇幅。
- 平台分类必须填。主分类只有 1 个，情绪对得上基调，情节 / 角色没有硬贴。标签不能代替一句冲突。

## 落盘

| 文件 | 规则 |
|---|---|
| `故事卡/主分类/篇名.md` | 一篇一卡，按主分类进文件夹 |
| `正文/主分类/篇名.md` | 一篇一文件：导语 + `## 01` 起各章，单章 1000–2000 字 |
| `作品台账.md` | 选题后就挂上；状态和平台分类随写更新 |
| `复盘/主分类/篇名.md` | 只在发文后 |

书名作目录名时去掉标点，短、能认。

## 交付

- 选题：三个选项，短，让用户选。每个带主分类和情绪。
- 故事卡：只改该篇卡。
- 正文：按章给 md。不要在回复里只贴半章当完稿。
- 改稿：先说改了哪一刀，再给正文。
- 写完一章：报字数、本场升级、钩子类型、打开了哪些资料库、下一章从哪接。
