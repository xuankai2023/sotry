# 风向

热门一个月会变。动笔前扫，不要把本页当永久菜单。

## 去哪看

- 番茄作家助手：作品 → 短故事 → 热门故事。
- 小红书账号「番茄作家助手」：热门题材、风向雷达图。
- 番茄 APP 短故事相关榜。只拆结构：开篇怎么钩、卡点在哪、人设反差在哪。不抄设定、不搬句子。

扫完把当天看到的写进本页「本周备忘」，过期就划掉。

## 常见方向（只作入口，以当周榜为准）

超短常吃：虐心婚恋、婚姻家庭、女性成长、悬疑惊悚。情节上常见打脸逆袭，不要为了热度去追妻火葬场、系统、金手指。

中短常吃：追妻/追夫、重生虐恋、倒计时、换夫换妻、学乖、报恩。本工程仍按 `分类.md` 和 `红线.md` 决定跟不跟。

选之前过一遍 `红线.md`。极端亲子恨、性别对立、丑化公职，即使榜上有类似味道也不跟。货架热、稿子踩红线，仍不准写。
