# 按基调拆分 · 索引

短故事按基调拆材料，避免一篇里多个发动机混用。

## 入口

| 目录 | 主功能 |
|---|---|
| `01-虐/` | 误会、亏欠、迟到的在意；内有 `词语库.md`、`语法库.md` |
| `02-爽/` | 压迫、证据、反击和反转；内有 `词语库.md`、`语法库.md` |
| `03-甜/` | 误会、靠近、互相选择；内有 `词语库.md`、`语法库.md` |
| `04-悬疑反转/` | 反常、线索、误导和真相回扣；内有 `词语库.md`、`语法库.md` |
| `05-现实扎心/` | 普通困境、关系账、选择代价和余味；内有 `词语库.md`、`语法库.md` |
| `06-轻喜讽刺/` | 错位、误会、社交尴尬和反讽回弹；内有 `词语库.md`、`语法库.md` |
| `07-温情成长/` | 小修补、主动选择、边界和不说满的暖；内有 `词语库.md`、`语法库.md` |

## 使用规则

- 一篇只选一个主基调。
- 副基调只能调味，不能改变冲突发动机。
- 每个基调都必须先过 `../03-事件避雷与微创新库.md`。
- 按基调写正文时，只读当前基调的 `词语库.md` 和 `语法库.md`，不要把多种基调的句法连续混用。
