# 悬疑反转 · 词语库

只抽词类和动作方向，不直接搬句子。

## 反常物

- 反向的门锁
- 多出的签名
- 少一秒的监控
- 被擦过的鞋印
- 空白收据
- 重复来电
- 错位的杯口
- 没拆封的快递
- 倒放的照片
- 改过的备注名

## 线索动作

- 把时间码停住
- 把照片放大一角
- 把聊天记录往前翻
- 把门缝量了一下
- 把标签撕开半边
- 把录音倒回十秒
- 把钥匙齿对上锁孔
- 把名单里那个名字圈住

## 误导词组

- 看起来正好
- 像是顺手
- 少了一个人
- 多了一件物
- 位置不该在那里
- 时间对不上
- 证据太完整
- 解释来得太快

## 反应词

- 顿住
- 回看
- 没接话
- 重新数一遍
- 把手收回
- 先关屏幕
- 只问一句
- 声音低下去

## 禁用替换

- 不写“真相大白”，改抽“时间码 / 名单 / 备注名”。
- 不写“她很怀疑”，改抽“回看 / 重新数一遍 / 把录音倒回”。
- 不写“反转震撼”，改抽“证据太完整 / 解释来得太快”。
