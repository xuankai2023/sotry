# 爽 · 材料入口

爽文主线是“被压住的人拿到证据、时机或能力，做出反击选择”。爽点要靠因果，不靠无脑开挂。

## 分区

| 分区 | 用途 |
|---|---|
| 人物心理动作 | 写忍、看清、决定、反击 |
| 人物关系 | 写压迫、轻视、背叛、翻盘 |
| 场景物件 | 写证据、合同、手机、门禁等功能 |
| 对话潜台词 | 写羞辱、试探、反击台词 |
| [词语库](词语库.md) | 写证据、压迫、反击、时机和翻盘词 |
| [语法库](语法库.md) | 写短促推进、证据落地、反击兑现和章末钩子 |

## 使用规则

- 反击必须有前文埋下的证据或选择。
- 不靠极端对立和群体污名化制造爽感。
- 每次打脸只升一档，不连续三章同一种翻盘。
