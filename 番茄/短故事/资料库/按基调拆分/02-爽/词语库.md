# 爽 · 词语库

本库只服务短故事爽文基调：压迫、证据、反击和反转。只抽词类和动作方向，不直接搬句子。

## 身体动作

- 抬眼
- 站稳
- 松开手腕
- 合上文件夹
- 指尖点住证据
- 往前一步
- 把手机翻面
- 把工牌摘下
- 把椅子推回去
- 没再退

## 证据物件

- 录音波形
- 监控时间码
- 合同骑缝章
- 门禁记录
- 转账备注
- 聊天截图边框
- 快递签收单
- 会议纪要
- 工位抽屉钥匙
- 准考证折痕

## 压迫词组

- 当众点名
- 故意漏报
- 把功劳换名
- 把错推过来
- 卡住权限
- 先扣帽子
- 让她自证
- 用规矩压人
- 把话说死
- 留一张空椅

## 反击动作

- 把原件拿出来
- 把录音播放到关键秒
- 把合同翻到最后一页
- 把门禁记录投屏
- 把署名改回来
- 把辞职信压在桌上
- 把截图按时间排开
- 把对方的话照原样读一遍

## 节奏词

- 正好
- 到点
- 该轮到
- 不急
- 先别关
- 还有一页
- 现在能说了
- 这次不退
- 证据自己到场
- 规则反过来

## 禁用替换

- 不写“逆袭”，改抽“站稳 / 原件 / 署名改回”。
- 不写“打脸”，改抽“录音关键秒 / 合同最后一页”。
- 不写“霸气”，改抽“抬眼 / 不急 / 这次不退”。
- 不写“开挂”，改抽“门禁记录 / 会议纪要 / 前文埋证据”。
