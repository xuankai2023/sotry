# 虐 · 词语库

本库只服务短故事虐文基调：误会、亏欠、迟到的在意。只抽词类和动作方向，不直接搬句子。

## 身体动作

- 指尖退回
- 肩线塌下
- 喉结停住
- 手背擦过空位
- 指腹压住旧痕
- 眼神错开半秒
- 袖口被攥皱
- 脚步停在门外
- 手机贴着掌心发热
- 背影没有回头

## 旧物与证据

- 旧钥匙齿
- 折过的车票
- 没发出去的短信
- 退回的红包
- 病房缴费单
- 纸袋封口
- 雨伞弯骨
- 相册空格
- 录音文件名
- 便签背面的字

## 情绪降噪词

- 慢半拍
- 没接住
- 太迟
- 原来还在
- 说轻了
- 留错地方
- 忍过一秒
- 先放下
- 不再等
- 没能问

## 误会动作

- 把解释删掉
- 把票据藏回夹层
- 把门带上但没反锁
- 把通话记录划过去
- 把伞留在原地
- 把名字写错一笔
- 把药放到门口
- 把礼物退到桌边

## 段尾词组

- 门外的脚步停了
- 屏幕暗下去
- 旧票没有展开
- 雨水顺着伞骨往下滴
- 纸袋口又合上
- 那句解释迟了一章
- 名字还在，称呼变了
- 这次没人追出来

## 禁用替换

- 不写“心碎”，改抽“指尖退回 / 旧票没有展开”。
- 不写“遗憾”，改抽“太迟 / 没能问 / 门外脚步”。
- 不写“深情”，改抽“药放门口 / 伞留原地 / 录音文件名”。
- 不写“误会很深”，改抽“解释删掉 / 名字写错 / 通话记录划过去”。

- 被划掉的称呼

### 动作补强

- 把药盒推回去
- 把号码删到最后一位
- 把相框扣在桌上
- 把围巾折得太齐
- 把票根夹进书里
- 把语音听到一半关掉
- 把伞递过去又收回
- 把门铃按轻一点
- 把解释停在输入框
- 把收据压到杯底
- 把照片翻到背面
- 把病历夹抱紧
- 把称呼改回全名
- 把蛋糕盒拎到门外
- 把旧钥匙放进抽屉
- 把快递单撕到一半

### 反应补强

- 先笑后低头
- 先点头后停住
- 眼睛避开日期
- 手指松不开
- 声音轻到听不清
- 脚尖没有进门
- 肩膀先认输
- 呼吸乱了一拍
- 看见了也没问
- 想追又停
- 没把话发出去
- 把“算了”说太快
- 听完才挂
