# 虐 · 材料入口

虐文主线不是纯惨，而是“嘴上放弃，手里还在意”。每个材料都要同时能帮人、也能伤人。

## 分区

| 分区 | 用途 |
|---|---|
| 人物心理动作 | 写迟疑、隐忍、错过、补救 |
| 人物关系 | 写误会、亏欠、未说出口 |
| 场景物件 | 写病房、雨夜、门口、旧物等功能 |
| 对话潜台词 | 写狠话、软话和句后动作 |
| [词语库](词语库.md) | 写压低情绪的动作、旧物、证据和反应词 |
| [语法库](语法库.md) | 写误会、迟到、留白和低声卡点句法 |

## 使用规则

- 虐点必须由具体选择造成，不靠天降苦难堆叠。
- 伤害方不能纯恶，被伤者不能纯惨。
- 结局可以留白，但不能靠鸡汤和解。
