# 甜 · 材料入口

甜文主线不是没阻力，而是“两个有顾虑的人在具体选择里靠近”。甜点要有误会、行动和确认。

## 分区

| 分区 | 用途 |
|---|---|
| 人物心理动作 | 写躲、试探、照顾、确认 |
| 人物关系 | 写误会、暧昧、互相选择 |
| 场景物件 | 写饭、伞、消息、钥匙等功能 |
| 对话潜台词 | 写嘴硬、玩笑、确认关系 |
| [词语库](词语库.md) | 写靠近、照顾、消息、误会和确认词 |
| [语法库](语法库.md) | 写玩笑、试探、行动甜点和确认关系句法 |

## 使用规则

- 甜来自行动，不靠空泛宠溺。
- 误会要能推动选择，不能拖成水文。
- 结尾留一寸余味，不把生活全部说满。
