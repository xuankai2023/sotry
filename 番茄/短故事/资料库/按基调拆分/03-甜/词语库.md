# 甜 · 词语库

本库只服务短故事甜文基调：误会、靠近、互相选择。只抽词类和动作方向，不直接搬句子。

## 身体动作

- 指尖碰到又缩回
- 低头笑一下
- 把伞偏过去
- 手背贴近杯壁
- 脚步放慢
- 把消息看第二遍
- 站到光下面
- 肩膀轻轻靠近
- 把围巾递过去
- 没有立刻松手

## 甜点物件

- 半把伞
- 温牛奶杯
- 没撤回的消息
- 备用钥匙
- 饭盒隔层
- 创可贴边角
- 充电线
- 车票座位号
- 便利贴小箭头
- 门口小夜灯

## 误会词组

- 以为只是顺手
- 以为发错
- 以为不记得
- 以为谁都一样
- 以为只是客气
- 以为没有等
- 以为已经走了
- 以为没看见
- 以为玩笑是真的
- 以为沉默是拒绝

## 靠近动作

- 把伞往他那边偏
- 把饭盒多留一格
- 把消息停在输入框
- 把钥匙放到显眼处
- 把杯子换成温的
- 把座位号截给对方
- 把创可贴贴在桌角
- 把玩笑收成认真话

## 节奏词

- 刚好
- 没撤回
- 还热
- 留了一格
- 偏了半寸
- 等了一会儿
- 轻一点
- 这次没躲
- 原来记得
- 可以再近一点

## 禁用替换

- 不写“甜宠”，改抽“伞偏半寸 / 饭盒多一格”。
- 不写“心动”，改抽“消息看第二遍 / 手背贴杯壁”。
- 不写“暧昧”，改抽“玩笑收成认真话 / 没撤回的消息”。
- 不写“命中注定”，改抽“备用钥匙 / 小夜灯 / 车票座位号”。

### 动作补强

- 把备注改成少辣
- 把伞往外偏
- 把充电线递过去
- 把钥匙扣留在桌角
- 把消息停在已输入
- 把饭盒最上层留给他
- 把围巾搭到椅背
- 把座位号截屏
- 把歌单名字改掉

### 反应补强

- 笑意没藏住
- 手指停在发送键
- 眼睛先看备注
- 声音轻快一点
- 步子慢下来
- 没把伞推回去
- 看懂后低头
- 耳尖先红
- 玩笑短了一截
- 沉默变得不尴尬
- 她没有躲
- 他把答案说慢
