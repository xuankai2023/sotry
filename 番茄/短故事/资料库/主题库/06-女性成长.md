# 女性成长

## 主题边界

写女性在亲密关系、家庭、职场和自我选择中的看清、离开、重建和反击。不写性别对立，不用苦难堆人设。

## 常见冲突

| 冲突类型 | 可写方向 | 避免雷同 |
|---|---|---|
| 被安排 | 谁替她决定人生 | 不写全员压迫的扁平爽文 |
| 离开 | 她怎样真正拿回选择 | 不只靠新男主拯救 |
| 重建 | 钱、住处、工作如何落地 | 不用一夜暴富解决 |

## 可用人物关系

- 女主 / 伴侣 / 原生家庭
- 女主 / 同事 / 女性朋友
- 女主 / 孩子 / 长辈

## 生活证据

- 银行卡、租房合同、体检单、工牌、旧手机、行李箱。

## 微创新方向

- 改变转折来源：不是被背叛后觉醒，而是一次小账、一份合同、一条权限变化。
- 改变成长结果：不是赢给别人看，而是能独立处理一个生活难题。

## 雷同避让

- 不复用网上小说常见整链：丈夫背叛 → 女主离婚 → 神秘身份曝光 → 众人后悔。

## 可配基调

- 虐：她终于承认自己累了。
- 爽：她把被夺走的选择拿回来。
- 甜：她在关系里保留自己。
