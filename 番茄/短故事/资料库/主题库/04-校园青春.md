# 校园青春

## 主题边界

写同学关系、暗恋、竞赛、升学、误会和成长。不写未成年人擦边，不把霸凌猎奇化。

## 常见冲突

| 冲突类型 | 可写方向 | 避免雷同 |
|---|---|---|
| 暗恋 | 误会怎样从小动作发生 | 不照搬校草校花模板 |
| 竞赛 | 名额、推荐、排名带来压力 | 不用天才开挂解决 |
| 友谊 | 朋友怎样在关键时刻站错位 | 不只靠一封信解释全部 |

## 可用人物关系

- 同桌 / 班干部 / 老师
- 暗恋者 / 被暗恋者 / 好友
- 学生 / 家长 / 补课老师

## 生活证据

- 作业本、座位表、成绩单、校服袖口、饭卡、操场广播。

## 微创新方向

- 改变误会载体：不是情书被捡，是错交的作业、座位调换、饭卡记录。
- 改变成长后果：不是考上就圆满，而是学会说出一次真实选择。

## 雷同避让

- 不复用网上小说常见整链：暗恋多年 → 高考错过 → 多年后重逢 → 误会解除。

## 可配基调

- 虐：青春里的话没来得及说。
- 爽：被低估的人证明自己。
- 甜：两个人在小动作里确认彼此。
