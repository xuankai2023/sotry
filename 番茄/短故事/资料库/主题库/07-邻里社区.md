# 邻里社区

## 主题边界

写小区、楼道、邻居、物业、业委会和熟人社会里的面子、误会、利益和互助。不写地域黑和群体污名化。

## 常见冲突

| 冲突类型 | 可写方向 | 避免雷同 |
|---|---|---|
| 楼道纠纷 | 公共空间怎样变成私人账 | 不写泼妇骂街模板 |
| 物业矛盾 | 责任如何被踢来踢去 | 不写单一恶物业 |
| 熟人面子 | 谁碍于面子不说真话 | 不靠群聊截图包办全部反转 |

## 可用人物关系

- 邻居 / 物业 / 业主
- 独居者 / 热心人 / 旁观者
- 新住户 / 老住户 / 门卫

## 生活证据

- 门禁卡、快递架、电梯监控、物业单、楼道灯、业主群。

## 微创新方向

- 改变冲突入口：不是噪音，而是一件公共物件被谁默认占用。
- 改变反转方式：不是监控揭露，而是日常记录慢慢对上。

## 雷同避让

- 不复用网上小说常见整链：恶邻欺负人 → 监控曝光 → 全小区道歉。

## 可配基调

- 虐：好心被当成应该。
- 爽：规则终于落到对的人身上。
- 甜：陌生人从互防到互帮。
