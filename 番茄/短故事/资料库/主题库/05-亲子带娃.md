# 亲子带娃

## 主题边界

写抚养、再婚、陪伴、教育、照护分工和孩子视角里的误会。不渲染极端亲子仇恨，不把孩子当工具人。

## 常见冲突

| 冲突类型 | 可写方向 | 避免雷同 |
|---|---|---|
| 陪伴缺席 | 谁总在关键时刻迟到 | 不用车祸、绝症强催泪 |
| 再婚关系 | 谁被迫重新排座位 | 不把继父母写成固定反派 |
| 教育选择 | 分数、兴趣、钱如何冲突 | 不写家长一夜醒悟 |

## 可用人物关系

- 父母 / 孩子 / 老人
- 单亲家长 / 新伴侣 / 孩子
- 老师 / 家长 / 同学

## 生活证据

- 接送卡、作业本、儿童水杯、书包、疫苗本、家长群。

## 微创新方向

- 改变孩子知道真相的方式：不是偷听，是物件位置、接送记录、群消息。
- 改变补救方式：不是道歉，而是承担一个长期动作。

## 雷同避让

- 不复用网上小说常见整链：亲子误会 → 孩子重病 → 父母悔悟 → 全家和解。

## 可配基调

- 虐：孩子先学会不等。
- 爽：被忽视的一方停止无偿承担。
- 甜：照护变成可见的共同选择。
