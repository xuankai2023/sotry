# 家庭亲情

## 主题边界

写父母、子女、兄弟姐妹之间的偏心、照顾、亏欠和重新分工。不写极端仇恨、猎奇伦理和单方纯恶。

## 常见冲突

| 冲突类型 | 可写方向 | 避免雷同 |
|---|---|---|
| 偏心 | 资源怎样被默认分给某个人 | 不写模板式“全家只宠假千金” |
| 照顾 | 谁被迫承担日常 | 不只用哭诉解释委屈 |
| 亏欠 | 迟来的补偿是否还有效 | 不用临终忏悔强行和解 |

## 可用人物关系

- 父母 / 长女或长子 / 被偏爱的孩子
- 兄弟姐妹 / 配偶 / 老人
- 子女 / 再婚家庭成员 / 外部亲戚

## 生活证据

- 饭桌座位、房间分配、转账记录、户口本、钥匙、旧照片。

## 微创新方向

- 改变压力入口：不是争宠，而是一个日常分工被所有人默认。
- 改变结局：不是认错团圆，而是重新划清责任。

## 雷同避让

- 不复用网上小说常见整链：被家人误会 → 断绝关系 → 身份反转 → 全家跪求原谅。

## 可配基调

- 虐：爱被分配成责任。
- 爽：长期承担者停止兜底。
- 甜：家庭成员学会具体分担。
