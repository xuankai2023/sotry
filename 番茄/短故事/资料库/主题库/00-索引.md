# 主题库 · 索引

主题库负责扩展题材入口；虐 / 爽 / 甜仍是基调，不在这里新增基调。

## 使用顺序

1. 先选主题方向。
2. 再定基调：虐 / 爽 / 甜。
3. 写一句冲突和微创新。
4. 按 `分类.md` 锁主分类和情绪。主题可以细，主分类必须粗、必须唯一。
5. 进入 `../03-事件避雷与微创新库.md` 过雷同事件门。
6. 填入故事卡，不直接写正文。

## 统一规则

- 主题只提供方向，不提供完整剧情。
- 公共题材可以写，具体事件组合必须新。
- 每个主题都要写出独有生活证据，不能只换人名和身份。
- 主分类对照 `分类.md`，不要在主题文件里自造货架。
