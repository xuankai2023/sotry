# 婚恋亲密关系

## 主题边界

写亲密关系里的误会、选择、放手、复合和重新确认。不写极端对立、羞辱猎奇和纯靠第三者推动的狗血。

## 常见冲突

| 冲突类型 | 可写方向 | 避免雷同 |
|---|---|---|
| 误会 | 信息差怎样被人为放大 | 不照搬“误会多年后病房揭真相” |
| 分手 | 谁先做出伤人的选择 | 不只换男女身份 |
| 复合 | 对方用什么行动补一寸 | 不用豪车、戒指、雨夜跪求收尾 |

## 可用人物关系

- 恋人 / 前任 / 新关系中的第三人
- 夫妻 / 长辈 / 孩子
- 暗恋者 / 被误解者 / 旁观朋友

## 生活证据

- 聊天记录、钥匙、合照、外卖地址、共同账单、行李箱。

## 微创新方向

- 改变误会来源：不是偷听，是系统提醒、旧地址、共同账户。
- 改变选择后果：不是追回，而是各自承担一个新代价。

## 雷同避让

- 不复用网上小说常见整链：分手羞辱 → 重病隐瞒 → 男主后悔 → 雨夜追妻。

## 可配基调

- 虐：在意来得太晚。
- 爽：被轻视者拿回选择权。
- 甜：误会解除后用行动确认关系。
