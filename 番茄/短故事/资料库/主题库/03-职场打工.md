# 职场打工

## 主题边界

写普通人工作里的背锅、抢功、裁员、加班、晋升和尊严。不写行业说明书，不把公司制度当主角。

## 常见冲突

| 冲突类型 | 可写方向 | 避免雷同 |
|---|---|---|
| 背锅 | 谁把错误推给沉默的人 | 不写万能录音一秒翻盘 |
| 抢功 | 成果怎样被拿走 | 不只靠老板突然醒悟 |
| 裁员 | 选择谁留下暴露关系 | 不把所有同事写成恶人 |

## 可用人物关系

- 新人 / 老员工 / 直属领导
- 同事 / 客户 / HR
- 打工者 / 家人 / 前同事

## 生活证据

- 工牌、群消息、会议纪要、报销单、打卡记录、电脑权限。

## 微创新方向

- 改变证据来源：不是录音，而是版本记录、权限日志、报销链。
- 改变反击方式：不是当众打脸，而是让制度按原规则回到对方身上。

## 雷同避让

- 不复用网上小说常见整链：被同事陷害 → 总裁识破 → 当场开除坏人 → 女主升职。

## 可配基调

- 虐：努力被误认成应该。
- 爽：证据反推责任。
- 甜：互相撑住打工人的难处。
