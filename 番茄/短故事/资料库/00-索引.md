# 短故事资料库 · 索引

本资料库只服务 `番茄/短故事/`，不引入长篇人物、情节、句子。后续写作只抽功能、动作、词类和生活证据，不直接搬整句。

## 使用顺序

1. 先定三锁：基调、一句冲突、微创新。
2. 需要扩选题时，先进入 `主题库/` 选题材方向，再按 `分类.md` 锁主分类和情绪。
3. 查 `03-事件避雷与微创新库.md`，确认事件链不雷同。
4. 按人物、关系、场景、对话、词语、语法各抽少量功能。
5. 如需按基调写，进入 `按基调拆分/`。
6. 如需补词语，进入 `词语库/`。
7. 如需改句式、钩子或段落节奏，进入 `语法库/`。

## 主库

| 文件 | 用途 |
|---|---|
| `01-人物心理动作库.md` | 把情绪写成手、物、路线和停顿 |
| `02-人物关系材料库.md` | 整理嘴上说与手里做的反差 |
| `03-事件避雷与微创新库.md` | 防抄袭、防雷同事件、生成微创新 |
| `04-场景物件材料库.md` | 提供短故事高频场景和物件功能 |
| `05-对话潜台词库.md` | 提供台词功能和句后动作 |
| `06-正文词句语料扩展库.md` | 管短句、段尾、转折和叙述节奏 |

## 分库

- `主题库/`：婚恋、家庭、职场、校园、亲子、女性成长、邻里、医疗、悬疑、财产、养老、县城乡镇。
- `词语库/`：身体动作、物件动作、情绪状态、关系称谓、场景感官、时间节奏、禁用词替换、动作强度、心理外化、身份职业、社交关系、证据手续、空间位置、转折反应。
- `语法库/`：开头、冲突推进、对话、信息揭示、卡点、章末钩子、段落呼吸、低质句式避雷、转场过渡、误会生成、反转确认、爽点兑现、虐点降噪、甜点行动、视角限知、结尾留白。
- `词库/`：旧入口，兼容早期“词类 + 句式”混合引用；新任务优先走 `词语库/` 和 `语法库/`。
- `按基调拆分/`：虐、爽、甜、悬疑反转、现实扎心、轻喜讽刺、温情成长七类短故事各自的材料入口；每类单独有 `词语库.md` 和 `语法库.md`，用于按基调补词和改句法。
