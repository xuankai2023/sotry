# 场景物件材料库

短故事场景只服务冲突、反转和钩子。物件必须被拿、放、递、藏、摔、还、换或错认。

## 场景模板

| 场景 | 入口动作 | 可藏秘密 | 可升级冲突 | 可做章末钩子 | 避免雷同 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

## 物件模板

| 物件 | 第一次意义 | 中段误会 | 卡点用途 | 结局变意 | 不能重复的用法 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

## 使用规则

- 每章只强化一个主场景或一个主物件。
- 物件不做怀旧清单，只推动选择。
- 同一物件跨篇可重复，但手、决定和后果必须不同。
