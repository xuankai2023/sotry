# 事件避雷与微创新库

本文件用于开写前避开抄袭、洗稿和雷同事件。公共题材可以写，具体事件链必须新。

## 事件指纹

每篇先填：

```text
开篇伤害：
第一次升级：
卡点动作：
反转真相：
结局动作：
本篇独有生活证据：
```

## 雷同判定

以下任一情况，退回故事卡：

- 与网上小说、榜单文、短剧梗或本目录旧篇有 3 个以上事件节点同构。
- 开篇、卡点、结局三处能换名复述。
- 只换职业、名字、道具、城市，人物选择和后果不变。
- 钩子顺序连续相同，且每章新信息功能相同。

## 微创新方向

| 老题材 | 不可只改 | 可以改 |
|---|---|---|
|  | 身份 / 名字 / 道具 | 事件发动方式 / 人物选择 / 后果 |

## 使用规则

- 先保留情绪目标，再重做事件。
- 扫榜只拆钩子、卡点和反差类型，不取具体桥段。
- 写进故事卡的“避开的雷同事件”必须具体。
