# 写法

短故事是情绪产品。前 300 字钩住，每千字加一刀，6–8 千字卡一次。

## 先锁三样

1. **基调**：虐 / 爽 / 甜，一本只主打一种。
2. **一句冲突**：谁、在什么局面、被什么卡住。
3. **微创新**：老梗只改一处。题材可以热，人必须新。

三样没锁，不准开正文。

## 再锁平台分类

三锁管怎么写。平台分类管读者从哪个货架进来，细则在 `分类.md`。

- 主分类只选 1 个：婚姻家庭 / 女生活 / 男生活 / 现言甜宠 / 虐心婚恋 / 青春虐恋 / 男生情感 / 女性成长 / 悬疑惊悚 / 玄幻仙侠。
- 情绪必须对上基调：虐对虐文，爽对爽文，甜对甜宠，甜虐交织对先虐后甜，悬疑对惊悚。
- 情节、角色能空则空。打脸逆袭、破镜重圆、女性互助必须是发动机，不能是味。
- 本工程默认现代。不写系统、金手指、追妻火葬场、真假千金、霸总、玄幻。
- 标签不能代替一句冲突。先有谁在什么场面被什么卡住，再决定进哪一个货架。
- 主分类定了，故事卡和正文进 `故事卡/主分类/`、`正文/主分类/`，不要堆在根目录。

## 导语：三拍

约 150–250 字。

1. 微创新背景：人是谁，局面为什么怪。
2. 当场冲突：有人当场做出伤害或选择。
3. 钩子：下一秒会怎样，正文接着演。

导语最后一句必须是还没结束的动作。正文第一句接这只手、这扇门、这句没说完的话。不要重开场。

简介也是三句：现在多惨 / 会有什么转机 / 后面还有更大的翻。书名 15 字内，口语，有反差。

## 全书两段

**卡点前（约 6–8 千字）**

用 5–8 个事件层层加压。每件事只加一档恨、愧、冷或打脸。卡在情绪最高处：人要走、秘密要揭、局面要塌，先切断。

**卡点后**

情绪先延续，再慢慢消解。补上前面没说清的原因。给一条成长或反击线。结局留白，不要把话说满。

虐文要双向有情：嘴里说不爱，手里却在伤自己。一边纯恶、一边纯惨，读者很快腻。

## 单章

每章只交三样：

- 一次背叛升级，或一次态度反转
- 一句更狠、或更软的台词
- 一条读者刚知道的新信息

章末钩子四选一，轮着换：

1. 秘密揭开前切断
2. 危机刚落到头上
3. 顺的局面突然塌
4. 不该出现的人/物进画

结尾要急。不要散文收束，不要给「可以先放下手机」的信号。

前 300 字：反常、冲突、秘密，至少两样到场。过场一句带过，字数留给加压的那几拍。

## 人

2–4 人。每人写清「嘴上说 / 手里做」。不要三代群像，不要制度说明书。
