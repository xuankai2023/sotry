# 平台分类

番茄作家助手投稿时的五维标签。它是投放层，不是写作层。

主分类同时是文件夹。一篇只进一个：

```text
故事卡/主分类/篇名.md
正文/主分类/篇名.md
正文/主分类/插图/篇名/
复盘/主分类/篇名.md
```

十个主分类文件夹必须和下面名单一致，不要自造。情节、角色、情绪、背景只写在故事卡里，不另建文件夹。

- 写作层仍用 `主题方向` + `基调` + 三锁，听 `写法.md` 和 `资料库/主题库/`。
- 投放层用本页：主分类 / 情节 / 角色 / 情绪 / 背景。
- 标签是读者进店货架，不是故事卡，不能用「打脸逆袭 + 大女主」代替一句冲突。

先锁三锁，再贴标签。没有三锁不准先选分类凑题。

## 怎么选

| 维 | 数量 | 规则 |
|---|---|---|
| 主分类 | 必选 1 | 按读者进店冲着什么选，不按作者自我定位，不按场上出现过的所有味道 |
| 情节 | 0–2 | 必须是冲突发动机。只是味、只是中段一刀，不贴 |
| 角色 | 0–2 | 必须上场并推动冲突。职业场景、路人身份不贴 |
| 情绪 | 必选 1，可加 1 个副 | 必须和内部基调对得上。一篇不要又主虐又主爽 |
| 背景 | 1–2 | 本工程默认带「现代」，再加一个空间：家庭 / 职场 / 校园 / 娱乐圈 |

其余合计不超过 5 个。宁少勿滥。货架贴多了，进店的人会对错故事。

选之前过 `红线.md`。标签热、稿子踩红线，仍不准写。

## 主分类（必选 1）

只许用下列 10 个，不要自造。

| 标签 | 读者进店冲着什么 | 本工程怎么用 |
|---|---|---|
| 婚姻家庭 | 亲子、赡养、财产、手足、再婚、婆媳、家庭账 | 发动机是家里的位置、钱、照顾和面子 |
| 女生活 | 现代女性日常处境，不够成长也不够家庭账 | 现有篇目少用；职场若没有「拿回选择」才选它 |
| 男生活 | 男主视角的生活流 | 默认不选。本工程默认女主第一人称 |
| 现言甜宠 | 互选、靠近、日常宠 | 只在发动机是甜、内部基调也是甜时选 |
| 虐心婚恋 | 恋爱或婚姻里的亏欠、错过、轻视、分手 | 发动机是两人关系，不是房子或孩子本身 |
| 青春虐恋 | 校园 / 青春期的爱与错过 | 爱是主卖才选；竞赛、保送、成长是主卖则改女性成长 |
| 男生情感 | 男主视角的情感 | 默认不选 |
| 女性成长 | 女人自己做选择、离开、重建、拿回位置 | 职场打工、自我选择优先走这里 |
| 悬疑惊悚 | 隐瞒、错认、证据、反转在推事件 | 邻里、合租、失踪、身份盗用优先走这里 |
| 玄幻仙侠 | 修仙法术 | 本工程默认不写 |

### 主分类决策

按发动机往下问，命中即停，不要因为场上有多种味道就改选：

1. 隐瞒 / 错认 / 证据 / 反转在推事件？→ 悬疑惊悚
2. 恋爱或婚姻里的亏欠、错过、轻视、分手？→ 虐心婚恋
3. 校园里的爱与错过是主卖？→ 青春虐恋
4. 女人自己做选择、离开、重建、职场拿回位置？→ 女性成长
5. 家庭账：亲子、赡养、财产、手足、再婚、婆媳？→ 婚姻家庭
6. 发动机是互选靠近？→ 现言甜宠
7. 现代女性日常困境，上面都不够格？→ 女生活
8. 用户点名男主视角？→ 男生情感 / 男生活
9. 修仙？→ 不准写

分不清时看书名和一句冲突里「当场卡住的那一下」。卡住的是桌卡、报告、语音，选虐心婚恋或悬疑；卡住的是房本、奶粉、入园表、养老卡，选婚姻家庭；卡住的是名单、工位、背锅，选女性成长。

## 情节（0–2）

| 标签 | 够格 | 不够格 |
|---|---|---|
| 打脸逆袭 | 卡点后靠证据、手续、选择把局面翻过来 | 只骂回去、只靠贵人、只揭身份 |
| 破镜重圆 | 分手双方走向重新选择 | 只重逢、只解释当年、结局不复合也不重新确认 |
| 女性互助 | 另一个女人上场做事，改变手续或证据 | 闺蜜旁白站台、作者替女主说话 |
| 大女主 | 她的选择在推事件，从头到尾是她动手 | 「她很惨然后赢了」、天降身份 |
| 先婚后爱 | 先有婚姻或同居手续，后有感情 | 只是订婚、只是见家长 |
| 追妻火葬场 | — | 本工程不写。极端后悔追妻，和双向有情、红线冲突 |
| 追夫火葬场 | — | 本工程不写 |
| 真假千金 | — | 本工程不写。换皮套，过不了微创新 |
| 系统 | — | 本工程不写 |
| 金手指 | — | 本工程不写。开挂不是生活证据 |

本工程最常用的只有：打脸逆袭、破镜重圆、女性互助。大女主慎贴，它会把现实主义稿送进女强货架。

## 角色（0–2）

| 标签 | 够格 | 不够格 |
|---|---|---|
| 白月光 | 有人把她或别人当成不可替代的过去，并因此做出伤害或选择 | 只是前任、只是旧照片 |
| 婆媳 | 婆媳冲突是发动机 | 婚礼上出现过婆婆 |
| 青梅竹马 | 正文里有共同长大的过去，这段过去在推事件 | 只是同桌、同学、邻居 |
| 姐弟恋 | 年龄差本身构成压力或选择 | 只是男方略小 |
| 女配 | 视角就是女配，她要从配角位置做选择 | 女主身边有个配角 |
| 医生 | 医生是人物，他的职业动作在推冲突 | 故事发生在医院、护士递了一张单 |
| 替身 | 言情替身梗：有人拿她顶替另一个人的感情位置 | 身份盗用、门禁副卡、冒名取件。那种走悬疑，不贴替身 |
| 霸总 | — | 不贴。资料库已禁标签人设 |
| 凤凰男 | — | 慎。极易滑到性别对立，先过红线 |
| 校花校草 | — | 不贴。标签人设，不服务冲突 |

现有篇目多数角色栏填「无」。宁空，不要为了丰富货架硬贴。

## 情绪（必选 1）

内部基调负责怎么写，平台情绪负责读者点进来要什么感觉。两者要对上，名称可以不同。

| 内部基调 | 情绪主 | 可加副 |
|---|---|---|
| 虐 | 虐文 | 救赎 |
| 爽 | 爽文 | — |
| 甜 | 甜宠 | — |
| 虐中带甜 / 甜中带虐 | 先虐后甜 | — |
| 爽中带虐 / 爽中带酸 / 爽中带暖 | 爽文 | 救赎 |
| 悬疑 / 悬疑反转 / 悬疑偏暖 / 悬疑带爽 | 惊悚 | 爽文或救赎 |
| 现实扎心 | 虐文 | 救赎 |
| 现实扎心带暖 | 救赎 | — |
| 轻喜讽刺 | 沙雕搞笑 | 爽文 |
| 温情成长 | 励志 | 救赎 |

| 标签 | 本工程怎么用 |
|---|---|
| 虐文 | 亏欠、错过、位置被拿走，疼点要当场 |
| 爽文 | 证据、手续、选择翻盘，不靠天降 |
| 甜宠 | 互选靠近。带虐的不要标甜宠 |
| 先虐后甜 | 同一对关系先伤后选。甜若来自闺蜜或自救，不要标这个 |
| 救赎 | 有人用行动补过或把位置还回去，不是口头道歉 |
| 惊悚 | 反常、错认、未揭的秘密在场上 |
| 励志 | 她自己跨过一个具体门槛 |
| 沙雕搞笑 | 轻喜、错位、熟人社会尴尬。扎心文不贴 |

一篇不要同时主贴虐文和爽文。读者会进错店。

## 背景（1–2）

| 标签 | 本工程怎么用 |
|---|---|
| 现代 | 默认必带 |
| 家庭 | 主场在家里、婚宴、病房陪护、入园、养老 |
| 职场 | 主场在工位、会议室、离职、裁员 |
| 校园 | 主场在教室、实验室、考场 |
| 娱乐圈 | 本工程暂无；真写再贴 |
| 古代 | 本工程默认不写 |
| 豪门世家 | 本工程不写 |
| 西幻魔法 | 本工程不写 |
| 西方古典 | 本工程不写 |
| 西方现代 | 本工程不写 |

空间标签只标主场。体检在医院、故事发动机是前任和旧地址，标现代即可，不必硬找家庭。邻里、合租、县城没有单独背景，用现代；若主场仍是家里的面子账，再加家庭。

## 主题方向 → 主分类

主题库负责扩题材，主分类负责进店。一篇主题可以细，主分类必须粗、必须唯一。

| 主题方向 | 主分类首选 | 改选条件 |
|---|---|---|
| 婚恋亲密关系 | 虐心婚恋 | 纯甜互选 → 现言甜宠 |
| 家庭亲情 | 婚姻家庭 | 她离开家庭位置去重建生活 → 女性成长 |
| 职场打工 | 女性成长 | 只写日常处境、没有拿回选择 → 女生活 |
| 校园青春 | 青春虐恋 | 爱不是主卖，竞赛 / 保送 / 成长是 → 女性成长 |
| 亲子带娃 | 婚姻家庭 | 发动机是她不再做默认母亲 → 女性成长 |
| 女性成长 | 女性成长 | 只是生活流 → 女生活 |
| 邻里社区 | 悬疑惊悚 | 没有隐瞒错认，只是邻里日常 → 女生活 |
| 医疗病房 | 婚姻家庭 | 发动机是恋人或前任 → 虐心婚恋 |
| 悬疑秘密 | 悬疑惊悚 | 秘密只是婚恋误会的壳 → 虐心婚恋 |
| 财产合同 | 婚姻家庭 | 她用手续把自己从家里摘出来 → 女性成长 |
| 老年赡养 | 婚姻家庭 | — |
| 县城乡镇 | 婚姻家庭 | 回乡日常、婚宴不是发动机 → 女生活 |

## 填到哪里

| 文件 | 写什么 |
|---|---|
| `故事卡/_模板.md` → `故事卡/主分类/篇名.md` | 「平台分类」整栏。选类理由写一句读者进店冲着什么。主分类改了，文件夹一起搬 |
| `正文/主分类/篇名.md` | 正文和插图跟主分类走 |
| `作品台账.md` | 按主分类分表。选题后就挂，不要等发文 |
| 选题交付 | 三个选项各带主分类 + 情绪，方便对货架，不代替三锁 |
| `复盘/主分类/篇名.md` | 发文后看进店对不对，下一篇只改货架或只改写法，不要两头一起改 |

填卡时对照本页。主分类空着、贴了「本工程不写」的标签、或其余标签超过 5 个，退回重填。

- 病房、体检不贴医生：医院是场，医生不是人物发动机。
