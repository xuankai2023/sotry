# 番茄短故事

独立工程。不读、不引、不改长篇目录。

平台官方名是「短故事」，作者口里常叫「小故事」。一篇一个完整情绪弧，走信息流，不是日更长篇。

## 目录

| 路径 | 干什么 |
|---|---|
| `skill/SKILL.md` | 开工总控。选题、填卡、导语、分章、复盘都听它 |
| `skill/quality-gates.md` | 章门、开篇门、篇门 |
| `skill/cannot-copy.md` | 不能搬 |
| `写法.md` | 选题、导语、卡点、章法 |
| `分类.md` | 平台五维：主分类 / 情节 / 角色 / 情绪 / 背景 |
| `红线.md` | 不能写的内容 |
| `风向.md` | 去哪扫榜，热门只作参考 |
| `故事卡/_模板.md` | 开写前先填卡 |
| `故事卡/主分类/` | 每篇一卡，按主分类进文件夹 |
| `正文/主分类/` | 每篇一个 md，导语和各章写在同一文件 |
| `复盘/主分类/` | 发文后记数据与改法 |
| `作品台账.md` | 篇目、字数、状态、平台分类 |

## 篇幅

- 超短：8千–2.49万字，必须完结。新人先写 1.2–1.8 万。
- 中短：2.5万–8万字。可先交前 1 万 + 大纲。
- 单章：1000–2000 字。按情节转、场景换、情绪折来切，不要按字数腰斩。

番茄长篇「一天 6000 字」的日更规则不适用于本目录。短故事按篇完结，一章写满即停。

## 开工顺序

1. 扫 `风向.md`，锁基调、一句冲突、微创新。
2. 按 `分类.md` 锁主分类和情绪，情节 / 角色 / 背景能空则空。
3. 复制 `故事卡/_模板.md` 为 `故事卡/主分类/篇名.md`，填满再开写。
4. 正文落在 `正文/主分类/篇名.md`。
5. 写完回填 `作品台账.md`。发文后补 `复盘/主分类/`。

## 隔离

写本目录任何文件时：

- 只读写 `番茄/短故事/`。
- 禁止打开长篇工程与 `novel-*` skill。
- 走 `番茄/短故事/skill/SKILL.md`。根目录 `.cursor/skills/fanqie-short-story/` 只做跳转。
